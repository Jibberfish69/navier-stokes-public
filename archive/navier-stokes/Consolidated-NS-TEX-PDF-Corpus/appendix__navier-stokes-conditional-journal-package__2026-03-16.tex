\section{Appendix: Open Items for Unconditional Promotion}

This appendix records what must be fully discharged before any unconditional theorem language is mathematically justified.

\begin{enumerate}[leftmargin=*]
\item A fully explicit classical scale-barrier proof at the required hypothesis level.
\item A nonlinear compactness proof that closes the convective term without modified-equation imports.
\item A classical gradient-control argument with complete continuation details.
\item A verified theorem-to-warrant map showing no hidden dependency on regularized dynamics.
\end{enumerate}

Until these are discharged in theorem-bearing form, the correct release posture remains conditional.
