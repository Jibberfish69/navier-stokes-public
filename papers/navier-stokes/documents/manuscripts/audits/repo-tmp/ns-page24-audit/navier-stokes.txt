Global Regularity for Periodic Three-Dimensional Navier–Stokes:
A Same-Solution Contrapositive Proof
Thomas Birnie
May 26, 2026

Abstract
We prove global smooth existence for the incompressible three-dimensional Navier–Stokes
equations on the periodic domain T3 , with smooth divergence-free initial data and zero external
force. A direct proof would give a priori estimates that keep the solution smooth for all time.
That is the gold-standard route. This paper takes the contrapositive route. It takes any
finite-time breakdown claim for the original solution and asks what that claim would have to
identify at the alleged final time.
At the alleged final time, such a claim has to point to a terminal object for the same solution.
The proof then asks a narrow question about that object. Does it still look like the same
Navier–Stokes object: a positive packet, the same equation acting on that packet, and one
coherent field on a positive scale? A yes answer keeps the branch on the smooth side of the
split. A no answer means the object has lost something it needed in order to count as a valid
terminal object for that solution. That is the whole split: pass as the same smooth object, or
fail and leave the class.
The split is checked in three places:
PackQ ,

PartN,Q ,

FieldN,r,Q .

PackQ asks for a positive material carrier. PartN,Q asks whether the same Navier–Stokes
equation, with its pressure and viscosity, still acts on that packet. FieldN,r,Q asks for positivescale field control on one witness record. The first place where the terminal object fails gives

Original Problem Statement

The problem is the incompressible three-dimensional Navier–Stokes existence and smoothness
problem. On the periodic three-torus T3 , the velocity u(x, t) and pressure p(x, t) satisfy
∂t u + (u · ∇)u + ∇p = ν∆u,

∇ · u = 0.

The datum is a smooth divergence-free velocity field u0 , and the solution starts from
u(·, 0) = u0 .
Here ν > 0 is fixed. The external force is zero. The question is whether the smooth solution
determined by u0 can lose smoothness at a finite time.

4

Reframing the Problem

This is the point where the paper changes the question. For a claimed finite breakdown, the first
burden is membership. A breakdown claim owes the reader a terminal object for the original
Navier–Stokes solution. The proof asks whether that object still belongs to the class defined by the
problem.
The guess behind the method is simple. The Navier–Stokes equations are expected to be smooth
for all time. Many blowup pictures look dangerous because they picture a failure mode without
checking whether the picture is still inside the problem. A packet with no carrier, a source with no
same-fluid ancestry, a slip between two fields, or a broken derivative tower may describe a failed
proof object. The class question asks whether it describes the original Navier–Stokes solution.
So the proof first asks what the picture is. Does it still have the same datum, the same equation,
the same pressure, the same viscosity, the same incompressibility law, the same velocity field, and
the same terminal witness record? A positive answer puts the object on the pass side of the split. A
failed answer gives the exit that the breakdown claim owed us.
This reframing holds the problem fixed. A finite-time breakdown claim has to stay attached to
the original smooth-data solution. The class-membership question is the test for that attachment.

Generally Classifying Failure Types From the List

Now put the list down as physical stories. A few shapes keep coming back.
One shape is loss of body. The terminal picture points at a trace, a pulse, a residue, or a limiting
record, yet the positive packet of the same transported fluid has disappeared.
Another shape is unpaid ancestry. The terminal reserve is assigned to a donor, a parent window,
a pressure channel, or a previous shell, yet the ancestry has left the same fluid object.
Another shape is lost participation. The packet remains visible, while the pressure-viscosityincompressibility law has stopped acting on it as the same Navier–Stokes law.
Another shape is broken neighbour relation. Two readings can be finite and locally meaningful
while failing to join into one smooth velocity field. This is where the Euler slip picture helps the
imagination.
Another shape is tower blowup. The packet stays positive, yet the derivative readings, pressure
readings, or viscous readings lose finite tower control.
Another shape is wrong carrier. A proof may succeed on a regularized, filtered, geometric,
exported, or strengthened object, while the Clay object stays untouched.
These are still pictures. They are deliberately earlier than the formal witness laws. The reader
should first see what the failed objects look like; only then do Pack, Part, and Field become natural
names for the tests.

Silver Standard Approach

The silver-standard approach now has its material. The paper takes the full positive-forward failure
field and asks the class-membership question for each picture. The split is
pass: the object remains the same Navier–Stokes member,
fail: the object exits the Navier–Stokes class.
On the pass side, the object still has the same packet, the same equation, the same pressureviscosity law, and one coherent velocity field. This is the smooth side of the split. On the fail side,
7

the object has lost one requirement that belongs to the problem definition. The failed picture then
cannot be an in-class finite breakdown of the original solution.
The reduced burden has two parts. First, the failure list must cover the possible nonsmooth
terminal pictures supplied by the forward-support field. Second, each nonsmooth picture must be
run through the class test. When the picture loses the packet, it lands at Pack. When it keeps a
packet while losing same-law participation, it lands at Part. When it keeps local readings while
losing one positive-scale field, it lands at Field.
Once the nonsmooth field is exhausted this way, the Navier–Stokes class has no nonsmooth
terminal member. The smooth datum and the local classical solution give the class its ordinary
smooth branch. The terminal work is the pass-or-exit test on every alleged nonsmooth branch.

8.1

Properties of NS Fluid

The Navier–Stokes fluid here is an ideal mathematical fluid. Water, honey, and oil can help the
imagination, yet the object is fixed by the equation. It has a velocity field u, a pressure p, fixed
positive viscosity ν > 0, normalized density through incompressibility, and smooth divergence-free
initial data. The force term is absent. This paper works on the periodic three-torus T3 , so the fluid
lives in a periodic box and the whole transported material atlas can be read on a compact domain.
The defining properties do not change after t = 0. The viscosity does not become another
viscosity. The pressure does not become an optional correction. The incompressibility law does not
acquire a pressure-responsive density variable. The velocity field moves under the same equation:
∂t u + (u · ∇)u + ∇p = ν∆u,

∇ · u = 0.

Viscosity dissipates velocity differences over time, and pressure keeps the field inside the divergencefree constraint. A terminal object that changes these properties has left the problem object.

8.2

Properties of Euler Fluid

Euler is the useful comparison because it removes the viscous term. It keeps transport and pressure
and sets the viscosity to zero. That makes slip easier to picture.
Imagine one plank sliding over another plank that stays still. As a fluid picture, this is two finite
incompressible flows with a tangential break between them. Each side has a velocity. The normal
volume relation can still make sense. The two sides do not form one smooth velocity field across the
interface. This is the simple slip-sheet picture.
In inviscid thinking, that picture is natural. The equation has no viscous tether forcing
neighboring velocities into one continuous profile. For fixed-viscosity Navier–Stokes, the same picture
points at the class-membership test. It may look like a velocity field, and the class-membership test
sees the missing viscous same-field law.

8.3

Viscosity

Viscosity is often described as damping. That is true. The proof also needs the tethering role of
viscosity. Viscosity transmits motion between nearby parts of the fluid. It acts like a tether between
neighboring velocity values. A fast piece pulls on a slow piece, and a slow piece pulls back on a fast
piece.
The Couette-flow picture is the clean version. Two boundary plates move at different speeds.
The viscous fluid between them forms a smooth velocity gradient. Viscosity turns the plank-slip
picture into one continuous velocity field.
A honey pour gives the same intuition in ordinary life. The honey slows as it folds and piles up,
yet the falling stream also pulls nearby honey along with it. The stream carries mass and momentum
through a viscous body. The point for Navier–Stokes is that viscosity damps motion and shares
motion. It gives neighboring packets a common law of response. A siphon gives the same kind of
picture: once the moving column is coupled, one part of the motion pulls the next part along.

8.4

Pressure, Viscosity, Incompressibility

Pressure, viscosity, and incompressibility form one law in the Navier–Stokes class. Incompressibility
says that a transported material volume keeps its volume. Pressure is the global response that keeps
the velocity field divergence-free. Viscosity diffuses velocity through ν∆u and couples neighboring
velocity readings.
These three features leave very little freedom for a terminal packet. A packet may be visible
as a region of space. It may even carry finite velocity values. It still has to take part in the same
pressure-viscosity law on the same incompressible carrier. This is the participation requirement.
This matters most for failure stories that appear as source residue, terminal atoms, or pressure
response. An incompressible Navier–Stokes packet has no separate density variable that can swell
or shrink to pay for a terminal source. It has no separate pressure law that acts on one packet while
the rest of the fluid follows another law. The packet either participates in the same law, or it has
left the class object under test.

Packet Witness Law

The packet law comes first because the proof needs a same-fluid body before it can read participation
or field coherence. A terminal trace, source atom, or endpoint number gives too little by itself. The
object has to give a positive transported packet of the same fluid.
Definition 4 (Packet witness law). PackQ means that the claimed terminal object has a positive
same-fluid packet. There is a transported carrier family for Q, a finite cover with finite overlap, and
a positive lower scale ρQ > 0. The packet is moved by the same velocity field u. A trace with no
positive carrier, or a donor history outside the same flow, fails this law.
On the torus branch, the clean packet is the whole transported material atlas. It is a finite
same-fluid cover of T3 , with finite overlap and positive carrier scale. This keeps packet selection
from becoming a private diagnostic choice. The packet under test is the material object that carries
the alleged terminal obstruction.

11

Packet Failure Types

A packet can fail before velocity blowup is discussed. It can lose every positive terminal radius.
It can name a source atom without a transported body. It can carry a Zeno chain whose parent
packets never leave a positive same-fluid terminal packet behind. It can point to a donor that does
not ride with the same flow. It can let the material atlas degenerate so that the terminal readout
lacks a positive same-fluid cover. These are packet-side failures.
The Zeno cases belong here. A Zeno story can give an endless ancestry of smaller and smaller
packet events near the terminal time. That ancestry supplies a long history, yet the class test
asks for a positive terminal packet Q. An unpaid infinite donor-refill chain, a zero-radius terminal
source residue, or a detached donor history fails Pack before the proof asks whether the velocity
tower is dead, jumped, or blown. Raw terminal source residue is also tested here first. Only after
a positive same-fluid carrier and a participating tower are retained does a sharper Field reading
become available.

12

Velocity Failure Types

The names dead, jump, and blown now have a job. They are mechanism names for the way a
terminal velocity-field picture fails the witness test. The mechanism is read first. The name comes
after the packet has been placed in the Pack/Part/Field tree.

12.1

Dead

Dead is the Part-first failure. A packet remains visible, yet the Navier–Stokes law has stopped
acting on it as the same law through the tower. A zero velocity value is irrelevant here. The packet
has lost same-object dynamics. It is present as a pictured packet and absent as a participating
Navier–Stokes packet.
11

A dead packet usually presses on Field as well. A packet that has lost the same pressure-viscosity
tower cannot keep neighboring tower readings coherent as one same-law field. The failure is seen
first through Part, and its effect spreads to Field.

12.2

Jump

Jump is the Field-first failure. The defining feature is incompatible finite readings.
A jump can appear inside one tower. Here the packet still has a carrier and a participating
law at the level being tested. The break occurs because the readings inside the tower fail to fit as
derivatives of one smooth field. A velocity value, a first derivative, and a higher derivative cannot
be arbitrary independent numbers at one point and one time. They have to be one tower.
A jump can also appear between neighboring packet towers. Finite velocities survive on both
sides while the positive-scale bridge fails. The plank-slip picture is the base-level example. There
are two finite readings and no smooth one-field relation between them.
Jump is native to Field because the visible loss is one-field coherence. It may also expose a Part
defect after the neighboring towers are included in one same-fluid record. The first readout is Field;
the cross-pressure on Part is part of the same terminal story.

12.3

Blown

Blown is the unbounded-tower failure. A positive packet remains visible, and some velocity derivative,
pressure readout, or viscous readout becomes unbounded. The terminal object may look like the
usual blowup picture. The witness test asks where that blowup lands.
There are two main readings. One reading is Pack-side: the deformation or material atlas
degenerates so badly that no positive same-fluid carrier remains. The other reading is tower-side:
the carrier remains, yet the finite-depth tower or its pressure-viscosity readout becomes unbounded.
The tower-side reading is Part-first. It also becomes Field-visible, because a neighboring packet
cannot share one positive-scale field with an unbounded tower reading.
From any packet in the same terminal family, the same event can be seen from the opposite side.
One packet sees its own tower become unbounded. A neighboring packet sees the positive-scale
field relation fail. That is why blown stays inside the witness tree as a Pack, Part, or Field event.

The Contrapositive Logic

The logic board is now simple. A finite-time breakdown claim owes the paper a terminal object for
the original Navier–Stokes solution. That terminal object is admitted to the class-membership test

Lemma 3 (Carrier pattern). A terminal branch with zero terminal radius, detached ancestry,

carrier requirement.
Proof. Each listed mechanism removes the positive transported packet needed to carry Q as the
same fluid branch. The carrier requirement is exactly the existence of such a positive transported
packet. The first lost requirement is therefore ¬PackQ .
Lemma 4 (Participation pattern). A terminal branch with a surviving carrier and broken pressure
participation, broken viscosity participation, dwell failure, or incompatible local source participation
fails the participation requirement.
Proof. After a carrier survives, the continuation branch still has to solve the same differentiated
Navier–Stokes equation on that carrier. The listed mechanisms break that same-equation participation while leaving the carrier question already passed. The first lost surviving requirement is

Proof. After carrier and participation survive, membership readout needs one positive scale where

requirement is therefore PackQ ∧ PartN,Q ∧ ∀r > 0 ¬FieldN,r,Q .
Proposition 11 (No hidden branch outside the patterns). Every selected branch handled in the

alternatives are Pack, Part, and Field. The last alternative is support for a later selected packet.
There is no fourth continuation requirement in the working class object.

The Attempt Chain In Reader Order

The record begins with the four-body circuit because that is where the smoothness project first

viscosity should smooth the fluid. It tried to make four statements pay one another. The scale
statement would keep high frequencies from carrying uncontrolled energy. The Q(t) statement

Closure Of The Failure Record

The failed positive attempts above leave only a small number of mathematical survivors. Every
route that tried to prove smoothness either asked for a direct estimate that would close the classical

proof, or else exposed a terminal object that has to be tested as the same Navier–Stokes solution.
The surviving objects have the same shape from different directions. The scale route leaves
unpaid high-frequency transfer. The Q(t) route leaves the vortex-stretching source. Compactness
leaves the need for a same-surface exact object. The curvature route leaves the need for a periodic
replacement for the geometric drain. The later source, pressure, Zeno, L3 , Leray, and critical-norm
routes leave terminal packets, residues, or readouts that must either pay one of those debts or enter
the class-membership test.
This is the point where the positive history becomes useful to the contrapositive proof. It asks
a mathematical question about the object left by the failed route: does the object still carry a
positive same-solution packet, does that packet still participate in the Navier–Stokes law, and does
the resulting field still have a positive-scale coherent readout?
When the answer is yes through all three questions, the branch is the pass side. It gives the
same-solution membership branch. When the answer first fails, the branch supplies the face failure:
¬PackQ ,

PackQ ∧ ¬PartN,Q ,

PackQ ∧ PartN,Q ∧ ∀r > 0 ¬FieldN,r,Q .

Those are the only exits used by the class proof.
Thus the failure record has a precise job. It identifies what a finite-time breakdown claim has to
carry at the terminal time. The main proof then tests that terminal object. The proof succeeds
only where the terminal object either remains a member of the working class or loses one of the
three witness requirements that define membership.
