We prove global smoothness for the unforced three-dimensional incompressible Navier--Stokes equations on \(\R^3\) for every viscosity \(\nu>0\) and every divergence-free Schwartz initial velocity \(u_0\).
Let \([0,T_*)\) be the maximal classical lifespan of the solution generated by \(u_0\), and suppose that \(T_*<\infty\).
For the fixed whole-terminal rectangle \((N,M)=(0,1)\), the lowest adjacent velocity rows give
\[
u\in L^2(0,T_*;H^2),
\qquad
u_t\in L^2(0,T_*;L^2).
\]
The adjacent trace identity then yields
\[
u\in C([0,T_*];H^1).
\]
Since \(H^1(\R^3)\hookrightarrow L^3(\R^3)\), the same velocity satisfies
\[
\sup_{0\leq t\leq T_*}\|u(t)\|_{L^3(\R^3)}<\infty.
\]
This collides immediately with the finite-endpoint criterion of Escauriaza, Seregin, and \v{S}ver\'ak, which requires
\[
T_*<\infty
\quad\Longrightarrow\quad
\sup_{0<t<T_*}\|u(t)\|_{L^3(\R^3)}=\infty.
\]
Thus no finite maximal endpoint can occur, and the solution is smooth for all \(t\geq0\).
