# Global Smoothness for the Forced Three-Dimensional Incompressible Navier–Stokes Equations

Thomas Birnie · forced-history manuscript · September 2026

**Status:** proof source complete; 82-page reader PDF and reproducible source
bundle prepared for the 21 September 2026 public release. The public source,
PDF, and release bundle are maintained at
<https://github.com/Jibberfish69/navier-stokes-public/tree/main/papers/navier-stokes/global-smoothness-forced-navier-stokes-20260921>.

This directory contains the proof for the one forced history generated by
\((u_0,\nu,f)\). The paper derives the pressure-complete
velocity–pressure–force mixed jet from that datum on every strict horizon.
For every finite pair of temporal and spatial orders, the datum-generated
whole-terminal theorem produces a compatible rectangle and keeps every
selected derivative norm finite through the chosen endpoint. Independently,
the critical-height tower and viscous diagonal relation supply the finite
rectangle identities. Adjacent rows then produce the common
endpoint jet, and local well-posedness restarts the same history from
\(u_*=u(T_*)\) with the same absolute-time force.

run `make bundle` to create the archive under `dist/`.
