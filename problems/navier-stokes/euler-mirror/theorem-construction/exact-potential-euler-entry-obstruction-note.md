# Exact-Potential Euler Entry Obstruction Note

## Purpose

Record the exact point where the parent exact-potential branch ceases to be an
Euler road after viscosity is removed.

This note is theorem-facing on purpose: it is not an audit summary. It states
the strongest honest Euler target still visible before the parabolic branch
begins.

## Parent Aim

The parent exact-potential road tries to convert surviving witness data into a
projective readout and then into an observability packet capable of feeding the
exact-potential `SG.4` supplier chain.

Its theorem order is:

1. class-membership witness to readout splice;
2. exact-potential witness/projector synchronization;
3. static-diffusion or heat-plus-perturbation PDE packet;
4. analytic-semigroup / interval observability / Carleman machinery;
5. measurable-time or windowwise observability;
6. exact-potential downstream supplier/export packets.

## Exact Surviving Euler Interface

The only honest Euler target that survives before the parabolic machinery
starts is the upstream witness-to-readout interface:

```math
\boxed{
\mathcal E_J^{cm}
+
\mathfrak R_J^{ang}
\Longrightarrow
\mathfrak e_{J,\mathrm{ang}}^{cm}
}
\tag{EPW1}
```

That is still a meaningful Euler theorem target because it only asks how the
class-membership witness data enter a branch-sensitive projector/readout packet.

## Exact Non-Euler Entry Point

The branch stops as soon as the parent dynamic packet is imported. The parent
exact-potential `V2` route uses the static-diffusion equation

```math
\partial_t \widetilde q_k
-\nu\,\nabla_\zeta\cdot(G_k\nabla_\zeta \widetilde q_k)
+\widetilde b_k\cdot \nabla_\zeta \widetilde q_k
+\widetilde c_k\widetilde q_k
=
\widetilde f_k^{hi}+\widetilde f_k^{cut}.
\tag{EPW2}
```

The next parent steps then require:

1. analytic-semigroup realization;
2. interval observability;
3. Wang--Zhang measurable-time observability, or a heat/Carleman substitute;
4. downstream static-diffusion readout closure.

After viscosity removal, the principal parabolic operator

```math
-\nu\,\nabla_\zeta\cdot(G_k\nabla_\zeta \widetilde q_k)
```

disappears. So the installed semigroup, heat, Stokes, static-diffusion, and
Carleman road is no longer the same theorem road at all.

This is the first exact non-Euler bridge on the exact-potential branch.

## Terminal Non-Euler Classification

The terminal classification is:

```math
\boxed{
\text{the direct Euler witness-to-projector/readout theorem would be a new
external route; the parent static-diffusion packet is non-Euler.}
}
\tag{EPW3}
```

So the exact-potential road is closed at entry for this branch.

## Status

The exact-potential branch is now honestly classified on Euler:

1. the witness-to-readout splice survives as an Euler theorem target;
2. the branch becomes non-Euler at the first static-diffusion / heat /
   semigroup step;
3. no downstream exact-potential closure claim is honest until a new Euler
   readout road replaces that entry packet.
