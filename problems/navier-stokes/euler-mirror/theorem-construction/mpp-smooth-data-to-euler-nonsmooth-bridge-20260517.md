# MPP Smooth Data To Euler Nonsmooth Bridge

## Status

Theorem-facing bridge note for the Euler mirror.

Role: connect smooth Euler initial data to the nonsmooth slip-sheet witness
without pretending to prove finite-time classical singularity from one fixed
datum.

## Boundary

There are three different statements:

1. a smooth-data singular limit can converge to a nonsmooth Euler member;
2. a weak Euler branch can start from smooth data and leave the classical
   one-field class;
3. one fixed smooth classical Euler solution can form a singularity in finite
   time.

This note proves the first statement directly. The second statement is an
external convex-integration route and must be marked as weak-branch /
non-classical unless an admissibility layer is specified. The third statement
splits by domain: it is known in a boundary/axisymmetric setting, and remains
outside this mirror's terminal classification in smooth finite-energy free space
or periodic no-boundary settings.

## Bridge A: Smooth Stationary Shear Layers To A Slip Sheet

Work locally in two or three dimensions on a window crossing the interface
`\{y=0\}`. Fix constants `a\ne b`. Let `\theta\in C^\infty(\mathbb R)` satisfy

```math
\theta(s)=0\quad(s\le -1),
\qquad
\theta(s)=1\quad(s\ge 1).
```

For `\varepsilon>0`, set

```math
U_\varepsilon(y)
=
b+(a-b)\theta(y/\varepsilon),
\qquad
u_\varepsilon(x,y,t)=(U_\varepsilon(y),0),
\qquad
p_\varepsilon=p_0.
\tag{SDB.1}
```

In three dimensions use `u_\varepsilon=(U_\varepsilon(y),0,0)`.

Each `u_\varepsilon(\cdot,0)` is smooth divergence-free initial data. The
solution is stationary and classical:

```math
\nabla\cdot u_\varepsilon=0,
\qquad
(u_\varepsilon\cdot\nabla)u_\varepsilon
=
U_\varepsilon(y)\partial_x u_\varepsilon
=0,
\qquad
\nabla p_\varepsilon=0.
\tag{SDB.2}
```

Thus

```math
\partial_t u_\varepsilon
\;+\;
\nabla\cdot(u_\varepsilon\otimes u_\varepsilon)
\;+\;
\nabla p_\varepsilon=0,
\qquad
\nabla\cdot u_\varepsilon=0
\tag{SDB.3}
```

classically for every `\varepsilon>0`.

As `\varepsilon\downarrow0`,

```math
u_\varepsilon
\longrightarrow
u_*
=
\begin{cases}
(a,0),& y>0,\\
(b,0),& y<0,
\end{cases}
\tag{SDB.4}
```

in `L^p_{\mathrm{loc}}` for every finite `p`, and distributionally, on every
bounded local window. The limit `u_*` is exactly the stationary tangential
vortex sheet proved in
[mpp-euler-pressure-nonparticipation-vortex-sheet-witness-20260517.md](/Users/thomasbirnie/Workspace/ToE/Research-Consolidation/problems/navier-stokes/euler-mirror/theorem-construction/mpp-euler-pressure-nonparticipation-vortex-sheet-witness-20260517.md).

## What This Proves

The slip-sheet is in the weak / local `L^p` closure of smooth classical Euler
flows generated by smooth initial data.

Therefore no Euler membership rule based only on flux-volume balance,
momentum-pressure fidelity, or pressure/incompressibility participation can
separate smooth Euler data from the slip-sheet by a closed class boundary. Any
such separation must use a stronger topology or a separately proved regularity
class.

In repo terms:

```math
\overline{\{\text{smooth Euler one-field flows}\}}^{\,L^p_{\mathrm{loc}}}
\cap
\{\neg EReg\}
\ne\varnothing.
\tag{SDB.5}
```

So the nonsmooth witness is not just an abstract weak object. It is the sharp
zero-thickness limit of smooth Euler shear layers.

## What This Does Not Prove

This bridge does not prove that one fixed smooth initial datum evolves into the
slip-sheet at a later time. Each `\varepsilon` has its own smooth initial datum,
and each corresponding classical solution remains smooth. The singularity is in
the zero-thickness limit, not in time evolution for a fixed datum.

That boundary matters. A same-datum finite-time bridge would have the form

```math
u_0\in C^\infty
\quad\Longrightarrow\quad
u(t)\to u_*
\text{ or loses }EReg\text{ at }T_*<\infty,
\tag{SDB.6}
```

and would be a genuine Euler singularity theorem. This note does not claim that.

## Bridge C: Fixed-Datum Classical Blowup With Boundary

If the domain includes the boundary geometry of the Hou-Luo scenario, the
fixed-datum classical bridge is available as an external theorem. Chen and Hou
prove finite-time blowup for the three-dimensional axisymmetric incompressible
Euler equations with smooth initial data, finite energy, and boundary:

<https://arxiv.org/abs/2210.07191>

The rigorous numerics companion verifies the computer-assisted constants used
by the stability framework:

<https://arxiv.org/abs/2305.05660>

This route has the shape

```math
u_0\in C^\infty_{\mathrm{div}}
\quad\Longrightarrow\quad
\exists T_*<\infty:
\text{the classical boundary Euler branch loses smoothness at }T_*.
\tag{SDB.6b}
```

It is a fixed-datum classical singularity theorem, but it is not the same as
the slip-sheet limit above. Its mechanism is nearly self-similar boundary
vorticity growth in the axisymmetric setting, not the zero-thickness stationary
shear limit.

The no-boundary version remains separate:

```math
\text{smooth finite-energy Euler on }\mathbb R^3
\text{ or }\mathbb T^3
\quad\Longrightarrow\quad
\text{finite-time singularity}
\tag{SDB.6c}
```

is not supplied by this bridge and remains an open target in the sources checked
here.

## Bridge B: Weak-Branch Route From The Same Smooth Datum

There is a separate known weak-solution route: convex integration gives highly
nonunique weak Euler solutions from broad classes of initial data. Wiedemann's
2011 theorem gives infinitely many global weak solutions for periodic
incompressible Euler from any solenoidal `L^2` datum, with bounded energy:

<https://arxiv.org/abs/1102.3614>

This applies in particular to smooth divergence-free data. It gives a
same-initial-data weak branch, but it is not a classical Euler evolution and it
should not be treated as an admissible physical branch unless a chosen
admissibility condition is separately verified. Wiedemann's dissertation also
separates non-admissible global weak existence from admissible existence on a
dense subset of data:

<https://hdl.handle.net/20.500.11811/5317>

For the repo, this route may be used only as:

```math
\text{smooth datum}
\leadsto
\text{nonunique weak Euler branch}
\leadsto
\text{possible nonsmooth/non-one-field behavior}.
\tag{SDB.7}
```

It is not a proof that the classical smooth branch itself forms a singularity.

## Honest Bridge Summary

The proved bridge to the slip-sheet is the smooth shear-layer limit `(SDB.1)` to
`(SDB.4)`.

The same-datum bridge exists only at the weak-branch level unless a separate
admissibility and weak-strong boundary is handled.

The fixed-datum classical blow-up bridge is available with boundary through the
Chen-Hou route. The no-boundary smooth finite-energy bridge is outside this
branch's terminal mirror classification.
