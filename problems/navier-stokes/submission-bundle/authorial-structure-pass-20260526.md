## Lived-History Teaching Spine

The paper should not begin as a periodic Sobolev case study. It should begin by teaching the proof behavior.

The lived route changed because positive source-wall work became a repeated deletion cycle:

```text
identify bad source / reserve / donor object
-> try to delete it
-> find sharper survivor
-> try to pay or delete that survivor
-> discover another visibility/sign/ledger problem.
```

The CM turn asks the deeper question:

```text
when a source-wall survivor remains, is it a thing to delete,
or is it evidence that the alleged terminal object has left the class?
```

The paper's explanation must preserve both corrections:

- Do not demand one positive estimate erase every bad object.
- Do not call any bad object `Exit(Q)` before deriving CM-test entry plus a concrete Pack/Part/Field face failure.
