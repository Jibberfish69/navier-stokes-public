# Basic Derived Proof Examples

This folder holds compact derived proof attempts.

The current residual-decay artifact is a worked proof-style example. It should
be treated as low-authority experimental material: useful for seeing how a
short proof explanation was attempted, but not good enough by location to serve
as a template or manuscript source.

Promote material from here only after checking both:

- the mathematical statement and assumptions are actually the ones the paper
  needs;
- the explanation carries a reader through the object clearly enough to reuse.
