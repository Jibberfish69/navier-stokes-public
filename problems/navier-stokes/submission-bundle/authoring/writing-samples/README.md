# Writing Samples

This shelf is for curated passages whose writing motion should be preserved.

Use it when a transcript, experiment, external model paper, or manuscript draft
contains a way of explaining that should be imitated later. The sample should
record what works: object order, pressure before definition, plain explanation
before notation, how a correction becomes a transition, or how a hard estimate
is taught without losing rigor.

This folder is not for raw transcripts and not for reusable templates. A sample
is a successful passage. A template is the reusable form abstracted from one or
more successful passages.
