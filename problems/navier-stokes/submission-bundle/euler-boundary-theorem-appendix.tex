\section{Selected-Packet Euler Boundary Theorem}

This appendix records the exact Euler material allowed in the Navier--Stokes proof.
Euler is used only after the same selected terminal packet has already been typed inside the Pack/Part/Field class test.
It is not a separate proof route.

\begin{definition}[Base Euler boundary membership]
For a selected terminal packet \(Q\), write
\[
  \Member_E(Q):=\mathrm{EVol}_Q(u)\wedge \mathrm{EMom}_Q(u,p).
\]
Here \(\mathrm{EVol}_Q\) means incompressible flux-volume readability and \(\mathrm{EMom}_Q\) means weak inviscid momentum-pressure readability on the same packet.
This base Euler test contains no Navier--Stokes participation predicate, no fixed viscosity, no positive-scale one-field predicate, and no smoothness requirement.
\end{definition}

\begin{definition}[Clean selected-packet Euler boundary]
A terminal packet \(Q\) is in the clean Euler boundary case at depth \(N\) when all of the following hold:
\begin{enumerate}
\item \(Q\) is the same selected Navier--Stokes terminal packet, not a neighboring comparison example.
\item \(\Pack_Q\) survives at least in the shared flux-volume sense needed for \(\mathrm{EVol}_Q\).
\item \(\mathrm{EVol}_Q(u)\wedge\mathrm{EMom}_Q(u,p)\) holds on \(Q\).
\item The first Navier--Stokes failure is only loss of fixed-viscosity participation or loss of positive-scale one-field coherence, with no Reynolds stress, source measure, pressure-source residue, concentration residue, oscillation defect, or same-packet compactness gap left over.
\end{enumerate}
\end{definition}

\begin{theorem}[Clean Part exit becomes base Euler entrance]
Assume \(Q\) is in the clean Euler boundary case and the first Navier--Stokes face lost after Pack is
\[
  \Pack_Q\wedge\neg\Part_{N,Q}.
\]
Then \(Q\) exits the fixed-positive-viscosity Navier--Stokes class through Part and is a base Euler member:
\[
  \Exit_{NS}(Q)
  \qquad\hbox{and}\qquad
  \Member_E(Q).
\]
\end{theorem}

\begin{proof}
The Navier--Stokes side is the installed Pack-first CM conclusion.
After \(\Pack_Q\) has survived, failure of \(\Part_{N,Q}\) says that the selected packet no longer carries the same differentiated pressure-viscosity tower through depth \(N\).
That tower includes the fixed positive-viscosity term \(\nu\Delta U_k\), so its failure is a Navier--Stokes class exit through Part.

The Euler side is exactly the base membership definition.
The clean boundary hypotheses say that the same packet still carries \(\mathrm{EVol}_Q(u)\) and \(\mathrm{EMom}_Q(u,p)\), and that no extra defect measure or source residue is being smuggled into the comparison.
Thus the escaped packet is not a fixed-viscosity Navier--Stokes member, but it is a base Euler member.
\end{proof}

\begin{theorem}[Clean Field exit becomes base Euler entrance]
Assume \(Q\) is in the clean Euler boundary case, \(\Pack_Q\) and \(\Part_{N,Q}\) survive for the branch split, and the first remaining Navier--Stokes face lost is
\[
  \Pack_Q\wedge\Part_{N,Q}\wedge\forall r>0\,\neg\Field_{N,r,Q}.
\]
Then \(Q\) exits the fixed-positive-viscosity Navier--Stokes class through Field and is a base Euler member:
\[
  \Exit_{NS}(Q)
  \qquad\hbox{and}\qquad
  \Member_E(Q).
\]
The same object may still fail stronger Euler regularity or one-field coherence.
\end{theorem}

\begin{proof}
Once Pack and Part survive, the remaining CM continuation service is positive-scale one-field coherence.
If every positive scale fails \(\Field_{N,r,Q}\), the selected packet exits the fixed-viscosity Navier--Stokes class through Field.
The clean boundary hypotheses separately give \(\mathrm{EVol}_Q(u)\wedge\mathrm{EMom}_Q(u,p)\) on the same packet.
That conjunction is \(\Member_E(Q)\).
The all-scales Field failure is therefore a failure of a stronger coherence layer, not a failure of base Euler membership.
\end{proof}
