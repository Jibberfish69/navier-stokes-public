\begin{abstract}
We prove global smooth existence for the incompressible three-dimensional Navier--Stokes equations on the periodic domain \(\mathbb T^3\), with smooth divergence-free initial data and zero external force.
A direct proof would prove estimates strong enough to keep the solution smooth for all time.
This paper uses a contrapositive route instead.
A finite-time breakdown claim has to identify a terminal object for the original solution, so the proof tests that object.

The test asks a simple question: does the terminal object still carry enough of the original solution to continue it?
If it does, the classical \(H^s\), \(s>5/2\), local theory extends the same solution past the claimed terminal time.
If it does not, the object has lost the structure required to be a legal terminal object for that same solution.

The proof records that structure through three checks.
They ask whether the terminal object keeps a positive material carrier, remains tied to the same Navier--Stokes pressure-viscosity evolution, and retains positive-scale field control on one witness record:
\[
  \Pack_Q,\qquad \Part_{N,Q},\qquad \Field_{N,r,Q}.
\]
These are the Pack, Part, and Field faces of the terminal packet.
The first failed face gives the class exit
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
Thus the claimed terminal object has only two outcomes: it remains a continuation packet for the same solution, or it fails one of the three checks and exits the class.
In the second case it is not an available Clay breakdown witness.

The rest of the manuscript makes this test precise for the periodic problem.
It constructs the transported whole-torus material atlas, captures each alleged terminal branch on that atlas, and reads the branch through Pack, Part, and Field in that order.
Sobolev, critical, local, and endpoint scenarios enter the proof by attaching to the selected terminal object and taking a job in the same terminal-packet test.
The conclusion is that no finite nonsmooth terminal branch remains available as a Clay breakdown witness for the periodic smooth-data Navier--Stokes evolution.
\end{abstract}

\section{The Navier--Stokes MPP And The Proof Contract}

The incompressible three-dimensional Navier--Stokes equations are
\[
  \partial_t u +(u\cdot\nabla)u+\nabla p=\nu\Delta u,\qquad
  \nabla\cdot u=0,
\]
with smooth divergence-free initial data \(u_0\).
The Clay problem asks whether the corresponding smooth solution exists for all time.
This manuscript proves global smooth existence on the periodic domain \(\mathbb T^3\) with zero external force.
Its terminal packet, material atlas, and continuation readout all live on the torus.

The proof contract is therefore explicit.
Its proof program is the Navier--Stokes MPP class-membership contrapositive.
Its Clay target is the periodic smooth-data problem.
The whole-space statement (A) is the export theorem carrying this terminal-packet conclusion from \(\mathbb T^3\) to \(\mathbb R^3\).

The gold standard question is
\[
  \text{which estimate forces the smooth solution to continue?}
\]
It proves a bound strong enough for classical continuation.
The silver standard question is
\[
  \text{which service must an alleged finite-breakdown branch lose?}
\]
It proves the contrapositive: every branch capable of finite nonsmooth terminal failure exits the legal same-solution class.
This paper uses the standard supercritical Sobolev continuation theorem as the final readout from a member packet.
The continuation readout used here is \(H^s\) with \(s>5/2\).
Critical, endpoint, local \(L^3\), no-pulse, and comparison arguments matter by tying themselves to the same terminal witness record and taking a Pack, Part, Field, or readout job.

\begin{proposition}[Periodic theorem and export path]
The proof in this manuscript is the periodic zero-force CM contrapositive theorem.
It proves that an alleged finite terminal breakdown witness on \(\mathbb T^3\) is consumed by the same-fluid Pack/Part/Field terminal packet tree.
That is the periodic smooth-data Clay target.
The whole-space statement (A) requires a theorem exporting that terminal-packet conclusion to \(\mathbb R^3\).
\end{proposition}

\begin{proof}
The selected packet used below is the transported whole-torus material atlas.
That atlas is a periodic object.
All Pack, Part, Field, and \(H^s\) readout statements in the main proof are built on that selected periodic packet.
The whole-space statement asks for the tightness/localization theorem that carries this packet conclusion to arbitrary whole-space data.
Thus the periodic theorem and the whole-space export theorem are different mathematical surfaces.
\end{proof}

\begin{theorem}[Classical continuation criterion]
Let \(s>5/2\).
Let \((u,p)\) be a smooth Navier--Stokes solution on \([0,T_*)\) with smooth divergence-free datum \(u_0\).
If
\[
  \sup_{0\le t<T_*}\|u(t)\|_{H^s}<\infty,
\]
then the same solution extends smoothly beyond \(T_*\).
\end{theorem}

\begin{proof}
The local well-posedness theorem in \(H^s\) with \(s>5/2\) gives a smooth continuation time depending only on \(\nu\), \(s\), and an upper bound for \(\|u(t)\|_{H^s}\).
The displayed bound supplies the same upper bound along every sequence of times approaching \(T_*\).
Restarting the local theory from such times gives a uniform positive continuation interval.
Those restarted solutions agree with the original solution on the overlap by uniqueness, so they extend the same velocity-pressure solution past \(T_*\).
\end{proof}

The first dependency is now fixed.
A branch that reaches one supercritical \(H^s\) continuation bound continues.
A branch that claims finite breakdown must explain which service of the same-solution continuation packet has failed.
The class-membership proof asks the finite terminal branch:
\[
  \begin{gathered}
  \text{can a branch capable of finite nonsmooth terminal failure}\\
  \text{still be a legal branch of the same continuation class?}
  \end{gathered}
\]

The proof contract is this.
Let \(O\) be a same-solution obstruction reached by a forward Navier--Stokes proof.
The obstruction has a pass side and a fail side:
\[
  O_{\Pass}\Rightarrow \text{the same continuation services remain},
\]
\[
  O_{\Fail}\Rightarrow \text{the branch is capable of finite terminal nonsmoothness}.
\]
The pass side is the member branch.
The fail side is tested as a terminal witness and must lose one of the required services.
Once it loses a required service, it exits the class:
\[
  O_{\Fail}\Rightarrow \Exit(Q;\Owork).
\]
Each obstruction family below repeats the same pattern.
A direct estimate names a terminal mechanism.
That mechanism still claims to be the original Navier--Stokes branch.
The proof therefore needs a test that decides whether the claimed terminal branch is still a legal same-solution continuation.

\section{The Proof Spine Before Details}

The proof can be read before the machinery is introduced.
The direct positive route tries to keep every continuation service alive.
The CM route keeps the terminal branch that the failed positive route leaves behind and asks whether that branch is still a legal same-solution continuation.

\begin{claim}[Class proof spine]
For every obstruction \(O\) reached by the forward-positive Navier--Stokes program,
\[
  O_{\Pass}\Rightarrow\Member(Q;\Owork)\Rightarrow\text{smooth continuation},
\]
while
\[
  O_{\Fail}\Rightarrow\Exit(Q;\Owork).
\]
Finite terminal witnesses are consumed by the CM terminal chain, so no legal in-class nonsmooth terminal branch remains.
\end{claim}

\begin{proof}
The first implication is membership readout.
The second implication is terminal packet capture followed by class exit.
The terminal witness consumption chain gives the face failure for every finite Clay breakdown witness.
The no-third-branch theorem removes the only branch shape that could be both an in-class continuation and a terminal nonsmooth witness.
\end{proof}

\section{The Positive Route Meets The Source Wall}

The enstrophy source wall is the first teaching example, not the proof spine.
The proof spine is the terminal same-fluid packet test built below.
This section is included because it shows how the positive-forward route naturally produces the pass/fail split that the CM contrapositive consumes.
The example gives the reader a familiar calculation in which the same branch split is visible.
Let
\[
  Q_1(t)=\|u(t)\|_{L^2}^2+\|\nabla u(t)\|_{L^2}^2.
\]
The \(L^2\) energy has a signed identity:
\[
  \frac12\frac{d}{dt}\|u(t)\|_{L^2}^2
  +\nu\|\nabla u(t)\|_{L^2}^2=0.
\]
The first derivative level has the source wall:
\[
  \frac12\frac{d}{dt}\|\nabla u(t)\|_{L^2}^2
  +\nu\|\Delta u(t)\|_{L^2}^2
  =
  \int_{\mathbb T^3}(u\cdot\nabla)u\cdot\Delta u\,dx
  =:\mathcal S(t).
\]
The source \(\mathcal S(t)\) has no fixed sign.
It is the place where a direct positive proof tries to absorb nonlinear production into viscosity.

\begin{proposition}[Positive source absorption gives the pass branch]
Assume that on a terminal interval the source satisfies
\[
  |\mathcal S(t)|
  \le
  \frac{\nu}{2}\|\Delta u(t)\|_{L^2}^2
  +F(Q_1(t)),
\]
where \(F\) is locally integrable along the branch.
Then \(Q_1\) remains bounded on that interval, and the branch remains on the pass side of the class test up to the regularity depth supplied by the continuation bootstrap.
\end{proposition}

\begin{proof}
The displayed inequality gives
\[
  \frac12\frac{d}{dt}\|\nabla u(t)\|_{L^2}^2
  +\frac{\nu}{2}\|\Delta u(t)\|_{L^2}^2
  \le
  F(Q_1(t)).
\]
Together with the \(L^2\) energy identity, this is a closed differential control for the low-order packet on the interval where \(F(Q_1(t))\) is integrable.
The usual parabolic smoothing and higher-order energy bootstrap then promote the bounded packet to a continuation norm at any fixed \(H^s\) with \(s>5/2\), once the higher-order source terms obey the same absorption pattern.
At that point the classical continuation criterion applies.
\end{proof}

This proposition is the gold-standard behaviour in miniature.
The source is absorbed, the continuation services survive, and the branch remains a member branch.
The hard case is the complementary behaviour.
Suppose the source absorption attempt leaves a positive terminal reserve on shrinking heat windows after ordinary losses and inherited parent mass have been removed.
Such a reserve is dangerous only while it claims to be part of the original same-solution branch.
That claim forces the class test.

\begin{definition}[Source-reserve failure branch]
A source-reserve failure branch is a same-solution terminal branch for which a positive source quantity \(R_N(W_j)\) survives on terminal heat windows \(W_j\to T_*\) after legal boundary losses, inherited parent mass, and paid finite terms have been separated.
\end{definition}

\begin{proposition}[The source-reserve failure branch exposes the class test]
Every source-reserve failure branch must answer three questions in order.
First, does a positive transported carrier remain?
Second, on that carrier, does the same Navier--Stokes pressure-viscosity tower remain?
Third, after carrier and participation survive, does one positive scale carry coherent field data strong enough for continuation?
A negative answer at the first, second, or third question gives carrier-side, participation-side, or field-side class exit respectively.
\end{proposition}

\begin{proof}
The reserve can affect the Clay solution only as a branch of the same preterminal velocity-pressure evolution.
That branch first needs a positive transported carrier for the packet \(Q\).
Failure at this level means the reserve has no same-fluid continuation packet.
When the carrier survives, the reserve must still participate in the differentiated Navier--Stokes pressure-viscosity tower on that carrier.
Failure at this level means the reserve has left the original equation on the selected carrier.
When carrier and participation both survive, the remaining question is positive-scale coherent field readout.
Failure there means the retained branch has no scale at which the continuation field can be read.
These are the three operational services required by the class object.
\end{proof}

The case study gives the reader the pattern used everywhere else.
The positive calculation is attempted first.
When it closes, the branch reads out through the continuation criterion.
When it leaves a terminal branch, the proof keeps that branch and asks for its first lost continuation service.
That is class membership in operation.

That is the reason to introduce class membership before returning to the branch catalogue.
The source-wall calculation has done its teaching job: a positive estimate tries to close, its failure leaves a retained terminal branch, and that branch has to answer whether it is still the same legal Navier--Stokes continuation.
The next section defines that legality test.

\section{The Working Class Object}

The obstruction field has now produced the object the proof must test.
A breakdown-capable branch is still attached to the original datum, equation, pressure, viscosity, and preterminal smooth flow.
The class object records exactly those same-object requirements.
It lets the proof ask whether the branch still has the services of a legal continuation.

\begin{definition}[Working Clay class object]
The working Clay class object \(\Owork\) is the class of same-solution Navier--Stokes continuation packets generated by the original smooth datum and read on one terminal witness record.
For a terminal packet \(Q\), the predicate
\[
  \Member(Q;\Owork)
\]
means that \(Q\) retains the services needed to be a legal same-solution continuation candidate.
The class-exit predicate is
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
\end{definition}

\begin{definition}[Witness record]
A witness record is the common record
\[
  \WitnessRecord=(u_0,\nu,u,p,Q,N,r,\Phi,T_*),
\]
where \(u_0\) is the original datum, \((u,p)\) is the same Navier--Stokes solution on \([0,T_*)\), \(Q\) is the terminal packet, \(N\) is the participation depth, \(r\) is the positive field scale, \(\Phi\) is the same-fluid carrier family, and \(T_*\) is the alleged terminal time.
\end{definition}

The common-record condition is important.
A carrier, participation tower, and readout synthesize into one continuation packet only when they belong to the same terminal object.
The class test is a single-record test.

\begin{definition}[The three services]
On a witness record \(\WitnessRecord\), the services are:
\[
  \Pack_Q,\qquad \Part_{N,Q},\qquad \Field_{N,r,Q}.
\]
\(\Pack_Q\) is the positive same-fluid carrier service.
It means that there is a finite transported carrier family \(\{\Phi_a\}_{a=1}^m\), a finite-overlap cover \(\{C_a\}_{a=1}^m\), and a number \(\rho_Q>0\) such that the selected terminal packet \(Q\) is carried on sets of diameter at least \(\rho_Q\), all transported by the same velocity field \(u\).

\(\Part_{N,Q}\) is the same-equation participation service.
It means that on the carrier supplied by \(\Pack_Q\), the differentiated pressure-viscosity tower remains the same Navier--Stokes tower through depth \(N\):
\[
  D_tU_k=K_k+B_k,\qquad
  K_k=-\nabla^{k+1}p+\nu\Delta U_k,\qquad 0\le k\le N.
\]
The tower has one finite participation envelope on the witness record:
\[
  \mathcal T_{N,Q}
  :=
  \sum_{k=0}^{N}
  \sup_{t<T_*}
  \sum_{a=1}^{m}
  \|\chi_a(t)U_k(t)\|_{L^2}^2
  <\infty,
\]
where \(\{\chi_a\}\) is a subordinate partition for the carrier cover.

\(\Field_{N,r,Q}\) is the positive-scale one-field coherence service.
It means that after carrier and participation survive, one positive scale \(0<r\le \rho_Q\) carries a finite coherent field energy:
\[
  \mathcal E_{N,r,Q}
  :=
  \sup_{t<T_*}
  \sum_{a=1}^{m}
  \sum_{|\alpha|\le N}
  \|\chi_a(t)\nabla^\alpha u(t)\|_{L^2}^2
  <\infty,
\]
with compatible pressure readout on the same cover.
\end{definition}

\begin{definition}[CM packet]
The class-membership packet at depth \(N\), scale \(r\), and terminal packet \(Q\) is
\[
  \CM_{N,r,Q}
  :=
  \Pack_Q\wedge\Part_{N,Q}\wedge\Field_{N,r,Q}
\]
on one witness record.
\end{definition}

\begin{lemma}[Membership readout]
Let \(N_s\) be a depth high enough for the standard \(H^s\) continuation criterion with \(s>5/2\).
If a legal same-solution terminal packet remains a member of \(\Owork\), then
\[
  \Member(Q;\Owork)
  \Longrightarrow
  \sup_{t<T_*}\|u(t)\|_{H^s}<\infty
\]
for some \(s>5/2\), and the same Navier--Stokes solution extends classically beyond \(T_*\).
\end{lemma}

\begin{proof}
Membership means that the terminal packet retains the three services on one witness record.
\(\Pack_Q\) supplies a finite positive carrier cover with finite overlap.
\(\Part_{N_s,Q}\) identifies the differentiated fields on that cover with the same pressure-viscosity Navier--Stokes tower through the continuation depth.
\(\Field_{N_s,r,Q}\) supplies the finite local derivative energy on a positive scale.
The partition of unity subordinate to the finite cover sums those local bounds into the displayed \(H^s\) bound at a supercritical continuation level \(s>5/2\).
Classical local well-posedness then continues the same solution past \(T_*\).
\end{proof}

\section{Which Objects Are Tested}

The class-membership proof tests finite terminal objects offered as Clay breakdown witnesses for the same original Navier--Stokes solution.
The object enters the test as the alleged terminal branch of the same equation.
The three services decide membership or exit.

\begin{definition}[CM-test-admissible Clay terminal object]
A finite terminal object \(W_*\) is CM-test-admissible when it is offered as a breakdown witness for the same original smooth-data Navier--Stokes solution.
This means:
\begin{enumerate}[leftmargin=2em]
\item \(W_*\) is attached to the maximal classical solution generated by the original datum \(u_0\).
\item On every preterminal window, the object solves the original incompressible Navier--Stokes system with the same velocity and pressure.
\item The terminal extraction uses the same transported fluid family supplied by the preterminal smooth windows.
\item After legal boundary losses, cutoff losses, non-selected branches, readout-only residues, and paid finite terms are removed, \(W_*\) is still the object claiming to be the finite terminal obstruction.
\item The remaining terminal services available to the object are exactly \(\Pack_Q\), \(\Part_{N,Q}\), and \(\Field_{N,r,Q}\).
\end{enumerate}
\end{definition}

\begin{remark}
CM-test-admissible means admissible for the test.
Membership and exit are conclusions.
\end{remark}

\begin{lemma}[Finite Clay breakdown enters the test]
Every finite same-solution Clay breakdown witness is CM-test-admissible.
\end{lemma}

\begin{proof}
A finite same-solution Clay breakdown witness is, by definition, the original smooth-data Navier--Stokes solution stopped at a finite terminal time where classical continuation is alleged to fail.
The datum, equation, pressure, velocity, viscosity, and preterminal fluid family are therefore the same ones used before the terminal time.
Legal losses and irrelevant branches can be stripped away without changing the alleged obstruction.
The remaining object is precisely the terminal object to be tested by the three services.
\end{proof}

\section{Terminal Packet Capture}

The capture theorem is the bridge from a hypothetical finite breakdown to the Pack-first decision tree.
It is the first formal place where the proof stops naming obstruction families and starts deciding the terminal object itself.

\begin{theorem}[Torus global material-atlas terminal capture]
Let \((u,p)\) be the maximal smooth Navier--Stokes solution generated by \(u_0\) on \(\mathbb T^3\times[0,T_*)\), with \(T_*<\infty\) assumed.
Choose a finite smooth material atlas and partition of unity on \(\mathbb T^3\) at time \(0\), and transport it by the same velocity field \(u\) on every preterminal interval.
Let \(Q_{\mathrm{atlas}}\) be the terminal tail of this transported whole-torus atlas.
Fix \(N_s\) high enough for \(H^s\) continuation readout with \(s>5/2\).
Then
\[
  T_*\text{ finite terminal non-continuation}
  \Longrightarrow
  \neg\Pack_{Q_{\mathrm{atlas}}}
  \vee
  \neg\Part_{N_s,Q_{\mathrm{atlas}}}
  \vee
  \forall r>0\,\neg\Field_{N_s,r,Q_{\mathrm{atlas}}}.
\]
Equivalently,
\[
  T_*\text{ finite terminal non-continuation}
  \Longrightarrow
  \begin{cases}
  \neg\Pack_{Q_{\mathrm{atlas}}},\\
  \Pack_{Q_{\mathrm{atlas}}}\wedge\neg\Part_{N_s,Q_{\mathrm{atlas}}},\\
  \Pack_{Q_{\mathrm{atlas}}}\wedge\Part_{N_s,Q_{\mathrm{atlas}}}\wedge\forall r>0\,\neg\Field_{N_s,r,Q_{\mathrm{atlas}}}.
  \end{cases}
\]
\end{theorem}

\begin{proof}
For every \(\varepsilon>0\), the restriction of \((u,p)\) to \([0,T_*-\varepsilon]\) is classical.
The transported finite atlas therefore exists on every compact preterminal interval and covers the whole torus with finite overlap.
This is the selected packet.
It is not a local diagnostic subsequence.

\(\Pack_{Q_{\mathrm{atlas}}}\) means that this whole transported atlas keeps positive carrier scale and the deformation comparability needed to read local packet bounds as Sobolev bounds on the fixed torus.
If that material atlas service fails at the terminal tail, the first lost service is \(\neg\Pack_{Q_{\mathrm{atlas}}}\).

Assume that \(\Pack_{Q_{\mathrm{atlas}}}\) survives.
The next question is whether the same differentiated Navier--Stokes pressure-viscosity tower survives on that atlas through depth \(N_s\).
If the tower fails, the first lost remaining service is \(\Pack_{Q_{\mathrm{atlas}}}\wedge\neg\Part_{N_s,Q_{\mathrm{atlas}}}\).

Assume that both \(\Pack_{Q_{\mathrm{atlas}}}\) and \(\Part_{N_s,Q_{\mathrm{atlas}}}\) survive.
If there is a positive scale \(r>0\) with \(\Field_{N_s,r,Q_{\mathrm{atlas}}}\), then the full packet \(\CM_{N_s,r,Q_{\mathrm{atlas}}}\) survives on the same whole-torus witness record.
The finite atlas covers \(\mathbb T^3\), Pack supplies the material comparability, Part supplies the same pressure-viscosity tower, and Field supplies the positive-scale coherent derivative energy.
The local finite-overlap packet bounds therefore sum to
\[
  \sup_{t<T_*}\|u(t)\|_{H^s(\mathbb T^3)}<\infty.
\]
The classical continuation criterion extends the same solution past \(T_*\), contradicting finite terminal non-continuation.
Thus \(\Field_{N_s,r,Q_{\mathrm{atlas}}}\) fails for every \(r>0\) after Pack and Part survive.
\end{proof}

\begin{corollary}[No fourth primitive service]
After legal losses, readout-only residues, non-selected branches, and paid finite terms are removed, a same-solution terminal obstruction has no primitive service outside Pack, Part, and Field.
\end{corollary}

\begin{proof}
The preceding theorem tests exactly the services needed for the same-solution continuation packet.
Any proposed residue either lacks the carrier, lacks participation after carrier survives, lacks positive-scale coherence after carrier and participation survive, or is a supplier/readout description waiting for one of those services to be tested.
\end{proof}

\section{The Pack Face}

The Pack face asks the first physical question.
Does the alleged terminal object retain a positive same-fluid carrier from the original smooth solution?
A branch that cannot answer yes has already left the class.
It does not matter how much formal source language remains around it.
Without a positive carrier, there is no same-solution packet to continue.

\begin{definition}[Pack-side terminal failure]
A selected terminal object has Pack-side failure when no positive transported carrier family survives for the packet \(Q\):
\[
  \neg\Pack_Q.
\]
The typical Pack-side mechanisms are zero terminal radius, detached donor ancestry, terminal source atom without positive carrier, unsupported first-created square reserve, and terminal carrier birth with no charge path.
\end{definition}

\begin{lemma}[Zero-radius packets are Pack-side]
Let \(Q\) be a selected terminal packet whose transported support has no positive terminal radius:
\[
  \rho_Q=0.
\]
Then \(Q\) fails \(\Pack_Q\) and hence exits \(\Owork\).
\end{lemma}

\begin{proof}
\(\Pack_Q\) requires a finite transported carrier cover with a positive lower carrier scale.
The condition \(\rho_Q=0\) removes that service.
The object may still be visible as a terminal trace or residue, but it is not a same-fluid continuation packet.
Thus \(\neg\Pack_Q\), and class exit follows by the definition of \(\Exit\).
\end{proof}

\begin{lemma}[Detached donor ancestry is Pack-side]
Suppose a terminal source or reserve branch selects donor ancestry that is not represented on a positive same-fluid carrier for \(Q\).
Then the selected branch is Pack-side:
\[
  \text{detached ancestry}(Q)\Longrightarrow\neg\Pack_Q.
\]
\end{lemma}

\begin{proof}
Donor ancestry can support a terminal obstruction only when the ancestry is still carried by the same transported fluid family.
Detached ancestry has no such carrier.
It may indicate where a forward-positive source estimate failed, but it does not supply a legal same-solution terminal packet.
The first service fails at Pack.
\end{proof}

\begin{lemma}[First-created reserve must be paid or carried]
Let \(R_N(W)\) be a positive square reserve on an admissible terminal heat window \(W\).
If the positive first-created increment is neither inherited from the parent window nor paid by a charge on \(W\), then the selected reserve branch is not a member branch.
It is either a Pack-side carrier birth failure or a live Pack-support burden.
\end{lemma}

\begin{proof}
A member branch cannot acquire positive terminal reserve from nowhere.
Positive reserve appearing at the terminal window must be represented by inherited mass, declared loss, or a charge path tied to the same transported packet.
When no such representation is available, the candidate branch is not yet a member packet.
At the class level the branch stays Pack-side until a later theorem supplies the missing positive carrier and charge path.
\end{proof}

The source-reserve birth chain is Pack-side support after terminal witness consumption.
The useful form is not a global smoothness estimate.
The useful form is a same-packet creation law:
\[
  R_N(W)
  \le
  (1-\delta)R_N(\mathrm{Past}(W))
  +\mathrm{Loss}_N(W)
  +\mathrm{Charge}_N(W)
  +o_N(1).
\]
This law says that terminal reserve cannot be first-created for free.
The latest reduction sharpens the historical positive source remainder into source-weighted angular depletion support on the selected positive source carrier.
That support serves the terminal CM witness tree by paying or depleting the Pack-side reserve birth.

\section{The Part Face}

The Part face asks whether the selected carrier still participates in the same Navier--Stokes pressure-viscosity tower.
Pack alone is only a carrier.
The Clay solution is not a moving set; it is the same velocity-pressure solution of the same equation.
The Part face protects that identity.

\begin{definition}[Part-side terminal failure]
Assume \(\Pack_Q\) survives.
A selected terminal object has Part-side failure when the differentiated Navier--Stokes tower cannot be retained on the carrier through the continuation depth:
\[
  \Pack_Q\wedge\neg\Part_{N,Q}.
\]
The typical Part mechanisms are pressure participation loss, viscosity participation loss, dwell failure, same-object dynamic carrier failure, and incompatible local source participation.
\end{definition}

\begin{lemma}[Pressure-viscosity loss is Part-side]
Let \(Q\) retain a positive carrier.
If, on that carrier, the differentiated fields cannot be represented by the same pressure-viscosity tower
\[
  D_tU_k=-\nabla^{k+1}p+\nu\Delta U_k+B_k,\qquad 0\le k\le N,
\]
then \(Q\) fails \(\Part_{N,Q}\).
\end{lemma}

\begin{proof}
The Part service is exactly the service that keeps the carrier tied to the original Navier--Stokes equation.
When the pressure, viscosity, or nonlinear participation terms cease to be the same tower on the selected carrier, the object may still be a transported object, but it is no longer a legal same-solution continuation packet.
The first surviving failure after Pack is \(\neg\Part_{N,Q}\).
\end{proof}

\begin{lemma}[Local translators are Part tests before they are readouts]
A local critical packet, local \(L^3\) packet, or Duhamel packet enters the class proof only after it is placed on the same witness record.
Before that placement it is support.
After that placement it is tested first for Pack and then for Part.
\end{lemma}

\begin{proof}
Local critical information can describe a terminal concentration without identifying the same witness record.
The class proof needs the same datum, same pressure, same viscosity, same carrier family, and same terminal packet.
The translator's job is to recover that common record.
Once the record is recovered, the packet faces the ordinary Pack and Part tests.
Only after those services survive can the packet become a Field or endpoint readout object.
\end{proof}

\begin{proposition}[Part is the same-equation guard]
A branch with a carrier and a broken pressure-viscosity tower cannot be a legal continuation branch for the Clay problem.
\end{proposition}

\begin{proof}
A legal continuation branch must solve the same incompressible Navier--Stokes equations with the same pressure and viscosity.
The carrier alone does not supply that identity.
When the pressure-viscosity tower breaks, the selected object is no longer the same equation on the same packet.
Thus it exits before any endpoint readout is relevant.
\end{proof}

\section{The Field Face}

The Field face is reached only after Pack and Part survive.
At that point the selected object has a positive same-fluid carrier and the same pressure-viscosity participation tower.
The remaining question is whether there is one positive scale carrying coherent field data strong enough for continuation.

\begin{definition}[Field-side terminal failure]
Assume \(\Pack_Q\) and \(\Part_{N,Q}\) survive.
The packet has Field-side failure when every positive scale loses coherent field energy:
\[
  \Pack_Q\wedge\Part_{N,Q}\wedge\forall r>0\,\neg\Field_{N,r,Q}.
\]
The typical Field mechanisms are retained-amplitude blowup, terminal pulse, averaged jump, good-scale failure, and incompatible surviving traces.
\end{definition}

\begin{lemma}[Retained positive-window blowup is Field-side]
Suppose \(\Pack_Q\) and \(\Part_{N,Q}\) survive.
If a retained positive terminal window has no positive scale on which the \(N\)-level field energy remains finite, then the selected branch fails Field.
\end{lemma}

\begin{proof}
After Pack and Part survive, the only service left for membership readout is the positive-scale coherent field service.
Unbounded retained field energy on every positive scale removes that service.
The branch is therefore Field-side.
\end{proof}

\begin{lemma}[Endpoint readout is downstream of Field]
Good-scale, no-pulse, terminal-tail, averaged, and endpoint-cover arguments are continuation readout support.
They prove membership only after the packet has already retained Pack, Part, and Field on one witness record.
\end{lemma}

\begin{proof}
Endpoint readout uses the packet's existing services.
It does not create the positive carrier, the same pressure-viscosity tower, or the coherent field service by itself.
When those services survive, readout converts them into an \(H^s\) continuation bound with \(s>5/2\).
When one service fails, readout is no substitute for the missing service.
\end{proof}

\begin{proposition}[Field is the last continuation gate]
A same-solution terminal packet that retains Pack, Part, and Field at a continuation depth \(N_s\) cannot be a finite nonsmooth terminal obstruction.
\end{proposition}

\begin{proof}
Pack gives the finite positive carrier cover.
Part keeps the same pressure-viscosity tower on that cover.
Field gives finite coherent derivative energy on a positive scale.
The finite cover and partition of unity produce a bounded \(H^s\) norm with \(s>5/2\).
The classical continuation theorem extends the same solution past the alleged terminal time.
Thus a terminal obstruction must fail before or at Field.
\end{proof}

\section{Class Exit}

The class-exit theorem turns first-face failure into the contrapositive conclusion.

\begin{theorem}[Finite failure witness exits the class]
Let \(W_*\) be a CM-test-admissible finite Clay terminal object.
Then for a suitable terminal packet \(Q\) and continuation depth \(N_s\),
\[
  W_*
  \Longrightarrow
  \Exit(Q;\Owork).
\]
\end{theorem}

\begin{proof}
By terminal packet capture, \(W_*\) loses a first required service:
\[
  \neg\Pack_Q
  \vee
  \neg\Part_{N_s,Q}
  \vee
  \forall r>0\,\neg\Field_{N_s,r,Q}.
\]
If \(\Pack_Q\) fails, the terminal object has no positive same-fluid carrier and is outside the member packets.
If \(\Part_{N_s,Q}\) fails after Pack survives, the terminal object has left the same pressure-viscosity Navier--Stokes tower and is outside the member packets.
If every positive \(\Field_{N_s,r,Q}\) fails after Pack and Part survive, the terminal object lacks the positive-scale coherence required for membership readout and is outside the member packets.

Each case is the loss of a required service for \(\Member(Q;\Owork)\).
Thus
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
\end{proof}

\section{The Class-Law Proof}

Classification supplies the exit witness.
The class-law proof checks that the same terminal branch cannot be both a member continuation and the nonsmoothness-capable face-failure witness.

\begin{definition}[Terminal face-failure witness]
A terminal face-failure witness is a same-solution terminal packet \(Q\) that is CM-test-admissible and satisfies \(\Exit(Q;\Owork)\) by a derived Pack, Part, or Field face failure.
It is the fail side of the obstruction split, not a legal member continuation branch.
\end{definition}

\begin{proposition}[Legal branch law]
Every legal same-solution continuation branch for the Clay Navier--Stokes problem is represented by the working class object:
\[
  \Legal_{\NS}(Q)\Longrightarrow \Member(Q;\Owork).
\]
\end{proposition}

\begin{proof}
A legal same-solution continuation branch is the original smooth-data Navier--Stokes evolution continued as the same velocity-pressure solution with the same viscosity and same fluid participation.
To be such a continuation branch, it must retain a positive same-fluid carrier, the same pressure-viscosity participation tower through the continuation depth, and positive-scale coherent field data for the \(H^s\) readout with \(s>5/2\).
Those are exactly the services defining membership in \(\Owork\).
\end{proof}

\begin{theorem}[No third in-class terminal branch]
There is no terminal branch that is both an in-class member branch and a finite nonsmooth obstruction branch:
\[
  \Member(Q;\Owork)
  \quad\text{and}\quad
  Q\text{ blocks smooth continuation at }T_*<\infty.
\]
\end{theorem}

\begin{proof}
Membership gives the three services on one witness record.
By membership readout, those services give a bounded \(H^s\) continuation norm with \(s>5/2\).
Classical local theory then extends the same solution past \(T_*\).
That contradicts the claim that the same branch blocks smooth continuation at \(T_*\).
\end{proof}

\begin{theorem}[CM branch theorem]
Let \(O\) be a same-solution obstruction reached by the forward-positive Navier--Stokes program.
Then the pass/fail split is decided by the working class object:
\[
  O_{\Pass}\Longrightarrow \Member(Q;\Owork)\Longrightarrow\text{smooth continuation},
\]
and
\[
  O_{\Fail}\text{ capable of finite nonsmoothness}
  \Longrightarrow
  \Exit(Q;\Owork).
\]
\end{theorem}

\begin{proof}
The pass branch retains the carrier, participation, and field services on one witness record.
It is therefore a member branch and continues smoothly by membership readout.

The fail branch is offered as a finite same-solution terminal obstruction.
By finite-breakdown entry, it is CM-test-admissible.
By terminal packet capture, it loses Pack, or loses Part after Pack survives, or loses every positive Field scale after Pack and Part survive.
By finite failure witness class exit, that first failed service gives \(\Exit(Q;\Owork)\).
\end{proof}

\begin{theorem}[Clay closure by terminal witness consumption]
Every finite terminal Clay witness from the same smooth initial datum is consumed by the CM terminal witness chain:
\[
\begin{aligned}
&\text{finite breakdown witness}\\
&\Longrightarrow \text{CM-test entry}\\
&\Longrightarrow
  \bigl(\neg\Pack_Q\vee\neg\Part_{N,Q}\\
&\qquad\vee\forall r>0\,\neg\Field_{N,r,Q}\bigr)\\
&\Longrightarrow \Exit(Q;\Owork).
\end{aligned}
\]
Together with the pass-branch membership readout and the no-third-branch law, this excludes finite terminal breakdown.
\end{theorem}

\begin{proof}
Assume, toward contradiction, that the maximal smooth solution from \(u_0\) stops at a finite time \(T_*\).
The alleged finite terminal object is CM-test-admissible by finite-breakdown entry.
Terminal packet capture and finite-failure type exhaustion force the terminal object into Pack, Part, or Field face failure.
The CM embedding reads that face failure as \(\Exit(Q;\Owork)\).

The same obstruction has its pass side represented by a lawful member witness, and membership readout extends a member branch smoothly past \(T_*\).
The no-third-branch law excludes a terminal branch that is both that member continuation branch and the mechanism-derived face-failure branch.
The terminal nonsmooth branch therefore has no legal in-class continuation status.
The alleged finite terminal time is not a Clay-admissible breakdown of the original smooth-data evolution.
\end{proof}

\section{The Clay-Facing CM Completion}

The class law has now been proved in its working form.
The Clay-facing completion records the exact terminal witness consumption chain:
\[
\begin{aligned}
&\text{finite Clay breakdown witness}\\
&\Longrightarrow \text{CM-test entry}\\
&\Longrightarrow \text{Pack/Part/Field finite failure type}\\
&\Longrightarrow \Exit(Q;\Owork).
\end{aligned}
\]
This is the same branch law used throughout the proof.
The pass side supplies a lawful \(\Member(Q;\Owork)\) branch and reads out to smooth continuation.
The fail side enters the CM terminal test and loses one required service.

\begin{definition}[Terminal witness consumption]
A finite Clay terminal witness is consumed by the CM proof when it is first admitted to the same-fluid terminal packet tree, then exhausted as one of
\[
  \neg\Pack_Q,\qquad
  \neg\Part_{N,Q},\qquad
  \forall r>0\,\neg\Field_{N,r,Q},
\]
and the derived face failure is embedded as
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
\end{definition}

\begin{proposition}[Reopening test]
The CM completion can be reopened only by producing a finite same-surface branch that remains a legal in-class \(\Member(Q;\Owork)\) continuation while carrying the terminal Pack/Part/Field failure witness, or by showing that a finite Clay breakdown witness fails CM terminal entry, finite-failure type exhaustion, or contrapositive embedding.
\end{proposition}

\begin{proof}
Those are exactly the two ways to escape the pass-or-exit branch law.
The first creates a genuine third branch.
The second breaks the terminal witness consumption chain.
Source-reserve, signed-pair, no-free-sink, no-pulse, and positive packet-survival estimates are support or pressure tests until they prove one of these two failures.
\end{proof}

\begin{theorem}[Completion criterion]
Assume the installed CM witness chain: finite Clay terminal witnesses are CM-test-admissible, terminal failure types are exhausted by Pack, Part, and Field, face failures embed as \(\Exit(Q;\Owork)\), pass branches have local \(\Member(Q;\Owork)\) witnesses, and no in-class terminal branch also carries the derived failure witness.
Then the smooth Navier--Stokes solution generated by smooth divergence-free data has no finite terminal breakdown.
\end{theorem}

\begin{proof}
Let a finite terminal obstruction be reached by the same-solution Navier--Stokes proof program.
The obstruction has a pass side and a fail side.
The pass side is a member branch and gives the usual smooth continuation readout.
The fail side is admitted to the CM terminal packet tree and loses Pack, Part, or Field, hence gives \(\Exit(Q;\Owork)\).
The no-third-branch law excludes a branch that is both a legal member continuation and the same terminal failure witness.
Thus the terminal obstruction has no legal same-class nonsmooth branch.
The maximal smooth solution continues past the alleged terminal time.
\end{proof}

\section{Forward Families As Support Examples}

The services are now defined.

The forward families below have a different job.

Each family is support or exposition until it names the selected terminal object and the first Pack, Part, or Field service lost by that object.

\subsection{Source Reserve And Donor Refill}

Source reserve is the main Pack-side obstruction.
A forward proof asks for a scale-critical donor-refill estimate strong enough to keep the nonlinear source tree from concentrating at \(T_*\).
The class proof asks a sharper question: when a terminal source reserve remains, is it carried by the same fluid packet, and is its first appearance paid by the same source economy?

\begin{definition}[Source-reserve branch]
A source-reserve branch is a selected terminal branch for which a positive source quantity \(R_N(W)\) survives on a terminal heat window \(W\) after legal losses and inherited parent mass are separated.
The branch is retained when the reserve is still attached to a positive same-fluid packet.
\end{definition}

\begin{proposition}[Source-reserve routing]
Every retained source-reserve branch can serve as a support example in one of three class roles:
\[
  \neg\Pack_Q,\qquad
  \Pack_Q\wedge\neg\Part_{N,Q},\qquad
  \Pack_Q\wedge\Part_{N,Q}\wedge\text{Field/readout pressure}.
\]
\end{proposition}

\begin{proof}
A source reserve with no positive same-fluid carrier is an example of Pack failure.
A source reserve with a carrier and no same pressure-viscosity participation tower is an example of Part failure.
A source reserve with carrier and participation has reached the retained packet level and can support a Field diagnostic.
The proof force comes from the same-atlas face certificate, not from the family label.
\end{proof}

The current source-reserve chain is the Pack-side form of the final closure burden.
Reserve creation, terminal reserve first appearance, positive remainder depletion, source-weighted angular depletion, BASAC reverse Holder production, terminal source anti-concentration, and uniform temporal source integrability all ask the same question in different coordinates:
\[
  \text{can positive terminal source reserve be born for free on the original branch?}
\]
The class proof uses this material only at the same-packet level.
Once the reserve is inherited, charged, depleted, or landed in a Pack/Part/Field face, it becomes support for the atlas proof object.

\subsection{BASAC, Pressure, And Rigid Residue}

BASAC and pressure-residue arguments search for a terminal source measure that is too rigid to be paid by the ordinary source balance.
The forward-positive route tries to rule that object out directly.
The class route reads the object by its service.

\begin{definition}[Rigid pressure-source residue]
A rigid pressure-source residue is a selected terminal object whose pressure/source contribution remains after transported boundary losses, parent ancestry, and paid finite terms have been removed.
It is terminally relevant only when it is attached to the same solution branch.
\end{definition}

\begin{lemma}[Rigid residue service test]
A rigid pressure-source residue has no independent class face.
It is Pack-side when it lacks a positive carrier, Part-side when it loses pressure participation after a carrier survives, and Field-side only after the same carrier and same participation tower both survive.
\end{lemma}

\begin{proof}
The class object has three services.
Rigidity, by itself, is a description of how a residue behaves.
It is not a fourth service.
The selected residue must still answer the Pack question, then the Part question, then the Field question.
Those answers determine its class role.
The proof spine spends the residue only after that role is certified on the same atlas.
\end{proof}

Pressure-tail Hardy controls, transported boundary tightness, pure-pressure sustain reductions, time-face anti-atom arguments, and production into rigid subclasses all narrow the selected residue.
The narrowed residue becomes proof material when it declares the first same-atlas service it cannot keep.

\subsection{Zeno And Terminal Atoms}

Zeno arguments describe terminal objects that appear only through infinite refinement toward \(T_*\).
They are tempting because a zero-radius object can look like an especially dangerous singularity.
For the class proof, zero radius is already decisive.

\begin{proposition}[Zeno routing]
A Zeno terminal branch with no positive terminal carrier is Pack-side.
A retained positive-scale Zeno branch is a finite typed subcase in the ordinary Pack/Part/Field tree.
\end{proposition}

\begin{proof}
A zero-radius terminal atom has no positive same-fluid carrier, so it fails Pack.
When a Zeno branch retains positive scale, the branch has supplied the carrier service and must be tested for same-equation participation and coherent field readout.
Thus Zeno names a terminal mode whose class role is decided by the ordinary first failed service.
\end{proof}

The temporal non-atomicity, residence lower-bound, time-face capacity, and terminal atom exclusion arguments live here.
Their class role is direct.
They either prevent the zero-radius object from being the original branch, or they show that the selected terminal object has already failed Pack on the atlas witness.

\subsection{Retained Amplitude, Low Strain, And Height Flux}

Retained-amplitude and low-strain routes are hard because a branch can keep enough structure to avoid immediate Pack failure while still accumulating terminal field pressure.
The forward-positive route tries to prove a gain, bounded variation, or height-flux control strong enough to force readout.
The class route preserves the branch split.

\begin{proposition}[Retained-amplitude routing]
A retained-amplitude branch either creates Pack gain, loses Part participation or dwell, reaches a licensed Field diagnostic, or falls into a Zeno terminal subcase.
\end{proposition}

\begin{proof}
Retained amplitude must live somewhere.
If it produces a positive same-fluid carrier, it is Pack support.
If the carrier survives while the same pressure-viscosity tower fails to participate with the retained branch, it is Part-side.
If Pack and Part both survive, the remaining retained amplitude is read as Field pressure.
If the retained object has no positive terminal scale, it is the Zeno/Pack subcase.
\end{proof}

Height-flux and frame-variation arguments keep a retained-amplitude branch from floating between faces.
The branch must create carrier gain, pay its dwell, enter a licensed Field readout, or collapse to a terminal atom before it can affect the atlas proof.

\subsection{Signed Current And No-Free-Sink}

Signed-current arguments try to turn source-current motion into a no-free-sink law.
The obstruction is that strain production has variable sign, while terminal source charge can move through scale-critical channels.
The class proof uses signed current as a face-routing tool.

\begin{lemma}[Signed current has no independent face]
A signed-current branch returns to Pack, Part, retained Field, Zeno, or support.
It cannot be used as a fourth witness service.
\end{lemma}

\begin{proof}
Signed current measures how the source economy moves.
The class object asks whether the selected terminal packet retains the carrier, participation tower, and coherent field.
Current information can prove or support one of those service statements.
It does not add another service to \(\CM_{N,r,Q}\).
\end{proof}

The terminal signed-saturation reduction is valuable precisely because it makes this routing explicit.
Failed saturation is paid by retained partners, legal exits, pair-weight charge, finite donor balance, or else becomes a terminal zero-radius source residue.
Those alternatives are Pack/Part/Field examples or support outcomes inside the same terminal world.

\subsection{Endpoint, No-Pulse, And Good-Scale Readout}

Endpoint arguments are closest to classical continuation.
They ask for a good scale, a read cover, pulse exclusion, terminal-tail control, and coherent \(H^s\) output.
They are essential on the pass side.
They become misleading when they are treated as the primitive class test.

\begin{proposition}[Readout role]
Endpoint readout proves smooth continuation from a member packet.
It cannot certify membership without the Pack, Part, and Field services on one witness record.
\end{proposition}

\begin{proof}
The \(H^s\) continuation theorem reads a packet that already has enough coherent field control.
That packet must be carried by the same fluid, governed by the same pressure-viscosity tower, and coherent on a positive scale.
Those are the three services.
Readout is the final consequence of the services, not a replacement for them.
\end{proof}

This is the point at which the silver-standard proof differs from a brute-force positive proof.
The pass branch can use any endpoint mechanism strong enough to read a member packet.
The fail branch is handled by class exit.
The atlas proof supplies the terminal packet, so one universal endpoint estimate across every obstruction family is no longer the proof spine.

\section{Support Roles}

It still has to say which class service it protects.

\begin{proposition}[Support enters through a face]
Let \(S\) be a source, readout, comparison, or supplier statement.

\begin{corollary}[Forward-positive estimates keep their value]

\[
  \text{support Pack},\quad
  \text{support Part},\quad
  \text{support Field},\quad
  \text{support readout},\quad
  \text{or support no genuine exit}.
\]
\end{corollary}

\begin{proof}
The estimate remains available exactly where it has mathematical force.
The class proof only prevents the estimate from pretending to be the class law by itself.
Once the estimate names a service or hinge, it can be used in the proof of that service or hinge.
\end{proof}

\begin{proposition}[Branch obligations enter by first lost service]

\section{The Closing Hinges}

The proof has three mathematical hinges.

First, torus global material-atlas terminal capture is complete:
\[
  W_*
  \Rightarrow
  \neg\Pack_Q
  \vee
  \neg\Part_{N_s,Q}
  \vee
  \forall r>0\,\neg\Field_{N_s,r,Q}.
\]

Second, membership readout gives the classical continuation bound:
\[
  \Member(Q;\Owork)
  \Longrightarrow
  \sup_{t<T_*}\|u(t)\|_{H^s}<\infty,\qquad s>5/2.
\]

Third, every finite Clay terminal witness passes through the terminal witness chain:
\[
  \text{CM-test entry}
  \Rightarrow
  \neg\Pack_Q\vee\neg\Part_{N_s,Q}\vee\forall r>0\,\neg\Field_{N_s,r,Q}

  \Exit(Q;\Owork).

A reopening branch has to produce a legal in-class nonsmooth third branch or break CM terminal entry, finite-failure type exhaustion, or contrapositive embedding.

Such a theorem can strengthen the pass side and simplify the branch field.
The class-membership contrapositive needs those estimates only when they attack one of the three hinges above.

\section{Branch Derivation Patterns}

The main proof uses one derivation pattern repeatedly.
The positive attempt supplies a proposed continuation mechanism.
The failed attempt supplies a selected terminal branch.
The class proof asks which continuation service that selected branch loses first.

\begin{lemma}[Carrier pattern]
A terminal branch with zero terminal radius, detached ancestry, first-created unpaid reserve, or terminal carrier birth without a same-fluid charge path fails the carrier service.
\end{lemma}

\begin{proof}
Each listed mechanism removes the positive transported packet needed to carry \(Q\) as the same fluid branch.
The carrier service is exactly the existence of such a positive transported packet.
The first lost service is therefore \(\neg\Pack_Q\).
\end{proof}

\begin{lemma}[Participation pattern]
A terminal branch with a surviving carrier and broken pressure participation, broken viscosity participation, dwell failure, or incompatible local source participation fails the participation service.
\end{lemma}

\begin{proof}
After a carrier survives, the continuation branch still has to solve the same differentiated Navier--Stokes pressure-viscosity tower on that carrier.
The listed mechanisms break that tower while leaving the carrier question already passed.
The first lost surviving service is therefore \(\Pack_Q\wedge\neg\Part_{N,Q}\).
\end{proof}

\begin{lemma}[Field pattern]
A terminal branch with surviving carrier and participation but retained positive-window blowup, terminal pulse, averaged jump, good-scale failure, or incompatible surviving traces fails the field service.
\end{lemma}

\begin{proof}
After carrier and participation survive, membership readout needs one positive scale where the coherent \(N\)-level field remains finite.
Each listed mechanism removes that positive-scale readout while preserving the earlier services for the purpose of the case split.
The first lost remaining service is therefore \(\Pack_Q\wedge\Part_{N,Q}\wedge\forall r>0\,\neg\Field_{N,r,Q}\).
\end{proof}

\begin{proposition}[No hidden branch outside the patterns]
Every selected branch handled in the forward-family analysis is a carrier branch, a participation branch, a field branch, a finite disjunction of those three, or a support theorem awaiting a selected terminal packet.
\end{proposition}

\begin{proof}
A selected branch either lacks a positive transported packet, keeps such a packet and loses the same pressure-viscosity tower, keeps both and loses positive-scale coherent field readout, or has not yet supplied the selected packet needed for the class test.
The first three alternatives are Pack, Part, and Field.
The last alternative is support for a later selected packet.
There is no fourth continuation service in the working class object.
\end{proof}
