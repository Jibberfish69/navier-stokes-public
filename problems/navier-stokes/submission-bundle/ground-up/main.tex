\begin{abstract}
The usual way to prove the Navier--Stokes Millennium problem is to prove a positive
regularity theorem: start with smooth divergence-free data, keep a scale-critical
quantity under control, and continue the classical solution forever. That is the
gold standard. It is also the path on which the current project repeatedly runs
into the hardest source-control, readout, and terminal-tail obstructions.

This paper organizes the same material around a different proof economy. Instead
of trying to positively delete every possible bad scenario, we build a
class-membership object for the Clay problem. Smooth Clay solutions are witnessed
as members of that class. Any alleged nonsmooth terminal witness must be placed
into the same-fluid class machinery and exhausted through its failure faces. If
the witness fails one of those faces, it is not a member of the Clay class-object.
The proof is therefore contrapositive: a genuine finite-time Clay failure would
have to be both a Clay witness and outside the class that defines such a witness.
\end{abstract}

\section{The Point Of The Paper}

The paper has one job. It has to turn the current Navier--Stokes repository into a
readable proof spine.

The repository contains a large positive program. That program tries to prove
regularity by direct control: Carleson source bounds, no-pulse theorems, readout
covers, pressure and source-drain estimates, terminal-tail uniformization, and
many related continuation mechanisms. Those mechanisms are important. They are
the natural first attack. They are also where the proof becomes longest and most
fragile.

The current route does not throw that work away. It uses it to learn the shape of
the obstruction. Then it changes the logical question.

The forward question is:
\[
  \text{Can every bad terminal scenario be positively ruled out?}
\]
The contrapositive question is:
\[
  \text{If a bad terminal scenario appears, can it still be a member of the Clay
  class?}
\]
The second question is weaker as an analytic demand but strong enough for the
Millennium problem if the class is chosen correctly. We do not need every bad
scenario to be impossible as a raw weak or singular object. We need every bad
scenario that would violate Clay smoothness to exit the class of admissible
smooth-data Navier--Stokes witnesses.

\section{The Clay Target}

We work with the incompressible three-dimensional Navier--Stokes equations
\[
  \partial_t u +(u\cdot\nabla)u+\nabla p=\nu \Delta u,\qquad
  \nabla\cdot u=0,
\]
with smooth divergence-free initial data. The Clay problem asks whether the
solution stays smooth for all time in the prescribed setting.

The paper does not replace that problem by a weaker problem. It introduces a
class object whose job is to say what counts as a Clay-relevant terminal witness.
The object is not an extra assumption. It is a bookkeeping surface for the
properties already demanded by the equations, the initial data, and the
continuation packet.

\begin{definition}[Working Clay class object]
The symbol \(\Owork\) denotes the same-fluid Navier--Stokes work object generated
by the Clay data, the Navier--Stokes equations, and the terminal continuation
packet used by the lane. A candidate terminal packet \(Q\) is a member when it
keeps the three witness services required below:
\[
  \Member(Q;\Owork).
\]
\end{definition}

The proof route is governed by the primitive
\[
  \Exit(Q):=\neg \Member(Q;\Owork).
\]
So the argument is not merely trying to find a singular flow. It is trying to
test whether an alleged singular terminal object can still satisfy the same
membership services that make it a Clay object.

\section{Gold Standard And Silver Standard}

The gold-standard proof is a positive proof. It proves that the solution never
develops the bad terminal object in the first place. In this repository, that
means proving enough source control, enough terminal scale coherence, enough
readout stability, and enough continuation control to keep the classical solution
alive.

That is the most direct proof style. It is also the place where the current route
keeps producing hard supplier burdens. Examples include scale-critical tree
Carleson control, positive remainder depletion, source-weighted angular
depletion, terminal source reverse Holder control, no-pulse readout, and
endpoint readout uniformization. Each of these is a serious analytic theorem.
None is the class-membership primitive itself.

The silver-standard proof is the class-membership contrapositive. It says:

\begin{quote}
If a proposed terminal object causes nonsmoothness, then it must fail one of the
services required to be a Clay terminal witness. Therefore it is outside the
class-object that the Clay problem is asking about.
\end{quote}

That is not a rhetorical dodge. It is a different proof economy. The positive
program tries to delete bad behavior. The contrapositive program classifies bad
behavior. Once the classification is exhaustive, every genuine bad behavior is
an exit witness.

\section{The Three Witness Services}

The current direct-live authority surfaces use a three-face witness envelope:
\[
  \CM_{N,r,Q}=\Pack_Q\wedge \Part_{N,Q}\wedge \Field_{N,r,Q}.
\]
The words are technical, but the idea is simple.

\begin{definition}[Pack]
\(\Pack_Q\) means that \(Q\) has a usable same-fluid carrier and finite-window
packing geometry. It rules out terminal objects that lose the very carrier
structure needed to talk about a Clay packet on a common scale.
\end{definition}

\begin{definition}[Part]
\(\Part_{N,Q}\) means that \(Q\) retains the Navier--Stokes participation law on
the relevant packet. It rules out objects that no longer participate in the same
pressure-viscosity carrier system.
\end{definition}

\begin{definition}[Field]
\(\Field_{N,r,Q}\) means that \(Q\) retains neighboring tower or one-field
coherence at the scale \(r\). It rules out terminal objects whose local fields no
longer synchronize into the continuation packet.
\end{definition}

The face names should not be read as decorative labels. They are the three
services a terminal witness must provide if it is still a Clay-relevant
Navier--Stokes object. Carrier, participation, and field coherence are the
minimum structure needed for the continuation packet to have a target.

\section{The Synchronized Witness Ledger}

There is a small but important bookkeeping point. The three faces cannot be
borrowed from three different branches and then glued together at the end. They
must live on the same witness ledger.

We write that ledger as
\[
  \WitnessLedger=(\Owork,Q,N,r,\Phi,\mathcal T).
\]
Here \(Q\) is the retained class region, \(N\) is the tower depth, \(r\) is the
positive field scale, \(\Phi\) is the same-fluid family, and \(\mathcal T\) is
the still-live terminal window. The symbols matter only because they stop a bad
shortcut. A Pack certificate on one carrier, a Part certificate on another
branch, and a Field certificate on a third readout do not make a Clay witness.

\begin{lemma}[Cross-face synthesis license]
If Pack, Part, and Field are certified on the same witness ledger, then the
triadic CM witness is certified on that ledger:
\[
  \Pack_Q(\WitnessLedger)\wedge
  \Part_{N,Q}(\WitnessLedger)\wedge
  \Field_{N,r,Q}(\WitnessLedger)
  \Longrightarrow
  \CM_{N,r,Q}(\WitnessLedger).
\]
\end{lemma}

\begin{proof}
This is not a hidden analytic estimate. It is the synchronization rule. The
class witness is defined as the conjunction of the three services on one
same-fluid ledger:
\[
  \CM_{N,r,Q}=
  \Pack_Q\wedge \Part_{N,Q}\wedge \Field_{N,r,Q}.
\]
So the bridge is legal exactly when all three predicates refer to the same
object, carrier, depth, scale, and terminal window.
\end{proof}

The membership direction is then:
\[
  \forall N\ \exists r_N>0:\ \CM_{N,r_N,Q}
  \Longrightarrow
  \Member(Q;\Owork).
\]
This direction is installed as a certificate direction. The contrapositive paper
does not use a naked formula \(\neg \CM\Rightarrow \neg \Member\) as a black box.
It proves exit by starting with the alleged Clay witness and finding the first
service that the witness itself loses.

\section{The Contrapositive Skeleton}

The governing implication is:
\[
  \CM_{N,r,Q}\Longrightarrow \Member(Q;\Owork).
\]
The proof does not currently rely on the blunt converse
\[
  \neg \CM_{N,r,Q}\Longrightarrow \neg \Member(Q;\Owork)
\]
as an unexplained slogan. Instead, it proves the converse by witness analysis:
take a candidate Clay terminal witness, place it into the same-fluid terminal
packet tree, and show that every finite failure type breaks \(\Pack\), \(\Part\),
or \(\Field\).

\begin{theorem}[Clay terminal witness entry]
Every alleged finite-time Clay terminal witness generated from the original
smooth Navier--Stokes data must enter the same-fluid canonical terminal packet
tree.
\end{theorem}

\begin{proof}[Proof idea]
The alleged witness is not arbitrary rough data. It is the terminal witness of a
maximal classical Navier--Stokes evolution starting from smooth Clay data. The
equations, the datum, and the terminal continuation packet therefore determine
the carrier, participation, and field-coherence questions that must be asked of
that witness. This is the entry step: before the witness can be used against the
Clay problem, it has to be judged inside the Clay packet tree.
\end{proof}

\begin{theorem}[Finite failure type exhaustion]
Once an alleged finite terminal witness is inside the same-fluid terminal packet
tree, its first genuine failure type exhausts through
\[
  \neg \Pack_Q,\qquad
  \neg \Part_{N,Q},\qquad
  \text{or}\qquad
  \forall r>0\,\neg \Field_{N,r,Q}.
\]
\end{theorem}

\begin{proof}[Proof idea]
A terminal witness can fail as carrier geometry, as participation in the
Navier--Stokes packet, or as same-field coherence. If none of those fails, then
the object still supplies the packet services needed for continuation. Thus a
genuine finite failure has to be found in one of the three witness services.
\end{proof}

\begin{theorem}[Clay CM contrapositive embedding]
An alleged finite-time Clay terminal witness whose finite failure type exhausts
through \(\Pack\), \(\Part\), or \(\Field\) is an exit witness:
\[
  \Exit(Q):=\neg \Member(Q;\Owork).
\]
\end{theorem}

\begin{proof}[Proof idea]
Membership in \(\Owork\) requires the packet services encoded by
\(\Pack_Q\), \(\Part_{N,Q}\), and \(\Field_{N,r,Q}\). If the alleged terminal
witness loses one of those services, then it is no longer a member of the class
object. It may be a diagnostic object, a supplier obstruction, a readout failure,
or a weak limit, but it is not the Clay member whose failure would refute global
smoothness.
\end{proof}

\section{Canonical Terminal Packet Capture}

The route becomes useful only after the alleged bad object is captured by the
same terminal packet. This is where the proof stops being a slogan. A finite-time
Clay counterexample is not just any singular distribution. It is supposed to be
the terminal obstruction of the same smooth-data Navier--Stokes evolution.

\begin{definition}[Same-solution terminal obstruction]
A terminal obstruction \(\mathcal R_*\) is same-solution when it is extracted
from a maximal classical solution \((u,p)\) on \([0,T_*)\), with
\(T_*<\infty\), after passing to a terminal subsequence and removing legal
boundary losses, cutoff losses, collar losses, non-selected branches,
readout-only artifacts, and paid finite ledger terms.
\end{definition}

\begin{theorem}[CanonicalTerminalPacketCapture.A]
Every same-solution terminal obstruction is captured by the Pack-first CM tree:
\[
  \mathcal R_*
  \Longrightarrow
  \neg \Pack_Q
  \vee
  \neg \Part_{N_s,Q}
  \vee
  \forall r>0\,\neg \Field_{N_s,r,Q}.
\]
Equivalently, the obstruction lands at the first failed service:
\[
  \mathcal R_*
  \Longrightarrow
  \begin{cases}
  \neg \Pack_Q,\\
  \Pack_Q\wedge\neg \Part_{N_s,Q},\\
  \Pack_Q\wedge \Part_{N_s,Q}\wedge
  \forall r>0\,\neg \Field_{N_s,r,Q}.
  \end{cases}
\]
\end{theorem}

\begin{proof}
Before \(T_*\), every compact window is classical. The local same-fluid packet
therefore supplies the same three services: a positive legal carrier, the
differentiated pressure-viscosity participation tower, and positive-scale
one-field coherence. The terminal extraction can only ask which of those
services survives.

If no positive legal carrier survives, the obstruction has lost Pack. If the
carrier survives but the differentiated Navier--Stokes tower cannot be written
on it through the continuation depth, the obstruction has lost Part. If both
carrier and participation survive, then a surviving Field scale would give the
full continuation packet. The \(H^s\), \(s>5/2\), continuation readout would then
extend the classical solution past \(T_*\), contradicting maximality. Thus Field
cannot survive at any positive scale on that last branch.
\end{proof}

\begin{corollary}[No fourth residue]
After legal losses, readout artifacts, non-selected branches, and paid finite
ledger terms are removed, a same-solution terminal obstruction has no fourth
primitive CM face.
\end{corollary}

\begin{proof}
A proposed fourth residue would have to be a same-solution terminal obstruction
that is not carrier loss, not participation loss, and not one-field coherence
loss. But those are exactly the three services used by the continuation packet.
The proposed residue is therefore either an already sorted failure of Pack,
Part, or Field, or it is supplier/readout language waiting for a bridge license.
\end{proof}

\section{The Witness Theorems Expanded}

The preceding section gives the short spine. This section expands the same
argument into the form a referee needs to see. The point is to begin with the
alleged Clay witness itself, not with an external deletion theorem.

\begin{definition}[CM-lawful Clay terminal witness]
A finite-time Clay terminal witness \(W_*\) is CM-lawful when it is offered as a
witness for the same original Navier--Stokes solution. This means five things.
It has the same smooth datum. It belongs to the same incompressible
Navier--Stokes equation. It is extracted from the same transported fluid carrier
available on preterminal smooth windows. It is still claiming to be the finite
terminal obstruction after boundary losses, cutoff losses, non-selected branches,
readout-only artifacts, and paid finite ledger terms have been removed. And its
only primitive terminal services are Pack, Part, and Field.
\end{definition}

This definition is deliberately not a conclusion. It does not assume the witness
has exited the class. It only says that if the witness is going to count against
the Clay problem, it has to be the witness of the same smooth-data
Navier--Stokes object.

\begin{theorem}[ClayTerminalWitnessCMEntry.A]
Every CM-lawful Clay terminal witness enters the same-fluid CM terminal packet
tree:
\[
  ClayWitness_{\CM}(W_*)\Longrightarrow TerminalCMTree(W_*).
\]
\end{theorem}

\begin{proof}
Let \(W_*\) be a CM-lawful terminal witness at \(T_*<\infty\). Let \((u,p)\) be
the maximal classical solution generated by the original smooth datum on
\([0,T_*)\). For every \(\varepsilon>0\), the restriction of this solution to
\([0,T_*-\varepsilon]\) is classical. Hence every compact preterminal window
carries the same datum, the same equation, the same velocity and pressure, and
the same transported fluid family.

On those preterminal windows, the same-fluid local class packet supplies Pack,
Part, and Field after choosing a positive local scale. These predicates are not
decorative estimates. They are the analytic services that say the local packet
is still inside the same Navier--Stokes object.

Now take the terminal extraction that produces \(W_*\). Because the witness is
CM-lawful, this extraction is not external to the preterminal family. It keeps
the same datum, same equation, same pressure-velocity pair, and same transported
carrier. Once legal losses and irrelevant branches are removed, the surviving
terminal object has only the Pack-first grammar:
\[
  \text{Pack first; if Pack survives, Part second; if Pack and Part survive,
  Field third.}
\]
Thus \(W_*\) enters \(TerminalCMTree(W_*)\).
\end{proof}

\begin{theorem}[ClayFiniteFailureTypeCMExhaustion.A]
Every CM-lawful finite Clay failure type is exhausted by a first failed CM face:
\[
  ClayWitness_{\CM}(W_*)\Longrightarrow
  \left(
    \neg \Pack_Q\vee
    \neg \Part_{N_s,Q}\vee
    \forall r>0\,\neg \Field_{N_s,r,Q}
  \right),
\]
where \(N_s\) is high enough for the installed \(H^s\), \(s>5/2\),
continuation readout.
\end{theorem}

\begin{proof}
By ClayTerminalWitnessCMEntry.A, \(W_*\) enters the Pack-first terminal CM tree.
Fix a terminal window \(Q\) on the same terminal tail and choose the continuation
depth \(N_s\).

First ask whether the terminal extraction leaves a positive legal same-fluid
carrier on \(Q\). If no such carrier survives, then the witness has lost the
packing service and \(\neg \Pack_Q\). This covers zero-radius terminal objects,
detached donor ancestry, and every selected terminal object that cannot be
placed on a positive same-fluid transported carrier.

Now assume Pack survives. The object has a legal carrier, so the next question is
whether the same differentiated Navier--Stokes participation tower survives on
that carrier:
\[
  D_tU_k=K_k+B_k,\qquad
  K_k=-\nabla^{k+1}p+\nu\Delta U_k,\qquad
  0\le k\le N_s.
\]
If the terminal witness cannot be written inside this same pressure-viscosity
tower with finite participation envelope through depth \(N_s\), then the
participation service has failed and \(\neg \Part_{N_s,Q}\). This covers tower
drop, pressure-viscosity participation failure, source residue that cannot
remain in the shared participation ledger, and every retained carrier whose
obstruction no longer belongs to the same Navier--Stokes law through the
required depth.

Finally assume Pack and Part both survive. If Field survived at some positive
scale \(r>0\), then the terminal packet would contain the full
continuation-complete CM witness
\[
  \CM_{N_s,r,Q}=
  \Pack_Q\wedge \Part_{N_s,Q}\wedge \Field_{N_s,r,Q}.
\]
The installed continuation readout at depth \(N_s\) gives
\[
  \sup_{t<T_*}\|u(t)\|_{H^s}<\infty,\qquad s>5/2.
\]
Classical local well-posedness in \(H^s\), \(s>5/2\), then extends the same
solution beyond \(T_*\). That contradicts the claim that \(W_*\) is a finite
terminal witness. Therefore no positive Field scale survives:
\[
  \Pack_Q\wedge \Part_{N_s,Q}\wedge ClayWitness_{\CM}(W_*)
  \Longrightarrow
  \forall r>0\,\neg \Field_{N_s,r,Q}.
\]

The three cases exhaust the terminal possibilities because the witness has
already entered the same-fluid CM tree. A fourth residue would have to be a
same-solution obstruction that is neither carrier loss, nor participation loss,
nor one-field coherence loss. After legal losses, readout artifacts,
non-selected branches, and paid finite ledger terms are removed, no such fourth
primitive service remains.
\end{proof}

\begin{theorem}[ClayCMContrapositiveEmbedding.A]
Every CM-lawful finite Clay terminal witness whose first failed service is
exhausted through Pack, Part, or Field is a class-exit witness:
\[
  ClayWitness_{\CM}(W_*)
  \Longrightarrow
  \Exit(Q;\Owork).
\]
\end{theorem}

\begin{proof}
By ClayFiniteFailureTypeCMExhaustion.A, the witness forces
\[
  \neg \Pack_Q
  \vee
  \neg \Part_{N_s,Q}
  \vee
  \forall r>0\,\neg \Field_{N_s,r,Q}.
\]
Each alternative is the loss of a service needed by the same-fluid continuation
packet. The Pack case loses the same-fluid carrier. The Part case loses
pressure-viscosity tower participation on that carrier. The Field case loses
positive-scale one-field coherence after Pack and Part have already survived.

The route's exit primitive is
\[
  \Exit(Q;\Owork):=\neg \Member(Q;\Owork).
\]
So the alleged Clay witness is not left as an unclassified counterexample
object. It has declared the exact service by which it leaves the working Clay
class.
\end{proof}

\begin{theorem}[ClayTerminalWitnessInvalidation.A]
There is no CM-lawful finite Clay terminal witness that remains unclassified by
the CM contrapositive program.
\end{theorem}

\begin{proof}
Let \(W_*\) be a CM-lawful finite Clay terminal witness. It enters the
same-fluid CM tree by ClayTerminalWitnessCMEntry.A. It then lands in exactly one
first failed service by ClayFiniteFailureTypeCMExhaustion.A: Pack fails first,
or Pack survives and Part fails, or Pack and Part survive and Field fails.

Each landing is an \(\Exit(Q)\) witness by ClayCMContrapositiveEmbedding.A.
Therefore the alleged witness does not remain as an in-class counterexample
object. Its own failure classifies it outside \(\Owork\).
\end{proof}

\begin{corollary}[ClayCMCounterexampleExclusion.A]
Inside the CM route, no finite-time Clay counterexample remains after
Pack/Part/Field witness-face exhaustion.
\end{corollary}

\begin{proof}
A CM-route Clay counterexample must provide a CM-lawful finite terminal witness
whose failure is not already exhausted by the class-membership witness grammar.
ClayTerminalWitnessInvalidation.A proves that every such witness is exhausted by
Pack, Part, or Field. Therefore no unexhausted CM-route counterexample remains.
\end{proof}

\section{Why The Forward Program Still Appears}

The paper must still discuss the positive program because it explains why the
class faces are the right faces.

For example, a scale-critical tree Carleson theorem is a natural positive
target. If it were proved directly from smooth data, it would provide strong
source control. But when this target fails in a selected terminal branch, the
failure is not a fourth kind of Clay failure. Once carrier and participation are
retained, the selected source-reserve failure is a field-coherence failure.

Likewise, a Zeno terminal atom looks like a source-control obstruction in the
positive program. In the contrapositive program, the same object is sorted by
whether it keeps a positive-radius packet, participates in the same fluid law,
and preserves field coherence. A terminal zero-radius residue is not a retained
positive-radius packet. It is a Pack-side exit unless extra structure is proved.

This pattern is the reason the paper begins with the forward mechanisms and then
switches. The forward mechanisms expose the obstruction. The contrapositive
method says where the obstruction lands.

\section{Major Surface Sorting}

The lane has already sorted the major non-Euler Navier--Stokes surfaces into the
class-membership program. The sorting rule is:

\begin{quote}
A surface is CM-live only when its selected failure lands in Pack, Part, Field,
or a typed subcase already sorted to those faces.
\end{quote}

The result is the following high-level map.

\begin{enumerate}[leftmargin=2em]
\item A selected scale-critical source-reserve failure lands in \(\Field\) once
\(\Pack\) and \(\Part\) are retained.
\item A selected finite Zeno terminal atom is sorted through the same witness
tree; a zero-radius endpoint residue is not a retained Pack packet.
\item Retained amplitude failure lands in Pack or Part, or returns to the
source-wall Field diagnostic.
\item Height-flux and low-strain BV failures route to Pack, Part, Field, or a
Zeno subcase already sorted by the witness tree.
\item Signed-current presentations do not create a new face; they return to
Pack, Part, or source-wall Field support.
\item Square-reserve failure is not a new face; retained failure is the Carleson
Field diagnostic.
\item Good-scale and readout failures are downstream Field/readout support.
\item The PCTP, no-pulse, AWG, TGC, and no-\(Jump_{\mathrm{avg}}\) family is
supplier/readout support unless separately licensed into a witness face.
\end{enumerate}

This is what the current repository means by major non-Euler CM contrapositive
closure. It does not say every positive theorem has been proved. It says every
major selected failure has a legal class-membership destination or remains
quarantined as support.

\section{Reader's Version Of The Proof}

Here is the argument without the machinery.

Start with a smooth Navier--Stokes datum and suppose, for contradiction, that the
Clay solution fails at a first finite time. The alleged failure must show up as a
terminal witness of that same solution. It cannot be a different equation, a
different fluid, a detached source artifact, or a bookkeeping residue that has
already been paid away.

Now ask what the witness still has. It needs a common packet to live on. That is
Pack. It needs to participate in the same pressure-viscosity Navier--Stokes
tower. That is Part. It needs neighboring tower coherence at a positive scale so
the continuation readout has an object. That is Field.

If the witness keeps all three, it is not a terminal breakdown witness; the
continuation readout extends the classical solution. If it loses one of the
three, it has exited the class-object that defines a Clay-relevant
Navier--Stokes witness. Thus the alleged counterexample never survives as an
in-class Clay object.

That is the whole proof idea. The technical work is making each sentence above
local, synchronized, and immune to supplier/readout substitutions.

\section{The Clean Proof Spine}

The proof spine can now be stated without the generated machinery.

\begin{claim}[Class-membership proof spine]
Assume a finite-time Clay failure exists from smooth Navier--Stokes data. Then it
has a terminal witness \(Q\). By terminal witness entry, \(Q\) must enter the
same-fluid CM packet tree. By finite failure type exhaustion, \(Q\) fails Pack,
Part, or Field. By the contrapositive embedding, that failure is
\(\Exit(Q)\). Hence \(Q\) is not a member of \(\Owork\). Therefore the alleged
Clay failure witness is not a Clay member.
\end{claim}

\begin{proof}
The assumption supplies a terminal object that is supposed to count against the
Clay problem. That object cannot be judged outside the Clay packet structure,
because the problem begins with smooth data and the Navier--Stokes equations.
The entry theorem places the object in the same-fluid packet tree.

Inside that tree, the object must retain carrier geometry, participation in the
Navier--Stokes packet, and field coherence. Those are the Pack, Part, and Field
witness services. If the terminal object fails, the exhaustion theorem says that
the first genuine finite failure appears in at least one of those services.

But losing one of those services is exactly leaving the class object. The bad
object is then outside \(\Owork\). It cannot be the member whose failure would
defeat the Clay statement.
\end{proof}

The current manuscript should be read as a serious working article, not as a

\section{What Is Still Not Being Claimed}

This draft is intentionally honest about the boundary.

It does not claim that every positive supplier theorem has been proved. It does
not claim that every weak, rough, singular, or diagnostic object is impossible.
It does not claim that endpoint readout, no-pulse, Carleson control, or
source-drain estimates are irrelevant. Those results remain valuable support.

The claim is narrower and cleaner: once a proposed bad object is tested as a
Clay terminal witness, every genuine finite failure type either exits the class
through Pack, Part, or Field, or remains quarantined until a named bridge theorem
promotes it into one of those faces.

That is the paper's submission shape. The remaining work is not to add more
generated appendices. The remaining work is to make the three theorem statements
above fully formal, local, and referee-readable.
