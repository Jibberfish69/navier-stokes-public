\nsoriginalsection{Gold-Standard Route and Same-Solution Burden}

This paper studies finite-time breakdown for the incompressible three-dimensional Navier--Stokes equations with smooth divergence-free initial data and zero external force, on both the periodic and whole-space branches. The gold-standard route seeks a priori estimates strong enough to propagate smoothness for all time. That route begins with the energy law, which controls total kinetic energy and accumulated viscous dissipation, and then pushes upward toward derivative-level control, where vortex stretching, scale concentration, loss of compactness, packet localization, and endpoint behaviour expose the main obstruction.

The present paper takes the complementary silver-standard route. A genuine breakdown claim has to do more than indicate where an estimate loses control. It has to identify what the original fluid becomes at the alleged final time. The central question is an identity question: does the proposed terminal object still represent the same incompressible viscous fluid field governed by transport, pressure, viscosity, and the divergence-free constraint?

We formalize that identity burden through three tests, each corresponding to a structural requirement for identifying the alleged terminal object with the original Navier--Stokes fluid.

The first is the Packet test. Since we are trying to certify smoothness, our window and witness carrier must be defined on a region of positive size rather than at a single point. Any argument that certifies smoothness at a terminal time must therefore retain control of the flow on a nonzero spatial region. When that window collapses to zero scale, there is no longer a positive region on which smoothness can be certified, and the claimed identification of the terminal object with the original fluid breaks down.

The second is the Participation Law. Navier--Stokes evolution is defined through the coupled action of transport, pressure, viscosity, and the incompressibility constraint. Participation therefore means that the object continues to enter these laws as an incompressible fluid field. In particular, the local incompressibility rule must remain meaningful and operative on the object itself. If the candidate no longer supports that law-governed participation, then it may arise as a mathematical limit, but it is no longer the same Navier--Stokes fluid.

The third is the Field Coherence Law. Once local participation is required, a further global requirement follows: the object must still cohere as one field. The incompressibility rule is imposed over the entire fluid field. Therefore, a lawful terminal breakdown candidate must also retain positive-scale field coherence across the whole domain of the fluid. If a variation or change occurs in the fluid field, the entire field responds simultaneously. Any proposed terminal state that breaks apart into separate pieces that no longer form a single connected fluid field fails this requirement. For example, if only isolated singular points, detached packets, or disconnected remnants remain, then the object no longer behaves as one incompressible Navier--Stokes fluid and cannot represent the same solution.

Together, these tests distinguish loss of control in an estimate from loss of the fluid's identity. Any finite terminal candidate either passes all three tests---retaining a material carrier, participating in the same Navier--Stokes dynamics, and cohering as a single field---and therefore remains within the smooth continuation regime, or it fails at least one test and thereby leaves the class of objects that can be identified with the same solution. In this way, finite-time breakdown is recast as a pass-or-exit classification for the same Navier--Stokes fluid.
