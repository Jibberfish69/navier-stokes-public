\begin{abstract}
The usual Navier--Stokes proof route is forward-positive. It tries to keep the
smooth solution under direct analytic control forever. That route is the gold
standard: prove the needed scale-critical estimates, prevent terminal breakdown,
and continue the classical solution. The present project keeps that route in the
paper because it is the natural way to discover the real obstructions. It also
records why that route becomes exceptionally hard: the source wall, the
terminal-tail readout, the no-pulse route, the square-reserve problem, the
height-flux route, the signed-current route, and the transfer/comparison
branches all ask for difficult positive control theorems.

The route proposed here is different. It treats the Clay problem as a
class-membership problem. A smooth Clay solution is witnessed as a member of the
working class object. An alleged nonsmooth terminal witness of the same equation,
same datum, and same fluid is tested against the services required by that
object. The services are Pack, Part, and Field: a same-fluid carrier, same
Navier--Stokes participation, and positive-scale one-field coherence. The proof
spine is simple in shape, but the work is to justify its use. A terminal witness
must first be shown to be the same-solution witness Clay is asking about; then a
first failed required service is a class exit:
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
The main work of the paper is to earn the right to use that line. Every
forward-positive branch and every currently indexed non-Euler Navier--Stokes
surface must either land in this witness tree or remain support until a named
Pack/Part/Field bridge promotes it.
\end{abstract}

\section{The Problem In One Plain Picture}

The Clay Navier--Stokes problem starts with smooth divergence-free initial data
and asks whether the corresponding three-dimensional incompressible flow remains
smooth for all time. The equations are
\[
  \partial_t u +(u\cdot\nabla)u+\nabla p=\nu\Delta u,\qquad
  \nabla\cdot u=0.
\]
The pressure is not an optional accessory, and viscosity is not a decorative
term. Together with incompressibility they decide what it means for the same
fluid to keep participating in the same Navier--Stokes law.

The direct picture is familiar. Start with a classical solution. Suppose there
is a first time \(T_*<\infty\) at which the smooth solution cannot be continued.
Then something terminal must have happened to the same solution. It is not enough
to point at any rough object or any formal singularity. A Clay counterexample
has to be a terminal witness of the original smooth-data Navier--Stokes
evolution.

That sentence is the hinge of the paper. If the alleged bad object is the
terminal witness of the same solution, then it must still answer the same
membership questions that define the Clay object. Does it have a usable
same-fluid carrier? Does it participate in the same pressure-viscosity law? Does
it keep positive-scale field coherence? Those are not after-the-fact labels.
They are the services a terminal object must keep if it is still a Clay witness.

The proof route therefore has two movements.

First, we let the forward-positive program run. We ask the natural questions:
can the source tree be controlled, can terminal pulses be ruled out, can the
readout be made uniform, can the reserve be depleted, can the signed current be
coerced, can the endpoint cover be prevented from collapsing? This is the
gold-standard route because it tries to kill the bad object outright.

Second, at the point where the forward route becomes a thicket of separate
supplier burdens, we change the logical question. We stop asking whether each
bad object can be positively deleted. We ask whether that bad object can remain
a member of the Clay class. If the bad object loses a required service, then it
has not refuted Clay smoothness from inside the class. It has testified to its
own class exit.

This is the silver-standard route in the sense intended by this paper. Its claim
is not that every singular-looking object is impossible in every broader weak or
diagnostic universe. Its claim is that a nonsmooth terminal object only matters
to the Clay problem while it remains inside the class whose members are the
Clay-relevant smooth-data Navier--Stokes witnesses.

\section{The Gold Standard}

The gold-standard Navier--Stokes proof is a forward-positive proof. It proves
that the bad terminal object never forms. A classical route of this kind controls
a continuation quantity, uses local well-posedness above the critical threshold,
and extends the smooth solution past every proposed terminal time.

In this repository the forward-positive program appears in many forms. The
names are numerous, but the idea is always close to the same thing: keep enough
source, scale, readout, and participation control alive that the solution can be
continued.

\subsection{Source Control}

The source-control branch tries to stop a terminal positive source reserve from
accumulating at the final scale. In its strongest form this is the
scale-critical tree Carleson problem. A successful positive theorem would show
that the donor-refill ancestry, active source reserve, and critical source
packet cannot concentrate in the terminal way needed for failure.

The project has many source-control presentations: local positive source
Carleson, square reserve evolution, native trilinear defect domination, positive
remainder depletion, source-weighted angular depletion, active-shell amplitude
gain, and terminal source reverse Holder variants. They are not cosmetic
duplicates. They are different ways of trying to find a positive source theorem.

\subsection{Endpoint Readout}

The endpoint-readout branch tries to convert packet control into a continuation
readout. It asks for a good scale, a uniform read cover, stable differentiated
towers, and a way to read terminal packets into an \(H^s\), \(s>5/2\), norm.
If that readout works on a positive terminal scale, classical local theory
continues the solution beyond \(T_*\).

This is why the Field face matters later. Field is not a vague word for
regularity. It is the positive-scale coherence needed to read the packet as one
continuable Navier--Stokes object.

\subsection{No-Pulse And Averaged Routes}

The no-pulse branch tries to rule out source pulses, terminal-tail jumps, and
averaged endpoint escapes. It includes the PCTP, source no-pulse, averaged weak
gain, terminal gain cover, and no-averaged-jump family. The positive aim is to
show that the terminal tail never produces the pulse or averaged jump needed for
breakdown.

These surfaces are useful because they identify the readout burden. They are
dangerous if they are mistaken for the class-membership primitive itself. A
no-pulse supplier is not Pack, Part, or Field merely because it talks about a
bad terminal pulse.

\subsection{Reserve, Height, And Signed Current}

The reserve branch asks for a square-reserve or active-window theorem strong
enough to control the source tree. The height branch asks whether first positive
height flux, low-strain variation, near-band material source charge, and frame
rotation can be forced into a controlled alternative. The signed-current branch
tries to turn terminal source motion into a no-free-sink or parabolic
edge-resistance principle.

Each branch is a serious positive attempt. Each also reveals a common pattern:
when the direct estimate fails, the failure is not automatically a new kind of
Clay counterexample. The failure must be tested for class membership.

\subsection{Transfer And Comparison}

The fixed-\(\nu\) Euler-to-Navier--Stokes transfer and the Euler mirror program
are separate branches. They compare neighboring theorem worlds and can expose
useful boundaries, but they do not automatically prove stand-alone
Navier--Stokes smoothness and they do not steer the non-Euler
class-membership proof. They remain quarantined from the main proof unless a
named theorem transfers the exact object into the same Pack/Part/Field witness
tree.

\section{Where The Gold Standard Hits The Wall}

The forward route hits the wall because each positive branch demands a theorem
that is stronger than what is needed for class-membership exclusion. A direct
proof tries to erase the bad object. The contrapositive proof lets the bad
object appear and asks whether it can still be the object Clay is talking about.

The difference is practical. A source residue can be hard to delete and still be
easy to classify. A zero-radius terminal atom can be hard to preclude and still
fail the Pack service immediately. A retained object can evade a positive
source theorem and still fail same-fluid participation. A readout branch can be
unable to produce endpoint smoothness and still reveal that positive-scale Field
coherence has failed.

The paper therefore does not hide the forward program. It uses the forward
program as the reader's path into the obstruction. The proof becomes shorter
only after the obstruction has been placed in the correct class-membership
question.

\subsection{The Source-Wall Obstruction}

The source wall asks for a direct theorem of the form: original smooth data
prevents the selected terminal source reserve from concentrating. The current
live authority sharpens the old source-wall language. For the
scale-critical donor-refill branch, the governing CM placement is Pack-side:
\[
  \Pack_Q \Longrightarrow \text{scale-critical donor-refill Carleson control}.
\]
A selected unpaid infinite donor-refill tree is therefore not a retained Field
object by default. It is first a Pack failure, because the ancestry needed for a
usable same-fluid carrier has detached.

This correction matters. Older retained-Field diagnostic language remains in
historical major-surface notes for branches where Pack and Part alternatives
have already been removed. The live paper must not read that older wording as a
global Field landing. First-face order governs: Pack is asked first, then Part,
then Field.

\subsection{The Zeno Obstruction}

The Zeno branch asks whether a terminal source atom can be excluded by temporal
anti-concentration, reverse Holder control, or a produced rigid residue class.
Those are forward-positive aims. The CM question is simpler. A terminal
zero-radius source residue is not a positive-radius Pack packet. It lands at
\[
  \neg \Pack_Q
\]
before any retained Field readout can be spent. A finite Zeno ancestry packet can
still be sorted by the typed Zeno rules, and a retained positive-scale atom may
become a Field diagnostic after Pack and Part have separately survived. But
Zeno is not a fourth face.

\subsection{The Retained-Amplitude Obstruction}

The retained-amplitude branch tries to prove that a retained face gains enough
low-strain or amplitude control from Pack and Part. The obstruction is that a
finite Pack deformation gauge does not by itself control accumulated positive
low-strain action. The branch therefore cannot be treated as a finished positive
smoothness proof.

For the CM paper, the failure has a smaller job. It must declare whether it is a
Pack-gain failure, a Part-envelope failure, or a return to the source-wall
diagnostic after the retained alternatives are fixed. It does not create an
independent fourth service.

\subsection{The Height And Low-Strain Obstruction}

The height-flux route asks whether first positive height creation, low-strain
variation, near-band material source charge, and frame variation can be paid
without circularity. The forward proof becomes hard because far-low terms can be
controlled while near-band and frame terms merge back into signed source balance.

The class-membership reading is a typed finite disjunction. A branch goes to
Pack gain, Part dwell or participation failure, legal Field source charge, or a
Zeno subcase already sorted by the witness tree. The hard positive theorem
remains useful, but it is not the proof spine.

\subsection{The Signed-Current Obstruction}

The signed-current program tries to rectify terminal source-current motion into
a parabolic no-free-sink law. The obstruction is that localized flux estimates
leave a scale-critical flux-amplitude remainder and variable-sign
strain-production term. That is why signed-current presentations keep returning
to active strain alignment, tangent weights, terminal no-free-sink, or source
reserve.

For CM use, the signed-current family has no independent face. It returns to
Pack, Part, source-wall Field after retained licensing, Zeno, or supplier
quarantine.

\subsection{The Square-Reserve Obstruction}

The square-reserve route tries to prove a square-charge law strong enough to
control the source reserve. First-moment source balance is not enough: a
first-moment tail can vanish while a square reserve remains order one. This is
why square reserve evolution and native trilinear defect domination remain
hard positive supplier work.

The CM paper does not need the square-reserve supplier theorem as a primitive.
When a selected retained square-reserve failure has been licensed past Pack and
Part, it reads as the Carleson source-reserve diagnostic. When the square-charge
identity is merely absent, the surface remains supplier work and cannot steer
the proof.

\subsection{The Readout Obstruction}

The good-scale and read-cover family tries to obtain endpoint readout. It asks
for noncollapse of the good scale, uniform cover, Field readout, DTC readout,
and terminal \(H^s\) continuation. A positive route must produce that structure
from original smooth data.

The contrapositive route asks a narrower question. If a terminal object has Pack
and Part but no positive Field scale, then it has already failed the service
needed for endpoint readout. If the readout surface only describes downstream
consumer behavior, it remains support.

\subsection{\texorpdfstring{The Local \(L^3\) Translator Obstruction}{The Local L3 Translator Obstruction}}

The local public-critical \(L^3\) branch translates terminal Duhamel response
mass into native source work on the same ledger, or into Pack/Part/legal exit.
This is useful witness extraction. It does not turn every public critical class
into a Clay closure theorem. Its job in this paper is branch-local: when the
local \(L^3\) terminal mass appears, it lands in the CM witness grammar.

\section{The Switch To Class Membership}

The switch is the point of the paper.

The gold-standard route asks:
\[
  \text{Can we prove from the original data that the bad terminal packet never
  appears?}
\]
The class-membership route asks:
\[
  \text{When the alleged bad packet appears, can it still be a member of the
  Clay class?}
\]
Those are not the same question. The first question is a positive smoothness
problem. The second question is a contrapositive class-exclusion problem.

The second question is the route used here. We take the properties of the
Navier--Stokes equations and the initial data, convert them into a class object,
define witnesses and failure types, and show that the failure types land in the
witness faces and exit the class object. Put simply: smooth solutions to the
Millennium Navier--Stokes problem are witnessed as class members. Nonsmooth
solutions of the same equation that fail one of the required services are
witnessed outside that class. They may remain diagnostically important, but they
are no longer in-class counterexamples to the object Clay asks us to continue.

This is not a slogan about ignoring singularities. The singularity is used. It
is made to answer a membership question. If the singular terminal object cannot
provide the services required by the same-fluid Navier--Stokes class, then it is
not the object whose existence would refute the Clay claim.

\section{The Class Object}

The working class object is denoted by \(\Owork\). It is the same-fluid
Navier--Stokes work object generated by the Clay data, the Navier--Stokes
equations, and the terminal continuation packet.

\begin{definition}[Working Clay class object]
A candidate terminal packet \(Q\) is a member of \(\Owork\) when it retains the
same-fluid services needed to function as a Clay-relevant Navier--Stokes
terminal witness:
\[
  \Member(Q;\Owork).
\]
The class-exit primitive is
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
\end{definition}

The definition is intentionally plain. The class is not a new equation. It is
the object we get when the original smooth data, incompressibility, pressure,
viscosity, transported fluid carrier, and terminal continuation packet are kept
on the same ledger.

A proposed terminal witness may be rough, singular, concentrated, or diagnostic.
That does not decide the Clay question. The Clay question is decided by whether
the proposed witness remains a member of the same class object. A terminal
packet that loses the services required for membership is not an in-class
counterexample.

\subsection{The Three Witness Services}

The direct-live surfaces use the three-face witness packet
\[
  \CM_{N,r,Q}=\Pack_Q\wedge\Part_{N,Q}\wedge\Field_{N,r,Q}.
\]
The notation is short because the idea should stay visible.

\begin{definition}[Pack]
\(\Pack_Q\) is the same-fluid carrier service. It says that \(Q\) has a usable
positive terminal carrier, cover, or packing geometry on which the same fluid
packet can be discussed. A zero-radius terminal residue, detached donor
ancestry, or unpaid infinite donor-refill tree fails here.
\end{definition}

\begin{definition}[Part]
\(\Part_{N,Q}\) is the same Navier--Stokes participation service. It says that
on the carrier \(Q\), the pressure-viscosity tower still participates in the
same differentiated Navier--Stokes law through depth \(N\):
\[
  D_tU_k=K_k+B_k,\qquad
  K_k=-\nabla^{k+1}p+\nu\Delta U_k,\qquad 0\le k\le N.
\]
Tower drop, participation failure, and unpaid source residue that cannot remain
in the shared pressure-viscosity ledger fail here.
\end{definition}

\begin{definition}[Field]
\(\Field_{N,r,Q}\) is the positive-scale one-field coherence service. It says
that after a same-fluid carrier and same participation tower have survived, the
local fields still synchronize at some positive scale \(r\). Failure here is the
loss of the positive-scale coherence needed for endpoint readout and
continuation.
\end{definition}

Pack, Part, and Field are services, not decorative bins. A bad object is not
classified by whichever name sounds closest. It is classified by the first
service it fails in the Pack-first terminal tree.

\subsection{The Same-Ledger Rule}

The three services cannot be borrowed from three different worlds. A Pack
certificate on one carrier, a Part certificate on another branch, and a Field
certificate on a third readout do not make a Clay witness. They must live on the
same witness ledger:
\[
  \WitnessLedger=(\Owork,Q,N,r,\Phi,\mathcal T).
\]
Here \(Q\) is the retained class region, \(N\) is the tower depth, \(r\) is the
positive field scale, \(\Phi\) is the same-fluid family, and \(\mathcal T\) is
the terminal window.

\begin{lemma}[Cross-face synthesis license]
On one witness ledger,
\[
  \Pack_Q(\WitnessLedger)\wedge
  \Part_{N,Q}(\WitnessLedger)\wedge
  \Field_{N,r,Q}(\WitnessLedger)
  \Longrightarrow
  \CM_{N,r,Q}(\WitnessLedger).
\]
\end{lemma}

\begin{proof}
This is the synchronization rule for the packet. The CM witness is the
conjunction of the carrier service, participation service, and field-coherence
service on the same ledger. The implication is legal exactly when the carrier,
tower, scale, same-fluid family, and terminal window match.
\end{proof}

The installed membership direction is
\[
  \forall N\ \exists r_N>0:\quad \CM_{N,r_N,Q}\Longrightarrow
  \Member(Q;\Owork).
\]
The paper does not use the blunt converse
\[
  \neg\CM_{N,r,Q}\Longrightarrow\neg\Member(Q;\Owork)
\]
as an unexplained logical shortcut. That converse is too crude. A random failure
of an arbitrary CM-looking packet is not automatically class exit. The exit
step is licensed by the witness analysis: start with the alleged Clay terminal
witness itself, put it into the same-fluid terminal tree, and find the first
service the witness loses.

\subsection{Capturing The Terminal Packet}

The capture theorem is where the route stops being a slogan. A finite-time Clay
counterexample is supposed to be a terminal obstruction of the same maximal
classical solution. Once legal losses, readout artifacts, non-selected branches,
and paid finite ledger terms are removed, that obstruction has only the
services required by the continuation packet.

\begin{definition}[Same-solution terminal obstruction]
A terminal obstruction \(\mathcal R_*\) is same-solution when it is extracted
from a maximal classical solution \((u,p)\) on \([0,T_*)\), \(T_*<\infty\), by
passing to a terminal subsequence and removing legal boundary losses, cutoff
losses, collar losses, non-selected branches, readout-only artifacts, and paid
finite ledger terms.
\end{definition}

\begin{theorem}[CanonicalTerminalPacketCapture.A]
Every same-solution terminal obstruction is captured by the Pack-first CM tree:
\[
  \mathcal R_*
  \Longrightarrow
  \neg \Pack_Q
  \vee
  \neg \Part_{N_s,Q}
  \vee
  \forall r>0\,\neg \Field_{N_s,r,Q}.
\]
Equivalently,
\[
  \mathcal R_*
  \Longrightarrow
  \begin{cases}
  \neg \Pack_Q,\\
  \Pack_Q\wedge\neg \Part_{N_s,Q},\\
  \Pack_Q\wedge \Part_{N_s,Q}\wedge
  \forall r>0\,\neg \Field_{N_s,r,Q}.
  \end{cases}
\]
\end{theorem}

\begin{proof}
For every compact subinterval \([0,T_*-\varepsilon]\), the solution is
classical. On such a window the same-fluid local packet supplies the carrier,
participation tower, and positive-scale field coherence required by the
continuation readout. Passing toward \(T_*\) asks what survives.

If no positive legal terminal carrier survives, Pack has failed. If the carrier
survives but the differentiated pressure-viscosity tower cannot be written on
it through depth \(N_s\), Part has failed. If Pack and Part survive and some
positive Field scale also survives, then the full continuation packet survives.
The installed \(H^s\), \(s>5/2\), readout gives a uniform continuation norm, and
classical local theory extends the same solution beyond \(T_*\). That contradicts
the claim that \(\mathcal R_*\) is a terminal obstruction. Hence Field fails at
every positive scale in the last case.
\end{proof}

\begin{corollary}[No fourth residue]
After legal losses, readout artifacts, non-selected branches, and paid finite
ledger terms are removed, a same-solution terminal obstruction has no fourth
primitive CM face.
\end{corollary}

\begin{proof}
A fourth residue would be a same-solution terminal obstruction that is not
carrier loss, not participation loss, and not field-coherence loss. Those three
services are exactly the services needed by the continuation packet. The
proposed residue is therefore either already one of the three failures, or it is
supplier/readout language waiting for a named bridge into one of them.
\end{proof}

\section{Where The Main Branches Go}

This is the reader's map of the branch field. Each branch appears because the
forward proof naturally asks for it; each branch also has to be given a legal
place in the class-membership proof. The point is not to make a larger table.
The point is to make sure that every familiar obstruction is either a
Pack/Part/Field witness, a finite typed alternative, or support that has not
earned authority over the proof.

\begin{description}[leftmargin=2em,style=nextline]
\item[Pack carrier and cover.]
The forward proof tries to keep a positive same-fluid carrier, cover, packing,
or transport window. When the common packing is lost, donor ancestry detaches,
or no positive terminal carrier remains, the alleged witness has failed the
first service. It lands at \(\neg\Pack_Q\), and the proof does not ask later
Field questions about that same object.

\item[Part participation.]
When the carrier survives, the forward proof has to keep the differentiated
pressure-viscosity tower on that carrier through the required depth. The
obstruction is a retained carrier whose terminal object no longer belongs to the
same Navier--Stokes participation law. After Pack survives, that is
\(\neg\Part_{N,Q}\). Source residue with a retained carrier is read here before
it is allowed to become Field language.

\item[Field coherence.]
Field is the retained case. The carrier is still there, and the same
pressure-viscosity participation law is still there, but the object loses
positive-scale one-field coherence and endpoint readout. The legal landing is
\(\forall r>0\,\neg\Field_{N,r,Q}\), and it is licensed only after the local
Pack and Part alternatives have been removed.

\item[Scale-critical tree Carleson.]
Here the forward proof wants direct donor-refill/source-reserve Carleson control
from the original smooth data. The live correction is simple: selected unpaid
donor-refill ancestry is Pack-side because the branch is not yet a retained
positive carrier. Older retained-Field wording is usable only after the local
Pack and Part alternatives have already been cleared.

\item[Local positive source Carleson and positive remainder depletion.]
This branch tries to delete terminal positive source reserve by source-weighted
depletion or angular decorrelation. The obstruction is that the deletion still
needs source-weighted terminal angular depletion or an equivalent positive
source-control input. Until that exact input lands a selected branch in Pack,
Part, or Field, it remains a positive supplier result rather than the
class-membership proof itself.

\item[Zeno and terminal atom.]
The forward route tries to prove temporal non-atomicity, reverse Holder control,
or a rigid residue class with Liouville. A terminal zero-heat-time or
zero-radius residue can survive that attempt. A terminal zero-radius residue
lands at \(\neg\Pack_Q\); retained positive-scale Zeno atoms are typed
diagnostics, not a fourth service beside Pack, Part, and Field.

\item[Retained amplitude.]
The forward hope is that retained Pack/Part structure forces enough amplitude
gain to keep the endpoint coherent. The obstruction is that finite deformation
gauge does not control accumulated positive low-strain action. In the
class-membership proof this branch becomes Pack-gain failure, Part-envelope
failure, or source-wall retained diagnostic. It does not create a new retained
amplitude face.

\item[Height and low strain.]
The forward proof tries to turn first positive height flux or low-strain BV
control into a decisive positive estimate. The obstruction is the near-band
region, where material source charge and frame variation merge back into signed
source balance. The class-membership use is a finite typed disjunction:
Pack gain, Part/dwell failure, legal Field charge, or Zeno.

\item[Signed current and no-free-sink.]
The forward proof tries to get a parabolic no-free-sink or edge-resistance law
for terminal source current. Variable-sign strain production and a
scale-critical flux-amplitude remainder keep that route from becoming a free
coercion theorem. Its failures return to Pack, Part, source-wall Field/Zeno, or
positive supplier support; there is no independent ``current'' face.

\item[Square reserve and native trilinear.]
This branch asks for a square-source charge law or native trilinear defect
domination. The reason it matters is that first-moment control does not force
square-reserve control. When the square-charge identity is absent, this is
supplier work. When a selected retained square-reserve failure survives, it
reduces to the Carleson diagnostic.

\item[Good scale and read cover.]
Good scale, uniform read cover, and endpoint \(H^s\) readout are powerful only
after the packet they read has survived. The obstruction is that upstream
source-wall or Zeno production is still needed before readout can be spent. This
branch explains Field readout; it does not supply an upstream primitive.

\item[PCTP, no-pulse, and averaged route.]
The no-pulse family tries to exclude terminal pulses, averaged jumps, and
terminal-tail escape. It remains conditional because source-drain and diffuse
legal ancestry are not fully priced. It may support Field readout after a
licensed bridge, but it is not itself Pack, Part, or Field.

\item[Receiver escape and retained Field endpoint.]
This branch asks whether receiver/coherence escape breaks the retained endpoint
packet. The bridge is narrow and depends on retained Pack and retained Part. In
that licensed branch the landing is Field; neighboring DTC, tower, and ACT.KX
notes remain conditional support.

\item[Local \(L^3\) Duhamel translator.]
The local \(L^3\) translator converts terminal Duhamel response mass into native
source work or exit. Its strength is also its limit: it is local, and it does
not prove every public critical-class bridge. It gives a branch-local landing:
terminal local \(L^3\) mass lands in Pack/Part/legal class-exit form, and under
retained Pack plus Part can feed the local Field readout.

\item[Fixed-\(\nu\) Euler transfer.]
The fixed-\(\nu\) branch compares Euler and Navier--Stokes on the same datum,
same interval, and fixed viscosity. That is a transfer program. It does not
become stand-alone Navier--Stokes smoothness, and it does not enter the
non-Euler class-membership proof unless an explicit transfer theorem lands the
exact object.

\item[Euler mirror.]
The Euler mirror removes viscosity to study overlap and divergence with the
Euler theorem program. It is valuable comparison work, but it is not the
fixed-\(\nu\) transfer theorem and cannot steer the Navier--Stokes
class-membership frontier. It stays outside the non-Euler sweep as comparison
support.

\item[Downstream export and legacy branches.]
TPS/SG.4, exact potential, Hodge, strict-shadow, mixed-jet, Lagrangian, and
export surfaces are presentation or downstream support unless a named bridge
lands the exact object in Pack, Part, or Field. They can organize proof
material. They cannot certify the Pack-first witness tree by presentation alone.

\item[Generated, runtime, and source-history surfaces.]
Dashboards, manifests, generated copies, runtime status, and historical notes
are useful carriers of context. They can also lag or inherit stale closure
language. The proof therefore reads them as authority carriers or provenance:
they inherit the Pack/Part/Field gate and create no independent face.
\end{description}

The ledger is long because the promise is long. The proof spine is short; the
branch field is not. A submission reader needs to see that the paper has not
smuggled a positive supplier burden into the class-membership primitive, and has
not smuggled a generated export surface into theorem authority.

\subsection{How The Branches Read}

The ledger above is still too compressed to be the reader's only guide. A table
can say where a branch lands, but it cannot make the movement feel inevitable.
This section walks the main branch families in the order a human reader should
feel them: what the forward proof wants, why that want is natural, where the
obstruction appears, and why the obstruction becomes either a class-exit witness
or quarantined support.

\subsubsection{Carrier Failure Is Not A Mystery}

The first question is not subtle. Does the terminal object still have a usable
same-fluid carrier? If it does not, it has already lost the first service. That
is Pack failure.

This point is easy to miss because many analytic presentations dress the failure
in richer language. A donor tree may detach. A terminal residue may have no
positive heat radius. A source-refill ancestry may be unpaid. A zero-thickness
atom may be the surviving object after every legal loss is removed. These
objects can be mathematically interesting, but none of them is automatically a
retained Clay packet. The first thing the proof asks is whether the alleged
counterexample can still be placed on a positive common carrier of the same
fluid.

That is why the live authority places the selected unpaid donor-refill
Carleson branch on the Pack side. The older way of talking about source-wall
diagnostics sometimes described a retained source-reserve failure as Field-side.
That wording is legal only after the row has already inherited or discharged its
Pack and Part alternatives. The current paper keeps the order strict. The
terminal object does not get Field language simply because it comes from a
source-control branch. It earns Field only after it has first kept a carrier and
kept participation.

In ordinary language, the Pack test asks whether there is still a positive
same-fluid carrier on which the alleged witness can be read. If that carrier is
gone, the object has already failed the first membership service.

\subsubsection{Participation Failure Is Where The Equation Bites}

Suppose the carrier survives. The next question is whether the object still
participates in the same Navier--Stokes law. This is the Part service.

The reason Part is separate from Pack is physical as well as formal. A set can
still carry a packet, and yet the packet may no longer be a lawful participant
in the same pressure-viscosity evolution. The flow is incompressible, pressure
is coupled nonlocally, viscosity is present at fixed positive \(\nu\), and the
differentiated tower has to remain the same tower. A terminal object that cannot
be written inside that tower is not merely a difficult Field readout. It has
lost participation.

This is where raw source residue has to be handled carefully. A residue that is
not first deleted by a positive theorem can be the witness. If it has no
carrier, it exits through Pack. If a carrier remains but the residue cannot stay
inside the shared pressure-viscosity/source participation ledger, it exits
through Part. Field is reserved for the later case where the carrier and the
participation law have both survived and the remaining failure is positive-scale
coherence.

This order prevents a common false shortcut. It is tempting to call every source
or readout obstruction a Field obstruction because Field is the last visible
readout. The witness grammar blocks that shortcut. Field is not the dumping
ground for anything that looks analytical. Part is where the same-equation
requirement bites.

\subsubsection{Field Failure Is The Last Retained Failure}

Field is the last service because it is the service that can only be asked after
the first two have survived. A terminal object with no carrier cannot fail Field
as a retained Field object. A terminal object that cannot participate in the
same pressure-viscosity law cannot fail Field as a retained Field object. Field
is the branch where the same-fluid carrier is still present, the same equation is
still active, and the final coherence needed for continuation disappears.

This is why the Field count in the diagnostic map is large. Many surfaces are
receiver, readout, endpoint, source-residue, or retained-coherence surfaces.
They become Field-side after their local Pack and Part alternatives are removed.
That does not mean the paper assumes Pack and Part globally. It means the row
has a local proof-order: first carrier, then participation, then positive-scale
field coherence.

Field matters only after the earlier services have survived. Carrier loss
explains a Pack exit. Participation loss explains a Part exit. Field explains
the remaining retained case: the object is still on the same carrier and still in
the same equation, but no positive scale supports one coherent continuable field.

\subsubsection{Why Source-Control Surfaces Stay In The Paper}

The source-control material stays in the paper because it is how the project
found the hard geometry. It would be wrong to erase it. The Carleson tree,
positive remainder, angular depletion, local positive source, native trilinear,
and square-source surfaces all point toward the same pressure point: terminal
source production is the place where a positive proof becomes expensive.

The class-membership proof does not make those surfaces irrelevant. It changes
their role. A source-control theorem can still be a strong positive supplier. It
can simplify the branch ledger by preventing a bad object from appearing. It can
also feed downstream no-pulse or endpoint readout. What it cannot do is replace
the Pack-first witness tree.

When a source-control attempt fails, the paper does not say, ``therefore the
proof is stuck.'' It asks what the failed source-control branch has produced.
The answer is a selected failure. That selected failure is then tested for
carrier, participation, and field coherence. If it exits, the contrapositive has
used the obstruction. If it is merely a supplier statement without a selected
failure, it is quarantined until a named bridge gives it a face.

This is the difference between abandoning the forward program and absorbing it
into the contrapositive route. Every forward source-control surface becomes
either a witness-face landing, a typed subcase, or support.

\subsubsection{Why Zeno Does Not Become A Fourth Face}

Zeno language is dangerous because it can sound like a new primitive endpoint.
There is finite ancestry, terminal atom language, temporal non-atomicity, source
residue, reverse Holder control, and rigid residue classes. If those words are
allowed to steer the proof, Zeno becomes a fourth service without earning that
role.

The paper does not allow that. Zeno is a presentation of how a terminal source
or ancestry object can appear. It is not a new class service. A terminal
zero-radius residue fails Pack. A retained positive-scale Zeno atom is read only
after carrier and participation have survived. A temporal anti-concentration
theorem is a positive supplier theorem. A rigid residue class with Liouville is
another supplier route. None of those objects gets to bypass Pack, Part, and
Field.

The forward-positive aim is clear: prove temporal non-atomicity or produce a
rigid class and rule it out. That would be a strong positive theorem. It is also
more than the CM contrapositive needs. The contrapositive only needs the terminal
Zeno object to answer the membership services. When it fails one, it exits.

\subsubsection{Retained Amplitude Is A Boundary, Not A New Program}

The retained-amplitude branch has a natural forward hope. If a retained face has
Pack and Part, perhaps the same structure forces enough amplitude gain or
low-strain control to keep the field coherent. The obstruction is that net
deformation control is not the same as accumulated positive low-strain control.
One can keep the former finite while the latter still becomes problematic.

That obstruction matters, but its CM role is bounded. It either exposes a Pack
gain problem, a Part envelope problem, or a source-wall diagnostic. It does not
create an extra retained-amplitude service sitting next to Pack, Part, and
Field.

The reader should not treat retained amplitude as a new theorem program that
must be solved before the contrapositive can move. It is a boundary surface. It
helps decide where a selected retained failure belongs.

\subsubsection{Height Flux And Low Strain Are A Typed Routing Engine}

The height-flux route is one of the places where the forward program looks most
tempting. A first large positive height flux feels like it ought to leave a
visible charge. Low-strain BV feels like it ought to let the proof sample the
right times. Near-band and frame-variation terms feel like they ought to be
payable by scale separation.

Parts of that intuition work. Far-low variation has parabolic gain. Some burst
alternatives route cleanly. The obstruction is the near-band and frame
alignment region, where material source charge and signed source balance
reappear. The forward proof does not get a free height-control theorem.

The CM use is cleaner. The branch is a typed routing engine. It says that first
positive height or low-strain failure must become Pack gain, Part/dwell failure,
legal Field source charge, or a Zeno subcase. The branch is successful for this
paper because it does not leave a nameless residue. It routes the residue into
the existing witness grammar.

\subsubsection{Signed Current Shows The Cost Of Coercion}

The signed-current route tries to turn motion into coercion. It lifts terminal
source-current behavior into a parabolic graph or flow picture, tries to prevent
closed source-current cycles, and looks for a no-free-sink law. This is a good
forward idea. If it closed unconditionally, it would be a serious positive
source-control engine.

The obstruction is that the PDE does not give the graph proof for free. The
commutator has variable sign. Absolute value estimates can lose the cancellation
the route needs. Localized flux estimates leave a scale-critical amplitude
remainder. Coercion keeps asking for active strain alignment, tangent weight
rigidity, or another source-control theorem.

For the CM proof, this whole family is support unless it produces a selected
failure with a face. The signed-current branch can return to Pack, Part,
source-wall Field, or Zeno. It cannot install a fourth face called
``current.'' That is the honest value of the branch: it narrows the route and
shows where the same old membership services are being lost.

\subsubsection{Square Reserve Explains Why First Moments Are Not Enough}

The square-reserve branch gives a good physical lesson. A first-moment source
tail can look harmless while a square reserve remains large. That is why a
positive proof wants square-reserve evolution, active-shell source
normalization, or native trilinear domination. The forward route is trying to
find a quantity strong enough to see the terminal reserve that weaker ledgers
miss.

The CM proof does not deny that problem. It places it. If the square-reserve
identity is absent, the branch is supplier work. If a selected retained
square-reserve failure survives after Pack and Part have been licensed, it
returns to the Carleson source-reserve diagnostic. If the ancestry required by
the reserve has detached, it is earlier Pack failure.

This is a recurring theme: the positive theorem and the contrapositive landing
are not enemies. The positive theorem tries to remove the branch. The
contrapositive landing says what the branch means when it is not removed.

\subsubsection{Readout Is Downstream Until It Is Licensed}

Readout surfaces can sound decisive because endpoint readout is close to
continuation. If the proof has a good scale, a read cover, Field readout, DTC
readout, and an \(H^s\) endpoint bound, then local theory continues the solution.
That is powerful.

But readout is downstream. It cannot be used to assume the packet it is supposed
to read. A readout theorem may explain why positive Field coherence would
continue the solution. It may also explain why loss of Field is terminal after
Pack and Part survive. What it cannot do is create Pack, Part, or Field from
dashboard language.

This is why good-scale and endpoint surfaces sit in support unless their exact
object has a bridge into the witness tree. The paper uses them to explain the
importance of Field. It does not let them steer the proof ahead of the
membership services.

\subsubsection{The No-Pulse Family Is A Supplier, Not The Spine}

The no-pulse and averaged routes are attractive because they feel close to the
reader's intuition about blow-up. A terminal pulse or averaged jump is a vivid
bad event. Ruling it out positively would make the proof feel decisive.

The repository's live authority keeps the direction typed. PCTP, source
no-pulse, averaged weak gain, terminal gain cover, and no-averaged-jump are
supplier or readout surfaces. They are allowed to support endpoint production.
They are not allowed to become the class-membership primitive.

The distinction matters for the manuscript. The paper should not sell no-pulse as the
hidden proof. It should show why no-pulse appears in the forward program, why it
is difficult, and why the CM route does not require it to delete every terminal
object. Once a terminal object is a lawful exit witness, the contrapositive has
already used it.

\subsubsection{The Local Critical Translator Has A Narrow Job}

The local critical translator is useful because it shows how terminal Duhamel
response mass can be localized to same-ledger nonlinear source work or exit. In
plain terms, it prevents a local \(L^3\) packet from floating outside the CM
grammar. It either becomes native source work on the same ledger or it has
already touched Pack/Part/legal exit.

That is valuable. It is also narrow. It is not a generic theorem saying every
public critical class is controlled, and it is not the Clay-facing proof by
itself.
Its job is to make one public-critical-looking branch enter the witness faces.

The paper includes it because a reader will reasonably ask what happens to
critical concentration language. The answer is: local terminal \(L^3\) Duhamel
mass has an installed CM translator, and that translator is branch-local support
for the same Pack-first proof.

\subsubsection{Transfer And Mirror Branches Stay Separate}

The fixed-\(\nu\) transfer program and the Euler mirror program are important
because they teach what depends on viscosity and what does not. They are not
the same program. Fixed-\(\nu\) transfer compares two equations on the same
datum and interval. Euler mirror removes viscosity for comparison and exposes
overlap and divergence with an Euler theorem program.

Neither branch is allowed to steer the non-Euler CM proof. This is not because
the comparison is useless. It is because the proof object is different. The
non-Euler CM proof starts with a Navier--Stokes Clay terminal witness and asks
for Pack, Part, and Field in the Navier--Stokes same-fluid class. A transfer or
mirror result enters only when it has a named theorem landing the exact object
into that class.

This separation is part of paper quality. A submission draft that blurs Euler
comparison with Navier--Stokes class membership would look broad but would be
less honest. The present route keeps them apart.

\subsubsection{Generated Surfaces Are Consumers}

Generated surfaces are useful to workers. They summarize, export, gate,
diagnose, and route. They are not theorem truth. This matters because a
generated surface can lag behind the direct-live authority and still sound
confident.

The proof therefore reads generated YAML, submission copies, dashboards, runtime
state, and export manifests as carriers or consumers. They inherit from the
theorem notes and direct-live surfaces they cite. They do not create new faces.
They do not close a proof because a field says ready. They do not reopen a proof
because a stale blocker says open. The paper's authority runs through the
Pack-first witness tree and the materialized surface ledgers.

This is also why the old proof-obligation matrix is absent from the proof. A
flat matrix can be useful to legacy automation, but it is too lossy to govern
this paper. The live proof has multiple branches, multiple support layers, and a
first-face order that a flat readiness artifact can erase.

\section{How Every Surface Is Classified}

\subsection{The Main Non-Euler Branches}

The major non-Euler classification is the branch-level version of the same
claim. It says that the named major Navier--Stokes surfaces have no independent
CM steering authority outside Pack, Part, Field, typed finite subsets, or
support quarantine.

\begin{proposition}[MajorNonEulerCMContrapositiveClosure.A]
For the major non-Euler Navier--Stokes branches named in the live surface map,
every selected failure has one of the following outcomes:
\[
  \text{Pack exit},\quad
  \text{Part exit},\quad
  \text{Field exit},\quad
  \text{typed Pack/Part/Field/Zeno subcase},\quad
  \text{support quarantine}.
\]
\end{proposition}

\begin{proof}[Branch sorting]
The branch ledger above is the sorting map. The Pack and Part branches are direct
service failures. Field branches are retained only after the local Pack and Part
alternatives have been removed or inherited. Zeno branches are typed; a terminal
zero-radius residue lands at Pack, while retained positive-scale atoms are
diagnostic Field branches after licensing. Retained amplitude, height/low-strain,
signed-current, square-reserve, good-scale, no-pulse, \(L^3\), transfer, export,
generated, runtime, and source-history surfaces either land through that tree or
remain barred from theorem use until a named bridge promotes them. No branch
creates a fourth primitive service.
\end{proof}

\subsection{Every Indexed Surface}

The all-surface classification is the row-level version. It matters because a
proof repository this large can drift even when each single note sounds
plausible. The surface sweep prevents that drift from becoming theorem
authority.

\begin{proposition}[AllNonEulerNSSurfaceFaceSweep.A]
Every indexed non-Euler Navier--Stokes text surface is classified as Pack or a
Pack bridge, Part or a Part bridge, Field or Field readout support, a typed
Pack/Part/Field/Zeno subset, a source-wall/Zeno diagnostic, or support material
with no independent CM steering authority.
\end{proposition}

\begin{proposition}[AllNonEulerCMContrapositiveClosure.A]
Every indexed non-Euler row is certificate-classified for the CM contrapositive
program: its selected failure certifies a Pack, Part, or Field exit, or the row
is barred as a CM theorem source until promoted by a named bridge.
\end{proposition}

\begin{proof}
The materialized index, diagnostic map, and certificate ledger have the same
row set. The diagnostic map assigns each row a selected failure type or a
support quarantine. The certificate ledger then assigns a certificate rule: direct
face failure, selected retained Field failure, finite face disjunction, authority
inheritance, or no selected CM failure without bridge. These rules exhaust the
row set. Therefore every row has a legal CM landing, an inherited no-new-face
status, or a quarantine status.
\end{proof}

This is the paper's answer to the phrase ``every surface'' for the current
materialized non-Euler field. The proof spine does not print 1944 rows in the
main text. It keeps row authority in the ledgers and presents the branch
families in the paper so a referee can inspect the logic without reading a file
inventory as prose.

\subsection{How A Row Earns A Role In The Proof}

The row-level machinery is easiest to understand as five tests. A surface does
not become proof material merely because it contains the word regularity, source,
endpoint, Pack, Part, Field, readout, or Clay. It becomes proof material only
after the audit has found its selected failure and determined the legal CM role
of that failure.

\subsubsection{First, Is It In The Right Problem?}

The first test is scope. The row must belong to the non-Euler
Navier--Stokes proof field. Euler mirror, fixed-\(\nu\) Euler-to-Navier--Stokes
transfer, zero-viscosity comparison, and Euler-class comparison surfaces are
excluded from this pass. They may be useful in their own branch, but they do not
enter the non-Euler CM proof by accident.

This prevents a subtle error. A comparison note can sound like it has solved a
Navier--Stokes branch because it explains how a nearby equation behaves. That
is not enough. The non-Euler CM proof starts with a Navier--Stokes Clay terminal
witness. A comparison surface enters only when it has a named theorem that
transfers the exact witness into the same Pack/Part/Field class.

\subsubsection{Second, What Job Is It Doing?}

The second test is role. The row is classified by theorem role, not by
keyword. A sentence can mention Pack while actually discussing a Field readout.
A source note can mention Field while its first selected failure is Pack. A
generated YAML surface can mention closure while merely inheriting authority
from another note.

The role classifier asks what job the row is doing. Is it a carrier or cover
failure? Is it pressure-viscosity participation? Is it one-field coherence or
receiver readout after retained hypotheses? Is it a typed finite disjunction?
Is it source history, runtime state, manuscript export, generated authority, or
downstream support?

That role test is why the paper can handle thousands of surfaces without
flattening them. A file is not trusted because of its tone. It is trusted only
where its role is licensed.

\subsubsection{Third, What Bad Object Is It Offering?}

The third test is selected failure. The row must say what bad object or
bad branch it is actually presenting. A vague obstruction is not enough. The
selected failure is the object that will be tested against the membership
services.

For a carrier branch, the selected failure may be zero positive radius,
detached ancestry, or loss of common packing. For a participation branch, it may
be tower drop, pressure-viscosity nonparticipation, or unpaid source residue
after the carrier remains. For a Field branch, it may be loss of positive-scale
coherence after carrier and participation survive. For a support branch, there
may be no selected CM failure at all.

This is where the paper avoids proof-shaped fog. It does not ask whether a
surface sounds serious. It asks what witness the surface is trying to hand to
the proof.

\subsubsection{Fourth, Which Service Fails First?}

The fourth test is first-face order. The selected failure is not placed
by resemblance. It is placed by the Pack-first terminal tree:
\[
  \Pack\quad\text{then}\quad\Part\quad\text{then}\quad\Field.
\]
The order matters. A source residue with no positive carrier is Pack failure.
A source residue with retained carrier but broken pressure-viscosity
participation is Part failure. Only a retained branch with Pack and Part
licensed reaches Field as a one-field coherence or readout failure.

This first-face order is what prevents older retained-Field language from
drifting into the current paper. It also prevents no-pulse, readout, and source
surfaces from becoming Field by name alone. The Field face is last because it is
the last retained service.

\subsubsection{Fifth, What Status Has It Earned?}

The fifth test is the certificate. The row receives one of the statuses recorded
in the certificate ledger.

If the selected failure breaks Pack, Part, or Field, the row is a certified CM
exit. If the row is a typed subset, it is a finite disjunction whose alternatives
have already been routed to the faces. If the row is an authority carrier or
generated copy, it inherits the gate and creates no new face. If the row has no
selected CM failure, it is unlicensed until a named bridge promotes it.

This is why quarantine is not failure. Quarantine is a theorem-status
claim. It says: this surface cannot be used to steer the CM proof. It may remain
useful, but it is not currently proof material for class exit.

\subsection{What Support Is Allowed To Do}

The word quarantine can sound defensive, so the paper should say exactly what it
means. A quarantined surface is not deleted. It is not called false. It is not
ignored. It is prevented from doing a job it has not earned.

There are several kinds of quarantine.

\subsubsection{Positive Supplier Results}

A supplier surface proposes a positive theorem that would help the proof if
proved. Examples include positive source depletion, temporal anti-atom
theorems, square-reserve evolution, active-shell gain, reverse Holder control,
or source-current coercion. These surfaces are valuable research targets. They
can still shrink the forward program.

They are quarantined only from CM authority. A supplier theorem is not a witness
face by itself. It becomes CM proof material when it lands the exact selected
failure in Pack, Part, or Field, or when it proves that a branch cannot appear
and thereby simplifies the branch ledger. Until then, it is support.

\subsubsection{Readout Results}

A readout surface explains how a packet would produce continuation, endpoint
control, no-pulse behavior, averaged no-jump behavior, or terminal-tail
uniformization. These surfaces are close to the final smoothness feeling, so
they are especially easy to overuse.

The paper keeps them downstream. Readout explains what a surviving packet would
give, and it explains why Field coherence matters. It does not create the
packet it reads. Without Pack and Part, readout is not a Field witness. Without
a named bridge, readout is support.

\subsubsection{Export And Manuscript Surfaces}

Export and manuscript surfaces translate proof material into public-facing
forms. They help workers and readers. They do not decide theorem truth. A
manuscript, manifest, submission status, or generated copy can say what the proof
is presenting, but it cannot become the proof authority over the direct-live
theorem surfaces.

This is why this paper names its authority sources at the end. The manuscript is
a consumer of the live proof surfaces. It is not allowed to make a stale
generated readiness label into mathematical truth.

\subsubsection{History And Recovery Notes}

Source-history and recovery notes are retained because they preserve the
project's idea field. They may contain old names, earlier route attempts, and
terminology that later authority corrected. That material remains searchable and
useful, but it cannot silently override the current live edge.

The source-wall Field wording is the main example in this paper. Some older

\subsection{When A Branch Stops Steering The Proof}

A branch is classified for this paper when it can no longer steer as an
unclassified CM obstruction. There are three ways that can happen.

\subsubsection{By A Face Landing}

The cleanest classification is direct face landing. The selected failure breaks the
carrier, participation, or field-coherence service. Once that happens, the
branch is not a surviving in-class counterexample. It has become an exit
witness.

This is enough for the class-membership proof layer even when it is not positive
smoothness closure. A bad object can remain as a diagnostic object. It can even
remain as a challenge for a stronger positive theorem. It no longer remains as an
in-class Clay counterexample.

\subsubsection{By A Finite Disjunction}

Some branches do not land in one face immediately. They produce a finite list of
lawful alternatives. Height and low-strain branches are like this: Pack gain,
Part/dwell failure, legal Field source charge, or Zeno. Typed disjunction is
classified when every alternative has already been routed to the witness tree.

This matters because a finite disjunction can look like unfinished branching.
For the CM proof, it is finished when each branch of the disjunction has a legal
landing. The paper does not need one label for the whole family. It needs no
unrouted residue.

\subsubsection{By Inheritance}

Generated authority, manuscript copies, runtime state, and some governance
surfaces do not carry independent failures. They are classified by inheritance.
They inherit the current Pack/Part/Field gate from the theorem surfaces they cite.
They cannot add a fourth face and cannot bypass the live edge.

This inheritance rule is part of the backend machinery of the paper. It keeps
presentation surfaces from becoming mathematical sources.

\subsubsection{By A Promotion Bar}

A quarantined surface is classified negatively for theorem use. It is barred
from steering the CM proof until it has a named promotion bridge. This is a
genuine classification state for the current CM ledger because it prevents silent
drift. The paper knows where the surface sits: support, not theorem spine.

That bar can be lifted. A future theorem can promote a supplier or readout
surface by landing the exact object in Pack, Part, or Field. The bar says only
that such a theorem is not currently present.

\subsection{The Reader's Simple Test}

A Clay-facing reader should be able to test the paper with a small set of
questions.

\subsubsection{The Same-Solution Question}

Is the alleged bad object a witness of the same original smooth-data
Navier--Stokes evolution?

If the answer is no, the object may be interesting but it is not the Clay
terminal witness being consumed by this proof. If the answer is yes, it enters
the same-fluid terminal packet tree.

\subsubsection{The Carrier Question}

Does the witness still have a positive same-fluid carrier?

If the answer is no, the witness exits through Pack. The proof does not need to
ask Field questions about an object that lacks the carrier required for Field.

\subsubsection{The Participation Question}

If the carrier survives, does the witness still participate in the same
pressure-viscosity Navier--Stokes tower?

If the answer is no, the witness exits through Part. The proof does not turn raw
source residue into Field unless same-equation participation has survived.

\subsubsection{The Field Question}

If carrier and participation survive, does the witness have positive-scale
one-field coherence?

If the answer is no, the witness exits through Field. If the answer is yes, the
full continuation packet survives, and the \(H^s\), \(s>5/2\), readout extends
the classical solution past the alleged terminal time.

\subsubsection{The Promotion Question}

Is any surface being used before it has answered the first four questions?

If yes, that surface is being promoted too early. It must either be landed in
Pack, Part, or Field, or it must be quarantined as support. This is the simple
reader-facing version of the entire surface authority system.

\section{The Contrapositive Witness Argument}

The Clay-facing CM spine can now be short because the terms have been earned.
The route starts with the alleged Clay witness itself. It does not start with a
positive theorem saying no bad object exists.

\begin{definition}[CM-lawful Clay terminal witness]
A finite-time Clay terminal witness \(W_*\) is CM-lawful when it is offered as a
witness for the same original Navier--Stokes solution. This means:
\begin{enumerate}[leftmargin=2em]
\item same datum: \(W_*\) is attached to the maximal classical solution
generated by the original smooth datum;
\item same equation: the preterminal object solves the original incompressible
Navier--Stokes system with the same pressure and velocity field;
\item same fluid: terminal extraction uses the same transported carrier or flow
family supplied on preterminal smooth windows;
\item same terminal role: after legal boundary losses, cutoff losses,
non-selected branches, readout-only artifacts, and paid finite ledger terms are
removed, \(W_*\) is still claiming to be the finite terminal obstruction;
\item same witness grammar: the only primitive terminal services available to
that obstruction are \(\Pack_Q\), \(\Part_{N,Q}\), and
\(\Field_{N,r,Q}\).
\end{enumerate}
\end{definition}

The definition does not assume exit. It only says what the alleged witness must
be if it is going to count against the Clay problem. The exit is the conclusion.

\begin{theorem}[ClayTerminalWitnessCMEntry.A]
Every CM-lawful Clay terminal witness enters the same-fluid CM terminal packet
tree:
\[
  ClayWitness_{\CM}(W_*)\Longrightarrow TerminalCMTree(W_*).
\]
\end{theorem}

\begin{proof}
Let \(W_*\) be a CM-lawful terminal witness at \(T_*<\infty\), and let
\((u,p)\) be the maximal classical solution generated by the original smooth
datum on \([0,T_*)\). For every \(\varepsilon>0\), the restricted solution on
\([0,T_*-\varepsilon]\) is classical. Hence every compact preterminal window
carries the same datum, equation, velocity, pressure, transported carrier, and
local same-fluid packet.

The terminal extraction producing \(W_*\) is, by hypothesis, an extraction from
this same preterminal family. After legal losses and irrelevant branches are
removed, the surviving terminal object can only ask the continuation-packet
questions: does the same-fluid carrier survive, does the same participation
tower survive, and does positive-scale field coherence survive? Those are
Pack, Part, and Field. Thus \(W_*\) enters the Pack-first terminal CM tree.
\end{proof}

\begin{theorem}[ClayFiniteFailureTypeCMExhaustion.A]
Every CM-lawful finite Clay failure type is exhausted by a first failed CM
witness face:
\[
  ClayWitness_{\CM}(W_*)
  \Longrightarrow
  \left(
    \neg\Pack_Q
    \vee
    \neg\Part_{N_s,Q}
    \vee
    \forall r>0\,\neg\Field_{N_s,r,Q}
  \right),
\]
where \(N_s\) is high enough for the installed \(H^s\), \(s>5/2\),
continuation readout.
\end{theorem}

\begin{proof}
By ClayTerminalWitnessCMEntry.A, the witness enters the Pack-first tree. Fix a
terminal window \(Q\) and continuation depth \(N_s\).

First ask whether a positive legal same-fluid carrier survives. If not, the
witness has lost the carrier service and \(\neg\Pack_Q\).

Assume Pack survives. Then ask whether the same differentiated
Navier--Stokes pressure-viscosity tower survives on that carrier through depth
\(N_s\). If not, the witness has lost the participation service and
\(\neg\Part_{N_s,Q}\).

Assume Pack and Part survive. If Field survived at some positive scale
\(r>0\), then \(\CM_{N_s,r,Q}\) would survive on the same ledger. The installed
continuation readout gives
\[
  \sup_{t<T_*}\|u(t)\|_{H^s}<\infty,\qquad s>5/2.
\]
Classical local theory would extend the same solution beyond \(T_*\), which
contradicts the terminal role of \(W_*\). Therefore no positive Field scale
survives:
\[
  \forall r>0\,\neg\Field_{N_s,r,Q}.
\]
The three cases exhaust the witness because the witness has already entered the
terminal CM tree.
\end{proof}

\begin{theorem}[ClayCMContrapositiveEmbedding.A]
Every CM-lawful finite Clay terminal witness whose first failed service is
exhausted through Pack, Part, or Field is a class-exit witness:
\[
  ClayWitness_{\CM}(W_*)\Longrightarrow \Exit(Q;\Owork).
\]
\end{theorem}

\begin{proof}
By ClayFiniteFailureTypeCMExhaustion.A, the witness loses Pack, loses Part after
Pack survives, or loses Field after Pack and Part survive. Each alternative is
the loss of a service required for \(\Member(Q;\Owork)\). By the class-exit
primitive,
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
Thus the witness is not left as an unclassified in-class counterexample. It
declares the exact service by which it leaves the working Clay class.
\end{proof}

\begin{theorem}[ClayTerminalWitnessInvalidation.A]
There is no CM-lawful finite Clay terminal witness that remains unclassified by
the CM contrapositive program.
\end{theorem}

\begin{proof}
A CM-lawful finite Clay terminal witness enters the same-fluid terminal CM tree
by ClayTerminalWitnessCMEntry.A. It then lands at a first failed service by
ClayFiniteFailureTypeCMExhaustion.A. Each first failed service is class exit by
ClayCMContrapositiveEmbedding.A. Hence no such witness remains as an in-class
terminal counterexample.
\end{proof}

\begin{corollary}[ClayCMCounterexampleExclusion.A]
Inside the CM route, no finite-time Clay counterexample remains after
Pack/Part/Field witness-face exhaustion.
\end{corollary}

\begin{proof}
An in-class CM-route counterexample would need a CM-lawful finite terminal
witness whose failure is not exhausted by the Pack-first witness grammar. The
previous CM-exhaustion step classifies every such witness. Therefore, within the
CM route, the counterexample does not remain as an in-class object.
\end{proof}

\section{The Half-Page Proof Spine}

\begin{claim}[Class-membership proof spine]
Let \(W_*\) be a CM-lawful finite terminal witness for the smooth-data
Navier--Stokes problem, and let \(Q\) be its terminal packet. Then \(W_*\) is
not a surviving in-class Clay counterexample.
\end{claim}

\begin{proof}
The witness enters the same-fluid terminal packet tree. In that tree it must

\[
  \neg\Pack_Q,\qquad
  \neg\Part_{N_s,Q},\qquad
  \text{or}\qquad

The lost service is a loss of membership in the working Clay class object.
Therefore
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
The alleged terminal witness may remain a diagnostic, supplier, readout, or
quarantine object, but it is not a surviving member-counterexample to the
smooth-data Navier--Stokes class.
\end{proof}

The spine is short for the right reason. It is short because the paper has
already walked through the forward-positive obstructions, the Pack/Part/Field
witness services, the same-ledger rule, the terminal packet capture, the branch
