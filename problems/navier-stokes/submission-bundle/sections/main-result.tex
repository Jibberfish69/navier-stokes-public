\section{Main Result}

\subsection{CM-contrapositive statement}

The proof is written for the original three-dimensional incompressible
Navier--Stokes problem from smooth divergence-free data.

\begin{theorem}[Current CM terminal witness classification]
Let \(u_0\) be smooth and divergence-free, and let \((u,p)\) be the corresponding
maximal classical Navier--Stokes solution on its maximal interval. Every alleged
finite Clay terminal witness from this same datum enters the same-fluid CM
terminal packet tree, is exhausted as a Pack, Part, or Field finite failure type,
and embeds as
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
This is the installed CM classification theorem.  It does not yet by itself
exclude finite terminal breakdown for the original Clay solution; the remaining
Clay-closing bridge is to prove that such a classified exit cannot be the actual
finite terminal obstruction for the same original smooth-data solution.
\end{theorem}

\subsection{Proof skeleton}

\begin{lemma}[Pass branch]
For each obstruction split reached by the forward-positive program, the pass
branch has a lawful same-solution \(\Member(Q;\Owork)\) witness and reads out to
smooth continuation.
\end{lemma}

\begin{lemma}[Fail branch]
A finite nonsmoothness-capable fail branch is CM-test-admissible and produces one
of
\[
  \neg\Pack_Q,\qquad \neg\Part_{N,Q},\qquad
  \forall r>0\,\neg\Field_{N,r,Q}.
\]
\end{lemma}

\begin{lemma}[No third branch]
No branch is both a legal in-class \(\Member(Q;\Owork)\) continuation and the
same terminal nonsmooth Pack/Part/Field failure witness.
\end{lemma}

\begin{proof}[Proof of the theorem]
Assume a finite terminal breakdown. The terminal object is a same-datum Clay
witness, hence it is admitted to the CM terminal packet tree. The pass side is a
member branch and continues smoothly. The fail side is a Pack, Part, or Field
face failure and embeds as \(\Exit(Q;\Owork)\). The no-third-branch law excludes
an in-class nonsmooth terminal branch. Thus the alleged finite terminal
breakdown has no legal same-class branch, and the maximal smooth solution
continues.
\end{proof}

\paragraph{Reopening boundary.}
The current CM completion can be reopened only by producing a legal in-class
nonsmooth third branch or by breaking terminal CM entry, finite failure type
exhaustion, or CM contrapositive embedding.
