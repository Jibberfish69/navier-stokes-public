\section{Notation and Internal Dependency Labels}

The paper uses a small number of project names.  Each name is tied to a proof role.

\begin{description}
\item[\(\Owork\).] The working same-solution Navier--Stokes class object.  It keeps the datum, equation, pressure law, viscosity, incompressibility constraint, and preterminal branch together.
\item[\(\Member(Q;\Owork)\).] The class-membership predicate for a selected terminal record \(Q\).  A member record is on the continuation side and must be paired with the relevant readout.
\item[\(\Exit(Q;\Owork)\).] The class-exit conclusion.  It means
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]
\item[\(\Pack_Q\).] The Pack witness face.  It asks whether the selected record still has a positive same-fluid carrier or packet.
\item[\(\Part_{N,Q}\).] The Part witness face.  It asks whether the same pressure-viscosity-incompressibility law still participates on the derivative tower being tested.
\item[\(\Field_{N,r,Q}\).] The Field witness face.  It asks whether a positive-scale coherent velocity-field readout survives at scale \(r\).
\item[\(Q_{\mathrm{ann}}\).] A selected annular residual terminal witness.  It is admitted to the CM test only after the positive-radius annular residue has been tied to the same original Navier--Stokes branch.
\item[Gold route.] The forward-positive proof route.  It tries to control the original solution directly.
\item[Silver route.] The CM contrapositive route.  It classifies a selected same-solution terminal record after a forward obstruction has survived.
\item[Annular witness.] The positive-radius terminal residue surrounding a proposed endpoint.  It is the live boundary because a radius-zero point alone does not carry the full singularity claim.
\end{description}

These names are proof objects.  A branch, comparison packet, Euler boundary, source-reserve estimate, or positive-forward estimate note enters the paper only when it pays one of these roles: same-solution admission, Pack, Part, Field, member readout, exit conclusion, gold obstruction, silver landing, context, obsolete route, or open continuation.
