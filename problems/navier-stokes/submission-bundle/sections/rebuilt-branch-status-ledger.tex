\section{Branch Status Ledger}
\label{sec:branch-status-ledger}

The rebuilt manuscript is organized by branch family. Each branch has its own
positive-forward aim, its own stopping object, and its own CM-exit role. This
ledger records the current staging status so that a reader can see what each
section is doing.

The ledger has two functions. First, it prevents branch material from being
promoted before it lands on the CM-exit grammar. Second, it keeps the manuscript
from reading like a raw archive. Each branch must finish with a clear status:
continuation readout, Pack failure, Part failure, Field failure, support, or scope
boundary.

The ledger will expand as additional branches are rebuilt: LPAS, Volterra,
signed-pair, pressure/vortex-sustain, no-pulse/source-wall, endpoint/local,
torus, and whole-space export.
