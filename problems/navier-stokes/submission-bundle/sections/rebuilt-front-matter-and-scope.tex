\section*{Abstract}

We study finite-time breakdown claims for the three-dimensional incompressible
Navier--Stokes equations from smooth divergence-free data. The direct route to
global regularity is a positive-forward estimate: control the nonlinear source,
keep the relevant derivative quantities finite, recover a classical continuation
criterion, and extend the solution. This paper records what happens when that
route is pushed branch by branch. Across scale barriers, source estimates,
compactness arguments, packet constructions, endpoint criteria, and surface
transfers, the same pattern appears: the positive-forward attempt leaves a
terminal survivor, residue, defect, or scope boundary whose proof role must be
classified.

The proof method developed here is the class-membership exit contrapositive.
Rather than trying to erase every terminal survivor by a stronger positive
estimate, we ask whether the alleged finite-time breakdown object still qualifies
as a same-solution Navier--Stokes terminal witness. The witness is tested by the
requirements for class membership: a positive material carrier, same-equation
participation, and positive-scale field coherence. Failure of the first required
requirement gives a class exit,
\[
  \Exit(Q;\mathfrak O_{\NS}^{\mathrm{work}})=
  \neg\Member(Q;\mathfrak O_{\NS}^{\mathrm{work}}),
\]
and the object cannot serve as an in-class nonsmooth terminal continuation of the
same solution.

The manuscript is organized by branch family. Each branch states its
positive-forward aim, carries out the relevant calculation, identifies the
stopping obstruction, records the survivor object, and then re-reads that object
through the class-membership exit test. The periodic zero-force problem on
\(\mathbb T^3\) is the first concrete domain treated here. Whole-space
\(\mathbb R^3\) export is tracked as its own branch and scope boundary.

\section{Scope And Proof Polarity}
\label{sec:scope-proof-polarity}

The Navier--Stokes global regularity problem asks whether a smooth
divergence-free datum can generate a finite-time loss of smoothness under the
three-dimensional incompressible Navier--Stokes evolution. The ordinary standard
for solving the problem is a positive-forward proof. Such a proof gives estimates
that remain on the original solution and propagate enough regularity to continue
the classical flow beyond any proposed terminal time.

The present manuscript follows a different proof polarity. It begins with the
same positive-forward attempts because those attempts identify the actual objects
that threaten continuation. When a branch stops, the stopping point is not treated
as a vague failure of technique. It is treated as a terminal object with a precise
job: if it is to witness finite-time breakdown, it must still be a same-solution
Navier--Stokes object.

This is the role of the class-membership exit method. A proposed terminal object
is tested for the requirements needed to remain in the working Navier--Stokes
class. If the object keeps those requirements, it belongs to the continuation side of
the branch. If it loses one of them, it exits the class and cannot serve as the
same finite nonsmooth terminal witness.

The proof is branch-organized. The four-body route appears first only
as a diagnostic example of the positive-forward obstruction pattern. It is not
the governing route of the proof. The governing route is the CM-exit
contrapositive method applied to the terminal objects produced by the branch
families.

The concrete domain treated first is the periodic zero-force case on
\(\mathbb T^3\). Branches involving whole-space \(\mathbb R^3\),
localization, or tightness are tracked explicitly as export and scope material.
No branch-local statement is promoted to a whole-space Clay-facing conclusion
without its own export argument.
