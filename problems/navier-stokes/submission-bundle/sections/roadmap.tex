\section{Proof Roadmap}

The proof opens with the CM contrapositive class-exit chain. An alleged finite
Clay terminal witness is admitted to the same-fluid terminal packet test, the
first lost Pack/Part/Field requirement is derived, and that face failure is read as
\[
  \Exit(Q;\Owork):=\neg\Member(Q;\Owork).
\]

First, the terminal object is fixed as the same original Navier--Stokes branch:
same datum, same equation, same pressure-viscosity law, same preterminal smooth
solution, and one witness record.

Second, the object enters the CM terminal packet tree. A lawful member branch
keeps the three continuation requirements
\[
  \Pack_Q,\qquad \Part_{N,Q},\qquad \Field_{N,r,Q},
\]
and reads out to smooth continuation through the usual \(H^s\), \(s>5/2\),
criterion.

Third, a finite nonsmooth terminal branch is exhausted in Pack-first order:
\[
  \neg\Pack_Q,\qquad
  \neg\Part_{N,Q},\qquad
  \forall r>0\,\neg\Field_{N,r,Q}.
\]

Fourth, the no-third-branch law excludes a branch that is both an in-class
continuation packet and the same finite nonsmooth terminal witness.

The active manuscript proves this roadmap on the periodic zero-force surface
\(\mathbb T^3\), where the transported whole-torus material atlas supplies the
selected terminal packet, and on the whole-space surface \(\mathbb R^3\), where
the exterior Duhamel source is first separated into harmless initial tail,
harmless compact-core far-kernel contribution, and the genuinely exterior
nonlinear source. The direct positive exterior \(H^s\) tail estimate is a
stronger export theorem. The CM route also treats the survivor branch: bounded
exterior frequencies vanish under exterior \(L^2\) tightness, and any surviving
dyadic exterior source fails Pack, Part, or every fixed positive Field scale.
Source-reserve, signed-pair, no-free-sink, no-pulse, endpoint, local-critical,
and comparison material enters the proof only by landing on the same witness
record as Pack, Part, Field, or continuation readout.
