# Defect-Reduction Tower And Four-Body Recurrence Note

## Purpose

This note records the strongest current synthesis of the failed Euclidean
repair routes.

The point is not merely that the routes "all fail." The stronger claim is that
they appear to apply different normal-form reductions to the same survivor
class. The four-body architecture should therefore be read not only as a
regularity circuit, but also as the current refinement pipeline for that same
defect.

## Main claim

The failed routes are not leaving unrelated burdens behind. They repeatedly
produce lower-codimension readouts of the same one-sided accumulated-scale
obstruction.

The common starting class is

```math
\mathcal E^{(0)}
:=
\text{one-sided scale-memory / accumulated lower-prefix transport-stress against the active shell.}
```

What changes from route to route is not the underlying obstruction class, but
the normal form in which its survivor is exposed.

This note should now be read as a **pre-terminal structural synthesis**.
The stricter terminal comparison, after pushing each route to the first exact
survivor no longer reduced by the current theorem stack, is recorded separately
in
[two-family-terminal-impasse-note.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/two-family-terminal-impasse-note.md).
That later comparison shows two terminal survivor families rather than one
already-proved common terminal class.

## Common reduction pattern

Each route performs some version of the same four moves:

1. remove strict low-mode or same-scale pieces;
2. isolate finite-band spill / collar / edge packets;
3. convert the remaining lifted or cumulative object into a one-sided carrier;
4. pass to a positive, weighted, or quotient readout of the surviving part.

Schematically,

```math
\mathcal E^{(n+1)} = \mathcal R(\mathcal E^{(n)}),
```

where `\mathcal R` is not yet a proved operator, but the notes consistently
show that it lowers descriptive complexity without yet proving quantitative
contraction.

## Evidence from the current route stack

### 1. Shell square-factor payment route

In
[dyadic-shell-gain-lemma.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/dyadic-shell-gain-lemma.md),
the shell commutator splits into a local block and a tail block. The local
block is discharged, while the surviving tail asks for the residual square-factor
payment needed to make the shell kernel summable.

So this route already has the form

```math
\text{full shell obstruction}
\;\rightsquigarrow\;
\text{tail survivor}
\;\rightsquigarrow\;
\text{unpaid square-factor request.}
```

### 2. Cumulative-tail stress route

In
[far-corona-cumulative-tail-stress-theorem.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/far-corona-cumulative-tail-stress-theorem.md),
the continuum far-corona attack reduces the direct object to `(CTS)`, and the
first inherited Euclidean collapse turns `(CTS)` into `(LPAS)` in
[lower-prefix-active-square-theorem.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/lower-prefix-active-square-theorem.md):

```math
\mathcal P_j^\downarrow(t)\,2^{-j}D_j(t)^2.
```

That is the same obstruction after one more positive collapse:

```math
\text{continuum one-sided cumulative tail}
\;\rightsquigarrow\;
\text{dyadic lower-prefix active-square.}
```

### 3. Signed descent route

In
[signed-lifted-band-scale-descent-identity.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/signed-lifted-band-scale-descent-identity.md),
the signed lifted commutator is first rewritten as logarithmic scale descent,
then telescoped, and only afterwards pushed to a positive residual majorant.

After collar-class reduction, the bulk lifted band is no longer the live
burden. The genuinely new analytic survivors are:

- the upper boundary packet;
- the mesoscopic residual.

So the same obstruction becomes

```math
\text{signed lifted bulk}
\;\rightsquigarrow\;
\text{boundary packet} + \text{mesoscopic residual}.
```

### 4. Volterra and lower-triangular routes

In
[volterra-scale-memory-formalization-note.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/volterra-scale-memory-formalization-note.md)
and

the same one-sided object is reclassified as a Volterra primitive and then as
a weighted lower-triangular operator.

The lower-triangular note shows there is exactly one weighted scale-persistent
quotient mode. The kill audit in
[persistent-weighted-quotient-kill-routes-audit.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/persistent-weighted-quotient-kill-routes-audit.md)
then shows that the true survivor is not the full prefix, but only its affine
quotient:

```math
\text{one-sided prefix}
\;\rightsquigarrow\;
\text{weighted quotient mode}
\;\rightsquigarrow\;
\text{affine moments }(M_0,M_1).
```

### 5. Body 1 lifted-band route

In
[body1-kernelized-lifted-band-integration-audit.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/body1-kernelized-lifted-band-integration-audit.md),
the exact lifted-band packet gains a real spectral-gap kernel `2^{-(j-k)}`, so
the route is not stationary. But the remaining obstruction is the residual
lower-shell weight

```math
2^{3k}\|\Delta_k u\|_2^2
=
2^k \cdot 2^{2k}\|\Delta_k u\|_2^2,
```

which the present Body `1` surface cannot absorb.

So even here the route has the same normal-form shape:

```math
\text{raw lifted packet}
\;\rightsquigarrow\;
\text{kernelized lifted packet}
\;\rightsquigarrow\;
\text{persistent lower-shell defect.}
```

## Same categorical failure

At the structural, pre-terminal level, the common categorical failure is:

```math
\boxed{
\text{each route kills exact/local/collar bulk, but leaves a low-codimension persistent readout of one-sided scale accumulation.}
}
```

Equivalently:

```math
\boxed{
\text{the routes simplify the defect class, but they do not yet prove that the survivor shrinks in the right norm.}
}
```

This is why the routes keep reappearing as:

- half-derivative deficit;
- lower-prefix active-square;
- boundary packet;
- mesoscopic residual;
- weighted quotient mode;
- affine quotient moment;
- residual lower-shell weight.

These are not unrelated obstructions. They are successive readouts of the same
survivor class before the current theorem stack reaches route-local terminal
normal form.

## Consequence for the four-body architecture

The four-body route should not be discarded on this evidence.
It should be re-read as the current defect-reduction loop.

The packet logic from
[four-body-regularity-circuit-and-ontic-extension.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/four-body-regularity-circuit-and-ontic-extension.md)
remains:

```text
S_cl -> Q_cl,
(S_cl, Q_cl) -> C_cl,
C_cl -> G_cl,
G_cl -> S_cl.
```

But the open dynamics inside that packet are now better understood:

- `Body 1` isolates and exports the current scale-side defect carrier;
- `Body 2` stabilizes the bulk layer but does not sharpen shell geometry;
- `Body 3` preserves whatever defect theorem Body `1` already exports, but
  does not create new fine-scale structure;
- `Body 4` reads the exact limit and exposes the current survivor on the
  continuation side.

Then the `4 -> 1` return problem is not accidental route drift.
It is the place where the newly exposed survivor is fed back into a stronger
`Body 1` export theorem on the same geometry.

That is exactly what is recorded in
[lifted-remainder-feedback-into-body1-audit.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/lifted-remainder-feedback-into-body1-audit.md):
the open lifted remainder in `Body 4` and the stronger lifted-remainder theorem
needed in `Body 1` are equivalent reformulations of the same packet-level
burden.

So the live four-body reading is:

```math
\boxed{
\text{each full pass through the circuit exposes the next normal form of the same defect,}
}
```
```math
\boxed{
\text{and the pipeline is refined by feeding that survivor back into the relevant body.}
}
```

## Honest boundary

What the current notes do **not** yet prove is that the induced defect tower
contracts quantitatively.

And, more sharply after the terminal comparison note, they do **not** yet prove
that all routes share one exact terminal survivor class.

The present evidence only supports:

1. repeated structural descent of the same survivor class;
2. repeated reduction to lower-codimension readouts;
3. no proved norm-level contraction yet.

So the real next theorem question is no longer "one more estimate on one
route." At the structural level it is:

```math
\boxed{
\text{does the defect-reduction tower converge, or is it merely a sequence of sharper normal forms of the same persistent mode?}
}
```

At the stricter terminal level, the comparison has sharpened to:

```math
\boxed{
\text{can the two currently visible terminal survivor families be collapsed by the exact bridge obligations `(B1)`--`(B3)`?}
}
```
