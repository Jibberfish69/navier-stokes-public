## Proposition `ECD.A` (common conformal structure is equivalent to normalized chart-defect rigidity)

Fix one retained chart block `\Omega_k\times I_k`, let `m:=\dim\Omega_k=6`, and
write the installed `F.11d` diffusion family as

```math
a_k(\zeta,t)=\nu G_k(\zeta)+a_k^{chart}(\zeta,t),
\tag{ECD.2}
```

with `G_k` positive definite and time-independent. Define the chart defect
matrix

```math
B_k(\zeta,t)
:=
\nu^{-1}G_k(\zeta)^{-1/2}\,a_k^{chart}(\zeta,t)\,G_k(\zeta)^{-1/2},
\tag{ECD.3}
```

so that

```math
a_k(\zeta,t)
=
\nu\,G_k(\zeta)^{1/2}\bigl(I+B_k(\zeta,t)\bigr)G_k(\zeta)^{1/2}.
\tag{ECD.4}
```

Define also the normalized chart-defect tensor

```math
\mathfrak B_k(\zeta,t)
:=
\bigl(\det(I+B_k(\zeta,t))\bigr)^{-1/m}\,
\bigl(I+B_k(\zeta,t)\bigr),
\qquad m=6.
\tag{ECD.5}
```

Then the following are equivalent:

1. the diffusion family `a_k(\cdot,t)` has time-rigid normalized anisotropy;
2. the associated metric family `g_{k,t}` has one common conformal structure;
3. the normalized chart-defect tensor `\mathfrak B_k(\cdot,t)` is independent
   of `t`.

### Proof

By `(ECD.4)`,

```math
\det a_k
=
\nu^m\,(\det G_k)\,\det(I+B_k).
\tag{ECD.6}
```

Hence the normalized anisotropy tensor from the common conformal-structure note
becomes

```math
(\det a_k)^{-1/m}a_k
=
(\det G_k)^{-1/m}\,
G_k^{1/2}\,
\mathfrak B_k\,
G_k^{1/2}.
\tag{ECD.7}
```

Since `G_k` is time-independent, the left-hand side is independent of `t` if and
only if `\mathfrak B_k` is independent of `t`. By the earlier note, that same
left-hand side is exactly the common conformal-structure rigidity object.
So all three statements are equivalent. ∎

## Corollary `ECD.B` (the installed convex wall is one normalized chart-defect theorem)

On the installed `F.11d` route, the first convex-branch burden is now exactly:

```math

\quad\text{for every }t,t'\in I_k

\tag{ECD.8}
```

Equivalently,

```math
\boxed{
\bigl(\det(I+B_k)\bigr)^{-1/6}(I+B_k)

\tag{ECD.9}
```

Once `(ECD.8)` holds, the common conformal-structure wall is closed. What
remains after that is the stronger scalar-flattening step needed to reach the
exact constant-diffusion packet `(F.11g2)`.
