# Exported Remainder Active-Shell Absorption Result

## Target

The exported remainder term has the form

```math
C_\varepsilon\Phi_s(\mathcal E_D^{(s)}(X)).
```

To absorb it into the viscous shell scale one needs

```math
C_\varepsilon\Phi_s(\mathcal E_D^{(s)}(X))\ll \nu2^{2j}.
```

## Theorem

If `\Phi_s(\mathcal E_D^{(s)}(X(t)))<\infty`, then the exported remainder is absorbable on every shell satisfying

```math
2^{2j}\ge K\nu^{-1}C_\varepsilon\Phi_s(\mathcal E_D^{(s)}(X(t))).
```

Equivalently, above the active carrier threshold

```math
j\ge J_{rem}(t):={1\over2}\log_2\left(K\nu^{-1}C_\varepsilon\Phi_s(\mathcal E_D^{(s)}(X(t)))\right),
```

one has

```math
C_\varepsilon\Phi_s(\mathcal E_D^{(s)}(X(t)))
\le \eta\nu2^{2j}.
```

## Proof

Choose `K>=eta^{-1}` in the displayed threshold definition and rearrange.

## Consequence

The carrier export route supplies a high active-shell theorem. To convert it into an all-shell theorem up to an endpoint, the route must also control the finite region below `J_{rem}(t)` or prove a uniform bound on `\Phi_s(\mathcal E_D^{(s)})` that makes the threshold globally fixed.

## Boundary

This does not create unconditional all-shell absorption. It is the correct active-shell form of exported remainder absorption.
