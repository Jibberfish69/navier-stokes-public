# Far-Corona To Tail-Square Reserve Result

## Target

The desired implication was

```math
FC\Longrightarrow
\int_0^T2^{-2N}E_N(t)^2dt
\le
\varepsilon\nu\int_0^TD_N(t)dt+C2^{-2\delta N}.
```

This tail-square reserve would close the threshold-collar product because

```math
\Theta_N^\sharp E_N
\le
\varepsilon\nu D_N+C_{\varepsilon}2^{-2N}E_N^2.
```

## Expansion of the tail square

Write

```math
E_N(t)^2=
\sum_{j,k\ge N}E_j(t)E_k(t).
```

This splits into three regions:

```math
|j-k|\le C
```

near-diagonal/same-scale interactions,

```math
j\\gg k
```

far-corona upper-lower interactions, and

```math
k	supset j
```

the symmetric far-corona side.

The far-corona theorem `FC` controls only the coupled density generated by the middle-far packet. It does not include the entire near-diagonal part of `E_N^2` and it does not automatically include both symmetric all-tail pairings.

## Obstruction

The missing piece is the near-diagonal tail square

```math
\sum_{|j-k|\le C}E_jE_k.
```

This term can be as large as `E_N^2` while carrying no far-corona separation. Therefore the kernel gap `\ell/r` has no leverage on it.

Thus `FC` does not imply the full reserve

```math
2^{-2N}E_N^2.
```

It implies only the far-separated component of a tail-square decomposition.

## Correct sufficient theorem

To build the desired reserve, one needs either:

```math
\int_0^T2^{-2N}\sum_{j,k\ge N}E_jE_kdt
\le
\varepsilon\nu\int_0^TD_Ndt+C2^{-2\delta N},
```

as a standalone tail-square theorem, or the pair of estimates:

```math
\text{near-diagonal tail-square control}
```

plus

```math
FC\text{ for the far-separated part.}
```

The far-corona route supplies only the second part.

## Result

Far-corona closure is useful for the lifted packet, but it does not by itself build the full tail-square reserve required to close `\Theta_N^\sharp E_N`. The next required object is a near-diagonal tail-square theorem or a direct collar-product theorem.
