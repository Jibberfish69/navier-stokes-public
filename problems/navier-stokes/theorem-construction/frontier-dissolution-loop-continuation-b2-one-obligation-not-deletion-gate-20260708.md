## Why B2 cannot be admitted as a net-negative new name

A new name is admissible in the loop only if its birth deletes at least two
existing names. B2 does not currently delete any wall. It is an exact next
calculation that could pay later in either direction:

- if the restoring sign is proved with the required row propagation, it may
  become a reducer for the four surviving aspects;
- if the sign is adverse or indefinite, it is a refutation of that physical
  program rather than a dissolution of the written walls;
- if the computation is blocked by the named kill modes, it returns a sharper
  obstruction, not a deletion.

The present B2 text therefore belongs in the target/method layer. It should
guide the next physical computation, but it cannot be counted as the one
surviving terminal object under the frozen exit condition.
