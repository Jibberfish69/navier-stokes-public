## 1. The positive field-current theorem

Let \(K\Subset\mathbb R^3\times I\) be a fixed Eulerian spacetime window with
interior room for the shifts being tested. Suppose each retained smooth history
has a certificate current
\[
  \mathscr C_j
  =
  (u_j,p_j,\mu_{D1,j}^{\rm sel},\mu_{W8,j},
   Q_j,\mathcal A_j,\mathcal T_j,\mathcal S_j,\mathcal Z_j)
\]
on \(K\), where the coordinates record the selected Door-1 row, W8 payer row,
pressure/VPI graph row, ancestry/transport row, tower row, service/selector row,
and zero-surplus row as distributions or finite Radon measures. Assume:

1. all measure rows have uniform total variation/tightness on compact
   subwindows;
2. all distribution rows have uniform local distribution bounds in a topology
   where the nonlinear graph clauses are closed or legally defect-carried;
3. the terminal window has fixed interior margin for the tested shifts;
4. the zero-surplus and route-out coordinates are closed as nonnegative
   measure/defect rows.

Then the closure of the family \(\{\mathscr C_j\}\) is compact in the product
weak-star/distribution topology after passing to subsequences. Fixed time-shift
pullback is continuous in this topology. For a distribution or measure row
\(T\),
\[
  \langle \tau_h T,\phi\rangle
  =
  \langle T,\phi(\cdot,\cdot-h)\rangle ,
\]
and if \(T_n\to T\), then \(\tau_hT_n\to\tau_hT\) for every fixed \(h\) whose
pullback stays inside the window.

Thus if \(\mathscr C=\lim_n\mathscr C_{j_n}\), then
\[
  \tau_h\mathscr C
  =
  \lim_n\tau_h\mathscr C_{j_n},
\]
and the shifted approximants are still actual shifted certificate currents
whenever the terminal margin is available. The hull is therefore shift-invariant
by ordinary continuity of pullback on spacetime currents.

This avoids the instantaneous-state obstruction. The \(S^1\) counterexample
works because a time-zero state forgets its future germ. A spacetime current
state is already the local history on \(K\); the shifted future is read by
pullback from the same current, not guessed from a point state.

## 2. What this corrects

The prior W9 path-modulus gates proved a sufficient route: a compact state
space plus uniform local BV/equicontinuity for every material-time row gives a
shift-continuous path hull. The field-current view shows that BV path control is
not the only lawful topology. A common spacetime current topology can supply
compactness and shift-continuity by weak-star/distribution compactness and
translation continuity.

So the W9 residue should not be overstated as "prove pointwise material-time BV
for every row." The sharper residue is:
\[
  \text{realize the selected c0-bearing record as one bounded, closed,
  terminal-roomed spacetime certificate current.}
\]
