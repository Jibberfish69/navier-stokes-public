# W8 Does Not Reduce to W7 Plus W9

Frontier opened: W3, W7, W8, W9. Cross-wall failure: W8 is not identified with
W7+W9, because W7 is retained record graph passage/admission and W9 is
material-time certificate path/action closedness, while W8 is the selected-linear
original-data payment row on the order-locked full-packet carrier before
positive readout.

Physical sentence: the same original Navier-Stokes parent packet may have a
closed retained record and a compact certified material-time path, while the
future selected readout still sees an unpaid first-ratio half-tail. Closure can
preserve rows already present; it does not create the parent-weighted
selected-linear bill before the future positive readout spends it.

## Certificate

The attempted deletion would need:

\[
  \text{W7 retained graph passage}
  +
  \text{W9 compact certificate path invariance}
  \Longrightarrow
  \text{WLF.60/ODP.91 selected-linear original-data payment}.
\]

The half-tail model refutes that implication as a certificate. On a single
parent-known retained edge, set

\[
  \nu_\ell=\frac{2^{-\ell}}{\ell+1}.
\]

The raw/square support is finite, and it can be carried as a static legal row
or as a constant material-time certificate path, so W7-style graph closedness
and W9-style shift invariance are vacuous in the model. But the selected
first-ratio read is

\[
  \sum_\ell 2^\ell\nu_\ell
  =
  \sum_\ell \frac{1}{\ell+1}
  =
  \infty .
\]

Thus closure of the record and compactness/invariance of the certificate path
do not imply the selected-linear original-data payment row. To delete W8 into
W7+W9 one would still need a theorem saying that retained graph admission plus
certificate path compactness produces the parent-weighted selected
first-admission pulse measure before positive readout. No checked source states
that theorem.
