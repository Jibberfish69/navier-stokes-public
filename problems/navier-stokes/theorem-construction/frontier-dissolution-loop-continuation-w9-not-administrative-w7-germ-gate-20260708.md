# W9 is not administrative W7-with-germ-preservation

Frontier opened: W3, W7, W8, W9.

Cross-wall failure sentence: W9 is not identified with W7 by renaming W7 as
"W7 with germ preservation", because checked W7 is retained-record graph
passage/admission through a critical limit, while checked W9 is compact
certified material-time path-hull/action plus zero-surplus certificate closure.

The new phrase is not admitted as a frontier name. It has only two readings:

1. If "W7 with germ preservation" means ordinary W7 plus datum/ancestry
   uniqueness on actual histories, then it still lacks certified paths
   \(Z_j:I_j\to X\), a compact shifted hull, continuous fixed material-time
   shifts, terminal-window room, and zero-surplus closed graph data.
2. If it means W7 plus those path-hull/action clauses, then it already contains
   W9's surviving content and is a circular repackaging, not a net-negative
   birth deleting two existing names.

The physical separation is the same-fluid time coordinate. W7 decides whether
the retained pressure source, pressure row, material-frame rows, material-time
rows, and positive VPI record pass through one critical compactness limit or
route out. W9 asks whether the certified retained family has a material-time
path topology on which fixed shifts act continuously while datum, pressure law,
ancestry, cover, tower, service, payer, zero-surplus, and terminal-window rows
remain legally carried.

Attackable certificate: take the certificate-state abstraction with all
pointwise record rows legal and zero payer, but with retained phase paths
\[
  Z_n(t)=e^{int}\in S^1.
\]
Every fixed time has legal row data, and the ordinary W7 graph reading sees no
new pressure/material-frame/VPI row defect. A W8 payer coordinate can be set to
zero. But the shifted family is not compact in \(C_{\rm loc}\) and has no
continuous material-time action on a compactified path hull without adding a
uniform material-time modulus or a canonical path-germ coordinate. That missing
path topology is W9, not administrative residue.

Therefore no wall is deleted. The only honest strict reduction remains the
conditional one already recorded: if W7 row passage is strengthened by a proved
future-determining path-germ/action coordinate, terminal-window room, and
zero-surplus closed graph data, then W9 can be retried as a consumer. Those
extra clauses are exactly the unproved W9 content.
