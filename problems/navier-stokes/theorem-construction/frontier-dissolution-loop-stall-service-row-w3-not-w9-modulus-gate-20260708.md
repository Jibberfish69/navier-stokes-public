# Gate on W3 as the W9 service/readout modulus row

Cross-wall failure sentence: W3 is not identical to the W9 service row, because
W3 is fixed-packet payment-to-cubic-service persistence, while W9's service row
is uniform material/label modulus for active service readouts in the common
certificate path topology.

Physical sentence: the same local strain-production budget can stop a
participating cubic service packet from disappearing without also proving that
the chosen service label, center, bank, scale, time window, and selector move
with one uniform modulus along the certified material-time path.

## Source check

W3 is `CriticalServicePersistenceFromPayment.A`. The critical-service audit
states the direct row as: in a lawful strict atom zero-payment sequence, the
same-field payment must force strong \(L^3\) persistence of the selected
Vieillefosse service, or route the disappearing service to a stopped/pass,
parent-owned, collar/exit, or nonparticipating class. The same file says the
missing Door-1 theorem is the \(H^1\)/strong-\(L^3\) payment input; the
companion Door-1 note proves that input only under admission of the local
same-field strain \(H^1\) response as retained payment, and leaves affine
endpoint Door-2 burdens open.

The W9 service row is sourced differently. The shift-hull file says:

```text
The service row needs a uniform material/label modulus. Failure of the modulus
is moving selector, center, envelope, time, scale, bank, weight, rung, or
profile-admission escape, not silent retained service.
```

The WKB service-modulus source identifies the exact row as
`WKBServiceModulus.A`: active pressure-service readouts \(F_j\) on the admitted
compact WKB phase-label space must be uniformly bounded and equicontinuous in
the selected label metric. Failure is moving service functional escape through
material path/center, envelope/collar/gauge, time window/refresh label,
relative scale/rung, bank coordinate, weight/population assignment, or
profile-level selector topology. That source proves no uniform modulus for
actual Navier-Stokes WKB service readouts.

## Gate result

W3 is a necessary service-amplitude persistence coordinate for the W9 service
row, but it is not the W9 service/readout modulus. It prevents silent loss of
selected cubic service under a zero-payment compactness sequence once the
same-field \(H^1\) bill is admitted. It does not provide a uniform label
modulus for the active service readout on the compact certificate state space,
does not control moving selector/center/bank/scale/time/weight/rung labels, and
does not install the service coordinate as a continuous row in the common
material-time path topology.

The service-row transcription can bank only this conditional piece:

\[
\text{W3 admitted H}^1\text{/strong-}L^3\text{ payment}
\Longrightarrow
\text{no silent loss of the selected cubic service amplitude.}
\]

The missing service-row fact remains:

\[
\text{uniform material/label modulus for the W9 service/readout coordinate}
\]

or a typed paid selector/custody/profile-admission escape for failure of that
modulus.
