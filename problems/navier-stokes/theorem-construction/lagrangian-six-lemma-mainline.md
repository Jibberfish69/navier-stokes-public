## Base surface

Let `X(a,t)` be the flow map, `F:=\nabla_a X`, `A:=F^{-1}`, `G:=AA^\top`,
and

```math
v(a,t):=u(X(a,t),t),
\qquad
q(a,t):=p(X(a,t),t).
\tag{1}
```

The pulled-back equation is

```math
\partial_t v + A^\top \nabla_a q
=
\nu\,\operatorname{div}_a(G\nabla_a v),
\qquad
G=AA^\top.
\tag{2}
```

The geometry evolves by

```math
\partial_t A = -A(\nabla_x u)(X,t),
\qquad
\partial_t G
=
-A\big((\nabla_x u)+(\nabla_x u)^\top\big)(X,t)A^\top.
\tag{3}
```

So the real question is no longer whether explicit transport can be canceled.
It is whether the geometry-driven heat operator in `(2)` can absorb the
deformation commutators generated by differentiating `(2)`.

## Fixed derivative family

For a finite depth `r`, work on the joint family

```math
\mathcal U_r^{Lag}
:=
\Big\{
U_\alpha,\ \partial_a^\beta G
:\ 1\le |\alpha|,|\beta|\le r
\Big\},
\qquad
U_\alpha:=\partial_a^\alpha v.
\tag{4}
```

This is the correct finite family because the top-order commutators already
contain products of the form

```math
(\partial^\beta G)\,\nabla_a(\partial^\gamma v).
\tag{5}
```

So a route that tracks only `U_\alpha` is not closed.

## Lemma 1. Differentiated Lagrangian decomposition

### Target statement

For every multi-index `\alpha` with `1\le |\alpha|\le r`,

```math
\partial_t U_\alpha
+
A^\top\nabla_a Q_\alpha
=
\nu\,\operatorname{div}_a(G\nabla_a U_\alpha)
+
\mathcal C_\alpha^v
+
\mathcal L_\alpha,
\tag{6}
```

where:

- `Q_\alpha:=\partial_a^\alpha q`,
- `\mathcal C_\alpha^v` is the true deformation-commutator packet,
- `\mathcal L_\alpha` collects lower-order exact-divergence and bookkeeping
  terms.

One explicit version is

```math
\mathcal C_\alpha^v
=
-\sum_{0<\beta\le \alpha}\binom{\alpha}{\beta}
(\partial_a^\beta A^\top)\nabla_a Q_{\alpha-\beta}
+
\nu\sum_{0<\beta\le \alpha}\binom{\alpha}{\beta}
\operatorname{div}_a\!\Big((\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\Big).
\tag{7}
```

The differentiated constraint is

```math
\operatorname{div}_a(AU_\alpha)=\mathcal P_\alpha.
\tag{8}
```

### What it buys

This isolates the principal variable-coefficient heat part and identifies the
deformation commutator packet as the only live top-order burden.

## Lemma 4A. Coefficient-commutator absorption

### Target statement

For the viscous coefficient packet

```math
\mathcal C_{\alpha}^{v,\mathrm{visc}}
:=
\nu\sum_{0<\beta\le \alpha}\binom{\alpha}{\beta}
\operatorname{div}_a\!\Big((\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\Big),
\tag{14a}
```

show that

```math
\left|
\sum_{1\le |\alpha|\le r}
\langle \mathcal C_\alpha^{v,\mathrm{visc}},U_\alpha\rangle
\right|
\le
\varepsilon\,\mathcal D_r^{Lag}
+
C_\varepsilon\Big(\mathcal C_{r,\mathrm{top}}^{Lag}+\mathcal K_r^{Lag}\Big),
\tag{14b}
```

where the true top-slot deformation defect is

```math
\mathcal C_{r,\mathrm{top}}^{Lag}
:=
\sum_{1\le |\alpha|\le r}
\|(\partial_a^\alpha G)\nabla_a v\|_{L_a^2}^2.
\tag{14c}
```

The model term is

```math
\left|
\nu\int (\partial_a^\alpha G)\,\nabla_a v:\nabla_a U_\alpha\,da
\right|
\le
\varepsilon \nu \|\nabla_a U_\alpha\|_{L_a^2}^2
+
C_{\varepsilon,\nu}\|\nabla_a v\|_{L^\infty}^2
\|\partial_a^\alpha G\|_{L_a^2}^2.
\tag{15}
```

### Operational reduction

The key point is that the viscous commutator is already linear in
`\nabla_a U_\alpha` after one exact integration by parts:

```math
\Big\langle
\operatorname{div}_a\!\big((\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\big),
U_\alpha
\Big\rangle
=
-
\int
(\partial_a^\beta G)\,\nabla_a U_{\alpha-\beta}:\nabla_a U_\alpha\,da.
\tag{15a}
```

Therefore Young's inequality gives, term by term,

```math
\left|
\Big\langle
\operatorname{div}_a\!\big((\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\big),
U_\alpha
\Big\rangle
\right|
\le
\varepsilon \|\nabla_a U_\alpha\|_{L_a^2}^2
+
C_\varepsilon
\|(\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\|_{L_a^2}^2.
\tag{15b}
```

Summing over `\alpha` and `\beta` reduces Lemma 4A to the precise defect family

```math
\mathcal C_{r,\mathrm{comm}}^{Lag}
:=
\sum_{1\le |\alpha|\le r}\;
\sum_{0<\beta\le \alpha}
\|(\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\|_{L_a^2}^2.
\tag{15c}
```

On the bootstrap window coming from Lemma 3 and the bridge capsule `(13c)`,
all lower-order slots `0<\beta<\alpha` are tame:

```math
\sum_{1\le |\alpha|\le r}\;
\sum_{0<\beta<\alpha}
\|(\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\|_{L_a^2}^2
\le
C_{r,\Lambda_*}\,\mathcal K_r^{Lag},
\tag{15d}
```

because one factor always lies strictly below top order and hence is placed in
`L^\infty_a` by the `H^r_a` algebra window.

So the only genuinely new top-order object is exactly `(14c)`, coming from the
slot `\beta=\alpha`. Equivalently, the honest content of Lemma 4A is now:

```math
\boxed{
\text{all lower-order viscous coefficient commutators are already absorbed;}
}
```

```math
\boxed{
\text{the sole live part is the top-slot deformation ledger }
\mathcal C_{r,\mathrm{top}}^{Lag}.}
\tag{15e}
```

### What it buys

This removes the fake burden “control the whole commutator family somehow.”
The mainline now needs only one theorem-grade top-order estimate:

```math
\mathcal C_{r,\mathrm{top}}^{Lag}
\le C_{Lag}
\mathcal D_r^{Lag}+\mathcal K_r^{Lag},
\tag{15f}
```

because every non-top viscous commutator is already ledger-lower-order.

### Discharge on the current bootstrap surface

Assume `r>\frac52` and that the active bootstrap window carries

```math
\|\nabla_a v\|_{L_a^\infty}\le \Lambda_*,
\qquad
\sum_{1\le |\beta|\le r}\|\partial_a^\beta G\|_{L_a^2}^2
\le C_G
\mathcal K_r^{Lag}.
\tag{15g}
```

Then, for each `1\le |\alpha|\le r`,

```math
\|(\partial_a^\alpha G)\nabla_a v\|_{L_a^2}
\le
\|\nabla_a v\|_{L_a^\infty}\,\|\partial_a^\alpha G\|_{L_a^2},
```

so

```math
\mathcal C_{r,\mathrm{top}}^{Lag}
\le
\|\nabla_a v\|_{L_a^\infty}^2
\sum_{1\le |\alpha|\le r}\|\partial_a^\alpha G\|_{L_a^2}^2
\le
C_{r,\Lambda_*}\,\mathcal K_r^{Lag}.
\tag{15h}
```

Therefore `(15f)` holds, and `(14b)` closes in the theorem-grade form

```math
\left|
\sum_{1\le |\alpha|\le r}
\langle \mathcal C_\alpha^{v,\mathrm{visc}},U_\alpha\rangle
\right|
\le
\varepsilon\,\mathcal D_r^{Lag}
+
C_{\varepsilon,r,\Lambda_*}\,\mathcal K_r^{Lag}.
\tag{15i}
```

So Lemma 4A is no longer a live theorem burden on the current surface.
