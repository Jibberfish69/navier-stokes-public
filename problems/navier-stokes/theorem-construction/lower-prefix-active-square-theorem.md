# Lower-Prefix Active-Square Theorem

## Purpose

This note isolates the exact dyadic theorem generated by the direct attack on
the cumulative-tail stress theorem `(CTS)` from
`far-corona-cumulative-tail-stress-theorem.md`.

If `(CTS)` is not proved directly in its continuum form, the inherited
Euclidean inputs reduce it to one precise new dyadic weighted square object.
This note packages that object as its own theorem target.

So this note answers:

```math
\text{if `(CTS)` does not close directly, what exact theorem remains?}
```

## Definitions

Write

```math
D_j(t):=2^{4j}\|\Delta_j u(t)\|_{L_x^2}^2,
\qquad
E_j(t):=2^{2j}\|\Delta_j u(t)\|_{L_x^2}^2.
```

Fix the separation constant `C_1\ge 1` coming from the far-corona lower bound
`r\ge c_1\ell`. Define the lower-prefix `H^1` energy by

```math
\mathcal P_j^{\downarrow}(t)
:=
\sum_{k\le j-C_1}E_k(t).
\tag{1}
```

This is the exact cumulative lower-frequency `H^1` energy seen by the active
shell `j` in the direct `(CTS)` reduction.

## Theorem target

The exact dyadic theorem generated by the direct inherited Euclidean attack on
`(CTS)` is

```math
\textbf{(LPAS)}
\qquad
\int_0^T
\sum_{j\ge N}
\mathcal P_j^{\downarrow}(t)\,
2^{-j}D_j(t)^2\,dt
\le
\nu\int_0^T D_N(t)\,dt + C_*2^{-2\delta N}.
\tag{LPAS}
```

Read literally, `(LPAS)` says:

```math
\text{lower-prefix }H^1\text{ energy cannot accumulate against the active-shell square}
```

at barrier scale.

## Exact position in the far-corona route

The note
`far-corona-cumulative-tail-stress-theorem.md`
proves that the direct inherited Euclidean attack on `(CTS)` yields

```math
\int_0^T
\sum_{j\ge N}
\mathcal P_j^{\downarrow}(t)\,
2^{-j}D_j(t)^2\,dt
\le
C_{\mathrm{CTS}}\left(\nu\int_0^T D_N(t)\,dt + C_*2^{-2\delta N}\right).
\tag{2}
```

So `(LPAS)` is the exact new dyadic theorem surface produced by that attack.

Consequently, the far-corona route now admits the exact sufficient chain

```math
\text{(LPAS)}
\Longrightarrow
\text{(CTS)}
\Longrightarrow
\text{FCTS}
\Longrightarrow
\text{far-corona Carleson closure}.
\tag{3}
```

The first implication is just the reduction already written in
`far-corona-cumulative-tail-stress-theorem.md`. The second and third
implications come from the direct `L_x^2\times L_x^2` attack recorded in
`far-corona-carleson-direct-attack.md`.

## Why this is genuinely new

`(LPAS)` is not one of the currently installed one-sided square theorems.

1. `SDS^\sharp` controls upper-tail square queues.
2. `UTKD^\sharp` controls upper-tail kernelized dissipation queues.
3. `PCI^\sharp` controls paired upper-tail carriers.

All of those are one-sided **high-tail** objects.

By contrast, `(LPAS)` is a **lower-prefix times active-square** theorem:

```math
\mathcal P_j^{\downarrow}(t)\cdot 2^{-j}D_j(t)^2.
```

So `(LPAS)` is not implied by the currently installed Euclidean queue.

## Bounded self-attempt: why the installed queue does not close `(LPAS)`

There are three immediate reduction attempts, and each fails for a structural
reason.

### 1. Reduction to the upper-tail queue fails by orientation

Using `E_k=2^{-2k}D_k`, one may rewrite

```math
\mathcal P_j^{\downarrow}(t)\,2^{-j}D_j(t)^2
=
\sum_{k\le j-C_1}
2^{-2k-j}D_k(t)D_j(t)^2.
\tag{4}
```

This is a lower-prefix / active-square interaction. The installed queue
`SDS^\sharp`, and the downstream `UTKD^\sharp` / `PCI^\sharp`, control
**upper-tail** objects in which the active index is paired with shells above
it. They do not change the orientation of the interaction and therefore do not
apply to `(4)`.

### 2. Reduction to a same-scale square theorem fails by the unbounded prefix

A crude estimate gives

```math
\mathcal P_j^{\downarrow}(t)\le \sum_{k\in\mathbb Z}E_k(t)=\|\nabla u(t)\|_{L_x^2}^2.
\tag{5}
```

So `(LPAS)` would follow from

```math
\int_0^T
\|\nabla u(t)\|_{L_x^2}^2
\sum_{j\ge N}2^{-j}D_j(t)^2\,dt
\le
C_{\mathrm{LPAS}}\left(\nu\int_0^T D_N(t)\,dt + C_*2^{-2\delta N}\right).
\tag{6}
```

But the inherited Euclidean surface supplies only

```math
\int_0^T \|\nabla u(t)\|_{L_x^2}^2\,dt<\infty,
```

not the `L_t^\infty` or Carleson-type control that would be needed to absorb
the extra factor in `(6)`. So the crude prefix collapse does not close the
theorem.

### 3. Young/Cauchy factorization fails at the active square

One may also try

```math
\mathcal P_j^{\downarrow}(t)\,2^{-j}D_j(t)^2
=
\big(\mathcal P_j^{\downarrow}(t)^{1/2}2^{-j/2}D_j(t)\big)^2.
\tag{7}
```

To use Cauchy or Young one would need a companion theorem controlling either

```math
\sum_j \mathcal P_j^{\downarrow}(t)
```

or

```math
\sum_j 2^{-j}D_j(t)^2
```

at barrier scale, together with a way to keep the product one-sided in time.
No such theorem is currently installed above the Euclidean surface.

### Outcome of the bounded self-attempt

The conservative reductions to:

1. the upper-tail queue,
2. same-scale square control with a crude prefix bound,
3. weighted Young/Cauchy factorization,

all fail without additional theorem input.

So `(LPAS)` is not just unproved; it is genuinely not discharged by the
currently installed Euclidean theorem stack.

What it fixes is the exact next theorem if the continuum cumulative-tail

Carleson placeholder. It lands on one explicit dyadic weighted square object,
namely `(LPAS)`.

So the honest fork is now:

