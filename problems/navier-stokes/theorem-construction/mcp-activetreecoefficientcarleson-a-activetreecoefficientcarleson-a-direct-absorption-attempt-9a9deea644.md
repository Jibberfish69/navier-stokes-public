# ActiveTreeCoefficientCarleson.A direct coefficient-margin attempt

## Status

Failed direct discharge.  The good-coefficient portion of the quartic normal-form remainder contributes only the explicit `\theta` fraction
`\int_{G_\theta}\mathfrak S_N\mathcal A_N\le\theta\int_I\mathcal A_N`.  The bad-coefficient portion requires uniform integrability of the active-square density on terminal coefficient-bad sets.  That uniform integrability is route-equivalent to `ScaleCriticalTreeCarleson.A` / `LocalPositiveSourceCarleson.A`.  Therefore `ActiveTreeCoefficientCarleson.A` does not close the source wall as an independent theorem from `OriginalSmoothData`.

## Target

From the parabolic cubic normal-form attempt, the remaining coefficient-weighted active-square remainder is

```math
\int_I \mathfrak S_N(t)\mathcal A_N(t)\,dt,
\qquad
\mathcal A_N(t):=\sum_{j\ge N}2^{-j}D_j(t)^2.
```

The desired theorem is

```math
\boxed{
\textbf{ActiveTreeCoefficientCarleson.A:}\quad
\int_I \mathfrak S_N(t)\mathcal A_N(t)\,dt
\le
\theta\int_I\mathcal A_N(t)\,dt+o_N(1)+\text{legal losses}.
}
```

Here `\mathfrak S_N(t)` is the terminal active-tree low/intermediate strain/source coefficient left by the quartic normal-form remainder after pressure, cutoff, and off-packet legal losses are routed.

## Step 1. Good-coefficient absorption

Split

```math
I=G_\theta\cup B_\theta,
\qquad
G_\theta:=\{t:\mathfrak S_N(t)\le\theta\},
\qquad
B_\theta:=\{t:\mathfrak S_N(t)>\theta\}.
```

On `G_\theta`,

```math
\int_{G_\theta}\mathfrak S_N(t)\mathcal A_N(t)\,dt
\le
\theta\int_I\mathcal A_N(t)\,dt.
```

This is exactly the good-set payment needed by the corrected Bellman
inequality; it is spendable only as the displayed `\theta` fraction.

## Step 2. Bad-coefficient remainder

The remaining term is

```math
\int_{B_\theta}\mathfrak S_N(t)\mathcal A_N(t)\,dt.
```

A first attempt uses finite preterminal smoothness or an `L^1_t` bound for `\mathfrak S_N`.  This is insufficient.  Separate integrability of `\mathfrak S_N` and first-moment dissipation does not control the product with `\mathcal A_N`.  The active-square density may concentrate on the set where `\mathfrak S_N` is large.

The exact product obstruction is:

```math
\mathfrak S_N\in L^1(I),
\qquad
\int_I\sum_{j\ge N}D_j(t)\,dt=o_N(1)
```

does not imply

```math
\int_{B_\theta}\mathfrak S_N(t)\sum_{j\ge N}2^{-j}D_j(t)^2\,dt=o_N(1).
```

A sequence of shrinking terminal windows can keep the first moment small while keeping the square density concentrated on `B_\theta`.

## Step 3. Uniform-integrability reformulation

The bad part would close if one had

```math
\boxed{
\int_{B_\theta}\mathcal A_N(t)\,dt
\le o_N(1)+\text{legal losses}
}
```

uniformly for every terminal coefficient-bad set generated by `\mathfrak S_N`.  But this is precisely the scale-critical tree Carleson reserve restricted to the bad set.

Equivalently, one needs a source-control theorem preventing active-square density from concentrating where the terminal active-tree coefficient is large.  This is a restatement of the source wall, not a consequence of the coefficient split.

## Step 4. Cauchy/Young fallback

A second attempt writes the coefficient as a product of parent and child packet factors and applies Cauchy/Young.  This returns to

```math
\int_I\sum_{k>N}2^k\left(\sum_{\ell>k+4}D_\ell(t)\right)^2dt,
```

the same active-square / scale-critical tree reserve.  Thus Cauchy/Young does not discharge the bad coefficient set; it changes notation back to `ScaleCriticalTreeCarleson.A`.

## Conclusion

`ActiveTreeCoefficientCarleson.A` reduces to the same source-wall primitive.  It proves the useful decomposition

```math
\int_I\mathfrak S_N\mathcal A_N
=\text{displayed }\theta\text{-good part}+\text{bad-set active-square concentration},
```

but the bad-set active-square concentration is not controlled by `OriginalSmoothData` or by the parabolic cubic normal form.

Therefore the direct implication

```math
OriginalSmoothData\Longrightarrow ActiveTreeCoefficientCarleson.A
```

is not proved by this route.
