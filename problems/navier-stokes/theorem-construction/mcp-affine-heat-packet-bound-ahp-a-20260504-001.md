# Affine heat packet bound `AHP.A`

## Status

Local theorem note for the Navier-Stokes principal-flow adjoint route.

Claimed status: conditional local packet estimate on coefficient-good working segments.

This note proves the packet stability input needed before the Cotlar / `TT^*` Bessel step. It is a supplier theorem for

```math
CoeffStop.A \Rightarrow WeightedAdjBessel.A.
```

## Theorem `AHP.A`

Fix a tile `T` with radius `r_T`, upper time `t_+`, and working interval `I_T`. Let

```math
\dot X_T(t)=b_k(X_T(t),t),
\qquad
\dot J_T(t)=(\nabla b_k)(X_T(t),t)J_T(t),
\qquad
J_T(t_+)=I,
```

and set

```math
y=J_T(t)^{-1}(x-X_T(t)).
```

Assume the working segment is parabolic:

```math
0\le t_+-t\le \Lambda r_T^2.
```

Assume uniform affine ellipticity:

```math
\|J_T(t)\|+\|J_T(t)^{-1}\|\le \Lambda_J,
\qquad
\lambda I\le B_T(t)\le \Lambda I.
```

Assume the terminal packet satisfies, for every `|\alpha|\le N+2`,

```math
|\partial_y^\alpha \varphi_T(t_+,y)|
\le C_\alpha r_T^{-3/2-|\alpha|}
\exp(-c_0|y|^2/r_T^2).
```

On a coefficient-good tile the pulled-back gauged packet equation is

```math
\bigl(-\partial_t-\nu\nabla_y\cdot(B_T(t)\nabla_y)\bigr)\varphi_T
=
\mathcal E_T(t)\varphi_T,
```

with coefficient density `\beta_T\in L^1(I_T)` satisfying

```math
\int_{I_T}\beta_T(t)\,dt\le C\varepsilon_M.
```

The density is generated by the affine-flow and strain remainders

```math
r_T^2\|\nabla^2 b_k(t)\|_{L^\infty(Q_T^*)}
+r_T\|\nabla A_k(t)\|_{L^\infty(Q_T^*)}
```

and by localization commutators bounded by `C_M2^{-cM}`. In packet norms, it gives

```math
\|H_T(t,s)\mathcal E_T(s)u(s)\|_{\mathcal P_N(t)}
\le C\beta_T(s)\|u(s)\|_{\mathcal P_N(s)}.
```

Then, for every `|\alpha|\le N`,

```math
|\partial_y^\alpha \varphi_T(t,y)|
\le C_\alpha r_T^{-3/2-|\alpha|}
\exp(-c|y|^2/r_T^2).
```

Consequently, in the physical variables,

```math
|\partial_x^\alpha \varphi_T(t,x)|
\le C_\alpha r_T^{-3/2-|\alpha|}
\exp\left(-c|x-X_T(t)|^2/r_T^2\right).
```

The constants depend on `\alpha,N,\nu,\lambda,\Lambda,\Lambda_J,\Lambda` and the terminal packet constants, and they are uniform in `T` once `M` is large enough.

## Proof

### 1. Affine heat kernel

For `t\le s\le t_+`, define

```math
A_T(t,s)=\int_t^s B_T(\tau)\,d\tau.
```

Since `B_T` is spatially constant and uniformly elliptic, the propagator for

```math
-\partial_t u-\nu\nabla_y\cdot(B_T(t)\nabla_y u)=0
```

has kernel

```math
K_T(t,s;y,z)
=
\frac{1}{(4\pi\nu)^{3/2}\det(A_T(t,s))^{1/2}}
\exp\left[-\frac{(y-z)^TA_T(t,s)^{-1}(y-z)}{4\nu}\right].
```

The ellipticity bounds imply

```math
|\partial_y^\alpha K_T(t,s;y,z)|
\le C_\alpha (s-t)^{-(3+|\alpha|)/2}
\exp\left(-c\frac{|y-z|^2}{s-t}\right)
```

for `t<s`, with the standard limiting interpretation at `t=s`.

Because `s-t\le \Lambda r_T^2`, convolution with a scale-`r_T` terminal Gaussian preserves the scale. Thus

```math
|\partial_y^\alpha H_T(t,t_+)\varphi_T(t_+)(y)|
\le C_\alpha r_T^{-3/2-|\alpha|}
\exp(-c|y|^2/r_T^2).
```

### 2. Packet norm

Fix `a>0` smaller than the kernel exponent and define

```math
\|u(t)\|_{\mathcal P_N(t)}
=
\max_{|\alpha|\le N}
\sup_y r_T^{3/2+|\alpha|}
\exp(a|y|^2/r_T^2)|\partial_y^\alpha u(t,y)|.
```

The previous kernel estimate gives

```math
\|H_T(t,t_+)\varphi_T(t_+)\|_{\mathcal P_N(t)}\le C_0.
```

The coefficient-good structure gives

```math
\|H_T(t,s)\mathcal E_T(s)u(s)\|_{\mathcal P_N(t)}
\le C\beta_T(s)\|u(s)\|_{\mathcal P_N(s)}.
```

This follows term by term. The affine drift remainder obeys

```math
|b_k(X_T+J_Ty,t)-b_k(X_T,t)-\nabla b_k(X_T,t)J_Ty|
\le C r_T^2\|\nabla^2 b_k(t)\|_{L^\infty(Q_T^*)}
```

on the heat tube. The strain remainder obeys

```math
|A_k(X_T+J_Ty,t)-A_k(X_T,t)|
\le C r_T\|\nabla A_k(t)\|_{L^\infty(Q_T^*)}.
```

After the scaling `y=r_T z`, each first-order, zero-order, and cutoff-commutator term contributes at most `C\beta_T(t)` to the packet norm after applying the affine heat kernel. The Gaussian weight absorbs the polynomial factors generated by derivatives and commutators.

### 3. Duhamel closure

Duhamel gives

```math
\varphi_T(t)=H_T(t,t_+)\varphi_T(t_+)
+\int_t^{t_+}H_T(t,s)\mathcal E_T(s)\varphi_T(s)\,ds.
```

Let

```math
P(t)=\sup_{\tau\in[t,t_+]}
\|\varphi_T(\tau)\|_{\mathcal P_N(\tau)}.
```

Then

```math
P(t)
\le C_0+C\int_t^{t_+}\beta_T(s)P(s)\,ds.
```

Backward Gronwall yields

```math
P(t)
\le C_0\exp\left(C\int_t^{t_+}\beta_T(s)\,ds\right)
\le C_0e^{C\varepsilon_M}.
```

For `M` large enough this is bounded by a uniform constant. Expanding the definition of `\mathcal P_N` gives

```math
|\partial_y^\alpha\varphi_T(t,y)|
\le C_\alpha r_T^{-3/2-|\alpha|}\exp(-c|y|^2/r_T^2).
```

### 4. Conversion to physical variables

Since `y=J_T^{-1}(x-X_T)`, every `\partial_x^\alpha` is a finite linear combination of `\partial_y^\beta` with `|\beta|=|\alpha|` and coefficients bounded by powers of `\|J_T^{-1}\|`. Uniform ellipticity gives

```math
|J_T^{-1}(x-X_T)|\ge c|x-X_T|.
```

Therefore

```math
|\partial_x^\alpha\varphi_T(t,x)|
\le C_\alpha r_T^{-3/2-|\alpha|}
\exp\left(-c|x-X_T(t)|^2/r_T^2\right).
```

This is the desired affine heat packet bound.

## Boundary of the result

The `L_t^1(H^1\to H^{-1})` estimate supplies the energy form of the perturbative argument. The pointwise Gaussian estimate also uses the fact that `\mathcal E_T` is the coefficient-good affine-flow and strain remainder. An arbitrary operator with the same abstract `H^1\to H^{-1}` size can fail to preserve the Gaussian packet class.

If the affine frame has unbounded aspect ratio, the proved packet estimate remains valid in affine distance,

```math
\exp(-c|J_T^{-1}(x-X_T(t))|^2/r_T^2),
```

and the isotropic physical-space bound requires the stated uniform affine ellipticity.

## Downstream use

For the normalized adjoint packet

```math
\chi_T=g_T^{-1}\psi_T=g_T^{-1}G_T\varphi_T,
```

the strain-gain normalization gives `\|g_T^{-1}G_T\|\le C`. Hence `\chi_T` inherits the same packet bounds on coefficient-good tiles. This is the packet-stability input for the overlap decay and Cotlar proof of `WeightedAdjBessel.A`.
