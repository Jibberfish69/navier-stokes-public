# BootSquare Weight Higher-Moment Source Boundary

## Status

Failed as an unconditional source proof.

The desired actual source estimate is one of:

```math
M_J^2\le C
```

on the retained family, or, for some `delta>0`,

```math
\sup_J\int (M_J^2)^{1+\delta}d\mu_J\le C_\delta.
```

Either estimate would give uniform integrability of `M_J^2` and hence the weighted bad-set mass collapse once the unweighted bad-set collapse is available.

The current persisted surfaces prove the implication:

```text
higher moment / bounded weight => uniform integrability => weighted mass collapse.
```

They do not prove the actual analytic bound on `M_J^2` itself.

## Source theorem still needed

```text
prove pointwise boundedness of M_J^2 on the retained family,
or prove a uniform higher-moment estimate for M_J^2.
```
