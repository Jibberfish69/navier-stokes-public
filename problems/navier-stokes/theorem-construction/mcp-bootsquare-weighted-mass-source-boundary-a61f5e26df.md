# BootSquare Weighted Mass Source Boundary

## Status

Failed as an unconditional proof from support alone.

## Setup

Let

```math
\beta_J:=\Lambda_J^{boot}\eta_J^{boot},
\qquad d\nu_J:=M_J^2d\mu_J.
```

Choose a measurable support carrier `B_J` so that

```math
supp\,\beta_J\subset B_J.
```

## Target

The weighted mass target is

```math
\nu_J(B_J)\to0.
```

## Boundary

Support localization alone does not imply weighted mass collapse. The support carrier could be the full retained family. Also, unweighted smallness of `B_J` is insufficient if the weight `M_J^2` concentrates on `B_J`.

Thus the source theorem is exactly:

```text
beta_J is supported on a weighted bad set B_J with nu_J(B_J)->0.
```
