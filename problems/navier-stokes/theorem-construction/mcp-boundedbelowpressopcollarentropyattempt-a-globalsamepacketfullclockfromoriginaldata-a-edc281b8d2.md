# BoundedBelowPressOpCollarEntropyAttempt.A

Status: failed as an unconditional construction; reduced to an exact necessary birth-reserve/packing theorem.

## Target

Build a same-material entropy

```math
\widetilde{\mathscr A}_N^{press/op+collar}
```

such that

```math
\widetilde{\mathscr A}_N^{press/op+collar}(t)
\ge -C_N(u_0)
```

and

```math
d\widetilde{\mathscr A}_N^{press/op+collar}
+c_N\left(d\Omega_N^{press/RHS}+d\Omega_N^{collar}\right)
\le dR_N^{legal}.
\tag{PCE.1}
```

The natural pressure/collar record is

```math
E_{pc,N}:=E_{p,N}+E_{coll,N}.
```

The direct pressure/operator and collar identities give, after wrong-sign recirculation has been removed,

```math
d(-E_{pc,N})+c_N d\Omega_N^{press/collar}
\le dR_N^{legal}
```

but \(-E_{pc,N}\) is bounded below only when the continuation-depth pressure/collar record is already bounded.

## 1. Scalar transform no-go

Try

```math
\widetilde{\mathscr A}_N=-\Phi(E_{pc,N})
```

with \(\Phi\) increasing.  To keep a lower bound, \(\Phi\) must be bounded above, or at least sublinear enough that \(-\Phi(E)\ge -C_N(u_0)\) along arbitrary possible record growth.

But the derivative is

```math
d\widetilde{\mathscr A}_N=-\Phi'(E_{pc,N})\,dE_{pc,N}.
```

To pay the full positive pressure/collar growth with a uniform constant, one needs

```math
\Phi'(E)\ge c_N>0
```

on the growth range.  Then

```math
\Phi(E)\ge c_NE-C,
```

so \(-\Phi(E)\) is unbounded below as \(E\to\infty\).  Therefore no scalar bounded-below monotone transform can keep the full toll of \(-E_{pc,N}\).

Saturating transforms such as \(E/(1+E)\), \(\arctan E\), or truncated dyadic barriers are bounded below after negation, but their derivatives vanish or truncate at high record.  They pay only a weakened growth measure, not \(d\Omega_N^{press/collar}\).

## 2. Cross-storage test

Try

```math
\widetilde{\mathscr A}_N=-E_{pc,N}+X_N.
```

To be bounded below without already knowing \(E_{pc,N}\le C\), the correction must satisfy

```math
X_N(t)\ge E_{pc,N}(t)-C_N(u_0).
\tag{PCE.2}
```

But differentiating such a correction necessarily returns the same pressure/operator and higher-collar growth, unless \(X_N\) is an independent finite birth reserve.  If \(dX_N\) contains the live growth, the sign of \(-E_{pc,N}\) is cancelled or the live clock is moved into the residual.  If \(dX_N\) does not contain the live growth, `(PCE.2)` is exactly a nontrivial domination theorem.

Thus a cross-storage closes only if there exists an independent finite native reserve \(\mathcal R_N^{pc}\) such that

```math
\mathcal R_N^{pc}(t)\ge E_{pc,N}(t)-C_N(u_0)
```

while its consumption is charged by legal/birth terms.  That is not installed by the current inputs.

## 3. Necessary noncircular replacement

The only possible noncircular replacement has the form

```math
\widetilde{\mathscr A}_N^{press/op+collar}
=
\mathcal B_N^{pc,birth}
-
E_{pc,N},
\tag{PCE.3}
```

where \(\mathcal B_N^{pc,birth}\) is a finite same-material birth-capacity ledger satisfying

```math
\mathcal B_N^{pc,birth}(0)\le C_N(u_0),
\qquad
\mathcal B_N^{pc,birth}(t)-E_{pc,N}(t)\ge -C_N(u_0),
\tag{PCE.4}
```

and

```math
d\mathcal B_N^{pc,birth}\le dR_N^{legal}
```

after subtracting the actual birth charges already included in the left-hand pressure/collar clock.

Equivalently, one must prove the native birth-packing theorem:

```math
\sum_{\gamma\in\Gamma_N^{press/collar}}\omega_\gamma
\le
C\sum_{\rho\in\mathcal R_N^{pc}(u_0)}\rho
+
\int_0^{T^*}dR_N^{legal},
\qquad
\sum_{\rho\in\mathcal R_N^{pc}(u_0)}\rho\le C_N(u_0).
\tag{PCE.5}
```

Here \(\Gamma_N^{press/collar}\) is the family of one-way pressure/RHS and higher-collar growth births, and \(\mathcal R_N^{pc}(u_0)\) is a finite native reserve generated by the original smooth material packet.

## Verdict

The requested entropy cannot be built from a bounded transform of \(-E_p-E_{coll,N}\) while keeping the full derivative sign.  A bounded-below entropy with the full pressure/collar toll is equivalent to an independent finite birth-reserve/packing theorem for one-way pressure/RHS and higher-collar growth.

Thus the exact remaining theorem is:

```math
\boxed{
\text{prove the native birth-packing estimate `(PCE.5)` for one-way pressure/operator and higher-collar growth.}
}
```

If `(PCE.5)` is proved, `(PCE.3)` gives the desired bounded-below entropy and `(PCE.1)` follows.  Without `(PCE.5)`, the construction is circular.
