## 1. Actual center material projection

Let `u,p` be the original smooth incompressible Navier-Stokes solution on `[0,T*)`, let `X(a,t)` be the material flow, and let `C_0` be the selected center material set with a fixed positive-thickness material collar `A_0`. Choose a smooth material cutoff `psi_C(a)` satisfying `psi_C=1` on the center, `psi_C=0` outside `C_0 union A_0`, and `supp nabla_a psi_C subset A_0`. Its Eulerian representative is

```math
\phi_C(X(a,t),t)=\psi_C(a),
\qquad
(\partial_t+u\cdot\nabla)\phi_C=0.
```

The actual center material projection is

```math
M_C(t)=\int \frac12 |u(x,t)|^2\phi_C(x,t)\,dx.
```

The center endpoint measure is the terminal weak-* defect of the positive projected center-growth measure after the native dissipative term is included:

```math
d\mu_{C}^{(n)}(t)
=
\left[{d\over dt}M_C^{(n)}(t)
+2\nu\int\phi_C^{(n)}|S^{(n)}|^2\,dx\right]_+dt.
```

Equivalently, since the smooth identity below holds exactly, this is the positive part of the same annular traction-work measure. This definition uses the actual transported center projection, rather than an abstract packet measure.

## 2. Smooth prelimit identity

With

```math
S={\nabla u+\nabla u^T\over2},
\qquad
T=-pI+2\nu S,
```

the momentum equation is `D_t u = div T`. Since `div u=0`,

```math
D_t \frac12|u|^2 = \nabla\cdot(Tu)-T:\nabla u
=\nabla\cdot(Tu)-2\nu|S|^2.
```

Multiplying by the transported cutoff and integrating gives

```math
{d\over dt}M_C(t)+2\nu\int\phi_C|S|^2\,dx
=-\int u\cdot T\nabla\phi_C\,dx.
```

Because `nabla phi_C` is supported on the transported material annulus `A(t)=X(A_0,t)`, the right side is a same-fluid annular stress transaction.

Define

```math
F_A(t):=-\int u\cdot T\nabla\phi_C\,dx,
\qquad
\rho_A(t):=|F_A(t)|
```

or, for the full rectified carrier used in the repo,

```math
\rho_A(t):=
|F_A(t)|+2\nu\int_{A(t)}|S|^2\,dx+\Xi_{N,\psi_C}(t),
```

where `Xi_{N,psi_C}` is the same-packet material flux-variation/service density from the annular flux derivative identity.

The smooth domination is therefore pointwise as measures:

```math
d\mu_C^{(n)}(t)\le \rho_A^{(n)}(t)\,dt.
```

Passing to the terminal limit preserves domination against nonnegative continuous test functions. Hence for every endpoint window, allowing the usual selector/collar synchronization enlargement,

```math
\mu_{center}((T^*-\theta,T^*])
\le
C\int_{T^*-\Theta(\theta)}^{T^*}\rho_A(t)\,dt,
\qquad
\Theta(\theta)\downarrow0.
```

For a strictly transported fixed cutoff, one may take `Theta(theta)=theta`. Extra `Theta` only records endpoint synchronization or collar-selection modulus.

## 3. Terminal tail for the same carrier

If the carrier is a fixed positive-thickness smooth material annulus and

```math
\rho_A\in L^1(0,T^*),
```

then absolute continuity of the Lebesgue integral gives

```math
\lim_{\theta\downarrow0}
\int_{T^*-\Theta(\theta)}^{T^*}\rho_A(t)\,dt=0.
```

Combining with the previous domination gives

```math
\mu_{center}((T^*-\theta,T^*])\to0.
```

Thus the center endpoint measure has zero terminal atom whenever the same annular carrier is genuinely L1.
