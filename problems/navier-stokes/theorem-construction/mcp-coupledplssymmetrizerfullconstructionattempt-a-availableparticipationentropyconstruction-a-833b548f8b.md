# Coupled PLS symmetrizer full construction attempt

Status: failed as a final closed construction.  This note is a construction attempt, not a refusal.  It tests the natural ways to build the bounded-below same-material PLS symmetrizer and identifies the exact noncircular obstruction.

## Target

Construct \(H_N=I+K_N\) and

```math
\mathscr A_N(t)=\langle H_N(t)Y_N(t),Y_N(t)\rangle_{PLS}
```

so that

```math
\mathscr A_N(t)\ge -C_N(u_0),
\qquad
 d\mathscr A_N+c_N\,d\Omega_N^{PLS}\le dR_N^{legal},
\qquad
\int_0^{T^*}dR_N^{legal}<\infty .
```

Here \(Y_N\) is the full same-material PLS state: velocity tower, pressure/incompressibility tower, material coefficient/metric tower, Helmholtz--Leray/Stokes tower, transported collar tower, annular Cauchy stress-work carrier, strain tower, and viscous/tower loss coordinates.

## 1. What the material law gives

The transported material equations give one same-packet system:

```math
\partial_t v+A^T\nabla_a q=
u\operatorname{div}_a(G\nabla_a v),
\qquad
\operatorname{div}_a(Av)=0,
```

```math
\partial_tA=-A(\nabla_a v)A,
\qquad
G=AA^T,
\qquad
\partial_tG=(\partial_tA)A^T+A(\partial_tA)^T.
```

Top-order pressure cancels against \(\operatorname{div}_a(Av)=0\).  The material Helmholtz--Leray/Stokes projector records the remaining pressure constraint.  The collar current is generated by \(\nabla_x\phi=A^T\nabla_a\psi\).  The annular Cauchy stress-work identity is

```math
{d\over dt}M_\phi+2\nu\int\phi|S|^2dx
=-\int u\cdot(-pI+2\nu S)\nabla\phi\,dx.
```

So the variables do form one PLS transaction.  The issue is coercivity of the rectified/unsigned clock, not attachment.

## 2. Algebraic instantaneous symmetrizer attempt

Try \(K_N=K_N(Y_N,A,G,\phi)\) as an instantaneous bounded self-adjoint cross-operator with

```math
|\langle K_NY_N,Y_N\rangle|\le\theta\langle Y_N,Y_N\rangle+C_N(u_0),\qquad 0<\theta<1.
```

Then lower boundedness is immediate:

```math
\mathscr A_N\ge(1-\theta)\langle Y_N,Y_N\rangle-C_N(u_0).
```

Differentiation gives the required operator inequality

```math
\dot H_N+H_N\mathcal L_N^{PLS}+(\mathcal L_N^{PLS})^*H_N
\le -c_N\mathcal Q_N^{PLS}+Legal.
```

The direct smooth-packet calculation only gives

```math
|\mathcal I_N|\le \varepsilon dD_N^{vis}+C_\varepsilon\Theta_N\mathscr A_{org,N}dt+dR_N^{legal}.
```

Thus the instantaneous \(K_N\) must convert the factor

```math
\Theta_N\mathscr A_{org,N}dt
```

into a negative drop.  No installed algebraic identity supplies that sign.  At this stage the term is visible but not coercive.

## 3. Pressure/Helmholtz--Leray Schur-complement attempt

Use the material constraint \(\operatorname{div}_a(Av)=0\) and eliminate pressure through the material Stokes/Helmholtz--Leray projector.  This gives the correct projected velocity equation and removes top-order pressure overcount.  It does not produce a positive clock: the projector derivative

```math
\partial_t\mathbb P_A
```

is generated by \(\partial_tA=-A(\nabla_a v)A\), hence returns to the same material strain/coefficient service.  The Schur complement changes coordinates; it does not change the sign of the remaining rectified PLS variation.

Verdict: correct symmetrization of the constraint, no full-clock coercivity.

## 4. Annular stress-work cross-storage attempt

Use \(M_\phi\), \(F_\phi=\int u\cdot T\nabla\phi\), or a pressure-time corrected annular flux as \(X_{PLS,N}\).  The exact identity gives net stress-work:

```math
\int_a^bF_\phi(t)dt=M_\phi(a)-M_\phi(b)-\int_a^bD_\phi(t)dt.
```

The clock requires positive rectified action:

```math
\int_a^b(D_\phi+|F_\phi|)dt.
```

Adding \(F_\phi\) to the storage differentiates into the full spatial pressure-stress-velocity density, but it has no universal sign.  Adding \(|F_\phi|\) destroys smooth signed cancellation and still differentiates into \(\operatorname{sgn}(F_\phi)F_\phi'\), not a coercive bound for \(|F_\phi|\).  Defining the storage as a future tail \(\int_t^{T^*}|F_\phi|\) is circular.

Verdict: annular stress-work is the native carrier, not a self-coercive producer.

## 5. Material metric / strain storage attempt

Use singular values of \(D_aX\), \(A\), or \(G\), e.g. a log metric anisotropy.  Incompressibility fixes \(\det D_aX=1\), so positive stretch is paired with compression.  A storage decreasing at a fixed rate for every positive stretch direction must behave like a negative accumulated stretch history.  If unsaturated, it is unbounded below on long strain histories.  If saturated, it stops paying a uniform normalized high-shell toll.  This is the material-geometric version of the scalar shell-potential obstruction.

Verdict: metric storage alone cannot be bounded below and uniformly coercive.

## 6. Riccati / trajectory Gramian attempt

For the abstract linearized PLS system

```math
\partial_tY_N+\mathcal L_N^{PLS}(t)Y_N=\mathcal R_N^{legal},
```

one can formally solve the Lyapunov equation

```math
\dot H_N+H_N\mathcal L_N^{PLS}+(\mathcal L_N^{PLS})^*H_N=-\mathcal Q_N^{PLS}.
```

The solution is a future observability/Gramian object:

```math
H_N(t)=U(T,t)^*H_N(T)U(T,t)+\int_t^T U(s,t)^*\mathcal Q_N^{PLS}(s)U(s,t)ds.
```

This pays the clock by construction.  But its boundedness and comparability to \(I\) are exactly equivalent to a finite full PLS observability/action estimate.  If the terminal normalized pulse stack exists, the integral defining \(H_N\) diverges or loses the relative bound.  Thus the Riccati construction is circular unless an independent observability/no-free-pulse theorem is already known.

Verdict: exact formal construction, not a noncircular proof.

## 7. Exact obstruction

All noncircular candidates reduce to the same missing line:

```math
\mathcal I_N+dX_{PLS,N}+c_N\,d\Omega_N^{PLS}
\le \varepsilon dD_N^{vis}+\varepsilon dD_N^{rad}+dR_N^{legal}.
```

The installed material calculation gives only

```math
d\mathscr A_{org,N}+dD_N^{vis}+dD_N^{rad}
\le C\Theta_N\mathscr A_{org,N}dt+dR_N^{legal}.
```

This is a growth/readout law.  It is not a bounded-below coercive entropy law.

## Verdict

A final closed construction of \(\mathscr A_N\) is not obtained.  The coupled PLS symmetrizer would close the problem, and the variables do form one same-material transaction, but the actual bounded-below cross-storage paying the unsigned full PLS clock remains unconstructed by the installed identities.

The remaining statement cannot be honestly hidden inside notation.  It is:

```math
\boxed{
\text{prove a noncircular full-PLS observability/coercivity theorem excluding free normalized terminal PLS pulses.}
}
```

Equivalently, prove the signed commutator/coercivity line above for a bounded-below same-packet cross-storage.
