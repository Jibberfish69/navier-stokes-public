# Coupled PLS symmetrizer transaction attempt

Status: one-transaction identity verified at the formal material-system level; unsigned-clock payment by a bounded-below cross-storage is not discharged from installed inputs.  The exact missing line is the signed same-packet commutator/coercivity inequality.

## Target

Show that pressure constraint, material metric motion, Hodge/Stokes motion, transported collar motion, annular Cauchy stress-work, strain, and viscosity form one symmetrizable same-material transaction whose unsigned participation clock is paid by the drop of

```math
\mathscr A_N=\mathscr A_{org,N}+X_{PLS,N}.
```

## Same-material system

On the transported material chart,

```math
\partial_t v+A^T\nabla_a q=\nu\operatorname{div}_a(G\nabla_a v),
\qquad
\operatorname{div}_a(Av)=0,
```

with

```math
\partial_tA=-A(\nabla_a v)A,
\qquad
G=AA^T,
\qquad
\partial_tG=(\partial_tA)A^T+A(\partial_tA)^T.
```

The material Hodge/Stokes projector is \(\mathbb P_A\), the transported collar has physical gradient \(\nabla_x\phi=A^T\nabla_a\psi\), and the Cauchy stress is

```math
T=-pI+2\nu S.
```

Thus pressure constraint, coefficient/metric motion, projector motion, collar motion, annular stress-work, strain, and viscosity are all generated by the same material law.  There is no external source coordinate.

## Positive organization and controlled cross-storage

Let \(Y_N\) denote the full depth-\(N\) PLS state: velocity tower, pressure/incompressibility tower, coefficient/metric tower, transported collar tower, Hodge/Stokes tower, strain tower, and annular stress-work carrier.  The positive part has the schematic form

```math
\mathscr A_{org,N}\simeq \langle Y_N,Y_N\rangle_{PLS}\ge0.
```

Let

```math
X_{PLS,N}=\langle K_NY_N,Y_N\rangle_{PLS}
```

with \(K_N=K_N^*\) a same-packet cross-operator.  The required lower-bound condition is

```math
|X_{PLS,N}|\le \theta\mathscr A_{org,N}+C_N(u_0),\qquad 0<\theta<1.
```

Then

```math
\mathscr A_N\ge(1-\theta)\mathscr A_{org,N}-C_N(u_0)\ge -C_N(u_0).
```

So the lower-bound part is solved once \(K_N\) is relatively controlled.

## Differentiated symmetrizer identity

Writing the linearized/differentiated full PLS system schematically as

```math
\partial_tY_N+\mathcal L_N^{PLS}Y_N=\mathcal R_N^{legal},
```

one obtains

```math
\frac d{dt}\langle (I+K_N)Y_N,Y_N\rangle
=
\langle (\dot K_N-(I+K_N)\mathcal L_N^{PLS}-(\mathcal L_N^{PLS})^*(I+K_N))Y_N,Y_N\rangle
+dR_N^{legal}.
```

The principal pieces have the expected transaction roles:

1. \(A^T\nabla q\) cancels against the material divergence constraint \(\operatorname{div}_a(Av)=0\) at top order; remaining pieces are material Hodge/collar commutators.
2. \(-\nu\operatorname{div}_a(G\nabla\cdot)\) is symmetric positive in the material metric and supplies viscous PLS loss.
3. \(\partial_tA\) and \(\partial_tG\) are exactly strain/material-metric motion terms generated by the same velocity field.
4. \(\partial_t\mathbb P_A\) is a projector-motion commutator generated by \(\partial_tA\) and the pressure constraint.
5. The transported collar current is generated by \(A^T\nabla_a\psi\) and is the same material interface as the annular Cauchy stress-work.
6. The annular identity

```math
\frac d{dt}M_\phi+2\nu\int\phi|S|^2dx=-\int u\cdot(-pI+2\nu S)\nabla\phi\,dx
```

keeps the pressure/strain stress-work on the same transported packet.

Thus the system is one same-material PLS transaction.  This part is verified.

## Required coercive line

To prove the requested payment of the unsigned clock, the cross-operator must satisfy the operator inequality

```math
\langle (\dot K_N-(I+K_N)\mathcal L_N^{PLS}-(\mathcal L_N^{PLS})^*(I+K_N))Y_N,Y_N\rangle
+c_N\,d\Omega_N^{PLS}
\le dR_N^{legal}.
```

Equivalently, in the already installed smooth-packet notation, the missing line is

```math
\mathcal I_N+dX_{PLS,N}+c_N\,d\Omega_N^{PLS}
\le
\varepsilon dD_N^{vis}+\varepsilon dD_N^{rad}+dR_N^{legal}.
```

The current direct calculation gives only the BKM-type growth estimate

```math
|\mathcal I_N|\le \varepsilon dD_N^{vis}+C_\varepsilon\Theta_N\mathscr A_{org,N}\,dt+dR_N^{legal},
```

or

```math
d\mathscr A_{org,N}+dD_N^{vis}+dD_N^{rad}
\le C\Theta_N\mathscr A_{org,N}dt+dR_N^{legal}.
```

This proves visibility of the full PLS transaction but not the signed bounded-below drop needed to pay the rectified clock.

## Verdict

The pressure constraint, metric motion, Hodge/Stokes motion, collar motion, annular Cauchy stress-work, strain, and viscosity do form one same-material PLS transaction.  What is not proved by the installed inputs is that this transaction is already symmetrized by a bounded-below \(X_{PLS,N}\) whose derivative dominates the unsigned clock.

The exact remaining theorem is:

```math
\boxed{
\exists K_N=K_N^*,\ |\langle K_NY_N,Y_N\rangle|\le\theta\langle Y_N,Y_N\rangle+C_N(u_0),
\quad
\dot H_N+H_N\mathcal L_N^{PLS}+(\mathcal L_N^{PLS})^*H_N
\le -c_N\mathcal Q_N^{PLS}+Legal,
}
```

where \(H_N=I+K_N\) and \(\mathcal Q_N^{PLS}\) is the density of the unsigned full PLS clock.  This is the coupled PLS symmetrizer/coercivity theorem.
