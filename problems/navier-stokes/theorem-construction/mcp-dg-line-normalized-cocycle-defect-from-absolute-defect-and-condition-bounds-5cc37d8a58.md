# DG-Line Normalized Cocycle Defect From Absolute Defect And Condition Bounds

## Status

Conditional theorem.

Assume on the retained family that

```math
\sigma_2(H_J)\ge s_*>0,
\qquad
\sigma_1(H_J)\le S_*<\infty.
```

Then

```math
\frac{\sigma_2(H_J)^2}{\sigma_1(H_J)}
\ge
\frac{s_*^2}{S_*}.
```

Therefore, if the absolute reduced cocycle defect satisfies

```math
\|E_H\|_{op}
\le
(\varepsilon_A/2)\frac{s_*^2}{S_*},
```

then automatically

```math
\|E_H\|_{op}
\le
(\varepsilon_A/2)
\frac{\sigma_2(H_J)^2}{\sigma_1(H_J)}.
```

This is exactly the normalized defect estimate needed for the DG-Line relative Gramian error packet. Consequently,

```math
\|E_A\|_{op}\le\varepsilon_A\lambda_2(A_J).
```
