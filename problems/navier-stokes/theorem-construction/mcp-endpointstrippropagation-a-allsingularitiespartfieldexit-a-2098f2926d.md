# Endpoint-Strip Classification Propagation Through Pack-Illegal Families

## Target

Propagate `LimitOfClassTerminalArtifact.A` and `UniformServiceTopologyCertification.A` through the Pack-illegal terminal families identified by the Pack non-exclusion route.

Circularity caveat: "Pack-illegal" names the singular family being audited. It is not the exclusion proof. The propagation below must land through `Part_{N,Q}` / `Field_{N,r,Q}` failure, service-topology class exit, same-solution admissibility failure, or continuation/readout recovery before ordinary Pack_Q is used.

## Propagation rule

Any Pack-illegal terminal family that reduces to the endpoint-strip profile is classified as a class-exit witness:

```text
finite L1 endpoint mass
+ positive mass on vanishing terminal windows
+ infinite every-super-L1 residence cost
+ no uniform service budget for the claimed service tested before Pack
=> weak terminal limit only, not valid class survivor.
```

## Families covered

### 1. Zero-radius terminal measure concentration

Covered directly.

It is exactly the endpoint-strip model. It is a weak terminal measure limit without uniform service-budget survival.

Classification:

```text
class-exit witness.
```

### 2. Infinite-cost endpoint strip

Covered directly.

This is the canonical form of `LimitOfClassTerminalArtifact.A`.

Classification:

```text
class-exit witness.
```

### 3. Selected source / positive Pack source terminal no-atom failures

Covered when the selected source branch has been reduced to the same finite-L1 / infinite-super-L1 endpoint strip.

Classification:

```text
class-exit witness, unless a stronger selected-source residence budget is supplied, in which case the endpoint strip disappears by absolute continuity.
```

### 4. Active-time thickness failures

Covered when the only missing thickness is the endpoint strip with positive mass on vanishing windows.

Classification:

```text
absence of thickness = no uniform service budget for the claimed service tested before Pack = class-exit witness.
```

### 5. Material collar / deformation collapse

Partially covered.

If collar collapse is expressed as the same terminal endpoint strip in the collar-strain ledger, then it is covered.

If collar collapse is instead an affine/material readout issue without reduction to finite-L1 / infinite-super-L1 endpoint concentration, it remains open under:

```text
AffineMaterialReadoutToFixedHs.A
or
TerminalCollarStrainFieldFailure.A.
```

### 6. Selector drift

Partially covered.

If selector drift selects only the endpoint strip, then the endpoint classification applies.

If selector drift produces a non-strip cross-profile positive object, it remains open under:

```text
PackFunctionalStabilityUnderProfileDecomposition.A.
```

### 7. Near-resonant cross-profile Pack molecule

Partially covered.

If the molecule's positive terminal defect reduces to the endpoint-strip profile, it is covered.

If the molecule is a genuine two-profile or cross-profile readout object whose positive defect has not been assigned to one field or shown to reduce to the endpoint strip, it remains open under:

```text
PositivePackDefectOrthogonality.A
or
CrossProfileTerminalSourceAtomExclusion.A.
```

### 8. Detached or surrogate packet

Already covered by same-solution admissibility.

Classification:

```text
`Part_{N,Q}` failure at admissibility.
```

### 9. Retained Part / Field jump obstruction

Already covered by ordinary Part/Field laws once Pack is present.

Classification:

```text
ordinary Part or Field exit.
```

## Propagation theorem

```text
EndpointStripPropagation.A:
Every Pack-illegal terminal family whose obstruction is the finite-L1 / infinite-super-L1 endpoint strip is a class-exit witness by LimitOfClassTerminalArtifact.A and UniformServiceTopologyCertification.A.
```

## What remains outside this propagation

The propagation does not close all Pack-illegal terminal families.

The remaining non-strip families are:

```text
1. affine/material readout collapse not reduced to endpoint strip;
2. selector drift not reduced to endpoint strip;
3. cross-profile positive Pack defect not reduced to endpoint strip.
```

Those require:

```text
AffineMaterialReadoutToFixedHs.A,
PackFunctionalStabilityUnderProfileDecomposition.A,
PositivePackDefectOrthogonality.A.
```

## Route consequence

The endpoint-strip branch is classified as a terminal artifact, not excluded by Pack_Q. The route can certify Pack_Q's positive-radius requirement for the ordinary branch only after the three non-strip families above are either reduced to endpoint strip and discharged through Part/Field first, sent to `Part_{N,Q}` / `Field_{N,r,Q}` exit without using Pack_Q, or turned into continuation/readout recovery.
