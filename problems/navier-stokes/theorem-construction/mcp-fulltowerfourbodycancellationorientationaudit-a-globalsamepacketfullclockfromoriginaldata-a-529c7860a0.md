# FullTowerFourBodyCancellationOrientationAudit.A

Status: algebraic cancellation discharged; theorem-grade full-tower cancellation not discharged.  The missing item is the oriented channel theorem for the enlarged full tower list.


for the enlarged same-carrier tower action containing metric, coefficient, commutator, pressure/Helmholtz--Leray, viscous/collar, geometry, and radius-spend channels.

## 1. Cancellation algebra

If one has four inequalities

```math
A_1+E_{12}\le E_{41}-\partial_\sigma\Phi_1,
```

```math
A_2+E_{23}\le E_{12}-\partial_\sigma\Phi_2,
```

```math
A_3+E_{34}\le E_{23}-\partial_\sigma\Phi_3,
```

```math
A_4+E_{41}\le E_{34}-\partial_\sigma\Phi_4,
```

then summing cancels all internal exchanges and gives

```math
A_{4B,N}^{tower}:=A_1+A_2+A_3+A_4
\le -\partial_\sigma\Phi_{4B},
\qquad
\Phi_{4B}:=\Phi_1+\Phi_2+\Phi_3+\Phi_4.
```

If

```math
\Phi_{4B}(\sigma_0)<\infty,
\qquad
\Phi_{4B}\ge -C_N(u_0),
```

then

```math
\int_{\sigma_0}^{\infty}A_{4B,N}^{tower}d\sigma
\le \Phi_{4B}(\sigma_0)+C_N(u_0)<\infty.
```

This part is proved.

## 3. Exact obstruction

The problematic branch is the material metric/coefficient tower.  In material variables

```math
\partial_tA=-A(\nabla u)\circ X,
\qquad
\partial_tG=-2ASA^\top.
```

At higher derivative rungs, \(D_a^kA\) and \(D_a^kG\) are driven by transported derivatives of \(u\) plus lower coefficient products.  Therefore the coefficient channel can be oriented only if its positive growth is paired with an exchange/capacity that is not the material record itself.

The invalid shortcut is

```math
\text{generated by material equations}
\Longrightarrow
\text{paid by }A_{4B,N}^{tower}.
```

The valid statement still needed is

```math
\boxed{\text{FullTowerChannelOrientation.A}}
```

or more sharply

```math
\boxed{\text{MetricCoefficientExchangeCapacity.A}.}
```

This theorem must produce the Body-IV or adjacent exchange capacity that pays positive metric/coefficient growth without assuming bounded \(\mathfrak P_N^{mat}\).

## 4. Reduced theorem

`FullTowerFourBodyCancellation.A` is equivalent to:

1. the already proved exchange-summation lemma above;
2. a channel orientation theorem assigning every enlarged tower activity to one of the four body inequalities;
3. a bounded-below combined capacity for that exact orientation.

Only item 1 is currently proved.  Items 2--3 remain open.

The obstruction is noncircular payment of the material metric/coefficient tower, not the algebraic cancellation of the four-body loop.
