# Global Full Clock Stress-Time Spatial Reduction

Date: 2026-06-25

The live physical object is one original smooth material spike-wave history.
The annular stress-time term is generated by that same history; it is not a free
curve in time.

Work in the gauge-reduced packet

```math
D_tU=\nabla\cdot T^\sharp,
\qquad
T^\sharp=-PI+2\nu S(U),
\qquad
\nabla\cdot U=0.
```

Since

```math
D_t\partial_i f=\partial_iD_tf-(\partial_iU_k)\partial_k f,
```

we get

```math
D_tS_{ij}(U)
=
{1\over2}
(\partial_i\partial_kT^\sharp_{jk}+\partial_j\partial_kT^\sharp_{ik})
-
{1\over2}
(\partial_iU_k\partial_kU_j+\partial_jU_k\partial_kU_i).
```

Thus the viscous part of

```math
I_2=\int U_i(D_tT^\sharp_{ij})\partial_j\phi
```

is a spatial collar/tower expression:

```math
|2\nu U\cdot D_tS(U)\nabla\phi|
\leadsto
|\nabla\cdot T^\sharp|\,|U|\,|\nabla^2\phi|
+
|\nabla\cdot T^\sharp|\,|\nabla U|\,|\nabla\phi|
+
|U|\,|\nabla U|^2|\nabla\phi|.
```

The pressure-time piece is elliptic, not external. Since

```math
-\Delta P=\partial_iU_j\partial_jU_i,
```

applying the material derivative gives

```math
\begin{aligned}
-\Delta D_tP
= {}&
(\partial_i\partial_kT^\sharp_{jk}-\partial_iU_k\partial_kU_j)\partial_jU_i\\
&+\partial_iU_j(\partial_j\partial_kT^\sharp_{ik}-\partial_jU_k\partial_kU_i)\\
&-2\partial_iU_k\partial_{ik}P-(\Delta U_k)\partial_kP .
\end{aligned}
```

So

```math
D_tP=(-\Delta)^{-1}\mathcal E_P(U,T^\sharp,P)
```

with \(\mathcal E_P\) equal to the displayed same-packet source.

Consequently the stress-time term reduces to the spatial same-packet density

```math
\begin{aligned}
\mathcal S_\phi^\sharp
:={}&
|\nabla\cdot T^\sharp|\,|T^\sharp|\,|\nabla\phi|
+
|U|\,|\nabla(-\Delta)^{-1}\mathcal E_P|\,|\nabla\phi|\\
&+
|\nabla\cdot T^\sharp|\,|U|\,|\nabla^2\phi|
+
|\nabla\cdot T^\sharp|\,|\nabla U|\,|\nabla\phi|\\
&+
|U|\,|\nabla U|^2|\nabla\phi|
+
|U|\,|T^\sharp|\,|\nabla U|\,|\nabla\phi|.
\end{aligned}
```

The finite rectified annular force-action variation now reduces to

```math
\int_0^{T_*}
\sum_j2^{\gamma j}
```
