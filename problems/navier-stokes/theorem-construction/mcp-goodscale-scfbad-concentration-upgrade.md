# GoodScale.TTU — SCF-Bad Concentration Upgrade

## Status

Conditional endpoint-typing upgrade.

## Target

Upgrade the grammar-level implication

```math
(a,t)\in\mathcal B_{\varepsilon_m}^{\Phi}
\Longrightarrow
Jump_{avg}
```

into an endpoint tower face when the endpoint tower/readout gauge is the only alternative.

## SCF-bad point

An active terminal point is SCF-bad when

```math
(a,T_*)\in\mathcal B_{\varepsilon_m}^{\Phi},
```

meaning

```math
\forall r>0,
\quad
SCF_{base}(Q_r^\Phi(a,T_*))>\varepsilon_m.
```

## Tower-bounded alternative

Assume instead that the endpoint tower/readout gauge is finite on a terminal neighborhood of this active point:

```math
\mathfrak A_{N,Q}\in L^\infty([t_0,T_*)),
```

with depth high enough to control the local velocity gradients and the pressure normalization appearing in `SCF_base`. Assume also bounded pack geometry, so same-fluid cylinders are uniformly CKN-comparable.

Then the local tower bound gives uniform pointwise bounds for the velocity rungs on the active neighborhood. The pressure part is supplied by the local pressure split plus energy harmonic-tail control:

```math
p=p_i^{loc}+h_i,
\qquad
-\Delta p_i^{loc}=\partial_a\partial_b(\chi_i u_au_b).
```

The local product-source carrier is bounded by the tower/readout hypothesis, and the harmonic tail is bounded by the energy ledger.

Therefore the normalized scale-critical packet decays on sufficiently small same-fluid cylinders:

```math
SCF_{base}(Q_r^\Phi(a,T_*))\to0
\qquad (r\downarrow0).
```

For small enough `r`, this gives

```math
SCF_{base}(Q_r^\Phi(a,T_*))\le\varepsilon_m,
```

contradicting SCF-badness.

## Upgrade

Thus an active SCF-bad terminal point forces failure of the finite tower/readout alternative:

```math
(a,T_*)\in\mathcal B_{\varepsilon_m}^{\Phi}
\Longrightarrow
tower\text{-}blown
```

under the stated tower-depth and pressure-readout compatibility assumptions.

Consequently

```math
(a,T_*)\in\mathcal B_{\varepsilon_m}^{\Phi}
\Longrightarrow
tower\text{-}blown\vee Jump_{avg}.
```

and, once `tower-blown` is treated as the stronger endpoint face,

```math
SCF\text{-bad active terminal point}
\Longrightarrow
tower\text{-}blown.
```

## Boundary

This is a typing upgrade, not an independent tower-bound proof. A noncircular proof of `GoodScale.TTU` still needs an upstream exclusion of `tower-blown`, or a direct endpoint contradiction where the tower-bound supplier enters without using `READ.COVER` generated by `GoodScale.TTU`.
