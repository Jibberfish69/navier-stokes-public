# Line-By-Line Pressure Readout Expansion For `DTC.Read`

## Status

Theorem-facing expansion of the pressure component in `DTC.Read`.

## Fixed Cover Data

Let `READ.COVER` supply finitely many nested cover elements

```math
B_i'\Subset B_i\Subset 2B_i,
\qquad 1\le i\le M,
```

with lower radius `r_*>0`. Let `\chi_i` satisfy

```math
\chi_i\equiv1\text{ on }B_i,
\qquad
\operatorname{supp}\chi_i\subset2B_i,
\qquad
\|\nabla^\ell\chi_i\|_\infty\le C_{\ell}r_*^{-\ell}.
```

Assume `ATD_m^\varepsilon` supplies

```math
\sup_{i,t}\|u(t)\|_{C^{N+2,\alpha}(2B_i)}\le M_U.
```

## Pressure Split

On each `B_i`, write

```math
p=p_i^{loc}+h_i,
\qquad
-\Delta p_i^{loc}=\partial_a\partial_b(\chi_i u_a u_b).
```

Then `h_i` is harmonic on `B_i`.

## Local Poisson Part

For `0\le q\le N`, define

```math
S_{q,i}(t):=\|\nabla^q(\chi_i u\otimes u)(t)\|_{C^{0,\alpha}(2B_i)}.
```

Leibniz and the cutoff bounds give

```math
S_{q,i}(t)
\le C(q,r_*)\left(1+M_U^2\right).
```

The local Schauder estimate for the double-divergence Poisson equation gives

```math
\|\nabla^{q+1}p_i^{loc}(t)\|_{L^\infty(B_i')}
\le C_{q,\alpha}(r_*)S_{q,i}(t).
```

Hence

```math
\|\nabla^{q+1}p_i^{loc}(t)\|_{L^\infty(B_i')}
\le C_{loc}(q,\alpha,r_*,M_U).
```

## Harmonic Tail

The harmonic part is generated by the far source `(1-\chi_i)u\otimes u` plus the cover normalization. Interior harmonic estimates give

```math
\|\nabla^{q+1}h_i(t)\|_{L^\infty(B_i')}
\le C_{harm}(q,r_*)\|h_i(t)-c_i(t)\|_{L^1(B_i)}.
```

Using the far-field kernel representation and energy bound,

```math
\|\nabla^{q+1}h_i(t)\|_{L^\infty(B_i')}
\le C_{tail}(q,r_*)\|u(t)\|_2^2
\le C_{tail}(q,r_*)\|u_0\|_2^2.
```

The additive pressure constant `c_i(t)` disappears after applying `\nabla^{q+1}`.

## Combined Pressure Bound

For `0\le q\le N`,

```math
\|\nabla^{q+1}p(t)\|_{L^\infty(B_i')}
\le C_{loc}(q,\alpha,r_*,M_U)+C_{tail}(q,r_*)\|u_0\|_2^2.
```

Taking the finite maximum over `1\le i\le M` gives one cover constant

```math
C_P(N,\alpha,r_*,M,M_U,\|u_0\|_2).
```

## Forcing Rung

The forcing rung is

```math
K_q=-\nabla^{q+1}p+\nu\Delta U_q.
```

The viscous term is controlled by the `q+2` tower rung:

```math
\|\Delta U_q\|_{L^\infty(B_i')}
\le C\|U_{q+2}\|_{L^\infty(B_i')}
\le C M_U.
```

Therefore

```math
\sup_{i,t}\|K_q(t)\|_{L^\infty(B_i')}
\le C_K(N,\alpha,r_*,M,M_U,\nu,\|u_0\|_2).
```

## DTC.Read Output

Together with the velocity tower bounds from `ATD_m^\varepsilon`, the forcing rung estimate gives the pointwise transported-center packet:

```math
DTC.A_{avg}+READ.COVER+ATD_m^\varepsilon\Longrightarrow DTC.A.
```

## Boundary

All constants are finite because the cover is finite and has lower radius `r_*`. The theorem is a terminal readout theorem after `READ.COVER`.
