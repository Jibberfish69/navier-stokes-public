## Finding

The route is coherent, but the new certification surface has to be read with a
sharp scope limit.

`UniformServiceTopologyCertification.A` is a class-topology bridge:

```text
valid survival through Pack / Part / Field
=> uniform control of the service claimed,
not merely weak terminal measure existence.
```

That is the right bridge for the endpoint strip. The strip can exist weakly as
`M delta_{T*}`, while failing to survive as a Part or Field service object once
that service requires a terminal-window modulus.

## Non-overclaim scope

The certification bridge does not prove a new Navier-Stokes estimate.

It cannot by itself prove:

```text
finite same-solution participation residence,
finite donor-drain compatibility,
one-field readout continuity,
or affine/material readout to fixed-Hs control.
```

It only says that a witness lacking the uniform budget for the service it
claims is not a survivor through that service.

## Correct route use

For endpoint-strip witnesses, the usable theorem chain is:

```text
positive mass on vanishing terminal windows
=> weak-* endpoint atom M delta_{T*}
=> no preterminal L^1_s density represents the terminal object
=> no terminal-window modulus
=> not a survivor through any service tested before Pack whose certification requires
   that modulus.
```

The last line depends on the service-certification principle. It is not a
standalone PDE estimate.
