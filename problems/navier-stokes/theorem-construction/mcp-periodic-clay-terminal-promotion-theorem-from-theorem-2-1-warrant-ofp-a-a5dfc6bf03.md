## Theorem `PCT.A` (Periodic Clay terminal promotion)

Let `u_0` be smooth, divergence-free, and zero-mean on `T^3`. Let `(u,p)` be the maximal classical solution of the three-dimensional incompressible Navier-Stokes equations with `f=0` on `[0,T_*)`.

Assume the installed Theorem 2.1 class-membership warrant on the periodic branch:

```math
CFI.A + End_{NS}\Longrightarrow \text{no finite-time class exit}.
```

Assume also that the terminal six-burden route supplies the two inputs in the recorded order:

```math
LCI.A + FCI.5f \Longrightarrow CSP.A \Longrightarrow OFP.A \Longrightarrow CFI.A,
```

and

```math
DTC\text{-to-TowerBound}+END.Exh+END.Cross+END.Pack+END.Field\Longrightarrow End_{NS}.
```

Then `T_* = +\infty`; hence the periodic Clay branch with `f=0` is discharged on the original periodic Navier-Stokes surface.

## Proof

Local classical well-posedness gives a maximal interval `[0,T_*)`. Suppose, for contradiction, that `T_*<\infty`.

By maximality, a finite terminal obstruction occurs at `T_*`. On the installed class-membership route, every such obstruction is typed through the class vocabulary

```math
M_Q(u,p)=Pack_Q\wedge Part_{N,Q}\wedge Field_{N,r,Q}
```

or through the endpoint certificate matrix. Thus a first finite terminal obstruction must be one of the following:

1. loss of participation/liveness, recorded as `\neg Part`;
2. loss of packing/pack gauge, recorded as `\neg Pack`;
3. loss of one-field coherence, recorded as `\neg Field`;
4. tower-amplitude escape, recorded by the `DTC-to-TowerBound` endpoint face.

The installed endpoint matrix converts these into the accepted endpoint certificates:

```math
\neg Part \Longrightarrow Dead,
```

```math
\neg Pack \Longrightarrow packing\text{-}detached\vee tower\text{-}blown,
```

```math
\neg Field \Longrightarrow Jump.
```

Together with `END.Exh`, `END.Cross`, `END.Pack`, and `END.Field`, the route yields `End_NS`; hence every endpoint certificate is excluded.

On the class-membership side, the terminal six-burden packet supplies

```math
LCI.A+FCI.5f\Longrightarrow CSP.A\Longrightarrow OFP.A\Longrightarrow CFI.A.
```

Therefore the Theorem 2.1 warrant applies:

```math
CFI.A+End_{NS}\Longrightarrow \text{no finite-time class exit}.
```

This contradicts the existence of the first finite terminal obstruction at `T_*`. Hence no finite `T_*` exists, and `T_* = +\infty`.

Since the solution remains classical for all finite time on the original periodic Navier-Stokes equation with `f=0`, the periodic Clay branch is discharged.
