# PLS recirculation packing closure

Status: recirculation subcase discharged; full clock still reduces to one-way positive material-record growth.

## Target

Close the branch in which the participation-law--strain interface has infinite positive variation by repeated back-and-forth recirculation:

```math
\int_0^{T^*}\sum_j[m_j^{PLS}(t)]_+dt=\infty
```

with the positive mass generated by oscillatory exchange rather than one-way growth of the continuation-depth material record.

## 1. Correct carrier

The carrier is the participation-law--strain interface.  Pressure/RHS, Hodge/Stokes projection, coefficient motion, transported collar motion, Cauchy stress, viscosity, incompressibility, velocity, and strain are coordinates of one material transaction.

The corrected primitive identity is

```math
d(-E_w)+[m_w^{PLS}]_+dt
=
\nu D_wdt+[-m_w^{PLS}]_+dt.
```

Thus recirculation is not a free signed-transfer problem.  A return/backscatter event is another PLS event, with the same material participation coordinates and the same shell/rate cost.

## 2. Bounded-record recirculation closes

Assume on a terminal interval family that the continuation-depth material record is bounded:

```math
\sup \mathcal P_N^{mat}\le K.
```

The installed bounded-record action-cycle theorem gives a pointwise bound for the full PLS action density:

```math
\mathcal A_N^{PLS}(t)\le C_N(K).
```

Therefore any interval carrying fixed positive PLS action \(\eta>0\) has length at least

```math
|I|\ge \eta/C_N(K).
```

A bounded-overlap family of such intervals cannot accumulate infinitely inside finite \(T^*\). Hence infinite unit recirculation cycles are impossible while the material record stays bounded.

This proves the bounded-record oscillatory branch is closed.

## 3. Accelerated recirculation is high-rate participation and is paid

If the cycles try to accelerate, their active material time scale shrinks.  On shell \(j\), the heat rate is

```math
\nu 2^{2j}.
```

The subheat branch, where the material participation rate is below a fixed multiple of \(2^{2j}\), is absorbed by high-shell viscous residence:

```math
[m_j^{PLS}]_+^{subheat}dt
\lesssim
\nu 2^{2j}e_j(t)dt+\text{legal terms}.
```

The superheat branch, where the material participation rate exceeds the heat rate, is paid by the installed top-strain / coefficient-frame / transported-collar clock.  In that branch, rapid recirculation forces the same positive top-strain or coefficient/collar participation that the strain-log storage already counts.

Thus faster cycling increases, rather than hides, the already-paid participation cost.

## 4. No free top-frequency regeneration

Smooth initial data may contain infinitely many frequencies, but the initial tails are summable at every fixed continuation depth.  The heat semigroup penalizes shell \(j\) on rate \(2^{2j}\).  A top shell that decays can re-enter only through the nonlinear participation law.  That re-entry is exactly PLS service:

```math
\text{top-shell regeneration}
\Longrightarrow
[m_j^{PLS}]_+\text{ or an already counted companion service.}
```

So infinite top-frequency regeneration cannot be a hidden source.  It is either viscously damped, top-strain/superheat paid, legal-residual paid, or it is one-way growth of the material record itself.

## 5. Closure of the recirculation alternative

Suppose infinite positive PLS variation is caused by recirculation rather than one-way material-record growth.  Then one of the following must occur:

1. bounded-record unit cycles: impossible by the bounded-record packing estimate;
2. accelerated subheat cycles: absorbed by high-shell viscosity;
3. accelerated superheat cycles: paid by top-strain/coefficient/collar participation;
4. top-frequency regeneration: counted as PLS service and paid by the same high-frequency viscous/superheat alternatives.

Every oscillatory recirculation branch is therefore charged by already finite terms.

Hence

```math
\boxed{
\operatorname{Var}^+_{recirc,(0,T^*)}(m^{PLS})<\infty.
}
```

## 6. Remaining branch

The only branch not closed by this note is one-way positive material-record growth:

```math
\int_0^{T^*}d[\log(1+\mathcal P_N^{mat})]_+=\infty.
```

This is not recirculation.  It is the continuation-depth record becoming unbounded.  Therefore the live frontier is sharpened:

```math
\text{PLS recirculation is closed; any remaining full-clock failure is one-way positive material-record growth.}
```

This matches the installed bounded-record action-cycle theorem and the high-frequency no-free-regeneration analysis.
