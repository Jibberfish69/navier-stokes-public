# Relative Schur PressOp / Collar Storage Direct Attack

Date: 2026-06-25

## 0. Target

The corrected live object is a bounded-below replacement for the negative
pressure/operator plus higher-collar storage:

```math
\exists\ \widetilde{\mathscr A}_N^{press/op+collar}
\ge
-C_N(u_0)
```

such that

```math
d\widetilde{\mathscr A}_N^{press/op+collar}
+
c_N\left(
d\Omega_N^{press/RHS}
+
d\Omega_N^{collar}
\right)
\le
dR_N^{legal}.
\tag{RS.1}
```

The annular stress-work block is not included in the obstruction here.  Its
natural negative transported-energy storage is already bounded below by the
physical energy after the installed null-mode corrections.

This note tests the natural repair candidate: a relative Schur-complement /
elliptic graph storage for pressure, Hodge projection, and transported collar.

## 1. Pressure graph

On the material packet,

```math
L_Gq=R(v,A,G),
\qquad
L_G=-\operatorname{div}_a(G\nabla_a).
\tag{RS.2}
```

Let

```math
\mathcal Q_G(R):=L_G^{-1}R.
\tag{RS.3}
```

The exact pressure graph defect is

```math
Z_q:=q-\mathcal Q_G(R).
\tag{RS.4}
```

But `(RS.2)` gives

```math
Z_q\equiv0
\tag{RS.5}
```

on every smooth same-carrier packet.  Therefore any storage made from
\(\|Z_q\|^2\), or from a positive Schur complement measuring distance to the
elliptic pressure graph, has zero derivative on the exact packet.  It cannot
tax the pressure/RHS clock.

The nonzero pressure graph energy is instead

```math
E_p
:=
{1\over2}\langle q,L_Gq\rangle
=
{1\over2}\langle R,L_G^{-1}R\rangle .
\tag{RS.6}
```

The installed pressure/operator attack gives

```math
\dot E_p
=
\langle q,\dot R\rangle
+
\int ASA^\top\nabla_aq\cdot\nabla_aq\,da .
\tag{RS.7}
```

So \(-E_p\) has the right derivative orientation.  Its lower-bound problem is
unchanged:

```math
-E_p(t)\ge -C
\quad\Longleftrightarrow\quad
E_p(t)\le C .
\tag{RS.8}
```

This is continuation-depth pressure/operator control.

The scalar saturation variant also cannot give a uniform toll.  Let

```math
\mathscr A_p^\Phi=-\Phi(E_p),
\qquad
0\le\Phi'\le1.
\tag{RS.9}
```

To pay a fixed fraction of positive pressure/operator growth for arbitrarily
large \(E_p\), one needs

```math
\Phi'(E)\ge c>0
\quad\text{for all large }E.
\tag{RS.10}
```

Then

```math
\Phi(E)\ge cE-O(1),
\tag{RS.11}
```

so

```math
\mathscr A_p^\Phi(E)\to-\infty .
\tag{RS.12}
```

If \(\Phi\) is bounded to preserve a lower bound, then \(\Phi'\) must lose a
uniform positive lower bound somewhere, and the storage stops paying the full
pressure/RHS clock.  Thus scalar graph-energy saturation repeats the same
obstruction.

## 2. Hodge Schur complement

The material Hodge projection is already the Schur complement of the
constraint:

```math
h=\mathbb P_Ah+A^\top\nabla_a\pi_h,
\qquad
L_G\pi_h=-\operatorname{div}_a(Ah),
\tag{RS.13}
```

so

```math
\mathbb P_Ah=h-A^\top\nabla_aL_G^{-1}
\left(-\operatorname{div}_a(Ah)\right).
\tag{RS.14}
```

There is no additional Hodge graph defect after the projection is enforced.
Differentiating the projection gives the already-installed commutator:

```math
[\partial_t,\mathbb P_A]
\quad\text{generated by}\quad
\dot A,\ \dot G,\ \dot L_G .
\tag{RS.15}
```

Using

```math
\dot A=-A(\nabla_xu\circ X),
\qquad
\dot G=-2ASA^\top,
\tag{RS.16}
```

this is the same pressure/operator, coefficient-frame, and collar service
clock.  The Hodge Schur complement changes coordinates; it does not create a
new one-sided drop.

## 3. Collar graph

The transported collar is also an exact graph of the material map:

```math
\phi(X(a,t),t)=\psi(a),
\qquad
\nabla_x\phi=A^\top\nabla_a\psi.
\tag{RS.17}
```

The base collar graph defect is therefore zero.  Higher collar records are
finite-depth derivatives of the same exact coefficient graph:

```math
D_a^\beta A,\qquad D_a^\beta G,\qquad D_a^\beta(A^\top\nabla_a\psi).
\tag{RS.18}
```

A relative defect to the exact transported collar graph vanishes.  The nonzero
quantity is the higher collar record itself:

```math
E_{coll,N}.
\tag{RS.19}
```

The negative storage \(-E_{coll,N}\) has the right oriented derivative sign,
but

```math
-E_{coll,N}(t)\ge -C
\quad\Longleftrightarrow\quad
E_{coll,N}(t)\le C,
\tag{RS.20}
```

which is again continuation-depth material-record control.  Saturating
\(-E_{coll,N}\) has the same defect as `(RS.9)`--`(RS.12)`: a bounded-below
storage cannot keep a uniform toll at arbitrarily large collar record.

## 4. Combined graph correction

Any correction of the form

```math
\widetilde{\mathscr A}_N^{graph}
=
-\Phi_p(E_{p,N})
-\Phi_c(E_{coll,N})
+
B(Z_q,Z_{\mathbb P},Z_\phi)
\tag{RS.21}
```

has only two possibilities.

First, the defect part is exact:

```math
Z_q=Z_{\mathbb P}=Z_\phi=0.
\tag{RS.22}
```

Then \(B\) contributes no clock.

Second, the nonzero part comes from the graph energies \(E_{p,N}\) and
\(E_{coll,N}\).  A uniform toll for the clocks

```math
d\Omega_N^{press/RHS}+d\Omega_N^{collar}
\tag{RS.23}
```

requires \(\Phi_p'\) and \(\Phi_c'\) to stay bounded below along unbounded
records, forcing \(\widetilde{\mathscr A}_N^{graph}\) to be unbounded below.

Therefore the relative Schur graph correction does not construct the missing
bounded-below entropy.

## 5. What remains

The remaining route is not a new pressure-only producer.  It is the same
participation-law-strain packet, but the pressure/operator plus collar block
must close by principal-rank structure rather than by a graph-defect storage.

The noncircular statement is a top-rank triangular descent / no-self-birth
absorption:

```math
d\Omega_N^{press/RHS}
+
d\Omega_N^{collar}
\le

d\Omega_N^{press/RHS}

d\Omega_N^{collar}
```


The installed notes already identify the non-self branches: initial smooth

## Verdict

The corrected "OR" object is right: the blocker is specifically the
pressure/operator plus higher-collar storage, with annular stress already
separated.

The natural relative Schur-complement repair does not close it.  On the exact
same-material packet, the pressure/Hodge/collar graph defects vanish; the only
nonzero graph energies are the raw continuation-depth records, whose negatives
are bounded below only after the desired record bound is already known.

So the actual closure has to prove the strict top-rank triangular descent
`(RS.24)`, or an equivalent no-self-birth absorption for pressure/RHS plus
higher-collar service inside the same participation-law-strain packet.
