# RelativeSchurComplementPressCollarConstructionAttempt.A

Status: Schur-complement correction constructed; closed entropy law reduced to an unproved top-rank triangular/no-self-birth estimate.

## 0. Variables

Let

```math
Y_N=(v,A,G,\phi,\mathbb P_A,\text{strain/frame data})_{\le N}
```

be the free same-material packet variables and let

```math
Z_N=(q,C_N)
```

be the pressure/operator plus higher-collar tower.  The pressure component is governed by

```math
L_Gq=R(Y_N),
\qquad
L_G=-\operatorname{div}_a(G\nabla_a),
```

and the collar tower is governed by the transported-collar graph

```math
C_N=\mathcal C_N(A,G,\phi)+\text{commutator/lower-rank terms}.
```

Equip \(Z_N\) with the pressure/collar Hilbert form

```math
\|Z_N\|_{pc,N}^2
:=
\langle q,L_Gq\rangle+\|C_N\|_{coll,N}^2.
```

Thus

```math
E_{pc,N}:=E_{p,N}+E_{coll,N}={1\over2}\|Z_N\|_{pc,N}^2.
```

## 1. Forced graph

Define the elliptic/collar graph map

```math
\Gamma_N(Y_N)
:=
\left(
L_G^{-1}R(Y_N),\ \mathcal C_N(A,G,\phi)
\right)
```

at top rank, with the local harmonic/collar memory retained as part of the same interface-current record.  Let the relative pressure/collar defect be

```math
W_N:=Z_N-\Gamma_N(Y_N).
```

At principal top rank, \(W_N\) is zero.  At finite depth it consists of commutators, harmonic/collar memory defects, projection defects, and lower-rank material terms.

## 2. Schur-complement correction

Define

```math
\boxed{
\mathcal G_N^{ell/collar}
:=
E_{pc,N}-{1\over2}\|Z_N-\Gamma_N(Y_N)\|_{pc,N}^2 .
}
\tag{RSC.1}
```

Equivalently,

```math
\mathcal G_N^{ell/collar}
=
\langle Z_N,\Gamma_N(Y_N)\rangle_{pc,N}
-{1\over2}\|\Gamma_N(Y_N)\|_{pc,N}^2 .
```

Then the relative Schur-complement storage is

```math
\boxed{
\widetilde{\mathscr A}_N^{press/op+collar}
:=
-E_{pc,N}+\mathcal G_N^{ell/collar}
=
-{1\over2}\|W_N\|_{pc,N}^2 .
}
\tag{RSC.2}
```

This is the correct graph-subtracted object.  It removes the pressure/collar energy parallel to the elliptically forced graph and leaves only the relative pressure/collar defect.

## 3. Bounded-below test

`(RSC.2)` is bounded below if and only if the relative defect is bounded:

```math
\|W_N(t)\|_{pc,N}^2\le C_N(u_0)+\text{already-paid lower-rank/top-strain/legal terms}.
\tag{RSC.3}
```

This is weaker than bounding \(E_{pc,N}\) itself.  It is not the circular raw pressure/collar record bound.  However `(RSC.3)` is still a theorem: it requires the finite-depth graph error to be genuinely lower rank or paid by top-strain/frame, viscosity, annular stress, or legal residuals.

Thus the Schur complement fixes the raw lower-bound problem only if the pressure/collar defect \(W_N\), not the full pressure/collar graph energy, satisfies the lower-rank/paid-error estimate `(RSC.3)`.

## 4. Derivative test

Differentiate `(RSC.2)`:

```math
d\widetilde{\mathscr A}_N^{press/op+collar}
=
-\langle W_N,dW_N\rangle_{pc,N}
-{1\over2}\langle W_N,\dot H_{pc,N}W_N\rangle\,dt,
\tag{RSC.4}
```

where \(H_{pc,N}\) denotes the time-dependent pressure/collar Hilbert form.

The graph-parallel part of \(dE_{pc,N}\) has disappeared.  Therefore `(RSC.4)` taxes only the relative defect growth directly.  To recover the desired estimate

```math
d\widetilde{\mathscr A}_N^{press/op+collar}
+c_N(d\Omega_N^{press/RHS}+d\Omega_N^{collar})
\le dR_N^{legal},
\tag{RSC.5}
```

one needs a top-rank triangular/no-self-birth theorem:

```math
\boxed{
(d\Omega_N^{press/RHS}+d\Omega_N^{collar})_{top}
\le
C\,d\Omega_N^{rel.defect}
+C\,d\Omega_N^{lower}
+C\,d\Omega_N^{strain/frame}
+C\,dD_N^{vis/rad}
+C\,d\Omega_N^{annular}
+dR_N^{legal}.
}
\tag{RSC.6}
```

Here \(d\Omega_N^{rel.defect}\) is the positive orientation generated by `(RSC.4)`.  The statement `(RSC.6)` is exactly the assertion that pressure/collar graph-parallel growth has no autonomous top-rank self-birth: once the elliptic/collar graph is subtracted, any remaining top-rank pressure/collar activity either is relative defect or descends to lower-rank/top-strain/viscosity/annular/legal channels.

## 5. What is proved

The explicit correction `(RSC.1)` is constructed, and it yields the graph-subtracted storage `(RSC.2)`.  This is the relative Schur-complement object requested.

## 6. What is not proved here

The closed entropy law `(RSC.5)` is not proved from the current installed inputs.  It is equivalent to the two missing estimates:

```math
\|W_N\|_{pc,N}^2\le C_N(u_0)+\text{paid lower-rank/top-strain/legal terms}
```

and the top-rank no-self-birth estimate `(RSC.6)`.

The pressure-collar same-packet routing surfaces prove admission into the same PLS packet.  They do not by themselves prove the Schur graph defect bound or the terminal preservation of Calderon-Zygmund pressure cancellation after one-sided positive selection.

## Verdict

The construction is

```math
\boxed{
\mathcal G_N^{ell/collar}=E_{pc,N}-{1\over2}\|Z_N-\Gamma_N(Y_N)\|_{pc,N}^2 .
}
```

The proof closes if and only if the relative graph-defect lower-bound estimate and top-rank triangular/no-self-birth estimate `(RSC.6)` are proved.  Those estimates are not installed here.
