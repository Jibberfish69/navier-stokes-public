# Signed weighted lifted-remainder cancellation before absolute values

## Target

Prove a signed estimate for the true weighted lifted remainder before absolute values, for example

```math
\int_0^T G_N^{lift,\sigma}(t)\,dt
\le C2^{-2\delta N},
```

where

```math
G_N^{lift,\sigma}
=
\sum W_{j,k,\ell}^{\sigma}R_{j,k,\ell}^{lift}.
```

A proof of this target, together with active-square residual-tail control, feeds
`PositiveRemainderDepletion.A` and hence the source-pulse closure chain.

## Attempt

The unweighted dyadic exchange identity cancels paired shell transfer. That cancellation acts before one-sided shell weights, lifted packet reductions, physical cutoffs, and terminal active-window selection are inserted.

After those operations, the live remainder has a principal strain form

```math
R_{j,k,\ell}^{lift}
:=
2^{2j}\langle \mathcal C_j(\nabla a_k,\Delta_j u),\Delta_j u\rangle.
```

The sign of this term depends on the alignment of the active shell packet with the symmetric strain generated by the donor/lower packet. On terminal active windows the active packet may align with an expanding strain eigendirection. In that case the contribution is positive at the exact carrier used by the no-pulse branch.

One-sided shell weights orient the shell sum. They do not force cancellation among strain eigendirections. Cutoffs and projectors also fail to supply a sign: they localize and route errors, while the legal interior strain-production term remains.

Therefore the desired signed estimate would need an additional theorem, such as:

```math
\text{active eigendirection decorrelation},
```

```math
\text{signed measure cancellation for }G_N^{lift,\sigma},
```

or

```math
\text{a structural identity rewriting }G_N^{lift,\sigma}\text{ as nonpositive plus divergence/loss}.
```

No current route surface supplies one of these statements.

## Result

The signed cancellation target is not discharged. The valid reduction is:

```math
\boxed{
\text{signed weighted lifted-remainder branch}
\Longrightarrow
\text{needs eigendirection decorrelation or active-square residual-tail control.}
}
```

If one takes absolute values instead, the estimate becomes a positive-carrier bound and returns to

```math
\text{active-square residual-tail / ScaleCriticalTreeCarleson.A}.
```

## Verdict

This item remains open and does not close `PositiveRemainderDepletion.A`. The loop should proceed to the replacement branch:

```math
\boxed{\text{Active-square residual-tail / ScaleCriticalTreeCarleson reserve.}}
```
