# Signed weighted lifted-remainder cancellation plus residual-tail control — failed discharge

## Target
Prove the combined source-control theorem:

`signed weighted lifted-remainder cancellation + residual-tail control -> active-square Carleson source control`.

## Signed cancellation component
The bare separated commutator vanishes by Fourier support, so the live terminal record is the true weighted lifted remainder after shell weights, projector/cutoff reductions, and lifted summation:

`G_N^{lift,sigma} = sum W_{j,l}^{sigma} R_{j,k,l}^{lift}`.

A useful theorem would prove cancellation before absolute values:

`int_0^T G_N^{lift,sigma}(t) dt <= C 2^{-2 delta N}`

or an equivalent signed estimate with reserve.

Current surfaces do not provide the needed strain-sign cancellation. The principal lifted remainder has variable sign and can align with expanding strain directions, so one-sided shell weights alone do not enforce cancellation.

## Residual-tail component
If absolute values are inserted, the route collapses to a positive carrier whose Young inequality output contains an active-square tail burden plus a residual first-moment tail. The installed full tail-square reserve controls cumulative tail energy, while the active-square residual requires shellwise square-dissipation control.

The residual-tail control needed here is therefore as strong as active-square upper-tail Carleson or one of its equivalent source-normalized forms.

## Verdict
The combined theorem is not discharged. It splits into two independent live requirements:

1. strain-sign cancellation for the true weighted lifted remainder;
2. active-square-strength residual-tail control.

Neither follows from current exchange algebra, energy, or tail-square reserve surfaces.

## Consequence
The source-control route still reduces to direct active-square Carleson via a monotone/source-dominance theorem, or to a new cancellation theorem for the lifted signed remainder plus an active-square residual estimate.
