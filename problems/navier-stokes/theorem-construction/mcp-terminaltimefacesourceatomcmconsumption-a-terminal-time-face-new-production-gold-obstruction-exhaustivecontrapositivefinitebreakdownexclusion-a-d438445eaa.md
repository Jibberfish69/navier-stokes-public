## Proof

Start with the terminal layer model. The live frontier already identifies this as the exact obstruction left by finite `L^1_s` source control:

```math
g_m(s)=\frac{a}{\tau_m}1_{(-\tau_m,0]},
\qquad \tau_m\downarrow0.
```

This produces nonzero mass at the terminal time face and no terminal time-thickness modulus. It is a weak terminal measure limit, not a super-`L^1_s` service object.

Now split by CM status.

### Case 1: no admitted same-solution CM terminal residual object

If the terminal atom is only a diagnostic/support object, a Pack boundary record, or an object without same original datum / same maximal branch / same pressure-viscosity tower custody, then it is not an admitted surviving terminal residual object in the CM test.

This consumes the branch by admissibility failure. It is not a branch the referee can demand to land in `Member(Q)` or a concrete Part/Field face, because it never enters as an admitted same-solution terminal residual object.

### Case 2: admitted, but no finite same-solution participation service

Assume `Q` is admitted as a same-solution terminal residual object. If the terminal source atom is not carried by a finite same-solution pressure-viscosity/tower participation record, then

```text
not Part_{N,Q}.
```

The branch is consumed by concrete Part Part/Field failure.

The endpoint strip model supplies the reason: the terminal source mass has no finite terminal residence modulus and infinite every-super-`L^1_s` cost. If the asserted Part service requires finite same-window participation/residence/donor-readout budget, the terminal atom cannot satisfy it.

### Case 3: admitted and Part-retained

Assume instead that `Part_{N,Q}` is retained. Then the terminal atom is not external noise and not detached support. It is an internal terminal source/readout event of the same Navier-Stokes tower.

But the object has nonzero terminal source/readout mass and zero heat-time participation. That is exactly a terminal readout jump/source-residue event. A retained same-equation terminal jump is incompatible with one coherent `Field_{N,r,Q}` at any positive tested readout scale.

Therefore

```text
forall r>0 not Field_{N,r,Q}.
```

The branch is consumed by concrete Field Part/Field failure.

### Case 4: positive-radius coherent readout survives

If instead the object has a positive-radius coherent target-class readout with no terminal source/readout jump, then it is no longer the terminal time-face source atom described above. It has entered the ordinary continuation/readout branch. That is not a finite-breakdown obstruction.

## Conclusion

The terminal time-face source atom/new-production object is consumed in the CM contrapositive without proving the forward gold anti-atom theorem.
