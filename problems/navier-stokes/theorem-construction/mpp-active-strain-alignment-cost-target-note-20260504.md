## Audit Correction: Positive Strain Is Not Identically Zero

The earlier rigidity target was too strong.  A frozen symmetric trace-free strain
field can genuinely amplify aligned packets.  If `S` has a positive eigenvalue
and a packet is polarized in the expanding eigendirection, then

```math
(v\cdot Sv)_+>0.
```

Therefore the theorem cannot say

```math
\int_{-\infty}^{0}\int (v\cdot Sv)_+\,dy\,ds=0
```

for every finite-energy ancient tangent packet.  Positive strain alignment is a
real Euclidean phenomenon.  The only viable rigidity is terminal-generation
rigidity: a terminal pulse tangent with no incoming high-frequency/source mass
is zero.

## Candidate Proof Route For `TPNI.A`

Try to remove the strain transport by changing variables:

```math
z=e^{-sS}y,
\qquad
w(z,s)=e^{sS}v(e^{sS}z,s).
```

Formally this gives an anisotropic heat--Stokes equation

```math
\partial_s w+\nabla_z q
=
\nu\nabla_z\cdot(A(s)\nabla_z w),
```

with

```math
A(s)=e^{-sS}e^{-sS^T}.
```

On each finite interval `[-R,0]`, this is uniformly parabolic.  The no-incoming
condition becomes local decay of `w` on compact sets as `s\to-\infty`.

The desired analytic theorem is a backward-uniqueness / Carleman statement:

```math
\boxed{
\text{an ancient solution of the transformed anisotropic Stokes system generated
by a terminal pulse and carrying no incoming high-frequency/source mass is zero.}
}
\tag{ABU.A}
```

Then `w\equiv0`, hence `v\equiv0`, contradicting the normalized active mass.

## Audit Boundary For The Candidate Proof

The proof route above still has two nontrivial licenses.

First, local compact decay as `s\to-\infty` may be too weak by itself.  Under the
strain flow, mass can enter a fixed compact region from spatial infinity along
contracting directions.  Thus a valid terminal no-incoming hypothesis must rule
out incoming mass through the full backward parabolic boundary, not merely on
each fixed compact.  A usable form might be a global weighted `L^2` decay, a
scale-localized high-frequency tail vanishing statement, or a no-flux condition
on transported backward cylinders inherited from the terminal rescaling.

Second, the change of variables must be written with the correct Stokes/divergence
structure.  The formal transform removes the vector stretching, but the
divergence constraint and pressure projection may become anisotropic rather than
the standard `\nabla_z\cdot w=0` system.  The Carleman theorem must be proved for
the exact transformed system, not only for the scalar heat surrogate.

Therefore the sharpened target is:

```math
\boxed{
NoIncomingLicense.A
+
AnisotropicBackwardUniqueness.A
\Longrightarrow
TPNI.A.
}
```

This is narrower and more route-compatible than the rejected positive-strain-zero
statement, but it remains a missing theorem.

## Non-Circularity Boundary

The bridge

```math

\Longrightarrow
```

does not by itself prove `ASAC.A`, because `ASAC.A` is being used to prove
