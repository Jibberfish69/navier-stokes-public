# MPP AncestryCompactBound / SourceResidueLiouville Direct Attempt Note

## Status

Direct attempt on the compactness side of the ancestry closure:

```math
\boxed{
AncestryCompactBound.A+SourceResidueLiouville.A.
}
```

This note assumes an infinite legal same-fluid source ancestry chain and tests
whether installed compactness already forces a forbidden ancient
source-residue limit.

## Target

Given an infinite chain

```math
\cdots \to P^{-2}\to P^{-1}\to P^0
```

with comparable normalized active source residue, prove:

1. **compact-bound production**

```math
AncestryCompactBound.A:
\quad
\text{the rescaled chain has a local suitable ancient limit in a rigid class }
\mathcal B;
```

2. **source-residue Liouville**

```math
SourceResidueLiouville.A:
\quad
\mathcal B
\Longrightarrow
\gamma_\ast\,d\mu_\ast^\sigma=0.
```

This contradicts the inherited nonzero source residue once the compact-bound production theorem places the limit in `\mathcal B`.

## Compact-Bound Test

Local suitable compactness on fixed backward cylinders is available after
localized packets and uniform local energy bounds are supplied.  But the
installed route does not force the resulting ancient object into any rigid
class such as:

```math
\text{bounded ancient},
\qquad
\text{Type I},
\qquad
\text{finite global ancient energy},
\qquad
\text{critical norm smallness},
\qquad
\text{self-similar},
\qquad
\text{axisymmetric/two-dimensional}.
```

An infinite ancestry chain can move through scales and labels while preserving
only local suitable bounds and nonzero source residue.  That is not enough for
a known Liouville theorem.

## Liouville Test

The broad theorem

```math
\text{no nonzero ancient local suitable packet exists}
```

is false: smooth nonzero ancient cancellation profiles, including Beltrami or
Stokes-mode examples, can carry nonzero local energy packets.  The only viable
Liouville theorem must be source-residue typed and terminal-generation typed.

The current repo does not prove:

```math
\gamma_\ast\,d\mu_\ast^\sigma=0
```

for all ancient limits generated by legal source ancestry chains.

## Verdict

`AncestryCompactBound.A+SourceResidueLiouville.A` is not installed.

The exact replacement theorem is:

```math
\boxed{
BoundedAncestryClass.A+SourceResidueLiouville.A:
\quad
\text{force infinite legal source ancestry into a rigid ancient class and
prove source residue vanishes there.}
}
```

Without this new compact-bound/Liouville package, the compactness branch remains
conditional.

The direct audit
`mpp-bounded-ancestry-class-source-residue-liouville-direct-audit-note.md`
records that local suitable compactness supplies no rigid ancient class and no
source-residue Liouville theorem applies without such a class.
