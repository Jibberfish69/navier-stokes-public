# MPP Ancient.NoPulse Rigidity Audit Note

## Status

Bounded theorem attempt on the second compactness-route burden after
`MSC.Localize^{carrier}`.

The conclusion is that the broad rigidity statement is false as written.  A
viable compactness route must use a sharper source-residue version:

```math
Ancient.NoPulse^{src}.
```

## Broad Target Under Test

The broad form suggested by the compactness route is:

```math
Ancient.NoPulse^{strong}:
\quad
\text{no nontrivial local suitable ancient Navier-Stokes limit can carry a
unit-scale critical packet.}
```

This is too strong.

## Smooth Ancient Counterexample To The Broad Form

On the periodic surface, let `\phi` be a nonzero divergence-free Stokes
eigenmode with

```math
-\Delta\phi=\lambda^2\phi,
\qquad
\mathbb P((\phi\cdot\nabla)\phi)=0.
```

A single divergence-free Fourier mode has this property; a Beltrami mode is the
concrete eigenmode example.  Set, for `s\le 0`,

```math
v(y,s)=A e^{-\nu\lambda^2s}\phi(y),
```

with pressure chosen to absorb the gradient part of `(v\cdot\nabla)v`.  Then

```math
\partial_s v+v\cdot\nabla v+\nabla q-\nu\Delta v=0,
\qquad
\nabla\cdot v=0.
```

This is a smooth ancient local suitable solution on every finite backward
cylinder.  For `A\ne0`, its unit-scale velocity and gradient packets are
nonzero.  Therefore the broad statement `Ancient.NoPulse^{strong}` is false.

The example may grow as `s\to-\infty`, but the local suitable compactness route
only gives finite control on fixed backward cylinders unless an additional
global ancient bound is installed.

## Why This Does Not Refute The Source Version

The example above is not a source-balanced pulse.  Its Leray-projected
nonlinearity vanishes:

```math
\mathbb P((v\cdot\nabla)v)=0.
```

Thus it does not carry the active nonlinear source residue needed for
`SOURCE.NO-PULSE.A`.  It refutes only the broad “no nontrivial ancient packet”
statement.

The compactness route therefore needs the sharper theorem:

```math
\textbf{Ancient.NoPulse}^{src}:
```

No local suitable ancient limit generated by a same-fluid terminal,
source-balanced bad pulse can carry a nonzero inherited active source residue.

Equivalently, after localization and rescaling,

```math
\gamma_\ast\,d\mu_\ast^\sigma=0
```

for every terminal-generated ancient limit in the licensed source-residue
class.

## Missing Extra Hypotheses

The current repo does not install any of the hypotheses that would support such
a source-residue Liouville theorem, for example:

```math
\text{bounded ancient solution},
\qquad
\text{Type I control},
\qquad
\text{finite global ancient energy},
```

```math
\text{critical norm smallness},
\qquad
\text{self-similar profile class},
\qquad
\text{axisymmetry or two-dimensional reduction}.
```

Nor does it install a terminal-generation law proving that every localized bad
source pulse limit falls into one of those classes.

## Correct Conditional Route

The compactness route can only be stated as:

```math
MSC.Localize^{src}
+
Ancient.NoPulse^{src}
\Longrightarrow
MSC.BadAC,
```

where `MSC.Localize^{src}` is stronger than the carrier version: it must
localize not merely global mixed-shell mass, but the source-balanced bad pulse
residue itself.

In expanded form:

1. `MSC.Localize^{src}` selects a same-fluid physical cylinder carrying a
   nonzero active source-residue packet.
2. Local compactness extracts a local suitable ancient limit preserving that
   source residue.
3. `Ancient.NoPulse^{src}` excludes such a terminal-generated source-residue
   limit.

## Verdict

The broad ancient Liouville route is closed negatively:

```math
\boxed{
Ancient.NoPulse^{strong}\ \text{is false.}
}
```

The only viable compactness target is:

```math
\boxed{
MSC.Localize^{src}+Ancient.NoPulse^{src}.
}
```

This sharper pair is still not proved from `OriginalSmoothData`.  It is another
presentation of the same no-pulse atom:

```math
OriginalSmoothData\Longrightarrow SOURCE.NO\text{-}PULSE.A.
```
