# MPP Annular Residual Specific Case Exhaustion

Date: 2026-06-14

## 1. Object Under Test

The case is the residual annular packet left by the exact cone/funnel audit.
The endpoint point alone is not the witness.  The witness claim is carried by
positive-radius annular fields

```math
A_m
=
\{(x,t):\alpha r_m<|x-x_*|<\beta r_m,\ t_m-\theta r_m^2<t<t_m\},
\qquad
r_m\downarrow0,\quad t_m\uparrow T_*.
```

After heat descendants, legal losses, through-flow, and paid finite terms are
removed, the remaining positive source refill is

```math
D_j^{res}(t;t_0)
:=
2^{2j}
\int_{t_0}^{t}
e^{-c_0\nu2^{2j}(t-s)}
\Phi_j^+(s)\,ds.
```

This is the object whose earlier treatment was too loose.  It must be decided
in exact order: gold first, obstruction second, silver after admission third.

## 2. Gold Standard

The gold theorem would prove scale-uniform residual annular control:

```math
\forall\varepsilon>0\ \exists r_\varepsilon>0
\quad r_m<r_\varepsilon\Longrightarrow
D_{j_m}^{res}(t_m;t_0)\le\varepsilon
```

for every same-solution terminal annular schedule, or an equivalent
undiscounted scale-critical cone/profile budget.

The installed inputs do not prove this theorem.  The exact obstruction is the
heat-time pulse

```math
I_m=[t_m-2^{-2j_m},t_m],
\qquad
\Phi_{j_m}^+(s)=a_m\,1_{I_m}(s),
\qquad
0<a_0\le a_m\le A,
```

with \(j_m\to\infty\) and \(t_m\uparrow T_*\).  Its physical source mass is
finite:

```math
\sum_m\int_{I_m}\Phi_{j_m}^+(s)\,ds
\le
A\sum_m2^{-2j_m}<\infty.
```

Its residual heat-scale load is still bounded below:

```math
D_{j_m}^{res}(t_m;t_m-2^{-2j_m})
=
2^{2j_m}a_m
\int_0^{2^{-2j_m}}
e^{-c_0\nu2^{2j_m}\sigma}\,d\sigma
=
a_m{1-e^{-c_0\nu}\over c_0\nu}
\ge
a_0{1-e^{-c_0\nu}\over c_0\nu}.
```

This proves the present gold obstruction.  Finite source mass, finite ancestry,
local energy, boundary flux, cone volume, and first-moment drain do not exclude
terminal heat-time concentration.  A gold proof needs a new time-thickness or
new-production theorem such as

```math
TerminalTimeFaceAntiAtom.A
```

or the equivalent \(B_{ASAC}\) new-production theorem.  That theorem is not
installed.

## 3. Exhaustive Branches

After the gold audit, the specific case has three possible proof-program
branches.

### Branch A: gold pass

If the residual annular supplier is proved, then the residual load vanishes on
the shrinking annular schedule.  The packet is not a surviving residual
obstruction.  The branch goes to the usual continuation/member side when the
readout hypotheses are retained.

### Branch B: no annular admission

If the residual annular packet is not selected from the same original
Navier--Stokes solution, does not carry a same-solution positive-radius
annular tail, or is not readout-complete for the alleged finite breakdown, then
it is not the annular witness consumed by silver.

On the periodic branch, failure of the whole transported torus atlas selection,
carrier, or material comparability is a Pack failure of \(Q_{\mathrm{atlas}}\).
On the whole-space branch, the exterior Duhamel survivor has its own
Pack/Part/Field consumption.  A private diagnostic annular packet with no
admission is support only.  It is not an open fourth branch.

### Branch C: admitted annular witness

Assume the residual annular packet is admitted as \(Q_{ann}\): same original
solution, terminal residual role, legal and paid terms removed, same-solution
positive-radius carrier, and readout completeness.

If

```math
Part_{N_s,Q_{ann}}
\quad\text{and}\quad
\exists r>0\,Field_{N_s,r,Q_{ann}},
```

then the readout gives an \(H^s\), \(s>5/2\), continuation norm for the same
branch.  With bound \(M\),

```math
\|\Delta_j\mathbb P\nabla\cdot(u\otimes u)\|_2
\le C_sM^2\,2^{-j(s-1)},
\qquad
\|u_j\|_2\le M\,2^{-js},
```

so

```math
\Phi_j^+(t)\le C_sM^3\,2^{(3-2s)j}
```

and

```math
D_j^{res}(t;t_0)
\le
C'_sM^3\,2^{(3-2s)j}
\to0.
```

Since \(s>5/2\), an admitted branch retaining Part and a positive Field scale
cannot also carry the nonzero residual pulse from Section 2.  That retained
branch is

```math
Member(Q_{ann};\mathcal O_{work}).
```

For a finite nonsmooth admitted residual witness, the only remaining failures
are

```math
\neg Part_{N_s,Q_{ann}}
```

or

```math
Part_{N_s,Q_{ann}}
\wedge
\forall r>0\,\neg Field_{N_s,r,Q_{ann}}.
```

Those are the Part and Field exits.  They support

```math
Exit(Q_{ann};\mathcal O_{work})
:=
\neg Member(Q_{ann};\mathcal O_{work}).
```

Pack is not the argument after annular admission; carrier and selection have
already been paid for this test.

## 4. Specific Case Theorem

For the pulling-teeth cone/funnel/active-square case, no hidden branch remains.
The case is exhausted as follows.

```text
gold residual annular supplier proved
  => no surviving residual annular obstruction;

gold supplier not proved from installed inputs
  => exact terminal time-face pulse obstruction;

residual packet not admitted
  => support-only or Pack boundary on the governing terminal record;

residual packet admitted and smooth/readout-complete
  => Member(Q_ann; O_work);

residual packet admitted and finite nonsmooth
  => Part failure or Field failure, hence Exit(Q_ann; O_work).
```

This closes the specific case in the proof-program sense requested here.  It
does not close the stronger forward-positive gold theorem.  It also does not
turn a private diagnostic packet into a terminal witness before admission.

## 5. Non-Claims

This note does not prove global regularity by itself.

It does not prove `TerminalTimeFaceAntiAtom.A`.

It does not prove the stronger scale-uniform annular supplier.

It does prove that the specific hand-waved annular residual case has no
remaining untyped route: it is gold pass, exact gold obstruction, no-admission
support/Pack boundary, admitted Member branch, or admitted Part/Field exit.
