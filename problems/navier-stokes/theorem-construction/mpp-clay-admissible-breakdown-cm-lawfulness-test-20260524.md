# MPP Clay-Admissible Breakdown CM Test-Admissibility Check

Date: 2026-05-24

Status: target-fidelity audit; no positive-forward estimate introduced.

## Test Question

Does a Clay-admissible finite breakdown witness supply the
same-solution terminal object needed for the CM test used by
`ClayTerminalWitnessCMEntry.A / ClayFiniteFailureTypeCMExhaustion.A /
ClayCMContrapositiveEmbedding.A`?

## Verdict

Yes for the finite same-surface breakdown branch.

A finite Clay breakdown witness is not a class-member. It is the alleged
bad object under test: the maximal
classical Navier-Stokes solution from the original smooth datum, stopped at a
finite terminal time where classical continuation is alleged to fail. Therefore
it satisfies the five same-solution CM test-admissibility checks from
`mpp-clay-terminal-witness-invalidation-20260523.md`.

## Five-Clause Test

1. Same datum.

   A Clay finite breakdown witness is attached to the original smooth datum. This
   is exactly the first CM test-admissibility clause: the terminal object is
   attached to the maximal classical solution generated by that datum.

2. Same equation.

   On every preterminal interval, the object is the original incompressible
   Navier-Stokes solution with the same velocity and pressure. An altered
   equation, regularized flow, geometric surrogate, or external object is not a
   Clay breakdown witness for the current theorem surface.

3. Same fluid.

   `SLC.A` supplies the same-fluid Part/Field packet on every classical
   still-live preterminal window. A terminal witness extracted from the finite
   breakdown branch is a terminal subsequence or residue of that preterminal
   family, so it uses the same transported carrier/flow family until a first
   CM service failure is typed. Pack-only failure is declared only when no
   positive carrier and no meaningful same-solution original participation
   record remain.

4. Same terminal role.

   `CanonicalTerminalPacketCapture.A` starts from a maximal classical solution on
   `[0,T_*)` and strips legal boundary/cutoff/collar losses, non-selected
   branches, readout-only artifacts, and paid finite ledger terms. The remaining
   terminal obstruction is exactly the object still claiming to be the finite
   terminal obstruction.

5. Same witness grammar.

   `CanonicalTerminalPacketCapture.A`, `AnyFiniteFailureWitnessCMExit.A`, and
   the Pack-out-of-CM boundary correction audit prove that every same-solution
   terminal obstruction has only the primitive continuation services:

   ```text
   Pack_Q,
   Part_{N,Q},
   Field_{N,r,Q}.
   ```

   The first failed service is therefore `not Part_{N,Q}` or
   `forall r>0 not Field_{N,r,Q}`. For singular or zero-radius same-solution
   branches, `not Pack_Q` is the first service only after the pointwise
   pressure-viscosity-source participation record is absent. If that record
   remains, the branch is surfaced under `Part_{N,Q}` or `Field_{N,r,Q}` first.

## Theorem Extracted By The Test

```text
ClayAdmissibleFiniteBreakdown(W_*)
=> CMTestAdmissibleTerminalObject(W_*).
```

Composing with the installed Clay-facing CM theorem family gives:

```text
ClayAdmissibleFiniteBreakdown(W_*)
=> derived Part/Field failure
=> Exit(Q):=not Member(Q).
```

This closes the outside-CM loophole for finite Clay breakdown witnesses.

## Boundary

This test does not add a donor-reserve, source-wall, no-pulse, or positive
packet-survival proof.

It also does not by itself install the stronger public-closing sentence:

```text
class-exit is inadmissible as a Clay breakdown counterexample witness.
```

`ClaySolutionCMExitInadmissibility.A` proves class-exit inadmissible for a Clay
smooth solution, and explicitly marks the breakdown-counterexample version as a
separate bridge. The class-membership endpoint note contains the right
target-fidelity shape, but it marks itself as not yet proving global regularity.

The next target-fidelity test was:

```text
ClayBreakdownClassExitInadmissibility.A:
derived Part/Field failure supporting Exit(Q)
cannot be a valid Clay breakdown counterexample witness.
```

That test is recorded in
`mpp-clay-breakdown-class-exit-inadmissibility-proof-attempt-20260524.md`.
The target-fidelity-only proof fails: terminal class-exit contradicts a Clay
smooth-solution witness, but a breakdown counterexample witness is allowed to be
the allegation that no global smooth solution exists. The corrected burden is
terminal CM completeness for the same Part/Field face classification: make
the canonical terminal object precise enough that the failure has no fourth
primitive service outside Part and Field. The preterminal-reflection route
is not promoted.
