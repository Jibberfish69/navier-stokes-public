## Claim

Every finite same-surface Clay breakdown object from original smooth data is a
canonical same-solution terminal obstruction eligible for
`CanonicalTerminalPacketCapture.A`.

```math
ClayAdmissibleFiniteBreakdown(W_*)
\Longrightarrow
SameSolutionTerminalObstruction(W_*).
```

This is the extraction step needed by `ClayTerminalCMCompleteness.A`.

## Proof

Let `W_*` be a finite same-surface Clay breakdown object.

### Same Datum

By the Clay breakdown assumption, `W_*` comes from the maximal classical
Navier-Stokes solution generated by the original smooth divergence-free datum.
So the terminal object is attached to the same initial datum, not to a surrogate
or replacement flow.

### Same Equation

On every preterminal interval `[0,T_*-\epsilon]`, the object is the original
incompressible Navier-Stokes solution with the same velocity and pressure. Any
regularized equation, altered force law, Euler comparison object, or external
approximation is outside the finite same-surface Clay breakdown branch.

### Same Fluid

Before `T_*`, smoothness supplies the same transported fluid carrier on every
still-live window. The terminal extraction is taken from that preterminal
same-fluid family. If the positive carrier fails at the terminal endpoint, that
is the Field-window evidence:

```math
\neg Pack_Q.
```

It is not evidence that the terminal object was outside the CM test.

### Same Terminal Role

The object left after removing legal boundary/cutoff/collar losses,
non-selected branches, readout-only artifacts, and paid finite ledger terms is
exactly the obstruction still claiming to be the finite terminal breakdown.
That is the input object of `CanonicalTerminalPacketCapture.A`.

### Same Witness Grammar

Once the object is the same-solution terminal obstruction, the installed capture
theorem gives the only primitive terminal services:

```text
Pack_Q,
Part_{N_s,Q},
Field_{N_s,r,Q}.
```

There is no fourth primitive terminal service for a same-solution obstruction.
Therefore the object is eligible for the Field-certification terminal CM classifier.
