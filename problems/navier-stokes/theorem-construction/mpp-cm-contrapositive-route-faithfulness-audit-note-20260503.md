## Governing Fit Test

An argument is route-faithful if it answers one of these exact questions.

| Role | Faithful question |
| --- | --- |
| `CM` definition | What is the exact `Pack / Part / Field` witness? |
| Still-live admission | Why does a classical still-live window carry `CM`? |
| Class-exit bridge | If a non-smooth occurrence is genuine, which `CM` component fails? |
| Survivor control | If the feared packet remains lawful `CM`, can a local supplier propagate it? |
| Continuation readout | Once `CM` and tower data are installed, which `H^s` relaunch theorem gives the same-solution continuation? |

An argument is mis-seated when it changes the governing theorem into:

```math
OriginalSmoothData
\Longrightarrow
\text{bad terminal packet cannot occur at all},
```

without first proving that the packet is a genuine class-exit witness if it is
being used as the non-smooth occurrence.

The three faithful exits are:

| Exit | Meaning for the source-pulse packet |
| --- | --- |

   Correct seat: terminal branch splitter and readout cover after averaged
