## Classification Key

`conditional-support`: valid support after a root source-wall theorem is
supplied, but not an unconditional closure from `OriginalSmoothData`.

`live-root`: exact current theorem burden.

`installed-subcore`: theorem-grade subresult now accepted inside the route.

`preserved-alternate`: exact branch to keep available if the direct live root
does not close.

`branch-local context`: valid local branch material, but not the current
governing live edge.

`historical failed attempt`: negative or incomplete route evidence retained for
provenance, not an active discharge.

`downstream consumer`: usable only after the source-wall root closes.

`stale generated overlay`: release or packet surface whose generated status
must be reconciled by shared-system repair rather than by theorem rewriting.
