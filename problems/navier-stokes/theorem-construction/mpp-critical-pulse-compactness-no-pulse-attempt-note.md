# MPP Critical-Pulse Compactness No-Pulse Attempt Note

## Status

Bounded theorem attempt on `SOURCE.NO-PULSE.A`.

This note tests the compactness route: assume the no-pulse theorem fails,
rescale the active heat-scale pulses, and try to exclude the limiting critical
object.

The compactness extraction is route-compatible.  The exclusion is not installed.
The remaining theorem becomes a Liouville/depletion statement for the critical
pulse profile.

## Failure Sequence

Failure of the no-pulse atom may be expressed in any equivalent active packet.
Use the mixed-shell presentation:

```math
MSC.Spill.NoPulse
```

fails if there exist terminal shell indices `j_n\to\infty`, heat-scale
intervals

```math
I_n=[t_n-c2^{-2j_n},t_n],
```

and active packets for which

```math
c_\gamma\le\gamma_{j_n}(t)\le C_\gamma
\qquad\text{on a nontrivial part of }I_n,
```

while the mixed bilinear dissipation measure carries a fixed normalized amount
on the same windows.

Equivalently, in active-window language, the scale-critical source packet does
not become small on any terminal subtail.

## Rescaling

Let

```math
r_n:=2^{-j_n},
\qquad
v_n(y,s):=r_n\,u(x_n+r_n y,t_n+r_n^2s),
```

with pressure

```math
q_n(y,s):=r_n^2\,p(x_n+r_n y,t_n+r_n^2s).
```

On fixed backward cylinders, the Navier-Stokes equations are invariant:

```math
\partial_s v_n+v_n\cdot\nabla v_n+\nabla q_n-\nu\Delta v_n=0,
\qquad
\nabla\cdot v_n=0.
```

The active normalization gives a nonzero critical packet in the rescaled
sequence.  The compactness step would require the following uniform bounds on
each bounded pulled-back cylinder: local \(L^\infty_sL^2_x\) velocity control,
local \(L^2_s\dot H^1_x\) dissipation control, local \(L^{3/2}_{s,x}\) pressure
control, and the local energy inequality in the same-fluid/moving coordinates,
with constants depending only on the bounded distortion class.

Only after those bounds and the nonzero packet localization are proved can one
extract a subsequence converging in the local suitable weak sense to a
nontrivial ancient or backward-eternal local suitable object

```math
(v_\ast,q_\ast)
```

carrying the normalized pulse residue.

## What Would Close The Route

The compactness route would close if the repo had a theorem of the form:

```math
\textbf{Ancient.NoPulse:}
```

Every local suitable ancient limit generated by a terminal same-fluid
scale-critical source pulse, with the retained energy class and pressure
normalization inherited from `OriginalSmoothData`, has zero active source
residue.

In mixed-shell language this says:

```math
\gamma_\ast\,d\mu_\ast^\sigma=0
```

for the limiting spill-coefficient / mixed-dissipation defect pair.

In vorticity language it says the limit cannot carry a persistent positive
stretching packet

```math
\omega_\ast\cdot S_\ast\omega_\ast
```

at unit scale.

## Why The Current Inputs Do Not Exclude The Limit

The installed inputs give compactness and local suitability, but not a
Liouville theorem strong enough for this class.

The limit is not known to be:

```math
bounded,
\qquad
self-similar,
\qquad
Type\ I,
\qquad
axisymmetric,
\qquad
small in a critical norm.
```

Without one of those extra structural hypotheses, local suitable compactness only
turns failure of no-pulse into a nontrivial ancient critical object.  It does
not make that object impossible.

The CKN epsilon theorem also cannot be used backwards here.  The pulse is
precisely a failure of smallness of the scale-critical packet; CKN says small
packets are regular, not that every nonsmall ancient packet is impossible.

## Relation To `Jump_avg`

This compactness route is the blow-up version of the same obstruction already
seen in `Jump_avg`:

```math
Jump_{avg}
\quad\leadsto\quad
\text{no positive terminal SCF-good scale}
\quad\leadsto\quad
\text{nonzero scale-critical rescaled packet}.
```

Eliminating the branch by compactness therefore requires a genuine exclusion
of the nonzero rescaled packet.  That is exactly `Ancient.NoPulse`.

## Verdict

The compactness route does not discharge `SOURCE.NO-PULSE.A` from current
inputs.

It gives a clean alternate theorem target:

```math
\boxed{
Ancient.NoPulse:
\text{ exclude nontrivial same-fluid critical pulse limits.}
}
```

The follow-up rigidity audit `mpp-ancient-nopulse-rigidity-audit-note.md` shows
that this broad form is too strong: smooth nonzero ancient Navier-Stokes
profiles exist.  The only viable version is the source-residue theorem
`Ancient.NoPulse^{src}`.  That sharper target is equivalent at route level to
the active no-pulse atom and is not currently installed by the finite-energy,
local-suitability, pressure, or endpoint packages.

## May 1 Extraction Bridge Audit

The follow-up note
`mpp-ancient-nopulse-extraction-bridge-attempt-note.md` sharpens this compactness
route one step further.  Failure of `MSC.BadAC` is currently phrased using the
global dyadic shell-time measure

```math
\mathfrak B_N^\sigma(t)\,dt.
```

That object is not yet a spatial Radon measure on physical cylinders.  Therefore
the blow-up extraction also needs the carrier-tether form audited in

```math
MSC.Localize^{carrier}:
\quad
\neg MSC.BadAC
\Longrightarrow

```

The rigidity audit also shows that the carrier must preserve source residue,
not merely nonzero local energy.  Only after `MSC.Localize^{src}` is supplied
can the existing local compactness machinery extract the needed local suitable
ancient source-residue pulse limit.  The compactness route therefore has two
exact burdens:

```math
MSC.Localize^{src}
\quad\text{and}\quad
Ancient.NoPulse^{src}.
```

## May 1 Diagonal Carrier Audit

The follow-up notes `mpp-msc-localize-diagonal-carrier-attempt-note.md` and
`mpp-msc-diagtether-direct-attempt-note.md` sharpen the first burden again.
The global mixed-shell product `D_jD_\ell` localizes first to a double-space
carrier, not to one physical heat-scale cylinder.  Therefore `MSC.Localize^{src}`
requires a co-location theorem before compactness can start.

The direct diagonal attempt closes negatively from the installed estimates:
near-diagonal same-fluid mass is not forced by a global product of shell norms.
The viable compactness repair is:

```math
(DiagDom.A+Ancient.NoPulse^{src})
\quad\text{or}\quad
LocalSource.NoPulse.A.
```

This is a stricter dependency list than the original `Ancient.NoPulse` target:
ancient rigidity is only useful after `DiagDom.A` preserves physical
co-location and source residue through localization.  `LocalSource.NoPulse.A`
closes the no-pulse atom only if it proves zero retained source residue on the
selected pre-Cauchy packet family, without passing through ancient compactness.
