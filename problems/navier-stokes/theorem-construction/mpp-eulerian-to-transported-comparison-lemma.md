## Comparison Lemma

### Lemma EC-comparison

For every finite depth `N`, packet `\psi`, label increment `r`, and time `t`,

```math
\widetilde E_{N,r,\psi}(t)
\le
\widehat{\mathcal E}^{cmp}_{N,r,\psi}(t).
\tag{EC.4}
```

Equivalently,

```math
\widetilde E_{N,r,\psi}(t)
\le
\int_{\mathbf R^3}
\psi(a)^2
\sup_{\eta\in\mathcal R_r(t;\psi)}
\sum_{k=0}^{N}\lambda_k
\big|\delta_\eta U_k(X(a,t),t)\big|^2\,da.
\tag{EC.4a}
```

### Proof

By the exact bridge identity `(TB.11)`,

```math
\widetilde E_{N,r,\psi}(t)
=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}
\psi(a)^2
\big|
\delta_{h(a,r,t)}U_k(X(a,t),t)
\big|^2\,da.
\tag{EC.5}
```

For each fixed `a`, the increment `h(a,r,t)` belongs to `\mathcal R_r(t;\psi)`,
so the pointwise integrand is bounded by `\mathfrak e^{cmp}_{N,r,\psi}(a,t)`.
Integrating against `\psi(a)^2\,da` gives `(EC.4)`. ∎

## Geometric Bridge For The Transported Range

The packing side refines the geometry of `\mathcal R_r(t;\psi)`.

From `(TB.14)`--`(TB.18)`,

```math
h(a,r,t)=F(a,t)r+\varepsilon_h(a,r,t),
\tag{EC.6}
```

with the exact packetwise bound

```math
\int_{\mathbf R^3}\psi(a)^2\,|\varepsilon_h(a,r,t)|^2\,da
\le
|r|^2\,P_F^\ast(r,t;\psi).
\tag{EC.7}
```

So the transported range is not arbitrary. It is generated by the finite
packing image `F(a,t)r` plus the packetwise error `\varepsilon_h`.

This is the exact bridge from packing control to comparison control:

```math
\boxed{
P_F^\ast(r,t;\psi)\text{ small}
\Longrightarrow
\int_{\mathbf R^3}\psi(a)^2
|h(a,r,t)-F(a,t)r|^2\,da
\le
|r|^2P_F^\ast(r,t;\psi).
}
\tag{EC.8}
```

Meanwhile `A_F(t;\psi)` controls the size of the finite packing class itself:

```math
\boxed{
A_F(t;\psi)\text{ finite}
\Longrightarrow
F(a,t)\text{ stays inside a finite packetwise distortion class in the packetwise }L_a^2(\psi^2 da)\text{ sense.}
}
\tag{EC.9}
```

Taken together, `(EC.7)`--`(EC.9)` say that the increment family entering the
comparison object is generated by the packet's own finite packing class.

## Exact Immediate Closure Shape

The comparison lemma now gives the first exact immediate closure statement.

Fix `\rho>0` and a time interval `I`. Define

```math
\widehat{\mathcal E}^{cmp}_{N,\rho,\psi}(t)
:=
\sup_{0<|r|\le\rho}\widehat{\mathcal E}^{cmp}_{N,r,\psi}(t).
\tag{EC.10}
```

### Candidate Theorem EC-immediate-closure

Assume

```math
\sup_{t\in I}\widehat{\mathcal E}^{cmp}_{N,\rho,\psi}(t)<\infty.
\tag{EC.11}
```

Then

```math
\sup_{t\in I}\sup_{0<|r|\le\rho}\widetilde E_{N,r,\psi}(t)<\infty.
\tag{EC.12}
```

Likewise, if `\widehat{\mathcal E}^{cmp}_{N,\rho,\psi}(t)` is quantitatively
small as `\rho\downarrow 0`, then `\widetilde E_{N,r,\psi}(t)` inherits the
same transported smallness.

This is the exact bookkeeping repair. It restores correctness immediately, but
it does not yet turn the geometric bridge `(EC.6)`--`(EC.8)` into a quantitative
comparison theorem.
