## Exact Eulerian Pullback Identity

For every fixed Eulerian increment `\eta\in\mathbf R^3`,

```math
E_N(\eta,t;\psi)
=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}
\psi(a)^2
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2\,da.
\tag{EC.3}
```

Indeed, since `x=X(a,t)`, `\phi_t(X(a,t))=\psi(a)`, and `\det F(a,t)=1`,
changing variables in `(MP.6)` gives exactly `(EC.3)`.

This identity is the reason the comparison route is the right next theorem:
the Eulerian packet already pulls back to the material packet without losing
the PDE-native coercive structure.

## Comparison Lemma

### Lemma EC-comparison

For every finite depth `N`, packet `\psi`, label increment `r`, and time `t`,

```math
\widetilde E_{N,r,\psi}(t)
\le
\mathcal E^{cmp}_{N,r,\psi}(t).
\tag{EC.4}
```

Equivalently,

```math
\widetilde E_{N,r,\psi}(t)
\le
\sup_{\eta\in \mathcal R_r(t;\psi)} E_N(\eta,t;\psi).
\tag{EC.4a}
```

### Proof

By the exact bridge identity `(TB.11)`,

```math
\widetilde E_{N,r,\psi}(t)
=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}
\psi(a)^2
\big|
\delta_{h(a,r,t)}U_k(X(a,t),t)
\big|^2\,da.
\tag{EC.5}
```

For each `a`, the increment `h(a,r,t)` belongs to `\mathcal R_r(t;\psi)`, so
the integrand is bounded by the packetwise supremum over
`\eta\in\mathcal R_r(t;\psi)`. Using `(EC.3)` for that supremum gives
`(EC.4)`. ∎

## Geometric Bridge For The Transported Range

The packing side refines the geometry of `\mathcal R_r(t;\psi)`.

From `(TB.14)`--`(TB.18)`,

```math
h(a,r,t)=F(a,t)r+\varepsilon_h(a,r,t),
\tag{EC.6}
```

with the exact packetwise bound

```math
\int_{\mathbf R^3}\psi(a)^2\,|\varepsilon_h(a,r,t)|^2\,da
\le
|r|^2\,P_F^\ast(r,t;\psi).
\tag{EC.7}
```

So the transported range is not arbitrary. It is generated by the finite
packing image `F(a,t)r` plus the packetwise error `\varepsilon_h`.

This is the exact bridge from packing control to comparison control:

```math
\boxed{
P_F^\ast(r,t;\psi)\text{ small}
\Longrightarrow
h(a,r,t)\approx F(a,t)r
\text{ on the packet in }L_a^2(\psi^2 da).
}
\tag{EC.8}
```

Meanwhile `A_F(t;\psi)` controls the size of the finite packing class itself:

```math
\boxed{
A_F(t;\psi)\text{ finite}
\Longrightarrow
F(a,t)\text{ stays inside a finite packetwise distortion class.}
}
\tag{EC.9}
```

Taken together, `(EC.7)`--`(EC.9)` say that the increments on which the
Eulerian defect engine must be controlled are precisely the increments created
by the packet's own finite packing class.

## First Fused Closure Theorem Shape

The comparison lemma now gives the first honest fused closure theorem shape.

Fix `\rho>0` and a time interval `I`. Define the packet-generated Eulerian
range at time `t` by

```math
\mathcal R_\rho(t;\psi)
:=
\bigcup_{0<|r|\le\rho}\mathcal R_r(t;\psi).
\tag{EC.10}
```

### Candidate Theorem EC-fused-closure

Assume:

```math
\sup_{t\in I}\sup_{\eta\in\mathcal R_\rho(t;\psi)}E_N(\eta,t;\psi)<\infty,
\tag{EC.11}
```

```math
\sup_{t\in I}A_F(t;\psi)<\infty,
\tag{EC.12}
```

and

```math
\sup_{t\in I}\sup_{0<|r|\le\rho}P_F^\ast(r,t;\psi)<\infty.
\tag{EC.13}
```

Then

```math
\sup_{t\in I}\sup_{0<|r|\le\rho}\widetilde E_{N,r,\psi}(t)<\infty.
\tag{EC.14}
```

Moreover, if the Eulerian packet is quantitatively small on the packet-generated
range and `P_F^\ast(r,t;\psi)\to 0` as `r\to 0`, then
`\widetilde E_{N,r,\psi}(t)` inherits the same smallness as `r\to 0`.

The point is not that `(EC.11)`--`(EC.13)` close the whole route. The point is
that they put the fused closure theorem in the correct order:

```math
\mathcal Q_{1,r,\psi}^{str}
\Longrightarrow
P_F
\Longrightarrow
h(a,r,t)\approx F(a,t)r
\Longrightarrow
E_N\text{ controls }\widetilde E_{N,r,\psi}.
\tag{EC.15}
```

That is the first exact fused closure loop visible from the current stack.

## Why This Comes Before A Direct Transported Law

A direct transported propagation law for `\widetilde E_{N,r,\psi}` is real, but
it is a second-stage refinement.

If one differentiates `\widetilde E_{N,r,\psi}` directly, the same PDE-native
structure from the Eulerian defect law reappears after being pulled through:

1. the moving flow map `X`;
2. the deformation matrices `F` and `A`;
3. the transported increment `h(a,r,t)`;
4. the geometric commutators created by those coefficients.

That route should eventually be written out because it is more intrinsic.
But it is not the cleanest next theorem.

The comparison route is cleaner because it keeps the exact native Navier--Stokes
coercive structure on the Eulerian surface where it is already available, and
uses the packing bridge only to identify which Eulerian increments matter for
transported closure.
