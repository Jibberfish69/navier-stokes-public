## 0. Target

The low-response-strain route now needs:

```math
\boxed{
FiniteLowResponseControl.A.
}
```

For every fixed low cutoff `M` and compact positive-viscosity interval
`J=[nu_-,nu_+]Subset(0,infty)`, prove:

```math
\sup_{\nu\in J}
\int_W\|\nabla P_{\le M}\partial_\nu u^\nu(t)\|_{L^\infty}dt
<\infty
\tag{FLC.1}
```

on the preterminal smooth slabs used in the no-fold argument, with high
response leakage charged by `ResponseHeightCreationControl.A`.

## 1. Projected Response Equation

Let:

```math
z=\partial_\nu u,
\qquad
z_{\le M}:=P_{\le M}z.
```

Project:

```math
L_u z=\Delta u
```

to the finite-dimensional range of `P_{\le M}`:

```math
\partial_t z_{\le M}
=
A_M(t)z_{\le M}
+F_M(t)
+R_M^{hi}(t),
\tag{FLC.2}
```

where:

```text
A_M(t): finite matrix generated by interactions with retained low/collar u;
F_M(t): P_{\le M} Delta u plus finite commutator/cutoff terms;
R_M^{hi}(t): terms containing P_{>M}z or high-output leakage.
```

Since `M` is fixed, all norms on `Range(P_{\le M})` are equivalent:

```math
\|\nabla z_{\le M}\|_{L^\infty}
\le C_M\|z_{\le M}\|_2.
\tag{FLC.3}
```

## 2. High Leakage Is Legal

The full-coefficient response-height drain gives:

```math
ResponseHeightCreationControl.A.
```

Thus any contribution of `P_{>M}z` to the low finite system is either:

```text
1. inherited from past response height;
2. charged by ordinary Delta-u dissipation;
3. legal frame/cutoff leakage.
```

For fixed `M`, choose the response-height cutoff above `M` and absorb:

```math
\int_W\|R_M^{hi}(t)\|_2dt
\le C_M LegalResponseCharge(W).
\tag{FLC.4}
```

This is exactly why finite-low response control was separated from high
response-height creation.

## 3. Finite-Dimensional Gronwall

From `(FLC.2)`:

```math
\frac{d}{dt}\|z_{\le M}\|_2
\le
\|A_M(t)\|\|z_{\le M}\|_2
+\|F_M(t)\|_2
+\|R_M^{hi}(t)\|_2.
\tag{FLC.5}
```

On a compact positive-viscosity interval, retained finite modes of `u^\nu` are
smooth and finite on every preterminal slab.  Hence:

```math
\int_W\|A_M(t)\|dt<\infty,
\qquad
\int_W\|F_M(t)\|_2dt<\infty.
\tag{FLC.6}
```

The response initial datum is:

```math
z(0)=0.
```

Gronwall, `(FLC.4)`, and `(FLC.6)` give:

```math
\sup_{\nu\in J}\sup_{t\in W}\|z_{\le M}(t)\|_2
\le
C_{M,J,W}
+C_M LegalResponseCharge(W).
\tag{FLC.7}
```

Using `(FLC.3)` and integrating over `W` proves `(FLC.1)`.

on compact positive-viscosity preterminal slabs.
