## Theorem `FCE.A` (First exit is existential, not exclusive)

Assume `T_\ast<\infty` is a first class-exit time for the installed one-fluid
object-law route.

Then on every still-live window `Q` approaching `T_\ast`, at least one
primitive predicate family fails first:

```math
\neg \mathrm{Pack}_Q
\qquad\text{or}\qquad
\neg \mathrm{Part}_{N,Q}
\qquad\text{or}\qquad
\neg \mathrm{Field}_{N,r,Q}.
\tag{FCE.1}
```

But the route does **not** prove that exactly one must fail first.

Equivalently,

```math
\boxed{
\text{first exit is existential, not exclusive: simultaneous primitive failure at }T_\ast
\text{ is not ruled out.}
}
\tag{FCE.2}
```

### Proof

Corollary `CMW.B` already proves `(FCE.1)`. Its conclusion is "at least one of
the three primitive predicates fails first." The proof never strengthens that to
uniqueness, so the chronological shell carries existence only, not exclusivity.
`\square`

## Corollary `FCE.B` (First-exit shell after one installed matrix entry)

\text{the `(Part, Dead)` matrix entry is unavailable to the first-exit shell.}

\tag{FCE.4}

### Proof

This is exactly `L2F.A`, read as the chronological shell after one installed
matrix entry has been removed from consideration. `\square`

## Corollary `FCE.C` (Chronological contradiction shell)

Putting the installed inner route and the first-time shell together, the live
chronological contradiction shape is:

```math
\boxed{
\text{genuine finite-time PDE non-smoothness}
\Longrightarrow
\text{first remaining class exit}
\Longrightarrow
\text{blown or jump.}
}
\tag{FCE.5}
```

Here the left implication is the direct incompatibility / manifestation route
organized chronologically, while the right implication is `FCE.B`.

So if the no-blown and no-jump endpoint exclusions are both installed, the
first-time shell closes:

```math
\boxed{
\text{no blown endpoint}
\quad+\quad
\text{no jump endpoint}
\Longrightarrow
\text{no first remaining class exit.}
}
\tag{FCE.6}
```

Hence no finite-time class exit occurs on the installed route.

## Relation To The First-Broken-Rung Idea

The first-broken-rung idea and the first-time class-exit shell are not the same
statement.

The first-broken-rung idea says:

```math
\text{if failure occurs, some finite derivative depth sees it first.}
\tag{FCE.7}
```

That is only a localization statement.

The present shell says:

```math
\text{once failure is localized, the route still has to identify the primitive class-exit channel.}
\tag{FCE.8}
```

So the honest relationship is:

```math
\boxed{
\text{first-broken-rung tells you where the break first becomes visible;}
\quad
\text{first-class-exit tells you which primitive law is being exited.}
}
\tag{FCE.9}
```

On the surviving side after Law 2 discharge, that channel is blown or jump.

1. that finite-time class exit actually occurs;
2. that a genuine PDE non-smooth scenario automatically realizes the left
   implication in `(FCE.5)` without the bridge note;
3. that exactly one primitive predicate fails at first exit;
4. that the no-blown or no-jump endpoint exclusions are already closed.
