# Affine quotient transition square-packing and branch synthesis

The previous direct test found the missing bridge below

```text
AffineQuotientTransitionPayment.A.
```

The bridge was named

```text
AffineQuotientTransitionLocalization.A.
```

This note sharpens that bridge. The localization theorem is not one estimate.
It has three independent mathematical burdens:

```text
1. stopped square-packing for the transition expansion;
2. inherited-chamber signed-channel record/return payment;
3. reset-local affine-band-to-critical-jump carrier payment.
```

Only after all three are proved can record/return and critical reset be used to
pay the affine quotient.

## 1. The square-packing core

Let `P` be a retained stopped root. After the paid removals, the desired
linear localization has the form

```math
\mathcal C_\theta[\widetilde Z_P^{fresh}]
=
\sum_{e\in\mathscr E(P)}
\mathcal C_\theta[Z_e]
+
R_{legal}(P),
\tag{1}
```

where the transition edges split as

```math
\mathscr E(P)
=
\mathscr E_{rep}(P)\cup\mathscr E_{reset}(P).
\tag{2}
```

Here `rep` edges are inherited parent-state chambers and `reset` edges are
genuine fresh parent-child reset jumps.

The first missing theorem is not yet the branch payment. It is the square bound
that lets `(1)` enter the affine quotient norm:

```text
StoppedAffineQuotientTransitionSquarePacking.A.
```

Statement:

```math
\int H_w(t)
\left\|
\sum_{e\in\mathscr E(P)}
\mathcal C_\theta[Z_e](t)
\right\|_{L_x^2}^2dt
\le
C\sum_{e\in\mathscr E(P)}
\int H_w(t)\|\mathcal C_\theta[Z_e](t)\|_{L_x^2}^2dt
+R_{legal}(P).
\tag{3}
```

Equation `(3)` is the part that is not installed by laminarity alone.

## 2. Why laminar overlap alone fails

The laminar ancestry notes install structural support: the high-ratio family
must be carried as a laminar same-material ancestry forest, and repeated visits
on one ancestry line must spend deformation, frame motion, collar separation,
or annular turnstile variation.

But those notes still leave the global weighted reserve open. They identify the
wall as a finite weighted same-material ancestry reserve controlling

```math
\sum_{\ell\ge0}2^\ell\nu_\ell.
\tag{4}
```

That is support for `(3)`, not a proof of `(3)`.

The obstruction is elementary. On one laminar chain, take collinear pieces

```math
f_k=M^{-1/2}g,\qquad 1\le k\le M.
\tag{5}
```

Then

```math
\sum_{k=1}^M\|f_k\|_2^2=\|g\|_2^2,
\qquad
\left\|\sum_{k=1}^Mf_k\right\|_2^2=M\|g\|_2^2.
\tag{6}
```

So bounded overlap or laminar nesting does not square the affine transition
expansion. The theorem must manufacture one of:

```text
martingale difference cancellation,
Bessel orthogonality,
or a Bellman decrement.
```

The stopped-compensator synthesis points to the right direction: put visible,
silent, and exchange increments in a lift space before terminal positive
selection, prove a root square-function estimate, and then recover the scalar
selection readout. That is the correct species of proof for `(3)`.

## 3. Stopped martingale proof shape

The natural attempt is a stopped corona martingale argument.

For every transition edge `e=Q\to Q'`, write the localized affine transition
piece as

```math
\mathcal C_\theta[Z_e]
=
D_e+B_e.
\tag{7}
```

The intended roles are:

- `D_e`: the martingale or Bessel difference produced by a genuine change of
  selected material state;
- `B_e`: the predictable inherited component, routed to record/negative return.

The square-packing theorem should prove

```math
\int H_w
\left\|\sum_eD_e\right\|_{L_x^2}^2dt
\le
C\sum_e\int H_w\|D_e\|_{L_x^2}^2dt+R_{legal}(P),
\tag{8}
```

while the predictable part is not squared by laminar overlap. It is sent to the
record/return branch:

```math
\sum_e B_e
\leadsto
\sum_{\mathcal A\in\mathscr E_{rep}(P)}
\sum_{\kappa\in\mathcal K_N}
\left(
\operatorname{Rec}_\infty(\Psi_{\kappa,\mathcal A})
+V_-^{return}(\Psi_{\kappa,\mathcal A})
\right).
\tag{9}
```

This is the first better idea under the localization theorem: do not try to
estimate the full affine quotient as one positive source. Turn it into a stopped
martingale plus predictable return.

## 4. Inherited branch theorem

The inherited branch is not paid by the old one-channel theorem

```text
PrimitivePLSDriverToSignedCommutatorIdentity.A.
```

That wording is now stale. The repaired source says the primitive PLS driver is
a finite same-packet signed-channel decomposition:

```text
PrimitivePLSSignedChannelDecomposition.A.
```

So the inherited branch needs:

```text
InheritedAQRepToPrimitivePLSRecordReturn.A.
```

Statement:

```math
AQ_{rep}(P)
\le
C\int_{\mathcal F_{rep}(P)}
\sum_{\kappa\in\mathcal K_N}
\left(
\operatorname{Rec}_\infty(\Psi_{\kappa,\mathcal A})
+V_-^{return}(\Psi_{\kappa,\mathcal A})
\right)
d\mathcal R_{ancestry}(\mathcal A)
+R_{legal}(P).
\tag{10}
```

This theorem has two inputs:

```text
PrimitivePLSSignedChannelDecomposition.A
+
StoppedNegativeReturnOrientedPayment.A.
```

The first input identifies the localized affine repeated piece with the same
finite signed-channel family before positive projection. The second input
orients the negative Jordan part into bounded-multiplicity strain, selector,
collar, donor, order-lock, and legal payments.

Without those inputs, record/return is only a scalar BV shape. It is not yet a
payment for `AQ_rep(P)`.

## 5. Reset branch theorem

For genuine parent-child reset edges, the installed reset notes prove the
correct weight, not the proof. Raw reset distance fails the half-tail test.
The charge has to be critical-weighted:

```math
J_{crit}(Q\to Q')
\simeq
w(Q')\|\Delta Z_{Q\to Q'}^{fresh}\|_{\mathcal H_{raw}}^2
+J_{select/lock}^{crit}
+J_{collar/turn}^{crit}
+R_{legal}.
\tag{11}
```

The reset branch therefore needs:

```text
ResetLocalAffineBandToCriticalJumpCarrier.A.
```

Statement:

```math
\int H_w(t)
\|\mathcal C_\theta[\Delta Z_{Q\to Q'}^{fresh}](t)\|_{L_x^2}^2dt
\le
CJ_{crit}(Q\to Q')
+R_{legal}(Q).
\tag{12}
```

The global sum of `(12)` is the reset-facing form of

```text
LogScaleResetDerivativeCarrierBound.A.
```

The noncircular source of the weight must be original-history motion before
future selected-tail formation:

```math
\Delta Z_{Q\to Q'}^{fresh}
=
\int_{\log r(Q')}^{\log r(Q)}
\partial_\sigma Z(\sigma)d\sigma
+\mathrm{turnstile}_{Q\to Q'}
+\mathrm{exchange}_{Q\to Q'}
+R_{legal}.
\tag{13}
```

Then one must prove the selected-weight packing bound

```math
\sum_{Q,Q'}w(Q')
\|\Delta Z_{Q\to Q'}^{fresh}\|_{\mathcal H_{raw}}^2
\lesssim
\int_{\mathcal C(P)}
\left(
|\partial_\sigma Z|^2
+|\mathrm{turnstile}_\sigma|^2
+|\mathrm{exchange}_\sigma|^2
\right)d\sigma dt
+R_{legal}(P).
\tag{14}
```

Endpoint-to-jump wording is not installed as the reset bridge. The current
source-backed bridge is log-scale derivative, collar-turnstile, exchange, and
native-birth packing.
