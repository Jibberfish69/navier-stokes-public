# Announceable reset derivative representation: boundary

## 1. Target

The previous note proved the analytic active-weight estimate under the following
input: each strict fresh reset innovation has a parent-announced scale interval
and a derivative representation

```math
D_e
=
|I_e|^{-1}\int_{I_e}
(\partial_\sigma Z
+\operatorname{turnstile}_\sigma
+\operatorname{exchange}_\sigma
+\operatorname{covector}_\sigma)\,d\sigma
+Err_e^{legal},
\tag{1}
```

with bounded overlap of the witness intervals/tubes.

This note tests whether `(1)` follows from the bare fact that the edge is a
strict fresh reset.

## 2. Formal representation under a continuous stopped transition

Let \(q_e(\sigma,t)\) be the parent-known stopped selector/transition coordinate
whose change triggers the reset.  Suppose:

1. \(q_e\) is determined from the parent stopped history before positive child
   readout;
2. \(q_e\) is absolutely continuous in log scale \(\sigma\) along the same
   material history;
3. the strict reset edge is the first crossing of a stopped threshold by
   \(q_e\);
4. the child innovation is the endpoint difference of the transported stopped
   coefficient:

```math
D_e(t)=q_e(\sigma_1,t)-q_e(\sigma_0,t)+Err_e^{legal}(t),
\qquad I_e=[\sigma_0,\sigma_1].
\tag{2}
```

Then the fundamental theorem of calculus gives

```math
D_e(t)=\int_{I_e}\partial_\sigma q_e(\sigma,t)\,d\sigma+Err_e^{legal}(t).
\tag{3}
```

The derivative of the transported coefficient decomposes into the routed
same-material pieces:

```math
\partial_\sigma q_e
=
\partial_\sigma Z
+\operatorname{turnstile}_\sigma
+\operatorname{exchange}_\sigma
+\operatorname{covector}_\sigma
+Err^{legal}.
\tag{4}
```

Substituting `(4)` into `(3)` gives exactly the desired representation `(1)` up
to the harmless normalization by \(|I_e|\), depending on whether \(D_e\) is stored
as an endpoint difference or an interval average.

Thus the representation is valid under a stopped continuous first-crossing
model.

## 3. Bounded-overlap requirement

The Carleson summation also needs the witness intervals/tubes to pack:

```math
\sum_{e\subset P}1_{I_e\times T_e}(\sigma,t)
\le C_N+R_{legal}
\tag{5}
```

or more generally

```math
\sum_{e\subset P}\int_{I_e\times T_e} F
\le C_N\int_{\operatorname{Hist}(P)}F+R_{legal}(P)
\tag{6}
```

for nonnegative \(F\).  This follows if resets are chosen as maximal first-exit
intervals in a laminar stopped tree, because distinct reset witnesses are either
disjoint or nested with a geometric scale drop/legal stop.  It does not follow
from reset existence alone.

## 4. Direct obstruction

A strict fresh reset only says the stopped carrier/selector/order datum changes:

```math
\mathfrak R(Q')\ne \mathfrak R(Q).
```

That does not by itself provide:

1. a parent-known transition coordinate \(q_e\);
2. absolute continuity in log scale;
3. a first-crossing time announced from the parent side;
4. an endpoint-difference identity for the child innovation;
5. bounded overlap of the corresponding witness intervals.

Without those structures, a reset can still be an after-the-fact child selection.
Then the derivative identity `(1)` is not meaningful and the active-weight
Cauchy reduction cannot be applied.

## 5. Exact missing theorem pair

The remaining producer is therefore not an analytic inequality.  It is a stopped
selector geometry theorem:

```text
StoppedSelectorTransitionAbsoluteContinuity.A / AnnounceableResetStoppingTime.A
```

Statement:

Every strict fresh reset retained by the stopped selector is generated by a
parent-known absolutely continuous transition coordinate and occurs as a first
crossing/exit event, so the child innovation is an endpoint difference along the
same material history.

The second required theorem is the packing statement:

```text
ResetWitnessIntervalBoundedOverlap.A / ResetSparsePackingFromOriginalHistory.A
```

Statement:

The witness intervals/tubes associated to strict reset first crossings have
bounded overlap or Carleson sparse packing in original-history measure.

Together they imply `AnnounceableResetDerivativeRepresentation.A`.

## 6. Conditional implication

If the two missing theorems hold, then every strict reset edge has `(1)` and
`(5)`.  The previous Cauchy reduction then gives

```math
\sum_{e\subset P}\int H_{I_e}(t)\|D_e(t)\|^2\,dt
\le
C_N\int_{\operatorname{Hist}(P)}
w\left(
|\partial_\sigma Z|^2
+|\operatorname{turnstile}_\sigma|^2
+|\operatorname{exchange}_\sigma|^2
+|\operatorname{covector}_\sigma|^2
\right)
+CR_{legal}(P).
```

So the reset active-weight branch would close.

## 7. Result

`AnnounceableResetDerivativeRepresentation.A` is not proved from the bare reset
condition.  It reduces to two precise stopped-selector geometry obligations:

```math
\boxed{\text{StoppedSelectorTransitionAbsoluteContinuity.A / AnnounceableResetStoppingTime.A}}
```

and

```math
\boxed{\text{ResetWitnessIntervalBoundedOverlap.A / ResetSparsePackingFromOriginalHistory.A}.}
```

The active-weight analytic obstruction is now understood; the remaining hard
work is to make strict resets genuinely announceable first-crossing events with
bounded overlap in the original same-material history.
