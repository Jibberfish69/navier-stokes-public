# Annular Payback Physical Frame Completion Boundary

Date: 2026-06-25

## 0. Object

The object is one original smooth incompressible Navier--Stokes material
history on the periodic surface:

```math
\partial_tu+(u\cdot\nabla)u+\nabla p=\nu\Delta u,
\qquad
\nabla\cdot u=0.
\tag{APB.1}
```

The material map satisfies

```math
\dot X(a,t)=u(X(a,t),t),
\qquad
\det D_aX(a,t)=1.
\tag{APB.2}
```

The center spike, transported annular layers, pressure response,
incompressibility constraint, viscous stress, nonlinear frequency transfer, and
later stress/strain return are readings of this one history.  Heat-scale
windows are samples of that history, not independent packet events.

## 1. What the physical picture proves exactly

Let \(\phi\) be a transported annular cutoff:

```math
(\partial_t+u\cdot\nabla)\phi=0.
\tag{APB.3}
```

With

```math
T=-pI+2\nu S,
\qquad
S={\nabla u+\nabla u^\top\over2},
\tag{APB.4}
```

the exact transported local energy identity is

```math
{d\over dt}\int {1\over2}|u|^2\phi\,dx
+
2\nu\int\phi |S|^2\,dx
=
-\int u\cdot T\nabla\phi\,dx.
\tag{APB.5}
```

This proves attachment: a center storage change is a same-fluid annular
stress/strain transaction before any terminal limit is taken.

After gauge reduction, the annular stress-work flux has the form

```math
F_\phi^\sharp(t)
=
\int U_iT^\sharp_{ij}\partial_j\phi\,dx,
\qquad
T^\sharp=-PI+2\nu S(U),
\qquad
D_tU=\nabla\cdot T^\sharp.
\tag{APB.6}
```

Its derivative is generated by the same packet:

```math
\begin{aligned}
{d\over dt}F_\phi^\sharp
= {}&
\int(\nabla\cdot T^\sharp)_iT^\sharp_{ij}\partial_j\phi\,dx\\
&+
\int U_i(D_tT^\sharp_{ij})\partial_j\phi\,dx\\
&-
\int U_iT^\sharp_{ij}(\partial_jU_k)(\partial_k\phi)\,dx .
\end{aligned}
\tag{APB.7}
```

Thus the annular return is not a free signal.  It is pressure, viscosity,
incompressibility, and velocity acting through one transported material
history.

## 2. Fixed annulus consequence

For one transported annulus, the installed bounded-record lemma gives:

```math
\sup_{t\in I}\mathcal P_N^{mat}(t)\le K,
\qquad
\int_I\mathcal S_N^{mat}(t)\,dt<\infty
\tag{APB.8}
```

implies

```math
\operatorname{Var}_I F_\phi^\sharp
=
\int_I |(F_\phi^\sharp)'(t)|\,dt
\le
C_{\phi,N}(K)
\left(
|I|+\int_I\mathcal S_N^{mat}(t)\,dt
\right).
\tag{APB.9}
```

So the physical payback picture proves:

```math
\text{bounded same-material record and service}
\Longrightarrow
\text{finite rectified annular force-action variation}.
\tag{APB.10}
```

This is the exact mathematical content of the later-annulus return once the
same material history is retained.

```math

\Longrightarrow

\tag{APB.11}
```

where \(d\Omega_N^{full}\) contains positive material-record variation and
positive annular pressure/strain service:

```math

\supset
C_N\,d[\log(1+\mathcal P_N^{mat})]_+
+
\sum_j2^{\gamma j}
\|\Delta_j\mathcal S_\phi^\sharp(t)\|_{L^1_x}\,dt.
\tag{APB.12}
```

Finite energy, finite raw viscous dissipation, smooth initial frequency tails,

```math

\qquad

\tag{APB.13}
```

```math

\tag{APB.14}
```

```math

\tag{APB.15}
```

This calculation is on the same material history.  It is not a detached packet
model.  It shows that physical attachment and raw energy accounting do not
remove the unweighted terminal clock by themselves.
