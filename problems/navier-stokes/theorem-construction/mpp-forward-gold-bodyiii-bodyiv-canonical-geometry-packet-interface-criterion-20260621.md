# Body-III / Body-IV Canonical Geometry Packet Interface Criterion

Date: 2026-06-21

## 0. Aim

The \(C\to G\) interface is the passage from compactness/no-loss to
gradient/deformation geometry.

Body III produces an Eulerian limiting packet:

```math
\mathcal P_*.
\tag{CGI.1}
```

Body IV consumes a material geometry packet built from a flow map and its
deformation coefficients:

```math
X(a,t),
\qquad
F=D_aX,
\qquad
A=F^{-1},
\qquad
G=AA^\top.
\tag{CGI.2}
```

The interface is exact only when these are the same four-body packet after the
material pullback and the same gauge, packet labels, cutoffs, and derivative
rungs are retained.

This note proves the interface criterion:

```math
\boxed{
\text{canonical Eulerian packet}
+
\text{volume-preserving material geometry realization}
\Longrightarrow
\text{same }C\to G\text{ exchange current.}
}
\tag{CGI.3}
```

It does not prove that a terminal Navier-Stokes compactness limit always
supplies the required material geometry realization.

## 1. Eulerian packet from Body III

Let \(X_E=(U,\Pi)\) be the limiting velocity-pressure tower profile on an
Eulerian selected carrier \(C_E\).

Body III closes its own no-loss relay when

```math
\mathcal P_*=\mathcal P_E[U,\Pi],
\tag{CGI.4}
```

where

```math
\mathcal P_E[U,\Pi]
=
\left(
dL_E,\ dD_E,\ dA_E,\ dJ_E,\ d\widetilde J_E,\ dR_E
\right)
\tag{CGI.5}
```

is the canonical Eulerian four-body packet computed from the same limiting
velocity-pressure tower.

Failure of `(CGI.4)` is already Body-III no-loss relay failure:

```math
\mathcal K_C=\mathcal P_*-\mathcal P_E[U,\Pi],
\qquad
dK_C^+=(d\mathcal E_C)^+.
\tag{CGI.6}
```

The \(C\to G\) interface begins after `(CGI.4)` has been either proved or
charged.

## 2. Geometry realization consumed by Body IV

Body IV requires a material carrier \(C_G\) and a material map

```math
\Xi:C_G\to C_E,
\qquad
\Xi(a,t)=(X(a,t),t),
\tag{CGI.7}
```

generated by the limiting velocity field:

```math
\partial_tX(a,t)=U(X(a,t),t).
\tag{CGI.8}
```

Set

```math
F=D_aX,
\qquad
A=F^{-1},
\qquad
G=AA^\top.
\tag{CGI.9}
```

Incompressibility gives the exact Jacobian identity

```math
\det F(a,t)=1.
\tag{CGI.10}
```

Thus, whenever the material map is defined with enough regularity on the
selected packet,

```math
\int_{\Xi(E)} \phi(x,t)\,dx\,dt
=
\int_E \phi(X(a,t),t)\,da\,dt
\tag{CGI.11}
```

for every measurable \(E\subset C_G\) and every integrable packet density
\(\phi\).  This is the exact volume-preserving bridge from the Eulerian packet
to the material geometry packet.

## 3. Pullback of packet measures

For any signed or nonnegative Eulerian packet measure

```math
d\nu_E=\phi_E(x,t)\,dx\,dt\,\delta_\lambda
\tag{CGI.12}
```

on a fixed packet label \(\lambda\), define its material pullback by

```math
d\nu_G
:=
\Xi^\sharp d\nu_E
=
\phi_E(X(a,t),t)\,da\,dt\,\delta_\lambda.
\tag{CGI.13}
```

The same definition applies componentwise to \(\mathcal P_E[U,\Pi]\):

```math
\Xi^\sharp \mathcal P_E[U,\Pi]
=
\left(
\Xi^\sharp dL_E,\ \Xi^\sharp dD_E,\ \Xi^\sharp dA_E,\ 
\Xi^\sharp dJ_E,\ \Xi^\sharp d\widetilde J_E,\ \Xi^\sharp dR_E
\right).
\tag{CGI.14}
```

The canonical Body-IV packet is the material packet computed from
\((v,q,A,G)\), where

```math
v(a,t)=U(X(a,t),t),
\qquad
q(a,t)=\Pi(X(a,t),t).
\tag{CGI.15}
```

Write it as

```math
\mathcal P_G[v,q,A,G].
\tag{CGI.16}
```

The \(C\to G\) interface condition is exactly

```math
\boxed{
\mathcal P_G[v,q,A,G]
=
\Xi^\sharp \mathcal P_E[U,\Pi]
}
\tag{CGI.17}
```

on the same packet labels, cutoffs, selected rungs, and gauge choices.

## 4. Exact interface identity

Assume `(CGI.4)` and `(CGI.17)`.

Then the current leaving Body III is the same signed measure as the current
entering Body IV after the carrier map \(\Xi\):

```math
\boxed{
dJ_G^{\rm in}
=
\Xi^\sharp dJ_C^{\rm out}.
}
\tag{CGI.18}
```

Equivalently, after transporting both currents to the common selected
four-body carrier,

```math
\boxed{
dK_{C\to G}=0.
}
\tag{CGI.19}
```

### Proof

By `(CGI.4)`, the weak Body-III packet is the canonical Eulerian packet.
By `(CGI.17)`, the Body-IV material packet is exactly the pullback of that
canonical Eulerian packet.  Since all packet labels, rungs, cutoffs, and gauge
choices are the same, the exchange-current component also pulls back exactly.
The equality `(CGI.18)` follows componentwise from `(CGI.13)` and
the volume-preserving identity `(CGI.11)`.  After both sides are regarded as
measures on the common selected four-body carrier, this is `(CGI.19)`.

## 5. Defect decomposition

When the interface condition fails, define

```math
\mathcal K_{C\to G}
:=
\mathcal P_G[v,q,A,G]-\Xi^\sharp\mathcal P_E[U,\Pi].
\tag{CGI.20}
```

The positive orientation defect contributed by this interface is

```math
\boxed{
K_{C\to G}^+
\le
K_C^+
+
K_{\rm geom,map}^+
+
K_{\rm geom,gauge}^+
+
K_{\rm geom,coef}^+
+
R_{\rm legal}.
}
\tag{CGI.21}
```

The components mean the following.

First, if `(CGI.4)` fails, the mismatch is already \(K_C^+\).

Second, if the material map \(\Xi\) is absent, nonunique, or not regular enough
to define the pullback packet on the retained carrier, the failure is

```math
K_{\rm geom,map}^+.
\tag{CGI.22}
```

Third, if the Eulerian packet and material packet use different gauges,
cutoffs, labels, projections, or rung families, the failure is

```math
K_{\rm geom,gauge}^+.
\tag{CGI.23}
```

Fourth, if the pulled-back coefficients \(A,G\) or their finite tower
commutators are not retained with the strength Body IV needs, the failure is

```math
K_{\rm geom,coef}^+.
\tag{CGI.24}
```

These geometry failures are components of the Body-IV geometry defect \(K_G^+\)
unless the failure has already been charged to the Body-III relay defect
\(K_C^+\).

## 6. Relation to deformation action

This interface theorem does not turn deformation geometry into a new
unweighted reserve supplier.

The deformation path-action note proves that deformation action is the same
critical currency in geometry language:

```math
\text{same-carrier deformation action}
\Longrightarrow
\text{selected critical-strain/source-square reserve}.
\tag{CGI.25}
```

The reverse production remains the gold wall:

```math
\text{current inputs do not prove}
\quad
\text{finite physical energy/local energy}
\Longrightarrow
\text{same-carrier deformation action}.
\tag{CGI.26}
```

Thus \(C\to G\) is a handoff theorem, not a standalone payment theorem.  It
prevents compactness from producing a ghost Eulerian object that Body IV cannot
consume.

## 7. Four-body consequence

The \(C\to G\) interface closes when all of the following hold:

```math
\boxed{
\mathcal P_*=\mathcal P_E[U,\Pi]
\quad
\text{or the mismatch is charged to }K_C^+;
}
\tag{CGI.27}
```

```math
\boxed{
\Xi(a,t)=(X(a,t),t),\quad \det D_aX=1,
\quad
\text{exists on the same selected carrier;}
}
\tag{CGI.28}
```

and

```math
\boxed{
\mathcal P_G[v,q,A,G]
=
\Xi^\sharp\mathcal P_E[U,\Pi]
\quad
\text{or the mismatch is charged to }K_G^+.
}
\tag{CGI.29}
```

In a lossless same-carrier branch,

```math
K_C^+=0,
\qquad
K_G^+=0,
\qquad
R_{\rm legal}=0,
\tag{CGI.30}
```

so

```math
\boxed{
dK_{C\to G}=0.
}
\tag{CGI.31}
```

The compact packet and the geometry packet are then the same object written in
Eulerian and material coordinates.

## 8. Current state

This note proves the exact \(C\to G\) accounting criterion:

```math
\boxed{
\text{canonical Eulerian compact packet plus admissible material geometry
realization implies exact compactness-to-geometry exchange.}
}
\tag{CGI.32}
```

It does not prove the Navier-Stokes production theorem that every terminal
compactness limit has enough material regularity, gauge persistence, coefficient
control, and same-carrier label retention to make \(K_{\rm geom,map}^+\),
\(K_{\rm geom,gauge}^+\), and \(K_{\rm geom,coef}^+\) vanish.

The remaining four-body work after this note is the actual geometry production
and return problem: prove that the material geometry packet exists on the
selected terminal carrier and then recertifies the next Body-I tower packet, or
charge the failure in \(K_G^+\).
