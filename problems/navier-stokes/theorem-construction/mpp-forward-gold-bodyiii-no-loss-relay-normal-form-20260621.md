# Body III No-Loss Relay Normal Form

Date: 2026-06-21

## 0. Aim

Body III in the upgraded four-body loop is:

```math
\text{compactness/no-loss}.
\tag{BNR.1}
```

Its job is not to create a new payment.  Its job is to relay the same
four-body packet through compactness without losing the terms that made the
loop balanced.

The exact distinction is:

```math
\boxed{
\text{weak compactness of the packet is cheap;}
}
\tag{BNR.2}
```

while

```math
\boxed{
\text{identifying the weak packet with the packet of the limiting
Navier-Stokes profile is the no-loss theorem.}
}
\tag{BNR.3}
```

This note proves the measure-level relay form and names the exact defect when
the identification fails.

## 1. Four-body packet measures

Let \(K\) be a compact time or log-scale interval.  For each \(n\), suppose a
selected four-body packet carries finite Radon measures

```math
\mathcal P_n
=
\left(
dL_n,\ dD_n,\ dA_n,\ dJ_n,\ d\widetilde J_n,\ dR_n
\right)
\tag{BNR.4}
```

where \(dL_n,dJ_n,d\widetilde J_n\) are signed and
\(dD_n,dA_n,dR_n\) are nonnegative.

Assume the packet satisfies the body inequality

```math
dL_n+dD_n+dA_n+dJ_n
\le
d\widetilde J_n+dR_n
\tag{BNR.5}
```

as signed measures on \(K\).

Assume uniform total variation bounds:

```math
\sup_n
\left(
|dL_n|(K)+dD_n(K)+dA_n(K)+|dJ_n|(K)
+|d\widetilde J_n|(K)+dR_n(K)
\right)
<\infty.
\tag{BNR.6}
```

Then, after passing to a subsequence,

```math
dL_n \stackrel{*}{\rightharpoonup} dL_*,
\qquad
dD_n \stackrel{*}{\rightharpoonup} dD_*,
\qquad
dA_n \stackrel{*}{\rightharpoonup} dA_*,
\tag{BNR.7}
```

and similarly

```math
dJ_n \stackrel{*}{\rightharpoonup} dJ_*,
\qquad
d\widetilde J_n \stackrel{*}{\rightharpoonup} d\widetilde J_*,
\qquad
dR_n \stackrel{*}{\rightharpoonup} dR_*.
\tag{BNR.8}
```

The nonnegative limits \(dD_*,dA_*,dR_*\) are nonnegative measures.

## 2. Inequality passes to the weak packet

For every nonnegative \(\varphi\in C(K)\), `(BNR.5)` gives

```math
\int\varphi\,dL_n
+
\int\varphi\,dD_n
+
\int\varphi\,dA_n
+
\int\varphi\,dJ_n
\le
\int\varphi\,d\widetilde J_n
+
\int\varphi\,dR_n.
\tag{BNR.9}
```

Passing to the weak-star limit gives

```math
\int\varphi\,dL_*
+
\int\varphi\,dD_*
+
\int\varphi\,dA_*
+
\int\varphi\,dJ_*
\le
\int\varphi\,d\widetilde J_*
+
\int\varphi\,dR_*.
\tag{BNR.10}
```

Since this holds for every nonnegative continuous \(\varphi\),

```math
\boxed{
dL_*+dD_*+dA_*+dJ_*
\le
d\widetilde J_*+dR_*.
}
\tag{BNR.11}
```

Thus compactness relays the inequality to the weak packet.

This is not yet the Navier-Stokes no-loss theorem.  It only says the measure
ledger has a weak limit.

## 3. Canonical packet of the limiting profile

Suppose the underlying normalized solutions converge, in whatever topology has
actually been proved, to a limiting profile \((U,P)\).

The limiting profile has its own canonical four-body packet:

```math
\mathcal P[U,P]
=
\left(
dL[U],\ dD[U],\ dA[U],\ dJ[U],\ d\widetilde J[U],\ dR[U]
\right).
\tag{BNR.12}
```

For example:

```math
dD[U]
\quad
\text{is the dissipation/tower-loss measure computed from }U,
\tag{BNR.13}
```

```math
dJ[U]
\quad
\text{is the pressure-transport-viscous trace current computed from }(U,P),
\tag{BNR.14}
```

and

```math
dA[U]
\quad
\text{is the selected positive carrier computed after the same selection rule.}
\tag{BNR.15}
```

Body III closes only when the weak packet equals this canonical packet:

```math
\boxed{
\mathcal P_*=\mathcal P[U,P].
}
\tag{BNR.16}
```

This is the no-loss relay condition.

## 4. Relay defect

Define the Body-III relay defect componentwise:

```math
\mathcal K_C
=
\mathcal P_*-\mathcal P[U,P].
\tag{BNR.17}
```

Equivalently,

```math
\mathcal K_C
=
\left(
dK_L,\ dK_D,\ dK_A,\ dK_J,\ dK_{\widetilde J},\ dK_R
\right),
\tag{BNR.18}
```

where

```math
dK_A=dA_*-dA[U],
\qquad
dK_D=dD_*-dD[U],
\qquad
dK_J=dJ_*-dJ[U],
\tag{BNR.19}
```

and similarly for the remaining components.

The defect may contain:

```math
\boxed{
\text{lost pressure trace;}
}
\tag{BNR.20}
```

```math
\boxed{
\text{lost selected positive source carrier;}
}
\tag{BNR.21}
```

```math
\boxed{
\text{lost tower-radius or high-rung tail information;}
}
\tag{BNR.22}
```

```math
\boxed{
\text{lost orientation/polar data from positive selection;}
}
\tag{BNR.23}
```

or

```math
\boxed{
\text{lost nonlinear product information, such as }
V_n\otimes V_n\not\to U\otimes U.
}
\tag{BNR.24}
```

These are not separate new routes.  They are the exact ways Body III can fail to
relay the same four-body packet.

## 5. Limit inequality with relay defect

The weak packet satisfies `(BNR.11)`.  Substituting
\(\mathcal P_*=\mathcal P[U,P]+\mathcal K_C\) gives

```math
dL[U]+dD[U]+dA[U]+dJ[U]
\le
d\widetilde J[U]+dR[U]+d\mathcal E_C,
\tag{BNR.25}
```

where the signed relay error is

```math
d\mathcal E_C
=
dK_{\widetilde J}
+
dK_R
-
dK_L
-
dK_D
-
dK_A
-
dK_J.
\tag{BNR.26}
```

The spendable obstruction is its positive part:

```math
\boxed{
dK_C^{+}:=(d\mathcal E_C)^+.
}
\tag{BNR.27}
```

Therefore Body III has the exact alternatives:

```math
\boxed{
dK_C^+=0
\quad\Longrightarrow\quad
\text{the limiting profile inherits the same body inequality;}
}
\tag{BNR.28}
```

or

```math
\boxed{
dK_C^+>0
\quad\Longrightarrow\quad
\text{compactness/no-loss has produced a charged relay defect.}
}
\tag{BNR.29}
```

At a terminal endpoint \(\tau\), the same statement reads

```math
\boxed{
K_C^+(\{\tau\})>0
\quad
\text{is exactly terminal compactness/no-loss failure.}
}
\tag{BNR.30}
```

## 6. Four-body meaning

In the upgraded four-body program, Body III is the arrow

```math
\text{participation}
\to
\text{compactness/no-loss}.
\tag{BNR.31}
```

The exact Body-III theorem needed for closure is:

```math
\boxed{
\text{the weak packet produced from the selected same-carrier Navier-Stokes
sequence equals the canonical packet of the limiting profile,}
}
\tag{BNR.32}
```

or else

```math
\boxed{
\text{the mismatch }dK_C^+\text{ is retained as a legal compactness/no-loss
payment.}
}
\tag{BNR.33}
```

This is the precise meaning of "no hidden loss" in the four-body loop.

It is stronger than extracting an ancient profile and weaker than proving
regularity.  It only asks that whatever compact object is produced still carries
the same tower, pressure, source, orientation, and activity records that entered
Body III.

```math
\boxed{

}
\tag{BNR.34}
```

The Navier-Stokes no-loss identification is not installed:

```math
\boxed{
\mathcal P_*=\mathcal P[U,P]
\quad
\text{or}
\quad
dK_C^+\text{ legal/summable.}
}
\tag{BNR.35}
```

That is the Body-III production theorem still needed by the upgraded four-body
