# E4 delamination: the record passes as geometry, but ownership can still fail

## 1. Gate being tested

signed density can pass weakly. It can. The question is whether the positive

```math

\quad\Longrightarrow\quad

\text{ with the same parent source address.}
\tag{DL.1}
```

The allowed direct proof note already states the gap: weak-star compactness of
defect measures does not give `(DL.1)` unless the record functional is lower
semicontinuous and the selected source address remains the same.

## 2. What is installed

The signed-height record note installs the scalar work and the finite-truncation
native menu identity. Before record selection, the scalar work decomposes as

```math

=
\sum_{e\in{\mathcal E}_P(t)}\omega_e(t)\,dt
+dLegal_P+dStop_P.
\tag{DL.2}
```

For a record interval \([a,b]\), this gives the native admission row

```math

\left[\int_{I_e\cap[a,b]}\omega_e\right]_+
+Legal([a,b])+Stop([a,b]).
\tag{DL.3}
```

Each edge has a same-fluid address: high packet, low coefficient/current,
material time coordinate, and parent charge coordinate. This is real progress:
the scalar record is no longer a nameless time integral.

The missing entrance theorem is that every future-positive record-menu edge

stored parent reserve see only one coordinate, while future record intervals

statement are both true, but not for the same parent edge.

Second, in the frozen-symbol form, choose an amplitude \(z\) in the joint
detector nullspace:

```math

\qquad

\tag{DL.9}
```

is invisible to the parent detectors that the known storage rows use. That is
not a Navier-Stokes counterexample. It is the exact logical obstruction to
