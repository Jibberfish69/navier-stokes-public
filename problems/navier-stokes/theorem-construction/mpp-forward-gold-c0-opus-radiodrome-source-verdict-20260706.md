# Source verdict on the Opus radiodrome handoff

## 1. What the handoff contributes

The Opus radiodrome handoff is useful as a definition. It keeps the object at
the right altitude: one same-fluid Navier-Stokes field read up its participation
tower. The radiodrome coordinate is the unpaid tower-relay defect, not a local
pressure-Hessian angle and not a detached pursuit gadget.

The canonical definition also gives the right analytic translation of the
remaining rigidity clause:

```math
\nu\int|\nabla\delta|^2
\hbox{Field/four-body surplus}
\ge
(1+2\varepsilon)\,\mathrm{Prod}(\delta),
\qquad
c_0=2\varepsilon .
```

This is exactly the strict same-field tower-relay capture margin. It is the
same object as the theta-clock route-b profile theorem in the active c_0 file.

## 2. What it does not contribute

The handoff does not install the strict margin. The ratio-one heat-scale relay
is a surplus-zero object: viscosity, Field motion, and four-body exchange can be
nonzero while their scale-covariant surplus is zero. A zero-surplus profile is
not an absolute-zero profile, so the zero-bill kernel cannot be applied to it
without an additional coercivity theorem.

Physically, the same packet can keep paying the covariant fare while never
posting extra fare. That is the equality-speed pursuit picture. Radiodrome
detects this marginal profile; it does not forbid it.

## 3. Supersession check

The older `GOAL-item6` terminus says the lane has reduced to a single
cancellation defect and uses the claim that Gate2 pawl pricing is proved. That
claim is no longer current. The item2 file has been regraded:

adjacent exchange identities do not retain positive total record. A two-leg
signed cycle has signed sum zero but positive total record. Thus Gate2 still
needs a pre-readout positive carrier, negative partner, and signed current on
the same selected channel, or a strict route-b theorem that excludes the
theta-clock marginal profile.

Opus's radiodrome note should be carried forward as a correct coordinate and
bad-sequence detector for `c_0`. It should not be carried forward as a proof of

refutation of that theorem.

can sustain positive normalized theta-clock service with all same-packet surplus
