# Parent-owned positive record: lower entrance source verdict

## 1. Tested proof route

The active failed-gate certificate names the current Gate2 repair theorem:

```math
\texttt{ParentOwnedPositiveRecordBillCurrency.A}.
```

The tempting proof from the allowed signed-height source is:

1. use the finite native work menu to preannounce all possible record work;
2. use the frozen detector-angle algebra to put positive work into parent
   root/full-exchange currency;
3. conclude that every future positive record is parent-owned and billed.

This would be enough for normalized passage, because a unit record with
\(B(W_j)\to0\) could no longer exist.

The allowed source does not prove this route.

## 2. What the menu identity proves

The signed-height source proves the finite-truncation native menu identity:

```math
P(t)\,dt
=
\sum_{e\in\mathcal E_P(t)}
\omega_e(t)\,dt
+dLegal_P+dStop_P .
\tag{LEM.1}
```

Each edge is a same-fluid address: retained high packet, low strain/current
coefficient from the same velocity field, material time coordinate, and parent
charge coordinate.

For one record interval \([a,b]\), this yields:

```math
\lambda
\le
\sum_e
\left[
\int_{I_e\cap[a,b]}\omega_e
\right]_+
+Legal([a,b])+Stop([a,b]).
\tag{LEM.2}
```

This proves menu origin and one-record admission. It does not prove storage of
all future positive selections from the menu.

## 3. First failed clause: future-positive selection storage

The missing estimate is:

```math
\sum_j\lambda_j^{-1}
\sum_e
\left[
\int_{I_e\cap[a_j,b_j]}\omega_e
\right]_+
\le
C_N(u_0)+Paid+Legal+Stop .
\tag{LEM.3}
```

or, in the active c_0 bill currency,

```math
\sum_j
R_j^{menu,+}
\le
C\int_{\cup_j W_j}
\left(
dE^{Field}+dA_{4B}+dVisc
\right)
+Legal+Stop .
\tag{LEM.4}
```

The source explicitly leaves `(LEM.3)' open. The obstruction is the familiar
same-parent size problem: a menu edge can have a correct same-fluid origin while
future record intervals keep selecting positive work from an unbudgeted part of
the menu.

Thus the first lower failed clause is:

```math
\texttt{RecordNativeWorkMenuPositiveSelectionStorage.A}.
\tag{LEM.5}
```

## 4. Why frozen detector algebra is not enough

The source then lowers menu storage to detector faithfulness. After one retained
packet, one frequency direction, and one menu edge are frozen, the finite
amplitude space \(V\) has detector map

```math
D z=(m_{root}z,m_{FE}z)
\tag{LEM.6}
```

and record functional \(w_{rec}z\). On that frozen quotient,

```math
[w_{rec}z]_+\le C|Dz|
\quad\Longleftrightarrow\quad
\ker D\subseteq\ker w_{rec}.
\tag{LEM.7}
```

This is real linear algebra. It is still not a proof of the retained edge
theorem, because the source adds two required lifts.

First, the frozen work edge must be split into pressure-active and
joint-detector-silent parts. The pressure-active part is governed by the
detector angle. The joint-detector-silent part must already be paid before
record readout by same-material service, legal exit, or stop.

Second, the exact weighted root/Hodge projector does not preserve the raw
Littlewood-Paley shell. The commutator and moving-chart residues must be
admitted as legal, stopped, lower-order, or active-paid material.

The allowed source names the retained entrance as:

```math
\texttt{RecordMenuPressureActiveOrSilentService.A}
+
\texttt{RetainedRecordEdgeExactProjectorChartLicense.A}.
\tag{LEM.8}
```

## 5. Physical meaning

The menu identity says the same velocity field generated the work. The detector
angle says a frozen visible component would be seen by the parent root/full-
exchange detectors.

The missing physical statement is stronger. Before the future record selector
counts an edge as positive, that edge must either be visible in parent bill
currency or already paid as detector-silent same-material service. The weighted
projector used to see it must also be a lawful retained-packet reading rather
than a shell-changing after-the-fact projection.

Without those two facts, a unit record can be real same-fluid work and still
fail to be stored in \(B=dE^{Field}+dA_{4B}+dVisc\) currency.
