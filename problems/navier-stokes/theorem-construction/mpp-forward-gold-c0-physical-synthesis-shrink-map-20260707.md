# c0 physical synthesis shrink map

## 1. Physical object

The subject is one same-fluid Navier-Stokes material history. It is
incompressible, viscous, dissipative, pressure-constrained, and irreversible in
time.

The bad c0 object is not a scale profile. It is a critical-height climb:

\[
H(t)=\frac12\|u(t)\|_{\dot H^{1/2}}^2,
\qquad H(t_j)\to\infty,
\tag{CPS.1}
\]

with positive material record service retained while every same-packet payment
channel remains exactly ratio-one marginal.

Self-similar and DSS calculations are now only scale-equality tests. Exact NS
scaling preserves \(H\), and a DSS orbit is periodic in that critical-height
currency, so profile exclusion does not exclude `(CPS.1)' unless a separate
bridge turns the critical-height record ladder into a profile while preserving
positive record service.

## 3. What is demoted

Self-similar / DSS profile work is a quarantine and falsifiability surface. It
is useful for detecting scale-equality mistakes, not for closing c0 by itself.

Radiodrome is the tower-relay defect coordinate \(dL^{rad}\). It detects the
ratio-one marginal recurrence; it is not itself the floor.

Broad `FreshCarrierMismatchEvacuationOrTerminalAtom.A` is no longer the live
endpoint. Finite mismatch is already forced into the selected trilinear carrier
or named charges. The unadmitted survivor is terminal visible readout.

The terminal WLF atom is not an additional retained route-b zero-loss profile
after theta-payer admission. The admitted atom survives as a nonzero payer
measure and contradicts zero surplus; after same-witness CM admission it is a
Part/Field consumer.

Raw Bessel freshness, local first-admission atoms, primitive same-packet
ownership, stopped selector support, affine martingales, scalar storage, and
generic capacity labels are support or coordinate projections unless they pay
the same record-admitted terminal/full-packet wall.
