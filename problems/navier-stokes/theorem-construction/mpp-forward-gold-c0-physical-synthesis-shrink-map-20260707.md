# c0 physical synthesis shrink map

## 1. Physical object

The subject is one same-fluid Navier-Stokes material history. It is
incompressible, viscous, dissipative, pressure-constrained, and irreversible in
time.

The bad c0 object is not a scale profile. It is a critical-height climb:

\[
H(t)=\frac12\|u(t)\|_{\dot H^{1/2}}^2,
\qquad H(t_j)\to\infty,
\tag{CPS.1}
\]

with positive material record service retained while every same-packet payment
channel remains exactly ratio-one marginal.

Self-similar and DSS calculations are now only scale-equality tests. Exact NS
scaling preserves \(H\), and a DSS orbit is periodic in that critical-height
currency, so profile exclusion does not exclude `(CPS.1)' unless a separate
bridge turns the critical-height record ladder into a profile while preserving
positive record service.

is useful for detecting scale-equality mistakes, not for closing c0 by itself.
