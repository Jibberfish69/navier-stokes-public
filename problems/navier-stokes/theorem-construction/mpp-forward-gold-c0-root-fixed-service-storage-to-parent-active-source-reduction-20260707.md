# c0 root-fixed service storage descends to parent active source

## 1. Same physical object

The root-fixed terminal storage line is still the same fluid-field-object.  One
original smooth Navier-Stokes packet is transported, re-coordinated by pressure,
read through heat/viscosity, constrained by incompressibility, and tested by the
moving stress/frame/selector apparatus before any child positive readout is
clipped.

The terminal storage theorem asks for this packet to spend through an actual
terminal-uniform service density.  The TFE source audit shows where that density
must come from: the parent must already own the active state before the child
readout.

## 2. The terminal storage line is downstream

The root-fixed endpoint implication is:

\[
\mathcal L_P(t)
=
\mathcal L_P(t_0)+\int_{t_0}^{t}\ell_P(s)\,ds+Paid_P(t),
\tag{PAS.1}

\[
d\mu_P^{end}
\le
C(\ell_P)_-\,dtdx+d\lambda_P+dPaid_P,
\tag{PAS.2}

with terminal-uniform \(L^1\) control of the un-paid densities.  Then the
endpoint trace is absolutely continuous and the terminal atom disappears.

The source audit says `(PAS.1)'--`(PAS.2)' are produced once the active source
theorem constructs, from the original coupled packet,

\[
J_P^S,\quad Z_P^S,\quad f_P,\quad \mathcal M_P,
\tag{PAS.3}
\]

with selected admission before clipping, stopped current Carleson, native
depletion with strict \(\theta<1\), and terminal uniform integrability.  This is
the installed TFE.1516 package.

So the descent is:

\[

Terminal service storage should no longer be treated as an independent bottom
for c0.  It is the endpoint face of the parent-known active source theorem.

Likewise, stopped current Carleson, log-density/BMO, reverse Holder,
entropy/reverse Holder, native-birth packing, and positive critical transfer
are not sibling producers here.  They are coordinate faces of one same physical
object: parent-known active state deletion for the original coupled packet
before child positive readout.

strictly smaller noncircular supplier for one of its clauses, or route failure
to a same-witness endpoint face in the CM grammar.
