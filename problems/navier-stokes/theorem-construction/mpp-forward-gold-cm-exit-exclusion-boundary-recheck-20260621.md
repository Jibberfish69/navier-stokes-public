# CM-Exit Exclusion Boundary Recheck

Date: 2026-06-21

## 0. Trigger

After the discarded-partner endpoint/donor closure, the native channel-first
source carrier satisfies

```math
A_{\rm native}
\le
C A_{4B}+R_{\rm legal}+T_\sigma
\tag{CEB.1}
```

outside the typed CM exits

```math
Pack_Q+\neg Part_{N,Q},
\tag{CEB.2}
```

and

```math
Pack_Q+Part_{N,Q}+\forall r>0\,\neg Field_{N,r,Q}.
\tag{CEB.3}
```

So the remaining sentence can be read in two different ways:

```math
\boxed{
\text{exclude the CM exits from original smooth data}
}
\tag{CEB.4}
```

or

```math
\boxed{
\text{prove a direct forward terminal reserve.}
}
\tag{CEB.5}
```

This note checks which reading is already installed and which remains open.

## 1. Installed CM consumption

`AnyFiniteFailureWitnessCMExit.A` proves the abstract landing theorem:

```math
\mathcal F
\Longrightarrow
\neg Pack_Q
\vee
\neg Part_{N,Q}
\vee
\forall r>0\,\neg Field_{N,r,Q}.
\tag{CEB.6}
```

Here \(\mathcal F\) is an alleged same-solution finite-time failure witness
after legal losses, boundary exits, non-selected branches, and readout-only
artifacts have been removed.

`ClayTerminalWitnessCMEntry.A`,
`ClayFiniteFailureTypeCMExhaustion.A`, and
`ClayCMContrapositiveEmbedding.A` then say that a CM-test-admissible finite Clay
terminal object from original smooth data enters the same-fluid CM tree and is
classified by one first failed service.

The checked CM direction is therefore:

```math
\boxed{
\text{finite terminal witness}
\Longrightarrow
\text{Pack/Part/Field face failure}
\Longrightarrow
Exit(Q):=\neg Member(Q).
}
\tag{CEB.7}
```

This is consumption of the failure witness.  It is not a proof that no such
failure witness can arise.

## 2. Positive no-exit is a different theorem

The older direct no-exit theorem is `TerminalCMNoExit.A`:

```math
OriginalSmoothData
\Longrightarrow
\neg GenuineCMExit(T_*).
\tag{CEB.8}
```

At the packet level this asks for a surviving continuation-complete packet:

```math
OriginalSmoothData
\Longrightarrow
\exists Q,r>0:
Pack_Q\wedge Part_{N_s,Q}\wedge Field_{N_s,r,Q}.
\tag{CEB.9}
```

The direct attempt splits `(CEB.9)` into three positive no-exit faces:

```math
\boxed{
\text{Pack no-exit,}\qquad
\text{Part no-exit,}\qquad
\text{licensed Field no-exit.}
}
\tag{CEB.10}
```

The checked direct attempt does not prove these from original smooth data.

Pack no-exit requires terminal same-fluid carrier survival with positive scale
and finite deformation gauge.  Current energy/local smoothness on compact
preterminal intervals does not supply the terminal uniformity.

Part no-exit requires the same pressure-viscosity tower to close through the
continuation depth \(N_s\) on the retained carrier.  Current inputs do not
produce terminal pressure-viscosity/tower control independently of the desired
continuation scale.

Field no-exit, after Pack and Part survive, requires a positive coherent
one-field readout scale.  Current retained-Field diagnostics are conditional;
they do not prove the positive retained Field scale from original smooth data.

Thus

```math
\boxed{
\texttt{TerminalCMNoExit.A}
\text{ remains a positive packet-survival theorem, not an installed CM
consumption theorem.}
}
\tag{CEB.11}
```

## 3. Boundary for the current branch

For the forward-gold branch, excluding `(CEB.2)` and `(CEB.3)` from original
smooth data would amount to proving a positive no-exit supplier.  At current
resolution this is not smaller than the terminal reserve problem already
isolated.

The direct no-exit supplier list is:

```math
\boxed{
\texttt{UniformNormalizedLocalEnergyPressure.A},
\quad
\texttt{TerminalHardyNoWaste.A},
\quad
\texttt{SourceSquareReserve.A},
\quad
\texttt{SelectedCriticalStrainCarleson.A},
\quad
\texttt{NormalizedCKNCarleson.A},
\quad
\texttt{StrictNoWasteFullLoopLyapunov.A}.
}
\tag{CEB.12}
```

These are forward-positive suppliers.  They try to prevent the endpoint pulse
before it is consumed as a CM face.

The CM route uses the other side:

```math
\boxed{
\text{endpoint pulse survives}
\Longrightarrow
\text{same-witness admission}
\Longrightarrow
\text{Part/Field face failure.}
}
\tag{CEB.13}
```

That is already the installed consumption behavior, assuming the endpoint
object is a CM-test-admissible same-solution terminal witness.

## 4. Result

The post-native-bridge state is:

```math
\boxed{
A_{\rm native}
\le
C A_{4B}+R_{\rm legal}+T_\sigma
}
\tag{CEB.14}
```

on the no-exit branch, hence

```math
\boxed{
\int_{\sigma_0}^{\infty}A_{\rm native}(\sigma)\,d\sigma<\infty.
}
\tag{CEB.15}
```

The two remaining CM faces are not new hidden residues.  They are the already
installed CM consumption targets:

```math
Pack_Q+\neg Part_{N,Q},
\qquad
Pack_Q+Part_{N,Q}+\forall r>0\,\neg Field_{N,r,Q}.
\tag{CEB.16}
```

So the branch should not say only "exclude CM exits" unless the proof program
has explicitly switched to the positive packet-survival theorem
`TerminalCMNoExit.A`.

The exact fork is:

```math
\boxed{
\text{direct terminal reserve production}
\quad\text{or}\quad
\text{CM consumption of the endpoint Part/Field face.}
}
\tag{CEB.17}
```
