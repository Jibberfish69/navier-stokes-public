## 1. The candidate inference under audit

The complete-frame assembly uses the retained orthonormal frame

```math
(p,\widehat\xi,n),
\qquad
n=p\times\widehat\xi,
```

and the trace-free identity

```math
p\cdot Sp+\widehat\xi\cdot S\widehat\xi+n\cdot Sn=0
```

to obtain

```math
[p\cdot Sp]_+
\le
[-\widehat\xi\cdot S\widehat\xi]_+
+
[-n\cdot Sn]_+ .
\tag{CSA.1}
```

This is correct as a pointwise complete-frame payment/admission identity.
It shows that a positive retained velocity-polarization pump is not detached
from the same material packet. It is carried by transverse wave-covector
compression or annular/collar-normal compression.

The complete-frame assembly then tries to use the top-strain log storage

```math
L_j=
\left[\log{\lambda_+(S_{<j-C})\over\delta2^{2j}}\right]_+,
\qquad
B_j=e_jL_j
\tag{CSA.2}
```

and the signed identity

```math
{d\over dt}B_j
+
e_j\lambda_+(S_{<j-C})
\mathbf 1_{\{\lambda_+(S_{<j-C})>\delta2^{2j}\}}
=
(m_j-d_j)L_j
+
e_j{W_\lambda\over\lambda}
\tag{CSA.3}
```

to conclude finite superheat residence after summing shells and passing
through the relaxed master balance.

That last promotion is the point that requires audit.

## 2. What the storage actually proves

Integrating `(CSA.3)` gives

```math
\int_I
e_j\lambda_+(S_{<j-C})
\mathbf 1_{\{\lambda_+(S_{<j-C})>\delta2^{2j}\}}
\,dt
\le
B_j(t_1)-B_j(t_0)
+
\int_I
\left[(m_j-d_j)L_j
+
e_j{W_\lambda\over\lambda}\right]\,dt .
\tag{CSA.4}
```

Since \(B_j\ge0\), this is useful only when the right-side positive exchange
has an independently finite bound after summing over shells and time. The
problem is that the right-side positive exchange is not a legal lower-order
residual. It contains the same material participation-law-strain service:
primitive shell pump, pressure-Hessian strain partner, viscous strain-tower
service, coefficient/frame motion, and transported collar motion.

Thus the storage gives a valid channel identity:

```math
\text{superheat strain residence}
\le
\text{same-packet strain-log exchange}
+\text{strict loss/legal terms}.
\tag{CSA.5}
```

It does not by itself give the finite total estimate

```math
\int_0^{T_*}d\Omega_N^{full}<\infty .
\tag{CSA.6}
```

The finite total follows only after the positive part of the right-side
same-packet exchange is either already included in a left-side clock/loss
before compactness, or independently controlled by a bounded-below
same-material entropy/no-free-upcrossing theorem.

## 3. Why this is not a cosmetic objection

The primitive driver pointwise contraction test already shows that local
trace-free strain, incompressibility, pressure ellipticity, and shell gap do
not produce a pointwise sign contraction. There are smooth divergence-free
normal forms where a selected high shell aligns with a positive strain
direction and produces order-one positive low-high same-material action driver.

The complete-frame identity repairs the missing third direction in that local
reading. It prevents a retained packet from being a positive-cone null. It
does not rule out large rectified transverse compression history. The
transverse compression records are themselves components of the full same-material action.

So the inference

```math
\text{complete-frame pointwise payment}
\Longrightarrow
\text{finite full same-material action}
\tag{CSA.7}
```

is circular unless `(CSA.6)` is supplied by a noncircular global
same-material storage or no-free-upcrossing argument.

The current noncircular target is unchanged:

\tag{CSA.11}

The storage cannot use bounded continuation-depth material record as input,
