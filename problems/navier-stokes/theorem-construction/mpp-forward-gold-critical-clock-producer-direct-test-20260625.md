# Critical Clock Producer Direct Test

Date: 2026-06-25

## 0. Object

The object is the original smooth solution and its transported material
annular history.  Heat-scale windows are samples of that same history.

The remaining full-clock density is the super-heat-rate material residence

```math
\mathcal R_{sh,N}(t)
=
\sum_j
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}(t)>\delta2^{2j}\}},
\tag{CCP.1}
```

where

```math
\Theta_j^{mat}
=
\Theta_j^{strain}
+
\Theta_j^{press}
+
\Theta_j^{coef}
+
\Theta_j^{collar}.
\tag{CCP.2}
```

The question is whether a BKM-style critical clock is an independent producer
for `(CCP.1)`.

## 1. What the critical clock would have to do

For the fixed continuation-depth material record \(Y_N=1+\mathcal P_N^{mat}\),
the Osgood repair would need

```math
\Theta_N(t)
\le
C K(t)\bigl(1+\log Y_N(t)\bigr)+r(t),
\qquad
\int_0^{T_*}K(t)\,dt<\infty,
\qquad
r\in L^1_t.
\tag{CCP.3}
```

Then

```math
{d\over dt}\log\bigl(1+\log Y_N(t)\bigr)
\le
C K(t)+r(t),
\tag{CCP.4}
```

and the material record cannot blow up at \(T_*\).

This is the exact role of BKM/Kozono--Taniuchi-type clocks.  They are
continuation clocks.

## 2. Heat-scale scaling

A terminal heat-scale event of width \(\ell\) has

```math
|u|_\ell\sim \ell^{-1},
\qquad
|\nabla u|_\ell\sim \ell^{-2},
\qquad
\tau_\ell\sim \ell^2.
\tag{CCP.5}
```

Thus

```math
\int_{t_\ell-\tau_\ell}^{t_\ell}
\|\nabla u(t)\|_{L^\infty}\,dt
\sim
1.
\tag{CCP.6}
```

The same order-one contribution is seen by vorticity \(L^\infty\), critical
Besov-vorticity clocks, and the material strain-clock.  This is why the
critical clock is correctly scaled.

The raw energy and raw dissipation see instead

```math
\int_{Q_\ell}|u|^2
\sim
\ell,
\qquad
\int_{Q_\ell}|\nabla u|^2
\sim
\ell.
\tag{CCP.7}
```

So finite physical energy can coexist with infinitely many order-one critical
clock samples.

## 3. The superheat residence gives the same conclusion

The sharp strain-superheat interpolation gives

```math
\mathcal R_{sh}^{strain}(t)
\le
C E_0^{1/4}D(t)^{5/4},
\qquad
D(t)=\|\nabla u(t)\|_2^2.
\tag{CCP.8}
```

Energy supplies only

```math
\int_0^{T_*}D(t)\,dt<\infty.
\tag{CCP.9}
```

It does not supply

```math
\int_0^{T_*}D(t)^{5/4}\,dt<\infty.
\tag{CCP.10}
```

The scalar enstrophy envelope

```math
D'(t)\le C D(t)^3
\tag{CCP.11}
```

is compatible with \(D\in L^1_t\) while \(D^{5/4}\notin L^1_t\).  Therefore
the strain part of the superheat clock already escapes raw energy and the
standard scalar enstrophy ODE.

The pressure, coefficient, and collar parts of `(CCP.2)` are not easier.  They
are generated by the same material elliptic pressure operator, the same
coefficient equations, and the same transported collar/frame variation.  They
are components of the full material clock, not consequences of energy alone.

## 4. Result

An integrable critical clock of the form `(CCP.3)` would close the gold route,
but proving that clock from original smooth data is exactly the missing
same-material full-clock theorem.

Thus the critical-clock branch is not an independent producer:

```math
\boxed{
\text{critical clock finite}
\Longrightarrow
\text{continuation;}
}
\tag{CCP.12}
```

```math
\boxed{
\text{original energy/local energy}
\not\Longrightarrow
\text{critical clock finite.}
}
\tag{CCP.13}
```

The remaining direct proof target is therefore the same-material no-free-
upward-transfer / bounded-storage statement:

```math
\boxed{
\int_0^{T_*}
\sum_j
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}(t)>\delta2^{2j}\}}
\,dt
<\infty
}
\tag{CCP.14}
```

or an equivalent bounded-below same-material storage that pays this residence.
