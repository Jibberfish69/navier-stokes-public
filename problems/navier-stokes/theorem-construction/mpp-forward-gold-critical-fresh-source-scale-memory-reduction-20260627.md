# Critical fresh-source scale-memory reduction

## 1. Target

The live estimate is

```math
\sum_{Q\subset P}W_Q\|F_Q\|^2\le C_N(u_0)\mathcal R(P)+R_{legal}(P).
\tag{1}
```

The unweighted Bessel estimate is insufficient.  The factor \(W_Q\) has to be generated by original scale-memory data before the selected readout.

## 2. Scale-memory representation

Assume each fresh increment has a parent-known interval \(I_Q\) and an original generator \(G_Q\) such that

```math
F_Q(t)=|I_Q|^{-1}\int_{I_Q}G_Q(\sigma,t)\,d\sigma+Err_Q^{legal}(t).
\tag{2}
```

Here \(G_Q\) is built from original same-material scale derivative, frame/turnstile motion, exchange motion, covector motion, and dynamic source terms.

Let \(a(\sigma,t)>0\) be the original memory density and set

```math
W_Q(t)=\frac{|I_Q|^2}{\int_{I_Q}a(\sigma,t)^{-1}\,d\sigma}.
\tag{3}
```

## 3. Cauchy estimate

Weighted Cauchy--Schwarz gives

```math
\left\|\int_{I_Q}G_Q\,d\sigma\right\|^2
\le
\left(\int_{I_Q}a^{-1}\right)
\left(\int_{I_Q}a\|G_Q\|^2\right).
\tag{4}
```

Using `(2)` and `(3)`,

```math
W_Q\|F_Q\|^2
\le C\int_{I_Q}a\|G_Q\|^2\,d\sigma+CR_Q^{legal}.
\tag{5}
```

Thus the critical weight is exactly the dual Cauchy weight of the original scale-memory average.

## 4. Summation

If the witness intervals/tubes pack sparsely,

```math
\sum_{Q\subset P}1_{I_Q\times T_Q}\le C_N+R_{legal},
\tag{6}
```

then

```math
\sum_{Q\subset P}W_Q\|F_Q\|^2
\le
C_N\int_{\operatorname{Hist}(P)}a\|G\|^2+CR_{legal}(P).
\tag{7}
```

If

```math
\int_{\operatorname{Hist}(P)}a\|G\|^2\le C_N(u_0)\mathcal R(P)+R_{legal}(P),
\tag{8}
```

then `(1)` follows.

This note proves the analytic reduction, not the producer.  The remaining theorems are:

Conditional reduction:
