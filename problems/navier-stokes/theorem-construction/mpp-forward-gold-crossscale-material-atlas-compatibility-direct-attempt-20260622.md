# Cross-Scale Material Atlas Compatibility Direct Attempt

Date: 2026-06-22

## 0. Target

The fixed-atlas \(C_N\) calculation proves that

```math
d_\sigma [L_C^{M,\ell,\delta}]_+
\le
C\,d_\sigma A_{4B,N_\ast}^{ann,M,\ell,\delta}
\tag{CMA.1}
```

when the same transported material annulus, label map, center/time
normalization, and collar are differentiated across \(\sigma\).

The remaining question is whether a retained terminal family actually has that
same cross-scale material atlas, or whether the moving center/time/label/collar
data adds terms outside the simultaneous packet.

## 1. Exact inverse-label identity

Let \(X(a,t)\) be the material flow map and \(Y(t,z)\) its inverse label map:

```math
X(Y(t,z),t)=z.
\tag{CMA.2}
```

Then

```math
(\partial_t+u\cdot\nabla_z)Y=0.
\tag{CMA.3}
```

For a heat-scale microscope, set

```math
r_\sigma=e^{-\sigma},
\qquad
t_\sigma(s)=T_\sigma+r_\sigma^2s,
\qquad
z_\sigma(y)=x_\sigma+r_\sigma y,
\tag{CMA.4}
```

and pull labels into rescaled variables:

```math
Y_\sigma(s,y)=Y(t_\sigma(s),z_\sigma(y)).
\tag{CMA.5}
```

Differentiate `(CMA.5)` with respect to \(\sigma\).  From `(CMA.3)`,

```math
\partial_\sigma Y_\sigma
=
\nabla_zY(t_\sigma,z_\sigma)
\left(
\partial_\sigma z_\sigma
-u(t_\sigma,z_\sigma)\,\partial_\sigma t_\sigma
\right).
\tag{CMA.6}
```

Since

```math
\partial_\sigma z_\sigma
=
\dot x_\sigma-r_\sigma y,
\qquad
\partial_\sigma t_\sigma
=
\dot T_\sigma-2r_\sigma^2s,
\tag{CMA.7}
```

and \(V_\sigma=r_\sigma u(t_\sigma,z_\sigma)\), while
\(\nabla_yY_\sigma=r_\sigma\nabla_zY(t_\sigma,z_\sigma)\), `(CMA.6)` becomes

```math
\boxed{
\partial_\sigma Y_\sigma
=
\nabla_yY_\sigma
\left(
-y+2sV_\sigma
+r_\sigma^{-1}\dot x_\sigma
-r_\sigma^{-2}\dot T_\sigma\,V_\sigma
\right).
}
\tag{CMA.8}
```

This is the exact cross-scale label-map law.

## 2. Fixed center/time is already compatible

If \(T_\sigma=T\) and \(x_\sigma=x_\ast\), `(CMA.8)` reduces to

```math
\boxed{
\partial_\sigma Y_\sigma
=
\nabla_yY_\sigma(-y+2sV_\sigma).
}
\tag{CMA.9}
```

This term is inside the same packet.  The factor \(\nabla_yY_\sigma\) is the
material frame/coefficient coordinate, and \(V_\sigma\) is the velocity
coordinate.  Therefore fixed center/time atlas motion is not an external
defect.

For a label cutoff

```math
\zeta_\sigma(s,y)=\zeta_0(Y_\sigma(s,y)),
\tag{CMA.10}
```

one gets

```math
\partial_\sigma\zeta_\sigma
=
(\nabla_a\zeta_0)(Y_\sigma)\cdot\partial_\sigma Y_\sigma.
\tag{CMA.11}
```

Under `(CMA.9)`, the cutoff/collar variation is also generated by the same
material frame and velocity coordinates. It is a \(G_N/Q_N\) channel of the
same four-body packet.

Thus the fixed-center, fixed-label, transported-collar case proves the atlas
compatibility needed by `(CMA.1)`.

## 3. Moving center/time terms

For a moving center or terminal time, `(CMA.8)` has the normalized modulation
term

```math
\mathfrak m_\sigma
:=
r_\sigma^{-1}\dot x_\sigma
-r_\sigma^{-2}\dot T_\sigma\,V_\sigma.
\tag{CMA.12}
```

Then

```math
\partial_\sigma Y_\sigma
=
\nabla_yY_\sigma(-y+2sV_\sigma)
+
\nabla_yY_\sigma\mathfrak m_\sigma.
\tag{CMA.13}
```

The first term is same-packet, as above.  The second term is same-packet only
when the modulation record is carried by the simultaneous packet:

```math
d\Lambda_{mod,N}(\sigma)
:=
\left\|
\nabla_yY_\sigma\mathfrak m_\sigma
\right\|_{\mathcal M_N(\widehat A_\sigma)}
d\sigma
\tag{CMA.14}
```

must be included as \(S_N/G_N\) scale-frame drift, or controlled by the same
material-record growth loss.  Without `(CMA.14)`, changing centers/times can
make \(d_\sigma L_C\) compare different packets.

So the moving-center/time compatibility condition is:

```math
\boxed{
d\Lambda_{mod,N}
\le
C\,dA_{4B,N}^{mod}
}
\tag{CMA.15}
```

with \(dA_{4B,N}^{mod}\) part of the same simultaneous packet.

## 4. Label, sign, and collar jumps

The selector/collar stabilization theorem already gives the correct
dichotomy.  Finite/compact selector data with vanishing variation stabilizes
labels, signs, tests, cutoffs, and collar topology.  Positive variation is
visible packet motion.

For cross-scale atlas compatibility, the needed measure is

```math
d\Lambda_{atlas,N}
:=
d\Lambda_{mod,N}
+dN_{label}
+dN_{sgn}
+\|d_\sigma\zeta_\sigma\|_{\mathcal C_N}\,d\sigma
+d\Lambda_{collar,N}.
\tag{CMA.16}
```

The required same-packet form is

```math
\boxed{
d\Lambda_{atlas,N}
\le
C\,dA_{4B,N}^{atlas}.
}
\tag{CMA.17}
```

When `(CMA.17)` holds, the moving-atlas terms from `(CMA.18)` of the
cross-scale compactness note are enveloped inside the simultaneous packet.
Then \(d_\sigma L_C\) remains a derivative of the same one-fluid object.

When `(CMA.17)` fails, the branch is not a hidden \(C_N\) derivative.  It is
loss of the retained cross-scale material atlas itself.

## 5. Direct attempt result

The moving-atlas calculation proves the exact fixed-center/fixed-label
compatibility:

```math
\partial_\sigma Y_\sigma
=
\nabla_yY_\sigma(-y+2sV_\sigma).
\tag{CMA.18}
```

Thus the fixed retained material atlas is already order-locked to the
pressure-viscosity-incompressibility-velocity packet.

The unresolved part is not generic atlas language.  It is the normalized
modulation and jump variation:

```math
r_\sigma^{-1}\dot x_\sigma,
\qquad
r_\sigma^{-2}\dot T_\sigma,
\qquad
dN_{label},
\qquad
dN_{sgn},
\qquad
d\Lambda_{collar,N}.
\tag{CMA.19}
```

The remaining theorem clause is therefore:

```math
\boxed{
\texttt{CrossScaleMaterialAtlasCompatibility.A}
}
\tag{CMA.20}
```

with precise content `(CMA.17)`.

This clause is internal to
`SimultaneousMaterialFourBodyPacketCoercivity.A`: it says the \(\sigma\)-path
of packets is one material packet path, not a sequence of unrelated selected
microscopes.

The fixed-terminal-gauge solution discharges the center/time modulation part on
the retained branch.  With \(T_\sigma=T^\ast\) and \(x_\sigma=x^\ast\),
`(CMA.8)` reduces to `(CMA.18)`.  Moving active packets become bounded
rescaled translations when they remain in the retained heat-scale atlas, and
those translations are exactly what the \(C_N\) material time/space translation
moduli measure.  Label/sign/collar/selector variation is then handled by the
selector-collar stabilization theorem.  Thus the retained-branch
cross-scale atlas is fixed enough for \(d_\sigma L_C\); the live construction
returns to the bounded-below \(X\)-term symmetrizer.
