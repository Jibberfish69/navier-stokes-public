# Cross-Scale Material Compactness Evolution Direct Attempt

Date: 2026-06-22

## 0. Target

The preterminal compactness coordinate has been realized as a same-packet
defect modulus

```math
C_N
\equiv
\{L_C^{M,\ell,\delta}\}_{M,\ell,\delta}.
\tag{CSM.1}
```

The remaining \(C_N\)-face of the simultaneous packet is the log-scale
evolution:

```math
d_\sigma [L_C^{M,\ell,\delta}]_+
\le
C\,d_\sigma A_{4B,N}^{ann,M,\ell,\delta}.
\tag{CSM.2}
```

This note tests `(CSM.2)` directly.  The point is not to add a compactness
supplier.  The point is to see whether the same material participation law
already differentiates the \(C_N\) record as the heat-scale microscope changes.

## 1. Fixed-center heat-scale generator

Fix \(T\), \(x_\ast\), and set \(r=e^{-\sigma}\).  Define

```math
V_\sigma(s,y)
:=
r\,u(T+r^2s,x_\ast+ry),
\qquad
Q_\sigma(s,y)
:=
r^2p(T+r^2s,x_\ast+ry).
\tag{CSM.3}
```

Then

```math
\partial_sV_\sigma
+(V_\sigma\cdot\nabla_y)V_\sigma
+\nabla_yQ_\sigma
=
\nu\Delta_yV_\sigma,
\qquad
\nabla_y\cdot V_\sigma=0,
\tag{CSM.4}
```

and

```math
-\Delta_yQ_\sigma
=
\partial_i(V_\sigma)_j\,\partial_j(V_\sigma)_i.
\tag{CSM.5}
```

Differentiate `(CSM.3)` with respect to \(\sigma\).  Since
\(\partial_\sigma=-r\partial_r\),

```math
\boxed{
\partial_\sigma V_\sigma
=
-V_\sigma
-y\cdot\nabla_yV_\sigma
-2s\,\partial_sV_\sigma .
}
\tag{CSM.6}
```

Using `(CSM.4)`,

```math
\partial_\sigma V_\sigma
=
-V_\sigma-y\cdot\nabla_yV_\sigma
+2s\left(
(V_\sigma\cdot\nabla_y)V_\sigma
+\nabla_yQ_\sigma
-\nu\Delta_yV_\sigma
\right).
\tag{CSM.7}
```

So the fixed-center scale derivative of velocity is not an external clock.  It
is scaling drift plus the same transport, pressure, viscosity, and
incompressibility tuple.

For pressure,

```math
\boxed{
\partial_\sigma Q_\sigma
=
-2Q_\sigma
-y\cdot\nabla_yQ_\sigma
-2s\,\partial_sQ_\sigma .
}
\tag{CSM.8}
```

The pressure time derivative is determined by differentiating the same pressure
Poisson law:

```math
-\Delta_y\partial_sQ_\sigma
=
\partial_s\left(
\partial_i(V_\sigma)_j\,\partial_j(V_\sigma)_i
\right).
\tag{CSM.9}
```

Thus pressure scale evolution closes only on the mixed pressure tower.  This is
exactly the mixed-tower point already installed for terminal time-face work.

## 2. Consequence for the material packet record

Let the retained material atlas be fixed across the tested \(\sigma\)-tail.
Pull `(CSM.3)` back to the same material annulus and write the full record as

```math
Z_{N,\sigma}^{mix}
:=
\left(
\partial_s^mD_a^\alpha v_\sigma,\,
\partial_s^mD_a^\alpha q_\sigma,\,
\partial_s^mD_a^\beta A_\sigma,\,
\partial_s^mD_a^\beta G_\sigma,\,
\partial_s^mD_a^\alpha h_\sigma
\right)_{m+|\alpha|,\ m+|\beta|\le N_\ast}.
\tag{CSM.10}
```

The index \(N_\ast\) must be chosen high enough that applying
\(\partial_\sigma\) to the displayed \(C_N\) rungs stays inside the recorded
mixed tower.  In practice, the \(C_N\) coordinate at level \(N\) is controlled
by a finite higher mixed level \(N_\ast=N+N_0\), where \(N_0\) accounts for the
one \(s\)-derivative, one scaling derivative, and the viscous second spatial
derivatives generated by `(CSM.7)`--`(CSM.9)`.

For each component of \(Z_{N,\sigma}^{mix}\), the fixed-atlas
\(\sigma\)-derivative has the form

```math
\partial_\sigma Z_{N,\sigma}^{mix}
=
\mathcal D_{scale}Z_{N,\sigma}^{mix}
+
\mathcal N_{TPVI}(Z_{N_\ast,\sigma}^{mix}),
\tag{CSM.11}
```

where \(\mathcal D_{scale}\) is generated by the explicit terms
\(-V\), \(-y\cdot\nabla V\), \(-2Q\), and \(-y\cdot\nabla Q\), and
\(\mathcal N_{TPVI}\) is generated by the same transport-pressure-viscosity-
incompressibility tower in `(CSM.4)`--`(CSM.9)`.

This is the fixed-atlas cross-scale law.  It is exact at the level of the
rescaled equations.

## 3. Differentiating the \(C_N\) compactness modulus

The preterminal \(C_N\) coordinate is built from finite-rank tails, material
spatial translation moduli, and material time-translation moduli of the full
record.  Replacing the earlier spatial record by the mixed record gives

```math
\begin{aligned}
L_C^{M,\ell,\delta}(\sigma)
:={}&
\sum_\kappa
\|(I-\Pi_M)Z_{N,\sigma}^{mix,\kappa}\|_{\mathcal X_\kappa}^2\\
&+
\sum_\kappa
\sup_{|\xi|\le \ell}
\|\delta_\xi^a Z_{N,\sigma}^{mix,\kappa}\|_{\mathcal X_\kappa}^2\\
&+
\sum_\kappa
\sup_{|\tau|\le \delta}
\|\delta_\tau^s Z_{N,\sigma}^{mix,\kappa}\|_{\mathcal Y_\kappa}^2 .
\end{aligned}
\tag{CSM.12}
```

For fixed \(M,\ell,\delta\), differentiate `(CSM.12)` in \(\sigma\).  Each
term is a pairing of a defect component with its \(\sigma\)-derivative.  Using
`(CSM.11)` gives

```math
d_\sigma [L_C^{M,\ell,\delta}]_+
\le
C\,d_\sigma \mathcal A_{4B,N_\ast}^{C,M,\ell,\delta},
\tag{CSM.13}
```

where the right side is not a new measure.  It is the part of the same
simultaneous four-body packet generated by:

```math
\text{scale drift in }S_N,
\qquad
\text{pressure-viscosity-incompressibility participation in }Q_N,
\tag{CSM.14}
```

```math
\text{compactness/no-loss variation in }C_N,
\qquad
\text{material frame and strain geometry in }G_N.
\tag{CSM.15}
```

Thus, under a fixed cross-scale material atlas and a mixed \(C_N\) record,
`(CSM.2)` is proved at the level of the generated packet terms:

```math
\boxed{
d_\sigma [L_C^{M,\ell,\delta}]_+
\le
C\,d_\sigma A_{4B,N_\ast}^{ann,M,\ell,\delta}.
}
\tag{CSM.16}
```

## 4. What breaks without a fixed cross-scale material atlas

The fixed-atlas calculation above assumes that the same material annulus, same
labels, same selected collar, and same center/time normalization are being
differentiated in \(\sigma\).  A general terminal family may instead use

```math
T_\sigma,\qquad x_\sigma,\qquad Y_\sigma,\qquad \zeta_\sigma,
\tag{CSM.17}
```

where \(Y_\sigma\) is the inverse material-label map and \(\zeta_\sigma\) is
the annular/collar selector.

Then \(\partial_\sigma Z_{N,\sigma}^{mix}\) gains atlas-variation terms:

```math
\dot T_\sigma\,\partial_t u,
\qquad
\dot x_\sigma\cdot\nabla_xu,
\qquad
(\partial_\sigma Y_\sigma)\cdot\nabla_a Z_{N,\sigma}^{mix},
\qquad
\partial_\sigma\zeta_\sigma .
\tag{CSM.18}
```

These terms are not allowed to sit outside the route.  They must be one of the
simultaneous packet coordinates:

```math
\dot T_\sigma,\ \dot x_\sigma,\ \partial_\sigma Y_\sigma
\quad\leadsto\quad
S_N/G_N\text{ scale-frame drift channels},
\tag{CSM.19}
```

```math
\partial_\sigma\zeta_\sigma
\quad\leadsto\quad
Q_N/G_N\text{ transported collar channel}.
\tag{CSM.20}
```

Without that atlas compatibility, the expression \(d_\sigma L_C\) is not yet
an order-locked same-packet derivative.  It is a comparison between different
packets.

## 5. Direct attempt result

The fixed-atlas cross-scale generator is derived:

```math
\partial_\sigma V
=
-V-y\cdot\nabla V-2s\,\partial_sV,
\qquad
\partial_\sigma Q
=
-2Q-y\cdot\nabla Q-2s\,\partial_sQ.
\tag{CSM.21}
```

After using the rescaled Navier-Stokes law and the pressure Poisson tower,
this generator is exactly the same pressure-viscosity-incompressibility-
velocity participation law plus scale drift.

The derivation forces one correction to the \(C_N\) coordinate: the compactness
record must be mixed in \(s\) and material space, not spatial-only.  With that
mixed record and a fixed cross-scale material atlas,

```math
d_\sigma [L_C^{M,\ell,\delta}]_+
\le
C\,d_\sigma A_{4B,N_\ast}^{ann,M,\ell,\delta}.
\tag{CSM.22}
```

The general retained terminal family is still not closed, because moving
centers, times, labels, collars, and material maps produce `(CSM.18)`.  The
remaining clause is therefore:

```math
\boxed{
\texttt{CrossScaleMaterialAtlasCompatibility.A}
}
\tag{CSM.23}
```

as an internal face of
`SimultaneousMaterialFourBodyPacketCoercivity.A`.

This is not a separate compactness theorem.  It is the exact condition that
the log-scale derivative of \(C_N\) remains the derivative of the same
one-fluid material packet.
