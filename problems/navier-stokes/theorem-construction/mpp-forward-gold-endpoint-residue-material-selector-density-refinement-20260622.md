# Endpoint Residue / Material Selector Density Refinement

Date: 2026-06-22

## 0. Point of the refinement

`EndpointResidueDensityPolicy.A` says that no arbitrary finite endpoint measure
may enter the gold endpoint packet.  The selector/collar channel was recorded as

```math
d\Lambda_{sel}
=
\|d_s\chi_s\|_{C^2}\,ds
+\|d_s\Phi_s\|_{\mathcal T}\,ds
+dN_{label}
+dN_{sgn}
+d\Lambda_{collar}.
\tag{MSR.1}
```

Finite mass of `(MSR.1)` is not enough for endpoint uniform integrability.  The
model pulse

```math
\tau_m^{-1}{\bf 1}_{(-\tau_m,0]}(s)\,ds
\tag{MSR.2}
```

still survives.

The selector/collar residue becomes a gold endpoint density only when the
selector motion is not arbitrary.  It must be generated by the same local
velocity-pressure-incompressibility tower as the retained packet.

## 1. Discrete label and sign residues

Assume the finite or compact selector graph branch from the selector
stabilization theorem.

On the no-loss retained tail, the label and sign records stabilize:

```math
\ell_m(s)=\ell_\ast,
\qquad
\operatorname{sgn}_m(s)=\operatorname{sgn}_\ast
\quad
\text{for }s\in(-\theta_0,0]
\tag{MSR.3}
```

after passing to the stabilized same-carrier tail.  Hence

```math
\big(dN_{label,m}+dN_{sgn,m}\big)((-\theta,0])=0
\qquad
0<\theta<\theta_0.
\tag{MSR.4}
```

If `(MSR.3)` fails, the branch is already selector/sign drift.  That residue is
not admitted into the gold endpoint measure.

Thus the discrete selector residues are solved inside the gold no-exit branch:
they are eventually zero near the endpoint.

## 2. Continuous selector motion as a material finite-jet density

Let

```math
\mathcal J_K^{loc}
=
\{\partial_y^\alpha U_m,\partial_y^\alpha Q_m^{loc}:|\alpha|\le K\}
\tag{MSR.5}
```

be the local finite jet controlled by `FiniteEndpointJetTemporalModulus.A`.

The continuous selector/collar channel is endpoint-uniform-integrable if the
selected cutoff, selected test, and fixed-topology collar are generated by
finite-dimensional material kinematics:

```math
\begin{aligned}
\partial_s\chi_m &= F_\chi(\mathcal J_K^{loc};\chi_m),\\
\partial_s\Phi_m &= F_\Phi(\mathcal J_K^{loc};\Phi_m),\\
\partial_s\Gamma_m &= F_\Gamma(\mathcal J_K^{loc};\Gamma_m),
\end{aligned}
\tag{MSR.6}
```

where the maps \(F_\chi,F_\Phi,F_\Gamma\) are locally Lipschitz in the fixed
selector/collar topology and polynomially bounded by the finite jet:

```math
\|F_\chi\|_{C^2}
+\|F_\Phi\|_{\mathcal T}
+\|F_\Gamma\|_{\Gamma}
\le
C\big(1+\|\mathcal J_K^{loc}\|_{H_y^\sigma}^{d}\big),
\qquad
\sigma>{3\over2}.
\tag{MSR.7}
```

Then `FiniteEndpointJetTemporalModulus.A` gives

```math
\sup_m
\|\mathcal J_K^{loc}\|_{L_s^\infty H_y^\sigma}<\infty,
\tag{MSR.8}
```

and therefore

```math
\|d_s\chi_m\|_{C^2}
+\|d_s\Phi_m\|_{\mathcal T}
+\lambda_{collar,m}
\in L_s^\infty(-1,0)
\tag{MSR.9}
```

uniformly on the retained tail.  Consequently,

```math
\Lambda_{sel,m}^{cont}((-\theta,0])
\le
C\theta.
\tag{MSR.10}
```

This is stronger than the required endpoint uniform integrability.

## 3. Exact role of the transported-selector identity

The transported-selector commutator identity already proves that the transport
part of the selected source is a material variation of the selector metric:

```math
\langle A_s^{tr}(u\cdot\nabla u),A_s^{tr}u\rangle
=
-{1\over2}\langle [u\cdot\nabla,G_s^{tr}]u,u\rangle.
\tag{MSR.11}
```

This supports `(MSR.6)`: the selector is allowed to move with the same
incompressible transport and cotangent deformation that generated the packet.
It does not by itself prove `(MSR.6)` for the actual retained endpoint
selector.  That is the remaining kinematic realization step.

## 4. Resulting residue split

The selector/collar part of `EndpointResidueDensityPolicy.A` now splits as

```math
\boxed{
\texttt{Finite/compact selector stabilization}
+
\texttt{MaterialSelectorKinematicRealization.A}
+
\texttt{FiniteEndpointJetTemporalModulus.A}
\Longrightarrow
\text{selector/collar endpoint UI.}
}
\tag{MSR.12}
```

The failure alternative is exact:

```math
\boxed{
\neg\texttt{MaterialSelectorKinematicRealization.A}
\quad\text{means selector/collar motion is not carried by the same local
NS participation tower.}
}
\tag{MSR.13}
```

That failure is a selector/collar branch.  It is not a naked finite endpoint
measure inside the gold endpoint packet.

## 5. Updated endpoint-residue state

Inside the gold no-exit branch:

1. discrete label/sign residues vanish on the terminal tail;
2. continuous material selector/collar residues are controlled by the local
   finite-jet endpoint modulus;
3. non-material selector/collar motion exits through the selector/collar branch.

So the remaining residue-policy production burdens are now narrower:

```math
\boxed{
\texttt{MaterialSelectorKinematicRealization.A}
}
\tag{MSR.14}
```

for selector/collar motion, plus the separate signed/donor, terminal trace, and
geometry residue density or absorption clauses already isolated elsewhere.
