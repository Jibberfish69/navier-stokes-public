## 1. The endpoint carrier

On a selected terminal heat-scale packet, write the normalized positive source
time marginal as

```math

\qquad
-1\le s\le0.
\tag{ELC.1}
```

The installed visibility is finite normalized mass:

```math
\sup_m\int_{-1}^{0}a_m(s)\,ds\le C.
\tag{ELC.2}
```

The forward-gold no-jump target is endpoint uniform integrability:

```math
\lim_{\theta\downarrow0}\limsup_m
\int_{-\theta}^{0}a_m(s)\,ds=0.
\tag{ELC.3}
```

The sharp enemy is the terminal layer

```math
a_\tau(s)=\tau^{-1}{\bf 1}_{(-\tau,0]}(s),
\qquad
0<\tau<1.
\tag{ELC.4}
```

It has exactly unit mass:

```math
\int_{-1}^{0}a_\tau(s)\,ds=1,
\tag{ELC.5}
```

and violates `(ELC.3)` because

```math
\int_{-\theta}^{0}a_\tau(s)\,ds=1
\qquad
\text{whenever }0<\tau\le\theta.
\tag{ELC.6}
```

## 2. Superlinear entropy is exactly Orlicz endpoint UI

Let \(\Phi:[0,\infty)\to[0,\infty)\) be increasing, convex, and superlinear:

```math
\lim_{z\to\infty}{\Phi(z)\over z}=\infty.
\tag{ELC.7}
```

The bound

```math
\sup_m\int_{-1}^{0}\Phi(a_m(s))\,ds<\infty
\tag{ELC.8}
```

implies `(ELC.3)` by the de la Vallee-Poussin argument already installed in
`mpp-forward-gold-orlicz-endpoint-ui-production-direct-test-20260620.md`.

For the terminal layer `(ELC.4)`,

```math
\int_{-1}^{0}\Phi(a_\tau(s))\,ds
=
\tau\,\Phi(\tau^{-1}).
\tag{ELC.9}
```

Writing \(z=\tau^{-1}\), `(ELC.9)` becomes

```math
{\Phi(z)\over z},
\qquad z\to\infty,
\tag{ELC.10}
```

which diverges by `(ELC.7)`.  Thus superlinear entropy kills the atom only
because it is exactly a super-\(L^1\) endpoint payment.  It is not produced by
the finite mass statement `(ELC.2)`.

## 3. Linear or logarithmic entropy cannot kill the atom

Assume instead that \(\Phi\) has at most linear growth:

```math
\Phi(z)\le C_\Phi(1+z)
\qquad
\text{for all }z\ge0.
\tag{ELC.11}
```

Then for `(ELC.4)`,

```math
\int_{-1}^{0}\Phi(a_\tau(s))\,ds
\le
(1-\tau)\Phi(0)+C_\Phi(\tau+1),
\tag{ELC.12}
```

which stays bounded as \(\tau\downarrow0\).  So every entropy controlled by a
linear \(L^1\) ledger is compatible with the terminal atom.

For the purely logarithmic example \(\Phi(z)=\log(1+z)\),

```math
\int_{-1}^{0}\log(1+a_\tau(s))\,ds
=
\tau\log(1+\tau^{-1}),
\tag{ELC.13}
```

and `(ELC.13)` tends to zero as \(\tau\downarrow0\).  Logarithmic carrier
entropy is therefore weaker than the available mass ledger for the endpoint
question.

## 4. Energy entropy remains radius-discounted

A state-space entropy of the velocity, such as an \(L^2\log L\) local energy,
does not become a no-jump theorem for the selected source carrier.

Use the scale test

```math
u_{r,\tau}(t,x)
=
r^{-1}\tau^{-1/3}\chi\!\left({t-T\over r^2\tau}\right)
V\!\left({x-x_0\over r}\right),
\tag{ELC.14}
```

where \(V\) is smooth, divergence-free, and compactly supported, and \(\chi\)
is smooth, supported in \((-1,0]\), and bounded above and below by positive
constants on \((-1/2,0]\).  This is a scaling test for estimates, not an exact
Navier--Stokes solution.

The normalized cubic/source carrier generated by `(ELC.14)` has a terminal
layer of the form `(ELC.4)`.  The local \(L^2\log L\) energy is bounded by a
constant multiple of

```math
r\,\tau^{-2/3}
\log\!\left(2+r^{-2}\tau^{-2/3}\right).
\tag{ELC.15}
```

Taking \(\tau=r^\alpha\) with \(0<\alpha<3/2\), the expression in `(ELC.15)`
tends to zero as \(r\downarrow0\).  Thus a physical state entropy can vanish
while the normalized selected source carrier keeps fixed endpoint mass.  The
missing theorem must act on the selected carrier itself, or supply an
unweighted no-waste reserve that dominates it.

## 5. Branch entropy needs a real refill theorem

A branch entropy for donor ancestry can only help if terminal refill is forced
to split mass in a quantitatively nontrivial way.

Let a donor chain have one continuing parent at each generation with mass share
one.  The branch probability vector is then \((1)\) at every generation, so its
entropy is

```math

\tag{ELC.16}
```

This chain can still be a terminal Zeno refill chain.  Hence branch entropy does
not charge the live enemy unless one first proves a theorem of the form:

```math
\text{each terminal refill has at least two retained branches with shares }
\ge\delta>0,
\tag{ELC.17}
```

or an equivalent finite-alphabet / fixed-share / definite entropy-drop result.
The installed same-fluid ancestry and bounded-overlap inputs do not prove
`(ELC.17)`.
