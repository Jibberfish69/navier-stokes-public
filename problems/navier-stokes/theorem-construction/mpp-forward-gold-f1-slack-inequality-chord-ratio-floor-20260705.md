# F1's floor rides the bare chords

## 1. The catch, owned

My monotonicity line kept the numerator's derivative and forgot the
denominator moves too. Codex's display is the truth:

  d/dphi log F1 = f(phi-w) - f(phi),
  f(beta) = kq sin(beta) / [c(beta)(a + c(beta))],  a = q - k,

and it changes sign on admissible sectors. The claim is withdrawn.

## 2. The slack inequality

For a >= 0 and 0 < u <= v:

  (a+u)v - u(a+v) = a(v-u) >= 0   =>   (a+u)/(a+v) >= u/v.

With u = c(phi-w) < v = c(phi) (the chord increases on the sector):

  F1(phi,w) >= G(phi,w) := c(phi-w)/c(phi)   wherever q >= k.

A fence lifted by the same post at both ends never dips below the
bare fence. The bare chord ratio is the harsher price; a floor of a
floor is a floor.

## 3. The equal-dip lemma

G is F2's problem with the window shifted:

  d/dphi log G = kq[h(phi-w) - h(phi)],  h(beta) = sin(beta)/c(beta)^2,

critical where h(phi-w) = h(phi), i.e. (same algebra as F2's cleared
equation, midpoint now phi - w/2):

  cos(phi - w/2) = R cos(w/2),  R = 2kq/(k^2+q^2).

At that point, with psi-tilde = phi - w/2 and cos(psi-tilde) =
R cos(w/2):

  G^2 = sin(phi-w)/sin(phi)
      = [sin(psi-tilde) - R sin(w/2)] / [sin(psi-tilde) + R sin(w/2)],
  sin(psi-tilde) = sqrt(1 - R^2 cos^2(w/2))

- the SAME closed form as F2's cleared critical value: it depends
only on (R, w), not on where the window sits. Two fences cut from
the same span dip to the same depth wherever they stand. No new
interior value enters the campaign.

## 4. G's candidate list

Width: d/dw log G = -kq sin(phi-w)/c(phi-w)^2 < 0 - G falls as the
width grows; box minimum at the width cap. Angle scan there: the two
endpoints plus the shared interior value where the exact comparison

  cos(phi_hi - w/2) <= R cos(w/2) <= cos(phi_lo - w/2)

places the critical point inside. Every candidate exact; the
rectangular hull is legitimate because a floor over a larger box is
still a floor - the factorwise route's own logic.

## 5. The ordering condition, honestly

## 6. F1's exact critical equation, for completeness

Cross-multiplying f(phi-w) = f(phi) and splitting the a-part from
the chord-square part:

  a[sin(phi-w)c(phi) - sin(phi)c(phi-w)]
    = 2(k^2+q^2) sin(w/2)[cos(phi - w/2) - R cos(w/2)].

At a = 0 this reduces exactly to G's critical equation: the
financing term measures the displacement of F1's own lowest point
from the bare fence's. Filed as fallback, not load-bearing.
