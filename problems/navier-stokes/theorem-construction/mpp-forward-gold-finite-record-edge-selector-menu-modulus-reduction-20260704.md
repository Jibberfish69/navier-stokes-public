# Finite record-edge selector menu modulus reduction

## 1. Same physical selector story

The object is one retained record edge in the original Navier-Stokes evolution.
It has a high packet, a low pressure/strain coefficient, a material time
window, a polarity, and a selector label reading the edge before the
signed-height record calls the edge positive.

The parent-known finite menu is lawful only if the parent can name, before the
future record is read, finitely many selector records that cover every possible
future-positive retained edge at the fixed depth and packet type.

That is a physical statement about the same fluid packet. Transport moves the
packet, pressure and strain rotate the active direction, viscosity drains
energy, incompressibility constrains volume, and the selector label records
which same-packet channel carries the positive record. If the label can change
after the event by chasing the largest future readout, the parent did not own
the edge. The readout selected the payer after the work appeared.

So a finite menu is not a finite-dimensional truncation of the velocity field.
It is a finite pre-readout atlas for the selector labels of the same retained
record edge.

## 2. Why compactness and stopped scores do not supply the menu

The stopped-score theorem proves the downstream transaction. Once an
order-locked retained selector chart has already been chosen, the score family
is finite, parent-known, and absolutely continuous in log scale; a strict reset
is a first exit of finite stopped inequalities or a paid selector/collar/legal
defect.

That theorem does not prove that every arbitrary future-positive record edge
was already in such a chart. The missing object is

\[
\texttt{FiniteParentKnownRecordEdgeSelectorMenu.A}.
\tag{FSM.1}
\]

The old selector-uniformity notes show the obstruction. A compact label set can
support moving positive spikes

\[
s(a,t)=\sum_n A_n\phi_n(a)\psi_n(t)
\tag{FSM.2}
\]

with disjoint label-time supports. Every fixed finite parent menu misses all
but finitely many late spikes, while the future supremal selector keeps
following the active label.

Physically, this is not a count of packets. It is unpaid selector motion. The
same fluid record has no parent-owned label identity; the positive face is
being reselected at readout time.

## 3. Lawful finite-menu supply

The noncircular producer is a same-record selector modulus or an equivalent
finite-complexity law. One useful form is:

\[
\texttt{RecordEdgeSelectorLabelModulusOrPaidDrift.A}.
\tag{FSM.3}
\]

At fixed depth, packet type, and retained edge class, the parent has a compact
selector label space \(K_{N,Q}\). For each retained edge \(e\), the selector
score \(s_\theta(e)\) is built from the same material packet, transported
frame, pressure-Hodge/current component, order-lock data, collar geometry,
polarity, and legal stop state.

The theorem says that for every tolerance \(\eta\) below the strict absorption
margin, the parent can choose a finite net

\[
\mathcal A_{N,Q,\eta}\subset K_{N,Q}
\tag{FSM.4}
\]

before readout, and every future-positive retained record edge satisfies either

\[
s_\theta(e)
\le
\max_{a\in\mathcal A_{N,Q,\eta}}s_a(e)
+\eta A_{\rm rec}(e)
+Err_{\rm legal}(e),
\tag{FSM.5}
\]

or the excess outside the net is paid as one of the physical selector losses:
selector drift, tie gap, order-lock partner deficit, collar/geometric loss,
heat-scale return failure, donor/reselection loss, legal loss, stop, material
service, or exit.

Equivalently, one may supply a finite-complexity partition

\[
\sup_{\theta\in C_j}s_\theta(e)
\le
C\,s_{\theta_j}(e)+r_j(e),
\qquad
\sum_j r_j(e)\ \text{is paid on the same parent ledger},
\tag{FSM.6}
\]

or an integrable label modulus

\[
|s_\theta(e)-s_{\theta'}(e)|
\le
\omega_e(d(\theta,\theta')),
\tag{FSM.7}
\]

with the modulus paid over the same material history before the record edge is
read as positive.

The point is physical: nearby selector labels must stay nearby as readings of
the same retained edge, unless the motion that separates them is charged as an
actual material/collar/order-lock/reselection event.
