# Full Hodge-Stokes Pressure Trace Defect Reduction

Date: 2026-06-21

## 0. Aim

The full packet compactness/no-loss split left the pressure trace defect

```math
Q_nV_n\cdot\nabla\chi_n
\not\to
QV\cdot\nabla\chi
\quad\text{in }L^1.
\tag{PTR.1}
```

This is too coarse.  The local pressure generated by the retained same carrier
is paid once the transport product has passed.  The true pressure obstruction is
the harmonic/nonlocal pressure memory left after that local part is removed.

The reduction is:

```math
\boxed{
\text{pressure trace defect}
\Rightarrow
\text{harmonic pressure memory, collar/gauge loss, or selector drift.}
}
\tag{PTR.2}
```

## 1. Local pressure part passes with the transport product

Work on fixed packet regions \(K\Subset K'\Subset Q_1\), and choose a spatial
cutoff \(\zeta=1\) on \(K\), supported in \(K'\).  Decompose the pressure as

```math
Q_n
=
Q_n^{loc}+H_n,
\tag{PTR.3}
```

where

```math
Q_n^{loc}
=
\mathcal R_i\mathcal R_j
\big(\zeta (V_n)_i(V_n)_j\big),
\tag{PTR.4}
```

and \(H_n\) is harmonic on the retained packet interior after the usual local
pressure decomposition.

The transport product evacuation gives

```math
V_n\otimes V_n\to V\otimes V
\quad\text{strongly in }L^{3/2}(K').
\tag{PTR.5}
```

Calderon-Zygmund boundedness then gives

```math
\boxed{
Q_n^{loc}\to Q^{loc}
\quad\text{strongly in }L^{3/2}(K).
}
\tag{PTR.6}
```

Together with \(V_n\to V\) strongly in \(L^3(K)\) and
\(\nabla\chi_n\to\nabla\chi\) uniformly,

```math
\boxed{
Q_n^{loc}V_n\cdot\nabla\chi_n
\to
Q^{loc}V\cdot\nabla\chi
\quad\text{in }L^1(K).
}
\tag{PTR.7}
```

Thus the same-carrier local pressure trace is not the live pressure wall.

## 2. Harmonic pressure memory is the real remainder

The remaining pressure term is

```math
H_nV_n\cdot\nabla\chi_n.
\tag{PTR.8}
```

Weak \(L^{3/2}\) pressure compactness does not by itself give strong
convergence of this term.  The harmonic part can carry nonlocal pressure
information from outside the retained packet, and it can move in time even when
it is spatially smooth on each fixed slice.

So the pressure trace defect reduces to:

```math
\boxed{
H_nV_n\cdot\nabla\chi_n
\not\to
HV\cdot\nabla\chi
\quad\text{in }L^1,
}
\tag{PTR.9}
```

or to failure of the selected pressure gauge/collar to remain on the same
carrier.

## 3. Corrected defect name

The corrected pressure defect is not generic pressure failure.  It is:

```math
\boxed{
\text{PressureMemoryCollarTraceDefect.A}
}
\tag{PTR.10}
```

meaning that the nonlocal harmonic pressure, affine-pressure gauge, or collar
trace fails to converge in the selected full Hodge-Stokes packet.

## 4. Current result

Combining transport product evacuation with the local pressure decomposition:

```math
\boxed{
\text{local same-carrier pressure trace passes;}
\qquad
\text{harmonic pressure memory/collar trace remains open.}
}
\tag{PTR.11}
```

The remaining no-loss production wall is therefore not the full pressure
channel.  It is the nonlocal pressure-memory/collar piece, plus viscous measure,
selector graph, signed saturation, terminal trace, and legal routing.
