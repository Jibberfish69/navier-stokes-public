# Full Hodge-Stokes Remaining Defect Core

Date: 2026-06-21

## 0. Aim

This note states the exact residual theorem for the corrected full
Hodge-Stokes route.

The selected packet must first carry the full local participation tuple:

```math
R_{j,Q}+N_{j,Q}+P_{j,Q}+V_{j,Q}=L_{j,Q},
\qquad
I_{j,Q}\text{ retained on the same carrier.}
\tag{RDC.1}
```

After that tuple is retained, scalar estimates may enter only as cleanup.

The theorem is:

```math
\boxed{
\text{full-packet no-loss fails}
\Rightarrow
\mathcal R_{\rm sel}
\cup
\mathcal R_{\rm sat}
\cup
\mathcal R_{\rm jump}
\cup
\mathcal R_{\rm legal}.
}
\tag{RDC.2}
```

where the four residuals are:

```math
\mathcal R_{\rm sel}
=
\text{unbounded positive-part selector complexity or carrier drift,}
\tag{RDC.3}
```

```math
\mathcal R_{\rm sat}
=
\text{missing negative signed partner }dN_{\rm miss},
\tag{RDC.4}
```

```math
\mathcal R_{\rm jump}
=
\text{positive endpoint storage jump }[dM_\ast(\{0\})]_+,
\tag{RDC.5}
```

and

```math
\mathcal R_{\rm legal}
=
\text{non-summable or non-terminal-AC legal/collar residual.}
\tag{RDC.6}
```

## 1. Components already reduced

Transport is not a residual on a fixed carrier:

```math
V_n\otimes V_n\to V\otimes V
\quad\text{strongly in }L^{3/2}.
\tag{RDC.7}
```

The local pressure generated by that transport product passes:

```math
Q_n^{loc}V_n\cdot\nabla\chi_n
\to
Q^{loc}V\cdot\nabla\chi
\quad\text{in }L^1.
\tag{RDC.8}
```

The harmonic pressure remainder is a collar trace:

```math
H_nV_n\cdot\nabla\chi_n\,dy\,ds
\quad\text{is supported on }\operatorname{collar}(\chi_n),
\tag{RDC.9}
```

so it belongs to legal/collar routing, terminal trace, or selector/collar
drift.

The viscous defect is paid or gives strong convergence:

```math
\mu^\nu\ne0
\Rightarrow
\text{visible viscous payment},
\qquad
\mu^\nu=0
\Rightarrow
\nabla V_n\to\nabla V\text{ strongly in }L^2.
\tag{RDC.10}
```

Finite or compact selector graphs close by subsequence or compactness.  Only
unbounded positive-part selector complexity or carrier/collar drift remains:

```math
\text{selector graph failure}
\Rightarrow
\mathcal R_{\rm sel}.
\tag{RDC.11}
```

Terminal trace atoms route through the signed atom balance:

```math
\mu_\ast^+(\{0\})
\le
\mu_\ast^-(\{0\})
+
\Lambda_\ast(\{0\})
+
[dM_\ast(\{0\})]_+.
\tag{RDC.12}
```

The loss term is visible payment, the negative terminal countertrace is signed
saturation, and the storage term is \(\mathcal R_{\rm jump}\).

## 2. Proof of residual core

Assume full-packet no-loss fails after `(RDC.1)` has been retained.

The transport, local pressure, harmonic pressure, viscous, finite-selector, and
terminal-trace reductions remove all other listed compactness/no-loss defects
or route them into named channels:

```math
\text{transport/local-pressure/viscous failures}
\Rightarrow
\text{passed or visible payment;}
\tag{RDC.13}
```

```math
\text{harmonic pressure}
\Rightarrow
\mathcal R_{\rm legal}\cup\mathcal R_{\rm jump}\cup\mathcal R_{\rm sel};
\tag{RDC.14}
```

```math
\text{selector graph failure}
\Rightarrow
\mathcal R_{\rm sel};
\tag{RDC.15}
```

```math
\text{terminal trace atom}
\Rightarrow
\mathcal R_{\rm sat}\cup\mathcal R_{\rm jump}
\quad\text{or visible loss.}
\tag{RDC.16}
```

The positive selected density still has the polar identity

```math
dA_{\mathcal S}
=
dJ_{\mathcal S}+dN_{\mathcal S},
\qquad
dN_{\mathcal S}=dN_{\rm ret}+dN_{\rm legal}+dN_{\rm miss}.
\tag{RDC.17}
```

If \(dN_{\rm miss}\ne0\), this is \(\mathcal R_{\rm sat}\).  If
\(dN_{\rm miss}=0\) or is legally charged, and if \(\mathcal R_{\rm sel}\),
\(\mathcal R_{\rm jump}\), and \(\mathcal R_{\rm legal}\) are absent, then the
positive selected carrier converges in total variation by the \(L^1\)
Lipschitz property of \(a\mapsto[a]_+\):

```math
[h_n]_+\to[h]_+
\quad\text{in }L^1.
\tag{RDC.18}
```

Thus full-packet no-loss cannot fail.

Contrapositively, if full-packet no-loss fails, one of
`(RDC.3)`--`(RDC.6)` occurs.  This proves `(RDC.2)`.

## 3. Current result

The compactness/no-loss branch is now exact:

```math
\boxed{
\text{full-tuple retention}
+
\neg\mathcal R_{\rm sel}
+
\neg\mathcal R_{\rm sat}
+
\neg\mathcal R_{\rm jump}
+
\neg\mathcal R_{\rm legal}
\Longrightarrow
\text{same-carrier selected positive no-loss.}
}
\tag{RDC.19}
```

The remaining production problem is exactly to exclude or charge the four
residuals.  The old breaker estimates cannot be used to do that before the
tuple assignment `(RDC.1)` has been made.
