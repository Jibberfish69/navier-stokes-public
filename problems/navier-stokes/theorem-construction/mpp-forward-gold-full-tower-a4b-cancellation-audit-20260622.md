# Full Tower A4B Cancellation Audit

Date: 2026-06-22

## 0. Audit question

The previous note proved the local normal-form identity

```math
d[\log(1+\mathcal P_N)]_+
\le
C\,dA_{4B,N}^{ann}
\tag{FTA.1}
```

provided \(A_{4B,N}^{ann}\) is the full tower-level same-carrier annular
activity containing metric strain, coefficient commutators, velocity tower,
pressure service, viscous/collar service, strain-vorticity geometry service,
selector/collar service, and Body-I radius-spend/exchange.

The audit question is whether the existing oriented four-body cancellation
already proves

```math
\int_{\sigma_0}^{\infty} A_{4B,N}(\sigma)\,d\sigma<\infty
\tag{FTA.2}
```

for that enlarged object.

## 1. What is already proved

The abstract oriented four-body mechanism has the shape

```math
A_1+E_{12}\le E_{41}-\partial_\sigma\Phi_1,
```

```math
A_2+E_{23}\le E_{12}-\partial_\sigma\Phi_2,
```

```math
A_3+E_{34}\le E_{23}-\partial_\sigma\Phi_3,
```

```math
A_4+E_{41}\le E_{34}-\partial_\sigma\Phi_4.
\tag{FTA.3}
```

Summing cancels the internal exchanges and yields

```math
A_{4B}:=A_1+A_2+A_3+A_4
\le
-\partial_\sigma\Phi_{4B}.
\tag{FTA.4}
```

If \(\Phi_{4B}\) is bounded from below and has finite entrance value, then

```math
\int A_{4B}<\infty .
\tag{FTA.5}
```

Body-I also has an exact tower normal form:

```math
dL_S+dD_S^{rad}=dJ_{SQ}.
\tag{FTA.6}
```

This shows that factorial weights and radius spend can be oriented as a
scale/tower body exchange.

## 2. What is not yet proved

The Body-I normal form explicitly does not prove selected terminal activity
control. Its own missing theorem has the form

```math
dA_{sel}
\le
C\,dD_S^{rad}+C\,dR_S
\tag{FTA.7}
```

or a lossless tower-cycle rigidity alternative.

The newly defined full tower-level annular activity is larger than the
lower-order annular stress/energy activity. It contains, in particular,

```math
d\mathcal A_N^{metric},\quad
 d\mathcal A_N^{coeff},\quad
 d\mathcal A_N^{comm},\quad
 d\mathcal A_N^{press},\quad
 d\mathcal A_N^{visc/collar},\quad
 d\mathcal A_N^{geom},\quad
 d\mathcal A_N^{rad}.
\tag{FTA.8}
```

The current oriented cancellation theorem has not been verified for this exact
expanded list. In particular:

1. The metric strain-clock channel is not controlled by lower-order energy; it
must be a Body-IV activity term.

2. Coefficient and velocity tower commutators are generated by differentiated
material equations, but the existing four-body cancellation has not been shown
to orient all of them with adjacent exchanges that cancel.

3. Pressure service is derived from the pressure term plus differentiated
incompressibility, but it still requires a pressure-compatible same carrier and
an oriented Body-II exchange slot.

4. Body-I radius spend is installed, but selected terminal participation
activity domination by radius spend is explicitly not installed.

Therefore `(FTA.2)` is not currently proved for the enlarged object `(FTA.8)`.

## 3. Exact failure of the naive closure

The invalid shortcut is:

```math
\text{generated by the material equations}
\quad\Longrightarrow\quad
\text{controlled by }\int A_{4B}.
\tag{FTA.9}
```

The valid implication is only:

```math
\text{generated by the material equations}
\quad\Longrightarrow\quad
\text{eligible as a same-carrier four-body channel.}
\tag{FTA.10}
```

Eligibility is not cancellation control. Cancellation control requires an
oriented four-body inequality for the exact channel list.

## 4. Correct next theorem

The missing theorem is:

```math
\boxed{\texttt{FullTowerFourBodyCancellation.A}}
```

with statement:

```math
\boxed{
\begin{aligned}
&\text{On one fixed transported annular atlas and same material gauge,}\
&\text{the full tower channel list }(FTA.8)\text{ admits oriented exchanges}\
&\text{between Body I, Body II, Body III, and Body IV so that}\
&\int_{\sigma_0}^{\infty}A_{4B,N}(\sigma)\,d\sigma<\infty .
\end{aligned}}
\tag{FTA.11}
```

The proof must provide four inequalities of the form `(FTA.3)` for the enlarged
activity, not merely identify the terms.
