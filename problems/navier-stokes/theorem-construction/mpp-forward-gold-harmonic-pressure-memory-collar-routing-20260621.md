# Harmonic Pressure Memory Collar Routing

Date: 2026-06-21

## 0. Aim

After the local pressure generated by the retained packet passes, the remaining
pressure term is the harmonic/nonlocal pressure memory:

```math
H_nV_n\cdot\nabla\chi_n.
\tag{HPC.1}
```

This is not an interior hidden source.  It lives where \(\nabla\chi_n\) lives,
namely on the packet collar.

The routing statement is:

```math
\boxed{
\text{harmonic pressure memory}
\Rightarrow
\text{collar pressure-flux trace, terminal trace atom, or legal routing.}
}
\tag{HPC.2}
```

## 1. Collar support

In the localized energy packet, the harmonic pressure component contributes
through

```math
\lambda_n^H
=
H_nV_n\cdot\nabla\chi_n\,dy\,ds.
\tag{HPC.3}
```

Since \(\nabla\chi_n\) is supported on the collar,

```math
\operatorname{spt}\lambda_n^H
\subset
\operatorname{collar}(\chi_n).
\tag{HPC.4}
```

So this term cannot be counted as a free interior source on the retained core.
It is a pressure-flux trace across the cutoff/collar.

## 2. Routing dichotomy

If the collar pressure-flux measures are uniformly terminal absolutely
continuous or summable, then

```math
\boxed{
\lambda_n^H
\text{ is legal/collar paid.}
}
\tag{HPC.5}
```

If not, there is a terminal trace defect:

```math
\boxed{
\lambda_n^H
\rightharpoonup
\lambda^H+a_H\delta_{s=0},
\qquad
a_H\ne0,
}
\tag{HPC.6}
```

or the carrier/collar itself has drifted, which belongs to the selector graph
defect.

Thus the pressure-memory remainder has only three homes:

```math
\boxed{
\text{legal collar payment}
\quad\text{or}\quad
\text{terminal trace atom}
\quad\text{or}\quad
\text{selector/collar drift.}
}
\tag{HPC.7}
```

## 3. Current result

The pressure trace branch is now fully routed:

```math
\boxed{
\text{local pressure passes;}
\qquad
\text{harmonic pressure memory is collar/terminal/legal.}
}
\tag{HPC.8}
```

So pressure is no longer a separate same-carrier compactness/no-loss wall after
the local Calderon-Zygmund part has passed.  It feeds the remaining terminal
trace, legal routing, or selector graph problem.
