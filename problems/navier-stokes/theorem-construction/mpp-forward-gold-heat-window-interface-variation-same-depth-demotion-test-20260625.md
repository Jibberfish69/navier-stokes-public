# Heat-Window Interface Variation Same-Depth Demotion Test

Date: 2026-06-25

## 0. Object

The previous note proved that the active shell pump

```math
m_j(t)=P_j(t)+C_j(t)
\tag{HWV.1}
```

has exact variation density

```math
\mathcal Z_j^{iface}(t)=|\dot P_j(t)|+|\dot C_j(t)|.
\tag{HWV.2}
```

The rectified feed estimate on an interval \(I\) was

```math
\int_I[m_j]_+
\le
[e_j(b)-e_j(a)]_+
+\int_I d_j
+|I|\int_I\mathcal Z_j^{iface}(t)\,dt .
\tag{HWV.3}
```

For the terminal heat-scale sample attached to shell \(j\), the interval
length satisfies

```math
|I_j|\simeq 2^{-2j}.
\tag{HWV.4}
```

Therefore the actual variation contribution is not
\(\mathcal Z_j^{iface}\) by itself.  It is the heat-window-demoted density

```math
\mathcal W_j^{iface}(t)
:=
2^{-2j}\mathcal Z_j^{iface}(t).
\tag{HWV.5}
```

The question is whether \(\mathcal W_j^{iface}\), not
\(\mathcal Z_j^{iface}\), is controlled at the same continuation depth.

## 1. Pressure-interface demotion

Write

```math
F_j:=\Delta_j^a(A^\top\nabla_aq),
\qquad
L_j:=\Delta_j^a\operatorname{div}_a(G\nabla_av).
\tag{HWV.6}
```

The shell equation is

```math
\dot v_j=-F_j+\nu L_j .
\tag{HWV.7}
```

The pressure-interface derivative from the previous note is

```math
\dot P_j
=
-w_j\langle \Delta_j^a(\dot A^\top\nabla_aq),v_j\rangle
-w_j\langle \Delta_j^a(A^\top\nabla_a\dot q),v_j\rangle
-w_j\langle F_j,\dot v_j\rangle .
\tag{HWV.8}
```

Substitute `(HWV.7)` into the last term:

```math
-w_j\langle F_j,\dot v_j\rangle
=
w_j\|F_j\|_2^2
-\nu w_j\langle F_j,L_j\rangle .
\tag{HWV.9}
```

Multiplying by the heat-window factor gives

```math
2^{-2j}|\dot P_j|
\le
w_j2^{-2j}\|F_j\|_2^2
+\nu w_j2^{-2j}|\langle F_j,L_j\rangle|
+w_j2^{-2j}|\langle \Delta_j^a(\dot A^\top\nabla_aq),v_j\rangle|
+w_j2^{-2j}|\langle \Delta_j^a(A^\top\nabla_a\dot q),v_j\rangle|.
\tag{HWV.10}
```

This is same-depth.  The factor \(2^{-2j}\) cancels the parabolic time
derivative cost.  The terms in `(HWV.10)` are:

```math
\text{pressure-gradient service}
+\text{pressure-viscous service}
+\text{coefficient/strain pressure service}
+\text{pressure-time elliptic service}.
\tag{HWV.11}
```

All four belong to the same transported material packet.

## 2. Pressure-time term is not a free signal

The pressure equation is

```math
L_Gq=R,
\qquad
L_G=-\operatorname{div}_a(G\nabla_a),
\tag{HWV.12}
```

so

```math
L_G\dot q=\dot R-\dot L_Gq .
\tag{HWV.13}
```

The operator derivative is

```math
\dot L_Gf
=
-\operatorname{div}_a(\dot G\nabla_af),
\qquad
\dot G=-2ASA^\top .
\tag{HWV.14}
```

The right-hand side derivative \(\dot R\) is generated by

```math
D_t(\nabla_xu)
=
-(\nabla_xu)^2-\nabla_x^2p+\nu\Delta_x\nabla_xu .
\tag{HWV.15}
```

pulled back to the same material annulus.  Thus

```math
2^{-2j}w_j
|\langle \Delta_j^a(A^\top\nabla_a\dot q),v_j\rangle|
\tag{HWV.16}
```

is a same-depth pressure-strain/pressure-Hessian/viscous-tower service.  It is
not an arbitrary endpoint-time signal.

## 3. Viscous-commutator demotion

The viscous commutator was

```math
B_j(v,G)
=
\Delta_j^a\operatorname{div}_a(G\nabla_av)
-
\operatorname{div}_a(G\nabla_av_j),
\tag{HWV.17}
```

and

```math
\dot C_j
=
\nu w_j\langle \dot B_j(v,G),v_j\rangle
+
\nu w_j\langle B_j(v,G),\dot v_j\rangle .
\tag{HWV.18}
```

The exact derivative is

```math
\begin{aligned}
\dot B_j(v,G)
={}&
\Delta_j^a\operatorname{div}_a(\dot G\nabla_av)
-
\operatorname{div}_a(\dot G\nabla_av_j)\\
&+
\Delta_j^a\operatorname{div}_a(G\nabla_a\dot v)
-
\operatorname{div}_a(G\nabla_a\dot v_j).
\end{aligned}
\tag{HWV.19}
```

The terms with \(\dot G\) are coefficient/strain variation terms.  The terms
with \(\dot v\) contain one parabolic time derivative.  On shell \(j\), the
heat-window factor demotes them:

```math
2^{-2j}\nu w_j
|\langle
\Delta_j^a\operatorname{div}_a(G\nabla_a\dot v)
-
\operatorname{div}_a(G\nabla_a\dot v_j),
v_j\rangle|
\tag{HWV.20}
```

is same-depth viscous/tower service after substituting

```math
\dot v=-A^\top\nabla_aq+\nu\operatorname{div}_a(G\nabla_av).
\tag{HWV.21}
```

The apparent extra two derivatives in `(HWV.20)` are exactly the derivatives
paid by the heat-time factor \(2^{-2j}\) and the high-shell viscous scale
\(2^{2j}\).  No uncontrolled \(N+2\) material record is required merely from
taking the time derivative.

## 4. Heat-window rectified estimate

For every active heat interval \(I_j\),

```math
|I_j|\int_{I_j}\mathcal Z_j^{iface}(t)\,dt
\lesssim
\int_{I_j}\mathcal W_j^{iface}(t)\,dt,
\tag{HWV.22}
```

where \(\mathcal W_j^{iface}\) is the sum of the same-depth terms listed in
`(HWV.10)`, `(HWV.16)`, and `(HWV.20)`.

Therefore `(HWV.3)` becomes

```math
\int_{I_j}[m_j]_+
\le
[e_j(b)-e_j(a)]_+
+\int_{I_j}d_j
+C\int_{I_j}\mathcal W_j^{iface}(t)\,dt .
\tag{HWV.23}
```

The physical meaning is direct: during one active heat window, repeated
up/down return of the same annular interface can only be caused by same-depth
pressure service, viscous service, coefficient/strain variation, or collar
variation of the original material packet.
