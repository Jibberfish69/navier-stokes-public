# Initial-Frequency Route Nonclosure At Cubic/Pressure Clock

Date: 2026-06-25

## 0. Same physical object

The object is one original smooth material spike-wave history.  The annular
layers are transported by that history, and the frequency decomposition is only
a reading of the same pressure-viscosity-incompressibility-velocity packet.

The gauge-reduced annular stress-work flux is

```math
F_\phi^\sharp(t)
=
\int U_iT^\sharp_{ij}\partial_j\phi\,dx,
\qquad
T^\sharp=-PI+2\nu S(U),
\qquad
D_t\phi=0 .
\tag{IFN.1}
```

The frequency-controlled route correctly proves that \(F_\phi^\sharp\) is not a
free time signal.  Its derivative is generated by

```math
\begin{aligned}
\mathcal S_\phi^\sharp
:={}&
|\nabla\cdot T^\sharp|\,|T^\sharp|\,|\nabla\phi|
+
|U|\,|\nabla(-\Delta)^{-1}\mathcal E_P|\,|\nabla\phi|\\
&+
|\nabla\cdot T^\sharp|\,|U|\,|\nabla^2\phi|
+
|\nabla\cdot T^\sharp|\,|\nabla U|\,|\nabla\phi|\\
&+
|U|\,|\nabla U|^2|\nabla\phi|
+
|U|\,|T^\sharp|\,|\nabla U|\,|\nabla\phi| .
\end{aligned}
\tag{IFN.2}
```

The target estimate is

```math
\int_0^{T_*}
\sum_j2^{\gamma j}
\|\Delta_j\mathcal S_\phi^\sharp(t)\|_{L^1_x}\,dt
<\infty .
\tag{IFN.3}
```

## 1. What smooth initial data pays

For every fixed continuation depth \(M\), smooth initial data gives

```math
\sum_j2^{Mj}\|\Delta_ju_0\|_2<\infty .
\tag{IFN.4}
```

The heat part satisfies

```math
\|\nabla^m\Delta_j e^{\nu t\Delta}u_0\|_2
\lesssim
2^{mj}e^{-c\nu2^{2j}t}\|\Delta_ju_0\|_2 .
\tag{IFN.5}
```

Thus the entrance spectrum and the linear viscous tail cannot be the source of
an infinite terminal annular return bill.  Any remaining bill is nonlinear
transfer inside the same material packet.

## 2. The cubic collar term already exceeds raw energy

The term

```math
\int |U|\,|\nabla U|^2|\nabla\phi|\,dx
\tag{IFN.6}
```

is the simplest obstruction inside `(IFN.2)`.  Ignoring the harmless bounded
collar factor, the natural global estimate is

```math
\int |U|\,|\nabla U|^2\,dx .
\tag{IFN.7}
```

Energy gives

```math
U\in L^\infty_tL^2_x,
\qquad
\nabla U\in L^2_{t,x}.
\tag{IFN.8}
```

These bounds do not control `(IFN.7)` in time.  At shell level, the same strain
calculation already gives the sharpened bound

```math
\mathcal R_{sh}^{strain}(t)
\le
C E_0^{1/4}D(t)^{5/4},
\qquad
D(t)=\|\nabla u(t)\|_2^2 .
\tag{IFN.9}
```

The energy inequality supplies

```math
\int_0^{T_*}D(t)\,dt<\infty,
\tag{IFN.10}
```

not

```math
\int_0^{T_*}D(t)^{5/4}\,dt<\infty .
\tag{IFN.11}
```

So the cubic collar coordinate of the same annular history is already
continuation-strength.  It is not paid by finite initial amplitude plus raw
energy depletion.

## 3. Pressure-time is the same full material clock

The pressure-time term in `(IFN.2)` is

```math
|U|\,|\nabla(-\Delta)^{-1}\mathcal E_P|\,|\nabla\phi|.
\tag{IFN.12}
```

The source \(\mathcal E_P\) is obtained by applying \(D_t\) to the pressure
constraint

```math
-\Delta P=\partial_iU_j\,\partial_jU_i .
\tag{IFN.13}
```

Using \(D_tU=\nabla\cdot T^\sharp\), this source contains the same spatial
stress/velocity tower:

```math
\mathcal E_P
=
\partial^2T^\sharp\,\partial U
+
(\partial U)^3
+
\partial U\,\partial^2P
+
\Delta U\,\nabla P
\quad
\text{same-packet lower collar/commutator terms}.
\tag{IFN.14}
```

This is not pressure in isolation.  It is the pressure/incompressibility
coordinate of the same annular stress/strain return.  Controlling `(IFN.12)` is
therefore equivalent to controlling the full material pressure service clock at
the same continuation depth.

## 4. Exact conclusion

The frequency-controlled physical picture proves the correct attachment:

```math
\text{terminal annular return}
\quad\text{comes from original spectrum plus nonlinear same-packet transfer.}
\tag{IFN.15}
```

It also proves the initial and linear pieces are paid:

```math
\text{smooth }u_0+\text{linear viscosity}
\quad\Longrightarrow\quad
\text{finite entrance/linear high-frequency bill.}
\tag{IFN.16}
```

The remaining nonlinear transfer is exactly

```math
\boxed{
\int_0^{T_*}
\sum_j2^{\gamma j}
\|\Delta_j\mathcal S_\phi^\sharp(t)\|_{L^1_x}\,dt
<\infty .
}
\tag{IFN.17}
```

This estimate contains the cubic collar clock `(IFN.11)` and the pressure-time
elliptic service `(IFN.12)`.  Therefore the finite-initial-frequency route is a
real reduction to the full same-material clock, but it is not a proof of that
clock from the current installed inputs.

The exact remaining proof obligation stays:

```math
\boxed{
\text{prove finite nonlinear same-material pressure/strain/stress-transfer
clock for the original transported history.}
}
\tag{IFN.18}
```

Any later proof must pay `(IFN.17)` directly or construct a bounded-below
same-material storage whose drop controls it.  A proof that pays only the
initial spectrum, only linear viscosity, only net stress-work, or only a
fixed-threshold velocity tail does not close the MPP gold route.
