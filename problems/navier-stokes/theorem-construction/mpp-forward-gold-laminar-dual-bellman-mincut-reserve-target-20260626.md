# Laminar dual Bellman / min-cut reserve target

Status: proposal corrected. The cumulative test displayed below is not the
Bellman dual for the root reserve. The corrected monotone-tree dual is equivalent
to `RootPositiveFluxReserveCoercivity.A`, not a proof of it.

## 1. Why this is better

The current edge is `RootPositiveFluxReserveCoercivity.A` on the selected laminar high-ratio ancestry forest. Direct constructions keep cycling:

- raw ledgers are finite but too weak;
- descendant-tail reserves inherit perfectly but are tautological;
- pressure-Hodge capacity gives a concrete representation but asks for the selected critical-strain reserve;
- no-Zeno splits into repeated-core root variation or shrinking-core selected-capacity no-escape.

The better target is to stop guessing the reserve and derive it by duality on the laminar tree.

## 2. Primal first-ratio action

Let `T` be the selected laminar high-ratio ancestry tree. Each retained node `Q` carries selected action `A(Q)`. The Gold wall is

```math
\sum_{Q\in T} A(Q)<\infty,
```

which is equivalent to the first ratio moment

```math
\sum_{\ell\ge0}2^\ell\nu_\ell<\infty.
```

## 3. Proposed dual test formulation

Instead of building a reserve directly, test the first-ratio action against all nonnegative laminar weights `\alpha_Q` satisfying the tree admissibility constraint

```math
\sum_{Q\subset R}\alpha_Q\le 1
\qquad\text{for every ancestry node }R.
```

The target dual estimate is

```math
\sum_{Q\in T}\alpha_Q A(Q)
\le C_N(u_0)+R_{legal}
\tag{LDB.1}
```

uniformly over all such admissible `\alpha`.

This is not enough to test the total first-ratio action. Taking `R` to be the
root already gives:

```math
\sum_{Q\in T}\alpha_Q\le 1.
```

Therefore this class can put weight only on a bounded amount of the tree. It
tests a normalized selected subfamily, not the full action

```math
\sum_{Q\in T}A(Q).
```

With this constraint, `(LDB.1)` does not imply the Gold tail.

## 4. Correct Bellman dual

For the inheritance inequality

```math
\sum_{Q'\in ch(Q)}A(Q')+\sum_{Q'\in ch(Q)}B(Q')
\le B(Q)+R_{legal}(Q),
```

the finite-tree linear-programming dual uses monotone ancestry multipliers:

```math
0\le \alpha_{Q'}\le \alpha_Q\le 1
\qquad
(Q'\in ch(Q)).
```

The constant test

```math
\alpha_Q\equiv 1
```

is admissible. Thus the corrected dual estimate:

```math
\sum_{Q\in T}\alpha_Q A(Q)
\le C_N(u_0)+R_{legal}
\tag{LDB.2}
```

for every monotone ancestry multiplier immediately includes:

```math
\sum_{Q\in T}A(Q)
\le C_N(u_0)+R_{legal}.
```

So the corrected dual is not a smaller theorem. It is exactly the root-reserve
coercivity theorem written in adjoint multiplier form.

By laminar tree duality, `(LDB.2)` is equivalent to the existence of a nonnegative Bellman reserve `B(Q)` satisfying the parent-child inheritance inequality

```math
\sum_{Q'\in ch(Q)}A(Q')+\sum_{Q'\in ch(Q)}B(Q')
\le B(Q)+R_{legal}(Q),
```

with finite root value.

Thus the reserve is not guessed; it is the dual certificate of the weighted laminar action bound.

## 5. PDE content of the corrected dual estimate

For a fixed monotone admissible `\alpha`, form the selected stress-test measure

```math
\mathcal M_\alpha
:=\sum_{Q\in T}\alpha_Q\,\mu_Q^{sel},
```

where `\mu_Q^{sel}` is the pressure-Hodge / critical-strain carrier of node `Q` transported on the original material history.

The PDE theorem that would close the route is:

```math
\boxed{\text{LaminarAdjointStressTestEstimate.A}}
```

Statement:

For every monotone laminar ancestry multiplier `\alpha`, the associated adjoint pressure-Hodge stress test is bounded by the original-data legal ledgers:

```math
\langle \mathcal M_\alpha,1\rangle
\le C_N(u_0)+R_{legal}.
```

Equivalently, the backward adjoint transport-elliptic response generated by `\mathcal M_\alpha` has legal energy.

The important point is that this must hold for `\alpha_Q\equiv 1`. Therefore it
must bound the whole selected laminar high-ratio action, not just a sparse
subfamily. A proof of this estimate would be a real proof of the root reserve;
the dual formulation alone does not supply new coercivity.

If the corrected dual estimate holds, it produces the root reserve
