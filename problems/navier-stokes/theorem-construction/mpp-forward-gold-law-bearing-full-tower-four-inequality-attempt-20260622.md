## 2. Body I status

The installed Body-I normal form gives

```math

\tag{FTI.11}
```

This is a valid signed tower-radius identity. It proves that factorial weights
remove fake binomial growth and that radius spend is a genuine nonnegative
scale/tower activity.

But `(FTI.11)` is not yet `(FTI.1)`, because `(FTI.1)` requires an incoming
geometry-to-scale current \(dJ_{GS}\) and a sign convention matching the rest of
the loop. The current construction has a tower output current, but it has not
installed the Body-IV return current as an actual signed input to Body I.

So Body I closes only conditionally on a constructed \(J_{GS}\).
