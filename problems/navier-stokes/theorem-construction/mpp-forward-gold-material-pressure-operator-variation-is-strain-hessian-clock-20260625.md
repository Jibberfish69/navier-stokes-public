# Material Pressure Operator Variation Is Strain-Hessian Clock

Date: 2026-06-25

## 0. Object

The live object is still one original smooth material history:

```math
\dot X(a,t)=u(X(a,t),t),
\qquad
v(a,t)=u(X(a,t),t),
\qquad
q(a,t)=p(X(a,t),t).
\tag{SHC.1}
```

Let

```math
F=D_aX,
\qquad
A=F^{-1},
\qquad
G=AA^\top,
\tag{SHC.2}
```

and let

```math
B=(\nabla_xu)\circ X,
\qquad
S={B+B^\top\over2},
\qquad
\Omega={B-B^\top\over2}.
\tag{SHC.3}
```

The material pressure operator is

```math
L_G f=-\partial_{a_\ell}(G_{\ell k}\partial_{a_k}f).
\tag{SHC.4}
```

The previous note reduced the live producer to finite variation of \(L_G\),
its pressure RHS, and the transported collar.  This note rewrites that target
in the physical variables of the same annulus.

## 1. First operator derivative

The material deformation obeys

```math
\dot F=BF.
\tag{SHC.5}
```

Therefore

```math
\dot A=-AB.
\tag{SHC.6}
```

Since \(G=AA^\top\),

```math
\dot G
=
\dot A A^\top+A\dot A^\top
=
-AB A^\top-AB^\top A^\top
=
-2ASA^\top .
\tag{SHC.7}
```

Consequently

```math
\dot L_G f
=
-\partial_{a_\ell}(\dot G_{\ell k}\partial_{a_k}f)
=
2\,\partial_{a_\ell}\!\left((ASA^\top)_{\ell k}\partial_{a_k}f\right).
\tag{SHC.8}
```

So the first material pressure-operator variation is exactly the pulled-back
strain of the same fluid annulus.

## 2. Second operator derivative

Differentiate `(SHC.7)`:

```math
\ddot G
=
-2\left(
\dot A SA^\top
+A\dot S A^\top
+AS\dot A^\top
\right).
\tag{SHC.9}
```

The material strain equation is

```math
D_tS+S^2+\Omega^2+(\nabla_x^2p)\circ X
=
\nu(\Delta_xS)\circ X.
\tag{SHC.10}
```

Hence

```math
\dot S
=
-S^2-\Omega^2-(\nabla_x^2p)\circ X
+\nu(\Delta_xS)\circ X.
\tag{SHC.11}
```

Substituting `(SHC.6)` and `(SHC.11)` into `(SHC.9)` gives the exact content
of the second operator variation:

```math
\ddot G
\in
\operatorname{Alg}\left(
A,\ S,\ B,\ \Omega,\ (\nabla_x^2p)\circ X,\ \nu(\Delta_xS)\circ X
\right),
\tag{SHC.12}
```

where `Alg` means the finite multilinear expression displayed by
`(SHC.9)`--`(SHC.11)`, with no external source.

Thus

```math
\ddot L_G f
=
-\partial_{a_\ell}(\ddot G_{\ell k}\partial_{a_k}f)
\tag{SHC.13}
```

is generated by the same strain, vorticity/rotation, pressure-Hessian, and
viscous-diffusion service of the original material packet.

## 3. Pressure RHS derivatives

The material pressure RHS is

```math
R
=
A_{\ell i}A_{kj}
(\partial_{a_\ell}v_j)(\partial_{a_k}v_i).
\tag{SHC.14}
```

Since

```math
A_{\ell i}\partial_{a_\ell}v_j
=
\partial_{x_i}u_j\circ X
=
B_{ji},
\tag{SHC.15}
```

we have

```math
R=\operatorname{tr}(B^2)
=
\operatorname{tr}(S^2)+\operatorname{tr}(\Omega^2).
\tag{SHC.16}
```

The material gradient equation is

```math
D_tB+B^2+(\nabla_x^2p)\circ X
=
\nu(\Delta_xB)\circ X.
\tag{SHC.17}
```

Therefore

```math
\dot R
=
2\operatorname{tr}(B\dot B),
\tag{SHC.18}
```

with

```math
\dot B
=
-B^2-(\nabla_x^2p)\circ X+\nu(\Delta_xB)\circ X.
\tag{SHC.19}
```

Differentiating once more,

```math
\ddot R
=
2\operatorname{tr}(\dot B^2+B\ddot B),
\tag{SHC.20}
```

and \(\ddot B\) is obtained by applying \(D_t\) to `(SHC.19)`.  Thus \(\dot R\)
and \(\ddot R\) are also same-packet strain/pressure-Hessian/viscous-tower
terms.

## 4. Collar derivative

For a transported material cutoff \(\psi(a)\), the material collar vector is

```math
B_\psi=A^\top\nabla_a\psi .
\tag{SHC.21}
```

Since \(\psi\) is fixed in material variables,

```math
\dot B_\psi=\dot A^\top\nabla_a\psi,
\qquad
\ddot B_\psi=\ddot A^\top\nabla_a\psi .
\tag{SHC.22}
```

Using `(SHC.6)` and its derivative, the collar variation is again coefficient
deformation generated by the same velocity-gradient history.

## 5. Exact replacement of the live producer

Let \(\mathcal R_N^{op}\) be the operator/RHS/collar variation density from
the previous collapse note.  At fixed continuation depth \(N\), `(SHC.8)`,
`(SHC.12)`, `(SHC.18)`, `(SHC.20)`, and `(SHC.22)` give the exact replacement

```math
\mathcal R_N^{op}
\simeq_N
\mathcal R_N^{strain\text{-}Hess},
\tag{SHC.23}
```

where \(\mathcal R_N^{strain\text{-}Hess}\) is the finite sum of the same
material \(N\)-depth norms of

```math
ASA^\top,\quad
\dot A,\quad
\ddot A,\quad
S^2,\quad
\Omega^2,\quad
(\nabla_x^2p)\circ X,\quad
\nu(\Delta_xS)\circ X,
\tag{SHC.24}
```

and the corresponding \(D_t\)-derivatives required by \(\dot R\), \(\ddot R\),
\(\dot B_\psi\), and \(\ddot B_\psi\).

This is an equivalence of finite sums of the displayed terms at the fixed
readout depth; it is not a new estimate.

Therefore the current live producer

```math
\int_0^{T_*}\mathcal R_N^{op}(t)\,dt<\infty
\tag{SHC.25}
```

is exactly the physical statement

```math
\int_0^{T_*}\mathcal R_N^{strain\text{-}Hess}(t)\,dt<\infty .
\tag{SHC.26}
```
