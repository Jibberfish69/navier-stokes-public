## 1. Exact pass case

Let

```math
\mathcal J_K^{loc}
=
\{\partial_y^\alpha U_m,\partial_y^\alpha Q_m^{loc}:|\alpha|\le K\}.
\tag{MSK.3}
```

Assume the selector data are order-locked in a fixed finite-dimensional
selector chart:

```math
\mathfrak s_m
=
(\chi_m,\Phi_m,\Gamma_m)
=
\mathcal S(\mathcal J_K^{loc},\Theta_m),
\tag{MSK.4}
```

where \(\Theta_m\) is a finite set of material/cotangent frame parameters, and
the chart obeys

```math
\|\partial_s\mathfrak s_m\|_{\mathfrak S}
\le
C\Big(
1+\|\mathcal J_K^{loc}\|_{H_y^\sigma}^{d}
+|\dot\Theta_m|
\Big),
\qquad
\sigma>{3\over2}.
\tag{MSK.5}
```

Assume also that the frame parameters are generated by the same finite jet:

```math
|\dot\Theta_m|
\le
C\big(1+\|\mathcal J_K^{loc}\|_{H_y^\sigma}^{d}\big).
\tag{MSK.6}
```

Then `FiniteEndpointJetTemporalModulus.A` gives

```math
\sup_m
\|\mathcal J_K^{loc}\|_{L_s^\infty H_y^\sigma}<\infty,
\tag{MSK.7}
```

and therefore

```math
\sup_m
\|\partial_s\mathfrak s_m\|_{L_s^\infty(-1,0;\mathfrak S)}
<\infty.
\tag{MSK.8}
```

Consequently

```math
\Lambda_{sel,m}^{cont}((-\theta,0])
=
\int_{-\theta}^{0}\|\partial_s\mathfrak s_m(s)\|_{\mathfrak S}\,ds
\le C\theta.
\tag{MSK.9}
```

This proves the pass case.

## 2. Why arbitrary post-hoc selectors fail

A selector chosen after the density is formed need not satisfy `(MSK.4)`.
For two candidate packets with nearly equal selected scores, an endpoint-sized
perturbation can switch the winner:

```math
\operatorname{score}_1(s)-\operatorname{score}_2(s)
\to0
\quad\text{as }s\uparrow0.
\tag{MSK.10}
```

Then the selected label can oscillate or jump inside \((-\theta,0]\) while the
underlying local finite jet remains bounded.  This is not a failure of the
local Navier-Stokes tower.  It is selector tie/drift.

Thus arbitrary extremizing selection requires a separate gate:

```math
\boxed{
\texttt{SelectorTieGapOrDriftCharge.A}.
}
\tag{MSK.11}
```

Either a strict selector gap stabilizes the selected branch, or the switching
variation is charged as selector/collar residue and cannot remain inside the
gold endpoint measure as a naked finite measure.

## 3. Why scalar heat-scale transport fails

The transported-selector identity gives the exact transport-channel relation:

```math
\langle A_s^{tr}(u\cdot\nabla u),A_s^{tr}u\rangle
=
-{1\over2}\langle[u\cdot\nabla,G_s^{tr}]u,u\rangle.
\tag{MSK.12}
```

For a scalar heat-scale symbol

```math
g_s(y,\xi)=\gamma(\log|\xi|-\sigma(s)),
\tag{MSK.13}
```

the cotangent material derivative contains

```math
D_s^c\log|\xi|
=
-\hat\xi\cdot S\hat\xi,
\qquad
S={1\over2}(\nabla U+\nabla U^T).
\tag{MSK.14}
```

A single scalar speed \(\dot\sigma\) cannot match the direction-dependent
quantity \(-\hat\xi\cdot S\hat\xi\) on a genuinely anisotropic packet.  The
stationary affine model

```math
U(y)=Sy,\qquad
S=\operatorname{diag}(a,-a,0),
\qquad
Q(y)=-{1\over2}y\cdot S^2y
\tag{MSK.15}
```

has

```math
\nabla\cdot U=0,
\qquad
(U\cdot\nabla)U+\nabla Q=0,
\qquad
\Delta U=0,
\tag{MSK.16}
```

but

```math
-e_1\cdot Se_1=-a,
\qquad
-e_2\cdot Se_2=a.
\tag{MSK.17}
```

So scalar heat-scale transport cannot realize `(MSK.4)` through anisotropic
strain.  The selector must become anisotropic/cotangent-material or pay the
fixed-selector strain commutator.

## 4. Anisotropic material selectors need heat-scale return

Let \(F\) be the material deformation gradient and \(A=F^{-1}\).  The
transported cotangent metric

```math
G_{mat}=AA^T
\tag{MSK.18}
```

obeys

```math
\partial_sG_{mat}
=
-A(\nabla U+\nabla U^T)A^T.
\tag{MSK.19}
```

This is generated by the local finite jet, so it satisfies the material part
of `(MSK.4)`.  The problem is return: the selected endpoint packet is still a
heat-scale/tower carrier.  The anisotropic metric remains comparable to the
heat-scale carrier only under a deformation-return bound:

```math
\kappa(G_{mat}(s))\le C
\quad
\text{or a charged Body-IV geometry defect.}
\tag{MSK.20}
```

Equivalently, the missing gate is

```math
\boxed{
\texttt{TransportedSelectorHeatScaleReturn.A}.
}
\tag{MSK.21}
```

Without `(MSK.21)`, the selector motion is material but no longer retained on
the same heat-scale endpoint carrier.
