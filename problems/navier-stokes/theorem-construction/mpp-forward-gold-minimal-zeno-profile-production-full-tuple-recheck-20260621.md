# Minimal Zeno Profile Production Full-Tuple Recheck

```math
\boxed{
\texttt{MinimalZenoProfileProduction.A}.
}
\tag{MZP.1}
```

```math
\boxed{
\text{exact Landau/Sverak zero-force profile}
\Longrightarrow
U=0.
}
\tag{MZP.2}
```

The open question is production.  The Zeno limit must become an exact profile

```math
\boxed{
\begin{gathered}
-\nu\Delta U+\nabla\cdot(U\otimes U)+\nabla P=\Phi_0\delta_0,\\
\nabla\cdot U=0,\qquad

\text{with no residual endpoint source, modulation drift, selector drift, or
defect measure.}
\end{gathered}
}
\tag{MZP.3}
```

This note asks whether the full participation tuple produces `(MZP.3)`.

## 1. What the full tuple adds

The full tuple forces every terminal packet to keep the same local equation

```math
R+N+P+V=L,
\qquad
I=0.
\tag{MZP.4}
```

This prevents a false profile proof where pressure is hidden by Leray
projection, viscosity is counted alone, incompressibility is used only as a
skew cancellation, or the nonlinear source is priced as scalar mass before the
carrier is retained.

So the full tuple gives a better compactness object:

```math
(U,\Pi;\mu_R,\mu_N,\mu_P,\mu_V,\mu_L,\mu_I;\mu_{\rm sel}^{+}).
\tag{MZP.5}
```

Every residual has to appear as endpoint source, pressure trace, viscous
defect, time/storage jump, incompressibility/signed-saturation defect,
selector/carrier defect, geometry defect, or legal residual.

This is visibility.  It is not yet profile production.

## 2. Endpoint residue is still not evacuated

The endpoint source model remains admissible at the level of finite measure
compactness:

```math
d\mu_m^{src,+}(y,s)
=
a\rho(y)\tau_m^{-1}{\bf 1}_{(-\tau_m,0]}(s)\,dy\,ds,
\qquad
\tau_m\downarrow0.
\tag{MZP.6}
```

It converges weak-star to

```math
d\mu_*^{src,+}
=
a\rho(y)\,dy\otimes\delta_{s=0}.
\tag{MZP.7}
```

The full tuple records where this atom sits.  It does not remove it.  The
needed endpoint theorem is still

```math
\boxed{
\lim_{\theta\downarrow0}\limsup_m
\mu_m^{src,+}(B_R\times[-\theta,0])=0
\qquad(R<\infty),
}
\tag{MZP.8}
```

or a charged endpoint residue that becomes a CM Part/Field face rather than a
forward-gold profile input.

Thus endpoint evacuation is equivalent here to terminal trace AC, endpoint UI,
source-square/critical-density terminal reserve, strict no-waste, or charged
defect routing.

## 3. Stationarity still needs unweighted action

On negative-time compact strips the Zeno extraction can give an ancient local
suitable package.  Stationarity requires quiet windows in renormalized time.
A standard route would need

```math
\boxed{
\int_{S_0}^{\infty}\mathcal A_R(s)\,ds<\infty.
}
\tag{MZP.9}
```

Physical dissipation gives only the discounted estimate

```math
\int_{S_0}^{\infty}e^{-s/2}\mathcal A_R(s)\,ds<\infty.
\tag{MZP.10}
```

The full tuple does not remove the exponential factor.  It can say the
recurrent action is accompanied by pressure, viscous, signed, storage, legal,
or geometry records, but it does not make the unweighted action finite.

Therefore the stationarity line remains

```math
\boxed{
\texttt{RenormalizedZenoStationarity.A}
\Leftarrow
\text{unweighted action/no-waste}
+
\text{full-tuple defect evacuation.}
}
\tag{MZP.11}
```

The current inputs do not prove the right side.

## 5. Homogeneity and sphere smoothness are downstream of stationarity

Exact \((-1)\)-homogeneity is not a consequence of one subsequential parabolic
blow-up limit.  It follows only after the scale orbit has a unique tangent or a
stationary self-similar orbit:

```math
\boxed{
\text{unique scale tangent}
+
\text{stationarity/self-similar orbit}
\Longrightarrow
U(\lambda x)=\lambda^{-1}U(x).
}
\tag{MZP.14}
```

Sphere smoothness is also downstream.  Once the profile is an exact stationary
Navier--Stokes solution on \(\mathbf R^3\setminus\{0\}\), elliptic regularity
and the Landau-class hypotheses can be invoked.  Before endpoint residue and
defect evacuation, the limiting object can be defect-bearing or only suitable
ancient; sphere smoothness is not forced.
