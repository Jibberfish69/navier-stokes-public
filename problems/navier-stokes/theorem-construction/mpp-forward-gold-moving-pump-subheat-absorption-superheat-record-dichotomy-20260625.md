# Moving Pump Sub-Heat Absorption / Super-Heat Record Dichotomy

Date: 2026-06-25

## 0. Object

The object is one transported material annular history.  At shell \(j\), let

```math
e_j(t)={1\over2}w_j\|v_j(t)\|_2^2
\tag{MSD.1}
```

be the weighted active-shell energy and let

```math
d_j(t)=\nu w_j\langle G\nabla_av_j,\nabla_av_j\rangle
\tag{MSD.2}
```

be the high-shell viscous residence in the same material chart.

On the retained material packet, the metric has finite ellipticity constants on
each preterminal interval:

```math
\lambda_G|\xi|^2\le G\xi\cdot\xi\le \Lambda_G|\xi|^2 .
\tag{MSD.3}
```

Therefore Bernstein on the fixed material chart gives

```math
d_j(t)\ge c_G\nu\,2^{2j}e_j(t)-r_{j}^{G}(t),
\tag{MSD.4}
```

where \(r_j^G\) is the already typed coefficient/collar commutator service of
the same material packet.  It is not an external residual.

## 1. Moving pump normal form

After the skew transport cancellation, the active moving pump has the form

```math
\mathcal M_j^{mov}(t)
=
\text{low material rate below shell }j
\times
\text{active high-shell energy/stress at shell }j
+\text{typed commutators}.
\tag{MSD.5}
```

More precisely, the pressure-viscosity-incompressibility-velocity packet gives

```math
[\mathcal M_j^{mov}(t)]_+
\le
C_0\,\Theta_j^{mat}(t)e_j(t)
+r_j^{mat}(t),
\tag{MSD.6}
```

where \(\Theta_j^{mat}\) is the same-material rate coefficient generated by
the low side of the active interaction:

```math
\Theta_j^{mat}
=
\Theta_j^{strain}
+\Theta_j^{press}
+\Theta_j^{coef}
+\Theta_j^{collar}.
\tag{MSD.7}
```

Here:

```math
\Theta_j^{strain}
\quad\text{comes from the moving low strain/velocity-gradient band,}
\tag{MSD.8}
```

```math
\Theta_j^{press}
\quad\text{comes from the pressure Hessian and pressure elliptic service,}
\tag{MSD.9}
```

```math
\Theta_j^{coef}
\quad\text{comes from } \dot A,\dot G \text{ and material frame motion,}
\tag{MSD.10}
```

and

```math
\Theta_j^{collar}
\quad\text{comes from transported collar/frame variation.}
\tag{MSD.11}
```

The term \(r_j^{mat}\) contains only same-packet typed commutators already
placed in the coefficient/collar service density.

Equation `(MSD.6)` is the coupled version of the physical statement: the
annulus can feed the active shell only through the material rate experienced by
that same annulus.

## 2. Sub-heat-rate absorption

Fix a small dimensional constant

```math
0<\delta< {c_G\nu\over 2C_0}.
\tag{MSD.12}
```

On the sub-heat region

```math
\Theta_j^{mat}(t)\le \delta\,2^{2j},
\tag{MSD.13}
```

the pump estimate `(MSD.6)` and the viscous residence lower bound `(MSD.4)`
give

```math
\mathbf 1_{\{\Theta_j^{mat}\le\delta2^{2j}\}}
[\mathcal M_j^{mov}]_+
\le
{1\over2}d_j
+r_j^{G}
+r_j^{mat}.
\tag{MSD.14}
```

Thus a moving annular pump whose material rate is slower than the shell heat
rate cannot be a terminal producer.  High-shell viscosity absorbs it on the
same material packet.

## 3. Super-heat-rate record branch

The only unabsorbed part is

```math
\mathbf 1_{\{\Theta_j^{mat}>\delta2^{2j}\}}
[\mathcal M_j^{mov}]_+
\le
C_0\,\Theta_j^{mat}e_j
+r_j^{mat}.
\tag{MSD.15}
```

This is not a detached source.  It is exactly a super-heat-rate material
record event:

```math
\Theta_j^{mat}>\delta2^{2j}.
\tag{MSD.16}
```

On a heat window \(I_j\) with length comparable to \(2^{-2j}\), `(MSD.16)`
means

```math
\int_{I_j}\Theta_j^{mat}(t)\,dt
\gtrsim
\delta
\tag{MSD.17}
```

whenever the selected super-heat region occupies a fixed portion of the active
window.  More generally, without any occupancy assumption, the surviving
super-heat contribution is already the weighted material residence

```math
\int_{I_j}
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}>\delta2^{2j}\}}\,dt .
\tag{MSD.18}
```

That residence is part of the full material clock, because \(\Theta_j^{mat}\)
is made only from strain, pressure elliptic service, coefficient motion, and
collar/frame motion on the same transported annulus.

## 4. Combined dichotomy

For every active shell and heat window,

```math
\int_{I_j}[\mathcal M_j^{mov}]_+\,dt
\le
{1\over2}\int_{I_j}d_j\,dt
+
C_0\int_{I_j}
\Theta_j^{mat}e_j
\mathbf 1_{\{\Theta_j^{mat}>\delta2^{2j}\}}\,dt
+
\int_{I_j}(r_j^G+r_j^{mat})\,dt .
\tag{MSD.19}
```

This is the exact no-free-moving-pump split:

```math
\text{sub-heat-rate pump}
\quad\Longrightarrow\quad
\text{high-shell viscous residence,}
\tag{MSD.20}
```

```math
\text{unabsorbed pump}
\quad\Longrightarrow\quad
\text{super-heat-rate material record residence.}
\tag{MSD.21}
```

No pressure-only, viscosity-only, frequency-only, or center-only object appears.

## 5. Consequence for the live edge

The previous interface-variation calculation removed arbitrary oscillation.
The heat-window demotion removed the fake uncontrolled higher-tower derivative
loss.  The present dichotomy removes the next fake branch: a moving low-high
annular pump below the heat rate cannot drive the terminal spike.

The only surviving producer is therefore the finite residence of the
super-heat-rate material coefficient:

```math
\int_0^{T_*}
\sum_j
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}(t)>\delta2^{2j}\}}\,dt
<\infty .
\tag{MSD.22}
```

This is not a new detached problem.  It is the same physical claim in its
sharpest current form: the surrounding annulus cannot keep feeding the active
shell unless its own pressure-strain-coefficient-collar material record
experiences super-heat-rate residence.

Thus terminal recurrence has only two same-packet possibilities left:

```math
\text{viscous residence pays it}
\quad\text{or}\quad
\text{super-heat-rate material record residence pays it.}
\tag{MSD.23}
```

The MPP-closing producer is finite total mass of the second term in `(MSD.22)`.
