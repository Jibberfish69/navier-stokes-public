## 1. Same-witness modulus needed

Let the same first Pack witness carry a selected positive terminal marginal

```math
d\mu_m(s)=a_m(s)\,ds
```

in normalized terminal time.  The needed same-witness strip modulus is

```math
\lim_{\theta\downarrow0}
\limsup_{m\to\infty}
\int_{-\theta}^{0}a_m(s)\,ds
=0.
\tag{NSP.1}
```

The endpoint model is

```math
a_m(s)=\tau_m^{-1}{\bf 1}_{(-\tau_m,0]}(s),
\qquad
\tau_m\downarrow0.
\tag{NSP.2}
```

It has fixed mass,

```math
\int_{-1}^{0}a_m(s)\,ds=1,
\tag{NSP.3}
```

and violates `(NSP.1)`:

```math
\lim_{\theta\downarrow0}
\limsup_{m\to\infty}
\int_{-\theta}^{0}a_m(s)\,ds
=1.
\tag{NSP.4}
```

Finite local `L^1_s` mass, local-energy BV traces, weak trace compactness,
same-solution custody, first-exit minimality, zero ASAC, paid finite donor
exits, and no fixed earlier selected source slice are all compatible with
`(NSP.2)`.

```math

\tag{NSP.5}
```

```math

\tag{NSP.6}
```

can consume a produced unweighted bound, but they do not produce that bound.
