## 1. Clause C target

Let \(q_m\) be the signed selected pre-Cauchy residue on the same selected
ledger after legal exits, retained finite signed partners, and finite donor
telescoping have been removed.  Let

```math
M_m^+(q_m)
\tag{NSS.1}
```

be the selected positive native carrier mass, and let

```math

\tag{NSS.2}
```

be the usable same-shadow signed readout: local-energy, projected stress,
source-mode, endpoint, or another legal readout on the same selected family.

The clause is the no-null lower bound

```math
M_m^+(q_m)=1
\quad\Longrightarrow\quad
\liminf_m\|L_mq_m\|_m>0.
\tag{NSS.3}
```

Equivalently, it excludes

```math
M_m^+(q_m)=1,
\qquad

\tag{NSS.4}
```

This is the same object as `SelectedPositiveConeNoNullReadout.A`.

## 4. Algebraic obstruction

The finite source-cloud model is

```math

\tag{NSS.9}
```

Then

```math

\qquad

\tag{NSS.10}
```

The carrier model is

```math

\qquad

\qquad
L(q_1,q_2)=q_1+q_2.
\tag{NSS.11}
```

The selected positive carrier sees

```math

\tag{NSS.12}
```

```math

\tag{NSS.13}
```

So the obstruction is not time concentration.  It is a compact same-shadow
positive-cone kernel.
