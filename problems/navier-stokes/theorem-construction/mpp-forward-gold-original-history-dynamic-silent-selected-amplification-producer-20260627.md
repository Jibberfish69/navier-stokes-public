## 1. Dynamic silent source is the right generator

A frozen boundary-flat pressure-Hodge source may be invisible:

```math
f_Q=\mathcal L_Aw_Q,\qquad
w_Q|_{\partial A_Q}=0,\qquad
\partial_{\nu_A}w_Q|_{\partial A_Q}=0.
\tag{1}
```

The useful fact is dynamic.  Along the material flow,

```math
D_tf_Q
=
\mathcal L_A(D_tw_Q)+[D_t,\mathcal L_A]w_Q.
\tag{2}
```

The commutator contains same-material deformation, frame, and metric motion:

```math
[D_t,\mathcal L_A]w_Q
=
\mathcal C_{\rm strain}(\nabla u,\nabla_A^2w_Q)
+\mathcal C_{\rm frame}(\nabla_A\nabla u,\nabla_Aw_Q)
+\mathcal C_{\rm metric}(D_tA,w_Q).
\tag{3}
```

In frozen symbol form, pressure-Hodge silence is

```math
\xi^TZ\xi=0.
\tag{4}
```

Since

```math
D_t\xi=-(\nabla u)^T\xi,
\tag{5}
```

preserving `(4)` while the source remains selected forces

```math
0=D_t(\xi^TZ\xi)
=-2\xi^T(\nabla u)Z\xi+\xi^T(D_tZ)\xi.
\tag{6}
```

Thus selected material persistence of a silent source creates an exchange
identity.  Frozen silence is allowed; selected silence through the material
clock must pay.
