# Original Smooth Same-Packet Realization Audit

Date: 2026-06-22

## 0. Point

After the transported-annular and donor total-exchange corrections, the
remaining boundary is not a hidden center-time pulse and not a zero-net donor
cycle.  The boundary is whether the same pressure-viscosity-incompressibility
velocity participation record is retained on the terminal packet.

The original smooth Navier-Stokes solution supplies this law on every
preterminal interval:

```math
\partial_t u+(u\cdot\nabla)u+\nabla p-\nu\Delta u=0,
\qquad
\nabla\cdot u=0.
\tag{OSR.1}
```

Thus, before the terminal limit, a material annular packet built from the same
solution carries all channels on the same object.

## 1. Preterminal same-packet realization

Let \(X(t,a)\) be the smooth volume-preserving material map generated by \(u\),
and let \(\zeta(a)\) be an annular label-space cutoff.  The transported cutoff

```math
\eta(t,x)=\zeta(X^{-1}(t,x))
\tag{OSR.2}
```

satisfies

```math
(\partial_t+u\cdot\nabla)\eta=0.
\tag{OSR.3}
```

For \(\phi=\eta^2\), the localized stress/energy identity is the same-packet
identity

```math
{d\over dt}{1\over2}\int \phi |u|^2
+
2\nu\int \phi |S(u)|^2
=
-\int u\cdot T(u,p)\nabla\phi,
\tag{OSR.4}
```

with

```math
T(u,p)=-pI+2\nu S(u).
\tag{OSR.5}
```

No pressure-only, viscosity-only, or scalar source replacement appears here.
The transported material annulus carries velocity, pressure, incompressibility,
and viscosity as one packet.

## 2. Zero-rank donor cycles

Let \(\mathcal C\) be a stabilized zero-rank donor cycle on the retained packet,
and let \(J_e(t)\) be the signed exchange along edge \(e\).  Its signed net can
vanish:

```math
\sum_{e\in\mathcal C}J_e(t)=0.
\tag{OSR.6}
```

That does not mean the exchange is absent.  The relevant participation amount is
the total exchange

```math
\mathcal A_{\mathcal C}^{tot}(t)
=
\sum_{e\in\mathcal C}|J_e(t)|.
\tag{OSR.7}
```

The selected positive donor residue on the cycle satisfies

```math
\mathcal Z_{\rm donor}^{\mathcal C}(t)
\le
\sum_{e\in\mathcal C}[J_e(t)]_+
\le
\mathcal A_{\mathcal C}^{tot}(t).
\tag{OSR.8}
```

If the cycle is built from the preterminal smooth material packet above, then
\(\mathcal A_{\mathcal C}^{tot}\) is a same-packet exchange quantity.  It is
not external to the four-body object; it is charged as the Body-III signed
current relay / retained partner-selection contribution inside \(A_{4B}\).

Thus a zero-net donor circulation is harmless on the retained same-packet
branch:

```math
\mathcal Z_{\rm donor}^{\mathcal C}
\le
C A_{4B}.
\tag{OSR.9}
```

## 3. What failure means

The original smooth solution gives `(OSR.1)` preterminally.  The only way the
donor cycle avoids `(OSR.9)` is that the terminal object no longer retains the
same pressure-viscosity-incompressibility velocity packet on the selected
carrier.

By the active contract, this is not a new gold-side residue.  It is the Part
face:

```math
Pack_Q+\neg Part_{N,Q}.
\tag{OSR.10}
```

Here \(Part\) means the original Navier-Stokes participation ontology of the
same-solution candidate, and \(Part_{N,Q}\) is only the localized finite-depth
record after a field-local record exists.

## 4. Consequence for the gold branch

On the retained same-packet branch,

```math
A_{\rm native}
\leadsto
A_{4B}.
\tag{OSR.11}
```

Since the four-body cycle gives

```math
\int_{\sigma_0}^{\infty}A_{4B}(\sigma)\,d\sigma<\infty,
\tag{OSR.12}
```

the same branch gives

```math
\int_{\sigma_0}^{\infty}A_{\rm native}(\sigma)\,d\sigma<\infty.
\tag{OSR.13}
```

Therefore the forward-gold branch has no remaining hidden terminal source
inside a retained same-packet material annulus.
