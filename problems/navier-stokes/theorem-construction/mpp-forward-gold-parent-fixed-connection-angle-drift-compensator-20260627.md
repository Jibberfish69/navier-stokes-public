# Parent-fixed connection angle-drift compensator

## 1. Placement

The latest endpoint-current block found a real obstruction:

```text
parent-subtracted endpoint-current increments need one parent-known Hilbert
geometry, or the angle drift between their moving geometries must be paid.
```

This is not a separate route from the stopped active-weight compensator.  It is
the geometric part of the same realization problem.  The active weight supplies
the root measure; the parent-fixed connection supplies the root frame and
inner product.  Bessel packing is legal only after both are fixed before
descendant selected-tail readout.

The right sharpened target is therefore:

```text
ParentFixedConnectionAngleDriftCompensator.A.
```

## 2. Parent-fixed transport

For a stopped root \(P\), let

```math
\mathfrak H_P
=
L^2(H_P^\ast\,dt\,dx;\mathcal H_{\rm lift})
```

be the root space generated by the stopped active-weight compensator.  The
fiber \(\mathcal H_{\rm lift}\) carries visible, silent, and exchange
coordinates.  Those coordinates move with material frame, covector, selector,
collar, and endpoint chart data.

Choose a parent-known connection \(\nabla^P\) on the retained stopped bundle and
let

```math
\mathsf U_{\sigma\to\sigma_P}^P:\mathcal H_{\sigma}\to\mathcal H_P
\tag{1}
```

be its parallel transport to the parent frame.  For each fresh edge \(e\), set

```math
\widetilde D_e
=
\mathsf U_{e\to P}^P
(I-\Pi_{\mathcal P_{e^-}})\mathcal C_\theta[Z_e].
\tag{2}
```

The construction is noncircular only when \(\nabla^P\), \(\mathsf U^P\),
\(H_P^\ast\), and the parent spans are determined from stopped parent/root
history before scalar selected readout.

## 3. The connection variation measure

The connection derivative has the form

```math
\mathcal K_P
=
\mathcal K_{\rm frame}
+\mathcal K_{\rm covector}
+\mathcal K_{\rm selector}
+\mathcal K_{\rm collar}
+\mathcal K_{\rm endpoint}
+\mathcal K_{\rm legal}.
\tag{3}
```

The already installed material-frame identities identify the first two
principal pieces:

```math
\dot G=-2ASA^\top,
\qquad
D_t\nabla_x\phi=-(\nabla u)^\top\nabla_x\phi,
\tag{4}
```

so coefficient-frame and base collar-normal variation are strain/frame
coordinates of the same material packet.  Complete-frame trace-free payment
then routes the principal positive primitive strain pump into wave-covector or
packet-normal/collar compression.  Selector and endpoint chart changes are the
stopped turnstile/reselection part.

Define the parent connection compensator by

```math
dA_P^{conn}
=
H_P^\ast
\|\mathcal K_P^{new}\|_{\operatorname{op}}^2\,d\sigma dt
+dA_P^{sel/chart}
+dR_{\rm legal,P}
+dStop_P,
\tag{5}
```

where \(\mathcal K_P^{new}\) is projected away from already inherited
parent-predictable transport.

The theorem must prove

```math
\boxed{
\int_{\operatorname{Hist}(P')}dA_{P'}^{conn}
\le
C_N(u_0)\mathcal R(P')
+R_{\rm legal}(P')
+Stop(P')
}
\tag{6}
```

for every stopped \(P'\subseteq P\), from original material history and without
using the downstream full material clock as an input.

## 4. Angle-drift estimate

Assume first that the fresh pieces are orthogonal in their moving parent
filtration:

```math
D_e\perp\mathcal P_{e^-}
\tag{7}
```

before transport to the fixed parent fiber.  Transport introduces
non-orthogonal cross terms:

```math
\left\|\sum_e\widetilde D_e\right\|_{\mathfrak H_P}^2
=
\sum_e\|\widetilde D_e\|_{\mathfrak H_P}^2
+2\sum_{e<f}
\langle\widetilde D_e,\widetilde D_f\rangle_{\mathfrak H_P}.
\tag{8}
```

The connection identity gives, schematically,

```math
\partial_\sigma
\langle \mathsf U_{\sigma_e\to\sigma}D_e,
        \mathsf U_{\sigma_f\to\sigma}D_f\rangle
=
\langle \mathcal K_P D_e,D_f\rangle
+\langle D_e,\mathcal K_P D_f\rangle
+Legal.
\tag{9}
```

Therefore Cauchy and stopped Carleson embedding reduce the cross term to the
connection compensator:

```math
\boxed{
\sum_{e<f}
|\langle\widetilde D_e,\widetilde D_f\rangle_{\mathfrak H_P}|
\le
\varepsilon\sum_e\int H_{e^-}\|D_e\|^2
+C_\varepsilon\int dA_P^{conn}
+R_{\rm legal}(P).
}
\tag{10}
```

Combining `(8)` and `(10)` gives the parent-fixed Bessel estimate once
`(6)` and the active-weight compensator are proved:

```math
\left\|\sum_e\widetilde D_e\right\|_{\mathfrak H_P}^2
\le
C\sum_e\int H_{e^-}\|D_e\|^2
+C\int dA_P^{conn}
+R_{\rm legal}(P).
\tag{11}
```

This is the precise content of

```text
EndpointCurrentAngleDriftCarleson.A.
```

## 5. Relation to the active-weight compensator

The active-weight compensator pays the scalar root measure:

```math
dA_P^{wt}
\quad\text{records new admitted active-weight upcrossings.}
\tag{12}
```

The connection compensator pays the moving geometry:

```math
dA_P^{conn}
\quad\text{records frame, covector, selector, collar, and endpoint-chart drift.}
\tag{13}
```

The common root realization needs both:

```math
dA_P^{root}
=dA_P^{wt}+dA_P^{conn}.
\tag{14}
```

The full realization theorem is then

```text
StoppedPredictableRootGeometryCompensator.A
```

with statement:

```math
\int_{\operatorname{Hist}(P')}dA_{P'}^{root}
+
\sum_{e\subset P'}
\int H_{e^-}\|D_e^{vis}+D_e^{sil}+D_e^{ex}\|^2
\le
C_N(u_0)\mathcal R(P')
+R_{\rm legal}(P')
+Stop(P').
\tag{15}
```

This is the parent-known geometry version of

```text
OriginalHistoryParentPredictableFreshInnovationCarleson.A.
```

## 6. Bad-profile test

If `(15)` fails with all allowed original-history charges vanishing, one of two
bad profiles remains.

The first is the active-weight half-tail:

```math
\sum_\ell\|D_\ell\|^2<\infty,
\qquad
\sum_\ell H_\ell\|D_\ell\|^2=\infty.
\tag{16}
```

That is killed only by \(dA_P^{wt}\).

The second is the angle-drift stack: the weighted innovations are individually
small and moving-orthogonal, but their parent-fixed transports stay positively
correlated:

```math
\sum_e\|D_e\|^2<\infty,
\qquad
\sum_{e<f}
|\langle\widetilde D_e,\widetilde D_f\rangle|=\infty.
\tag{17}
```

That is killed only by \(dA_P^{conn}\).

So the endpoint-current Bessel block is not a new proof route.  It adds the
missing connection term to the same compensator theorem already needed for
active weights.

## 7. Result

The sharpened Gold producer is:

```text
StoppedPredictableRootGeometryCompensator.A
  =
StoppedPredictableActiveWeightCompensator.A
+ ParentFixedConnectionAngleDriftCompensator.A.
```

This is still open.  It is a genuine improvement because it prevents the route
from pretending that a parent-known active weight alone gives a common Hilbert
geometry.  The common geometry also needs a paid material connection, and the
angle drift must be charged before endpoint-current Bessel packing is consumed.
