# Participation-Carrying Material Record Correction

Date: 2026-06-22

## 0. Correction

The previous local attempt proved a useful but incomplete statement:

```math
d[\log(1+\mathcal P_N)]_+
\le C\,dA_{4B,N}^{ann}.
\tag{PCR.1}
```

The flaw is that \(\mathcal P_N\) was treated as the object, while the
participation law was treated as a later admission mechanism. That loses the
four-body ontology.

The participation law must travel with the record. The proof object is not
just a tower norm. It is the same-material law-bearing packet:

```math
\boxed{
\mathcal P_N^{law}
=
\left(
\text{material record};
\text{differentiated material PDE};
\text{pressure/divergence constraints};
\text{transported cutoff identities};
\text{oriented four-body exchange currents}
\right).
}
\tag{PCR.2}
```

No generated term is admitted afterward merely because it is named a channel.
The generated terms must appear in the law as adjacent-body exchange currents.

## 1. Material participation law must be part of the carrier

On the retained transported annular atlas, the material equations are

```math
\partial_s v+A^T\nabla_a q
=\nu\operatorname{div}_a(G\nabla_a v),
\qquad
\operatorname{div}_a(Av)=0.
\tag{PCR.3}
```

For every tower rung,

```math
\partial_sU_\alpha
+A^T\nabla_a\pi_\alpha
-\nu\operatorname{div}_a(G\nabla_aU_\alpha)
=\mathcal C_\alpha,
\tag{PCR.4}
```

with

```math
\operatorname{div}_a(AU_\alpha)
=-[D^\alpha,\operatorname{div}_a(A\cdot)]v .
\tag{PCR.5}
```

The commutator \(\mathcal C_\alpha\), the pressure service produced by
`(PCR.5)`, and the viscous/collar terms are not external costs. They are the
participation law of the same material packet after differentiation.

So the right task is not:

```math
\text{derive growth terms}\quad\text{then prove they are paid by }A_{4B}.
\tag{PCR.6}
```

The right task is:

```math
\text{derive the law-bearing four-body exchange inequalities directly.}
\tag{PCR.7}
```

## 2. Correct four-body form

For the full tower packet one needs four oriented inequalities of the form

```math
A_S+E_{SQ}\le E_{GS}-d\Phi_S,
\tag{PCR.8}
```

```math
A_Q+E_{QC}\le E_{SQ}-d\Phi_Q,
\tag{PCR.9}
```

```math
A_C+E_{CG}\le E_{QC}-d\Phi_C,
\tag{PCR.10}
```

```math
A_G+E_{GS}\le E_{CG}-d\Phi_G.
\tag{PCR.11}
```

Here the exchanges \(E_{SQ},E_{QC},E_{CG},E_{GS}\) are not bookkeeping labels.
They must be the actual terms generated by the same differentiated material
participation law:

- Body I produces tower/radius-spend and nonlinear tower exchange;
- Body II receives the tower exchange and produces pressure-corrected
  participation service;
- Body III carries no-loss same-solution compactness/trace relay;
- Body IV carries strain-metric, coefficient, and deformation-geometry return
  service.

When `(PCR.8)`--`(PCR.11)` are summed, the exchange currents cancel and yield

```math
A_{4B,N}:=A_S+A_Q+A_C+A_G
\le
-d\Phi_{4B}.
\tag{PCR.12}
```

Then

```math
\int A_{4B,N}<\infty
\tag{PCR.13}
```

follows from the four-body storage bound. This is the missing theorem.

## 3. What changes from the failed audit

The previous audit failed because it asked:

```math
\text{Does the existing }\int A_{4B}<\infty\text{ control an enlarged service sum?}
\tag{PCR.14}
```

That is the wrong question. It treats the enlarged object as a ledger outside
the law.

The corrected question is:

```math
\boxed{
\text{Can the differentiated material participation law itself be written in
oriented four-body form for the full tower packet?}
}
\tag{PCR.15}
```

If yes, then the full tower-level \(A_{4B,N}\) is not appended to the old loop;
it is the loop.

This target replaces the looser `FullTowerFourBodyCancellation.A` wording.

## 5. Consequence

If `(PCR.16)` is proved, then material record loss implies positive four-body
activity because record growth is one component of the law-bearing activity,
not because it was later admitted:

```math
\text{record loss}
\Rightarrow
\int_I A_{4B,N}\ge c_N>0.
\tag{PCR.17}
```

Bounded overlap then gives the usual contradiction with `(PCR.13)`.

If `(PCR.16)` is not proved, the route remains open. But the exact open problem
is now correctly stated: carry the participation law with the same-material
record through the four-body balance, instead of trying to add generated record
growth to an older lower-order four-body object.
