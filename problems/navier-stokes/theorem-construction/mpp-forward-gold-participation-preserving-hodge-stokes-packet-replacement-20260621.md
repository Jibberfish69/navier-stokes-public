# Participation-Preserving Hodge-Stokes Packet Replacement

Date: 2026-06-21

## 0. Correction

The one-channel Leray replacement is too small for terminal selection.

The rule is:

```math
\boxed{
\mathbb P_{\rm Leray}
\text{ may appear only as one component of the packet, never as the packet
itself.}
}
\tag{HSP.1}
```

The selected packet must keep the full local Navier-Stokes participation law
visible:

```math
\partial_t u
+
(u\cdot\nabla)u
+
\nabla p
-
\nu\Delta u
=0,
\qquad
\nabla\cdot u=0.
\tag{HSP.2}
```

The reason is structural.  Leray projection recombines convection and pressure
before the terminal selector acts.  After localization, weighting, lifting,
positive-part extraction, and selected-carrier retention, that recombination
can hide which channel paid the selected positive residue.  That is exactly
where orientation, commutator, and saturation gates reappear.

## 1. Full Hodge-Stokes balance packet

For a retained terminal packet \(P\) with cutoff \(\chi_P\), carry the packet

```math
\boxed{
\mathcal K_P
=
\Big(
\chi_P(u\cdot\nabla u),\;
\chi_P\nabla p,\;
\nu\chi_P\Delta u,\;
\chi_P\partial_tu,\;
\chi_P\nabla\cdot u,\;
[\chi_P,\mathbb P_{\rm Leray}](u\cdot\nabla u),\;
\mathcal B_P^{cut},\;
\mathcal S_P^{sgn}
\Big).
}
\tag{HSP.3}
```

Here \(\mathcal B_P^{cut}\) denotes the cutoff, collar, and boundary terms
created when the local balance is tested, and \(\mathcal S_P^{sgn}\) denotes
the signed/oriented partner retained for terminal saturation.

The localized balance represented by `(HSP.3)` is

```math
\chi_P\partial_tu
+
\chi_P(u\cdot\nabla u)
+
\chi_P\nabla p
-
\nu\chi_P\Delta u
=
\mathcal R_P^{loc},
\tag{HSP.4}
```

where \(\mathcal R_P^{loc}\) is not a new force.  It is the legal localization
record generated by cutoffs, collars, moving windows, and test-pairing
commutators.

The Leray identity is still available:

```math
\mathbb P_{\rm Leray}\big((u\cdot\nabla)u\big)
=
(u\cdot\nabla)u+\nabla p,
\tag{HSP.5}
```

with \(p\) determined by the usual incompressible pressure equation.  But
`(HSP.5)` is now a compatibility identity inside the packet, not the selected
packet itself.

## 2. Carrier-level Hodge-Stokes map

At the carrier level, replace the bare Leray-Hodge projector by

```math
\boxed{
\mathbb H_D X
=
\big(
\mathbb P_DX,\;
(I-\mathbb P_D)X,\;
\delta_DX,\;
\Delta_DX
\big).
}
\tag{HSP.6}
```

This keeps the solenoidal component, gradient/pressure component, divergence
constraint, and viscous operator as one carrier-level object.

For a classical velocity field \(X\), the participation-preserving realization
is

```math
\boxed{
\mathcal N_D(X)
=
\Big(
(X\cdot\nabla)X,\;
\nabla p_X,\;
\mathbb P\big((X\cdot\nabla)X\big),\;
(I-\mathbb P)\big((X\cdot\nabla)X\big),\;
\nu\Delta X
\Big),
}
\tag{HSP.7}
```

where

```math
\nabla p_X
=
(I-\mathbb P)\big((X\cdot\nabla)X\big).
\tag{HSP.8}
```

Thus the projected equation may still be used, but the pressure channel is not
deleted from the carrier.

## 3. Corrected no-residue target

The no-residue route no longer asks only for a projected commutator payment.
It asks for a full-cycle payment:

```math
\boxed{
\text{ParticipationPreservingNoResidueFullCycle.A}
}
\tag{HSP.9}
```

On the retained same carrier, it asserts

```math
\boxed{
\left[
\mathcal C_\sigma^{tr}
+
\mathcal C_\sigma^{p}
+
\mathcal C_\sigma^{\nu}
+
\mathcal C_\sigma^{time}
+
\mathcal C_\sigma^{div}
+
\mathcal C_\sigma^{cut}
+
\mathcal C_\sigma^{sgn}
+
\mathcal C_\sigma^{geo}
\right]_{\mathcal S,+}
\le
\varepsilon\nu D_\sigma
-
\partial_\sigma\Phi_\sigma
+
T_\sigma
+
R_{\rm legal}(\sigma),
}
\tag{HSP.10}
```

with

```math
T_\sigma,\ R_{\rm legal}\in L^1_\sigma,
\qquad
\inf_{\sigma\ge\sigma_0}\Phi_\sigma>-\infty.
\tag{HSP.11}
```

The transport component may still use a transported selector metric.  For
\(A_\sigma^{tr}\), \(G_\sigma^{tr}=(A_\sigma^{tr})^\ast A_\sigma^{tr}\), and
\(L=u\cdot\nabla\),

```math
\boxed{
\langle A_\sigma^{tr}Lu,A_\sigma^{tr}u\rangle
=
-{1\over2}
\langle [L,G_\sigma^{tr}]u,u\rangle.
}
\tag{HSP.12}
```

The corrected full-cycle production equation has to keep the other channels
visible:

```math
\boxed{
\partial_sG_\sigma^{tr}
+
[L,G_\sigma^{tr}]
+
\mathcal P_\sigma
+
\mathcal V_\sigma
+
\mathcal I_\sigma
+
\mathcal B_\sigma
=
\partial_\sigma K_\sigma
+
R_\sigma.
}
\tag{HSP.13}
```

Here \(\mathcal P_\sigma\), \(\mathcal V_\sigma\), \(\mathcal I_\sigma\), and
\(\mathcal B_\sigma\) are the pressure, viscous, incompressibility/divergence,
and boundary/cutoff channels.  They are not hidden behind \(\mathbb P_{\rm
Leray}\).

## 5. Effect on the current forward-gold branch

The transported-selector identity remains useful, but it is only the transport
channel of the full participation packet.

The corrected route is:

```math
\boxed{
\text{bad selected activity}
\Longrightarrow
\text{positive full-cycle Hodge-Stokes participation payment}
}
\tag{HSP.25}
```

where the payment is carried by the same terminal packet through pressure,
viscosity, incompressibility, time residence, cutoff/collar terms, and signed
saturation.

Thus the current unproved production target is not a one-channel theorem named
by Leray projection.  It is:

```math
\boxed{
\text{ParticipationPreservingNoResidueFullCycle.A}
}
\tag{HSP.26}
```

This target would supply the no-residue branch of the unweighted four-body
reserve.  It remains open at production: construct the same-carrier full
Hodge-Stokes packet and prove `(HSP.10)` without a
\(C_\varepsilon\Theta_\sigma^2E_\sigma\) residual.
