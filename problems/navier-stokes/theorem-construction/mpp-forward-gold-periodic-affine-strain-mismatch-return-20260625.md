# Periodic Affine Strain Mismatch Return

Date: 2026-06-25

## 0. Same original periodic history

The active gold route is on the periodic surface.  The object is one smooth
periodic Navier--Stokes solution on `T^3` before a candidate terminal time:

```math
\partial_tu+(u\cdot\nabla)u+\nabla p=\nu\Delta u,
\qquad
\nabla\cdot u=0,
\qquad
u(x+\gamma,t)=u(x,t)
\tag{PAM.1}
```

for every lattice vector `gamma`.  The material history is the transported
whole-torus history generated by this original solution.

The affine strain model

```math

\qquad

\qquad

\qquad
\operatorname{tr}A=0
\tag{PAM.2}
```

is an exact local normal form.  It is not automatically a global periodic
history.

## 1. Nonzero affine strain is not periodic

Assume a periodic velocity field has spatially constant gradient:

```math
\nabla u(x,t)=A(t).
\tag{PAM.3}
```

Then for every period vector `gamma`,

```math
0
=
u(x+\gamma,t)-u(x,t)
=
\int_0^1 \nabla u(x+s\gamma,t)\gamma\,ds
=
A(t)\gamma .
\tag{PAM.4}
```

Since the period vectors span `R^3`,

```math
A(t)=0.
\tag{PAM.5}
```

Thus a nonzero affine strain field cannot be a global periodic velocity field.

The pressure in `(PAM.2)` is also not periodic unless `A^2=0`.  For symmetric
`A`, `A^2=0` implies `A=0`.  Therefore the nonzero pressure-balanced affine
strain packet is local, not a global torus solution.

```math
\tag{PAM.6}
```

```math

\tag{PAM.7}
```

So the local test forces the full clock to include pressure-balanced strain and
annular stress-work.
