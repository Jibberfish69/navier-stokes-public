# Pressure-Collar Same-Packet Routing Solution

Date: 2026-06-22

## 0. Target

The strain equation contains the pressure-Hessian term

```math
\int \phi\,S:\nabla^2Q\,dy .
\tag{PCR.1}
```

The global audit proved that this term cancels on a closed or decaying packet.
The local question is whether `(PCR.1)` creates a separate pressure obstruction
on the retained heat-scale material annulus.

## 1. Exact local pressure collar identity

For a transported annular cutoff \(\phi\), integrate by parts twice:

```math
\int \phi\,S:\nabla^2Q\,dy
=
\int Q\,\partial_i\partial_j(\phi S_{ij})\,dy .
\tag{PCR.2}
```

Since \(\partial_i\partial_jS_{ij}=0\), this becomes

```math
\boxed{
\int \phi\,S:\nabla^2Q\,dy
=
\int Q
\left[
(\partial_i\partial_j\phi)S_{ij}
+
2(\partial_i\phi)(\partial_jS_{ij})
\right]\,dy .
}
\tag{PCR.3}
```

Therefore local pressure is not an interior bulk production term.  It is
collar-supported because every term in `(PCR.3)` contains a derivative of
\(\phi\).

Define the strain-pressure collar density

```math
P_{\phi}^{strain}(s)
:=
\int_{\operatorname{collar}(\phi)}
|Q|
\left(
|\nabla^2\phi|\,|S|
+
|\nabla\phi|\,|\nabla S|
\right)\,dy .
\tag{PCR.4}
```

Then

```math
\left|\int \phi\,S:\nabla^2Q\,dy\right|
\le
C\,P_{\phi}^{strain}(s).
\tag{PCR.5}
```

This is the exact object to route.

## 2. Local pressure part

Decompose

```math
Q=Q^{loc}+Q^H,
\qquad
-\Delta Q^{loc}
=
\partial_i\partial_j(V_iV_j)
\tag{PCR.6}
```

on the retained collar neighborhood, with \(Q^H\) harmonic there.

For the local part, Calderon-Zygmund gives, at the same derivative depth as
the retained velocity tower,

```math
\|D^k Q^{loc}\|_{L^2(U_{collar})}
\le
C
\sum_{\ell\le k}
\|D^\ell V\,D^{k-\ell}V\|_{L^2(U_{collar}^+)} .
\tag{PCR.7}
```

Thus the local pressure contribution to `(PCR.4)` is a retained velocity-tower
collar term.  It is not an independent pressure supplier and not a pressure-only
loss.

## 3. Harmonic pressure-memory part

The harmonic part contributes

```math
P_{\phi,H}^{strain}(s)
:=
\int_{\operatorname{collar}(\phi)}
|Q^H|
\left(
|\nabla^2\phi|\,|S|
+
|\nabla\phi|\,|\nabla S|
\right)\,dy .
\tag{PCR.8}
```

This is the strain-tower version of the harmonic pressure-memory collar channel
already admitted for the transported annular carrier.  It is retained in the
same packet by using the same transported cutoff \(\phi\) and the same
velocity-pressure tower.

For direct terminal uniform-tail estimates, `(PCR.8)` would need its own tail
modulus.  For the four-body counting route, it is simply part of the
pressure-memory collar channel inside \(A_{4B}\) on the retained atlas.

## 4. Same-packet admission statement

Let \(A_{4B}^{ann,tower}\) denote the annular tower part of the already oriented
same-carrier four-body activity.  On the retained transported annular atlas,
`(PCR.4)` is one of its collar densities:

```math
\boxed{
P_{\phi}^{strain}(s)
\le
C\,A_{4B}^{ann,tower}(s).
}
\tag{PCR.9}
```

This is an admission statement, not a new external payment account.  It uses
only the existing pressure-viscosity-incompressibility-velocity packet:

```math
\text{local pressure from }V\otimes V
\quad+\quad
\text{harmonic pressure-memory}
\quad+\quad
\text{transported collar/tower derivatives}.
\tag{PCR.10}
```

## 5. Result

The local pressure half of the strain-tower wall is closed on the retained
atlas:

```math
\boxed{
\texttt{PressureCollarSamePacketRouting.A}
\quad\text{is solved as same-packet }A_{4B}\text{ admission.}
}
\tag{PCR.11}
```

What remains from the strain tower is not pressure in isolation.  After global
pressure cancellation and local pressure-collar routing, the bulk obstruction is
the selected positive vorticity-stretching carrier:

```math
\boxed{
\int \phi[\omega\cdot S\omega]_+
}
\tag{PCR.12}
```

So the live pure forward-gold wall becomes:

```math
\boxed{
\texttt{PositiveVorticityStretchingSaturation.A}
}
\tag{PCR.13}
```

or the equivalent absolute same-packet stretching reserve.
