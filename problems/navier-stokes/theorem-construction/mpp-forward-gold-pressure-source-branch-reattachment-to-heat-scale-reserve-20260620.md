# MPP Forward-Gold Pressure/Source Branch Reattachment To Heat-Scale Reserve

Date: 2026-06-20

## Status

Reattachment note. This does not prove `UnweightedTerminalCriticalActionReserve.A`
and does not prove the Navier--Stokes smoothness theorem.

It closes one route-management gap left by the strict heat-clock/eigenframe
test: the named pressure-Hessian child is already reducible to the same
heat-scale endpoint pulse unless it adds a genuinely new pressure theorem.

## 1. Child left by the heat-clock gap test

The strict heat-clock gap test leaves the pressure/Riccati obstruction:

```math
D_t(n\cdot Sn)
=
-n\cdot(S^2+\Omega^2+\nabla^2p)n
+\nu n\cdot\Delta Sn
+\text{frame/commutator terms}.
\tag{PSR.1}
```

The sign-definite part \(-n\cdot S^2n\) is not the whole equation. The
pressure-Hessian term and the vorticity/projection/localization terms are
unsigned in the selected direction. Thus the heat-clock equality packet is not
excluded by trace-free strain, frozen eigenframe alignment, or a scalar Riccati
sign law.

The apparent child is therefore

```math
\text{TerminalPressureHessianNoSustain.A}
\tag{PSR.2}
```

or a same-carrier source-current theorem strong enough to pay the selected
pressure sustain.

## 2. Existing pressure no-sustain attempt already splits the child

The low-high pressure-Hessian no-sustain attempt gives the exact available
dichotomy:

```math
\text{pressure-Hessian sustain}
\Longrightarrow
\text{source-current/legal-source branch}
\quad\text{or}\quad
\text{pure pressure-sustain branch}.
\tag{PSR.3}
```

The reason is algebraic. Pressure is generated by the quadratic pressure law,
while the native positive carrier is the selected one-sided local source-current
after localization, projection, weights, lifts, packet selection, and
positive-part extraction. These are not identical objects.

The tangent model

```math
S=\operatorname{diag}(2,-1,-1),
\qquad
\Omega=0
\tag{PSR.4}
```

keeps a pure strain/pressure-Hessian sustain possibility while the vorticity
source-current branch can vanish at the algebraic carrier level. So pressure
Poisson structure does not force every selected pressure lobe into the native
positive source-current carrier.

## 3. Source-current branch returns to the terminal time pulse

The one-sided near-band source-current attempt pays the finite graph cases:
retained signed partners, legal exits, finite donor sinks, and conditional ASAC
pair-weight defects. Its remaining branch is a terminal Zeno refill with
nonnegative selected time marginal

```math
I_m=(T_m-\tau_m,T_m],
\qquad
\tau_m\downarrow0,
\qquad
g_m\ge0,
\qquad
\int_{I_m}g_m(s)\,ds\ge M_0>0.
\tag{PSR.5}
```

Finite selected \(L^1_s\) mass permits the model

```math
g_m(s)=\tau_m^{-1}\mathbf 1_{(-\tau_m,0]}(s),
\tag{PSR.6}
```

with fixed mass and weak-* terminal atom. The low-high cost dichotomy proves the
conditional consumer:

```math
\sup_m\int_{I_m}g_m(s)^p\,ds<\infty,\quad p>1
\Longrightarrow
\int_{I_m}g_m(s)\,ds\to0,
\tag{PSR.7}
```

by Holder. Conversely, if the mass in `(PSR.5)` survives, then every
super-\(L^1\) cost diverges:

```math
\int_{I_m}g_m(s)^p\,ds
\ge
M_0^p\tau_m^{1-p}
\longrightarrow\infty
\qquad(p>1).
\tag{PSR.8}
```

Thus the source-current side is not a new pressure supplier. It is exactly the
same terminal strip modulus/source-residence/source-square wall in low-high
currency.

\tag{PSR.9}
