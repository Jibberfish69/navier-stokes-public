# Primitive chamber chart/projector lift reduction

## 1. Physical chart object

Work inside one admitted stopped common-selector chamber \(C_{\mathfrak R}\).
The primitive event \(z\) is already owned by the parent selector. The
chart/projector question is whether the same event is measured in one retained
material frame where the exact pressure-Hodge/root projector is lawful before
the event is counted.

In material variables the projector is governed by the same packet's metric

\[
G=AA^\top,
\qquad
A=(D_aX)^{-1}.
\tag{CPL.1}
\]

Thus the chart coordinate is physical. It says the pressure/incompressibility
projection of this same transported packet is read in a material chart whose
metric has the symbol control needed by the exact projector. If the packet
leaves that chart, if \(G\) twists beyond controlled symbol bounds, or if higher
projector/pressure/collar residues appear, the failure must be paid or exited
before selected readout.

## 2. Two chamber-level inputs

The metric input is:

\[
\texttt{PrimitiveStoppedChamberC11MetricTowerOrExit.A}.
\tag{CPL.2}
\]

On each admitted stopped common-selector chamber, the pulled-back metric of the
same packet has the scale-local \(C^{1,1}\) / symbol-seminorm control needed by
the exact projector, or the uncontrolled portion exits through legal, stop,
chart-transfer, material-frame/tower service, or Pack/Part/Field before the
event is counted.

The higher-projector service input is:

\[
\texttt{PrimitiveStoppedChamberHigherProjectorServiceOrExit.A}.
\tag{CPL.3}
\]

On the same chamber, the higher exact-projector residue generated by
pressure/RHS service, annular-stress service, higher collar derivatives,
finite-depth tower terms, or moving-chart pressure projection is either paid by
finite same-material service or exits before readout.

## 3. Strict reduction

Assume `(CPL.2)' and `(CPL.3)'. The metric input supplies the retained material
frame and exact-projector symbol class for the same primitive chamber. The
higher-projector service input pays every part of the moving projector that is
not covered by the base chart coordinate.

Therefore the primitive event has a lawful chart/projector coordinate on
\(C_{\mathfrak R}\), modulo paid/legal/stop/exit pieces:

\[
\begin{aligned}
&\texttt{PrimitiveStoppedChamberC11MetricTowerOrExit.A}\\
&+\texttt{PrimitiveStoppedChamberHigherProjectorServiceOrExit.A}
\end{aligned}
\Longrightarrow
\texttt{PrimitiveStoppedChamberChartProjectorLiftOrPaidExit.A}.
\tag{CPL.4}
\]

Together with the nonselector coordinate lift reduction, this replaces the
chart component of primitive event-address custody by two smaller chamber-level
objects.

## 4. Why retained-edge chart license is support here

The retained-edge chart-license audit already identifies the correct physical
split: metric symbol control plus projector escape payment. Its scope is one
future-positive retained record edge. That is not the same as an arbitrary
primitive signed-channel event of either sign inside \(C_{\mathfrak R}\).

The chamber theorem must be stated before the event is used as a positive trace
or a negative return. It cannot borrow a chart from a later retained edge, and
it cannot use the post-map address-change theorem to prove the chart existed.

So the installed retained-edge reductions are support and source evidence for
the right coordinates, while the open chamber inputs are `(CPL.2)' and
`(CPL.3)'.

## 5. Current proof truth

This is a strict reduction, not proof of chart/projector lift. The remaining
physical work is:

\[
\text{same-chamber metric-symbol control or exit}
\quad+\quad
\text{same-chamber higher projector service payment or exit}.
\tag{CPL.5}
\]

Until those are proved on the admitted primitive chamber itself, the proof has
retained-edge chart support, not a primitive event chart coordinate.
