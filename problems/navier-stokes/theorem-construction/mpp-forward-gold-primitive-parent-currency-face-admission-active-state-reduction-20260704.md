# Primitive parent-currency face admission active-state reduction

## 1. Physical object

Work inside one admitted stopped common-selector chamber \(C_{\mathfrak R}\) of
one smooth Navier-Stokes velocity field. A primitive signed-channel event is

\[
z=(\sigma,t,x,\kappa),
\qquad
d\mu_{\kappa,C}=|Y_{\kappa,C}|\,d\sigma dt .
\tag{PCAS.1}
\]

The parent-currency face of \(z\) is the row of the same parent packet that can
see or pay \(z\) before selected sign or same-face return is counted:

\[
\text{positive-baseline root/log},
\qquad
\text{zero-baseline endpoint seed},
\qquad
\text{active full-exchange}.
\tag{PCAS.2}
\]

These rows are not new face geometry. They are the face projection of the parent
active state, selected-root payment, and active/full-exchange storage object.

## 2. Nonduplicate inputs

The all-event state input is

\[
\texttt{ParentKnownPreReadoutActiveStateCapacityOrPaidBoundary.A}.
\tag{PCAS.3}
\]

It gives the primitive event a parent-known active state before stopped,
selector, child, or record readout, or pays the failure as a state boundary,
service, legal loss, stop, or exit.

The selected-critical currency input is

\[
\texttt{OriginalHistoryRecordResetRootPayment.A}.
\tag{PCAS.4}
\]

It supplies the inherited/repeated root-log face and the fresh reset/endpoint
seed face from the same original material history before selected readout. This
is the physical source of the critical weighted root/endpoint rows; martingale
or Bessel language is only a consumer after this geometry exists.

The service input is

\[
\texttt{PrimitiveParentCurrencyServiceRoutingOrExit.A}.
\tag{PCAS.5}
\]

It routes pressure-detector silent pieces, chart/projector escape, material
collar service, detector/channel service, legal loss, stop, or exit before the
event is counted as unpaid parent-currency face mass.

## 3. Strict reduction

Assume `(PCAS.3)'--`(PCAS.5)'. For an unpaid primitive event, `(PCAS.3)' gives a
parent active state. If the event is root-visible with positive baseline, it is
owned by the root/log face. If it enters as a first critical reset or
zero-baseline first-entry event, `(PCAS.4)' places it in the endpoint-seed face.
If it is active/full-exchange-visible after the parent state is built, it is
owned by the active full-exchange face. If none of these rows can own it,
`(PCAS.5)' routes the event to service, legal loss, stop, or exit.

Thus

\[
\begin{aligned}
&\texttt{ParentKnownPreReadoutActiveStateCapacityOrPaidBoundary.A}\\
&+\texttt{OriginalHistoryRecordResetRootPayment.A}\\
&+\texttt{PrimitiveParentCurrencyServiceRoutingOrExit.A}
\end{aligned}
\Longrightarrow
\texttt{PrimitiveStoppedChamberParentCurrencyFaceAdmissionOrPaidService.A}.
\tag{PCAS.6}
\]

## 4. Checked obstruction

Record-menu root projection faithfulness has the right face list, but its domain
is a retained future-positive record edge. It proves no all-event statement for
\(d\mu_{\kappa,C}\). A primitive negative return event, detector-silent event,
or overlap event can be part of the signed-channel measure before it is a
future-positive retained record edge.

Parent active-state capacity alone is also not enough. It can give a first
scale/collar/projector state for \(z\), but a first active state is not yet a
root/log, endpoint, or full-exchange face. The selected-critical root/endpoint
currency and service routing must be attached to the same event.

So the false shortcut is

\[
\text{active first address}
+\text{record-edge face admission}
\not\Rightarrow
\text{primitive all-event parent-currency face admission}.
\tag{PCAS.7}
\]

The missing statement is same-event attachment of active state, root/endpoint
currency, active/full-exchange visibility, and service routing before readout.

## 5. Current proof truth

Installed here:

\[
\text{parent active state}
+\text{original-history root/endpoint payment}
+\text{primitive service routing}
\Longrightarrow
\text{all-event parent-currency face admission}.
\tag{PCAS.8}
\]

Still open:

\[
\texttt{ParentKnownPreReadoutActiveStateCapacityOrPaidBoundary.A},
\quad
\texttt{OriginalHistoryRecordResetRootPayment.A},
\quad
\texttt{PrimitiveParentCurrencyServiceRoutingOrExit.A}.
\tag{PCAS.9}
\]

This keeps the physical story single: the same primitive event must have a
parent active state, a lawful parent-currency face, or a paid/service/legal/stop
exit before the proof may use it as face-owned sign or return.
