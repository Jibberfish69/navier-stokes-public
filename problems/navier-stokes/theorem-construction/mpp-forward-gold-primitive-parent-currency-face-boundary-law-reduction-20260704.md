# Primitive parent-currency face boundary law reduction

## 1. Physical object

Work inside one admitted stopped common-selector chamber \(C_{\mathfrak R}\) and
one primitive signed-channel event

\[
z=(\sigma,t,x,\kappa).
\tag{PCBL.1}
\]

The parent-currency face atlas has only three physical rows:

\[
\text{root/log},\qquad
\text{endpoint seed},\qquad
\text{active full-exchange}.
\tag{PCBL.2}
\]

A boundary between these rows is not a new geometric face. It is the same parent
packet changing which currency can receive the event before selected sign or
same-face return is counted.

The possible row motions are exhausted by:

1. root/log to endpoint seed, or endpoint seed back to root/log;
2. root/endpoint currency to active full-exchange, or active full-exchange back
   to root/endpoint currency;
3. overlap where the event is claimed by more than one row before a
   parent-announced priority has chosen the row.

These are motions of one transported Navier-Stokes packet. Transport and
pressure carry the packet, viscosity and material service pay real boundary
loss, the selected-critical root geometry pays repeated/restart motion, and the
active full-exchange storage pays selected-meter motion. The face-trace process
comes later and cannot be used to pay this row boundary.

## 3. Strict reduction

Assume `(PCBL.3)'--`(PCBL.5)'. Let \(z\) be an unpaid primitive event on the
stopped chamber.

If \(z\) crosses between the root/log row and the endpoint-seed row, then the
crossing is inherited record/return motion or fresh critical reset motion of the
same original root geometry. It is paid by `(PCBL.4)' or becomes legal, stopped,
service-paid, or exited.

If \(z\) crosses between root/endpoint currency and active full-exchange
currency, then the same parent selected meter has changed active state or
full-exchange carrier. Its raw state boundary is paid by `(PCBL.3)', and the
selected critical active potential is paid by `(PCBL.5)' with subunit absorption,
or the event is service/legal/stop/exit.

If \(z\) lies in several rows at once, use the parent-announced order

\[
\text{root/log}\prec\text{endpoint seed}\prec\text{active full-exchange}
\tag{PCBL.6}
\]

unless a row transition has occurred. The transition cases are the two cases
above. Thus the overlap is either prioritized before readout or paid as the same
root/endpoint or active/full-exchange boundary motion.

Therefore

\[
\begin{aligned}
&\texttt{ParentKnownPreReadoutActiveStateCapacityOrPaidBoundary.A}\\
&+\texttt{OriginalHistoryRecordResetRootPayment.A}\\
&+\texttt{ParentActivePotentialCapacityDomination.A}
\end{aligned}
\Longrightarrow
\texttt{PrimitiveStoppedChamberParentCurrencyFaceBoundaryLaw.A}.
\tag{PCBL.7}
\]

This is a strict reduction, not a proof of the three inputs.
