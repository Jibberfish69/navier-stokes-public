# Primitive raw material channel atlas multiplicity reduction

## 1. Physical object

After the fixed-chart proof, the open object is the raw atlas theorem:

```math
\texttt{PrimitiveRawMaterialChannelAtlasFiniteOverlapOrPaidBoundary.A}.
\tag{RAM.1}
```

The raw atlas has to cover the primitive signed-channel measure before stopped
or selector readout. A physical event

```math
z=(\sigma,t,x,\kappa)
\tag{RAM.2}
```

is one piece of the same velocity field under transport, pressure,
incompressibility, viscosity, scale, collar/projector, sign, and time. The
atlas problem is not whether smooth material charts exist. They do. The problem
is whether the same primitive event is claimed with finite multiplicity across
the active scale/collar/projector choices before any selected positive readout
chooses the useful chart.

## 2. Geometric material charts are support

On a fixed material scale \(j\), a standard dyadic or Besicovitch material
atlas gives a finite-overlap family of material balls or annuli:

```math
\sum_\ell {\bf 1}_{B_{j,\ell}^\ast}(a)\le K_a .
\tag{RAM.3}
```

Smooth transport does not increase that multiplicity because
\(X_j(\cdot,t)\) is one-to-one on the retained material history:

```math
\sum_\ell
{\bf 1}_{X_j(B_{j,\ell}^\ast,t)}(x)
\le K_a .
\tag{RAM.4}
```

The same-material dyadic overlap lemma proves the separated log-scale version.
If the log-scale windows are separated, each \((\sigma,t,x)\) belongs to at
most one selected scale window and at most \(K_a\) transported material labels:

```math
\sum_{j,\ell}{\bf 1}_{\widehat P_{j,\ell}}(\sigma,t,x)
\le K_a .
\tag{RAM.5}
```

This is real support. It says physical nesting at a terminal point is not a
contradiction to finite overlap once the log-scale clock is part of the packet.

## 3. Why this does not prove the raw atlas theorem

The raw atlas theorem needs more than geometric charts. It needs the parent to
choose, before readout, which active scale/collar/projector states are allowed
to carry the primitive signed-channel measure, and it needs all duplicate or
failed choices to be paid.

Without such active-scale custody, the same fluid event can be present in many
nested raw material charts:

```math
z\in C_{j_1}\cap C_{j_2}\cap C_{j_3}\cap\cdots .
\tag{RAM.6}
```

This is not a point-set paradox. It is the exact proof danger. The fixed-chart
formula can be true on each \(C_j\), while the proof still has no finite
pre-readout multiplicity for the primitive measure and no paid boundary charge
for the losing charts.

The older retained-atlas heat-scale and cross-scale notes solve retained or
separated branches. They do not select the raw active scale/collar/projector
atlas for every primitive signed-channel event before stopped admission.

## 4. Active multiplicity theorem

The live lower theorem is:

```math
\texttt{PrimitiveRawActiveScaleCollarProjectorMultiplicityOrPaidBoundary.A}.
\tag{RAM.7}
```

It states that before stopped/selector readout, the parent assigns the primitive
signed-channel measure to a raw material channel atlas with bounded active
multiplicity:

```math
\sum_{\alpha\in\mathcal A_{raw}}
{\bf 1}_{C_\alpha}(z)
\le M_N
\quad
\text{for }d\mu_{\kappa,S}\text{-a.e. unpaid }z,
\tag{RAM.8}
```

where each raw chart \(C_\alpha\) carries a material scale, collar/projector
state, high packet, lower material coefficient, and raw channel label before
readout. Any violation of `(RAM.8)' is not ignored; it is charged as scale
boundary, collar/projector transfer, channel rotation, material service, legal
loss, stop, or exit:

```math
d\mu_{\kappa,S}^{mult/bdry}
\le
dPaid^{scale}
+dPaid^{collar/proj}
+dPaid^{rotation}
+dPaid^{material}
+dLegal+dStop+dExit .
\tag{RAM.9}
```

## 5. Reduction

The geometric material atlas support supplies finite overlap inside each fixed
scale and for separated scale windows. If `(RAM.7)' supplies the active
scale/collar/projector selection and pays the boundary/multiplicity failures,
then the raw atlas theorem follows:

```math
\texttt{PrimitiveRawActiveScaleCollarProjectorMultiplicityOrPaidBoundary.A}
\Longrightarrow
\texttt{PrimitiveRawMaterialChannelAtlasFiniteOverlapOrPaidBoundary.A}.
\tag{RAM.10}
```

Combined with the fixed-chart formula proof:

```math
\texttt{PrimitiveRawMaterialChannelFormulaOnFixedChart.A}
+
\texttt{PrimitiveRawMaterialChannelAtlasFiniteOverlapOrPaidBoundary.A}
\Longrightarrow
\texttt{PrimitiveSignedChannelPreReadoutMaterialChannelizationPartition.A}.
\tag{RAM.11}
```

Thus the current carrier-support branch is reduced to `(RAM.7)'.

## 6. Checked obstruction to importing retained overlap

The shortcut

```math
\text{retained/separated dyadic overlap}
\Longrightarrow
\text{raw pre-readout active atlas}
\tag{RAM.12}
```

is not valid.

Retained/separated overlap counts a family after the retained packet or
separated log-scale subfamily has been named. The raw theorem must explain why
the whole primitive signed-channel measure is already assigned to such a
bounded-multiplicity family before a stopped chamber, selected face, or
future-positive edge has chosen it.

This is the same physical warning in atlas language: a local finite-width
packet is real, and a separated same-material packet family can be counted, but
Gold needs parent-known active-scale custody for every primitive event that the
later signed-height proof wants to spend.

## 7. First-address sharpening

The active multiplicity theorem has now been sharpened by the first-address
reduction
`mpp-forward-gold-primitive-raw-active-state-first-address-reduction-20260704.md`.
The lower producer is

```math
\texttt{PrimitiveRawActiveStateFirstAddressOrPaidTransition.A}.
\tag{RAM.13}
```

It says that before stopped or selector readout, each primitive signed-channel
event has one parent-known first active state

```math
s_0(z)=(j,\psi,\mathbb P_A,\kappa),
\tag{RAM.14}
```

or the event is paid, legal, stopped, or exited. Any later active state that
also claims the same event must be a same-packet parent-announced first-exit
transition: scale boundary, collar/projector transfer, channel rotation, or
material service.

Together with the already installed finite-band and maximal first-exit overlap
support, this gives the strict reduction

```math
\texttt{PrimitiveRawActiveStateFirstAddressOrPaidTransition.A}
\Longrightarrow
\texttt{PrimitiveRawActiveScaleCollarProjectorMultiplicityOrPaidBoundary.A}.
\tag{RAM.15}
```

This is the point where the stopped reset machinery legitimately enters. Reset
overlap can count active-state changes only after the state being exited has a
parent-known first address.

The parent-capacity reduction
`mpp-forward-gold-primitive-raw-active-state-parent-capacity-reduction-20260704.md`
then identifies that first-address theorem as a local projection of

```math
\texttt{ParentKnownPreReadoutActiveStateCapacityOrPaidBoundary.A}.
\tag{RAM.15a}
```

The same coupled material state that must support record-admitted active storage
also assigns primitive first active states. Thus the raw atlas branch is not a
separate bookkeeping frontier; it is under the parent active-state capacity wall.
