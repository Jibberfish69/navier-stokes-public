# Record-menu pressure-active quotient angle collar reduction

## 1. Physical object

The object is the same retained high packet before record readout. The parent
root/full-exchange detectors are physical gauges of how much of that packet's
work is visible to the parent storage currency.

A packet with tiny detector response is not usable as pressure-active storage
just because the detector value is nonzero. If the detector sees only an
arbitrarily small fraction of the record work, the parent storage constant would
blow up. Physically that packet is detector-silent for the purposes of the Gold
record estimate: its work must be charged as same-packet material service before
the record can count it.

Thus the pressure-active split must be robust:

```math
\text{fixed detector angle}
\quad\text{or}\quad
\text{near-silent material-service collar}.
\tag{QAR.1}
```

Exact kernel language is only shorthand after this collar has been installed.

## 2. Frozen symbol conic split

On a retained material chart, after legal gauges and lower-order pieces are
removed, the frozen symbol fiber is finite-dimensional. Let \(z\) be the
retained symbol amplitude, let \(D(z)\) denote the joint parent root /
full-exchange detector vector, and let \(A(z)\) be the record work norm or
selected positive record functional on this frozen fiber.

Fix a small angle threshold \(\eta>0\). Split the retained unit sphere into

```math
\mathcal C_{\rm act}(\eta)
=
\{z:\ |D(z)|\ge \eta |A(z)|\},
\tag{QAR.2}
```

and

```math
\mathcal C_{\rm ns}(\eta)
=
\{z:\ |D(z)|< \eta |A(z)|\}.
\tag{QAR.3}
```

On \(\mathcal C_{\rm act}(\eta)\), the parent detector controls the record work
with constant \(\eta^{-1}\). On \(\mathcal C_{\rm ns}(\eta)\), the detector is
too weak to pay the record work uniformly; the component must be routed to the
same material-service reserve as the exact detector-silent component.

Because the frozen retained bundle is finite-dimensional and parent-known after
the chart/license hypotheses, this conic partition is compact symbol geometry.
It is not the Navier-Stokes PDE producer.

## 3. Correct lower reading

The pressure-active quotient angle theorem is valid only in this robust form:

```math
\texttt{RecordMenuNearSilentServicePreReadoutReserve.A}
\Longrightarrow
\texttt{RecordMenuPressureActiveQuotientAngleGap.A}.
\tag{QAR.4}
```

Here `RecordMenuNearSilentServicePreReadoutReserve.A` is not a new independent
frontier. It is the robust reading of
`RecordMenuDetectorSilentServicePreReadoutReserve.A`: exact detector-silent
directions and the fixed near-silent collar are both charged before readout to
same-packet strain/exchange, complete-frame compression, viscous/radius,
collar/annular service, legal loss, stop, or exit.

With that robust reserve in place, the pressure-active quotient has the uniform
angle by construction. Without it, an exact-kernel split leaves a sequence of
near-null record edges whose detector constants diverge.

## 4. Physical consequence

This removes the angle lemma as a separate PDE wall. The wall is still the
finite reserve for silent or near-silent same-packet service:

```math
\text{near-silent record work}
\Longrightarrow
\text{same-packet service locally}
\Longrightarrow
\text{finite original-history reserve}.
\tag{QAR.5}
```

The primitive half-tail audit already identifies the last arrow as the
independent original-history primitive PLS strict half-barrier / bounded-below
Lyapunov / weighted laminar reserve theorem.

## 5. Current truth state

`RecordMenuPressureActiveQuotientAngleGap.A` should not be pursued as an
analytic Navier-Stokes theorem. It is finite-dimensional conic bookkeeping after
the reserve is robust enough to absorb a fixed detector-near-silent collar.

The active PDE burden remains
`RecordMenuDetectorSilentServicePreReadoutReserve.A`, now read robustly: silent
