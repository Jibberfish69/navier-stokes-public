# Retained record-edge stopped primitive channel admission lower-face reduction

## 1. Physical burden

The object is one retained future-positive exact-projector record edge from the
same evolving velocity field. Before the record reads its positive part, that
edge has to remain one physical packet under transport, pressure, viscosity,
incompressibility, scale, sign, alignment, and time.

The exact-projector residue is same-packet pressure/strain service. That already
blocks the wrong reading where the residue is detached Hodge algebra. The unpaid
physical question is narrower: can the same retained edge be placed, before
positive readout, on one stopped primitive signed channel, with a fixed selector
cone and a legal route for every pressure-silent remainder?

If the selector is chosen after the record reads the positive part, the sign is
post-hoc. If the silent transverse part is ignored, the record can count work
that the pressure/root detector cannot see. If the primitive channel is not
proved compatible with the exact-projector residue on the same stopped carrier,
the record edge has changed coordinates without payment.

The record-net-work admission pass already isolates

```math

\tag{RSC.1}
```

This says that a frozen retained high-packet/low-strain record edge is either
pressure-active for the parent root/full-exchange detectors, or its
pressure/root-silent component is same-packet material service, legal, stopped,
or exited before the record can count it. It is the physical answer to the
transverse pressure-Hodge-null obstruction.

The fresh common-selector repair proves the correct construction order for the
older fresh-source branch:

```math
\texttt{FreshCommonSelectorRefinementNoLoss.A}.
\tag{RSC.2}
```

That support is branch-specific. It builds one stopped common selector for the
lower fresh visible/silent/exchange source, upper active queue, and positive
native trilinear density. It does not by itself prove that an arbitrary retained
future-positive exact-projector record edge can be refined onto one stopped
selector before readout.

The stopped selector aperture note records that, after common-selector

```math
\texttt{StoppedSelectorConeAperture.A}

\tag{RSC.3}
```

So the aperture is not an independent analytic frontier. The missing record-edge

## 3. Lower physical faces

The coupled channel admission reduces to:

```math
\begin{aligned}
&\texttt{RecordMenuPressureActiveOrSilentService.A}\\

\tag{RSC.5}
```

The three lower faces have distinct physical jobs.

`RecordMenuPressureActiveOrSilentService.A` keeps the frozen record edge honest:
the pressure-active part is visible to the parent detector currency, and the
pressure-silent transverse part is paid, stopped, legal, or exited before
readout.

The pressure-face reduction now splits this into a quotient angle and a real
service reserve:

```math
\texttt{RecordMenuPressureActiveQuotientAngleGap.A}
+\texttt{RecordMenuDetectorSilentServicePreReadoutReserve.A}
\Longrightarrow
\texttt{RecordMenuPressureActiveOrSilentService.A}.
\tag{RSC.5p}
```

The raw detector-angle theorem is false on unrestricted trace-free tensors. The
same-packet complete-frame and silent-source identities route detector-silent
work locally into strain/exchange, viscous/radius, collar/frame, legal, stop, or
exit service; the unpaid part is proving that this service is reserved before
arbitrary future record readout in the record's own units. The primitive
half-tail audit sharpens the reserve: it can be supplied only by an independent
original-history primitive PLS strict half-barrier / bounded-below Lyapunov /
weighted laminar reserve theorem. Proving it through this stopped-channel
admission would be circular because this admission already depends on the
pressure-active-or-silent face.

`RetainedRecordEdgeCommonSelectorRefinementNoLoss.A` is the retained-edge
version of common selection. For every arbitrary future-positive exact-projector
record edge, it must construct one parent-known stopped carrier, selector cone,
order-lock, polarity, and primitive channel before positive readout. Any mass
lost while changing labels, cutoffs, projections, order-locks, representatives,
collars, charts, or packet coordinates is charged before readout.

The parent-announced capture pass reduces this face further:

```math
\texttt{RetainedRecordEdgeParentAnnouncedSelectorCapture.A}
+\texttt{stopped-selector variation/payment support}
\Longrightarrow
\texttt{RetainedRecordEdgeCommonSelectorRefinementNoLoss.A}.
\tag{RSC.5a}
```

The unpaid part is not selector motion after capture. Existing stopped-selector
surfaces pay that motion relative to same-packet strain/exchange, viscous/radius,
legal, stop, and order-lock currencies. The unpaid part is capturing the
arbitrary future-positive record edge by a finite parent-known stopped score
before the record reads its positive part.

`RetainedRecordEdgePrimitiveChannelCompatibility.A` is the coordinate
compatibility theorem. On that stopped selector, the higher exact-projector
residue must be the primitive signed-channel increment of the same packet, up
to base projector, collar/frame, high-high, legal, stopped, and material-service
pieces already routed by the projector-escape audit.

## 4. Proof of the strict reduction

Take a retained future-positive exact-projector record edge. By
`RecordMenuPressureActiveOrSilentService.A`, its frozen symbol part either is
pressure-active or its silent component is already paid, stopped, legal, or
exited before readout.

For the pressure-active survivor,
`RetainedRecordEdgeCommonSelectorRefinementNoLoss.A` places the same record edge
on one stopped common selector before the positive part is read. The consumed
aperture support then gives the signed cone coercivity on that chamber:

```math
\|S_e\|_{sel}
\le
\theta^{-1}[\Gamma_{\mathfrak R}(S_e)]_+
dR^{paid}_e .
\tag{RSC.6}
```

Finally, `RetainedRecordEdgePrimitiveChannelCompatibility.A` identifies
\(\Gamma_{\mathfrak R}(S_e)\) with the primitive signed-channel coordinate of
the same retained packet, modulo already-paid projector/base/collar/frame/legal
and service terms. Therefore the edge is admitted to a stopped primitive signed
channel before record readout. That is exactly
`RetainedRecordEdgeStoppedPrimitiveChannelAdmission.A`.

Together with the existing coupled-selector pass, this gives:
