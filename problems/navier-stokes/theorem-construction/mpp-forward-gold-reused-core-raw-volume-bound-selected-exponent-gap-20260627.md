# Reused-core raw-volume bound and selected exponent gap

This note separates two facts that were too easy to blur in the reused-core
branch.

There is a raw material-volume theorem that follows from the original smooth
history and energy class.  It controls the average material-line Cauchy-Green
strain service.  It does not control the selected ancestry measure used by the
Gold first-ratio action.

## 1. Raw material-line service is finite

Let \(X(a,t)\) be the material flow, \(F(a,t)=D_aX(a,t)\), and let \(\xi\) be
a fixed material direction.  For

```math
e(a,t)={F(a,t)\xi\over |F(a,t)\xi|},
```

the Cauchy-Green logarithmic identity gives

```math
{d\over dt}\log |F(a,t)\xi|
=
e(a,t)\cdot S(X(a,t),t)e(a,t).
\tag{1}
```

Therefore

```math
\operatorname{Var}_{[0,T]} \log |F(a,t)\xi|
\le
\int_0^T |S(X(a,t),t)|\,dt.
\tag{2}
```

Integrating over a transported material region \(\Omega_a\) and using
incompressibility,

```math
\int_{\Omega_a}\int_0^T |S(X(a,t),t)|\,dt\,da
=
\int_0^T\int_{X(\Omega_a,t)} |S(x,t)|\,dx\,dt.
\tag{3}
```

On the periodic box, for each \(T<T^*\),

```math
\int_0^T\int_{\mathbb T^3}|S(x,t)|\,dx\,dt
\le
T^{1/2}|\mathbb T^3|^{1/2}\|S\|_{L^2_{t,x}([0,T]\times\mathbb T^3)}
<\infty.
\tag{4}
```

Thus the unselected raw material-volume average of Cauchy-Green line strain is
finite:

```math
\int_{\Omega_a}
\operatorname{Var}_{[0,T]}\log |D_aX(a,t)\xi|
\,da
<\infty.
\tag{5}
```

This is a real installed bound.  It is weaker than
`RepeatedCorePositiveVariationRootBound.A`.

## 2. Why the raw bound is not the selected root reserve

The Gold selected action is scale critical on retained affine heat packets.  In
a heat-scale packet of radius \(r\),

```math
|\Sigma|\simeq r^{-2},
\qquad
|Q_r|\simeq r^5.
\tag{6}
```

The raw \(L^1\) strain bill is

```math
\int_{Q_r}|\Sigma|\,dxdt
\simeq
r^{-2}r^5
=r^3,
\tag{7}
```

and the raw \(L^2\) strain bill is

```math
\int_{Q_r}|\Sigma|^2\,dxdt
\simeq
r^{-4}r^5
=r.
\tag{8}
```

The selected critical strain bill is scale invariant:

```math
\int_{Q_r}|\Sigma|^{5/2}\,dxdt
\simeq
r^{-5}r^5
=1.
\tag{9}
```

So a terminal family with \(\sum_k r_k<\infty\) has finite raw \(L^2\) strain
cost and even smaller raw \(L^1\) cost while carrying infinitely many selected
critical units.  The raw Cauchy-Green line-service theorem proves that the
unweighted material volume has finite service.  It does not prove that the
selected ancestry measure is absolutely continuous in the stronger critical
units.

## 3. The missing theorem is a selected measure-change theorem

The reused-core root theorem should therefore be typed as selected, not raw:

```math
\int \mathcal V_{\rm core}(a)\,d\mathcal R_{\rm ancestry}^{\rm sel}(a)
\le
C_N(u_0)+R_{\rm legal}.
\tag{10}
```

Here \(d\mathcal R_{\rm ancestry}^{\rm sel}\) is the selected ancestry reserve
that counts retained high-ratio packets in first-ratio units.  Replacing it by
raw material volume \(da\) changes the problem.

The noncircular exponent-lift form is:

```text
SelectedReserveAbsoluteContinuityExponentLift.A
```

Plain statement:

For one original smooth Navier-Stokes material history, the selected ancestry
reserve generated by retained high-ratio packets has enough absolute
continuity, reverse Holder gain, or martingale square-function control relative
to raw material volume and legal same-packet reserves that raw material-line
Cauchy-Green service upgrades to finite selected first-ratio action.

Equivalently, prove one of the following without defining the selected reserve
to already contain the desired conclusion:

```math
d\mathcal R_{\rm ancestry}^{\rm sel}
\ll da
\quad\text{with a reverse-Holder / Carleson density strong enough to beat (9),}
\tag{11}
```

or

```math
\sum_{Q\in\mathcal T_{\rm sel}}A(Q)
\le
C_N(u_0)+R_{\rm legal}.
\tag{12}
```

or the same content in martingale language:

```math
f_{\rm sel}\in RH_{1+\varepsilon}(d\mathcal R)
\quad\text{or}\quad
S_{\rm mart}(f_{\rm sel})\in L^2(d\mathcal R).
\tag{13}
```

## 4. Relation to the current Gold hinge

This note does not prove the selected-density gain.  It removes a false route
to it.

The raw material-history calculation supplies `(5)`.  The Gold branch needs
`(10)` or the direct selected first-ratio form `(12)`.  The gap between them is
the same half-tail exponent gap isolated by the selected critical strain
level-set test:

```math
L^2\text{ raw strain}
\quad\leadsto\quad
\lambda^{-2}\text{ level decay}
\quad\text{but}\quad
L^{5/2}\text{ selected action needs the missing half-power.}
\tag{14}
```

Thus the better target is not another raw deformation estimate.  It is one of
these selected gain statements:

```text
SelectedReserveAbsoluteContinuityExponentLift.A
SelectedDensityMartingaleSquareFunctionCarleson.A
SelectedCriticalStrainCapacityGoodLambda.A
AdjointSelectedCapacityGain.A
```

Each is a different coordinate system for the same missing assertion: original
same-material history must prevent the selected ancestry density from
concentrating in the critical half-tail while raw volume remains finite.

## 5. Result

The checked improvement is:

```math
\int_{\Omega_a}
\operatorname{Var}_{[0,T]}\log |D_aX(a,t)\xi|
\,da
<\infty
\qquad(T<T^*),
\tag{15}
```

with the proof supplied by the exact Cauchy-Green identity, incompressible
change of variables, and the raw \(L^2_{t,x}\) strain ledger.

The live Gold obstruction is now sharper:

```math
\text{raw material-volume finiteness}
\not\Rightarrow
\text{selected ancestry first-ratio finiteness}.
\tag{16}
```

The next proof attempt should attack the selected change of measure directly:
reverse Holder / good-lambda / martingale square function for the selected
density, or an original-history absolute-continuity theorem that upgrades
raw material-line service to the selected critical action measure.
