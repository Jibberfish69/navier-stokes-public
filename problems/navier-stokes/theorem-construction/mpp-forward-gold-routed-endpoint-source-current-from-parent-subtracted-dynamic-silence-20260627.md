# Routed endpoint source current from parent-subtracted dynamic silence

This note sharpens the attached improvement at the current live hinge.

The useful sentence is:

```text
silent at one time is allowed;
silent through the material clock is expensive.
```

The repo has already absorbed the local part: a boundary-flat pressure-Hodge
source can be invisible at a frozen time, and the overstrong target that every
zero-cost silent source vanishes has been corrected.  Inherited silent material
may persist as parent-predictable transport.  The endpoint theorem only gets
paid by the parent-subtracted fresh quotient.

## 1. The wrong endpoint-current shortcut

For a scalar endpoint mass \(M\), an elliptic right inverse can often produce a
current \(J_{\rm ri}\) with

```math
D_AJ_{\rm ri}=M,
\qquad
\|J_{\rm ri}\|_{L^2}\lesssim \|M\|_{H^{-1}}.
\tag{1}
```

That is not the Gold current.  It chooses a current after the scalar endpoint
mass is already formed, and it gives only an elliptic normalization.  It does
not prove that the endpoint mass was generated by the same material packet
before future selected-tail readout.  It also does not control the weighted
endpoint estimate

```math
\int H_w(t)\|M_0^{fresh}(t)\|_{L_x^2}^2\,dt.
\tag{2}
```

The source identity needed by the endpoint route is therefore not:

```text
solve D_AJ=M_0^{fresh} by any right inverse.
```

It is:

```text
construct J from the same parent-stopped material history, then read M_0^{fresh}
as its endpoint divergence plus paid stop/legal/branch terms.
```

## 2. Parent-subtracted dynamic endpoint current

Fix a stopped parent \(P\).  For a retained transition edge \(e\), let
\(\mathcal P_{e^-}\) be the parent-predictable lifted silent/exchange span and
let \(H_{e^-}\) be the parent-known active weight, both constructed before the
child selected readout.

For a boundary-flat silent source

```math

\qquad
w_e|_{\partial A_e}=0,
\qquad
\partial_{\nu_A}w_e|_{\partial A_e}=0,
\tag{3}
```

material evolution gives

```math

=
\mathcal L_A(D_tw_e)+[D_t,\mathcal L_A]w_e.
\tag{4}
```

The fresh endpoint contribution is the parent-subtracted part:

```math

(I-\Pi_{\mathcal P_{e^-}})

```

The frozen-symbol version is the same statement.  Silence is


```math

```

The part of `(7)` lying inside \(\mathcal P_{e^-}\) is inherited transport.
The part outside \(\mathcal P_{e^-}\) is the fresh endpoint current generator in
`(5)`.

## 4. Carleson producer still open

The representation is useful only with the stopped current estimate

```math

{1\over\mathcal R(P')}
\left[
\int_{\widehat {P'}} |J_{EP}^{S,new}|^2\,d\mathcal R
+Stop(P')
+R_{\rm legal}(P')
\right]
\le
C_N(u_0).
\tag{12}
```

The noncircular route is to prove `(12)` from the parent-known derivative
charges:

```math
\sup_{P'\subseteq P}

\sum_{e\subset P'}
\int H_{e^-}

C_N(u_0)+{R_{\rm legal}(P')\over\mathcal R(P')}.

```

The right side of `(13)` must come from original material history:

```math
\int_{\operatorname{Hist}(P')}

+|\operatorname{covector}|^2
+|\operatorname{frame}|^2
```
