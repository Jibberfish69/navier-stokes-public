# Same-Shell Interface Variation Direct Calculation

Date: 2026-06-25

## 0. Object

The up/down shell balance reduced the remaining physical motion to repeated
sign changes of the same active-shell interface.  This note differentiates that
interface in the transported material variables.

The material equation is

```math
\partial_t v+A^\top\nabla_a q
=
\nu\,\operatorname{div}_a(G\nabla_a v),
\qquad
\operatorname{div}_a(Av)=0,
\tag{SIV.1}
```

with

```math
A=F^{-1},
\qquad
G=AA^\top .
\tag{SIV.2}
```

Let \(\Delta_j^a\) be a fixed material shell projection and set

```math
v_j=\Delta_j^av.
\tag{SIV.3}
```

The same-shell interface from the weighted material energy identity is

```math
m_j(t)=P_j(t)+C_j(t),
\tag{SIV.4}
```

where

```math
P_j(t)
:=
-w_j\left\langle
\Delta_j^a(A^\top\nabla_aq),v_j
\right\rangle,
\tag{SIV.5}
```

and

```math
C_j(t)
:=
\nu w_j
\left\langle
\Delta_j^a\operatorname{div}_a(G\nabla_av)
-
\operatorname{div}_a(G\nabla_av_j),
v_j
\right\rangle .
\tag{SIV.6}
```

Here \(P_j\) is the pressure/incompressibility/coefficient interface and
\(C_j\) is the viscous coefficient commutator.  Together they are the signed
active-shell pump.

## 1. Pressure-interface derivative

Differentiate `(SIV.5)`:

```math
\dot P_j
=
-w_j\left\langle
\Delta_j^a(\dot A^\top\nabla_aq),v_j
\right\rangle
-w_j\left\langle
\Delta_j^a(A^\top\nabla_a\dot q),v_j
\right\rangle
-w_j\left\langle
\Delta_j^a(A^\top\nabla_aq),\dot v_j
\right\rangle .
\tag{SIV.7}
```

The coefficient derivative is exact:

```math
\dot A=-A(\nabla_av)A.
\tag{SIV.8}
```

The shell velocity derivative is exact from `(SIV.1)`:

```math
\dot v_j
=
-\Delta_j^a(A^\top\nabla_aq)
+
\nu\Delta_j^a\operatorname{div}_a(G\nabla_av).
\tag{SIV.9}
```

The pressure derivative is not free.  The pressure equation is

```math
L_G q=R,
\qquad
L_G=-\operatorname{div}_a(G\nabla_a),
\tag{SIV.10}
```

with

```math
R
=
A_{\ell i}A_{kj}
(\partial_{a_\ell}v_j)(\partial_{a_k}v_i).
\tag{SIV.11}
```

Therefore

```math
L_G\dot q
=
\dot R-\dot L_Gq.
\tag{SIV.12}
```

The operator derivative is

```math
\dot L_G f
=
-\operatorname{div}_a(\dot G\nabla_af),
\qquad
\dot G=-2ASA^\top,
\tag{SIV.13}
```

where \(S=\operatorname{sym}((\nabla_av)A)\).  Thus every term in \(\dot P_j\)
is a pressure-strain-coefficient-velocity-viscous term of the same material
packet.

## 2. Viscous-coefficient commutator derivative

Write

```math
B_j(v,G)
:=
\Delta_j^a\operatorname{div}_a(G\nabla_av)
-
\operatorname{div}_a(G\nabla_av_j).
\tag{SIV.14}
```

Then

```math
C_j(t)=\nu w_j\langle B_j(v,G),v_j\rangle .
\tag{SIV.15}
```

Differentiate:

```math
\dot C_j
=
\nu w_j\langle \dot B_j(v,G),v_j\rangle
+
\nu w_j\langle B_j(v,G),\dot v_j\rangle .
\tag{SIV.16}
```

The commutator derivative is exactly

```math
\begin{aligned}
\dot B_j(v,G)
={}&
\Delta_j^a\operatorname{div}_a(\dot G\nabla_av)
-
\operatorname{div}_a(\dot G\nabla_av_j)\\
&+
\Delta_j^a\operatorname{div}_a(G\nabla_a\dot v)
-
\operatorname{div}_a(G\nabla_a\dot v_j).
\end{aligned}
\tag{SIV.17}
```

Using `(SIV.9)` and `(SIV.13)`, this is again a finite expression made from
the same material velocity, pressure, coefficient, incompressibility, and
viscous tower.

## 3. Interface variation density

For a smooth preterminal interval \(I\),

```math
\operatorname{Var}_I(m_j)
=
\int_I|\dot m_j(t)|\,dt .
\tag{SIV.18}
```

Define the exact same-shell interface variation density

```math
\mathcal Z_j^{iface}(t)
:=
|\dot P_j(t)|+|\dot C_j(t)|,
\tag{SIV.19}
```

with \(\dot P_j\) and \(\dot C_j\) given by `(SIV.7)` and `(SIV.16)`.  Then

```math
\operatorname{Var}_I(m_j)
\le
\int_I\mathcal Z_j^{iface}(t)\,dt .
\tag{SIV.20}
```

Summing over an active shell range \(J(t)\), with selector changes charged to
the transported collar/frame channel, gives

```math
\operatorname{Var}_I\!\left(\sum_{j\in J(t)}m_j\right)
\le
\int_I\sum_{j\in J(t)}\mathcal Z_j^{iface}(t)\,dt
+
R_J^{switch}(I).
\tag{SIV.21}
```

This is exact.  A repeated up/down sign change of the active pump must appear
as material variation of \(A,G,q,v\), viscous commutator variation, or
transported collar/frame variation.

## 4. Rectified feed consequence

For each shell, the scalar BV estimate gives

```math
\int_I[m_j(t)]_+\,dt
\le
\left[\int_I m_j(t)\,dt\right]_+
+
|I|\operatorname{Var}_I(m_j).
\tag{SIV.22}
```

Using `(SIV.20)`,

```math
\int_I[m_j(t)]_+\,dt
\le
\left[\int_I m_j(t)\,dt\right]_+
+
|I|\int_I\mathcal Z_j^{iface}(t)\,dt .
\tag{SIV.23}
```

The signed term is already read by the shell energy balance:

```math
\int_I m_j(t)\,dt
=
e_j(b)-e_j(a)+\int_I d_j(t)\,dt .
\tag{SIV.24}
```

So positive active-shell feed is controlled by storage change, viscous
residence, and same-shell interface variation:

```math
\int_I[m_j]_+
\le
[e_j(b)-e_j(a)]_+
+
\int_I d_j
+
|I|\int_I\mathcal Z_j^{iface}.
\tag{SIV.25}
```

This is the direct mathematical version of the physical picture: infinite
positive feed can occur only if storage grows, viscosity pays, or the same
pressure-strain interface has infinite rectified variation.

## 5. Same-depth closure test

The formula above admits the recirculation cost to the full packet.  It does
not by itself prove the MPP.

To close the gold route, one needs the same-depth estimate

```math
\int_0^{T_*}
\sum_j |I_j(t)|\,\mathcal Z_j^{iface}(t)\,dt
<\infty
\tag{SIV.26}
```

with the interval weights \(I_j\) matching the active heat-scale sampling, and
with all terms controlled by the same continuation-depth material clock.

An estimate of the form

```math
\mathcal Z_j^{iface}
\le
C\,\mathcal P_{N+r}^{mat}
\tag{SIV.27}
```

for an uncontrolled higher record \(N+r\) is not a closure.  It is only a
diagnostic derivative-loss estimate.  The closure must either absorb the
derivatives through the viscous two-derivative gain, identify the pressure
terms with the already-counted pressure-strain/coefficient variation, or
produce a bounded-below storage whose drop pays `(SIV.26)`.

## 6. Consequence

The remaining physical object is now as small as it gets:

```math
\text{finite same-depth rectified variation of the active material interface}
\quad m_j(t).
\tag{SIV.28}
```

Everything in that variation is generated by the original smooth material
Navier-Stokes history.  There is no detached endpoint pulse, no arbitrary
annular signal, and no pressure-only or viscosity-only substitute left.
