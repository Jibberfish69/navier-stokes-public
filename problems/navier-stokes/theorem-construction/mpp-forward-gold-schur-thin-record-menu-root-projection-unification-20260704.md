# Schur-thin / record-menu root-projection unification

## 1. One physical event

The current Gold packet is one smooth Navier-Stokes velocity field and one
signed critical-height record interval

\[
H(t)={1\over2}\|\Lambda^{1/2}u(t)\|_2^2,
\qquad
{dH\over dt}=P(t)-\nu D(t).
\tag{SRU.1}
\]

On a record upcrossing \([a,b]\),

\[
\int_a^bP(t)\,dt
=H(b)-H(a)+\nu\int_a^bD(t)\,dt
\ge\lambda .
\tag{SRU.2}
\]

The full-output Schur object reads the same nonlinear work at rate level.  The
lawful selector is the recombined full-output critical transfer, not
input-coloured positive clipping.  The record-menu object reads the same work at
window level: high packet, low pressure/strain/current coefficient, material
time, and parent charge coordinate.

Thus there are not two physical sources.  Schur-thin upcrossing and record-menu
positive selection are two readouts of the same question:

\[
\text{where did the future-positive signed work already live in the parent
packet before the record or child readout selected it?}
\tag{SRU.3}
\]

## 2. What Schur-thin really asks

After the full-output current has been admitted, Schur-visible mass is paid by
the retained Schur pairing.  The Schur-thin branch is the part whose selected
square bill is large while the admitted Schur current response is small.

The older no-retained-nonendpoint reduction proves an important conditional
fact: once first-entry novelty, return, motion, viscosity, legal, and stop are
removed, an already admitted retained invisible square bill cannot survive away
from the same-witness endpoint face.  That is a proof of nonendpoint
no-survivor after admission.

It does not prove the missing entrance.  A high-density invisible square mass
still has to become a lawful retained child, an endpoint face, or a
parent-announced selected-density/root-current measure before the storage rows
are allowed to count it.

The selected-density/log-density package is therefore useful only in this
licensed form:

\[
d\mu_{\rm root}^{sel}
\le
C f_{pc}\,d\mathcal R_{\rm root}
+dPaid+dEnd,
\tag{SRU.4}
\]

together with the parent-current log-density equation and root square-function
bound.  Its physical role is to limit how many selected future arrangements the
same raw square mass can become.

But `(SRU.4)' must be the selected measure of the signed-height record-menu edge.
If the record edge has not first entered the parent root/full-exchange currency,
then the density theorem budgets a different measure.

## 3. Record-menu entrance is the common lower object

The record-net-work pass separates the algebraic menu from the storage problem.
LP/Bony/native decomposition supplies a parent-built menu of work coordinates.
That is coordinate support.  The open law is finite positive-selection storage
over that future-read menu:

\[
\sum_j\lambda_j^{-1}
\sum_e
\left[\int_{I_e\cap[a_j,b_j]}\omega_e\right]_+
\le C_N(u_0)+Paid+Legal+Stop .
\tag{SRU.5}
\]

The current lower entrance theorem is

\[
\texttt{RecordMenuRootProjectionFaithfulness.A}.
\tag{SRU.6}
\]

For every future-positive native record edge, it must prove before readout that
the same edge is visible in parent root currency or active full-exchange
currency, or has already left through paid/legal/stop material:

\[
\left[\int_{I_e\cap[a,b]}\omega_e\right]_+
\le
C_N(dA_e^{root,+}+d\Xi_e^{FE,act})
+Legal_e+Stop_e .
\tag{SRU.7}
\]

Once `(SRU.7)' is available, the positive-baseline log/root face,
zero-baseline endpoint-seed face, active full-exchange face,
selected-density/log-density square function, and coupled storage rows have an
actual same-record object to store.  Without `(SRU.7)', they can be true for
another parent measure while the signed-height record work remains unpaid.

## 5. Checked obstructions

Scalar signed current is insufficient.  A signed current can return to its
starting value while accumulating arbitrarily large positive variation.

Pointwise \(P_+dt\) is too strong and reopens the clipping habit.  The record
interval already supplies the positive sign through `(SRU.2)'.  The proof should
admit the net signed work of the record, not manufacture a child-positive source.

Local detector-silent routing is insufficient.  Silent pressure/strain work is
locally routed into same-packet service, but the half-tail model

\[
\sum_\ell\nu_\ell<\infty,
\qquad
\sum_\ell2^\ell\nu_\ell=\infty
\tag{SRU.9}
\]

shows that local payer assignment does not produce a finite record reserve.

Storage without entrance is insufficient.  Parent active/full-exchange storage
budgets the faces it contains.  It does not pay the signed-height record work
unless that work has first entered those faces before readout.

Record-admitted depletion cannot prove entrance.  Depletion/reset/storage rows
consume root projection after the edge is admitted; using them to prove
`RecordMenuRootProjectionFaithfulness.A' is circular.

## 6. Next physical proof unit

The next proof attempt should use a minimal bad future-positive record edge.
After legal, stop, lower-order, and paid material are removed, freeze the
retained packet.  The pressure-active quotient becomes a finite-dimensional
detector-angle problem.  The silent or near-silent component is the real PDE
burden: it must be paid before readout by a primitive full-action strict
half-barrier, bounded-below Lyapunov, or weighted laminar reserve from the
original same-material history.

The chart-license side is separate.  Exact pressure-Hodge/root projection must
follow the same high packet in a controlled material chart, or every
boundary/collar/cutoff/chart-transfer/projector escape must be legal, stopped,
material-service paid, or exit before the record can count the edge.

So the current honest proof pressure is:

\[
\begin{array}{c}
\text{prove detector-active angle or pre-readout silent-service reserve}\\
+\text{prove exact-projector retained chart license}
\end{array}
\Longrightarrow
\text{record-menu root projection for the signed-height edge.}
\tag{SRU.10}
\]

Every future candidate theorem should be judged against `(SRU.10)' first.  If it
only produces selected-density, log-density, Schur storage, active capacity,
primitive event ownership, dyadic localization, or scalar current language
without attaching to the same pre-readout record-menu edge, it is support.
