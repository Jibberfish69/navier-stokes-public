# Selected-root record/reset single-geometry synthesis

## 1. Physical object

There is one original Navier-Stokes material history under transport, pressure,
viscosity, incompressibility, scale, sign, alignment, and terminal time.

The selected-critical half-tail is not a collection of unrelated dyadic
packets. It is one retained history emitting small raw increments
\(\nu_\ell\) that remain summable for raw meters,

```math
\sum_{\ell\ge0}\nu_\ell<\infty,
\tag{RSG.1}
```

while the selected critical meter sees the weighted action

```math
\sum_{\ell\ge0}2^\ell\nu_\ell=\infty.
\tag{RSG.2}
```

Once local payments, inherited parent pieces, selector/collar/legal losses, and
silent-source normal forms are removed, the physical question is:

Can the same original history generate a parent-known root geometry before the
selected readout, so every selected-critical birth is either inherited
record/return motion or a genuinely fresh critical reset with a paid weight?

## 2. The branch fork is a geometry split

The extremal fresh-source note gives two geometries for a failed selected-root
reserve:

```math
\text{repeated same-core reuse}
\qquad\text{or}\qquad
\text{shrinking selected-core escape}.
\tag{RSG.3}
```

Those are not two different physical substances.

On the same stopped root geometry, a selected transition edge \(e=Q\to Q'\)
has the parent-predictable decomposition

```math
\widetilde Z_e=B_e+D_e+R_e.
\tag{RSG.4}
```

The inherited predictable part \(B_e\) is the repeated-core branch. It is
record/return motion of an already announced material score.

The innovation part \(D_e\) is the shrinking-core branch. After inherited
no-reset descendants are sent back to record/return, it is a genuinely fresh
parent-child selected reset.

Thus the fork should be read as

```math
\texttt{root geometry}
\quad\Longrightarrow\quad
\texttt{predictable record/return}
+\texttt{fresh reset innovation}.
\tag{RSG.5}
```

The Bessel/martingale language is a consumer after the root geometry exists.
It does not create the root geometry.

## 3. Repeated-core face

On one stopped material ancestry, the signed primitive record \(\Psi\) gives
the scalar identity

```math
V_+(\Psi;I_M)
=
\Psi(t_M)-\Psi(t_0)+V_-(\Psi;I_M).
\tag{RSG.6}
```

This is proof-grade algebra. It says repeated selected positive visits are paid
by record growth or by negative return needed to reuse the same core.

The current strict reduction is

```math
\begin{aligned}
&\texttt{PredictableRootWeightMartingaleRealization.A}\\
&+\texttt{SignedStoppedPLSEvolutionIdentity.A}\\
&+\texttt{StoppedReturnBVFiniteFromOriginalData.A}
\end{aligned}
\Longrightarrow
\texttt{RepeatedCorePositiveVariationRootBound.A}.
\tag{RSG.7}
```

The checked obstruction is equally clear: bounded record height is not enough.
A bounded scalar record can oscillate forever while both positive and negative
variation diverge. The PDE theorem must identify negative return as finite
original-history service of the same material packet.

## 4. Shrinking-core face

A shrinking selected core has

```math
r_k\downarrow0,
\qquad
A_{\rm sel}(Q_k)\simeq1.
\tag{RSG.8}
```

Raw capacity misses it. For a heat-scale affine packet,

```math
R_{\rm raw}(Q_r)\sim r,
\qquad
A_{\rm sel}(Q_r)\sim1.
\tag{RSG.9}
```

So a family can satisfy finite raw cost while selected action diverges. Raw
reset distance, raw Bessel freshness, raw pressure-Hodge capacity, and local
compactness all see the wrong meter.

After no-reset inherited children are routed back to record/return, the
shrinking branch has the strict form

```math
\begin{aligned}
&\texttt{ParentChildResetOrRepeatedCoreDichotomy.A}\\
&+\texttt{ResetVisibleSelectedCarrierObservability.A}\\
&+\texttt{CriticalWeightedParentChildResetCarleson.A}
\end{aligned}
\Longrightarrow
\texttt{ScaleInvariantSelectedCapacityNoEscape.A}.
\tag{RSG.10}
```

The reset weight must be generated from original-history log-scale derivative,
collar/turnstile motion, exchange, covector/frame motion, or equivalent
same-material reset structure before child selected readout.

## 6. Why this simplifies the repo

This consolidation blocks three repeat failures.

First, it prevents repeated-core record/return and shrinking-core reset from
being treated as separate Gold source walls. They are the inherited and
innovation faces of the same stopped root geometry.

Second, it prevents martingale/Bessel/root-Hilbert language from becoming the

record admission. Record-admitted depletion, reset, and storage may be used only
after the edge has entered parent currency.
