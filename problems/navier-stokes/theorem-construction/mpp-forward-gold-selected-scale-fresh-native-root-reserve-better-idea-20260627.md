# Selected-scale fresh native root reserve better idea

The current relay hinge was stated as the pair

```text
SourceOriginHilbertEnergyDissipationForSelectedAmplification.A
+
SelectorCarrierNondegeneracyOrPaidReselection.A.
```

The parallel checks and the existing repo surfaces show that this pair is still
one level too broad.

## 1. Checked negative facts

The source-origin Hilbert lane has the right geometry only after the root carrier
is already noncircular.  Bessel/Pythagoras is a consumer theorem once a fixed
original-history carrier exists.  It does not by itself build the root bound.

The tempting negative storage

```math
\mathcal B_N=-{1\over2}\|Z\|_{\mathcal H_{src}}^2
```

pays only when its lower bound is already the desired root reserve.  Saturating
it restores bounded-below status but stops paying the full selected square
function.  Defining \(Z\) from the future selected tail makes the proof circular.

The selector-readout side is also not closed in full generality.  Finite-menu
and already-paid label branches are safe, but continuum reselection survives
unless it is paid by full-packet order-lock / selector variation or absorbed into
the same stopped exchange ledger.

The installed half-tail model remains the decisive test:

```math
\nu_\ell={2^{-\ell}\over \ell+1},
\qquad
\sum_\ell\nu_\ell<\infty,
\qquad
\sum_\ell 2^\ell\nu_\ell=\infty.
```

Any route that sees only raw source mass, raw pressure-collar energy, or an
unweighted Hilbert norm still permits this model.

## 2. What the invisible-child currencies actually bought

The multicurrency invisible-child attack was still useful.  It says the boundary
currencies should be used only on the pressure-visible quotient.  The selected
Schur-silent branch must be routed into same-material strain/exchange, not forced
back into pure parent-boundary observability.

After that split, the stopped compensator combines three previously separate
items:

```text
visible pressure-Hodge quotient,
silent source routed into exchange,
unpaid reselection treated as stopped jump/exchange.
```

So the remaining wall is not local invisibility and not selector crossing.  The
remaining wall is the selected-weighted root reserve for the stopped same-material
action.

## 3. The better object

The sharper object is:

```text
SelectedScaleFreshNativeRootReserve.A
```

Work below a stopped parent \(P\).  Let

```math
Z_P^{orig}=Z_P^{vis}\oplus Z_P^{sil}\oplus Z_P^{ex}
```

be the original-history visible/silent/exchange carrier.  For a retained selected
child \(Q\), remove source directions already spent by strict selected ancestors:

```math
F_Q=(I-\Pi_{\mathcal S_{<Q}})\Delta_Q Z_P^{orig}.
```

The spent-source audit gives the right chain principle: after lower-band carry,
legal/entrance, paid selector jumps, paid silent-source exchange, and paid
full-exchange refunds are removed, a strict retained selected birth must read a
fresh native increment.

The live theorem is therefore the selected-scale root bound for those fresh
increments:

```math
\omega_Q
\le
C_N\|F_Q\|_{\mathcal H_{src}^{sel}}^2
+R_{paid}(Q)+R_{legal}(Q),
```

and

```math
\sum_{Q\subset P}\|F_Q\|_{\mathcal H_{src}^{sel}}^2
\le
C_N(u_0)\mathcal R(P)+R_{legal}(P).
```

The norm \(\mathcal H_{src}^{sel}\) must be built from original-history channels
with selected-scale weight: top-strain/frame residence, material Hodge/projector
motion, Schur/collar defect, annular stress, and frequency-native birth.  It may
not be defined from the future selected descendant tail.

## 4. Why this is better

This attacks the actual counterprofile.  The half-tail survives because each
level has tiny raw mass \(\nu_\ell\) but unit selected charge
\(2^\ell\nu_\ell\).  A raw Hilbert norm sees \(\nu_\ell\).  The desired fresh
native norm must see the selected-scale charge at the first native birth and then
forbid rereading the same source direction downstream.

So the better idea is not another local detector.  It is a two-part native
packing theorem:

```text
fresh lower edge:
  every strict retained selected birth has a fresh original-history source atom
  of selected-scale size;

root upper edge:
  those fresh atoms are orthogonal / bounded-overlap after spent-source
  projection and have finite root norm from original smooth data.
```

The first line kills the exponent gap.  The second line kills reuse and sibling
copying.  Together they imply `NativeBirthChargePacking.A`, then
`SelectedCompressionRootReserve.A`, then the stopped full exchange action
estimate.

## 5. Failure profile

If this better object fails, the exact remaining obstruction is:

```math
Q_0\supset Q_1\supset Q_2\supset\cdots,
\qquad
\omega_{Q_k}\simeq1,
```

where every \(Q_k\) is a strict retained selected birth, the spent directions and
paid branches have been removed, each \(Q_k\) still has only a fresh raw
heat-scale source cost comparable to \(2^{-k}/(k+1)\), and the selected-scale
fresh native norm is not bounded below.

That is the object to attack.  It is smaller than the Hilbert/root pair because
it no longer asks the boundary to see silent children, no longer asks saturated
Hilbert storage to pay a future tail, and no longer lets continuum selector
motion hide as a separate problem.
