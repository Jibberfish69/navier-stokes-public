# Selected-scale native reserve atom joint-interface reduction

The better attack is not four independent channel proofs.  After the paid
top-strain/coefficient-frame residence, lower-band carry, entrance/legal,
nonlaminar, selector/order-lock, and already-paid exchange terms are removed, the
remaining selected birth is a single joint low-high material interface problem.

The apparent channel split is still useful, but only as a case-exhaustion device:

```math
\text{Hodge/projector}
\quad+\quad
\text{Schur/collar}
\quad+\quad
\text{annular}
\quad+\quad
\text{frequency-native}
\tag{1}
```

does not give four independent reserves.  It collapses to the same moving
low-high pressure-stress/cubic-collar interface whose positive rectified action
has to be charged by an original-data lower edge.

## 1. What the channel audit actually says

The material Hodge/projector term is not a detached producer.  The installed
commutator reduction gives

```math
[\mathcal R_j^{Hodge}]_+
\le
\text{paid top-strain/frame/collar coordinate}
+
C\,e_j\Theta_j^{press/RHS}
+
C\,e_j\Theta_j^{annular\ stress}
+
r_j^{legal}.
\tag{2}
```

So a retained selected Hodge/projector birth is really a pressure/RHS, annular
stress, or paid-coordinate birth.  It is not a separate one-sided storage.

The Schur/collar graph correction also does not create a reserve.  The exact
pressure, Hodge, and collar graph defects vanish on the transported packet:

```math
Z_q=Z_{\mathbb P}=Z_\phi=0.
\tag{3}
```

The nonzero graph energies have the right derivative orientation only after
putting a negative sign on them.  That lower edge is equivalent to bounding the
pressure/operator or collar record itself:

```math
-E_p(t)\ge -C
\Longleftrightarrow
E_p(t)\le C,
\qquad
-E_{coll,N}(t)\ge -C
\Longleftrightarrow
E_{coll,N}(t)\le C.
\tag{4}
```

Saturating the energies saves the lower bound only by losing a uniform toll on
the clock.  Thus Schur/collar is not a closed channel reserve either.

The annular identity proves same-fluid attachment.  For a transported cutoff,

```math
{d\over dt}\int {1\over2}|u|^2\phi\,dx
+
2\nu\int\phi |S|^2\,dx
=
-\int u\cdot T\nabla\phi\,dx.
\tag{5}
```

This kills the detached-pulse model, but it does not prove the finite total
positive material clock from original data.  The remaining estimate is still a
bounded-below same-packet inequality

```math
d\mathfrak L_N
+
c\,d\Omega_N^{full}
+
d\mathcal L_N
\le
dR_N,
\qquad
\mathfrak L_N\ge -C_N(u_0).
\tag{6}
```

Finally, the frequency-native formulation names the same problem in ratio
language.  Raw original-history ledgers give only

```math
\sum_{\ell\ge0}\nu_\ell<\infty,
\tag{7}
```

while the selected action requires

```math
\sum_{\ell\ge0}2^\ell\nu_\ell<\infty.
\tag{8}
```

So frequency-native reserve is real only when it sees the first ratio moment.

## 2. The collapsed object

The channel audit leaves one nonduplicate object:

```text
MovingLowHighInterfaceSelectedAtom.A
```

For every first uncharged retained selected high-ratio birth atom \(\gamma\),
after all paid exits have been removed, the same packet must create a selected
unit in the moving low-high material pressure-stress/cubic-collar interface:

```math
\omega_\gamma
\le
C_N\,\Delta_\gamma^+\mathcal J_N
+
R_{\rm legal}(\gamma),
\qquad
\omega_\gamma\simeq1,
\tag{9}
```

where \(\Delta_\gamma^+\mathcal J_N\) is the selected-scale positive contribution
of the joint interface, not a raw \(L^2\), raw annular, raw collar, or fixed-depth
source measure.

The root theorem needed to pack these atoms is:

```text
MovingLowHighInterfaceLowerEdge.A
```

Construct a same-material storage \(Z_N\), finite below from original data, whose
drop pays the positive joint interface:

```math
dZ_N
+
c_N\,d\mathcal J_N
\le
dR_N^{paid},
\qquad
Z_N(t)\ge -C_N(u_0).
\tag{10}
```

Here \(dR_N^{paid}\) may use only already-installed paid terms: top-strain/frame
log storage, base-collar service, viscosity/radius service, lower-rank material
record, legal finite-overlap terms, and branch pieces whose own lower edge has
already been proved without the target first-ratio tail.

## 3. Why this is better than the previous target wording

`SelectedScaleNativeReserveAtom.A` was too wide as a working target because it
invited four local channel attacks.  Those attacks are already classified:

```text
Hodge/projector -> pressure/RHS + annular stress + paid coordinates.
Schur/collar    -> exact graph defect zero; nonzero energy lower edge circular.
Annular         -> same-fluid attachment, not finite total selected clock.
Frequency       -> first-ratio moment, not raw source mass.
```

The remaining mathematical object is therefore the joint interface measure
\(d\mathcal J_N\).  A proof of `(9)` plus `(10)` gives the selected-scale native
reserve atoms and the bounded lower edge.  A failure of `(9)` or `(10)` produces
the exact minimal bad object: an infinite laminar chain of first uncharged
selected births whose Hodge/projector, Schur/collar, annular, and frequency
readings all remain attached to the same material packet, but whose joint
interface positive variation has no original-data lower-edge storage.

## 4. Result

The selected-scale native atom problem is now reduced to the joint low-high
interface lower edge:

```text
MovingLowHighInterfaceSelectedAtom.A
+
MovingLowHighInterfaceLowerEdge.A
```

This is not Gold closure.  It is a sharper nonduplicate hinge: prove a selected
unit contribution of the moving low-high pressure-stress/cubic-collar interface
for the first uncharged retained birth, then prove an original-data lower edge
for the same interface storage.  Channel attachment, Schur graph correction,
minimal-bad compactness, and raw source ledgers are support only until they prove
that joint lower edge.
