# Selected symbol kernel exclusion: counterboundary

This note tests `SelectedSymbolKernelExclusion.A` at the frozen pressure-Helmholtz--Leray symbol level.

## 1. Target

The desired exclusion was

```math
m_{PH}(a,\xi)z=0
\quad\Longrightarrow\quad
a_{sel}(a,\xi)z=0
\tag{SSK.1}
```

for every retained selected source amplitude `z`, modulo legal and gauge-null directions.

## 2. Frozen symbol test

At a frozen material point with Euclideanized coefficients, the pressure-Helmholtz--Leray scalar source generated by a stress-type tensor `Z` sees the longitudinal contraction

```math
m_{PH}(\xi)Z
\simeq
{\xi_i\xi_j Z_{ij}\over |\xi|^2}.
\tag{SSK.2}
```

Set `xi=e_1`. Then

```math
m_{PH}(e_1)Z=Z_{11}.
\tag{SSK.3}
```

Choose a nonzero transverse trace-free tensor, for example

```math
Z=
\begin{pmatrix}
0&0&0\\
0&1&0\\
0&0&-1
\end{pmatrix}.
\tag{SSK.4}
```

Then

```math
m_{PH}(e_1)Z=0,
\qquad
|Z|^2=2.
\tag{SSK.5}
```

Thus raw pressure-Helmholtz--Leray visibility does not control arbitrary critical-strain tensor amplitude.

## 3. Consequence

`SelectedSymbolKernelExclusion.A` is false for the full unrestricted critical-strain tensor class. Therefore `PressureHelmholtzSelectedSourceFaithfulness.A` cannot be proved from the pressure-Helmholtz--Leray operator alone.

The selected source must satisfy a stronger retained-class property: it must be pressure-active, meaning its selected action ignores or legally pays pressure-Helmholtz--Leray-null transverse modes.

The exact theorem needed is

```text

```

Statement:

For every retained same-material high-ratio selected packet, the selected critical-strain source lies in the pressure-Helmholtz--Leray-visible symbol subbundle, or else its pressure-Helmholtz--Leray-null component is already paid by legal exit, material service, complete-frame variation, or another finite original-data reserve.
