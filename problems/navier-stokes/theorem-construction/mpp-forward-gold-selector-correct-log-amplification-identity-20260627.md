# Selector-correct log-amplification identity

## 1. Target

The square-packing relay needs the selected log-density increment to be the
stopped readout of the routed current increment:

```math
\Delta_Q\lambda_{sel}
=\log {f_Q\over f_{par(Q)}}
=\ell_Q(\Delta_QJ^S)-\psi_Q+e_Q.
\tag{1}
```

Here \(\psi_Q\ge0\) is stop/entropy loss and \(e_Q\) is legal or square-packable
error.

## 2. Stopped selector score construction

In the stopped finite-score selector model, the selected density is generated by
one parent-known stopped score:

```math
\lambda_{sel}(Q)=s_R(Q)+r_Q^{legal}-\Psi_Q^{stop},
\tag{2}
```

where \(s_R\) is a fixed stopped readout of the routed carrier:

```math
s_R(Q)=\ell_R(J^S(Q)).
\tag{3}
```

The score/readout \(\ell_R\) is fixed by the stopped selector cone, order-lock,
material frame, and covector data before child readout.  Hence, for a retained
edge \(par(Q)\to Q\),

```math
s_R(Q)-s_R(par(Q))=\ell_Q(\Delta_QJ^S)+e_Q^{frame/covector}.
\tag{4}
```

The frame/covector term is already one of the routed square-packable legal or
service terms.  The stopping entropy satisfies

```math
\Psi_Q^{stop}-\Psi_{par(Q)}^{stop}=\psi_Q\ge0.
\tag{5}
```

Subtracting `(2)` between parent and child gives exactly `(1)`:

```math
\Delta_Q\lambda_{sel}
=\ell_Q(\Delta_QJ^S)-\psi_Q+e_Q.
\tag{6}
```

## 3. Bounded readout and error packing

The stopped aperture gives a uniform readout bound

```math
|\ell_Q(V)|\le C\|V\|_{\mathcal H_{lift}}.
\tag{7}
```

The error term satisfies

```math
\sum_{Q\subset P}|e_Q|^2\mathcal R(Q)\le CR_{legal}(P)+CStop(P).
\tag{8}
```

Therefore the identity is compatible with the square-packing relay:

```math
\sum_{Q\subset P}|\Delta_Q\lambda_{sel}|^2\mathcal R(Q)
\le C\sum_{Q\subset P}\|\Delta_QJ^S\|^2\mathcal R(Q)+CR_{legal}(P)+CStop(P).
\tag{9}
```

## 4. Failure mode

The identity fails if \(\lambda_{sel}\) is fitted after seeing the future selected
tail.  In that case there is no fixed stopped score \(s_R\), no bounded readout
\(\ell_Q\), and no square-packable error decomposition.  Such future-fitted
selection is not part of the stopped selector construction and must be routed as
a reset/legal defect.

## 5. Result

Under the finite parent-known stopped selector model,

```math
\boxed{
\Delta_Q\lambda_{sel}
=\ell_Q(\Delta_QJ^S)-\psi_Q+e_Q,
\qquad \psi_Q\ge0,
}
```

with bounded readout and square-packable errors.  This verifies the selector
identity needed to relay stopped routed-current square-packing to the selected
first-ratio martingale estimate.

The only remaining local relay item is the final parent-drop/full-clock assembly
in manuscript form.
