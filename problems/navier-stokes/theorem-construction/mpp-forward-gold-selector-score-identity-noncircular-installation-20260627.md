# Selector score identity: noncircular installation note

## 1. Installed statement

The selected log-amplification increment is generated by a stopped selector score and routed current readout:

```math
\Delta_Q\lambda_{sel}
=\ell_Q(\Delta_QJ^S)-\psi_Q+e_Q,
\qquad \psi_Q\ge0.
\tag{1}
```

The readout is uniformly bounded:

```math
|\ell_Q(V)|\le C\|V\|_{\mathcal H_{lift}}.
\tag{2}
```

The error ledger is square-packable:

```math
\sum_{Q\subset P}|e_Q|^2\mathcal R(Q)\le CR_{legal}(P)+CStop(P).
\tag{3}
```

## 2. Noncircular definition of selected density

The identity is valid only if selected density is defined by the parent-known stopped score:

```math
\lambda_{sel}(Q)=s_R(Q)+r_Q^{legal}-\Psi_Q^{stop},
\qquad
s_R(Q)=\ell_R(J^S(Q)).
\tag{4}
```

Taking the parent-child difference in `(4)` gives

```math
\lambda_{sel}(Q)-\lambda_{sel}(par(Q))
=\ell_Q(\Delta_QJ^S)-[\Psi_Q^{stop}-\Psi_{par(Q)}^{stop}]+e_Q.
\tag{5}
```

Set

```math
\psi_Q=\Psi_Q^{stop}-\Psi_{par(Q)}^{stop}\ge0.
\tag{6}
```

This gives `(1)`.

## 3. Legal and stop terms

The stop term is favorable because it is nonpositive in the log-amplification increment:

```math
-\psi_Q\le0.
```

Legal/frame/covector/order-lock errors are collected in \(e_Q\) and must satisfy `(3)`.  If an error does not satisfy `(3)`, the edge is not retained in the nonlegal stopped score branch; it must be routed as reset, legal loss, or stop loss.

## 4. Excluded circular cases

This identity is invalid if \(\lambda_{sel}\) is fitted after reading descendants.  In particular, the following are not allowed as inputs:

```text
future best-descendant selected density,
a posteriori thresholding of the selected tail,
readout chosen after observing child amplification,
error terms defined as the leftover future selected action.
```

Those are circular and must be classified as reset/legal/stop defects.

## 5. Installation result

`SelectorCorrectLogAmplificationIdentity.A` is installable with the explicit source-graph clause:

```text
selected density is the stopped parent-known score readout of J^S, minus monotone stop entropy, plus square-packable legal error.
```

This supplies the noncircular bridge from stopped routed-current square-packing to selected-density martingale square-function control.
