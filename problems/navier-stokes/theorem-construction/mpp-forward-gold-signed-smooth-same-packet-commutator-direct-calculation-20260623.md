# Signed Smooth Same-Packet Commutator Direct Calculation

Date: 2026-06-23

## 0. Result

The direct calculation does not prove the MPP.  It proves the exact current
state of the smooth same-packet commutator line.

For one smooth transported material packet, the material equations give a
finite continuation-depth tower inequality of BKM type:

```math
dE_{N,m}
+
dD_{N,m}^{vis}
+
dD_{N,m}^{rad}
\le
C\,\Theta_{N,m}\,E_{N,m}\,d\sigma
+
dR^0_{N,m}.
\tag{SSC-DC.1}
```

Here \(E_{N,m}\) is the same-material velocity/pressure/coefficient/collar
record at the chosen continuation depth, \(dD_{N,m}^{vis}\) is the
variable-coefficient viscous loss, \(dD_{N,m}^{rad}\) is the radius/tower
loss, and \(\Theta_{N,m}\) is the same-material strain/coefficient service
rate generated by the full pressure-viscosity-incompressibility-velocity
packet.

Thus

```math
d[\log(1+E_{N,m})]_+
\le
C\,\Theta_{N,m}\,d\sigma
+
dR^0_{N,m}.
\tag{SSC-DC.2}
```

This is a correct logarithmic growth readout.  It is not the signed coercive
master balance.  To close the gold route one still has to prove either

```math
\int_{\sigma_0}^{\infty}\Theta_{N,m}(\sigma)\,d\sigma<\infty
\tag{SSC-DC.3}
```

from the same material participation law, or the stronger signed cross-storage
line

```math
\mathcal I_{N,m}
+
dX_{comm,m}
+
c\,d[\log(1+\mathcal P_{N,m}^{mat})]_+
\le
\varepsilon dD_{N,m}^{vis}
+
\varepsilon dD_{N,m}^{rad}
+
dR^0_{N,m}.
\tag{SSC-DC.4}
```

The current installed ingredients do not prove `(SSC-DC.3)` or `(SSC-DC.4)`.

## 1. Smooth material tower calculation

The pulled-back material Navier-Stokes packet is

```math
\partial_s v_m+A_m^\top\nabla_a q_m
=
\nu\,\operatorname{div}_a(G_m\nabla_a v_m),
\qquad
\operatorname{div}_a(A_m v_m)=0.
\tag{SSC-DC.5}
```

Apply \(D^\alpha\), with \(|\alpha|\le N\):

```math
\partial_sD^\alpha v_m
+
A_m^\top\nabla_aD^\alpha q_m
-
\nu\operatorname{div}_a(G_m\nabla_aD^\alpha v_m)
=
\mathcal C_{\alpha,m},
\tag{SSC-DC.6}
```

where

```math
\mathcal C_{\alpha,m}
=
-[D^\alpha,A_m^\top\nabla_a]q_m
+
\nu[D^\alpha,\operatorname{div}_a(G_m\nabla_a)]v_m.
\tag{SSC-DC.7}
```

Testing `(SSC-DC.6)` against \(w_\alpha\zeta^2D^\alpha v_m\) and summing
gives

```math
\frac12 d
\sum_{|\alpha|\le N}
w_\alpha\int\zeta^2|D^\alpha v_m|^2
+
dD_{N,m}^{vis}
+
dD_{N,m}^{rad}
=
\mathcal I_{N,m}
+
dR^{collar}_{N,m}
+
dR^{press}_{N,m}.
\tag{SSC-DC.8}
```

The pressure/divergence term cancels at top order through
\(\operatorname{div}_a(A_mv_m)=0\).  The remaining pressure terms are lower
material commutators and collar currents.  They remain inside the same
pressure/incompressibility packet; they are not independent pressure-only
accounts.

The dangerous smooth commutator is

```math
\mathcal I_{N,m}
=
\sum_{|\alpha|\le N}
w_\alpha
\int
\zeta^2D^\alpha v_m\cdot\mathcal C_{\alpha,m}.
\tag{SSC-DC.9}
```

Factorial weights control the Leibniz combinatorics:

```math
w_\alpha^{1/2}{\alpha\choose\beta}
\lesssim_N
w_\beta^{1/2}w_{\alpha-\beta}^{1/2}.
\tag{SSC-DC.10}
```

Moser/Kato-Ponce style product estimates on the smooth material packet then
give

```math
|\mathcal I_{N,m}|
\le
\varepsilon dD_{N,m}^{vis}
+
C_\varepsilon\,\Theta_{N,m}\,E_{N,m}\,d\sigma
+
dR^0_{N,m}.
\tag{SSC-DC.11}
```

The service rate \(\Theta_{N,m}\) is made from the same-material strain,
coefficient, pressure-service, and collar/tower quantities that differentiate
the record:

```math
\Theta_{N,m}
\sim
\|S(V_m)\|_{L^\infty(\widehat A_m)}
+
\|A_m,G_m\|_{W^{N,\infty}}
+
\text{same-packet pressure/collar service}.
\tag{SSC-DC.12}
```

Substituting `(SSC-DC.11)` into `(SSC-DC.8)` and absorbing the
\(\varepsilon\) loss terms gives `(SSC-DC.1)`.

## 2. Why this is not closure

The calculation gives a growth law.  It does not give a one-way payment law.

The Eulerian analogue is the standard high-order estimate

```math
\frac{d}{dt}\|u(t)\|_{H^s}^2
+
2\nu\|\nabla u(t)\|_{H^s}^2
\le
C\|\nabla u(t)\|_{L^\infty}\|u(t)\|_{H^s}^2.
\tag{SSC-DC.13}
```

Consequently,

```math
\frac{d}{dt}\log(1+\|u(t)\|_{H^s}^2)
\lesssim
\|\nabla u(t)\|_{L^\infty}
\tag{SSC-DC.14}
```

up to lower-order bounded terms.  Continuation follows if the strain clock is
finite:

```math
\int_0^{T_*}\|\nabla u(t)\|_{L^\infty}\,dt<\infty.
\tag{SSC-DC.15}
```

But proving `(SSC-DC.15)` from original smooth finite-energy data is a
regularity theorem, not a consequence of the high-order energy identity alone.
The material packet version is the same issue with the correct same-fluid
geometry retained: proving finite \(\int\Theta_{N,m}\,d\sigma\) is the
unresolved gold estimate.

## 3. Infinite tower does not fix the sign

Running the calculation at all depths gives a projective family of inequalities
like `(SSC-DC.1)`.  It does not change the sign of \(\mathcal I_{N,m}\).

The full smooth field keeps all frequencies.  The finite \(N\) here is only the
continuation-depth coordinate needed for one fixed \(H^s\) relaunch readout.
For any \(s>5/2\), choose \(N=N_s\).  If `(SSC-DC.3)` or `(SSC-DC.4)` were
proved for that depth, the material-clock-to-fixed-\(H^s\) bridge would give
the continuation contradiction.  Demanding a single simultaneous infinite-tower
estimate would be stronger than necessary and would still need the same signed
clock mechanism at every depth.

## 4. Current theorem state

The same-fluid pay-it-back-later picture remains the correct physical object:
the last-time center pulse must be read through the later transported annular
stress/strain history.  The initial wave-packet picture also stays in this same
object.  Smooth initial data may contain infinitely many frequencies, but its
Fourier amplitudes have finite Sobolev tails:

```math
\sum_k (1+|k|^2)^s|\widehat u_0(k)|^2<\infty
\qquad
\text{for every }s.
\tag{SSC-DC.16}
```

That is entrance control for the full packet, not finite frequency support.
The nonlinear term can move energy into higher frequencies, so the initial tail
continues to control the terminal tower only under the same finite material
strain/coefficient clock:

```math
\mathcal P_N^{mat}(0)<\infty
+
\int_0^{T_*}\Theta_N(t)\,dt<\infty
\Longrightarrow
\sup_{t<T_*}\mathcal P_N^{mat}(t)<\infty.
\tag{SSC-DC.17}
```

The annular stress/strain return gives the correct internal-force carrier, and
on each fixed retained material annulus it has no endpoint atom.  Across a
shrinking heat-scale family, however, its physical mass is radius-discounted:

```math
\int_{T-r^2}^{T}\rho_{A_r}(t)\,dt
=
r\int_{-1}^{0}\widehat\rho_{A_r}(s)\,ds.
\tag{SSC-DC.18}
```

So the later return history is attached to the spike, but physical \(L^1\)
stress-work alone does not give the unweighted normalized clock.  The direct
calculation shows exactly what is still missing mathematically:

```math
\boxed{
\text{the full material strain/coefficient service clock must be finite,}
}
\tag{SSC-DC.19}
```

or equivalently,

```math
\boxed{
\text{the commutator must admit a signed same-packet cross-storage/coercivity
line.}
}
\tag{SSC-DC.20}
```

No current file proves that line.  The repo should therefore keep the MPP
closure conditional on `SignedSmoothSamePacketCommutatorCoercivity.A`, with
this note as the direct calculation showing why the unsigned tower estimate is
not enough.
