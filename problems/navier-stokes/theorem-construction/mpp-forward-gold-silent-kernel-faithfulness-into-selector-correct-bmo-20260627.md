# Silent-kernel faithfulness into selector-correct BMO

The better attack is exactly the silent interior source normal form.
Boundary invisibility alone cannot rule out a source

```math
f=L_Aw
```

with \(w\) boundary-flat.  The useful question is whether that invisible source
can also be a retained selected critical-strain carrier at zero same-material
cost.

## 1. Silent kernel first

On a retained material collar, let

```math
\mathcal K_{\rm sil}
:=
\{\,f=L_Aw:\ w|_{\partial A}=0,\ \partial_{\nu_A}w|_{\partial A}=0\,\}.
\tag{1}
```

The parent Schur trace can vanish on this kernel.  So the direct observability
claim

```math
\mathsf S_\infty U_\infty=0
\Longrightarrow
f=0
\tag{2}
```

is the wrong theorem.

The source-origin theorem is the correct theorem:

```math
\mathcal K_{\rm sil}
\cap
\{\text{retained selected pressure-Hodge carriers}\}
\subset
\{\text{hidden-potential / constraint material}\}
\cup
\{\text{same-material top-strain/exchange charged material}\}.
\tag{3}
```

In zero-cost form,

```math
\mathsf S_\infty U_\infty=0,
\qquad
d\Omega_\infty^{top\text{-}strain/ex}=0,
\qquad
dD_\infty^{vis/rad}=0
\quad\Longrightarrow\quad
A_\infty=0.
\tag{4}
```

This is the no-silent-selected-carrier statement actually needed by the Gold
route.

## 2. Why the hidden branch is unselected

The pressure force generated by \(w\) is

```math
\mathcal G_Aw=A^\top\nabla_aw.
\tag{5}
```

The material Hodge projector is

```math
\mathbb P_A=I-\mathcal G_A L_A^{-1}D_A,
\qquad
L_A=D_A\mathcal G_A.
\tag{6}
```

Therefore

```math
\mathbb P_A\mathcal G_Aw=0.
\tag{7}
```

So a purely hidden pressure-potential component is constraint material in the
projected material velocity equation.  It has no selected velocity-participation
readout.

## 3. Why a selected silent source spends exchange

If the same \(w\) is selected, it is selected through the strain-Hessian reading
in the material strain equation:

```math
D_tS+S^2+\Omega^2+\nabla_A^2q
=
\nu\Delta_AS+\mathcal C_A^{legal}.
\tag{8}
```

Set \(q=w\).  For a selected unit direction \(e\),

```math
-e\cdot\nabla_A^2w\,e
=
D_t(e\cdot Se)
+e\cdot S^2e
+e\cdot\Omega^2e
-\nu e\cdot\Delta_ASe
+\mathcal C_A^{legal}.
\tag{9}
```

Since \(e\cdot\Omega^2e=-|\Omega e|^2\),

```math
\left[-e\cdot\nabla_A^2w\,e\right]_+
\le
\left[D_t(e\cdot Se)\right]_+
+|S|^2
+|\Omega e|^2
+\nu|\Delta_AS|
+|\mathcal C_A^{legal}|.
\tag{10}
```

The right side is the same-material exchange service: top-strain log/exchange,
complete-frame strain-vorticity service, viscous/radius tower service, or legal
residual.

The old pressure-Hodge symbol kernel for transverse trace-free tensors is also
not a zero-cost selected carrier once the complete frame is retained.  With a
frame \((\hat\xi,p,n)\) and \(\operatorname{tr}S=0\),

```math
p\cdot Sp+n\cdot Sn=-\hat\xi\cdot S\hat\xi.
\tag{11}
```

So a transverse selected silent mode is not invisible to the full retained
packet.  It is carried by the complete-frame exchange coordinate.

Thus

```math
dA_{\rm sel}^{silent}
\le
C\,d\Omega^{top\text{-}strain/ex}
+C\,dD^{vis/rad}
+dR^{legal}.
\tag{12}
```

## 4. How this enters the selector-correct Hilbert carrier

The fixed-carrier Hilbert packet is

```math
\mathcal H_{\rm lift}
=
\mathcal H_{\rm vis}
\oplus
\mathcal H_{\rm sil}
\oplus
\mathcal H_{\rm ex}.
\tag{13}
```

The silent-kernel normal form dictates the roles of these summands:

```math
\mathcal H_{\rm vis}
=
\text{pressure-Hodge Schur/Rellich visible quotient},
\tag{14}
```

```math
\mathcal H_{\rm sil}
=
\text{boundary-flat pressure-potential bubble energy},
\tag{15}
```

```math
\mathcal H_{\rm ex}
=
\text{selected silent-source origin / top-strain exchange carrier}.
\tag{16}
```

The selected readout is not allowed to read hidden-potential material as free
activity.  In fixed-carrier form,

```math
\log r_Q
=
\ell_Q(\Delta_QZ)-\psi_Q+e_Q,
\tag{17}
```

where the functional \(\ell_Q\) annihilates pure constraint material in
\(\mathcal H_{\rm sil}\), and any silent selected component is represented in
\(\mathcal H_{\rm ex}\).  Therefore

```math
\Delta_QZ^{vis}=0,
\qquad
\Delta_QZ^{ex}=0,
\qquad
e_Q=0
\quad\Longrightarrow\quad
A_Q^{sel}=0
\tag{18}
```

on the fixed retained carrier.

This is the faithfulness statement that the earlier boundary-only theorem was
trying to obtain from Schur data alone.

## 5. Consequence for the Gold route

The martingale step is already a consumer theorem:

```math
\log r_Q
=
\ell_Q(\Delta_QZ)-\psi_Q+e_Q,
\qquad
\sup_P{1\over\mathcal R(P)}
\sum_{Q\subset P}
\bigl(\|\Delta_QZ\|_{\mathcal H}^2+|e_Q|^2\bigr)\mathcal R(Q)
\le C_N(u_0)
\tag{19}
```

implies

```math
\rho_{\rm sel}\in RH_{1+\varepsilon}(d\mathcal R).
\tag{20}
```

The silent-kernel theorem supplies the local faithfulness required by the fixed
carrier part of `(19)`.  It does not by itself supply the global Carleson
square function.

The remaining proof-bearing Gold object is still the selected-critical global
root/tent gain.  In the selector-correct Hilbert form, it is:

```math
\sup_P{1\over\mathcal R(P)}
\sum_{Q\subset P}
\bigl(
\|\Delta_QZ\|_{\mathcal H_{\rm vis}\oplus\mathcal H_{\rm sil}\oplus\mathcal H_{\rm ex}}^2
+|e_Q^{lab}|^2
\bigr)\mathcal R(Q)
\le
C_N(u_0)+R_{\rm legal}(P),
\tag{21}
```

with \(Z\) built from original material history, not from the future selected
tail.

decomposition before positive projection:


decomposition.  The strain/top-eigenframe, pressure-Hessian, Hodge/Stokes,
coefficient/frame, collar, annular interface, and viscous/radius coordinates
still have to be derived from the same material Navier-Stokes participation
law.

