# Silent-kernel source-origin normal form

## 1. Motivation

The boundary-observability route failed for the right reason. Elliptic theory permits boundary-flat interior sources:

```math
f=\mathcal L_A w,
\qquad
w|_{\partial A}=0,
\qquad
\partial_{\nu_A}w|_{\partial A}=0.
```

Such a source can be invisible to the parent Schur trace. Therefore the right question is not whether the boundary detects every interior source. It does not.

The sharper question is:

```math
\text{Can a boundary-flat pressure-Helmholtz--Leray source also be a retained selected critical-strain carrier?}
```

## 2. Proposed normal form

Define the silent source class

```math
\mathcal K_{sil}
:=
\left\{f:\ f=\mathcal L_A w,\ w|_{\partial A}=0,\ \partial_{\nu_A}w|_{\partial A}=0\right\}.
```

The desired source-origin normal form is the dichotomy

```math
f\in \mathcal K_{sil}\cap\mathcal C_{sel}
\quad\Longrightarrow\quad
\text{either } f \text{ is gauge/hidden-potential and } A(f)=0,
\quad\text{or } f \text{ spends top-strain exchange charge.}
\tag{SO.1}
```

Equivalently,

```math
\ker(\text{parent Schur trace})
\cap
\{\text{retained selected pressure-Helmholtz--Leray carriers}\}
\subseteq
\{\text{exchange-charged selected carriers}\}.
\tag{SO.2}
```

The ideal hard form is

```math
\ker(\text{parent Schur trace})
\cap
\{\text{retained selected pressure-Helmholtz--Leray carriers with zero exchange charge}\}
=
\{0\}.
\tag{SO.3}
```

## 3. Fork

### Branch A: gauge / hidden-potential material

If the boundary-flat source is only a hidden pressure-Helmholtz--Leray potential, then it is not selected critical-strain production. In that case the selected action vanishes:

```math
f\in\mathcal K_{sil},\quad f\in\mathcal G_{hidden}
\quad\Longrightarrow\quad
A_{sel}(f)=0.
\tag{SO.4}
```

This is the harmless branch.

### Branch B: retained selected origin

If the same boundary-flat source is genuinely a retained selected critical-strain carrier, then it is not free. Its source has to be generated by same-material top-strain/log exchange, packet-frame rotation, or covector/normal service inside the packet.

The desired lower bound is

```math
A_{sel}(f)
\le
C\,\mathcal E_{top\text{-}ex}(Q)
+C\,\mathcal S_{material}(Q)
+C\,R_{legal}(Q),
\tag{SO.5}
```

where `E_top-ex` is the top-strain log/exchange clock and `S_material` includes the pressure-null material service already isolated by the complete-frame demotion.

## 4. Connection to the current hinge

The current relay hinge is

```text
SelectedDensityMartingaleSquareFunctionCarleson.A
```

for the pressure-visible/null-routed selected density.

The source-origin normal form gives a route into that hinge:

1. pressure-visible selected density is charged by parent Schur trace;
2. boundary-flat but unselected sources have zero selected action;
3. boundary-flat retained selected sources are charged by top-strain exchange/material service;
4. the selected density martingale increment is then controlled by Schur trace plus exchange/service increments.

The target estimate becomes

```math
\sum_{Q\subseteq Q_0}
|\Delta_Q \rho_{sel}|^2\,\mu(Q)
\le
C\Bigl(
B_{Schur}(Q_0)
+E_{top\text{-}ex}(Q_0)
+S_{material}(Q_0)
+R_{legal}(Q_0)
\Bigr).
\tag{SO.6}
```

This is a sharper form of the selected-density square-function Carleson estimate.

## 5. Exact theorem pair needed

The route now needs two theorems.

```text
SilentKernelSourceOriginNormalForm.A
```

Statement: every boundary-flat pressure-Helmholtz--Leray source in the retained same-material packet is either gauge/hidden-potential and unselected, or has retained selected origin.

```text
BoundaryFlatSelectedCarrierExchangeCharge.A
```

Statement: every boundary-flat source with retained selected origin has a nonzero same-packet top-strain exchange/material-service charge controlling its selected action.

Symbolically,

```math
f\in\mathcal K_{sil}\cap\mathcal C_{sel}
\quad\Longrightarrow\quad
A_{sel}(f)
\le
C(E_{top\text{-}ex}+S_{material}+R_{legal}).
\tag{SO.7}
```

## 6. Result

This is better than another boundary observability theorem. It accepts that boundary-flat elliptic sources exist and instead classifies their origin.

The useful pressure point is:

```text
An invisible source is either unselected, or selected only by spending the top-strain exchange/material-service clock.
```

If `SO.7` is proved, the silent-source escape is removed from the selected-density Carleson problem, and the current selected first-ratio closure route becomes more realistic.
