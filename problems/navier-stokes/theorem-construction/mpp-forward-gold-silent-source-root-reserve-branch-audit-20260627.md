# Silent source / root reserve branch audit

The silent-source theorem is exactly the useful local statement, with the
necessary zero-service qualifier:

```math
\mathsf S_\infty U_\infty=0,
\qquad
\Omega_\infty^{strain/ex}=0,
\qquad
D_\infty^{vis/rad}=0
\quad\Longrightarrow\quad
A_\infty=0.
\tag{1}
```

Boundary-flat pressure-Hodge sources can exist.  The point is that a
boundary-flat source cannot be both retained-selected and free.  It is either
projected constraint material,

```math
\mathbb P_A(A^\top\nabla_aw)=0,
\tag{2}
```

or it enters through the material pressure-Hessian / complete-frame strain
packet and pays top-strain, exchange, viscous, or legal service:

```math
dA_{\rm sel}^{silent}
\le
C\,d\Omega^{top\text{-}strain/ex}
+C\,dD^{vis/rad}
+dR^{legal}.
\tag{3}
```

So the silent interior source direct attack closes the local invisible-child
escape.  It does not produce the global selected root summability.

## 1. Parent-drop after the silent-source normal form

The installed parent-drop law is:

```math
\sum_{Q'\in ch(Q)}A(Q')
\le
C\langle U_Q,\mathsf S_QU_Q\rangle
+C\,\Omega_Q^{strain/ex}
+C\,D_Q^{vis/rad}
+C\,R_{\rm legal}(Q).
\tag{4}
```

After pressure-visible/null routing this becomes the branch-local payment:

```math
A(Q)
\le
C\left(
\langle U_Q,\mathsf S_QU_Q\rangle
+\mathcal S_{\rm normal}(Q)
+\mathcal S_{\rm covector}(Q)
+\mathcal B_{\rm select}(Q)
+R_{\rm legal}(Q)
\right).
\tag{5}
```

Equation `(5)` is local.  The global proof still needs the original-history
upper/root reserve:

```math
\sum_{Q\in\mathcal T_{\rm sel}}
\left(
\langle U_Q,\mathsf S_QU_Q\rangle
+\mathcal S_{\rm normal}(Q)
+\mathcal S_{\rm covector}(Q)
+\mathcal B_{\rm select}(Q)
\right)
\le
C_N(u_0)+R_{\rm legal}.
\tag{6}
```

This is the selected root reserve.

## 3. Shrinking-core branch audit

The shrinking-core branch has per-core scale-invariant local payment, but raw
capacity is too small.  A transported affine half-tail can have summable raw

```math

\le
C_N(u_0)\mathcal R(P)+R_{\rm legal}(P).
\tag{8}
```

This is the fresh-source tent / scale-memory form of the same root reserve.
