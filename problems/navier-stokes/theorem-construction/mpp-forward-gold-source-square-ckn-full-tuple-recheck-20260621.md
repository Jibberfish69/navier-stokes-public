# Source-Square / CKN Full-Tuple Recheck

Date: 2026-06-21

## 0. Distinction

The participation-tuple audit marks source-square, critical density, CKN, and
amplitude currencies as coupling breakers when they are used before the selected
packet has carried the full tuple.

The valid repaired use is:

```math
\boxed{
\text{full tuple first, scalar critical currency second.}
}
\tag{SSCR.1}
```

That distinction matters.  Source-square/CKN is not the native payment carrier.
It is a possible consumer after same-carrier identification.

## 1. Valid consumer implication

After the selected packet carries

```math
R_{j,Q}+N_{j,Q}+P_{j,Q}+V_{j,Q}=L_{j,Q},
\qquad
I_{j,Q}\text{ retained on the same carrier,}
\tag{SSCR.2}
```

the source-square/critical-density consumer theorem is:

```math
\boxed{
dA_{\rm sel}
\le
C\,G\,dy\,ds\,d\sigma+dR_{\rm legal}
\quad\text{and}\quad
\int G^2<\infty
\Longrightarrow
\text{endpoint UI / no terminal atom.}
}
\tag{SSCR.3}
```

or, for the critical-density version,

```math
\boxed{
dA_{\rm sel}
\le
C\,H_{\Sigma,W}\,dy\,ds\,d\sigma+dR_{\rm legal}
\quad\text{and}\quad
\int H_{\Sigma,W}<\infty
\Longrightarrow
\text{unweighted selected-carrier reserve.}
}
\tag{SSCR.4}
```

The existing supplement notes prove these implications.

## 2. Missing producer

The current Navier-Stokes inputs do not prove either same-carrier domination or
the unweighted budget.

Energy and physical local energy give radius-discounted control at heat scale:

```math
\int e^{-\sigma}A(\sigma)\,d\sigma<\infty,
\tag{SSCR.5}
```

not

```math
\int A(\sigma)\,d\sigma<\infty.
\tag{SSCR.6}
```

Physical CKN mass has the same defect:

```math
\sum_j r_j^2\,\mathcal C(Q_{r_j})<\infty
\quad\text{does not imply}\quad
\sum_j \mathcal C(Q_{r_j})<\infty.
\tag{SSCR.7}
```

Positive-part selection leaves the carrier-domination problem:

```math
\left[
\langle \Sigma W,W\rangle
\right]_+
\le
C\,G
\tag{SSCR.8}
```

or

```math
\left[
\langle \Sigma W,W\rangle
\right]_+
\le
C\,H_{\Sigma,W}
\tag{SSCR.9}
```

is useful only when \(G\) or \(H_{\Sigma,W}\) has the unweighted same-carrier
terminal budget.

## 3. Result

The source-square/CKN branch is not dead; it is a consumer branch.

The exact full-tuple reading is:

```math
\boxed{
\text{source-square / critical-density / CKN}
=
\text{valid endpoint consumer after full-tuple carrier identification and
unweighted budget production.}
}
\tag{SSCR.10}
```

It does not currently produce the gold reserve from installed inputs.

Thus this branch returns to the same frontier:

```math
\boxed{
\texttt{FourBodyTerminalTraceAC.A}
\quad\text{or}\quad
\texttt{StrictFourBodyNoWasteLyapunov.A}
\quad\text{or}\quad
\text{no-free Zeno/profile production.}
}
\tag{SSCR.11}
```
