# MPP Forward-Gold Square-Spreading Branch Closeout

Date: 2026-06-20

as a forward-gold theorem.

actual selected positive carrier.  The branch has no lower bookkeeping escape
hatch left.

## 1. The pulse that survives

The normalized square budget is defeated by the heat-scale shape

```math
q_+(t)=A{\bf 1}_{[-h,0]}(t),
\qquad
h=\lambda^{-2},
\qquad
A=\lambda^{1/2},
\tag{SSB.1}
```

for which

```math
\lambda\int q_+^2\,dt=1,
\qquad
\int q_+\,dt=\lambda^{-3/2}\to0.
\tag{SSB.2}
```

So the pulse has order-one normalized square cost and vanishing linear mass.
That is the exact gap between the old linear donor ledger and the square
selected participation budget.

## 2. What the new direct tests add

`SelectedSquarePolarSaturation.A` does not follow from linear
`SelectedPositivePolarSaturation.A`: equal signed mass can be spread over a
longer donor window and lose square size.

`SquareDonorNoSpreading.A` is not a consequence of the finite donor graph.  The
linear storage model

```math
B'(t)=q_-(t)-q_+(t),
\qquad
B(t)\ge0,
\qquad
B(-H)=B(0)=0
\tag{SSB.3}
```

allows \(q_-\) to build a small reservoir on \([-H,-h]\) and \(q_+\) to drain it
on \([-h,0]\).  With \(H=\lambda^{-1}\),

```math
\sup_tB(t)=\lambda^{-3/2}\to0,
\qquad
\lambda\int q_-^2\,dt\to0,
\qquad
\lambda\int q_+^2\,dt=1.
\tag{SSB.4}
```

`SquareStorageBalance.A` also cannot be obtained from that linear reservoir.
Any storage functional whose possible drop is controlled by \(\sup B\),
\(\operatorname{Var}B\), first-moment source mass, or physical packet energy has
only \(o(1)\) drop on `(SSB.1)`--`(SSB.4)`.

Thus the square storage object, if it exists, must already carry unweighted
critical-action size.
