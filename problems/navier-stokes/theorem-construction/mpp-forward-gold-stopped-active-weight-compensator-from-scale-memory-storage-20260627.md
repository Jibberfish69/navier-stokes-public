# Stopped active-weight compensator from scale-memory storage

## 1. What is still open

The dynamic-silent-source improvement has the right form:

```text
silent at one frozen time is allowed;
silent through the material clock is expensive.
```

The route has already narrowed that sentence in two ways.

First, persistent zero-cost silence does not have to vanish as a source.  It
may remain as inherited parent transport.  The only theorem-grade statement is
that, after the parent-predictable silent span is subtracted, a zero-cost
selected silent component has no fresh quotient.

Second, high active-weight reset tubes are conditionally paid once the reset is
a parent-announced first-exit derivative interval with bounded-overlap witness
slabs.  The harmonic weight then matches Cauchy--Schwarz exactly.

So the live half-tail is not static elliptic silence and not reset tube escape.
It is unpaid active-weight upcrossing in the root Hilbert geometry:

```math
\sum_\ell \|D_\ell\|^2<\infty,
\qquad
\sum_\ell H_\ell\|D_\ell\|^2=\infty,
\tag{1}
```

where the large weights are predictable only as envelopes unless their
upcrossings are counted by original material history.

## 2. The compensator theorem

For a stopped root \(P\), let \(\mathcal F_\tau^P\) be the parent/root stopped
history before descendant selected-tail readout.  For every admissible child
scale interval \(I\), write the active harmonic weight

```math
H_I(t)= {|I|^2\over \int_I w(\sigma,t)^{-1}\,d\sigma}.
\tag{2}
```

Let \(H_P^\ast\) be the least stopped parent-predictable majorant of all child
active weights admitted below \(P\):

```math
H_I\le H_P^\ast
\qquad\text{on each retained announced edge }e\subset P.
\tag{3}
```

This majorant is only useful if its new upcrossings are paid.  Write the
stopped Doob--Meyer/Bellman decomposition schematically as

```math
H_P^\ast=H_{P,0}+M_P^{wt}+A_P^{wt},
\tag{4}
```

where \(A_P^{wt}\) is the increasing predictable compensator that records newly
admitted active-weight upcrossings.

The next producer is:

```text
StoppedPredictableActiveWeightCompensator.A.
```

For every stopped parent \(P'\subseteq P\),

```math
\boxed{
{1\over \mathcal R(P')}
\left[
\int_{\operatorname{Hist}(P')}dA_{P'}^{wt}
+
\sum_{e\subset P'}
\int H_{e^-}(t)
\|D_e^{vis}+D_e^{sil}+D_e^{ex}\|_{\mathcal H_{\rm lift}}^2\,dt
\right]
\le
C_N(u_0)+{R_{\rm legal}(P')+Stop(P')\over \mathcal R(P')}.
}
\tag{5}
```

Here \(H_{e^-}\), the affine span \(\mathcal P_{e^-}\), and the projection

```math
D_e=(I-\Pi_{\mathcal P_{e^-}})\mathcal C_\theta[Z_e]
\tag{6}
```

are built from stopped parent/root history before scalar selected readout.

## 3. Storage form

The same theorem can be stated as a parent-known scale-memory storage.  Let

```math
G_P^{new}
=
\Pi_{\rm new}
\left(
[D_t,\mathcal L_A]w
+\partial_\sigma Z
+\operatorname{turnstile}_\sigma
+\operatorname{exchange}_\sigma
+\operatorname{covector}_\sigma
+\operatorname{frame}_\sigma
\right)
\tag{7}
```

be the fresh visible/silent/exchange generator after parent-predictable
transport has been removed.  The storage form asks for a nonnegative
parent-known storage \(M_P\) and original-history density
\(\Theta_P^{orig}\) such that

```math
dA_P^{wt}
+a_P\|G_P^{new}\|^2\,d\sigma dt
\le
-D_{\sigma,t}M_P
+\Theta_P^{orig}
+dStop_P
+dR_{\rm legal,P},
\tag{8}
```

with

```math
0\le M_P\le C_N(u_0)\mathcal R(P)+R_{\rm legal}(P)+Stop(P),
\tag{9}
```

and

```math
\int_{\operatorname{Hist}(P)}\Theta_P^{orig}
\le C_N(u_0)\mathcal R(P)+R_{\rm legal}(P)+Stop(P).
\tag{10}
```

Integrating `(8)` gives `(5)`.  This is the coercive version of

```text
OriginalScaleMemoryStorageCoercivity.A.
```

It is stronger than the natural interior energy balance
\(\langle w,\mathcal L_Aw\rangle\).  That balance gives signed pairings, not
the square/coercive estimate needed for the selected-critical active weight.

## 4. Why this is noncircular

The theorem may use only original stopped material history:

```text
parent-known weights and affine spans;
commutator, covector, frame, turnstile, and scale-derivative channels;
record/return payment for inherited predictable transport;
stopped full-exchange/reselection payment;
legal and stop losses.
```

It may also use the already separated identities:

```text
PrimitivePLSDriverToSignedCommutatorIdentity.A
StoppedFullExchangeActionCarleson.A
ZeroCostDynamicSilentFreshnessRigidity.A
NoFreeHighWeightTubeEscapeCharge.A
```

as long as those identities are themselves proved before descendant selected
readout.

It may not use:

```text
FullMaterialClockLedger.A
future selected-tail data
OriginalHistoryRoutedCurrentEnergyFinite.A via downstream full-clock finiteness
an arbitrary endpoint elliptic right inverse
interior self-energy not already controlled by the commutator storage
```

because each of those imports the selected-critical payment after the route is
supposed to have produced it.

## 5. Bad-profile test

If `(5)` fails, normalize a stopped family so that

```math
\int dA_P^{wt}
+
\sum_{e\subset P}\int H_{e^-}\|D_e\|^2=1,
\tag{11}
```

while all allowed original-history charges tend to zero.

The reset-tube escape is already excluded by the parent-announced derivative
Cauchy estimate plus bounded witness overlap.  A tight same-carrier zero-cost
dynamic silent profile is excluded after parent-predictable transport is
subtracted.  Therefore any remaining bad sequence must create active weights
that keep increasing without a corresponding \(dA_P^{wt}\) payment.

The compensator theorem kills exactly that last possibility: every new active
weight admitted to the common root Hilbert geometry must be an announced
first-crossing/upcrossing event paid by the same original-history generator
that produces the parent-subtracted current.

Without `(5)` or `(8)`, the proof can still have a parent-predictable envelope
and Bessel orthogonality, but the half-tail `(1)` survives.
