# Stopped adjoint nondegenerate mean and testing-defect boundary

## 1. Target

The previous note reduced the stopped \(Tb\) producer to two estimates. For each stopped packet \(P\subseteq S\), construct an adjoint testing function \(b_P\) satisfying

```math
|\langle b_P\rangle_P|\ge c,
\qquad
\|b_P\|_{L^2(P,\mathcal R)}^2\le C\mathcal R(P)+C R_{legal}(P),
\tag{1}
```

and

```math
\|T_S(b_P\nu^S)\|_{L^2(P,\mathcal R)}^2
\le C\mathcal R(P)+Def_{test}(P)+C R_{legal}(P),
\tag{2}
```

with

```math
\sum_{P\subseteq P_0}Def_{test}(P)
\le C\mathcal R(P_0)+C R_{legal}(P_0).
\tag{3}
```

If `(1)`--`(3)` hold, the stopped \(Tb\) theorem supplies the BMO carrier needed for selected log-amplification Carleson control.

## 2. Direct mean test

Let the natural adjoint test have the schematic form

```math
b_P=1+\mathcal A_P\Phi_P,
\qquad
\mathcal L_A^*\Phi_P=g_P.
```

Then

```math
\langle b_P\rangle_P
=1+\langle \mathcal A_P\Phi_P\rangle_P.
```

To prove accretivity, one needs

```math
|1+\langle \mathcal A_P\Phi_P\rangle_P|\ge c.
\tag{4}
```

But the adjoint equation alone gives no sign or smallness control on the mean correction. In particular, there is no formal obstruction to

```math
\langle \mathcal A_P\Phi_P\rangle_P\approx -1,
```

which destroys accretivity while leaving the adjoint equation solvable.

Therefore `StoppedAdjointNondegenerateMean.A` does not follow from adjoint solvability or elliptic energy alone.

## 3. Direct testing-defect test

The testing defect is

```math
Def_{test}(P)
:=
\left[\|T_S(b_P\nu^S)\|_{L^2(P,\mathcal R)}^2-C\mathcal R(P)-C R_{legal}(P)\right]_+.
```

Packetwise routed source control gives local size bounds for selected action, but it does not imply

```math
\sum_{P\subseteq P_0}Def_{test}(P)\lesssim \mathcal R(P_0).
```

The reason is structural: testing defects are not just source mass. They measure failure of cancellation of the stopped singular/martingale transform over every subpacket. A sequence of small local sources can still create large testing defects if their signs, means, or selector directions are badly arranged across the stopped tree.

Thus `MaterialAdjointTestingDefectCarleson.A` is not a consequence of local packet payment.

## 4. What would close it

The direct route closes if the stopped selector supplies an accretive reference state \(b_P^0\) before the adjoint correction. The needed structure is:

```math
b_P=b_P^0+h_P,
```

with

```math
|\langle b_P^0\rangle_P|\ge 2c,
\qquad
\|h_P\|_{L^2(P,\mathcal R)}^2\le c^2\mathcal R(P),
\tag{5}
```

or at least

```math
|\langle h_P\rangle_P|\le c.
\tag{6}
```

Then `(1)` follows.

For the testing defects, the required original-history measure is a square testing measure

```math
\mu_{test}(P)
:= Def_{test}(P)+Stop(P)+R_{legal}(P),
```

with Carleson packing

```math
\mu_{test}(P_0)\le C\mathcal R(P_0)+C R_{legal}(P_0).
\tag{7}
```

The proof must produce `(7)` from same-material geometry, pressure-visible/null/source-origin routing, exchange-service, reset/order-lock, and legal stopping ledgers.
