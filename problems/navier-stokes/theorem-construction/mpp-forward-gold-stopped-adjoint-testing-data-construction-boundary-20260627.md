# Stopped adjoint testing data: construction boundary

## 1. Target

The current live hinge is to construct stopped testing data for the stopped same-material transform \(T_S\). The desired local test estimate is

```math
\|T_S(b_P\nu^S)\|_{L^2(P,\mathcal R)}^2
\le C\mathcal R(P)+C R_{legal}(P),
\tag{1}
```

with accretivity

```math
|\langle b_P\rangle_P|\ge c>0,
\qquad
\|b_P\|_{L^2(P,\mathcal R)}^2\le C\mathcal R(P),
\tag{2}
```

and Carleson packing of testing defects over stopped packets.

If `(1)` and `(2)` hold, stopped \(T1/Tb\) theory gives the BMO carrier \(Z^S=T_S\nu^S\), hence the selected log-amplification Carleson estimate.

## 2. Natural construction attempt

For a stopped packet \(P\subseteq S\), construct \(b_P\) from a local adjoint material test. Schematically solve

```math
\mathcal L_{A}^{*}\Phi_P
=\mathbf 1_P-\langle \mathbf 1_P\rangle_S
```

or the corresponding stopped same-material pressure-Helmholtz--Leray / martingale adjoint equation. Then set

```math
b_P := 1+\nabla_A\Phi_P\cdot \eta_P
```

or, in martingale language, use the normalized adjoint testing function generated by the stopped selector on \(P\).

The intended mechanism is:

```math
\langle \nu^S,b_P\rangle\approx 0
```

by the adjoint equation and routed source cancellation, while Caccioppoli/energy estimates give

```math
\|T_S(b_P\nu^S)\|_{L^2(P,\mathcal R)}^2
\lesssim \mathcal E_{adj}(P)+R_{legal}(P).
```

## 3. What this would need

The construction closes if the adjoint tests satisfy a scale-invariant testing-energy bound:

```math
\mathcal E_{adj}(P)
\le C\mathcal R(P)+C R_{legal}(P)
\tag{3}
```

and if their bad packets pack Carleson:

```math
\sum_{P\subseteq P_0} Def_{adj}(P)
\le C\mathcal R(P_0)+C R_{legal}(P_0).
\tag{4}
```

This would produce the stopped testing data directly from the original same-material operator, not from the future selected tail.

## 4. Direct obstruction

The adjoint construction is not automatic. Solving the local adjoint equation can create tests whose energy depends on the same selected concentration being estimated. Without an independent accretive energy bound `(3)`, the test functions may be mathematically valid but not usable for a Carleson/BMO proof.

Similarly, accretivity `(2)` is not guaranteed by solving an adjoint equation. If the adjoint correction cancels the mean or concentrates near the selected source, the testing family fails the local \(Tb\) hypotheses.

Thus the proof does not close at the level of formal adjoint solvability.
