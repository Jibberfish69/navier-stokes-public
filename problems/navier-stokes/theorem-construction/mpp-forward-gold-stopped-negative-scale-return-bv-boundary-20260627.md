# Stopped negative scale-return charge: BV boundary

## 1. Target

The stopped-core payment uses the elementary identity

```math
\sum_k [P_{k+1}-P_k]_+
\le
\operatorname{osc}(P)
+
\sum_k [P_k-P_{k+1}]_+.
```

So positive fresh selected action is finite if the negative primitive returns are also charged:

```math
\sum_k [P_k-P_{k+1}]_+
\le
C\mathcal R_{return}(Q_0)+C R_{legal}(Q_0).
\tag{1}
```

This is `StoppedNegativeScaleReturnCharge.A`.

## 2. Bounded record is not enough

The record oscillation bound alone does not imply `(1)`. A bounded scalar sequence can oscillate infinitely:

```math
P_k=(-1)^k
```

has bounded oscillation but infinite total positive and negative variation over an infinite sequence.

Therefore `(1)` cannot follow from boundedness of the stopped primitive record alone.

## 3. What is needed

The negative primitive return must be a real stopped-material event, not just a scalar drop. There must be a pre-existing return/BV ledger such that

```math
[P_k-P_{k+1}]_+
\le
C\mathcal R^-_k+C R_{legal}(Q_k)
\tag{2}
```

and

```math
\sum_k \mathcal R^-_k
\le C(u_0).
\tag{3}
```

Equivalently, the stopped primitive record must have finite negative variation in original-data currency:

```math
\operatorname{Var}^-(P;\text{stopped core})
\le C(u_0)+R_{legal}.
\tag{4}
```

## 4. Candidate source of the charge

If \(P\) is generated by a stopped material primitive PLS equation, then schematically

```math
D_t P = \mathcal G_{prod}-\mathcal G_{ret}+Err,
```

where `G_prod` is positive production and `G_ret` is scale return / relaxation. Then

```math
[D_tP]_-
\le
\mathcal G_{ret}+Err.
```

A valid charge theorem would be

```math
\int_{I_{Q_0}}[D_tP]_-\,dt
\le
C\int_{I_{Q_0}}\mathcal G_{ret}\,dt+C R_{legal}(Q_0)
\le C(u_0)+C R_{legal}(Q_0).
\tag{5}
```

After discretization along the stopped laminar chain, `(5)` gives `(1)`.

## 5. Exact missing theorem

The needed theorem is

```text
StoppedPrimitivePLSNoFreeOscillation.A
```

or equivalently

```text
StoppedReturnBVFiniteFromOriginalData.A
```

Statement:

On a fixed stopped material core and fixed signed primitive channel, the negative variation of the primitive PLS record is finite in original-data return/service currency:

```math
\sum_k [P(Q_k)-P(Q_{k+1})]_+
\le
C\mathcal R_{return}(Q_0)+C R_{legal}(Q_0),
```

with `R_return` not defined as future selected action.

## 6. Result

`StoppedNegativeScaleReturnCharge.A` is not discharged by bounded record oscillation. It requires a genuine no-free-oscillation/BV theorem for the stopped primitive PLS record.

The fixed stopped-core branch is therefore conditionally closed except for this BV return theorem. The reset branch remains separate:
