# Strain Superheat Sharp Interpolation Test

Date: 2026-06-25

## 0. Object

This note keeps the same object as the live gold route: the original smooth
solution and its transported material annular history. The active shell energy
is \(e_j(t)\), and the remaining super-heat-rate residence is

```math
\mathcal R_{sh,N}(t)
=
\sum_j
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}(t)>\delta2^{2j}\}} .
\tag{SSI.1}
```

The full material rate is the coupled same-packet rate

```math
\Theta_j^{mat}
=
\Theta_j^{strain}
+\Theta_j^{press}
+\Theta_j^{coef}
+\Theta_j^{collar}.
\tag{SSI.2}
```

This test only sharpens the strain coordinate. It does not split pressure,
viscosity, incompressibility, velocity, or the transported collar away from
the full material packet.

## 1. Strain contribution

The earlier pressure test used the low-strain Bernstein bound

```math
\Theta_j^{strain}(t)
\lesssim
2^{3j/2}G(t),
\qquad
G(t):=\|\nabla u(t)\|_2 .
\tag{SSI.3}
```

Let

```math
D_j(t):=2^{2j}e_j(t),
\qquad
D(t):=\sum_jD_j(t)\sim \|\nabla u(t)\|_2^2,
\qquad
E(t):=\sum_je_j(t)\le E_0 .
\tag{SSI.4}
```

Since the superheat indicator is bounded by one, the strain contribution is
controlled by the full strain shell sum:

```math
\mathcal R_{sh}^{strain}(t)
\le
C\,G(t)\sum_j2^{3j/2}e_j(t).
\tag{SSI.5}
```

Now interpolate the shell sum between energy and enstrophy:

```math
\begin{aligned}
\sum_j2^{3j/2}e_j
&=
\sum_j
\left(2^{2j}e_j\right)^{3/4}e_j^{1/4} \\
&\le
\left(\sum_j2^{2j}e_j\right)^{3/4}
\left(\sum_je_j\right)^{1/4} \\
&\le
D(t)^{3/4}E_0^{1/4}.
\end{aligned}
\tag{SSI.6}
```

Combining `(SSI.5)` and `(SSI.6)`, and using \(G(t)=D(t)^{1/2}\), gives the
sharpened strain-superheat bound

```math
\boxed{
\mathcal R_{sh}^{strain}(t)
\le
C E_0^{1/4}D(t)^{5/4}.
}
\tag{SSI.7}
```

This improves the earlier sufficient clock \(D(t)^{3/2}\).

## 2. Why raw energy still does not close it

The energy inequality gives

```math
\int_0^{T_*}D(t)\,dt<\infty .
\tag{SSI.8}
```

It does not give

```math
\int_0^{T_*}D(t)^{5/4}\,dt<\infty .
\tag{SSI.9}
```

The classical scalar enstrophy envelope also does not force `(SSI.9)`.  The
model profile

```math
D_\alpha(t)=(T_*-t)^{-\alpha},
\qquad
{4\over5}\le \alpha<1,
\tag{SSI.10}
```

has

```math
D_\alpha\in L^1(0,T_*),
\qquad
D_\alpha^{5/4}\notin L^1(0,T_*).
\tag{SSI.11}
```

It is also compatible with the scalar inequality

```math
D_\alpha'(t)\le C D_\alpha(t)^3
\tag{SSI.12}
```

near \(T_*\), because \(D_\alpha'(t)\sim (T_*-t)^{-\alpha-1}\) and
\(D_\alpha(t)^3=(T_*-t)^{-3\alpha}\), with \(\alpha\ge1/2\).

Therefore raw dissipation plus the standard enstrophy ODE still does not
produce the strain-superheat residence.

## 3. Pressure/coefficient/collar remain coupled

The estimate above handles only the strain coordinate in `(SSI.2)`. The
pressure, coefficient, and transported collar coordinates remain generated by
the same material pressure-viscosity-incompressibility-velocity packet:

```math
\Theta_j^{press}
+\Theta_j^{coef}
+\Theta_j^{collar}.
\tag{SSI.13}
```

Those terms are not separate supplier problems. They are the same annular
stress/strain return history seen through pressure elliptic service,
coefficient motion, viscosity, incompressibility, and collar transport.

## 4. Result

The sharp same-packet strain statement is:

```math
\int_0^{T_*}\mathcal R_{sh}^{strain}(t)\,dt
\le
C E_0^{1/4}
\int_0^{T_*}D(t)^{5/4}\,dt .
\tag{SSI.14}
```

This is a stricter and more useful reduction than the older \(D^{3/2}\)
bound, but it is still continuation-strength information, not a consequence
of energy alone.  The remaining gold theorem is still finite full
super-heat-rate material residence of the same transported annular history:

```math
\int_0^{T_*}
\sum_j
\Theta_j^{mat}(t)e_j(t)
\mathbf 1_{\{\Theta_j^{mat}(t)>\delta2^{2j}\}}
\,dt
<\infty .
\tag{SSI.15}
```
