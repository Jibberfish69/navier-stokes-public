# Terminal Overlap No-Jump Direct Test

Date: 2026-06-22

## 0. Exact object

The order-lock overlap surface leaves the time/storage term

```math
\int
\min\{[n_\sigma]_+,[-\partial_\sigma M_\sigma]_+\}.
\tag{TON.1}
```

For a retained terminal heat-scale sequence, first form the same-test time
marginal of the native positive scalar:

```math
da_m(s)
:=
\left(
\int [n_m(s,y)]_+\,dy
\right)ds.
\tag{TON.1a}
```

Let \(d\gamma_m\) be the positive time/storage partner measure generated by the
same packet:

```math
d\gamma_m(s):=d(-M_m)^+(s),
\tag{TON.1b}
```

with all selector/legal pieces already removed or recorded in their own packet
channels.  Define the order-lock overlap using the common dominating measure

```math
d\lambda_m:=da_m+d\gamma_m.
\tag{TON.1c}
```

If

```math
A_m={da_m\over d\lambda_m},
\qquad
G_m={d\gamma_m\over d\lambda_m},
\tag{TON.1d}
```

then

```math
\boxed{
d\nu_m^{ol}:=\min\{A_m,G_m\}\,d\lambda_m .
}
\tag{TON.1e}
```

In the absolutely continuous case, this is exactly

```math
d\nu_m^{ol}(s)
=
\min\left\{
\int[n_m(s,y)]_+\,dy,
[-\partial_sM_m(s)]_+
\right\}ds .
\tag{TON.1f}
```

The theorem tested here is

```math
\boxed{
\texttt{TerminalOverlapNoJump.A:}
\qquad
\lim_{\theta\downarrow0}\limsup_m
\nu_m^{ol}((-\theta,0])=0.
}
\tag{TON.2}
```

This is narrower than full endpoint no-jump.  It does not ask that every
storage drop vanish near the terminal face.  It asks that the storage drop not
overlap the selected native positive source in a terminal atom.

## 1. Exact consumers

### Hardy consumer

If there are \(\alpha\in(0,1)\) and \(C<\infty\) such that

```math
\sup_m
\int_{-1}^{0}(-s)^{-\alpha}\,d\nu_m^{ol}(s)
\le C,
\tag{TON.3}
```

then

```math
\nu_m^{ol}((-\theta,0])
\le
\theta^\alpha
\int_{-\theta}^{0}(-s)^{-\alpha}\,d\nu_m^{ol}(s)
\le
C\theta^\alpha.
\tag{TON.4}
```

Hence `(TON.2)` follows.

### Super-\(L^1\) density consumer

If

```math
d\nu_m^{ol}(s)=\rho_m^{ol}(s)\,ds
\tag{TON.5}
```

and for some \(q>1\),

```math
\sup_m\|\rho_m^{ol}\|_{L_s^q(-1,0)}<\infty,
\tag{TON.6}
```

then Hölder gives

```math
\nu_m^{ol}((-\theta,0])
\le
\|\rho_m^{ol}\|_{L_s^q}
\theta^{1-1/q},
\tag{TON.7}
```

so `(TON.2)` follows.

### Orlicz consumer

More generally, de la Vallee-Poussin uniform integrability of the densities
\(\rho_m^{ol}\) gives `(TON.2)`.  This is exactly the same endpoint-uniform-
integrability requirement, stated without choosing a power.

## 2. Exact pulse obstruction

The terminal heat-scale overlap pulse is the scalar time-marginal model

```math

a\,\tau_m^{-1}\mathbf 1_{(-\tau_m,0]}(s),
\qquad
\tau_m\downarrow0,
\tag{TON.8}
```

Then

```math
\nu_m^{ol}((-\theta,0])
=a
\quad
\text{whenever }\theta\ge\tau_m,
\tag{TON.9}
```

so `(TON.2)` fails.

The same pulse has uniformly finite \(L_s^1\) mass:

```math
\int_{-1}^{0}d\nu_m^{ol}=a.
\tag{TON.10}
```

It also has the exact Hardy blow-up

```math
\int_{-1}^{0}(-s)^{-\alpha}\,d\nu_m^{ol}(s)
=
{a\over 1-\alpha}\tau_m^{-\alpha}
\to\infty.
\tag{TON.11}
```

and for every \(q>1\),

```math
\|\rho_m^{ol}\|_{L_s^q}^q
=
a^q\tau_m^{1-q}
\to\infty.
\tag{TON.12}
```

Thus finite isolated \(L_s^1\) overlap mass, bounded storage, and visibility of
the full packet do not exclude the terminal overlap atom.
