# Terminal Same-Packet Record Survival: Material-Clock Direct Attempt

Date: 2026-06-22

## 0. Target

The current forward-gold wall is

```math
OriginalSmoothData
\Longrightarrow
\text{no loss of the terminal same-packet participation record.}
\tag{MCR.1}
```

This note rewrites that wall in the material language of the same packet.  The
object being preserved is still the pressure-viscosity-incompressibility-
velocity packet.  Stress/strain is the material record of how that packet
deforms; it is not an added fifth component.

## 1. Material same-packet record

Let \(X(a,t)\) be the flow map on the selected material packet:

```math
\partial_tX(a,t)=u(X(a,t),t),
\qquad
X(a,t_0)=a.
\tag{MCR.2}
```

Set

```math
F(a,t)=D_aX(a,t),
\qquad
A(a,t)=F(a,t)^{-1}.
\tag{MCR.3}
```

Incompressibility gives

```math
\det F(a,t)=1.
\tag{MCR.4}
```

The material frame evolves by

```math
\partial_tF
=
\nabla u(X(a,t),t)F.
\tag{MCR.5}
```

For the base annular geometry, the metric clock is sharper.  Let

```math
S={1\over2}\left(\nabla u+\nabla u^\top\right),
\qquad
C=F^\top F.
\tag{MCR.6}
```

Then

```math
\partial_tC
=
2F^\top S(X,t)F.
\tag{MCR.7}
```

The antisymmetric rotation part cancels from the metric.  It can move the
frame, but it does not stretch the material annulus.

## 2. Survival criterion

If the same-carrier strain clock is finite,

```math
\int_{t_0}^{T_*}
\|S(t)\|_{L^\infty(X(A_\sharp,t))}\,dt
<\infty,
\tag{MCR.8}
```

then Gronwall gives bounded distortion on the material collar:

```math
\sup_{t<T_*}
\left(
\|F(t)\|_{L^\infty(A_\sharp)}
+
\|F(t)^{-1}\|_{L^\infty(A_\sharp)}
\right)
<\infty.
\tag{MCR.9}
```

Consequently transported collars, transported cutoffs, and the material
annular atlas do not disappear at the endpoint.  For example, if
\(\eta(t,x)=\zeta(X^{-1}(x,t))\), then

```math
\nabla_x\eta(t,X(a,t))
=
F(a,t)^{-T}\nabla_a\zeta(a),
\tag{MCR.10}
```

so bounded \(F^{-1}\) keeps the collar geometry under control.

Full same-packet record survival also requires the velocity-pressure finite
tower to remain controlled in this material frame.  A compact statement is:

```math
\sup_{t<T_*}
\mathcal P_{N,Q}^{mat}(u(t),p(t),X(t),F(t))
<\infty .
\tag{MCR.11}
```

This is the material version of \(Part_{N,Q}\).

## 3. Why current energy inputs do not prove the clock

The Lagrangian deformation test already gives the heat-scale obstruction.  For
a selected packet of radius \(r\),

```math
u_r(t,x)
=
r^{-1}U(r^{-2}t,r^{-1}x),
\qquad
\nabla u_r(t,x)
=
r^{-2}\nabla U(r^{-2}t,r^{-1}x).
\tag{MCR.12}
```

Over one heat window of length \(r^2\),

```math
\int_{I_r}
\|S(u_r)(t)\|_{L^\infty(B_r)}\,dt
\simeq
1.
\tag{MCR.13}
```

So one heat-scale pulse can create order-one material deformation.

The physical dissipation on the same window is radius-weighted:

```math
\int_{I_r}\int_{B_r}|\nabla u_r|^2\,dx\,dt
=
r
\int_{-1}^{0}\int_{B_1}|\nabla U|^2\,dy\,ds.
\tag{MCR.14}
```

Therefore a terminal dyadic stack can have finite physical dissipation while
the material strain-metric clock sees order-one events at infinitely many
scales.  Energy does not prove `(MCR.6)`.

## 4. The collar coefficient correction

The localized stress-work algebra may display the term

```math
4\nu\int |V|^2|\nabla\eta|^2.
\tag{MCR.15}
```

That \(4\) is only the Young-envelope constant from the cutoff identity
\(\phi=\eta^2\).  The packet-level object is the viscous collar channel

```math
\nu |V|^2|\nabla\eta|^2,
\tag{MCR.16}
```

with constants absorbed.  This collar channel stays inside the same
pressure-viscosity-incompressibility-velocity participation packet; it is not
a separate viscosity-only supplier.

In material coordinates, `(MCR.14)` is controlled by the same deformation clock:

```math
\nu\int |V(t,y)|^2|\nabla_y\eta(t,y)|^2\,dy
\le
C\nu
\|F(t)^{-1}\|_{L^\infty(A_\sharp)}^2
\int_{A_\sharp}|V(t,X(a,t))|^2\,da.
\tag{MCR.17}
```

Thus collar survival is not an independent proof route.  It is one visible
piece of the same material packet record.
