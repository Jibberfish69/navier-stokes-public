# Terminal WKB high-factor admission fork

## 1. Object

The terminal-frequency fork left one horn after the nonvanishing WKB moment:
\[
  \phi D^3|K|\to0
  \quad\hbox{or intermittent service}.
  \tag{THA.1}
\]

That horn was routed to the high-factor source / no-free-upcascade branch. This
note checks what that routing means after the selected source-graph rules are
enforced.

The answer is:
\[
  \hbox{high-factor visibility}
  \neq
  \hbox{selected-record payment}.
  \tag{THA.2}
\]

A high-frequency source can be used in the Gold record only after it is admitted
as one of the retained selected-action currencies.

## 2. The high-factor estimate is not the payer

After low-low removal, the terminal source note gives
\[
  N
  =
  N_{\le K,\le K}
  +
  N_{\rm hi}^{(K)},
  \tag{THA.3}
\]
and any surviving terminal positive source atom must place fixed mass in
\[
  N_{\rm hi}^{(K)}
  =
  -\mathbb P\nabla\cdot
  \left(
    v_{\le K}\otimes v_{>K}
    +v_{>K}\otimes v_{\le K}
    +v_{>K}\otimes v_{>K}
  \right).
  \tag{THA.4}
\]

The installed high-factor estimate is
\[
\begin{aligned}
\int_{-\theta}^{0}
\|N_{\rm hi}^{(K)}(s)\|_{\dot H^{-1}}\,ds
&\le
2b_K E\,\theta\\
&\quad+
C_{\rm GN}E^{1/4}\theta^{1/4}
\left(
\int_{-\theta}^{0}
\|\nabla v_{>K}(s)\|_2^2\,ds
\right)^{3/4}.
\end{aligned}
\tag{THA.5}
\]

This is negative-Sobolev tail/enstrophy visibility. It is not a selected
positive carrier bound. The countermodel already proves the functional
separation:
\[
  \|N_n\|_{W^{-1,5/3}}\to0
  \quad\hbox{while}\quad
  \int[-N_n\cdot e_2]_+\,dx
  =2(2\pi)^2.
  \tag{THA.6}
\]

Thus the terminal-WKB high-factor horn cannot be closed by saying that a
high-frequency factor is visible in a negative norm.

## 3. Admission fork

Once the high-factor source is claimed as retained selected action, the
selected-action currency rule applies before positive readout.

There are three cases.

### Case A: bounded original-packet admission

The selected source functional has a bounded Riesz representative in the
original material stress history:
\[
  \Lambda_Q(G)
  =
  \langle G,A_Q\rangle_{\mathfrak H_P},
  \qquad
  \|A_Q\|_{\mathfrak H_P}\le C_N.
  \tag{THA.7}
\]

Then the installed bounded channel applies. Fresh directions Bessel-pack,
exact inherited reuse is parent current, changed inherited reuse is reset /
stop / legal / selector motion, and fast frequency transit is handled by the
stopped first-exit threaded packing machinery inside that admitted branch.

In this case the terminal-WKB high-factor source is not a new reservoir. It is
ordinary admitted selected action in the bounded original-packet channel.

### Case B: scale-native zoom admission

The natural selected unit is unit-size only after rescaling to a child packet of
radius \(r\). Pulling the unit test back to the original stress history gives
\[
  \|F_r\|_{\mathfrak H}^2
  =
  r^{-1}\|A_r\|_{L^2(dy\,ds)}^2.
  \tag{THA.8}
\]

So a unit rescaled read has original-packet size \(r^{-1/2}\). This is not
paid by bounded-Riesz Bessel packing. It is exactly the scale-native active
participation branch:
\[
  \texttt{NativeBirthChargePacking.A}
  \quad/\quad
  \texttt{SelectedGeneratorStorageCoercivity.A}
  \quad/\quad
  \texttt{PositiveCriticalTransferBound.A}.
  \tag{THA.9}
\]

In this case the terminal-WKB high-factor horn lands on the native-reserve
hinge, not on a separate raw no-free-upcascade theorem.

### Case C: no selected-record admission

If the high-frequency WKB source is neither a bounded original-packet selected
read nor a scale-native retained birth with a stated native-reserve account,
then it has not entered the Gold selected record. It is construction/exclusion,
carrier admission failure, stop/legal/reselection/selector drift, or an
external ansatz. It cannot be counted as retained supply.

## 4. Consequence for the terminal-frequency fork

The terminal-frequency horn is now:
\[
  \lambda\to\infty
  \Rightarrow
  \begin{cases}
    \phi D^3|K|\not\to0:
      &\text{same-solution WKB witness admission, then Field/readout},\\
    \phi D^3|K|\to0\text{ or intermittent, bounded read}:
      &\text{bounded-Riesz selected channel},\\
    \phi D^3|K|\to0\text{ or intermittent, scale-native read}:
      &\text{native-reserve / positive-critical-transfer hinge},\\
    \text{no selected-record admission}:
      &\text{construction/exclusion or admission failure}.
  \end{cases}
  \tag{THA.10}
\]

So the high-factor horn is not an independent overlap-bath reservoir. It is a
source-record fork.

## 5. Four-sentence result

The high-factor estimate sees the terminal-frequency horn only in a negative
tail/enstrophy currency, and that currency does not dominate the selected
positive carrier. A terminal-WKB high-frequency source can count only after
selected-record admission. Bounded original-packet admission is already routed
through the Riesz/Bessel/first-exit packing channel; scale-native zoom
admission is exactly the native-reserve / positive-critical-transfer hinge.
Anything outside those admissions is construction/exclusion or selected-record
failure, not retained supply.
