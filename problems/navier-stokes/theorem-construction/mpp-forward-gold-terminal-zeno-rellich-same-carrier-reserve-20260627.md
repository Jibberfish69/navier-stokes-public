# Terminal Zeno Rellich Same-Carrier Reserve

## Status

This note does not close the Gold route. It records a better proof mechanism for
the current open bill.

The current first gate is not broad invisible-child observability. The installed
finite reductions already push a retained fresh positive mismatch to the terminal
Zeno visible-readout branch. The unpaid line is:

```text
TerminalZenoVisibleReadoutPayment.A
```

The better target is:

```text
TerminalZenoRellichSameCarrierReserve.A
```

Plainly: use the collar Rellich/Pohozaev identity to force a retained selected
terminal Zeno pulse to pay as an unweighted reserve on the same selected carrier.

## 1. Why this is sharper than the old invisible-child attack

The old bad object was:

```math
A_\infty>0,
\qquad
\mathsf S_\infty U_\infty=0.
\tag{TZR.1}
```

It says that selected critical-strain action remains, while the parent
pressure-Hodge / Schur boundary defect sees nothing.

That object is still morally right, but it is too large for the current relay
state. The local invisible-child edge has already been reduced; the open survivor
is the same-fluid terminal Zeno donor chain after legal, reselection, finite
donor, pair-weight, entrance, and signed-partner charges have been removed.

So the active bad object should be the terminal version:

```math
\mu_m(ds)=a_m(s)\,ds,
\qquad
a_m(s)\ge0,
\qquad
\mu_m([-1,0])\ge m_0>0,
\tag{TZR.2}
```

with no endpoint, legal, storage, profile, or CM-service payment, and with the
same selected carrier still unpaid.

The terminal source normal form is:

```math
a_{\tau}(s)=M\tau^{-1}{\bf 1}_{(-\tau,0]}(s),
\qquad
\tau\downarrow0.
\tag{TZR.3}
```

Its mass is fixed, but its unweighted square bill is:

```math
\int_{-1}^{0}a_{\tau}(s)^2\,ds=M^2\tau^{-1}.
\tag{TZR.4}
```

Thus a reserve theorem does not need to see every possible invisible child. It
only needs to see that this retained terminal pulse cannot have zero Schur
payment and zero same-carrier square/no-waste payment at the same time.

## 2. The proposed theorem

State the next theorem as:

```text
TerminalZenoRellichSameCarrierReserve.A
```

Let \(W_m\) be the pressure-Hodge collar field generated by the selected
terminal Zeno remainder:

```math
\mathcal L_{A_m}W_m
=
\Pi_{\mathrm{PH}}(\mu_{\Sigma,m}^{\mathrm{sel}})
\quad\text{on }A_{Q_m}.
\tag{TZR.5}
```

Assume the finite mismatch evacuation has already removed or charged the legal,
reselection, finite donor, pair-weight, entrance, collar, endpoint-storage,
profile, and CM-service exits. If the boundary Schur payment vanishes in the
terminal limit, then the selected terminal readout must be paid by an unweighted
same-carrier reserve:

```math
\boxed{
\int_{-1}^{0}a_m(s)^2\,ds
\le
C\,\mathsf S_m(U_m,U_m)
+C\,R_{\mathrm{legal}}(Q_m)
+o_m(1).
}
\tag{TZR.6}
```

In the invisible terminal branch, \(\mathsf S_m(U_m,U_m)\to0\) and the charged
remainders are already removed. Then `(TZR.6)` forbids the terminal pulse
`(TZR.3)` unless the branch has landed in an authorized consumer.

## 3. Rellich identity that should produce it

Use a material-collar vector field \(X_m\) pointing from child to parent scale.
The schematic Rellich identity for `(TZR.5)` is:

```math
\int_{A_{Q_m}}
\mathcal Q_{A_m,X_m}(\nabla_{A_m}W_m,\nabla_{A_m}W_m)
+
\int_{A_{Q_m}}
(X_m\cdot\nabla_{A_m}W_m)\,
\Pi_{\mathrm{PH}}(\mu_{\Sigma,m}^{\mathrm{sel}})
=
\int_{\partial A_{Q_m}}
\mathcal B_{A_m,X_m}(W_m,\partial_{\nu_A}W_m)
+R_{\mathrm{legal}}(Q_m).
\tag{TZR.7}
```

The boundary term is the Schur / pressure-Hodge trace payment plus charged collar
terms. After the relay reductions, the dangerous case is exactly the case where
that right side is zero or already legal.

The new sign lemma needed inside `(TZR.7)` is:

```text
SelectedRellichBulkPositivity.A
```

It should say:

```math
\int_{A_{Q_m}}
\mathcal Q_{A_m,X_m}(\nabla_{A_m}W_m,\nabla_{A_m}W_m)
+
\int_{A_{Q_m}}
(X_m\cdot\nabla_{A_m}W_m)\,
\Pi_{\mathrm{PH}}(\mu_{\Sigma,m}^{\mathrm{sel}})
\ge
c\int_{-1}^{0}a_m(s)^2\,ds
-R_{\mathrm{polar}}(Q_m)
-o_m(1).
\tag{TZR.8}
```

If the polar remainder \(R_{\mathrm{polar}}\) is legal or already charged, then
`(TZR.7)` and `(TZR.8)` prove `(TZR.6)`.

## 4. What happens if the sign lemma fails

Failure of `(TZR.8)` is not a reason to return to broad route search. It names a
smaller obstruction:

```text
SelectedRellichPolarNullPacket.A
```

That obstruction says that the selected pressure-Hodge source pairs trivially
with the material Rellich multiplier while still carrying selected terminal mass.
This is exactly the situation where the next mathematical currency should be
adjoint polarization or microlocal defect measure, not another source-square
estimate.

The fallback order is:

```text
1. SelectedRellichBulkPositivity.A
2. SelectedAdjointPolarizationNoCancellation.A on the polar-null packet
3. NoInvisibleMicrolocalSelectedMeasure.A on the remaining symbol-null packet
```

This order keeps all three attacks on the same object. They are not parallel
route names anymore; they are successive pressure tests for the same terminal
Zeno survivor.

## Verdict

The better idea is not to keep attacking invisible-child observability in its
widest form. The better idea is to use the Rellich/Pohozaev selected-sign
identity on the terminal Zeno visible-readout survivor. That targets the exact
unpaid line: a retained selected terminal atom with no trace payment must either
produce an unweighted same-carrier reserve, expose a polar-null packet for the
adjoint/microlocal fallback, or land in the already named CM-service consumer
after same-witness admission.
