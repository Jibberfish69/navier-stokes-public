# Uniform Same-Material Terminal Clock Direct Attempt

Date: 2026-06-22

## 0. Target

The theorem isolated by the endpoint/Body-IV unification note is:

```math
\boxed{
\texttt{UniformSameMaterialTerminalClock.A}.
}
\tag{USC.1}
```

On each retained heat-scale material packet, let

```math
d\mathfrak C_{N,m}
=
\widehat\rho_{A,m}(s)\,ds
+
d[\log(1+\mathcal P_{N,m}^{mat})]_+
+
dK_{\rm iface,m}^+
+
dK_{\rm sel/collar,m}^+ .
\tag{USC.2}
```

The gold endpoint version is the uniform terminal-tail statement

```math
\boxed{
\lim_{\theta\downarrow0}\limsup_m
\mathfrak C_{N,m}((-\theta,0])
=0.
}
\tag{USC.3}
```

The log-scale recurrence version is that infinitely many retained bad
heat-scale packets cannot carry a fixed positive amount of \(d\mathfrak C_N\)
while the four-body packet has finite total activity.

The point of this note is to test whether `(USC.3)` is produced by the already
installed pieces.

## 1. Fixed annulus absolute continuity does not produce it

For one fixed retained material annulus,

```math
\rho_A(t)
=
\int_{\partial A(t)}|u\cdot T(u,p)n|\,dA
+
2\nu\int_{A(t)}|S(u)|^2\,dx
\tag{USC.4}
```

is an \(L^1\) time density, so its terminal tail vanishes.

Under heat-scale normalization,

```math
\int_{T-r^2}^{T}\rho_{A_r}(t)\,dt
=
r
\int_{-1}^{0}\widehat\rho_{A_r}(s)\,ds .
\tag{USC.5}
```

Thus fixed-annulus absolute continuity controls only the radius-discounted
physical tail.  It does not control `(USC.3)`.

## 2. Finite nested-chain telescoping does not produce it

For every finite nested material chain,

```math
W_0(I)
=
W_M(I)
-
\sum_{j=1}^{M}\left(E_{A_j}(b)-E_{A_j}(a)\right)
-
\sum_{j=1}^{M}D_{A_j}(I).
\tag{USC.6}
```

So finite delayed annular return is paid inside the same material packet.

For an infinite heat-scale chain, each scale may have physical cost \(O(r_j)\)
and normalized cost \(O(1)\).  Hence

```math
\sum_j r_j\widehat M_j<\infty
\quad\not\Longrightarrow\quad
\sum_j\widehat M_j<\infty .
\tag{USC.7}
```

Finite-chain telescoping is exact, but it does not produce the unweighted
terminal clock.

## 3. Material log-growth channel identity is conditional

The material log-growth identity proves, on a fixed transported annular atlas,

```math
d[\log(1+\mathcal P_N^{mat})]_+
\le
C\,dA_{4B,N}^{ann}
\tag{USC.8}
```

only when \(A_{4B,N}^{ann}\) is the full tower-level same-carrier activity
generated by the material equations:

```math
dA_{4B,N}^{ann}
=
d\mathcal A_N^{metric}
+d\mathcal A_N^{coeff}
+d\mathcal A_N^{comm}
+d\mathcal A_N^{press}
+d\mathcal A_N^{visc/collar}
+d\mathcal A_N^{geom}
+d\mathcal A_N^{rad}
+d\mathcal A_N^{selector/collar}
+d\mathcal A_N^{exchange}.
\tag{USC.9}
```

This is not a lower-order annular stress-work measure.  It is the tower-level
four-coordinate packet.  Therefore `(USC.8)` is useful only after the
simultaneous four-body loop is proved for that same object.

## 4. The kernel theorem does not produce it

The installed kernel theorem gives

```math
\ker\mathcal L_{4B,N}=\mathcal G.
\tag{USC.10}
```

So zero full loss is Galilean/affine-pressure gauge and selected singular
activity vanishes.

On the retained compact quotient this gives finite-time frozen observability.
The already installed no-return test shows why that is not enough: zero kernel
plus finite-time observability does not imply dissipative no-return, and a
positive endpoint term remains in the Gramian route.

Therefore the kernel theorem supplies the zero-loss rigidity check for the
clock, but not the clock itself.

## 5. Exact direct theorem

The direct gold theorem must be the same-material coercive identity

```math
\boxed{
d\mathfrak L_{4B,N}
+
c\,d\mathfrak C_N
+
d\mathcal L_{4B,N}
\le
dR_{4B,N},
}
\tag{USC.11}
```

where \(dR_{4B,N}\) is summable with the endpoint modulus required by the
terminal no-jump step.

Expanded, `(USC.11)` means:

```math
\boxed{
d\mathfrak L_{4B,N}
+
c\,\widehat\rho_A(s)\,ds
+
c\,d[\log(1+\mathcal P_N^{mat})]_+
+
c\,dK_{\rm iface}^+
+
c\,dK_{\rm sel/collar}^+
+
d\mathcal L_{4B,N}
\le
dR_{4B,N}.
}
\tag{USC.12}
```

This is not an additional route after the four-body solution.  It is the
four-body solution written with the endpoint/Body-IV clock included as part of
the nonnegative same-packet loss.

If `(USC.11)` is installed and \(\mathfrak L_{4B,N}\) is bounded below, then
the retained branch gives finite unweighted same-material terminal clock.  The
kernel theorem then removes the zero-loss branch as harmless gauge.
