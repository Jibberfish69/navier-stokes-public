# Upgraded Four-Body Current Frontier

Date: 2026-06-21

## 0. Aim

The upgraded four-body program is now best read as one coupled balance loop:

```math
\text{tower/scale}
\to
\text{participation}
\to
\text{compactness/no-loss}
\to
\text{gradient/geometry}
\to
\text{tower/scale}.
\tag{4BF.1}
```

The individual body normal forms are installed.  The loop is not closed.

The exact frontier is:

```math
\boxed{
\text{strict same-carrier four-body cycle payment}
}
\tag{4BF.2}
```

or

```math
\boxed{
\text{rigidity of every lossless four-body cycle.}
}
\tag{4BF.3}
```

This note consolidates the proof state so the old four-body idea is not
flattened into one body, one estimate, or one diagnostic defect.

## 1. Body I gives tower radius-spend, not selected-carrier domination

Body I has the exact normal form

```math
\boxed{
dL_S+dD_S^{\rm rad}=dJ_{SQ}.
}
\tag{4BF.4}
```

Here \(D_S^{\rm rad}\ge0\) is the radius-spend measure generated by moving
factorial/Gevrey radii:

```math
D_S^{\rm rad}
=
\sum_{(m,\alpha)}
\left(
-m{\tau'\over\tau}
-|\alpha|{\rho'\over\rho}
\right)
w_{m,\alpha}E_{m,\alpha}.
\tag{4BF.5}
```

The factorial weights remove the mixed binomial obstruction:

```math
{\tau^m\rho^{|\alpha|}\over m!\,\alpha!}
{m\choose a}{\alpha\choose\beta}
=
{\tau^a\rho^{|\beta|}\over a!\,\beta!}
{\tau^{m-a}\rho^{|\alpha-\beta|}
\over (m-a)!\,(\alpha-\beta)!}.
\tag{4BF.6}
```

Thus Body I supplies exact tower bookkeeping and a real nonnegative
radius-spend term.  It does not prove

```math
\boxed{
dA_{\rm sel}\le C\,dD_S^{\rm rad}+C\,dR_S.
}
\tag{4BF.7}
```

That is a same-carrier domination theorem still missing.

## 2. Body II gives signed participation, not positive payment

Body II has the exact local participation form

```math
\boxed{
dM_Q+dD_Q=dJ_Q,
\qquad
dD_Q\ge0.
}
\tag{4BF.8}
```

The current \(J_Q\) is signed.  A selected positive carrier formed before
signed summation obeys

```math
dA_{\mathcal S}
\le
dJ_{\mathcal S}^-
+
dD_{\mathcal S}
+
(dM_{\mathcal S})^+
+
dN_{\rm ret}
+
dR_{\rm legal}
+
dN_{\rm miss}.
\tag{4BF.9}
```

So Body II pays selected positive activity only through retained negative
current, true loss, storage jump, retained negative local partner, legal
residual, or the explicit selector defect \(dN_{\rm miss}\).

The missing Body-II production theorem is:

```math
\boxed{
dN_{\rm miss}=0
\quad\text{or}\quad
dN_{\rm miss}\text{ is legally charged.}
}
\tag{4BF.10}
```

This is the finite-packet form of terminal signed saturation / source-weighted
polar saturation.

## 3. Body III gives weak relay, not no-loss identification

Body III has the exact relay form:

```math
dL_n+dD_n+dA_n+dJ_n
\le
d\widetilde J_n+dR_n
\quad
\Longrightarrow
\quad
dL_*+dD_*+dA_*+dJ_*
\le
d\widetilde J_*+dR_*.
\tag{4BF.11}
```

This is weak packet compactness.  The no-loss theorem is stronger:

```math
\boxed{
\mathcal P_*=\mathcal P[U,P].
}
\tag{4BF.12}
```

Failure of `(4BF.12)` is the Body-III relay defect

```math
dK_C^+
=
\left(
dK_{\widetilde J}
+
dK_R
-
dK_L
-
dK_D
-
dK_A
-
dK_J
\right)^+.
\tag{4BF.13}
```

So Body III closes only if

```math
\boxed{
dK_C^+=0
\quad\text{or}\quad
dK_C^+\text{ is a charged no-loss defect.}
}
\tag{4BF.14}
```

The selected-carrier tightness defect is now part of this same Body-III
failure.  If \(\mu_n^A\) is the nonnegative selected carrier measure, define

```math
K_{\rm tight}^A
:=
\lim_{j\to\infty}\limsup_{n\to\infty}
\mu_n^A(C\setminus C_j).
\tag{4BF.14a}
```

Then the compactness estimate reads

```math
\limsup_{n\to\infty}A_{\rm sel}(X_n)
\le
A_{\rm ret}(X)
+
K_C^+
+
\limsup_n(K_{{\rm sel},n}+R_{{\rm legal},n}),
\tag{4BF.14b}
```

with \(K_{\rm tight}^A\) included in \(K_C^+\).  Hence non-tight selected
carrier mass is lost positive carrier for Body III, and a lossless cycle with
\(K_C^+=0\) forces tightness.

The interior selected-carrier identification is now equally explicit.  On a
fixed retained selected carrier,

```math
\sum_{P\in\mathcal S}
\|h_{n,P}-h_P[U,\Pi]\|_{L^1(K\times P)}
\to0
\tag{4BF.14c}
```

implies

```math
\|\mu_n^A-\mu^A[U,\Pi]\|_{\rm TV}\to0.
\tag{4BF.14d}
```

If `(4BF.14c)` fails, the mismatch is the interior selected-carrier component
of \(K_C^+\).  Thus Body III now has two exact selected-carrier clauses:
escaped mass is \(K_{\rm tight}^A\), and compact interior density/product/
pressure mismatch is \(K_{C,A}^{\rm int,+}\).

## 4. Body IV gives the geometry return arrow, not the unweighted clock

Body IV has the exact deformation-gradient equations:

```math
\partial_tF=(\nabla u)(X(a,t),t)F,
\qquad
\det F=1,
\tag{4BF.15}
```

and, for \(A=F^{-1}\), \(G=AA^\top\),

```math
\partial_tG
=
-2A\,S(X(a,t),t)\,A^\top.
\tag{4BF.16}
```

The same-carrier strain clock

```math
\Gamma_{A_0}(t_0,t)
=
\int_{t_0}^{t}
\|S(X(\cdot,\tau),\tau)\|_{L^\infty(A_0)}
\,d\tau
\tag{4BF.17}
```

keeps the pulled-back metric uniformly elliptic:

```math
e^{-2\Gamma_{A_0}}|\zeta|^2
\le
\zeta^\top G(a,t)\zeta
\le
e^{2\Gamma_{A_0}}|\zeta|^2.
\tag{4BF.18}
```

Thus Body IV can recertify Body I if the same-carrier deformation clock and
coefficient geometry remain controlled.

The missing Body-IV production theorem is the unweighted clock/action bound:

```math
\boxed{
\int_{\sigma_0}^{\infty}
A_{\rm strain}(\sigma)\,d\sigma<\infty
}
\tag{4BF.19}
```

or a charged geometry defect when `(4BF.19)` fails.

## 5. Same-carrier atom accounting is already abstractly solved

If the four body inequalities have the oriented same-carrier form

```math
dL_i+dD_i+c_i\,dA_i+dJ_i
\le
dJ_{i-1}+dR_i,
\tag{4BF.20}
```

then summing over the cycle gives

```math
\boxed{
dL_{4B}+dD_{4B}+dA_{4B}
\le
dR_{4B}.
}
\tag{4BF.21}
```

Consequently,

```math
\boxed{
\int_{\sigma_0}^{\infty}A_{4B}(\sigma)\,d\sigma
\le
L_{4B}(\sigma_0)-\inf L_{4B}
+
R_{4B}((\sigma_0,\infty)).
}
\tag{4BF.22}
```

This is the desired unweighted log-scale reserve.

The abstract accounting is not the open part.  The open part is producing
`(4BF.20)` from the actual Navier-Stokes bodies on the same selected carrier.

\quad
