## 1. First-Pulse Threshold Setup

Let the full-adjoint response mass on a terminal tile be:

```math
M_{full}(T,t)
:=
|\langle Z(t),\Chi_T^{full}(t)\rangle|^2.
\tag{FSP.1}
```

For a fixed response threshold `mu>0`, define the first response pulse time
`t_*` by:

```math
\sup_T M_{full}(T,t_*)\ge \mu
\tag{FSP.2}
```

and for all earlier legal packet faces:

```math
\sup_T M_{full}(T,t)<\theta\mu,
\qquad
t<t_*,
\tag{FSP.3}
```

with `theta>0` chosen below the parent-kernel constant.

This is the threshold-margin version of `ResponseNoParent_src.A`.

## 2. Stopped Endpoint Is A Parent

If a terminal tile `T` is coefficient-bad, define the backward stop:

```math
\mathcal C_T^{full}(\sigma_T,t_*)=\varepsilon.
\tag{FSP.4}
```

The stopped endpoint:

```math
\langle Z(\sigma_T),\Chi_T^{full}(\sigma_T)\rangle
\tag{FSP.5}
```

is not a new residual.  It is an earlier response parent.  Expanding
`\Chi_T^{full}(\sigma_T)` in the bounded-overlap response packet frame at
time `\sigma_T` gives:

```math
|\langle Z(\sigma_T),\Chi_T^{full}(\sigma_T)\rangle|^2
\le
C_{par}
\sum_{P\prec T}\kappa(P,T)M_{full}(P,\sigma_T)
+Err_{frame}(T).
\tag{FSP.6}
```

This is exactly the parent-kernel relation, with the parent face generated by
coefficient stopping.

## 3. Theorem `FullCoeffStopParentGap.A`

### Statement

At a first response pulse with threshold margin `(FSP.3)`, every
coefficient-stopped endpoint obeys:

```math
M_{full}^{stop-parent}(T)
\le
C_{par}\theta\mu+Err_{frame}(T).
\tag{FSP.7}
```

Choosing `theta <= (4C_{par})^{-1}` gives:

```math
M_{full}^{stop-parent}(T)
\le
\frac{\mu}{4}+Err_{frame}(T).
\tag{FSP.8}
```

### Proof

By `(FSP.6)`, the stopped endpoint is a bounded-overlap sum of earlier packet
masses.  Each earlier mass is bounded by `(FSP.3)`.  The parent weights satisfy
the installed Bessel/parent-kernel summability:

```math
\sum_{P\prec T}\kappa(P,T)\le C_{par}.
\tag{FSP.9}
```

Thus:

```math
M_{full}^{stop-parent}(T)
\le
C_{par}\theta\mu+Err_{frame}(T).
```

The choice of `theta` gives `(FSP.8)`. `\square`

## 4. Theorem `FullCoeffStopChargeLegal.A`

### Statement


coefficient stopping is legal in the first-pulse response drain:

```math

\tag{FSP.10}
```

### Proof

On a stopped slab, the exact identity gives:

```math
M_{full}(T,t_*)
\le
C M_{full}^{stop-parent}(T)
+C
\left|
\int_{\sigma_T}^{t_*}\langle\Delta u,\Chi_T^{full}\rangle dt
\right|^2.
\tag{FSP.11}
```

Use `FullCoeffStopParentGap.A`:

```math
C M_{full}^{stop-parent}(T)
\le
\frac{\mu}{2}+Err_{frame}(T)
\tag{FSP.12}
```

after shrinking `theta` against the constant in `(FSP.11)`.

Use `OrdinaryDissipationTail.A` and Bessel:

```math
\sum_T
\left|
\int_{\sigma_T}^{t_*}\langle\Delta u,\Chi_T^{full}\rangle dt
\right|^2
=o_N(1).
\tag{FSP.13}
```

For `N` large and legal frame errors small:

```math
M_{full}(T,t_*)<\mu,
\tag{FSP.14}
```

contradicting the definition of first pulse `(FSP.2)`.

Thus a coefficient stop cannot create terminal response mass at zero cost.  It
is legal because it is converted into an earlier parent plus ordinary
dissipation, not because the coefficient tower is directly estimated.
`\square`

one.  The coefficient-bad event is legal only because stopping produces an
earlier response parent and the first-pulse threshold kills that parent.
