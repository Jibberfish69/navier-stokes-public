## 1. Expanded Full Response Parent Relation

Define:

```math
P\prec_{resp}^{full}T
\tag{FPS.1}
```

if either:

```text
1. P is an earlier same-fluid response Duhamel parent of T;
2. P is an earlier packet in the bounded-overlap expansion of a stopped
   full-coefficient adjoint trace Chi_T^{full}(sigma_T).
```

The second case means:

```math
\Chi_T^{full}(\sigma_T)
=
\sum_{P\prec_{stop}T}a_{P,T}\Chi_P^{full}(\sigma_T)
+Err_{frame}(T)
\tag{FPS.2}
```

with:

```math
\sum_{P\prec_{stop}T}|a_{P,T}|^2\le C.
\tag{FPS.3}
```

## 2. Theorem `StoppedParentFrame.A`

### Statement

On every full-coefficient-good stopped segment, `(FPS.2)` and `(FPS.3)` hold
with the same terminal response packet frame used for full-adjoint mass.

### Proof

At the stopped face `sigma_T`, the propagated packet
`\Chi_T^{full}(\sigma_T)` satisfies the heat-tube normalization from
`FullCoeffGoodPacket.A`:

```math
\|\Chi_T^{full}(\sigma_T)\|_{\mathcal H_T}\le C_H.
```

The response packet frame at time `sigma_T` is used through the exact Bessel
analysis bound, on the same response-orthogonal subspace:

```math
a_{P,T}:=\langle \Chi_T^{full}(\sigma_T),\widetilde\Chi_P\rangle_{\mathcal H_T},
\qquad
\sum_{P\prec_{stop}T}|a_{P,T}|^2
\le C_B\|\Chi_T^{full}(\sigma_T)\|_{\mathcal H_T}^2.
\tag{FPS.3'}
```

Here `\{\widetilde\Chi_P\}` is the dual analysis frame paired with the response
packet synthesis frame.  Combining the two displayed bounds gives

```math
\sum_{P\prec_{stop}T}|a_{P,T}|^2\le C_B C_H^2,
```

which is `(FPS.3)` after renaming the constant.  The reconstruction identity is

```math
\Chi_T^{full}(\sigma_T)
=
\sum_{P\prec_{stop}T}a_{P,T}\Chi_P^{full}(\sigma_T)
+
\left(I-\Pi_{resp,T}\right)\Chi_T^{full}(\sigma_T),
```

and the final term is the installed `Err_frame(T)`. `\square`

## 3. Theorem `ResponseNoParent_full.A`

### Statement

Terminal first-pulse selection with respect to the expanded relation
`\prec_{resp}^{full}` gives:

```math
\boxed{
TerminalResponseFirstPulse^{full}
\Longrightarrow
FirstPulse.NoParent_{resp}^{full}.
}
\tag{FPS.4}
```

Equivalently:

```math
\sum_{P\prec_{resp}^{full}T_0}
\kappa(P,T_0)M_{full}(P)=0
\tag{FPS.5}
```

in the terminal normalized first-pulse limit.

### Proof

Order candidate response pulses by time and then by the finite packet ancestry
depth generated by `(FPS.1)`.  This order is well-founded on any finite
preterminal packet discretization because every parent lies at an earlier legal
face.  Choose `T_0` minimal among tiles carrying normalized positive full
response mass.  If an expanded parent `P` had nonzero normalized mass, `P`
would be an earlier candidate pulse, contradicting minimality.  Therefore all
expanded parent contributions vanish in the normalized first-pulse limit.
`\square`
