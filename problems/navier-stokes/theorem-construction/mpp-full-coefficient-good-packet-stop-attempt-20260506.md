## 1. Full Coefficient Packet Setup

Fix a terminal response tile:

```math
T=(j,Q_T,I_T),
\qquad
r_T=2^{-j},
\qquad
I_T=[t_-,t_+].
```

Let the center follow the actual smooth velocity:

```math
\dot X_T(t)=u(X_T(t),t),
\qquad
X_T(t_+)=x_T.
\tag{FCG.1}
```

Let the affine frame and strain gauge solve:

```math
\dot J_T(t)=(\nabla u)(X_T(t),t)J_T(t),
\qquad
J_T(t_+)=I,
\tag{FCG.2}
```

and

```math
\dot G_T(t)=\mathcal A_T(t)G_T(t),
\qquad
\mathcal A_T(t)=(\nabla u)^T(X_T(t),t)
\tag{FCG.3}
```

with the installed amplitude normalization `g_T(t)` absorbing the positive
central strain.

## 2. Full Coefficient Goodness

Define the full coefficient remainder budget:

```math
\mathcal C_T^{full}(a,b)
:=
\int_a^b
\left[
r_T^2\|\nabla^2u(t)\|_{L^\infty(Q_T^*)}
+r_T\|\nabla(\nabla u)(t)\|_{L^\infty(Q_T^*)}
+r_T^2\|\nabla^2\mathbb P_T u(t)\|_{L^\infty(Q_T^*)}
\right]dt.
\tag{FCG.4}
```

The last term is a placeholder for the localized Leray/projector commutator
coefficient.  In a strictly local chart it is absorbed into the first two
terms plus the installed projected-packet pressure ledger.

A subtile is full-coefficient-good if:

```math
\mathcal C_T^{full}(t_-,t_+)\le\varepsilon.
\tag{FCG.5}
```

## 3. Theorem `FullCoeffGoodPacket.A`

### Statement

On a full-coefficient-good subtile, normalized backward adjoint packets for
`L_u^*` satisfy heat-tube bounds:

```math
|\partial_x^\alpha\Chi_T^{full}(x,t)|
\le
C_\alpha r_T^{-3/2-|\alpha|}
\exp(-c|x-X_T(t)|^2/r_T^2),
\tag{FCG.6}
```

and the Bessel estimate:

```math
\left\|\sum_T c_T\Chi_T^{full}\right\|_{L_t^2H_x^1}^2
\le
C\sum_T|c_T|^2.
\tag{FCG.7}
```

### Proof

Pull the adjoint equation back by `(FCG.1)` and `(FCG.2)`, then gauge by
`(FCG.3)` and `g_T(t)`.  The central transport, affine deformation, and central
matrix strain are now principal.  What remains is a perturbation `E_T`
generated by:

```text
1. second-order spatial Taylor remainders of u around X_T(t);
2. first-order spatial Taylor remainders of grad u around X_T(t);
3. localized Leray/projector commutators already present in the installed
   projected packet calculus.
```

By `(FCG.4)`:

```math
\|E_T\|_{L_t^1(H^1\to H^{-1})}\le C\varepsilon.
\tag{FCG.8}
```

The unperturbed pulled-back equation is the affine heat equation with bounded
gauge, hence has Gaussian packet bounds.  Duhamel gives:

```math
\Chi_T^{full}
=
H_T^{aff}\Chi_T^{full}(t_+)
+\int_t^{t_+}H_T^{aff}(t,s)E_T(s)\Chi_T^{full}(s)ds.
\tag{FCG.9}
```

Choose `epsilon` so `C epsilon < 1/10`. The Duhamel term is absorbed in the
packet norm by the following estimate. Let `\mathfrak N_T` be the packet norm
for which the affine propagator obeys

```math
\mathfrak N_T(H_T^{aff}\Chi_T^{full}(t_+))\le C_0
```

and

```math
\mathfrak N_T\!\left(
\int_t^{t_+}H_T^{aff}(t,s)E_T(s)F(s)\,ds
\right)
\le
C_0\|E_T\|_{L_t^1(H^1\to H^{-1})}\mathfrak N_T(F).
```

Then `(FCG.8)` and `(FCG.9)` give

```math
\mathfrak N_T(\Chi_T^{full})
\le
C_0+C_0C\varepsilon\,\mathfrak N_T(\Chi_T^{full}).
```

Choosing `\varepsilon` so `C_0C\varepsilon\le 1/2` yields
`\mathfrak N_T(\Chi_T^{full})\le 2C_0`, which is `(FCG.6)`. The passage from
`(FCG.6)` to `(FCG.7)` uses the Schur test on the tube Gram matrix: bounded
overlap gives finite row and column sums, hence the associated matrix is
bounded on `\ell^2`. `\square`

## 4. Theorem `FullCoeffStopIdentity.A`

### Statement

If a tile is not full-coefficient-good, define the backward stop:

```math
\mathcal C_T^{full}(\sigma_T,t_+)=\varepsilon.
\tag{FCG.10}
```

Then the exact full adjoint identity on `[sigma_T,t_+]` gives:

```math
M_{full}(T)
\le
C M_{full}^{parent}(\sigma_T)
+C
\left|
\int_{\sigma_T}^{t_+}
\langle \Delta u,\Chi_T^{full}\rangle dt
\right|^2.
\tag{FCG.11}
```

There is no coefficient residual term.

### Proof

Apply `FullCoefficientAdjointIdentity.A` on the stopped slab
`[\sigma_T,t_+]` and square the result after the installed strain normalization.
The endpoint term at `\sigma_T` is by definition the stopped response-parent
mass.  The only volume term is `Delta u`.  `\square`

## 5. Ordinary Dissipation Charge On Stopped Segments

Using the Bessel estimate on good stopped subtiles:

```math
\sum_T
\left|
\int_{\sigma_T}^{t_+}\langle\Delta u,\Chi_T^{full}\rangle dt
\right|^2
\le
C_{\mathrm{Bessel}}
\|\Delta u_{>N}\|_{L_t^2H_x^{-1}}^2
\le
C_{\Delta}
\int\sum_{j>N}D_j(t)dt.
\tag{FCG.12}
```

Thus the stopped-volume term is legal by ordinary dissipation.  The remaining
issue is not the source term.  It is the interpretation of the stopped endpoint
created by coefficient badness.
