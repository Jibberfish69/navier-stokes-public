## 1. Truncated Full Linearized Operator

On a terminal tile of shell `j`, define the truncated coefficient:

```math
u^{lo}:=u_{\le j-M}.
```

Set:

```math
L_{u}^{lin,lo}Z
=
\partial_tZ+\mathbb P(u^{lo}\cdot\nabla Z+Z\cdot\nabla u^{lo})
-\nu\Delta Z.
\tag{FLAP.1}
```

This operator contains the full linearized coupling generated by the retained
low/intermediate field.  The discarded high-coefficient part is:

```math
R^{hi-coeff}
=
\mathbb P((u-u^{lo})\cdot\nabla Z+Z\cdot\nabla(u-u^{lo})).
\tag{FLAP.2}
```

## 2. Coefficient-Good Budget

For a tile `T`, define:

```math
\mathcal C_T^{lin}(a,b)
:=
\int_a^b
\left(
r_T^2\|\nabla^2u^{lo}\|_\infty
+r_T\|\nabla^2u^{lo}\|_\infty
+r_T\|\nabla B^{lo}\|_\infty
\right)dt,
\tag{FLAP.3}
```

where:

```math
B^{lo}:=\nabla u^{lo}.
```

The repeated second-derivative scale factors reflect the transport and matrix
coefficient perturbations in the affine frame.  A tile is coefficient-good if:

```math
\mathcal C_T^{lin}(t_-,t_+)\le\varepsilon_M.
```

## 3. Coefficient-Good Packet Theorem

### Theorem `TruncatedLinearizedResponseAdjointPacket.A`

On coefficient-good tiles, normalized adjoint packets for
`(L_u^{lin,lo})^*` satisfy:

```math
\left\|\sum_T c_T\Chi_T^{lin,lo}\right\|_{L_t^2H_x^1}^2
\le
C\sum_T|c_T|^2,
\tag{FLAP.4}
```

and admit the same parent-kernel decomposition and terminal lower-frame
detection as the installed projected affine adjoint packets.

### Proof

Use the same affine low-flow frame:

```math
\dot X_T=u^{lo}(X_T,t),
\qquad
\dot J_T=(\nabla u^{lo})(X_T,t)J_T.
```

Gauge the matrix coefficient `B^{lo}` by the fundamental matrix `G_T` and
normalize by:

```math
g_T(t)
=
\exp
\int_t^{t_+}\lambda_{\max}^+
\left(\frac{B^{lo}+B^{lo,T}}2\right)(X_T(s),s)\,ds.
```

In the pulled-back frame, the adjoint equation becomes anisotropic heat plus a
perturbation `E_T` whose `L_t^1(H^1->H^{-1})` norm is bounded by
`C\mathcal C_T^{lin}`.  On coefficient-good tiles this is at most
`C_{\mathrm{lin}}\epsilon_M`.
Choose `epsilon_M` so small that the perturbation is absorbed by Duhamel.

The normalized packets obey the same heat-tube bounds:

```math
|\partial_x^\alpha\Chi_T^{lin,lo}(x,t)|
\le
C_\alpha r_T^{-3/2-|\alpha|}
\exp(-c|x-X_T(t)|^2/r_T^2).
```

Schur/Cotlar summability gives `(FLAP.4)`.  The parent-kernel and lower-frame
statements follow from the same bounded-overlap terminal packet frame and
backward endpoint decomposition.  `\square`

