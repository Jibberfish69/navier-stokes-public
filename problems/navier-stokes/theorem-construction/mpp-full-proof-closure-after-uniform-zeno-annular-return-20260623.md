# Full Proof Closure After Uniform Zeno Annular Return

Date: 2026-06-23

## 0. Claim

Inside the installed repo framework, a finite-time Navier--Stokes Clay terminal
witness from original smooth data has no surviving branch.

The proof is a contradiction.  Assume a finite terminal witness exists.  The
preterminal solution is smooth, so the center spike, the annular layers
underneath it, and the later stress/strain return are all read on the same
material history generated by the initial datum.

The height-growth step is not left as a picture.  The original-data
spike-thinning trichotomy says that every genuine height doubling of a
normalized non-gauge selected terminal packet is one of three full-packet
events:

```math
\begin{array}{ll}
\text{material geometry thinning}
&\leadsto d[\log(1+\mathcal P_N^{mat})]_+,\\[1mm]
\text{material selection/interface change}
&\leadsto d\mathcal K_{\rm iface}+d\mathcal L_{4B,N},\\[1mm]
\text{same-material storage/stress-work change}
&\leadsto dA_{4B,N}+d\mathcal L_{4B,N}.
\end{array}
\tag{FCZ.1}
```

Thus each height doubling spends a positive amount of the full clock:

```math
\int_{I_j}d\Omega_N\ge\eta_N>0.
\tag{FCZ.1a}
```

## 1. Storage/overlap readout on the material history

The terminal center storage/overlap is attached to the same material annular
return.  For the transported material cutoff, the exact identity is

```math
\frac{d}{ds}M_m(s)
+
2\nu\int \phi_m |S_y(V_m)|^2\,dy
=
-\int V_m\cdot(-Q_mI+2\nu S_y(V_m))\nabla\phi_m\,dy.
\tag{FCZ.2}
```

Thus

```math
\nu_m^{ol}((-\theta,0])
\le
\int_{-\theta}^{0}\widehat\rho_{A,m}(s)\,ds
+
\int_{-\theta}^{0}r_m^{mat}(s)\,ds.
\tag{FCZ.3}
```

For transported cutoffs \(r_m^{mat}=0\); for selected packet cutoffs it is a
same-packet selector/collar legal residual.

The uniform terminal-Zeno annular return theorem gives

```math
\lim_{\theta\downarrow0}
\limsup_m
\int_{-\theta}^{0}\widehat\rho_{A,m}(s)\,ds
=0.
\tag{FCZ.4}
```

The proof of `(FCZ.4)` is the daughter-packet argument: if `(FCZ.4)` fails,
then every bad parent terminal strip becomes a smaller heat-scale daughter
packet with fixed positive same-material annular return.  Same-packet admission
puts that return inside the full same-packet clock, and a separated daughter
subfamily forces

```math
\int_{\sigma_0}^{\infty}d\Omega_N=\infty.
\tag{FCZ.5}
```

This contradicts the prelimit master balance:

```math
d\mathfrak L_{4B,N}
+
c_0\left(
dA_{4B,N}
+
d[\log(1+\mathcal P_N^{mat})]_+
+
d\mathcal K_{\rm iface}
\right)
+
d\mathcal L_{4B,N}
\le
dR_{4B,N},
\qquad
\int dR_{4B,N}<\infty .
\tag{FCZ.6}
```

where

```math
d\Omega_N
:=
dA_{4B,N}
+
d[\log(1+\mathcal P_N^{mat})]_+
+
d\mathcal K_{\rm iface}
+
d\mathcal L_{4B,N}.
\tag{FCZ.6a}
```

Therefore no endpoint storage/overlap pulse survives on the original material
history.

## 2. Critical-packet spike on the material history

If the terminal spike has no storage-variation pulse on the selected windows,
then it is the non-gauge critical-packet case on the same material history.  The
installed lower-bound theorem says

```math
\mathcal C^\perp(P_j)\ge\varepsilon_0
\quad\Longrightarrow\quad
\int_{P_j}dA_{4B,N}\ge c(\varepsilon_0)>0.
\tag{FCZ.7}
```

Infinitely many critical terminal packets again contradict the finite
four-body clock:

```math
\int_{\sigma_0}^{\infty}dA_{4B,N}<\infty .
\tag{FCZ.8}
```

So the non-gauge critical-packet case cannot be the finite terminal witness.

## 3. No center-only branch

The proof has no separate "discard the material history" case.  The alleged
finite-time witness is generated by a smooth preterminal solution, and every
terminal readout used here is the limit of that same material history.  A
center-only projection that forgets the annular return is simply not the object
being tested.

So the terminal witness has only these possibilities:

```math
\begin{array}{ll}
\text{storage/overlap pulse on the material history}
&\Rightarrow
\text{uniform annular return contradiction},\\[1mm]
\text{non-gauge critical packet on the material history}
&\Rightarrow
\text{finite }A_{4B,N}\text{ contradiction}.
\end{array}
\tag{FCZ.9}
```

No branch leaves a finite nonsmooth terminal object.
