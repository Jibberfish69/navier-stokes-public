# Conditional Closure Assembly After Uniform Zeno Annular Return

surviving finite-time Navier--Stokes Clay terminal branch once the signed smooth

The proof is a contradiction.  Assume a finite terminal witness exists.  The
preterminal solution is smooth, so the center spike, the annular layers
underneath it, and the later stress/strain return are all read on the same
material history generated by the initial datum.

The height-growth step is not left as a picture.  The original-data
spike-thinning trichotomy says that every genuine height doubling of a
normalized non-gauge selected terminal packet is one of three full-packet
events:

```math
\begin{array}{ll}

\tag{FCZ.1}
```

Under that finite full-clock theorem, each height doubling spends a positive

```math
\int_{I_j}d\Omega_N\ge\eta_N>0.
\tag{FCZ.1a}
```



under the signed smooth-packet clock theorem.
