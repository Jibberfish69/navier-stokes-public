## 1. The critical pole inside a declared Mellin ansatz

This is a profile test, not a profile conclusion.  Assume on a selected annular
branch that, as \(r\downarrow0\),

```math
u(r,\theta)=r^{-a}U(\theta)+o(r^{-a}),
\qquad
p(r,\theta)=r^{-2a}P(\theta)+o(r^{-2a}),
```

with the leading convective/pressure and viscous coefficients nonzero.  Under
that explicit ansatz the three stationary exponent classes are:

```math
(u\cdot\nabla)u = O(r^{-2a-1}),
\qquad
\nabla p=O(r^{-2a-1}),
\qquad
\nu\Delta u=O(r^{-a-2}).
```

The nonlinear/pressure exponent and the viscous exponent match only at

```math
2a+1=a+2,
\qquad
a=1.
```

So inside this Mellin ansatz, the candidate annular pole with matched
nonlinear/pressure and viscous exponents is

```math
u(r,\theta)=r^{-1}U(\theta)+o(r^{-1}),
\qquad
p(r,\theta)=r^{-2}P(\theta)+o(r^{-2}).
```

This test does not assert that the solution has such a profile. It identifies
the exact exponent a Mellin/radial pole would need before it could enter the
gold stress-flux branch.

## 2. The stress flux sees the pole

Write the momentum equation in divergence form:

```math
\partial_t u+\nabla\cdot\mathsf T(u,p)=0,
\qquad
\mathsf T(u,p):=u\otimes u+pI-\nu\nabla u.
```

For the critical ansatz above, the stress has the form

```math
\mathsf T(u,p)=r^{-2}\mathsf T_{-2}(\theta)+o(r^{-2}),
```

where \(\mathsf T_{-2}\) is the leading angular stress tensor generated by
\(U,P\).  Therefore the sphere flux

```math
\Phi(r,t)
:=
\int_{\partial B_r(x_*)}
\mathsf T(u,p)n\,dS
```

has the finite Mellin-limit candidate

```math
\Phi(r,t)
=
\int_{\mathbb S^2}\mathsf T_{-2}(\theta)n(\theta)\,dS_\theta+o(1).
```

This is the hidden-residue test. A terminal annular critical pole, if such a
pole is actually produced, would carry a possible point-force/source charge
through the stress flux.

## 4. Rescaled version

Use the modulated variables

```math
y=\frac{x-x_*(t)}{\lambda(t)},
\qquad
u(t,x)=\lambda(t)^{-1}U(s,y),
\qquad
p(t,x)=\lambda(t)^{-2}P(s,y).
```

The rescaled stress flux on the unit sphere is

```math
\Phi_U(s)
:=
\int_{\partial B_1}
\left(
U\otimes U+P I-\nu\nabla_y U
\right)n\,dS.
```

This quantity is invariant under the physical scaling. It is the right object
to track through a Zeno cascade.

The rescaled equation is

```math
U_s-\nu\Delta_y U+(U\cdot\nabla_y)U+\nabla_yP
+b(s)(U+y\cdot\nabla_yU)-c(s)\cdot\nabla_yU=0.
```

For smooth \(U,P\) and regular radii \(0<R_1<R_2\), define the radius-\(R\)
stress flux by

```math
\Phi_U(R,s)
:=
\int_{\partial B_R}
\left(
U\otimes U+P I-\nu\nabla_y U
\right)n\,dS.
```

Because \(\nabla_y\cdot U=0\),
\[
\nabla_y\cdot(U\otimes U+P I-\nu\nabla_y U)
=
(U\cdot\nabla_y)U+\nabla_yP-\nu\Delta_yU.
\]
The rescaled equation therefore gives the exact annular balance

```math
\Phi_U(R_2,s)-\Phi_U(R_1,s)
=
-\int_{A_{R_1,R_2}}
\left[
U_s+b(s)\Lambda U-c(s)\cdot\nabla U
\right]\,dy.
```

So non-locking is not charged by variation of \(b(s)\) alone. It is charged
only when it creates or changes the scale-invariant stress flux.
