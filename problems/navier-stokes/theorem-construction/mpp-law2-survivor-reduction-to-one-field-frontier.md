## Theorem `L2F.A` (No-drop installs only the `(Part, Dead)` entry)

Assume the separate Law 2 no-drop theorem `NDT.A`.

Then the exact route consequence is:

```math
\boxed{
\text{shared participation cannot fail through the dead shell on still-live neighborhoods.}
}
\tag{L2F.2}
```

Equivalently:

```math
\boxed{
\text{the `(Part, Dead)` matrix entry is installed.}
}
\tag{L2F.3}
```

### Proof

This is exactly Corollary `NDT.B` as re-read through the law / endpoint proof
matrix. `\square`

## Honest Boundary

`L2F.A` does **not** prove:

1. that `Part` is discharged under `Blown` or `Jump`;
2. that `Dead` cannot also test `Pack` or `Field`;
3. that the live frontier lies strictly on the `Pack / Field` side;
4. that exact-potential, normal-covector, or selector surfaces are now the
   only remaining theorem walls.

So the correct route sentence is:

```math
\boxed{
\text{one installed matrix entry is not a surviving-pair theorem.}
}
\tag{L2F.4}
```
