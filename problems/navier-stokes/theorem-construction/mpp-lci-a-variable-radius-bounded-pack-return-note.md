## Status

Candidate theorem-facing note.

Role: isolate the exact route-local return encoded by the bounded-pack
realization `VCB.Bc` / `OFP.C1m`.

## Purpose

The direct geometric target behind `OFP.C1k` is still the variable-radius
carrier theorem `VCB.A`. But once the pack-side gauge is already bounded, the
notes also offer a conditional realization:

```math
\boxed{
\text{widened receiver-side return}
\ +\
\text{anchored-center ledger}
\Longrightarrow
VCB.A.
}
\tag{VBR.0}
```

The exact question is whether `(VBR.0)` is a genuinely new supplier route or
just a return to old transported-center / lower-carrier surfaces.

(VBR.1)

LCI.B_{N+4,N+4,\delta+5\Lambda_{\delta,\rho}^{halo}}.

The second input `(VBR.2)` is exactly the old anchored-center ledger
`(LCI.3c5k)` on the transported-center scalar branch.

### Reduction `VBR.A` (The bounded-pack realization of `VCB.A` returns to old theorem families)

Under bounded pack-side gauge, Corollary `VCB.Bc` is therefore exactly

```math
LCI.B_{N+4,N+4,\delta+5\Lambda_{\delta,\rho}^{halo}}
\ +\
(LCI.3c5k)
\Longrightarrow
VCB.A.
\tag{VBR.4}
```

So the bounded-pack realization of the variable-radius carrier theorem is not a
new external supplier family. It is a route-local return to:

1. an old widened lower-carrier packet theorem;
2. the old anchored-center ledger on the transported-center branch.

### Proof

Substitute `(VBR.3)` for `VCB.Bc0`, and identify `VCB.Bc1` with the
already-installed anchored-center ledger `(LCI.3c5k)`. This rewrites
Corollary `VCB.Bc` exactly as `(VBR.4)`. ∎

### Corollary `VBR.B` (The bounded-pack variable-radius route is not the genuinely new escape branch)

The direct theorem `VCB.A` remains a real standalone target. But its bounded-
pack realization through `OFP.C1m` / `VCB.Bc` is not the new non-circular
supplier branch.

It returns to old `LCI`-family data, so the genuine external move still has to
come from the direct halo-shell / fixed-increment route, not from the bounded-
pack return itself.

## Honest Boundary

This note does **not** prove `VCB.A`. It does **not** show that the old
anchored-center ledger `(LCI.3c5k)` is independent of the oscillation package
on the installed route. It does **not** rule out the direct `VCB.A` theorem as
the real escape hatch.

What it does prove is narrower and exact:

1. the bounded-pack realization `VCB.Bc` is not a new theorem family;
2. it is exactly the old widened lower-carrier packet theorem together with the
   old anchored-center ledger;
3. therefore the bounded-pack `VCB` route is a route-local return, not the
   genuinely new supplier branch.
