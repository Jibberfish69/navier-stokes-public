# MPP Local-Eulerian Reference-Envelope Lemma

## Status

Candidate theorem-facing local-envelope note.

Role: exact concrete next-step surface for `RW.A`.

This note sits underneath
`mpp-reference-comparison-propagation-lemma.md`
and isolates the local Eulerian envelope needed to turn the packet-generated
reference comparison density into an interval-controlled packet.

## Purpose

The exact burden here is:

```math
\boxed{
\text{construct or state a packet-local Eulerian envelope }
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)
\text{ with }
\mathfrak e^{ref}_{N,\rho,\psi}(a,t)
\le
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t),
}
```

```math
\boxed{
\text{then integrate that envelope to recover }
\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t).
}
\tag{LE.0}
```

This is the exact next move for `RW.A`.

## Setup

Retain the packet-generated reference range and reference comparison density:

```math
\mathcal R_r^{ref}(t;\psi)
:=
\big\{
F(a,t)r:a\in\operatorname{supp}\psi
\big\},
\tag{LE.1}
```

```math
\mathfrak e^{ref}_{N,r,\psi}(a,t)
:=
\sup_{\eta\in\mathcal R_r^{ref}(t;\psi)}
\sum_{k=0}^{N}\lambda_k
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2,
\tag{LE.2}
```

```math
\mathfrak e^{ref}_{N,\rho,\psi}(a,t)
:=
\sup_{0<|r|\le \rho}
\mathfrak e^{ref}_{N,r,\psi}(a,t).
\tag{LE.3}
```

Define the scale-window reference range union

```math
\mathcal R_{\rho}^{ref}(t;\psi)
:=
\bigcup_{0<|r|\le \rho}\mathcal R_r^{ref}(t;\psi).
\tag{LE.4}
```

Define the corresponding Eulerian reference radius

```math
\Lambda_{\rho,\psi}^{ref}(t)
:=
\sup_{\eta\in\mathcal R_{\rho}^{ref}(t;\psi)}
|\eta|.
\tag{LE.5}
```

and the Eulerian reference ball

```math
\mathbb B_{\rho,\psi}^{ref}(t)
:=
\big\{
\eta\in\mathbf R^3:|\eta|\le \Lambda_{\rho,\psi}^{ref}(t)
\big\}.
\tag{LE.6}
```

This ball is an Eulerian window containing every transported reference
increment generated by the packet and the scale window.

## Exact Envelope Construction

Define the local Eulerian reference-envelope density

```math
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)
:=
\sup_{\eta\in\mathbb B_{\rho,\psi}^{ref}(t)}
\sum_{k=0}^{N}\lambda_k
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2.
\tag{LE.7}
```

Define the integrated Eulerian envelope packet

```math
\widehat{\mathcal E}^{Eul,ref}_{N,\rho,\psi}(t)
:=
\int \psi(a)^2\,
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)\,da.
\tag{LE.8}
```

### Lemma LE.A (Eulerian envelope dominates the reference packet)

For a.e. `a` and every time `t`,

```math
\mathfrak e^{ref}_{N,\rho,\psi}(a,t)
\le
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t).
\tag{LE.9}
```

Hence

```math
\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t)
\le
\widehat{\mathcal E}^{Eul,ref}_{N,\rho,\psi}(t).
\tag{LE.10}
```

### Proof

By `(LE.4)`--`(LE.6)`, every increment in the scale-window reference range
union `\mathcal R_{\rho}^{ref}(t;\psi)` lies inside the Eulerian reference ball
`\mathbb B_{\rho,\psi}^{ref}(t)`. The pointwise supremum defining `(LE.3)` is
therefore taken over a subset of the supremum defining `(LE.7)`, which gives
`(LE.9)`. Integrating against `\psi(a)^2\,da` yields `(LE.10)`. ∎

## Exact Theorem Interface

### Candidate Theorem LE.B (local Eulerian envelope suffices for `RW.A`)

Fix a compactly supported material packet `\psi`, a finite depth `N`, a time
interval `I`, and a scale window `0<|r|\le \rho`.

Assume the PDE-native Eulerian defect engine propagates the Eulerian envelope
packet:

```math
\sup_{t\in I}
\widehat{\mathcal E}^{Eul,ref}_{N,\rho,\psi}(t)
<\infty.
\tag{LE.11}
```

Then

```math
\sup_{t\in I}
\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t)
<\infty.
\tag{LE.12}
```

### Proof

This is `(LE.10)` with the displayed supremum taken in `t`. ∎

## Interpretation

The point of this note is not to close `RW.A` by itself. Its point is to make
the remaining burden completely explicit:

```math
\text{derive interval control of the Eulerian envelope packet }
\widehat{\mathcal E}^{Eul,ref}_{N,\rho,\psi}
\text{ from the PDE-native defect engine.}
\tag{LE.13}
```

That is the exact interface between the Eulerian defect engine and the
packet-generated reference-comparison packet.

## Boundary

This note does **not** yet prove:

1. a closed interval estimate for `(LE.11)` from `(MP.12)` or `(TC.18)`--`(TC.21)`;
2. a sharper packet-local Eulerian window than the enclosing ball
   `\mathbb B_{\rho,\psi}^{ref}(t)`;
3. propagation of the weighted-segment packet;
4. the downstream closure-packaging theorem.

It isolates only the exact local Eulerian envelope needed to make `RW.A`
concrete.
