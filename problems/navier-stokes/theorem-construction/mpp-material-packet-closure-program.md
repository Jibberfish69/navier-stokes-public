# MPP Material-Packet Closure Program

## Status

Candidate theorem-facing next-step note.

Role: packet-program surface for the unified material packet
`\mathcal H_N = E_N + \alpha A_F + \beta P_F`.

This note does **not** claim closure of the class-membership route. Its job is
more precise: replace the split packing/coherence discussion by one exact
material packet carrying the Law 1 / Law 3 side of the object law on a single
proof surface, with Law 2 participation kept on a separate handoff.

## Purpose

The class-membership route now has three primitive laws already isolated:

1. shared packing law;
2. shared participation law;
3. shared one-field law across neighboring towers.

The next exact packet move is **not** to package all three at once. It is to
fuse the Law 1 and Law 3 surfaces into one material packet whose evolution can
be studied directly, while keeping Law 2 on its own theorem surface.

The governing principle is:

```math
\boxed{
\text{one-field tower coherence and one-packing coherence should be propagated together, not as separate notes.}
}
\tag{MP.0}
```

## Material Notation

Let `X(a,t)` be the Lagrangian flow map, and write

```math
F(a,t):=D_aX(a,t),
\qquad
A(a,t):=F(a,t)^{-1},
\qquad
\det F(a,t)=1.
\tag{MP.1}
```

To avoid a collision of notation, reserve `A=F^{-1}` for the inverse
deformation gradient and write

```math
Y(x,t):=X(\cdot,t)^{-1}(x)
\tag{MP.2}
```

for the back-to-label map. The material cutoff generated by a compactly
supported label packet `\psi(a)` is then

```math
\phi_t(x):=\psi(Y(x,t)).
\tag{MP.3}
```

This is the exact material definition represented by the shorthand
`\phi_t=\psi\circ A`.

For the Eulerian tower, write

```math
U_k:=\nabla^k u,
\qquad
\delta_h f(x):=f(x+h)-f(x),
\tag{MP.4}
```

and for material relative deformation increments write

```math
\Delta_r Z(a,t):=Z(a+r,t)-Z(a,t).
\tag{MP.5}
```

## The Material Packet

Fix a finite depth `N`, positive rung weights `\lambda_0,\dots,\lambda_N`, and
positive coupling weights `\alpha,\beta`.

Define the localized tower-defect energy

```math
E_N(h,t;\psi)
:=
\sum_{k=0}^{N}
\lambda_k
\int
\phi_t(x)^2\,|\delta_h U_k(x,t)|^2\,dx.
\tag{MP.6}
```

Define the packing-class amplitude ledger

```math
A_F(t;\psi)
:=
\int
\psi(a)^2\Big(|F(a,t)|^2+|A(a,t)|^2\Big)\,da.
\tag{MP.7}
```

Define the relative packing-coherence ledger

```math
P_F(r,t;\psi)
:=
\int
\psi(a)^2\Big(|\Delta_rF(a,t)|^2+|\Delta_rA(a,t)|^2\Big)\,da.
\tag{MP.8}
```

Then define the full material packet

```math
\mathcal H_N(h,r,t;\psi)
:=
E_N(h,t;\psi)
+
\alpha\,A_F(t;\psi)
+
\beta\,P_F(r,t;\psi).
\tag{MP.9}
```

Later, once the transported tower-defect ledger `\widetilde E_{N,r,\psi}` has
been introduced in `(MP.26b)`, define the fused transported closure packet

```math
\widetilde{\mathcal H}_{N,r,\psi}(t)
:=
\widetilde E_{N,r,\psi}(t)
+
\alpha\,A_F(t;\psi)
+
\beta\,P_F(r,t;\psi).
\tag{MP.9a}
```

This packet carries the Law 1 / Law 3 side of the object law in one place:

1. `A_F` carries membership in a finite packing class;
2. `P_F` carries shared local packing between neighboring parcels;
3. `E_N` carries neighboring-tower one-field coherence.

The participation handoff is separate:

```math
\boxed{
\text{shared participation is not yet packaged inside }\mathcal H_N\text{ or }\widetilde{\mathcal H}_{N,r,\psi};\text{ it remains on the PDE-native Law 2 surface.}
}
\tag{MP.9b}
```

The role split is therefore:

```math
\mathcal H_N
\quad\text{= Eulerian-material derivation surface,}
\tag{MP.9c}
```

```math
\widetilde{\mathcal H}_{N,r,\psi}
\quad\text{= transported closure surface.}
\tag{MP.9d}
```

## 1. Tower-Defect Evolution Law

For a packet-friendly form of the tower defect equation, use the transport
carrier based at `x`:

```math
\big(\partial_t+u(x,t)\cdot\nabla\big)\delta_h U_k
+
\big(\delta_hu\big)\cdot\nabla U_k(x+h,t)
+
\delta_h\nabla^{k+1}p
-\nu\Delta\delta_h U_k
=
\delta_h B_k.
\tag{MP.10}
```

Let

```math
D_N(h,t;\psi)
:=
\sum_{k=0}^{N}
\lambda_k
\int
\phi_t(x)^2\,|\nabla\delta_h U_k(x,t)|^2\,dx.
\tag{MP.11}
```

Since `(\partial_t+u\cdot\nabla)\phi_t=0`, multiplying `(MP.10)` by
`2\lambda_k\phi_t^2\delta_h U_k`, summing over `k`, and integrating gives the
localized defect-energy identity

```math
\frac{d}{dt}E_N(h,t;\psi)
+
2\nu D_N(h,t;\psi)
=
\mathcal P_N^{red}(h,t;\psi)
+
\mathcal F_N^{press}(h,t;\psi)
+
\mathcal S_N(h,t;\psi)
+
\mathcal R_N(h,t;\psi)
+
\mathcal C_N^{cut}(h,t;\psi).
\tag{MP.12}
```

Here:

1. `\mathcal P_N^{red}` is the higher-rung pressure-redistribution packet;
2. `\mathcal F_N^{press}` is the pressure-flux packet;
3. `\mathcal S_N` is the strain/transport interaction packet coming from
   `(\delta_hu)\cdot\nabla U_k`;
4. `\mathcal R_N` is the cross-rung cascade packet coming from `\delta_h B_k`;
5. `\mathcal C_N^{cut}` is the viscous cutoff-commutator packet created by
   localizing with `\phi_t`.

The pressure split matches the corrected tower law:

```math
\boxed{
\text{for }k\ge 1,\ \text{pressure contributes redistribution plus flux;}
}
```

```math
\boxed{
\text{pure-flux is reserved for the base rung }k=0.
}
\tag{MP.13}
```

So the tower side of the packet is not a sterile continuation norm. It is a
localized neighboring-tower defect ledger driven by strain/cascade and damped
by viscosity.

## 2. Deformation Amplitude Law

The flow-map deformation obeys

```math
\partial_tF(a,t)=\big(\nabla u\big)(X(a,t),t)\,F(a,t),
\tag{MP.14}
```

and

```math
\partial_tA(a,t)=-A(a,t)\,\big(\nabla u\big)(X(a,t),t).
\tag{MP.15}
```

Because `\psi` is fixed in material coordinates, differentiating `(MP.7)` gives
the exact amplitude law

```math
\frac{d}{dt}A_F(t;\psi)
=
2\int
\psi(a)^2
\Big(
F:(\nabla u)(X,t)F
-A:A(\nabla u)(X,t)
\Big)\,da.
\tag{MP.16}
```

Hence

```math
\frac{d}{dt}A_F(t;\psi)
\le
2\|\nabla u(\cdot,t)\|_{L^\infty(X(\operatorname{supp}\psi,t))}\,
A_F(t;\psi).
\tag{MP.17}
```

This is the exact packet law for finite packing class: local strain controls the
material distortion amplitude.

## 3. Relative Deformation Law

The relative deformation increment satisfies

```math
\partial_t(\Delta_rF)
=
\big(\nabla u\big)(X(a+r,t),t)\,\Delta_rF
+
\Big(
\big(\nabla u\big)(X(a+r,t),t)
-\big(\nabla u\big)(X(a,t),t)
\Big)F(a,t).
\tag{MP.18}
```

Likewise, for the inverse deformation increment,

```math
\partial_t(\Delta_rA)
=
-\Delta_rA\,\big(\nabla u\big)(X(a+r,t),t)
-A(a,t)
\Big(
\big(\nabla u\big)(X(a+r,t),t)
-\big(\nabla u\big)(X(a,t),t)
\Big).
\tag{MP.19}
```

Differentiating `(MP.8)` and using `(MP.18)`--`(MP.19)` yields the exact
relative-packing inequality

```math
\frac{d}{dt}P_F(r,t;\psi)
\le
C\,\|\nabla u(\cdot,t)\|_{L^\infty(X(\operatorname{supp}\psi+B_r,t))}\,
P_F(r,t;\psi)
+
C\int
\psi(a)^2
\big|
\Delta_r\big((\nabla u)\circ X\big)(a,t)
\big|^2
\Big(
|F(a,t)|^2+|A(a,t)|^2
\Big)\,da.
\tag{MP.20}
```

The exact source term here is therefore

```math
\mathcal Q_{1,r,\psi}^{str}(t)
:=
\int
\psi(a)^2
\big|
\Delta_r\big((\nabla u)\circ X\big)(a,t)
\big|^2
\,da.
\tag{MP.20a}
```

This is the real bridge:

```math
\boxed{
\text{relative packing mismatch is driven by the exact rung-1 material strain-defect source term }\mathcal Q_{1,r,\psi}^{str}(t).
}
\tag{MP.21}
```

So the packet does not merely juxtapose packing and tower coherence. It couples
them through the first-rung strain increment.

In the transported bridge note, this exact source is bounded above by the
larger transported rung-1 packet `\widetilde E_{1,r,\psi}(t)`. That upper bound
is valid, but it is not the literal source term in `(MP.20)`.

## First-Exit Theorem Shape

The first real theorem target should now be stated in packet language.

### Candidate Theorem MP-first-exit (Law 1 / Law 3 packet exit)

Fix a finite depth `N` and a compactly supported material packet `\psi`.
If a finite-time Law 1 / Law 3 class exit occurs on that packet, then at least
one of the following failures must occur:

```math
A_F(t;\psi)\to\infty,
\tag{MP.22}
```

```math
P_F(r,t;\psi)\not\to 0
\quad\text{as }r\to 0,
\tag{MP.23}
```

or

```math
E_N(h,t;\psi)\not\to 0
\quad\text{as }h\to 0.
\tag{MP.24}
```

Equivalently:

```math
\boxed{
\text{finite-time Law 1 / Law 3 class exit forces failure of finite packing class,}
}
```

```math
\boxed{
\text{or failure of shared local packing coherence,}
}
```

```math
\boxed{
\text{or failure of neighboring-tower one-field coherence.}
}
\tag{MP.25}
```

That is the exact first-exit theorem shape for the material packet. The
dead-tower / Law 2 participation branch is not part of `MP-first-exit`; it is
handed off separately to
[mpp-dead-tower-rigidity-reduction-note.md](/Users/thomasbirnie/Workspace/ToE/Research-Consolidation/problems/navier-stokes/theorem-construction/mpp-dead-tower-rigidity-reduction-note.md).

### Layer 2. Dynamical propagation

Show that the strain-generated cascade cannot drive the transported tower
coherence ledger `\widetilde E_{N,r,\psi}` and `P_F` out of control before
`A_F` itself breaks.

So on the Law 1 / Law 3 packet surface the route is no longer diffuse. The
packet reduces that branch to one dynamical question.

## Smallest Visible Closure Hypothesis

The smallest presently visible packet-local closure hypothesis sits at rung `1`.

Using the transported defect ledger from the bridge note,

```math
\widetilde E_{1,r,\psi}(t)
:=
\sum_{k=0}^{1}\lambda_k
\int_{\mathbf R^3}
\psi(a)^2\,|\Delta_r^X U_k(a,t)|^2\,da,
\tag{MP.26a}
```

and, more generally for finite depth `N`,

```math
\widetilde E_{N,r,\psi}(t)
:=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}
\psi(a)^2\,|\Delta_r^X U_k(a,t)|^2\,da,
\tag{MP.26b}
```

define the fully fused material strain-defect control

```math
\widetilde{\mathfrak S}_1(\rho,I;\psi)
:=
\sup_{t\in I}\sup_{0<|r|\le \rho}\widetilde E_{1,r,\psi}(t)
+
\int_I
\sup_{0<|r|\le \rho}
\mathcal Q_{1,r,\psi}^{str}(t)\,dt.
\tag{MP.26}
```

This is now fully in transported label-space:

1. the first term is the transported rung-1 defect envelope;
2. the second term is the exact rung-1 material source term from `(MP.20a)`.

By the bridge inequality, the exact source term is controlled by the first term
up to the factor `\lambda_1^{-1}`. But keeping both pieces visible preserves
the exact source-versus-envelope hierarchy instead of flattening the source term
into the larger packet.

This is the smallest visible closure hypothesis because:

1. `\widetilde E_{1,r,\psi}` is the transported rung-1 control envelope for
   local tower coherence;
2. the exact source term `\mathcal Q_{1,r,\psi}^{str}` is the driver in the
   relative deformation law `(MP.20)`.

So the exact current frontier is:

```math
\boxed{
\text{what strain-defect control is sufficient to propagate both }\widetilde E_{N,r,\psi}\text{ and }P_F\text{ on a material packet?}
}
\tag{MP.27}
```

More concretely, the route now points at proving a theorem of the following
shape:

```math
\widetilde{\mathfrak S}_1(\rho,I;\psi)<\infty
\Longrightarrow
\sup_{t\in I}\sup_{0<|r|\le \rho}\widetilde E_{N,r,\psi}(t)
+
\sup_{t\in I}\sup_{0<|r|\le \rho}P_F(r,t;\psi)
+
\sup_{t\in I}A_F(t;\psi)
<\infty
\tag{MP.28}
```

for finite depth `N`, with quantitative smallness as `r\to 0`. Here the
`A_F` term is propagated in parallel through the amplitude law `(MP.17)`, so
the conclusion is now a true packet-propagation statement.

The live next reduction layer is the packetized reduction of the raw
reference-increment and segment-price objects to
`\widehat{\mathcal E}^{ref}_{N,r,\psi}` and
`\mathcal M^{wseg}_{N+1,r,\psi}`, as recorded in
`mpp-reference-increment-and-segment-packet-reduction.md`.
The live next theorem surface after that reduction is
`mpp-reference-and-weighted-segment-propagation-lemma.md`.

## Exact Boundary

This note does **not** yet prove:

1. the full closure of `(MP.12)`;
2. the rigidity layer for the surviving jump failure;
3. the propagation theorem `(MP.28)`;
4. the final contradiction to Navier-Stokes class exit.

It only sharpens the next proof surface:

```math
\boxed{
\text{the live route should now be carried by the transported closure packet }
\widetilde{\mathcal H}_{N,r,\psi}
\text{ and by the rung-1 strain-defect bridge between }\widetilde E_{N,r,\psi}\text{ and }P_F,
}
\tag{MP.29}
```

with `A_F` propagated in parallel by `(MP.17)`.
