# MPP No Genuine Exit From Smooth Data Direct Attempt

Date: 2026-05-25

Status: direct Clay-closing proof attempt; does not certify full closure.

## Target

The target theorem is the remaining Clay-level CM statement:

```text
NoGenuineExitFromSmoothData.A:
OriginalSmoothData => not GenuineCMExit(T_*)
for every finite terminal time T_*.
```

Equivalently, for the maximal classical Navier-Stokes solution generated by
smooth divergence-free data, no finite terminal tail realizes a genuine
continuation-complete Pack/Part/Field class exit.

This is the theorem left after the pass/fail obstruction engine and the
no-third-branch class law.  It is stronger than branch classification.  It says
the same smooth-data solution never realizes the exit branch.

## Method

Use a first-exit contradiction.

Assume original smooth data produce a first finite `T_*` with
`GenuineCMExit(T_*)`.  Since the solution is classical on every preterminal
window, every preterminal same-fluid window supplies local Pack/Part/Field
services.  A genuine exit can therefore only occur through loss of the terminal
limit of those services.

The proof must show that this terminal service loss is impossible from original
smooth data.

## Face Split At The First Genuine Exit

By the installed capture and finite-failure landing the first genuine exit is
one of:

```text
Pack failure:
  not Pack_Q.

Part failure after Pack survives:
  Pack_Q + not Part_{N,Q}.

Field failure after Pack and Part survive:
  Pack_Q + Part_{N,Q} + forall r>0 not Field_{N,r,Q}.
```

The no-third-branch theorem makes these exit branches incompatible with an
in-class continuation branch.  It does not by itself eliminate them as possible
terminal behavior of a hypothetical Clay counterexample.

## Direct Attempt

### 1. Pack branch

If the first genuine exit is Pack-side, the installed Pack placement is:

```text
not ScaleCriticalTreeCarleson.A => not Pack_Q.
```

The required exclusion would be:

```text
OriginalSmoothData => ScaleCriticalTreeCarleson.A.
```

The current installed material does not prove this implication.  The leading
edge notes say the post-reconcile Bellman and reserve attempts reduce the
problem to a scale-critical active-window height / donor-tail estimate, and
that estimate is not installed by the current first-moment, local-energy,
donor-balance, normalized-adjoint, active-shell, square-source, branch-reserve,
or Zeno compactness inputs.

So the Pack branch remains a real mathematical wall, not a naming problem.

### 2. Part branch

If Pack survives and Part fails, the missing theorem is a same-carrier
participation no-drop statement:

```text
OriginalSmoothData + Pack_Q
=> Part_{N,Q}
```

on the retained terminal ledger at the continuation depth.  Existing notes
record typed row bridges into `Part_{N,Q}`, but they remain conditional on the
same source-wall / terminal-ledger closure rather than an independent
original-data theorem.

Thus the Part branch is not separately closed from installed inputs.

### 3. Field branch

If Pack and Part survive and Field fails, the missing theorem is a retained
same-fluid source/readout coherence theorem:

```text
OriginalSmoothData + Pack_Q + Part_{N,Q}
=> exists r>0 Field_{N,r,Q}.
```

The current route reduces the retained source-pulse and signed-current
obstructions to terminal signed-saturation / source-wall primitives.  Those
are useful because they keep the branch inside Pack/Part/Field, but they do not
yet produce the positive Field coherence needed to rule out genuine exit.

Thus the Field branch is also not closed from installed inputs.

## Result Of The Attempt

The direct first-exit argument proves the following sharpened reduction:

```text
NoGenuineExitFromSmoothData.A
is equivalent, inside the installed CM grammar, to ruling out all three
first-exit faces from original smooth data:

1. OriginalSmoothData => Pack_Q terminal survival
   through ScaleCriticalTreeCarleson.A;
2. OriginalSmoothData + Pack_Q => Part_{N,Q} terminal no-drop;
3. OriginalSmoothData + Pack_Q + Part_{N,Q}
   => exists r>0 Field_{N,r,Q} terminal coherence.
```

The current repo has strong classification and face-reduction machinery for all
three branches.  It does not yet have the positive original-data terminal
survival theorem for the Pack branch, and the Part/Field branches depend on the
same source-wall closure.

## Referee Verdict

The no-third-branch law closes the legal branch ambiguity.

This direct attempt does not close the Clay MPP.  It exposes the exact missing
proof:

```text
OriginalSmoothData must prevent the first terminal Pack/Part/Field exit,
with the first concrete wall at ScaleCriticalTreeCarleson.A.
```

Any claim of Clay-ready closure must either prove
`OriginalSmoothData=>ScaleCriticalTreeCarleson.A` and the surviving Part/Field
terminal-service statements, or supply a different noncircular theorem that
rules out genuine CM exit without assuming classical continuation.
