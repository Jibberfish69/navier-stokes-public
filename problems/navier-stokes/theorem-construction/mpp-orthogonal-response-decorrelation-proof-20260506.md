## 1. Heat Response Has No Orthogonal Direction

Consider the pure heat response:

```math
\partial_t u=\nu\Delta u,
\qquad
z=\partial_\nu u.
```

On an exact Fourier mode `\xi`:

```math
\widehat z_\xi(t)
=
-t|\xi|^2 e^{-\nu t|\xi|^2}\widehat u_{0,\xi}
=
-t|\xi|^2\widehat u_\xi(t).
```

Thus `z_\xi` is parallel to `u_\xi`.  On a heat-matched shell:

```math
z_j^{heat}
=
-t\,2^{2j}u_j+Err_j^{width}.
\tag{ORD.2}
```

Therefore:

```math
\boxed{
(z_j^{heat})^\perp=Err_j^{width}.
}
\tag{ORD.3}
```

The orthogonal response is not generated by viscosity itself.  It is generated
by the nonlinear and pressure/cutoff response terms.

## 2. Duhamel Decomposition

The response equation is:

```math
\partial_t z+\mathbb P(u\cdot\nabla z+z\cdot\nabla u)
=
\nu\Delta z+\Delta u.
```

For each shell:

```math
z_j(t)
=
\int_0^t e^{\nu(t-s)\Delta}P_j\Delta u(s)\,ds
-\int_0^t e^{\nu(t-s)\Delta}P_j\mathbb P
(u\cdot\nabla z+z\cdot\nabla u)(s)\,ds.
\tag{ORD.4}
```

The first integral is heat-aligned modulo shell-width and time-variation
errors.  The second integral is the nonlinear response-rotation source:

```math
\mathcal R_j^{rot}(t)
:=
-\int_0^t e^{\nu(t-s)\Delta}P_j\mathbb P
(u\cdot\nabla z+z\cdot\nabla u)(s)\,ds.
\tag{ORD.5}
```

Therefore:

```math
\boxed{
z_j^\perp
=
(\mathcal R_j^{rot})^\perp
+Err_j^{width}
+Err_j^{time}.
}
\tag{ORD.6}
```

## 3. Conditional Orthogonal Decorrelation

Define:

```math
ResponseRotationCharge_N(W)
:=
\int_W\sup_{k>N}
2^k\sum_{\ell>k+4}
\|S_{<\ell}^{loc}\|_{L^\infty}
\|u_\ell\|_2
\|(\mathcal R_\ell^{rot})^\perp\|_2
\,dt.
\tag{ORD.7}
```

Then Cauchy gives:

```math
\left|
2\int\langle S_{<\ell}^{loc}u_\ell,z_\ell^\perp\rangle
\right|
\le
2\|S_{<\ell}^{loc}\|_{L^\infty}
\|u_\ell\|_2\|z_\ell^\perp\|_2.
\tag{ORD.8}
```

Using `(ORD.6)`, legal shell-width/time errors, and summing yields:

```math
\boxed{
ResponseRotationCharge.A
\Longrightarrow
OrthogonalResponseDecorrel.A.
}
\tag{ORD.9}
```

This is rigorous as a conditional theorem: the only non-legal piece is the
nonlinear response-rotation charge `(ORD.7)`.
