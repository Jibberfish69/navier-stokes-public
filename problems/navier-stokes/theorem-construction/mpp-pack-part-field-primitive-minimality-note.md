   the full triad installed;

   law.

That is stronger than "convenient packaging," but weaker than full
model-theoretic pairwise independence.

## Admissible Survivor Family

For this note, a candidate still-live survivor family `\Sigma` is called
**triad-admissible** if it admits realizations on still-live windows `Q` for
which, at every finite depth `N`, some scale `r_N>0` satisfies

```math
\mathrm{CM}_{N,r_N,Q}(u,p,\Phi).
\tag{PMIN.1}
```

Equivalently, `\Sigma` is triad-admissible precisely when it can still be
realized as a lawful same-fluid survivor rather than an already-illegal
class-exit picture.

## Theorem `PMIN.A` (Each law carries an irreducible theorem burden)

On the installed class-membership route, omitting any one primitive law leaves
one exact endpoint-exclusion theorem burden uncontrolled:

```math
\boxed{
\text{omit }\mathrm{Part}
\Longrightarrow
\text{the dead-endpoint burden remains open;}
}
\tag{PMIN.2a}
```

```math
\boxed{
\text{omit }\mathrm{Pack}
\Longrightarrow
\text{the no-blown burden remains open;}
}
\tag{PMIN.2b}
```

```math
\boxed{
\text{omit }\mathrm{Field}
\Longrightarrow
\text{the no-jump burden remains open.}
}
\tag{PMIN.2c}
```

Therefore:

```math
\boxed{
\text{dropping any one of }
\mathrm{Pack},\ \mathrm{Part},\ \mathrm{Field}
\text{ destroys one exact primitive exclusion theorem on the installed route.}
}
\tag{PMIN.3}
```

### Proof

This is exactly the route-noncollapse package
[mpp-pack-part-field-route-noncollapse-note.md](/Users/thomasbirnie/Workspace/ToE/Research-Consolidation/problems/navier-stokes/theorem-construction/mpp-pack-part-field-route-noncollapse-note.md)

Before `NDT.A`, omitting `Part` leaves the dead channel open. After `NDT.A`,
the live frontier is reduced to the surviving Law 1 / Law 3 pair, so omitting
`Pack` leaves the no-blown burden open and omitting `Field` leaves the no-jump
burden open. That is exactly the proof-theoretic irreducibility statement
already isolated on disk. `\square`

## Theorem `PMIN.B` (Lawful survivor families are triad-admissible)

Let `\Sigma` be any candidate still-live survivor family.

Then:

```math
\boxed{
\Sigma\text{ may be treated as a lawful survivor family only if it is triad-admissible in the sense of }(PMIN.1).
}
\tag{PMIN.4}
```

Equivalently,

```math
\boxed{
\text{if every realization of }\Sigma\text{ forces failure of }
\mathrm{Pack},\ \mathrm{Part},\ \text{or }\mathrm{Field},
\text{ then }\Sigma\text{ is already a class-exit picture, not a lawful survivor family.}
}
\tag{PMIN.5}
```

### Proof

This is Proposition `R4A.A` and its body-by-body corollaries read exactly as an
admissibility filter. The reverse four-body audit says that a feared body
surface is lawful only if it admits realization with the exact
class-membership witness installed through every finite depth. If not, it is
already dead/blown/jump class exit rather than a survivor to be controlled.
`\square`

## Theorem `PMIN.C` (No fourth primitive law on lawful survivor families)

On the installed architecture, a candidate fourth primitive law can arise only
in one of two illegitimate ways:

```math
\boxed{
\text{either it fails triad admissibility and is already an illegal class exit,}
}
\tag{PMIN.6a}
```

or

```math
\boxed{
\text{it is merely a downstream consumer readout of }
\neg\mathrm{Pack},\ \neg\mathrm{Part},\ \text{or }\neg\mathrm{Field},
\text{ not a new primitive source-level law.}
}
\tag{PMIN.6b}
```

Hence:

```math
\boxed{
\text{no lawful triad-admissible survivor family needs a fourth primitive source-level law beyond }
\mathrm{Pack},\ \mathrm{Part},\ \mathrm{Field}.
}
\tag{PMIN.7}
```

### Proof

The admissibility alternative `(PMIN.5)` rules out any feared survivor family
that cannot be realized with the triad installed. And `MTS.A` rules out the
other escape hatch: downstream branch defects are consumer readouts of the same
class exit, not new primitive source-level failure families. Combining the two
leaves no lawful source-level fourth law on the still-live survivor side.
`\square`

## What This Does Not Yet Prove

The installed theorem above is still weaker than a full semantic minimality
theorem.

It does **not** yet prove:

1. a model-theoretic realization where two primitive laws hold while the third
   fails;
2. global pairwise independence among `\mathrm{Pack}`, `\mathrm{Part}`,
   `\mathrm{Field}` on all conceivable decompositions;
3. canonical uniqueness of the triad among all source-level factorizations.

So the current result is still route-relative in a precise sense:

```math
\boxed{
\text{the proof runs through the installed still-live admissibility test, the installed endpoint architecture, and the installed branch-consumer boundaries.}
}
\tag{PMIN.9}
```
