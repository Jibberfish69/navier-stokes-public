## 1. Quantitative `TTU.A`

### Theorem `TTU.A_quant`

For the maximal smooth periodic solution generated by `OriginalSmoothData`, every terminal same-fluid approach tail satisfies

```math
OriginalSmoothData
\Longrightarrow
\text{strict averaged-good terminal branch}\vee Jump_{avg}.
```

More quantitatively, let

```math
\mathcal B_{\varepsilon_m}^{\Phi}
:=\{(a,t):\forall r>0,\ SCF_{base}(Q_r^{\Phi}(a,t))>\varepsilon_m\}.
```

Then every terminal tail either admits a finite SCF-good subcover with radii bounded below by some `R_*>0`, or it meets the strict-margin closure of `\mathcal B_{\varepsilon_m}^{\Phi}` and is typed as `Jump_avg`.

### Proof

Finite energy and local suitability give the scale-critical base packet at material-a.e. points. The SCF-good set is open in the same-fluid topology at strict margin. Compact subsets of the strict good region therefore admit finite SCF-good subcovers. Failure of a positive lower radius on the terminal tail is exactly loss of a positive averaged field/coherence scale, hence `Jump_avg` by `CAVG.J`.

## 2. Strict-margin cover degeneration


### Proof

## 4. Common scheduler lemma

### Lemma `SCH.Common`

If, for a finite cover and finite parameter set,

```math
\sum_{i,p}\bigl(1+A_{i,p}+V_i+P_i+F_{i,p}\bigr)\in L^1(0,T_*),
```

then there exists one finite partition of `(0,T_*)` on which every local `AACT.KX` scheduler inequality holds.

### Proof

Set

```math
B(t)=\sum_{i,p}(1+A_{i,p}+V_i+P_i),
\qquad
G(t)=\sum_{i,p}F_{i,p}.
```

Then `B,G in L^1`. Absolute continuity of the integral yields a finite partition into subintervals `J_l` where `\int_{J_l}B` and `\int_{J_l}G` are simultaneously small. Hence for each `i,p`,

```math
\left(\eta_X+\int_{J_l}F_{i,p}\right)
\exp\left(\int_{J_l}(1+A_{i,p}+V_i+P_i)\right)
\le2\eta_X.
```

This is the common scheduler.

## 8. Tower-to-continuation theorem

### Theorem `Tower.Cont`

For `s>5/2`, choose finite depth `N>s+2`. If

```math
\mathfrak A_{N,Q}\in L^\infty(0,T_*),
```

then

```math
\sup_{t<T_*}\|u(t)\|_{H^s(T^3)}<\infty,
```

and the solution extends past `T_*`.

### Proof

The tower bound controls pointwise velocity derivatives through order `N` on a
finite terminal cover. Since `N>s+2`, finite-cover Sobolev patching gives a
uniform `H^s` bound.  With

```math
M_s:=\sup_{t<T_*}\|u(t)\|_{H^s(T^3)}<\infty,
```

periodic \(H^s\) local theory gives a lifespan
\(\tau=\tau(\nu,s,M_s)>0\) for every datum with norm at most \(M_s\).  Choosing
\(t_j\uparrow T_*\) with \(T_*-t_j<\tau/2\), the solution launched from \(u(t_j)\)
exists beyond \(T_*\), and uniqueness identifies it with the original solution
on the overlap.

## 10. Periodic manuscript theorem statement

### Theorem `Periodic.NS.Main`

Let

```math
u>0,
\qquad
u_0\in C^\infty(\mathbb T^3;\mathbb R^3),
\qquad
\nabla\cdot u_0=0,
\qquad
\int_{\mathbb T^3}u_0\,dx=0.
```

Then the incompressible Navier-Stokes system on `T^3`, with zero forcing,

```math
\partial_tu+u\cdot\nabla u+
abla p=\nu\Delta u,
\qquad
\nabla\cdot u=0,
\qquad
u(0)=u_0,
```

has a unique smooth global solution

```math
u\in C^\infty([0,\infty)\times\mathbb T^3).
```

### Route proof

Assume the maximal smooth solution has finite endpoint `T_*`. By `TTU.A_quant`,
the terminal tail is strict averaged-good or `Jump_avg`. The strict branch gives
`DTC.A_avg` by `AACT.Global`; the `Jump_avg` branch is removed by `End_NS_avg`.
The compressed averaged chain gives `End_NS_avg`, and `READ.END_N` gives old
`End_NS` together with the repaired Part response-margin input. The endpoint
matrix then removes every first pointwise endpoint face. `Tower.Cont` gives the
`H^s` continuation contradiction. Therefore `T_*` is infinite.
