# MPP Pressure Quadratic-Defect Native-Carrier Dichotomy

Date: 2026-05-17

Status: independent dichotomy isolated; source-only carrier forcing remains open.

Purpose: continue the pressure/eigenframe branch after `PressureSourceAC.A` failed from installed identities. The requested item was an independent theorem forcing pressure quadratic-gradient defect to live on the native source-current carrier. The source-only theorem fails algebraically; the independent theorem available at this level is a carrier dichotomy.

## 0. Measures

Let

```math
\mu_*^{press-sus}
```

be the pressure-sustain residue extracted from selected positive pressure-Hessian terminal bills.

Let

```math
\nu_*^{src}
```

be the native same-fluid source-current residue, and let

```math
\nu_*^{legal,src}
```

collect legal source-current losses.

Define the source-legal carrier

```math
\Lambda_*^{src}:=\nu_*^{src}+\nu_*^{legal,src}.
```

## 1. Candidate source-only theorem

The desired source-only carrier theorem is

```math
\boxed{
QuadraticDefectSourceDomination.A:
\mu_*^{press-sus}\ll \Lambda_*^{src}.
}
```

The conditional consequence of this source-carrier domination theorem is
`PressureSourceAC.A` on the interior pressure region, and hence
`PressureSustainResidueToSourceResidue.A` there.

## 2. Failure of source-only forcing

The pressure quadratic-gradient carrier is generated by

```math
(S+\Omega)\otimes(S+\Omega),
```

seen through a Calderon-Zygmund pressure-Hessian operator and then through terminal positive selection.

The native source-current carrier is the vorticity-stretching object

```math
|w_j|^2[e_j\cdot S_{<j}^{loc}e_j]_+
```

plus same-fluid ancestry.

These carriers differ. The trace-free symmetric tangent test gives

```math
S=\operatorname{diag}(2,-1,-1),
\qquad
\Omega=0,
```

so the native vorticity source vanishes while the local pressure-Hessian sustain sign is positive:

```math
|\omega|^2[e\cdot Se]_+=0,
\qquad
-n\cdot\nabla^2p\,n=\frac{\operatorname{tr}(S^2)}{3}>0.
```

Therefore pressure quadratic-gradient defect has a component outside the native vorticity source carrier at the level of local identities. Any theorem forcing source-only support needs a new PDE exclusion of this pure-strain pressure component.

## 3. Independent dichotomy theorem

The measure-level theorem available without terminal skew is the Lebesgue decomposition of pressure-sustain residue against the source-legal carrier:

```math
\mu_*^{press-sus}
=
 f\,\Lambda_*^{src}
+
\mu_*^{press\perp src},
\qquad
\mu_*^{press\perp src}\perp \Lambda_*^{src}.
```

This gives the independent dichotomy

```math
\boxed{
PressureQuadraticCarrierDichotomy.A:
\mu_*^{press-sus}(E)>0
\Longrightarrow
\Lambda_*^{src}(E)>0
\quad\text{or}\quad
\mu_*^{press\perp src}(E)>0.
}
```

The first branch is the desired source-wall branch. The second branch is a pure pressure-source singular residue relative to the native source-current carrier.

## 4. Source-forcing corollary under a new exclusion theorem

If one proves

```math
\boxed{NoPurePressureSourceSingularResidue.A:
\mu_*^{press\perp src}=0,}
```

then the dichotomy yields

```math
\mu_*^{press-sus}>0
\Longrightarrow
\Lambda_*^{src}>0.
```

Thus

```math
PressureQuadraticCarrierDichotomy.A
+NoPurePressureSourceSingularResidue.A
\Longrightarrow
PressureSourceAC.A.
```

## 5. Verdict

The independent source-only theorem was not found. The strongest noncircular theorem at this level is the carrier dichotomy above.

The pressure branch has therefore split into two exact branches:

```math
\text{source-carried pressure residue}
\quad\Rightarrow\quad
\text{ordinary source-wall/Zeno machinery},
```

and

```math
\text{pure pressure-source singular residue}
\quad\Rightarrow\quad
\text{new legal classification or Liouville theorem required}.
```

This sets the next item precisely: decide whether `\mu_*^{press\perp src}` is a legal pressure residue class, or whether it requires a new Liouville theorem.
