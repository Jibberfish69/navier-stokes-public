## Principal Packet Equation

On a localized high-frequency packet, write the shell equation as

```math
(\partial_t+u_{\le k}\cdot\nabla-\nu\Delta)u_j
=
-S_ku_j+R_{j,k},
```

where

```math
S_k=\frac12(\nabla u_k+\nabla u_k^T),
```

and `R_{j,k}` contains commutators, pressure errors, cutoffs, and off-packet
interactions.

Move the strain into the principal operator:

```math
L_{j,k}u_j
:=
(\partial_t+b_k\cdot\nabla-\nu\Delta-A_k)u_j
=
R_{j,k}.
\tag{P}
```

Here `b_k=u_{\le k}` and `A_k` is the symmetric strain-production matrix with the
sign convention chosen so that `-A_ku_j` equals the retained principal strain
term.  Equivalently one may take `A_k=-S_k` in the display above.

This is the decisive bookkeeping move.  Positive strain alignment is no longer
an external source term; it is part of the packet propagator.

## Adjoint Packet Identity

For each positive-alignment tile `T`, construct a backward adjoint packet
`\psi_T` solving

```math
L_{j,k}^*\psi_T
=
-\partial_t\psi_T-b_k\cdot\nabla\psi_T-\nu\Delta\psi_T-A_k^*\psi_T
=0
```

on `T`, with terminal packet data at the forward face.  Pairing `(P)` with
`\psi_T` gives

```math
\frac{d}{dt}\langle u_j,\psi_T\rangle
=
\langle R_{j,k},\psi_T\rangle.
```

Thus the principal positive strain disappears from the forcing identity.  It
only changes the backward propagation and normalization of `\psi_T`.

Integrating across the tile,

```math
\langle u_j(t_+),\psi_T(t_+)\rangle
=
\langle u_j(t_-),\psi_T(t_-)\rangle
+
\int_{t_-}^{t_+}\langle R_{j,k},\psi_T\rangle\,dt.
\tag{A}
```

## Parent-Or-Charge Dichotomy

Let `S(T)` denote the positive strain-alignment source mass selected on tile
`T`.  Identity `(A)` gives two legal origins for `S(T)`.

The following display is the parent-or-charge form.  In the active
weighted route, this is replaced by the normalized child mass

```math
M(T)=g_T^{-2}|\langle u_j(t_+),\psi_T(t_+)\rangle|^2
```

and the normalized parent kernel defined from `\chi_T=g_T^{-1}\psi_T`.

If the residual pairing is large:

```math
\left|
\int_{t_-}^{t_+}\langle R_{j,k},\psi_T\rangle\,dt
\right|^2
\ge
c_{res}
S(T),
```

then the tile is charged by dissipation:

```math
S(T)\le C D(T)+Err(T).
```

If the residual pairing is small, then the packet must have a backward parent:

```math
|\langle u_j(t_-),\psi_T(t_-)\rangle|^2
\ge
c_{par}
|\langle u_j(t_+),\psi_T(t_+)\rangle|^2.
```

The finite-scale theorem target is therefore:

```math
\boxed{
S(T)
\le
\theta D(T)
+
\sum_{P\prec T}\kappa(P,T)S(P)
+
Err(T).
}
\tag{POC}
```

The parent relation `P\prec T` is generated by the backward adjoint packet
`\psi_T`.

## Backward Iteration

Iterating `(POC)` backward gives

```math
S(T_0)
\le
\theta\sum_{T\preceq T_0}D(T)
+
\sum_{P_m\prec\cdots\prec T_0}\kappa_m S(P_m)
+
\sum_{T\preceq T_0}Err(T).
```

In a first-pulse ancient limit, the backward parent term vanishes because there
is no earlier source-residue packet.  Thus

```math
S(T_0)
\le
\theta\sum_{T\preceq T_0}D(T)
+
o(1).
```

This is the desired drain sublemma behind Lemma B.

## Core Square Estimate

The exact analytic burden is the residual-pairing bound

```math
\boxed{
\sum_T
\left|
\int_{I_T}\langle R_{j,k},\psi_T\rangle\,dt
\right|^2
\le
C\int\sum_{q>N}D_q
+
o_N(1).
}
\tag{AdjRes}
```

Once `(AdjRes)` is proved, positive strain alignment has only two legal origins:

```math
\text{earlier parent mass}
\qquad\text{or}\qquad
\text{paid residual creation}.
```

The first-pulse hypothesis removes the parent chain, leaving only the
dissipation charge.

## Duality Proof Plan For `(AdjRes)`

Prove `(AdjRes)` by duality.  For arbitrary coefficients `c_T` satisfying

```math
\sum_T |c_T|^2=1,
```

define the combined adjoint packet

```math
\Psi=\sum_T c_T\psi_T.
```

Then

```math
\sum_T c_T
\int_{I_T}\langle R_{j,k},\psi_T\rangle\,dt
=
\int \langle R,\Psi\rangle\,dt.
```

It is enough to prove:

```math
\|R\|_{L_t^2H_x^{-1}}^2
\le
C\int\sum_{q>N}D_q+o_N(1),
\tag{R-H-1}
```

and

```math
\|\Psi\|_{L_t^2H_x^1}^2
\le
C.
\tag{Adj-Bessel}
```

Then

```math
\left|\int\langle R,\Psi\rangle\,dt\right|
\le
\|R\|_{L_t^2H_x^{-1}}
\|\Psi\|_{L_t^2H_x^1}
\le
C\left(\int\sum_{q>N}D_q+o_N(1)\right)^{1/2}.
```

Taking the supremum over `c_T` gives `(AdjRes)`.

### Residual `H^{-1}` Estimate

Decompose

```math
R=R^{comm}+R^{press}+R^{cut}+R^{off}.
```

The target termwise estimates are:

```math
\|R^{comm}\|_{H^{-1}}^2
\le
C_{comm}
D_j
```

by Coifman--Meyer commutator bounds;

```math
\|R^{press}\|_{H^{-1}}^2
\le
C_{press}
D_j
```

by Calderon--Zygmund pressure recovery and local pressure normalization;

```math
\|R^{cut}\|_{H^{-1}}^2
\le
C_{cut}
\nu\|\nabla w_j\|_2^2
```

by heat-scale cutoff absorption; and

```math
\sum_{j>N}\|R_j^{off}\|_{H^{-1}}^2=o_N(1)
```

by shell separation and terminal-tail localization.

Together:

```math
\|R\|_{L_t^2H_x^{-1}}^2
\le
C\int\sum_{q>N}D_q+o_N(1).
```

These estimates remain proof obligations; the note records the exact required
norm and decomposition.

### Adjoint Packet Bessel Bound

The first packet-calculus gate is now coefficient stopping followed by
`WeightedAdjBessel.A`, not uniform strain-gain control.  The coefficient
stopping surface is
`mpp-coefficient-stopping-for-strain-gauged-packets-note-20260504.md`; after
extracting the affine low-flow frame and central strain gauge, it stops tiles
whose remaining coefficient budget
`r_T^2\nabla^2b_k+r_T\nabla A_k` is too large and sends them to residual charge
or earlier source-pulse ancestry.
The weighted Bessel surface is
`mpp-adjbessel-strain-gauge-packet-calculus-note-20260504.md`.  The route drops
uniform `G_T` control and sends the growth factor into `ParentKernel.A`.
`ResidualPair.A` is mostly Calderon--Zygmund / commutator bookkeeping once the
coefficient-stopped weighted adjoint packet frame is valid.

#### Gauge out the central strain

For a tile `T`, let `X_T(t)` follow the low flow:

```math
\dot X_T(t)=b_k(X_T(t),t).
```

Let `G_T(t)` solve the matrix ODE

```math
\dot G_T(t)=\mathcal A_T(t)G_T(t),
\qquad
G_T(t_+)=I.
```

Here `\mathcal A_T` is `A_k(X_T,t)` with the sign and transpose dictated by the
adjoint convention.  For the displayed adjoint
`-\partial_t-b_k\cdot\nabla-\nu\Delta-A_k^*`, this is equivalently the matrix
coefficient that cancels the central `A_k^*(X_T,t)` term in the equation for
`\psi_T`.  The Bessel issue is independent of this sign convention; it depends
on the growth factor controlled by `\int_{I_T}|A_k(X_T,t)|dt`.

Write

```math
\psi_T(x,t)=G_T(t)\varphi_T(x,t).
```

Let `J_T` solve the linearized low-flow equation

```math
\dot J_T=(\nabla b_k)(X_T,t)J_T,
\qquad
J_T(t_+)=I.
```

Then `\varphi_T` solves an adjoint affine heat-transport equation whose
remaining coefficients are only the affine low-flow remainder

```math
b_k(x,t)-b_k(X_T,t)-\nabla b_k(X_T,t)(x-X_T)
```

and the oscillatory strain remainder

```math
A_k(x,t)-A_k(X_T(t),t).
```

On a `j`-scale packet,

```math
|x-X_T(t)|\le c_T 2^{-j}.
```

Since `k<j-M`, the stopped coefficient budget controls

```math
|A_k(x,t)-A_k(X_T(t),t)|
\le
C_A
r_T\|\nabla A_k(t)\|_{L^\infty(Q_T^*)},
```

and

```math
|b_k(x,t)-b_k(X_T,t)-\nabla b_k(X_T,t)(x-X_T)|
\le
C_b
r_T^2\|\nabla^2b_k(t)\|_{L^\infty(Q_T^*)}.
```

Coefficient stopping turns these affine-frame remainders into an
`C\varepsilon_M` perturbation inside the heat-scale packet calculus.

#### Packet stability

On coefficient-good tiles, the gauged packet should solve

```math
(-\partial_t-b_k\cdot\nabla-\nu\Delta)\varphi_T
=
\mathcal E_T\varphi_T,
\qquad
\|\mathcal E_T\|_{L_t^1(H_x^1\to H_x^{-1})}\le C\varepsilon_M.
```

Duhamel against the affine heat propagator `H_T` associated to `(X_T,J_T)`
should give

```math
|\partial_x^\alpha\varphi_T(x,t)|
\le
C_\alpha
r_T^{-3/2-|\alpha|}
\exp\left(-c\frac{|x-X_T(t)|^2}{r_T^2}\right).
```

The perturbative error should be bounded by `C\varepsilon_M` after coefficient stopping
and after choosing the scale gap `M` large enough.

#### TT* Bessel bound

For the gauged packets, prove almost-orthogonality:

```math
|\langle \varphi_T(t),\varphi_{T'}(t)\rangle|
\le
C
\exp(-c\,d(T,T')^2).
```

For gradients, prove the heat-time version:

```math
\int_{I_T\cap I_{T'}}
\langle \nabla\varphi_T,\nabla\varphi_{T'}\rangle\,dt
\le
C
\exp(-c\,d(T,T')^2).
```

Cotlar--Stein then gives

```math
\left\|\sum_T c_T\varphi_T\right\|_{L_t^2H_x^1}^2
\le
C\sum_T|c_T|^2.
```

Transferring back to `\psi_T=G_T\varphi_T` requires the decisive
strain-amplification condition

```math
\sup_T\|G_T\|\,\|G_T^{-1}\|\le C,
```

which follows from the sufficient bound

```math
\boxed{
\int_{I_T}|A_k(X_T(t),t)|\,dt\le C.
}
\tag{GT}
```

With `(GT)`, the desired adjoint packet calculus says the packet remains
localized, its frequency remains in the `j`-shell up to fixed collars, and
parabolic smoothing gives

```math
\sup_t
\sum_T|\langle f,\psi_T(t)\rangle|^2
\le
C\|f\|_2^2,
```

plus

```math
\int\|\nabla\Psi(t)\|_2^2\,dt
\le
C\sum_T|c_T|^2
=C.
```

Hence

```math
\|\Psi\|_{L_t^2H_x^1}^2\le C.
```

This is the optional unweighted `AdjBessel.A`.  The nontrivial point is
controlling the growth and anisotropy induced by the symmetric strain coefficient
`A_k`; in the primary route that growth is retained as the weight `g_T` and sent
to `ParentKernel.A`, not hidden in a harmless constant.

#### Weighted route and parent kernel

The primary route is the weighted Bessel statement:

```math
\left\|
\sum_T c_Tg_T^{-1}\psi_T
\right\|_{L_t^2H_x^1}^2
\le
C\sum_T|c_T|^2,
```

where

```math
g_T
=
\exp\left(\int_{I_T}\lambda_{\max}^{+}(A_k(X_T(t),t))\,dt\right).
```

Normalize child mass by the same gain:

```math
M(T):=
g_T^{-2}
|\langle u_j(t_+),\psi_T(t_+)\rangle|^2.
```

Then the backward-face parent kernel is the normalized overlap

```math
\kappa(P,T):=
|\langle \phi_P,\chi_T(t_-)\rangle|^2,
\qquad
\chi_T=g_T^{-1}\psi_T.
```

The live `ParentKernel.A` is the contraction theorem for surviving quiet
inherited edges.  In amplified-transfer form,

```math
K(P,T)=g_T^2|\langle\phi_P,\chi_T(t_-)\rangle|^2,
```

and, after pruning gain-stop edges,

```math
\sum_{T:P\prec T}K(P,T)\le(1-\delta)S(P).
```

The new concrete theorem inside this gate is `GainStop.A`: if
`2\Gamma_T>2h_T-\eta_0`, then the edge produces residual charge or an earlier
source-pulse tile, so it cannot remain in the inherited first-pulse kernel.  The
stopping-time theorem is isolated in
`mpp-gainstop-stopping-time-theorem-note-20260504.md`.

Uniform `(GT)` remains only an optional shortcut to the unweighted route.

## Required Analytic Licenses

The principal-flow adjoint route still requires the following non-bookkeeping
proofs.

1. `CoeffStop.A`: split tiles by the affine-frame coefficient budget
   `\mathcal C(T)=\int(r_T^2\|\nabla^2b_k\|_\infty+
   r_T\|\nabla A_k\|_\infty)dt`; prove coefficient stops become weighted
   residual charge or earlier source-pulse ancestry.

2. `AdjPacket.A`: construct adjoint wave packets for
   `\partial_t+u_{\le k}\cdot\nabla-\nu\Delta+S_k` on same-fluid heat-scale
   tiles, with localization and terminal normalization compatible with the
   positive-alignment packet frame.

3. `WeightedAdjBessel.A`: prove the strain-gauged weighted Bessel estimate for
   `g_T^{-1}\psi_T`, including the growth/anisotropy induced by the non-skew
   strain coefficient `A_k` on coefficient-good tiles.

4. `ResidualPair.A`: decompose `R_{j,k}` into commutator, pressure, cutoff, and
   off-packet pieces and prove the square pairing estimate `(AdjRes)`.

5. `ParentKernel.A`: prove contraction for surviving quiet inherited edges and
   prove `GainStop.A` so high-gain edges become residual charge or earlier
   source-pulse ancestry.

6. `FirstPulseKill.A`: prove the first-pulse ancient limit removes the terminal
   backward parent term rather than hiding it as incoming mass from `s=-\infty`.
