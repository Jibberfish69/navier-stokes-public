## Exact Claim

### Candidate Theorem RW.A (reference-comparison propagation)

Fix a compactly supported material packet `\psi`, a finite depth `N`, a time
interval `I`, and a scale window `0<|r|\le \rho`.

Assume the PDE-native Eulerian defect engine propagates the packet-generated
reference comparison density `\mathfrak e^{ref}_{N,r,\psi}(a,t)` on the
reference range family from `(RS.5)`--`(RS.7)` throughout `I`.

Then the propagated packetized reference comparison class satisfies

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)<\infty.
\tag{RW.3}
```

This is a candidate theorem shape. The unresolved burden is to extract this
packet-side reference comparison control directly from the Eulerian defect
engine carried by `(TC.18)`--`(TC.21)` and `(MP.12)`.

### Candidate Theorem RW.B (weighted-segment propagation)

Assume, on the same interval `I`, that:

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
P_F^\ast(r,t;\psi)<\infty,
\tag{RW.4}
```

```math
\sup_{t\in I}A_F(t;\psi)<\infty,
\tag{RW.5}
```

and that the packet-side next-rung control driven by the exact source
`\mathcal Q_{1,r,\psi}^{str}` remains finite along the weighted bridge segments
from `(RS.10)`.

Then the weighted-segment packet satisfies

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
\mathcal M^{wseg}_{N+1,r,\psi}(t)<\infty.
\tag{RW.6}
```

This is also a candidate theorem shape. The unresolved burden is to turn the
rung-1 material source control into the next-rung weighted-segment control
required by `(RS.10)`.

### Candidate Corollary RW.C (handoff to closure packaging)

If `(RW.3)` and `(RW.6)` both hold, and the packet-side bounds `(RW.4)`--`(RW.5)`
hold as well, then the downstream closure-packaging note applies and yields

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
\widetilde E_{N,r,\psi}(t)<\infty,
\tag{RW.7}
```

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
P_F(r,t;\psi)<\infty,
\tag{RW.8}
```

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
\widetilde{\mathcal H}_{N,r,\psi}(t)<\infty.
\tag{RW.9}
```

So this note isolates the true upstream burden for the current branch: it is
not the closure packaging itself, but the interval propagation of the two live
reduction quantities.

## Proof Skeleton

PDE-native coercivity enters through the Eulerian defect engine from
`(TC.18)`--`(TC.21)` and `(MP.12)`:

1. `+2\nu D_N`;
2. the corrected pressure split;
3. the strain/cascade hierarchy;
4. the cutoff commutator packet.

Bridge geometry enters through packet distortion and relative packing control:

1. `A_F` keeps the packet inside a finite distortion class;
2. `P_F^\ast` controls the relative-packing bridge windows;
3. `\mathcal Q_{1,r,\psi}^{str}` is the exact rung-1 material source feeding
   that relative-packing control.

The propagation hierarchy to be discharged is therefore:

```math
\mathcal Q_{1,r,\psi}^{str}
\Longrightarrow
\text{relative-packing control}
\Longrightarrow
P_F^\ast,
\tag{RW.10}
```

```math
E_N
\Longrightarrow
\text{packet-generated reference comparison control}
\Longrightarrow
\widehat{\mathcal E}^{ref}_{N,r,\psi},
\tag{RW.11}
```

```math
\mathcal Q_{1,r,\psi}^{str},\ P_F^\ast,\ A_F
\Longrightarrow
\text{packet-side next-rung segment control}
\Longrightarrow
\mathcal M^{wseg}_{N+1,r,\psi}.
\tag{RW.12}
```

Once `(RW.11)` and `(RW.12)` are discharged, the downstream closure-packaging
theorem applies as written.

The exact identities and inequalities on disk already cover the downstream
reduction step. The open part is the interval propagation of the two live
reduction quantities.
