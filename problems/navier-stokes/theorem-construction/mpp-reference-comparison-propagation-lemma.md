# MPP Reference-Comparison Propagation Lemma

## Status

Candidate theorem-facing split propagation note.

Role: exact `RW.A` surface for propagating the packetized reference-comparison
envelope from the PDE-native Eulerian defect engine.

This note sits underneath
`mpp-reference-and-weighted-segment-propagation-lemma.md`
and isolates only the reference-comparison side of the live propagation burden.

## Purpose

The exact burden here is:

```math
\boxed{
\text{propagate }\mathfrak e^{ref}_{N,r,\psi}(a,t)
\text{ and }\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)
\text{ from the Eulerian defect engine.}
}
\tag{RC.0}
```

The key structural point is that this is a genuinely local packet-generated
comparison problem, not merely a family of scalar fixed-increment energy bounds.

## Setup

Retain the live reference-range objects from the reduction note:

```math
\mathcal R_r^{ref}(t;\psi)
:=
\big\{
F(a,t)r:a\in\operatorname{supp}\psi
\big\},
\tag{RC.1}
```

```math
\mathfrak e^{ref}_{N,r,\psi}(a,t)
:=
\sup_{\eta\in\mathcal R_r^{ref}(t;\psi)}
\sum_{k=0}^{N}\lambda_k
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2,
\tag{RC.2}
```

```math
\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)
:=
\int \psi(a)^2\,\mathfrak e^{ref}_{N,r,\psi}(a,t)\,da.
\tag{RC.3}
```

For a scale window `0<|r|\le \rho`, define the local scale-window reference
density

```math
\mathfrak e^{ref}_{N,\rho,\psi}(a,t)
:=
\sup_{0<|r|\le \rho}\mathfrak e^{ref}_{N,r,\psi}(a,t),
\tag{RC.4}
```

and the corresponding integrated packet

```math
\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t)
:=
\int \psi(a)^2\,\mathfrak e^{ref}_{N,\rho,\psi}(a,t)\,da.
\tag{RC.5}
```

## Exact Theorem Shape

### Candidate Theorem RC.A (reference-comparison propagation)

Fix a compactly supported material packet `\psi`, a finite depth `N`, a time
interval `I`, and a scale window `0<|r|\le \rho`.

Assume the PDE-native Eulerian defect engine generated by `(TC.18)`--`(TC.21)`
and `(MP.12)` propagates the packet-generated local reference density
`\mathfrak e^{ref}_{N,\rho,\psi}(a,t)` on `I`.

Then

```math
\sup_{t\in I}\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t)<\infty.
\tag{RC.6}
```

Equivalently,

```math
\sup_{t\in I}\sup_{0<|r|\le \rho}
\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)<\infty.
\tag{RC.7}
```

This is the exact `RW.A` burden in packet form.

The concrete next-step local-envelope surface for this burden is
`mpp-local-eulerian-reference-envelope-lemma.md`.

## Exact Sufficient Interface

The theorem above becomes concrete once one has an Eulerian-side local envelope
dominating every packet-generated reference increment.

### Lemma RC.B (local Eulerian envelope suffices)

Assume there exists a nonnegative density

```math
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)
\tag{RC.8}
```

such that for a.e. `a` and all `0<|r|\le \rho`,

```math
\sup_{\eta\in\mathcal R_r^{ref}(t;\psi)}
\sum_{k=0}^{N}\lambda_k
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2
\le
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t),
\tag{RC.9}
```

and

```math
\sup_{t\in I}
\int \psi(a)^2\,
\mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)\,da
<\infty.
\tag{RC.10}
```

Then `(RC.6)`--`(RC.7)` follow.

### Proof

From `(RC.9)`, one has
`\mathfrak e^{ref}_{N,\rho,\psi}(a,t)\le \mathfrak e^{Eul,ref}_{N,\rho,\psi}(a,t)`
for a.e. `a`. Integrating against `\psi(a)^2\,da` and taking the supremum in
`t\in I` gives `(RC.6)`. Taking the supremum of `(RC.6)` in `r` using `(RC.4)`
gives `(RC.7)`. ∎

## No-Shortcut Warning

The live burden is genuinely local. A family of scalar fixed-increment packet
energies is not, by itself, the same thing.

Let

```math
E_N(\eta,t;\psi)
=
\sum_{k=0}^{N}\lambda_k
\int \psi(a)^2
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2\,da.
\tag{RC.11}
```

and write the packet-generated scale-window reference increment class as

```math
\mathcal R_{\rho}^{ref}(t;\psi)
:=
\bigcup_{0<|r|\le \rho}\mathcal R_r^{ref}(t;\psi).
\tag{RC.11a}
```

Then in general one only has

```math
\sup_{\eta\in \mathcal R_{\rho}^{ref}(t;\psi)}E_N(\eta,t;\psi)
\le
\widehat{\mathcal E}^{ref}_{N,\rho,\psi}(t)
\tag{RC.12}
```

in the favorable direction, not the reverse. So the live burden is still
stronger than propagating a family of fixed-increment packet energies, because
the packet-generated local comparison density `(RC.4)` retains the
`a`-dependent local supremum before integration.

That is why `RW.A` is a real theorem burden rather than a notational corollary.
