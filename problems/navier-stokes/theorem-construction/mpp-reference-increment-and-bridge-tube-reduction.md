# MPP Reference-Increment And Bridge-Tube Reduction

## Status

Auxiliary geometric unpacking note.

Role: auxiliary geometry surface for the residual reference-increment and
bridge-tube window objects.

This note is not the live reduction surface.
The live packet-facing reduction note is
`mpp-reference-increment-and-segment-packet-reduction.md`.

This note does **not** yet propagate the transported packet. Its job is to make
the two residual quantities in `(IS.13)` explicit and geometric instead of
leaving them hidden inside the increment-stability bridge.

## Purpose

After the live quantitative bridge

```math
\widetilde E_{N,r,\psi}(t)
\le
2\,\mathcal E^{ref}_{N,r,\psi}(t)
+
2\,|r|^2\,P_F^\ast(r,t;\psi)\,\mathcal M^{seg}_{N+1,r,\psi}(t),
\tag{RT.0}
```

the branch still carries two unresolved objects:

```math
\mathcal E^{ref}_{N,r,\psi}(t),
\qquad
\mathcal M^{seg}_{N+1,r,\psi}(t).
\tag{RT.1}
```

The purpose here is to expose them exactly as Eulerian window objects.

## Setup

Retain the packet/bridge notation:

```math
x(a,t):=X(a,t),
\qquad
\eta_\ast(a,r,t):=F(a,t)r,
\qquad
\varepsilon_h(a,r,t):=h(a,r,t)-F(a,t)r.
\tag{RT.2}
```

The residual geometric sets are:

```math
\mathcal R_r^{ref}(t;\psi)
:=
\big\{
F(a,t)r:a\in \operatorname{supp}\psi
\big\},
\tag{RT.3}
```

and

```math
\mathcal T_r^{bridge}(t;\psi)
:=
\big\{
x(a,t)+F(a,t)r+\theta \varepsilon_h(a,r,t):
a\in\operatorname{supp}\psi,\ \theta\in[0,1]
\big\}.
\tag{RT.4}
```

These are exactly the reference-increment set and the bridge tube generated by
the packet.

## 1. Reference-Increment Reduction

Recall the reference-increment packet

```math
\mathcal E^{ref}_{N,r,\psi}(t)
:=
\sum_{k=0}^{N}\lambda_k
\int \psi(a)^2
\big|
\delta_{F(a,t)r}U_k(X(a,t),t)
\big|^2\,da.
\tag{RT.5}
```

Define the Eulerian reference comparison packet

```math
\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)
:=
\int \psi(a)^2
\sup_{\eta\in\mathcal R_r^{ref}(t;\psi)}
\sum_{k=0}^{N}\lambda_k
\big|
\delta_\eta U_k(X(a,t),t)
\big|^2\,da.
\tag{RT.6}
```

### Lemma RT.A

For every finite depth `N`, packet `\psi`, label increment `r`, and time `t`,

```math
\mathcal E^{ref}_{N,r,\psi}(t)
\le
\widehat{\mathcal E}^{ref}_{N,r,\psi}(t).
\tag{RT.7}
```

### Proof

For each fixed `a`, the increment `F(a,t)r` belongs to
`\mathcal R_r^{ref}(t;\psi)`. So the pointwise integrand in `(RT.5)` is bounded
by the supremum defining `(RT.6)`. Integrating against `\psi(a)^2\,da` gives
`(RT.7)`. ∎

## 2. Bridge-Tube Reduction

Recall the segment envelope from the increment-stability bridge:

```math
\mathcal M^{seg}_{N+1,r,\psi}(t)
:=
\sup_{a\in\operatorname{supp}\psi}
\int_0^1
\sum_{k=0}^{N}\lambda_k
\big|
U_{k+1}\big(x(a,t)+F(a,t)r+\theta\varepsilon_h(a,r,t),t\big)
\big|^2\,d\theta.
\tag{RT.8}
```

Define the exact bridge-tube envelope

```math
\mathfrak M^{tube}_{N+1,r,\psi}(t)
:=
\sup_{y\in\mathcal T_r^{bridge}(t;\psi)}
\sum_{k=0}^{N}\lambda_k |U_{k+1}(y,t)|^2.
\tag{RT.9}
```

### Lemma RT.B

For every finite depth `N`, packet `\psi`, label increment `r`, and time `t`,

```math
\mathcal M^{seg}_{N+1,r,\psi}(t)
\le
\mathfrak M^{tube}_{N+1,r,\psi}(t).
\tag{RT.10}
```

### Proof

Every point of the form
`x(a,t)+F(a,t)r+\theta\varepsilon_h(a,r,t)` with
`a\in\operatorname{supp}\psi` and `\theta\in[0,1]` belongs to
`\mathcal T_r^{bridge}(t;\psi)`. So the integrand in `(RT.8)` is pointwise
bounded by `\mathfrak M^{tube}_{N+1,r,\psi}(t)`, and averaging in `\theta`
preserves that bound. Taking the supremum in `a` gives `(RT.10)`. ∎

## 3. Reduced Increment-Stability Bridge

Combining `(RT.7)` and `(RT.10)` with `(RT.0)` yields the fully reduced bridge:

### Theorem RT.C

```math
\widetilde E_{N,r,\psi}(t)
\le
2\,\widehat{\mathcal E}^{ref}_{N,r,\psi}(t)
+
2\,|r|^2\,P_F^\ast(r,t;\psi)\,\mathfrak M^{tube}_{N+1,r,\psi}(t).
\tag{RT.11}
```

That is the exact reduction of the two residual objects from `(IS.13)` to
explicit Eulerian window quantities.

## Interpretation

The branch is now fully explicit about its remaining unresolved quantities:

1. `\widehat{\mathcal E}^{ref}_{N,r,\psi}` is the reference-increment
   comparison packet;
2. `\mathfrak M^{tube}_{N+1,r,\psi}` is the bridge-tube envelope;
3. together with `P_F^\ast`, they are the only residual inputs in the current
   quantitative control of `\widetilde E_{N,r,\psi}`.

So the exact remaining theorem burden is no longer hidden:

```math
\boxed{
\text{propagate the reference packet and the bridge-tube envelope on the same material packet.}
}
\tag{RT.12}
```
