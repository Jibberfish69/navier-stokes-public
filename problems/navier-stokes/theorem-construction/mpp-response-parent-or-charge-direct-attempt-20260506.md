## 1. Duhamel Parent Expansion

The orthogonal response rotation is generated by:

```math
\mathcal R_j^{rot}(t)
=
-\int_{-\infty}^t e^{\nu(t-s)\Delta}P_j\mathbb P
(u\cdot\nabla z+z\cdot\nabla u)(s)\,ds.
```

Pair it against the terminal response-rotation test packet `\psi_T`:

```math
S_{resp}(T)
=
\left[
\int
\langle S_{<j_T}u_{j_T},(\mathcal R_{j_T}^{rot})^\perp\rangle
\psi_T
\right]_+.
```

Move the heat kernel backward onto the terminal test packet:

```math
\Psi_T(s)
=
e^{\nu(t_T-s)\Delta}P_{j_T}\mathbb P^\ast \psi_T.
```

Then:

```math
S_{resp}(T)
\le
\left[
\int_{s<t_T}
\langle u\cdot\nabla z+z\cdot\nabla u,\Psi_T(s)\rangle ds
\right]_+
+Err_{legal}(T).
\tag{RPC.2}
```

Decompose the spacetime support of `\Psi_T` into earlier same-fluid tiles
`P\prec_{resp}T`.  This yields:

```math
S_{resp}(T)
\le
\sum_{P\prec_{resp}T}
K_{resp}(P,T)S_{resp}(P)
+Charge_{resp}(T)
+Err_{legal}(T),
\tag{RPC.3}
```

provided the adjoint kernel is positive/flattened enough that bad sign changes
and off-tree pieces are legal.

## 2. Proved Formal Reduction

### Theorem `ResponseAdjointTreeReduction.A`

Assume:

```text
1. ResponseAdjointKernelFlattening.A:
   the backward heat/pressure packet paired with T decomposes into same-fluid
   parent tiles plus legal off-tree errors;

2. ResponseKernelSignControl.A:
   one-sided positive parts can be assigned to parent response masses without
   losing an uncontrolled absolute-value envelope;

3. ResponseLocalCharge.A:
   same-tile and off-scale response source pieces are bounded by response
   height, pressure/cutoff response charge, or legal loss.
```

Then `ParentOrCharge_resp.A` holds.

### Proof

Start from `(RPC.2)`.  Use `ResponseAdjointKernelFlattening.A` to partition
the adjoint packet into parent tiles and legal off-tree remainders.  Use
`ResponseKernelSignControl.A` to keep only the parent positive response mass
rather than taking absolute values over the full source.  Use
`ResponseLocalCharge.A` for the same-tile, near-scale, pressure, and cutoff
remainders.  This gives `(RPC.3)`, which is `(RPC.1)` after renaming the
kernel weights.  `\square`

## 3. Direct Closure Test

right side becomes:

alone.  It needs a signed/positive adjoint tree structure for the response
source.
