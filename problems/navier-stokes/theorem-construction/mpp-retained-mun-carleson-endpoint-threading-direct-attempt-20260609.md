# MPP Retained MuN Carleson Endpoint Threading Direct Attempt

## Status

`RetainedMuNCarlesonEndpointThreading.A` is not proved by the current theorem
stack.

This pass tests whether the absorbed fixed shell-pair estimate or the
`\mu_N` / `\nu_N` measure surfaces already give the weighted endpoint theorem
`(EP)` needed for the positive affine endpoint mass.

## Target

The current endpoint theorem is

```math
\int_0^T H_w(t)\|M_0(t)\|_{L_x^2}^2\,dt
\le
\frac{\eta\nu}{C}\int_0^TD_N(t)\,dt+C_*2^{-2\delta N}.
\tag{EP}
```

The absorbed fixed shell-pair estimate has the form

```math
\sum_{m\in\mathcal B_I(N)}
\sum_{j\in\mathcal B_J(N)}
|\mathcal C_{m,j}(t)|
\le
\varepsilon\nu D_N(t)
+
C\widetilde\Lambda_N^\sharp(t)E_N(t).
\tag{SP}
```

The measure surface is

```math
d\mu_N(t)=\widetilde\Lambda_N^\sharp(t)E_N(t)\,dt,
\qquad
d\nu_N(t)=\widetilde\Lambda_N^\sharp(t)\,dt.
```

The desired threading is:

```math
\text{(SP) or }\mu_N/\nu_N\text{ control}
\Longrightarrow
\text{(EP)}.
```

## Direct shell-pair threading test

The shell-pair estimate `(SP)` controls a commutator pairing:

```math
\langle[\Delta_j,\Delta_m u\cdot\nabla]\Delta_j u,\Delta_j u\rangle.
```

The endpoint theorem `(EP)` controls the positive accumulated stress mass:

```math
M_0(t)=\int_J\widetilde Z(\sigma,t)\,d\sigma.
```

These are not the same object. The commutator pairing has cancellation and a
velocity-gradient slot. The endpoint mass is positive and square-integrated
after scale accumulation. A theorem-grade comparison would need to prove that
the endpoint mass generated by the positive stress source is dominated by the
absorbed commutator family, or by the direct finite-collar bilinear packet

```math
\sum_{m\in\mathcal B_I(N)}\sum_{j\in\mathcal B_J(N)}
E_m^{1/2}2^{-j/2}D_j.
```

No installed note proves this comparison. The current notes only show that the
coefficient-bearing shell-pair packet lands on `\varepsilon\nu D_N+\mu_N`.
They do not show that the positive endpoint mass itself is recovered from that
packet.

## Carleson measure test

The upgraded gradient interface gives the interval implication:

```math
\mu_N(I)
\le
\frac{\varepsilon_\mu\nu}{C}\int_ID_N(t)\,dt+C_{\mu,*}2^{-2\delta N}
\Longrightarrow
\text{absorbed interval gradient inequality}.
```

This is a correct downstream interface. It is not a proof of `(EP)` unless the
Carleson estimate for `\mu_N` is supplied independently of the far-corona
endpoint theorem being proved.

Using the upgraded gradient inequality to bound `E_N`, then using that bound
to control `\mu_N`, and then returning to prove the far-corona endpoint theorem
would be circular on this route.

## Terminal-window test

For each fixed `N`,

```math
\widetilde\Lambda_N^\sharp\in L^1(0,T),
```

so terminal-window smallness of `\nu_N([t_0,T))` can be obtained by choosing
`t_0` close enough to `T`.

That helps the already-upgraded gradient bridge through Gronwall. It does not
by itself prove `(EP)`, because `(EP)` is one of the inputs needed to land the
far-corona contribution inside the upgraded bridge surface. The terminal-window
argument becomes useful after the missing far-corona packet has been threaded
into the gradient interface; it is not a substitute for that threading.

## Verdict

`RetainedMuNCarlesonEndpointThreading.A` is reduced, not proved.

The exact next target is:

