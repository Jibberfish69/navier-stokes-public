## Propagation Test

The pass branch is contradiction-bearing:

```text
Pack_Q + Part_{N,Q} + Field_{N,r,Q}
=> Member(Q)
=> H^s continuation
=> no finite Clay breakdown.
```

The retained tower bridge strengthens this pass branch. It says that once
Pack, Part, and Field are retained at one higher endpoint depth, the tower face
cannot survive as a fourth endpoint residue.

That is useful. It prevents this invalid move:

```text
Pack + Part + Field retained, but tower-blown still remains outside CM.
```

## Where The Propagation Fails

The first Pack-failure branch is different.

On a first Pack failure, the branch has:

```text
not Pack_Q.
```

So the retained CM hypothesis needed by the tower bridge is absent. The proof
cannot use:

```text
Pack_Q + Part_{N+2,Q} + Field_{N+2,r,Q}
=> not tower-blown
```

to exclude a branch whose first fact is:

```text
not Pack_Q.
```

The Pack/tower dichotomy also does not exclude the branch. It proves:

```text
no tower-blown => Pack_Q.
```

Equivalently, if Pack fails, the failure must be accompanied by tower escape or
some loss that prevents the no-tower branch. That is classification. It is not
a contradiction with a finite Clay breakdown, because a finite Clay breakdown
may present exactly as a Pack face failure unless a further theorem forbids
original smooth data from realizing that face.
