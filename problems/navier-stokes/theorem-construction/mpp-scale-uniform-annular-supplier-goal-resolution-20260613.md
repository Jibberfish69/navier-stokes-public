# MPP Scale-Uniform Annular Supplier Goal Resolution

Date: 2026-06-13

Status: corrected conditional boundary note.  The gold forward-positive supplier
is audited to its exact obstruction.  The surviving obstruction may be consumed
by silver only after it is admitted as the same-solution annular witness under
test with the continuation-readout bridge paid.  For that readout-complete
admitted annular witness, Pack is already paid by selection and carrier; the
remaining CM argument is Part or Field.  Without that readout bridge, the
residual-decay calculation is only a CM Part/Field-audit lemma.

## 1. Live Boundary

The live boundary is the scale-uniform annular supplier.  On terminal annular
windows

```math
0<\alpha<\beta,\quad \theta>0,\qquad
A_m=\{(x,t):\alpha r_m<|x-x_*|<\beta r_m,\ t_m-\theta r_m^2<t<t_m\},
\qquad r_m\downarrow0,\quad t_m\uparrow T_*,
```

the residual refill quantity is

```math
D_j^{res}(t;t_0)
:=
2^{2j}\int_{t_0}^{t}
e^{-c_0\nu2^{2j}(t-s)}\Phi_j^+(s)\,ds.
```

The gold supplier asks for scale-uniform control:

```math
\forall \varepsilon>0\ \exists r_\varepsilon>0
\quad r_m<r_\varepsilon\Longrightarrow D_m^{res}\le\varepsilon
```

for every same-solution terminal annular schedule, or for an equivalent
undiscounted scale-critical cone budget.

## 2. Gold Forward-Positive Audit

The installed forward-positive notes prove the following pieces.

1. The moving-cone local energy identity is exact.
2. Physical funnel energy and dissipation are discounted in cone time.
3. A finite undiscounted scale-critical cone budget gives late-slab smallness,
   hence the CKN/H^s continuation readout.
4. Finite physical wall flux, finite cone volume, finite total energy, global
   dissipation, raw LPAS, and the bare Gaussian profile identity do not remove
   the discount.
5. The residual ledger removes heat descendants and raw shear false positives;
   the only live positive source object is residual same-fluid nonlinear refill.

So the gold proof has reached a precise fork. It closes under either of these
new-production inputs:

```math
TerminalTimeFaceAntiAtom.A,
\qquad
TerminalNewProductionTheorem_{B_ASAC}.A,
```

or an equivalent theorem giving super-\(L^1\) temporal source integrability,
scale-critical source Carleson charge, diffuse-parent charge with a summable
penalty, transported no-incoming-flux control for the full retained terminal
class, or production of a rigid ancient source-residue class with a Liouville
vanishing theorem.

The current installed inputs do not prove that production theorem.  The hard
obstruction is the terminal time-face concentration sequence

```math
g_m(s)=m\,1_{(-1/m,0]}(s),
\qquad
g_m(s)\,ds\rightharpoonup \delta_0.
```

It has bounded \(L_s^1\) mass and zero fixed preterminal residence, while it
keeps unit terminal source mass.  This sequence is compatible with the current
finite source ledger and with the paid non-Zeno donor/refill exclusions.  It is
the exact reason the gold route cannot be closed from raw physical accounting,
local energy, lateral no-flux, source ancestry, or trace bounded variation
alone.

In the residual-refill currency the same obstruction has a heat-scale form.  Let
`lambda_m=2^{j_m}`, `tau_m=lambda_m^{-2}`, and choose disjoint terminal windows
`I_m=[t_m-tau_m,t_m]` with `t_m\uparrow T_*`.  On the selected shell set

```math
\Phi_{j_m}^+(s)=a_m\,1_{I_m}(s),
\qquad 0<a_0\le a_m\le A.
```

The unweighted source bill is summable:

```math
\sum_m\int_{I_m}\Phi_{j_m}^+(s)\,ds
\le A\sum_m2^{-2j_m}<\infty.
```

But the scale-critical refill at the end of each heat window stays bounded
below:

```math
D_{j_m}^{res}(t_m;t_m-\tau_m)
=
2^{2j_m}a_m\int_0^{2^{-2j_m}}
e^{-c_0\nu2^{2j_m}\sigma}\,d\sigma
=
a_m\,\frac{1-e^{-c_0\nu}}{c_0\nu}
\ge
a_0\,\frac{1-e^{-c_0\nu}}{c_0\nu}.
```

So finite physical source mass, finite source ancestry, and heat-window
localization do not imply the scale-uniform annular supplier.  A proof of the
gold supplier needs a genuine anti-atom or time-thickness input that rules out
this heat-scale pulse in the same-solution source ledger.

Thus the forward-positive attempt stops at the present resolution on a hard
obstruction, not on a proof of the scale-uniform supplier.

## 3. Silver Object

The object handed to silver is not a vague failed estimate.  It is the same
residual annular obstruction left after heat descendants, through-flow, legal
losses, finite payments, and paid dissipation have been removed.

Call the selected object \(Q_{ann}\).  It enters the CM test when it is:

1. selected from the same original smooth-data Navier--Stokes solution;
2. the terminal obstruction left by the gold residual ledger;
3. stripped of heat descendants, legal losses, readout-only artifacts, and
   paid finite terms;
4. readout-complete for the alleged finite breakdown, meaning that retained
   carrier, retained Part, and retained Field at the continuation depth supply
   the same-solution \(H^s\), \(s>5/2\), continuation bound through the installed
   pointwise readout bridge;
5. carried by a same-solution positive-radius annular tail for the CM test.

The periodic branch pays this selection/carrier/readout boundary through the transported
whole-torus atlas \(Q_{\mathrm{atlas}}\).  The whole-space branch pays its
corresponding boundary through the exterior Duhamel survivor / dyadic escape
CM matrix.  An unadmitted private annular diagnostic packet still has to meet the
five admission clauses above before it can be spent as \(Q_{ann}\).

This is where the previous draft made the wrong move.  Once \(Q_{ann}\) is
readout-complete admitted as the annular witness, Pack cannot be used as the CM
argument for this boundary.  A no-carrier outcome is a failure to admit this
annular witness, not the silver consumption of the readout-complete admitted
residual annular supplier.

## 4. Smooth And Nonsmooth Split

Once \(Q_{ann}\) is admitted with the continuation-readout bridge paid, the
split is exact.

### Smooth / member branch

If \(Q_{ann}\) retains the admission carrier and also retains:

```math
Part_{N_s,Q_{ann}},
\qquad
Field_{N_s,r,Q_{ann}}\quad\text{for some }r>0,
```

then the readout-completeness premise gives the same-solution \(H^s\),
\(s>5/2\), continuation norm.  The exact hypothesis spent here is:
there is \(M<\infty\) such that the same branch has an \(H^s\) readout with
\(\|u(T_*)\|_{H^s}\le M\).  The \(H^s\) local well-posedness theorem then gives
a time \(\tau=\tau(s,\nu,M)>0\) and a unique same-branch continuation in
\(C([T_*,T_*+\tau];H^s)\).  This is the member side:

```math
Member(Q_{ann};\mathcal O_{work}).
```

It is the smooth/pass branch, not a finite nonsmooth terminal witness.

This pass branch also kills the heat-scale obstruction above.  If the admitted
tail has the installed \(H^s\), \(s>5/2\), readout with bound \(M\), then the
Sobolev algebra/product bound and Littlewood--Paley projection give the exact
dyadic source estimate

```math
\|\Delta_j\mathbb P\nabla\cdot(u\otimes u)\|_2
\le C_sM^2\,2^{-j(s-1)},
\qquad
\|u_j\|_2\le M\,2^{-js}.
```

Hence

```math
\Phi_j^+(t)
\le C_sM^3\,2^{(3-2s)j},
```

and on every heat-scale annular window

```math
D_j^{res}(t;t_0)
\le
2^{2j}\int_{t_0}^{t}
e^{-c_0\nu2^{2j}(t-s)}
C_sM^3\,2^{(3-2s)j}\,ds
\le
C_s'M^3\,2^{(3-2s)j}
\to0.
```

Since \(s>5/2\), a branch with retained Part and retained continuation-readout
Field cannot carry a residual pulse with \(D_{j_m}^{res}\ge\eta>0\) along
shrinking heat-scale annuli.  This conclusion uses the uniform \(H^s\) bridge;
it does not follow from a merely local or scale-dependent field reading.

### Nonsmooth / exit branch

If the readout-complete admitted same-solution terminal witness is finite and
nonsmooth, carrier is no longer the disputed requirement.  The first possible CM
failure is:

```math
\neg Part_{N_s,Q_{ann}},
```

or

```math
Part_{N_s,Q_{ann}}
\wedge\forall r>0\,\neg Field_{N_s,r,Q_{ann}}.
```

Those two cases exhaust the admitted annular witness after carrier selection has
been paid.  Hence the nonsmooth branch
leaves the class object:

```math
Exit(Q_{ann};\mathcal O_{work})
:=
\neg Member(Q_{ann};\mathcal O_{work}).
```

For the terminal Zeno \(B_{ASAC}\) source residue, a zero-thickness point residue
does not supply the admitted annular witness.  That is a pre-admission failure
or a return to the gold anti-atom problem, not the CM argument for this annular
supplier boundary.  A retained positive-scale source-reserve branch stays on the
pass side when paid on the same ledger.  A readout-complete admitted annular fail
branch with nonzero residual heat-scale refill must fail through Part or Field:
if Part fails, the face is Part; if Part survives, retained continuation-readout
Field forces the residual refill to vanish, contradicting the selected
pulse lower bound.
