## Failed Discharge

The attempted bridge would need one of these two payments.

First possible payment:

```text
D.7mq + SSC-EP exact-potential readout
=> Field_avg
=> Field.Read
=> Field_{N,r,Q}.
```

Second possible payment:

```text

=> vanishing h/F defect + native segment tower control
=> Field_{N,r,Q}.
```

Neither payment is installed in the checked surfaces. `D.7mq` and `SSC-EP`
organize branch-sensitive projector/strain geometry. `Field.Read` requires the
terminal averaged Field object plus a positive-scale readout cover. `USCP.A2`
requires same-packet segment/tower control and vanishing native defect. The
current QSP branch does not prove either target by itself.

So the current state is:

```text
QSP finite-frame success => exact-potential / SG.4 readout supplier;
QSP finite-frame success != installed Field_{N,r,Q} certificate.
```

The failure side is equally important:

```text
QSP finite-frame failure != installed not Field_{N,r,Q}.
```

Without necessity or an alternate Field certificate, the QSP branch remains
support-only.
