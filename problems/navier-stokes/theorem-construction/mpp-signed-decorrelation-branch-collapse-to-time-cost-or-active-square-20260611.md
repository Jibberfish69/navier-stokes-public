# MPP Signed/Decorrelation Branch Collapse To Time Cost Or Active-Square

Date: 2026-06-11

Status: forward-positive branch collapse after the active-square consolidation.

## 0. Target

The signed branch was kept alive because it is the one way to avoid paying
positive active-square after absolute values.

The intended route was:

```text
signed trilinear cancellation before absolute values
=> no positive active-square residual
=> LPAS/CTS payment avoided.
```

The concrete mechanism was:

```text
ActiveEigendirectionDecorrel.A
```

or an equivalent theorem forcing the active packet away from expanding strain
directions on the selected terminal windows.

## 1. What The Existing Direct Tests Prove

The direct eigendirection tests have the same outcome.

Incompressibility gives:

```text
tr S = 0.
```

That removes isotropic expansion, while it allows expanding eigendirections.

Pressure recovery enforces the elliptic constraint and pays pressure/cutoff
bookkeeping. It does not create a sign rule for the interior strain readout.

Same-fluid transport keeps the packet tied to the same flow. It does not create
an angular mixing rate.

Global dyadic skew symmetry acts before the one-sided weights, terminal
selection, cutoffs, lifted remainders, and positive-part extraction. It does
not control the selected positive part.

Beltrami, helical, vorticity-direction coherence, angular equipartition, and
anti-coherence classes help only after a theorem produces the active terminal
packet inside those classes. The current inputs do not produce that theorem.

## 2. Persistent Alignment Is The Sharp Remaining Model

The hard model is not random angular behavior. It is persistent positive
alignment:

```text
active packet direction
stays in an expanding eigendirection
on a shrinking terminal heat-scale window.
```

On a window with real time thickness, persistent positive alignment would create
one of the desired payments:

```text
amplitude gain,
temporal residence,
or drain/no-incoming cost.
```

The obstruction is the zero-thickness terminal layer. The active source can
remain large while the time support shrinks, so integrated amplitude gain,
temporal residence, and drain charge can vanish in the limit unless a separate
time-concentration cost is proved.

In shell language, the same wall appears as:

```text
E_j' + c nu D_j <= F_j.
```

A source-balanced pulse can keep the active amplitude alive on a short terminal
interval when `F_j` balances the viscous term.

## 3. Why This Collapses The Signed Branch

The signed route now has two honest exits:

```text
persistent alignment creates a real cost,
```

or

```text
the proof returns to positive active-square control.
```

The first exit is exactly:

```text
SourceTimeConcentrationCost.A.
```

It must prove that squeezing positive source/alignment mass into terminal time
slabs carries a nonnegative cost that diverges, or at least exceeds the LPAS
payment requirement, as the slab thickness goes to zero.

The second exit is:

```text
ResidualSourceBalancedLPAS.A / ResidualDirectCTSOrFCTS.A.
```

It accepts that the signed/decorrelation route has not removed the positive
carrier and pays the active-square wall directly.

## 4. Result

The following labels are now bridge or alias surfaces at this resolution:

```text
SignedPositiveBalance.A,
SignedTrilinearCancellation.A,
ActiveEigendirectionDecorrel.A,
SourceWeightedEigenframeMixing.A,
PersistentExpansionAlignmentForcesReserve.A.
```

```text
source-time concentration cost,
```

So the forward-positive active-square wall is now:

```text
SourceTimeConcentrationCost.A
```

```text
ResidualSourceBalancedLPAS.A / ResidualDirectCTSOrFCTS.A.
```

This is the non-alias state of the signed/decorrelation branch.
