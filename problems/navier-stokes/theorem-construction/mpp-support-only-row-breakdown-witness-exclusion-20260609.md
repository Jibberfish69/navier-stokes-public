# MPP Support-Only Row Breakdown Witness Exclusion

Date: 2026-06-09

Status: active-completion bridge theorem. This note narrows the public Clay
finality bridge, but it does not close CMI finality.

## Target

The rendered-referee reread left this inventory-form burden:

```text
finite Clay terminal obstruction
=> CM-test entry
=> first Part/Field face
=> no support-only terminal row remains outside the inventory.
```

This pass attacks only the last clause. It asks whether a support-only
diagnostic row can serve as the actual finite breakdown witness while staying
outside the selected Part/Field terminal record.

## Theorem

```text
SupportOnlyRowsCannotServeAsFiniteBreakdownWitness.A
```

Let `W_*` be the same-solution terminal record extracted from a finite Clay
breakdown assumption. A row that is explicitly marked support-only,
diagnostic, downstream readout, route history, supplier quarantine, manuscript
scaffold, or generated status cannot be used as the actual finite terminal
breakdown witness unless it is first promoted to a proof-bearing terminal
obstruction row with:

```text
same-solution CM-test entry,
same-atlas or same-packet localization,
and a derived first Part/Field Part/Field failure.
```

## Proof

The finite Clay negation supplies one original smooth datum, one maximal
classical solution on `[0,T_*)`, and one same-solution terminal obstruction
record `W_*`.

By `ClayTerminalWitnessCMEntry.A`, the object under test is not an arbitrary
repo row. It is the canonical same-solution terminal packet record selected
from that maximal solution. By `ClayFiniteFailureTypeCMExhaustion.A`, a
proof-bearing terminal obstruction row must enter the same CM participation-field tree and
derive its first failed face:

```text
not Pack_Q,
or not Part_{N,Q},
or Part_{N,Q} + forall r>0 not Field_{N,r,Q}.
```

A support-only row lacks at least one of those requirements. It may motivate a
supplier theorem, explain a diagnostic route, record a readout, preserve
historical pressure, or guide manuscript organization. But without promotion
through same-solution entry plus first-Part/Field derivation, it is not the terminal
record `W_*` and cannot be the actual finite breakdown witness.

If a future proof wants to use that row as the breakdown object, the row changes
status: it becomes a promoted proof-bearing terminal obstruction row and must
pass the same CM entry and face-landing audit. It no longer remains
support-only.

Thus support-only rows are excluded as hidden terminal breakdown witnesses.

## What Remains Open

This theorem does not prove:

```text

```

proof-bearing terminal record. The proof-bearing record itself may still land
in a first Part/Field Part/Field failure. Classification of that Part/Field failure is
installed, but public Clay finality still needs a theorem proving that original
smooth data cannot realize such a first terminal Part/Field failure, or an equivalent
noncircular bridge from the selected Part/Field failure to contradiction.
