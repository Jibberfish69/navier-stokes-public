# MPP Survivor Equivalence Atlas Note

## Status

Theorem-facing definition and audit note.

Role: define the invariant object that lets branch-local readouts be compared
without changing the underlying same-fluid carrier.

This note does not prove that all existing branches are equivalent. It supplies
the relation and edge tests needed to audit whether two branch packets are
different coordinate charts on the same class-exit event of
`M_Q(u,p)`.

## Carrier-Identity Law

The primitive law for this note is:

```math
\boxed{
\text{a same-fluid object cannot change carrier, scale, selector, or endpoint
type while still counting as the same Navier--Stokes object.}
}
\tag{SEA.0}
```

The class-membership route reads singular behavior as illegal carrier change:

```math
\text{finite-time singular trace}
\Longrightarrow
\text{attempted departure from the same }M_Q(u,p)\text{ object.}
\tag{SEA.1}
```

The branch labels are not the invariant. The invariant is the endpoint-class
violation seen through those branch labels.

## Readout Packets

A route object is a readout packet

```math
R=(F,I,\Lambda,C,W,E,\rho).
\tag{SEA.2}
```

The entries are:

1. `F`: the same-fluid label family;
2. `I`: the still-live interval;
3. `\Lambda`: scale, carrier, selector, and finite-cover data;
4. `C`: the carrier law being propagated;
5. `W`: the witnessed defect, residue, or branch-local obstruction;
6. `E`: the endpoint cell in the `Pack / Part / Field` matrix, with the
   `Blown` shell split into its installed pack and tower faces when needed;
7. `\rho`: the licensed readout map into `M_Q(u,p)`.

Thus `R` is not just a branch theorem. It is a branch theorem plus its license
for reading the branch theorem as a statement about the same local NS object.

## Common Refinement

A common same-fluid refinement is a tuple

```math
\Omega=(F_\ast,I_\ast,\Lambda_\ast,M_Q(u,p))
\tag{SEA.3}
```

where:

1. `F_\ast` is a restriction or licensed refinement of the same label family
   used by both packets;
2. `I_\ast\subset I_1\cap I_2` is still-live for the same fluid;
3. `\Lambda_\ast` dominates the scales, carriers, selectors, and covers needed
   by both packets without using either packet's conclusion;
4. `M_Q(u,p)` is the same local class-membership object.

The common refinement is not allowed to recenter, relabel, or rescale by using a
downstream endpoint conclusion.

## Direct Survivor Co-Witness

Two packets are directly survivor co-witnessed, written

```math
R_1\bowtie_{\mathrm{surv}}R_2,
\tag{SEA.4}
```

when there exist a common refinement `\Omega` and a single endpoint-class
violation

```math
V_\Omega\in
\{Pack,Part,Field\}\times\{Dead,Blown,Jump\}
\tag{SEA.5}
```

such that both packets factor through that violation:

```math
R_1\longrightarrow V_\Omega,
\qquad
R_2\longrightarrow V_\Omega,
\tag{SEA.6}
```

by admissible bridge maps.

The bridge maps must preserve:

```math
\text{same labels, same fluid family, same endpoint cell, same carrier law,
same scale-limit object, and same proof direction.}
\tag{SEA.7}
```

In words:

```math
R_1\bowtie_{\mathrm{surv}}R_2
\quad\Longleftrightarrow\quad
\text{the two readouts are different projections of one class-exit event.}
\tag{SEA.8}
```

## Generated Survivor Equivalence

The survivor equivalence relation is the equivalence relation generated by the
direct co-witness relation:

```math
R_1\sim_{\mathrm{surv}}R_2
\quad:\Longleftrightarrow\quad
\text{there is a finite chain }
R_1=S_0\bowtie_{\mathrm{surv}}S_1
\bowtie_{\mathrm{surv}}\cdots
\bowtie_{\mathrm{surv}}S_k=R_2.
\tag{SEA.9}
```

This definition makes `\sim_{\mathrm{surv}}` reflexive, symmetric, and
transitive as atlas bookkeeping.

The proof-relevant burden is stronger: when a theorem claims two named branch
objects are "the same survivor," it should supply either a direct
`\bowtie_{\mathrm{surv}}` witness or the finite chain in `(SEA.9)`.

## Edge Types

Every map between readout packets must be classified as exactly one of four
edge types.

### Identity Edge

```math
R_1\to R_2
\tag{SEA.10}
```

is an identity edge when it preserves the same survivor and changes only
notation, normalization, or fixed packaging.

Identity edges may change symbols. They may not change labels, carrier law,
endpoint cell, proof direction, or scale-limit object.

### Readout Edge

```math
R_1\to R_2
\tag{SEA.11}
```

is a readout edge when `R_2` is a weaker projection of the same survivor. The
edge may forget information, but it may not create a new endpoint interpretation.

A readout edge is valid only if the forgotten structure is not later needed to
recover the carrier identity of the packet.

### Bridge Edge

```math
R_1\to R_2
\tag{SEA.12}
```

is a bridge edge when it transfers the same survivor across a licensed
carrier/scale/selector change.

A bridge edge must display:

```math
\text{input packet}
\quad
\text{transfer law}
\quad
\text{output packet}
\quad
\text{unchanged endpoint cell.}
\tag{SEA.13}
```

Bridge edges are the dangerous ones. They are admissible only if the transfer
law is proved without using the endpoint exclusion or forward-invariance
conclusion that the branch is trying to supply.

### Illegal Carrier Change

The edge is illegal when it changes any of the following without a licensed
bridge:

```math
F,\quad I,\quad \Lambda,\quad C,\quad E,\quad \rho,\quad
\text{or proof direction.}
\tag{SEA.14}
```

Illegal carrier change is not a failed notation choice. It is exactly the kind
of event the class-membership route is trying to expose.

## Primitive Test

The primitive test is:

```math
\boxed{
\text{if two packets force the same Pack / Part / Field failure on the same
still-live same-fluid family, they are survivor-equivalent.}
}
\tag{SEA.15}
```

The converse is not automatic. If two packets are declared
survivor-equivalent, the audit must exhibit the endpoint cell and the admissible
maps that preserve it.

## Theorem Target `SEA.A` (Survivor Representation Independence)

The central atlas theorem would be:

```math
\boxed{
\text{Every licensed route-native singular readout packet factors through a
unique endpoint-class violation of }M_Q(u,p)\text{ up to }
\sim_{\mathrm{surv}}.
}
\tag{SEA.A}
```

Equivalently, if a near-singular sequence produces tail leakage, tower
flux-debt, deformation commutator residue, selector defect, or receiver/collar
failure, then the readout packet must land in the same endpoint grammar:

```math
\{Pack,Part,Field\}\times\{Dead,Blown,Jump\}.
\tag{SEA.17}
```

The atlas theorem does not replace the analytic estimates. It says what the
analytic estimates must commute with.

## Commuting Diagram Form

The desired proof has two simultaneous paths:

```math
\text{classical PDE evolution}
\longrightarrow
\text{same-fluid membership}
\longrightarrow
\text{endpoint matrix},
\tag{SEA.18}
```

and

```math
\text{scale/tower/deformation/selector readouts}
\longrightarrow
\text{same survivor object}
\longrightarrow
\text{same endpoint exclusion}.
\tag{SEA.19}
```

The atlas compatibility theorem is the claim that `(SEA.18)` and `(SEA.19)`
commute for every licensed readout packet.

## Relation To Pack / Part / Field

This note does not add a fourth primitive law.

`Pack`, `Part`, and `Field` remain the endpoint grammar:

```math
Pack=\text{carrier persistence},
\qquad
Part=\text{shared participation},
\qquad
Field=\text{one-law coherence}.
\tag{SEA.20}
```

Survivor equivalence is a relation among readouts of failures of that grammar.
It is not a new row of the endpoint matrix.

## Audit Consequence

A branch audit should now record each edge as:

```math
\mathrm{IdEdge},\qquad
\mathrm{ReadoutEdge},\qquad
\mathrm{BridgeEdge},\qquad
\mathrm{IllegalCarrierChange}.
\tag{SEA.21}
```

The useful proof spine is then not "find one magic estimate." It is:

```math
\boxed{
\text{prove atlas compatibility for all route-native readout packets, then
exclude the endpoint cells.}
}
\tag{SEA.22}
```

## Boundary

This note does not prove:

1. that the `Pack / Part / Field` triad is globally unique;
2. that all named branches already represent the same survivor;
3. that all selector, tower, affine, pressure, and collar packets are already
   equivalent;
4. that endpoint exclusion can be used before `CFI.A`;
5. that an illegal carrier change is ruled out by naming it.

It only installs the invariant and the audit language needed to tell when a
branch is a coordinate chart on the same survivor and when it has silently
changed the object.
