# MPP TPS Good-Set Bundle First-Pack Survival Direct Attempt

Date: 2026-06-09

Status: new mechanism packet direct attempt. This note does not close
`OriginalSmoothDataPackSurvival.A`, `NoGenuineExitFromSmoothData.A`, or CMI
finality.

## Target

After `NS-LIVE-20260609-197`, the loop requires a concrete new mechanism packet,
not another inventory label.

This note tests:

```text
TPSGoodSetBundleExpansionToFirstPackSurvival.A
```

Proposed statement:

```text
For an original smooth-data terminal packet eligible for the CM test, a
selector-local good-set bundle expansion or shadow-time-decay theorem forces the
first Pack survivor to occupy positive active time on the same atlas. Hence the
terminal packet cannot realize a zero-thickness first Pack failure.
```

If proved, the propagation would be:

```text
TPS good-set bundle expansion
=> positive active-time thickness for the same Pack witness
=> no zero-thickness first Pack failure from original smooth data
=> OriginalSmoothDataPackSurvival.A
=> NoGenuineExitFromSmoothData.A.
```

## Why This Is A Real New Candidate

The proof method is geometric/dynamic rather than endpoint, source-density,
material-collar, h/F, Pack.TTU, minimal-bubble, cross-profile, or direct bridge.

The source-backed TPS surfaces identify the following open theorem input:

```text
quantitative good-set bundle expansion or shadow-time decay strong enough to
force L_I^{net} >= L_J^{thr}
```

They also name `CF-bundle-coercive` as the current candidate first attack on the
strong route, while `tps-shadow-time-budget-packet.md` records a weaker averaged
shadow-time route.

So this candidate has the required four parts:

```text
new mathematical input: good-set bundle expansion / shadow-time decay;
proof-method class: geometric nonshadowing / measure-linearized transverse expansion;
falsification model: zero-thickness terminal source layer with vanishing active-time support;
propagation path: positive active-time thickness => first Pack survival.
```

## Direct Attempt

Assume the installed TPS packet gives one of the two outputs:

```text
1. strong selector route: good active pairs have a transverse lower bound / bad-set
   smallness;
2. weak route: normalized pair-time shadow occupancy vanishes and time-averaged
   packet overlap collapses.
```

To use this for first Pack survival, the loop needs a same-object bridge:

```text
same original-data terminal Pack witness
=> belongs to the TPS good active-pair packet
=> TPS expansion controls its zero-thickness terminal source layer
=> positive active-time thickness or Pack-face survival.
```

The installed TPS files do not prove this bridge. They work at the selector /
pair-packet level. The strong route is still conditional on a transverse
lower-bound theorem such as `CF-bundle-coercive`; the weak route controls
time-averaged overlap, not the existence of a positive active-time interval for
the particular first Pack witness.

## Falsification Model

The same terminal layer that defeats the source-density attempts still tests this
candidate:

```math
g_m(s)=m\,1_{(-1/m,0]}(s).
```

A TPS weak shadow-time budget can make normalized pair overlap small on average
without proving that this particular source layer has preterminal residence. The
layer can concentrate in a vanishing terminal time strip while the pair-time
average remains small.

The strong route would defeat this model only after proving a theorem of the
form:

```text
CFBundleCoerciveFirstPackSurvivalBridge.A.
```

That theorem must say that the selector-good bundle expansion applies to the
same first Pack witness and prices zero-thickness terminal concentration by a
positive active-time lower bound.

## Result

`TPSGoodSetBundleExpansionToFirstPackSurvival.A` is not proved from the installed
TPS surfaces.

The route is useful because it is a genuine new mechanism family, but it remains
conditional. It narrows the new invention packet to:

```text
CFBundleCoerciveFirstPackSurvivalBridge.A
```

or an equivalent same-atlas theorem converting good-set bundle expansion /
shadow-time decay into positive active-time thickness for the original-data Pack
witness.
