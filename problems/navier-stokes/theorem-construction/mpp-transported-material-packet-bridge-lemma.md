# MPP Transported Material-Packet Bridge Lemma

## Status

Candidate later-stage theorem-facing note.

Role: direct transported refinement surface for the material packet after the
comparison and increment-stability layers.

This note now sits after the safe comparison repair
`mpp-eulerian-to-transported-comparison-lemma.md`
and the live quantitative bridge
`mpp-increment-stability-lemma.md`.

The purpose here is narrower:

1. define the transported defect energy on one label-indexed packet;
2. prove the exact bridge identities that fuse the label-space packing side and
   the physical-space tower-coherence side;
3. derive the packet inequality that exposes rung-1 strain defect as
   the driver of relative packing mismatch.

The note does **not** claim a closed proof of packet propagation.

## Purpose

The current route already has:

1. a flow-map packing law through `X,F,A`;
2. a finite-difference tower law through `\delta_h U_k`;
3. a material packet carrying `E_N`, `A_F`, and `P_F`.

What is still missing is the exact statement that these are one object in two
coordinate systems.

The lead bridge variable is the transported parcel separation

```math
h(a,r,t):=X(a+r,t)-X(a,t).
\tag{TB.0}
```

That is the true physical increment generated by the label increment `r`.

## Setup

Let `X(a,t)` solve

```math
\partial_t X(a,t)=u(X(a,t),t),
\qquad
X(a,0)=a.
\tag{TB.1}
```

Let

```math
F(a,t):=D_aX(a,t),
\qquad
A(a,t):=F(a,t)^{-1},
\qquad
\det F(a,t)=1.
\tag{TB.2}
```

Fix a smooth compactly supported label cutoff `\psi(a)`, a label increment `r`,
and rung weights `\lambda_k>0`. Let

```math
U_k(x,t):=\nabla_x^k u(x,t),
\qquad
k=0,1,\dots,N.
\tag{TB.3}
```

Define the transported tower defects

```math
\Delta_r^X U_k(a,t)
:=
U_k(X(a+r,t),t)-U_k(X(a,t),t).
\tag{TB.4}
```

The fused transported defect energy is

```math
\widetilde E_{N,r,\psi}(t)
:=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}\psi(a)^2\,|\Delta_r^X U_k(a,t)|^2\,da.
\tag{TB.5}
```

Its dissipative partner is

```math
\widetilde D_{N,r,\psi}(t)
:=
\sum_{k=0}^{N}\lambda_k
\int_{\mathbf R^3}\psi(a)^2\,
\big|
\nabla_x\big(\delta_{h(a,r,t)}U_k\big)(X(a,t),t)
\big|^2\,da,
\tag{TB.6}
```

So the spatial gradient is taken on the Eulerian defect field before pullback
to label space.

For the packing side, recall

```math
A_F(t;\psi)
:=
\int_{\mathbf R^3}\psi(a)^2\Big(|F(a,t)|^2+|A(a,t)|^2\Big)\,da,
\tag{TB.7}
```

and

```math
P_F(r,t;\psi)
:=
\int_{\mathbf R^3}\psi(a)^2
\Big(
|\Delta_rF(a,t)|^2+|\Delta_rA(a,t)|^2
\Big)\,da,
\tag{TB.8}
```

with

```math
\Delta_rF(a,t):=F(a+r,t)-F(a,t),
\qquad
\Delta_rA(a,t):=A(a+r,t)-A(a,t).
\tag{TB.9}
```

The packet to be propagated is therefore

```math
\mathcal J_{N,r,\psi}(t)
:=
\widetilde E_{N,r,\psi}(t)
+\alpha\,P_F(r,t;\psi)
+\beta\,A_F(t;\psi),
\qquad
\alpha,\beta>0.
\tag{TB.10}
```

## Exact Bridge Identity

The label-space defect and the Eulerian finite-difference defect are the same
object once the increment is taken to be the transported separation.

```math
\boxed{
\Delta_r^X U_k(a,t)
=
\delta_{h(a,r,t)}U_k(X(a,t),t).
}
\tag{TB.11}
```

This is the definition of the transported packet evaluated at
`h(a,r,t),X(a,t),t`:

```math
\delta_{h(a,r,t)}U_k(X(a,t),t)
=
U_k(X(a,t)+h(a,r,t),t)-U_k(X(a,t),t)
=
U_k(X(a+r,t),t)-U_k(X(a,t),t).
```

So `\widetilde E_{N,r,\psi}` is already the fused class-membership defect
energy: it measures tower coherence along the actual transported parcel
separation.

## Geometric Linearization Of Transported Separation

By the fundamental theorem of calculus in label space,

```math
h(a,r,t)
=
\int_0^1 F(a+\theta r,t)\,r\,d\theta.
\tag{TB.12}
```

Hence

```math
h(a,r,t)-F(a,t)r
=
\int_0^1 \big(F(a+\theta r,t)-F(a,t)\big)\,r\,d\theta.
\tag{TB.13}
```

Define the linearization error

```math
\varepsilon_h(a,r,t):=h(a,r,t)-F(a,t)r.
\tag{TB.14}
```

Then Jensen's inequality gives the exact pointwise estimate

```math
|\varepsilon_h(a,r,t)|^2
\le
|r|^2\int_0^1 |F(a+\theta r,t)-F(a,t)|^2\,d\theta.
\tag{TB.15}
```

Integrating against `\psi(a)^2` yields

```math
\int \psi(a)^2\,|\varepsilon_h(a,r,t)|^2\,da
\le
|r|^2
\int_0^1
\int \psi(a)^2\,|\Delta_{\theta r}F(a,t)|^2\,da\,d\theta.
\tag{TB.16}
```

So, defining the monotone segment mismatch

```math
P_F^\ast(r,t;\psi)
:=
\sup_{0\le \theta\le 1} P_F(\theta r,t;\psi),
\tag{TB.17}
```

one gets the exact packet bridge

```math
\int \psi(a)^2\,|\varepsilon_h(a,r,t)|^2\,da
\le
|r|^2\,P_F^\ast(r,t;\psi).
\tag{TB.18}
```

Therefore:

```math
\boxed{
P_F^\ast(r,t;\psi)\text{ small}
\Longrightarrow
c_F|F(a,t)||r|\le |h(a,r,t)|\le C_F|F(a,t)||r|
\text{ on the packet in }L_a^2(\psi^2 da).
}
\tag{TB.19}
```

This is the exact geometric meaning of the packing bridge.

## Exact Relative Deformation Laws

The deformation matrix obeys

```math
\partial_t F(a,t)=(\nabla u)(X(a,t),t)\,F(a,t).
\tag{TB.20}
```

Subtracting the equations at `a+r` and `a` gives

```math
\partial_t \Delta_rF(a,t)
=
(\nabla u)(X(a+r,t),t)\,\Delta_rF(a,t)
+
\Delta_r^X(\nabla u)(a,t)\,F(a,t),
\tag{TB.21}
```

where

```math
\Delta_r^X(\nabla u)(a,t)
:=
(\nabla u)(X(a+r,t),t)-(\nabla u)(X(a,t),t).
\tag{TB.22}
```

Likewise, since

```math
\partial_t A(a,t)=-A(a,t)\,(\nabla u)(X(a,t),t),
\tag{TB.23}
```

one gets

```math
\partial_t \Delta_rA(a,t)
=
-\Delta_rA(a,t)\,(\nabla u)(X(a+r,t),t)
-A(a,t)\,\Delta_r^X(\nabla u)(a,t).
\tag{TB.24}
```

These identities are exact.

They show the core theorem bridge:

```math
\boxed{
\text{relative packing mismatch is driven by the rung-1 transported defect.}
}
\tag{TB.25}
```

Indeed,

```math
\Delta_r^X(\nabla u)(a,t)=\Delta_r^X U_1(a,t).
\tag{TB.26}
```

Define the exact rung-1 geometric source term

```math
\mathcal Q_{1,r,\psi}^{str}(t)
:=
\int_{\mathbf R^3}
\psi(a)^2\,|\Delta_r^X U_1(a,t)|^2\,da
=
\int_{\mathbf R^3}
\psi(a)^2\,\big|\Delta_r((\nabla u)\circ X)(a,t)\big|^2\,da.
\tag{TB.26a}
```

Since `\lambda_1>0` and `\widetilde E_{1,r,\psi}` contains the rung-1 term, one
has the exact upper bound

```math
\mathcal Q_{1,r,\psi}^{str}(t)
\le
\lambda_1^{-1}\,\widetilde E_{1,r,\psi}(t).
\tag{TB.26b}
```

## Exact Relative Packing Inequality

Let

```math
\Lambda_{\psi,r}(t)
:=
\sup_{a\in \operatorname{supp}\psi \cup (\operatorname{supp}\psi+r)}
\big|(\nabla u)(X(a,t),t)\big|.
\tag{TB.27}
```

Also define the shifted packet distortion ledger

```math
A_F^\sharp(t;\psi,r)
:=
\int_{\mathbf R^3}
\Big(
\psi(a)^2+\psi(a-r)^2
\Big)
\Big(
|F(a,t)|^2+|A(a,t)|^2
\Big)\,da.
\tag{TB.27a}
```

Differentiating `(TB.8)`, using `(TB.21)`--`(TB.24)`, and applying Cauchy and
Young gives

```math
\frac{d}{dt}P_F(r,t;\psi)
\le C_{\mathrm{TB28}}
\Lambda_{\psi,r}(t)\,P_F(r,t;\psi)
+
A_F^\sharp(t;\psi,r)\,\mathcal Q_{1,r,\psi}^{str}(t),
\tag{TB.28}
```

Here `A_F^\sharp` is the exact packetwise absolute distortion ledger after the
fixed comparison shift between the `a` and `a+r` locations. The shift is part
of the ledger definition used in `(TB.21)`--`(TB.24)`, not a profile or scale
approximation.

So the exact source term for relative packing mismatch is the rung-1 transported
strain defect `\mathcal Q_{1,r,\psi}^{str}(t)`. The larger transported packet
`\widetilde E_{1,r,\psi}(t)` is a valid controlling upper bound by `(TB.26b)`,
but it is not literally the source term in `(TB.28)`.

## Conditional Packet Inequality

Together with the transported tower-defect evolution from
`mpp-shared-participation-and-tower-coherence-law.md`, the closed fused-packet
theorem must produce nonnegative quantities
`\mathcal J_{N,r,\psi}`, `\widetilde D_{N,r,\psi}`, and
`\mathcal C_{N,r,\psi}` satisfying

```math
\frac{d}{dt}\mathcal J_{N,r,\psi}(t)
+2\nu\,\widetilde D_{N,r,\psi}(t)
\le
\mathcal C_{N,r,\psi}(t)\,\mathcal J_{N,r,\psi}(t),
\tag{TB.29}
```

where `\mathcal C_{N,r,\psi}(t)` is built from:

1. packet strain envelopes;
2. rung-split cascade coefficients up to depth `N`;
3. the packet transport mismatch coming from the moving cutoff;
4. the fixed packet enlargement used in `(TB.28)`.

The exact propagation consequence would then be the Gronwall statement

```math
\mathcal J_{N,r,\psi}(t)
+2\nu\int_{t_0}^t
\exp\!\left(-\int_s^t\mathcal C_{N,r,\psi}(\tau)\,d\tau\right)
\widetilde D_{N,r,\psi}(s)\,ds
\le
\mathcal J_{N,r,\psi}(t_0)
\exp\!\left(\int_{t_0}^t\mathcal C_{N,r,\psi}(s)\,ds\right).
\tag{TB.29a}
```

So the missing theorem is not the formal shape `(TB.29)`. It is the construction
of `\mathcal J_{N,r,\psi}` and `\mathcal C_{N,r,\psi}` from the displayed
packet quantities, with

```math
\int_{t_0}^{t_1}\mathcal C_{N,r,\psi}(s)\,ds<\infty
\tag{TB.29b}
```

on the selected material packet.  The exact content of this bridge note is that
the only new geometric source term introduced by the packing side is the rung-1
transported defect.

## Exact Next Theorem Shape

The theorem target now visible is:

```math
\boxed{
\text{construct }(\mathcal J,\mathcal C)\text{ so that }(TB.29)\text{ and }(TB.29b)\text{ hold with the exact rung-1 source term.}
}
\tag{TB.30}
```

Equivalently, the sharp local closure question is:

```math
\boxed{
\text{what exact control on }\mathcal Q_{1,r,\psi}^{str}(t)\text{ is sufficient to keep }P_F(r,t;\psi)\text{ small and }A_F(t;\psi)\text{ finite?}
}
\tag{TB.31}
```

If one prefers to work with the larger transported packet, `(TB.26b)` gives the
conservative reformulation

```math
\mathcal Q_{1,r,\psi}^{str}(t)\ \text{controlled by}\ \widetilde E_{1,r,\psi}(t).
\tag{TB.31a}
```

That is the exact sense in which `\widetilde E_{1,r,\psi}` may be used here.
