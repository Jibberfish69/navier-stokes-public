## Primitive Material Geometry

The working object carries both the true finite material separation

```math
h(a,r,t):=\Phi(a+r,t)-\Phi(a,t)
\tag{USS.0}
```

and the infinitesimal deformation

```math
F(a,t):=D_a\Phi(a,t).
\tag{USS.1}
```

The affine separation defect is

```math
\mathfrak D_{h/F}(a,r,t)
:=
h(a,r,t)-F(a,t)r.
\tag{USS.2}
```

Using the finite-separation law in the ontic object package,

```math
h(a,r,t)=\int_0^1F(a+s r,t)r\,ds,
\tag{USS.3}
```

one has the exact identity

```math
\mathfrak D_{h/F}(a,r,t)
=
\int_0^1\bigl(F(a+s r,t)-F(a,t)\bigr)r\,ds.
\tag{USS.4}
```

So `\mathfrak D_{h/F}` is the first geometric place where finite scale,
infinitesimal deformation, scale memory, packing, selector direction, affine
quotient, and transported finite differences all meet.

## Scale-Window Defect Measure

The raw expression

```math
\frac{|\mathfrak D_{h/F}(a,r,t)|^2}{|r|^2}\,da\,\frac{dr}{|r|^3}
\tag{USS.5}
```

should not be used without a scale window. The theorem-facing object is the
truncated scale-window measure. For a label cutoff `\psi`, and scales
`0<\eta<\rho`, define

```math
d\mu_{t}^{h/F;\psi,\eta,\rho}(a,r)
:=
\mathbf 1_{\eta\le |r|\le\rho}\,
\psi(a)^2
\frac{|\mathfrak D_{h/F}(a,r,t)|^2}{|r|^2}
\,da\,\frac{dr}{|r|^3}.
\tag{USS.6}
```

Equivalently,

```math
\mu_{t}^{h/F;\psi,\eta,\rho}
\text{ measures terminal scale memory in }
h(a,r,t)-F(a,t)r
\text{ on the label packet }(\psi,\eta,\rho).
\tag{USS.7}
```

The truncation is part of the object. It prevents the atlas from hiding a scale
change in the notation. A passage `\eta\downarrow0`, `\rho\uparrow\rho_\ast`,
or `t\uparrow T_\ast` must be licensed by a scale-window theorem.

## Relation To Existing Packets

### Pack Readout

Packing reads `\mathfrak D_{h/F}` as failure of the finite separation to remain
coherent with the infinitesimal deformation model:

```math
h(a,r,t)\sim F(a,t)r.
\tag{USS.13}
```

This is the geometric content already used by the relative packing ledgers and
the increment-stability bridge.

### Tower / Field Readout

The tower and one-field routes read the same defect through the comparison

```math
\delta_{h(a,r,t)}U_k
-
\delta_{F(a,t)r}U_k.
\tag{USS.14}
```

Increment stability turns this into a product of the geometric defect
`\mathfrak D_{h/F}` and a next-rung segment carrier. Thus terminal scale memory
in `\mathfrak D_{h/F}` is one direct source of cross-rung finite-difference
residue.

### Deformation / Affine Readout

By `(USS.4)`, the same object is exactly the finite-scale variation of `F`:

```math
\int_0^1(F(a+s r,t)-F(a,t))r\,ds.
\tag{USS.15}
```

The affine survivor quotient and affine-excess packets are therefore not
separate primitives at this level. They are affine-coordinate readouts of the
same finite-to-infinitesimal mismatch, provided their carrier and scale windows
are preserved.

### Selector Readout

When the pack-side gauge keeps `h` and `F r` nondegenerate, the defect controls
angular/projective drift:

```math
\frac{h(a,r,t)}{|h(a,r,t)|}
\quad\text{versus}\quad
\frac{F(a,t)r}{|F(a,t)r|}.
\tag{USS.16}
```

Thus selector/projector defects can be read as direction-only shadows of
`\mathfrak D_{h/F}`. This is only a readout unless a theorem proves the
necessary nondegeneracy and scale transfer.

### Endpoint Readout

The endpoint matrix reads nonzero terminal `h/F` scale memory as living on the
surviving pair:

```math
\mathcal S_\ast^{h/F}
\leadsto
(Pack,Blown)
\quad\text{or}\quad
(Field,Jump).
\tag{USS.17}
```

This note does not choose the endpoint cell. It says the same defect is a
candidate common source for the surviving pack-side and field-side readouts.
