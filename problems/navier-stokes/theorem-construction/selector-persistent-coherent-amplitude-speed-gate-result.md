# Selector-Persistent Coherent Amplitude Speed Gate Result

## Target

This note routes the collar coefficient estimates through a direct selector-persistent amplitude gate.

The target amplitude gate on the persistent coherent support is

```math
\boxed{
\|u_{coh}\|_{L_x^\infty(\Gamma_j(t))}
\le
\kappa_U\nu2^j+C_U2^{-j}\Phi(\mathcal E_D(X)).
}
\tag{ASG.1}
```

The equivalent flow-speed gate is

```math
\boxed{
\sup_{x\in\Gamma_j(t)}\sup_{s\in I_j}
\frac{|\Phi_{coh}(s;t,x)-x|}{|s-t|}
\le
\kappa_U\nu2^j+C_U2^{-j}\Phi(\mathcal E_D(X)).
}
\tag{ASG.2}
```

Here `\Phi_{coh}(s;t,x)` is the absolutely continuous flow generated by the coherent velocity `u_{coh}` on the persistent support:

```math
\frac d{ds}\Phi_{coh}(s;t,x)
=u_{coh}(\Phi_{coh}(s;t,x),s),
\qquad
\Phi_{coh}(t;t,x)=x.
\tag{ASG.3}
```

The scalar `\nu` denotes viscosity.

## Lemma ASG.1: amplitude gate implies flow-speed gate

Assume `ASG.1` holds uniformly along the coherent flow tube

```math
\Phi_{coh}(r;t,x)\in\Gamma_j(r)
\qquad r\in I_j.
\tag{ASG.4}
```

Then `ASG.2` holds.

### Proof

By absolute continuity and `ASG.3`,

```math
\Phi_{coh}(s;t,x)-x
=
\int_t^s u_{coh}(\Phi_{coh}(r;t,x),r)\,dr.
\tag{ASG.5}
```

Using `ASG.1` on each support slice `\Gamma_j(r)`,

```math
|\Phi_{coh}(s;t,x)-x|
\le
|s-t|\left(\kappa_U\nu2^j+C_U2^{-j}\Phi(\mathcal E_D(X))\right).
\tag{ASG.6}
```

Divide by `|s-t|` and take the supremum. ∎

## Lemma ASG.2: flow-speed gate implies amplitude gate

Assume `ASG.2` and assume `u_{coh}` is continuous on the persistent support slices. Then `ASG.1` holds.

### Proof

For `x\in\Gamma_j(t)`, take `s\to t` in `ASG.2`. The flow derivative gives

```math
\lim_{s\to t}
\frac{\Phi_{coh}(s;t,x)-x}{s-t}
=u_{coh}(x,t).
\tag{ASG.7}
```

Thus

```math
|u_{coh}(x,t)|
\le
\kappa_U\nu2^j+C_U2^{-j}\Phi(\mathcal E_D(X)).
\tag{ASG.8}
```

Taking the supremum over `x\in\Gamma_j(t)` gives `ASG.1`. ∎

## Lemma ASG.3: amplitude gate gives coherent strain

Assume the fixed-fattened coherent projector supplies frequency localization:

```math
\boxed{u_{coh}=P_{\le j+A}u_{coh}.}
\tag{ASG.9}
```

By Bernstein,

```math
\|\nabla u_{coh}\|_{L_x^\infty}
\le
C_B(A)2^j\|u_{coh}\|_{L_x^\infty}.
\tag{ASG.10}
```

Combining `ASG.1` and `ASG.10`,

```math
\|\nabla u_{coh}\|_{L_x^\infty}
\le
C_B(A)\kappa_U\nu2^{2j}
+C_B(A)C_U\Phi(\mathcal E_D(X)).
\tag{ASG.11}
```

If

```math
C_B(A)\kappa_U\le c_0,
\tag{ASG.12}
```

and the lower-order term is inside the active absorption convention, then

```math
\|\nabla u_{coh}\|_{L_x^\infty}
\le
c_0\nu2^{2j}+C\Phi(\mathcal E_D(X)).
\tag{ASG.13}
```

## Lemma ASG.4: amplitude gate gives high-collar coefficient tail

For fixed collar width `M`,

```math
R_{j,A,M}:=P_{>j-M}P_{\le j+A}
```

has uniform `L^\infty\to L^\infty` norm `C_{A,M}`. Hence

```math
2^j\|P_{>j-M}u_{coh}\|_{L_x^\infty}
\le
C_{A,M}2^j\|u_{coh}\|_{L_x^\infty}.
\tag{ASG.14}
```

Using `ASG.1`,

```math
2^j\|P_{>j-M}u_{coh}\|_{L_x^\infty}
\le
C_{A,M}\kappa_U\nu2^{2j}
+C_{A,M}C_U\Phi(\mathcal E_D(X)).
\tag{ASG.15}
```

If

```math
C_{A,M}\kappa_U\le c_1,
\tag{ASG.16}
```

then

```math
2^j\|P_{>j-M}u_{coh}\|_{L_x^\infty}
\le
c_1\nu2^{2j}+C\Phi(\mathcal E_D(X)).
\tag{ASG.17}
```

## Theorem ASG: amplitude/speed gate supplies the collar coefficients

Assume the coherent flow is absolutely continuous on persistent support, the support is invariant under that flow on `I_j`, the fixed-fattened coherent projector `ASG.9` holds, and either the amplitude gate `ASG.1` or the flow-speed gate `ASG.2` holds.

Then the coherent coefficient inputs consumed by the low-pass commutator collar closure hold:

```math
\|\nabla u_{coh}\|_{L_x^\infty}
\le
c_0\nu2^{2j}+C\Phi(\mathcal E_D(X)),
\tag{ASG.18}
```

and

```math
2^j\|P_{>j-M}u_{coh}\|_{L_x^\infty}
\le
c_1\nu2^{2j}+C\Phi(\mathcal E_D(X)),
\tag{ASG.19}
```

provided `ASG.12` and `ASG.16` place the coherent speed constant in the collar absorption window.

## Boundary
