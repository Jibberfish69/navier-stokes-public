# Spatial-Derivative / Deformation-Geometry Curvature-Dissipation Theorem Target

## Purpose

Record the corrected theorem target suggested by the current tower, matrix,
weighted-Gram obstruction, and YM-heat bridge notes.

The earlier version of this note treated the spatial derivative family
`\{U_\alpha\}` as the primary analogue of YM curvature.
That is still useful, but it is no longer the deepest target.

The corrected split is:

```text
primary theorem surface:
Lagrangian deformation geometry (v,G)

visible shadow theorem surface:
Eulerian spatial derivative family {U_alpha}
```

For the current live route, the chosen classical surface is the periodic torus
branch. Any whole-space `R^3` formula is downstream export only unless
explicitly labeled otherwise.

Here

```math
U_\alpha := \partial_x^\alpha u,
\qquad
v(a,t):=u(X(a,t),t),
\qquad
G(a,t):=A(a,t)A(a,t)^\top.
\tag{1}
```

The reason for the correction is structural.

In YM heat flow, the cubic term appears because the field diffuses through a
geometry that the field itself creates.
For Navier--Stokes, the closest source-backed analogue is not the bare
Eulerian tower.
It is the Lagrangian equation

```math
\partial_t v + A^\top \nabla_a q
=
\nu\,\operatorname{div}_a(G\nabla_a v),
\qquad
G:=AA^\top,
\tag{2}
```

where the viscous operator is already a geometry-modified heat operator and
the geometry is generated by the flow itself.

So the corrected theorem target is:

```math
\boxed{
\text{the real curvature object is the deformation geometry }G,
\text{ while the Eulerian derivative tower is its visible shadow.}
}
\tag{3}
```

## 1. The two branches and why they split

### Branch A: Eulerian weighted-Gram shadow

Stay with the spatial derivative family

```math
U_\alpha=\partial_x^\alpha u,
\qquad 1\le |\alpha|\le r.
\tag{4}
```

Then the natural object is a weighted Gram functional

```math
\mathcal K_W[u]
:=
\sum_{\alpha,\beta} w_{\alpha,\beta}\,\langle U_\alpha,U_\beta\rangle.
\tag{5}
```

The weighted-Gram obstruction note proves:

```math
\frac{d}{dt}\mathcal K_W[u(t)]
+
2\nu\,\mathcal D_W[u(t)]
=
-\mathcal N_W[u(t)],
\tag{6}
```

where `\mathcal N_W[u]` is cubic in `u`.

So a bare quadratic Eulerian energy cannot directly produce a YM-style square
law, because:

- the quadratic weighted Gram energy has cubic nonlinear variation;
- a square defect built from the transport commutator is quartic.

That means this branch can only close by:

1. adding cubic or higher correction terms to the functional, or
2. proving a one-sided shadow inequality rather than an exact square identity.

### Branch B: Lagrangian deformation geometry

Pull back by the flow map `X(a,t)`.
Then advection disappears exactly and the equation becomes `(2)`.

The geometry evolves by strain:

```math
\partial_t A = -A\,(\nabla_x u)(X,t),
\tag{7}
```

and hence

```math
\partial_t G
=
-A\big((\nabla_x u)+(\nabla_x u)^\top\big)(X,t)A^\top.
\tag{8}
```

This is the deeper branch, because it has the same formal content as the YM
cubic term:

```math
\boxed{
\text{the field diffuses through geometry that it is simultaneously deforming.}
}
\tag{9}
```

So the missing NS square target is first sought in the deformation geometry,
not in a bare quadratic Eulerian tower energy.

## 2. Why `G` is the right analogue of the hidden YM geometry

For YM heat flow:

- the connection defines the covariant geometry;
- the heat operator is covariant with respect to that geometry;
- the cubic term is the visible trace of self-modified diffusion.

For Navier--Stokes in honest Lagrangian variables:

- the deformation metric `G` defines the conductivity geometry;
- the viscous term is
  `\nu\,\operatorname{div}_a(G\nabla_a v)`;
- the higher-order source comes from differentiating the coefficients `A,G`.

Differentiating `(2)` gives

```math
\partial_t \partial_a^\alpha v
+
A^\top\nabla_a \partial_a^\alpha q
=
\nu\,\operatorname{div}_a\!\big(G\nabla_a \partial_a^\alpha v\big)
+
\mathcal C_\alpha(A,G;v,q),
\tag{10}
```

where `\mathcal C_\alpha` is the coefficient-commutator packet.

So the explicit transport tower has been replaced by a geometric-commutator
tower:

```math
\boxed{
\text{all higher-order forcing comes from deformation-coefficient commutators.}
}
\tag{11}
```

That is exactly the place where a YM-style square defect could live.

## 3. Corrected primary theorem target

The primary theorem is now stated on the finite Lagrangian derivative
family

```math
\Big\{\partial_a^\alpha v,\ \partial_a^\beta G\Big\}_{1\le |\alpha|,|\beta|\le r}.
\tag{12}
```

### Theorem target: deformation-geometry curvature dissipation

There exist functionals

```math
\mathcal K_r^{\mathrm{Lag}}[v,G],
\qquad
\mathcal D_r^{\mathrm{Lag}}[v,G]\ge 0,
\qquad
\mathcal C_r^{\mathrm{Lag}}[v,G]\ge 0,
\qquad
\Psi_r^{\mathrm{Lag}}[v,G]\ge 0,
\tag{13}
```

defined on `(12)`, such that every smooth incompressible periodic
Navier--Stokes solution on the current torus-first internal branch
`\mathbb T^3` satisfies

```math
\boxed{
\frac{d}{dt}\mathcal K_r^{\mathrm{Lag}}[v(t),G(t)]
+
\mathcal D_r^{\mathrm{Lag}}[v(t),G(t)]
+
\mathcal C_r^{\mathrm{Lag}}[v(t),G(t)]
\le 0.
}
\tag{14}
```

Here:

- `\mathcal K_r^{\mathrm{Lag}}` is the deformation-curvature energy;
- `\mathcal D_r^{\mathrm{Lag}}` is the genuine viscous drain in the evolving
  metric;
- `\mathcal C_r^{\mathrm{Lag}}` is the square-type deformation defect,
  built from the coefficient-commutator packet and the failure of the evolving
  metric to remain transport-flat/tame;
- `\Psi_r^{\mathrm{Lag}}` is a blowup-controlling geometry norm.

The theorem must also prove coercive comparisons

```math
c_K\Psi_r^{\mathrm{Lag}}[v,G]
\le
\mathcal K_r^{\mathrm{Lag}}[v,G]
\le
C_K\Psi_r^{\mathrm{Lag}}[v,G],
\tag{15}
```

and

```math
\mathcal D_r^{\mathrm{Lag}}[v,G]
+
\mathcal C_r^{\mathrm{Lag}}[v,G]
\ge
c_D
\Psi_r^{\mathrm{Lag}}[v,G].
\tag{16}
```

Consequently,

```math
\frac{d}{dt}\mathcal K_r^{\mathrm{Lag}}[v(t),G(t)]
\le
-c\,\Psi_r^{\mathrm{Lag}}[v(t),G(t)].
\tag{17}
```

This is the corrected NS analogue of the YM sentence:

```text
curvature energy decreases because the field's self-modified diffusion drains
the very defect that the geometry records.
```

## 4. What the pieces mean

The viscous part is the natural variable-coefficient Dirichlet
energy:

```math
\mathcal D_{r,\mathrm{model}}^{\mathrm{Lag}}[v,G]
:=
\sum_{1\le |\alpha|\le r}
\int_{\mathbb T^3}
G\,\nabla_a \partial_a^\alpha v : \nabla_a \partial_a^\alpha v\,da
+
\text{metric-control terms}.
\tag{18}
```

The deformation defect measures the price of the geometry not remaining
tame under strain through an exact square packet of the form

```math
\mathcal C_{r,\mathrm{model}}^{\mathrm{Lag}}[v,G]
:=
\sum_{1\le |\alpha|\le r}
\|\mathcal C_\alpha(A,G;v,q)\|_{L_a^2}^2
+
\text{square-type strain/metric defect terms}.
\tag{19}
```

The exact formula is still open.
But the note now fixes the place where it has to be searched:

```math
\boxed{
\text{the missing square target comes from geometry-modified diffusion and its coefficient commutators.}
}
\tag{20}
```

## 5. Induced Eulerian shadow inequality

The older weighted-Gram / spatial-tower target is still useful, but only as
the visible shadow of the deeper Lagrangian law.

If `(14)` can be proved and the passage back to Eulerian variables is tame,
then it implies a shadow inequality of the form

```math
\boxed{
\frac{d}{dt}\mathcal K_r^{\mathrm{Eul}}[u(t)]
+
\mathcal D_r^{\mathrm{Eul}}[u(t)]
+
\mathcal F_r^{\mathrm{Eul}}[u(t)]
\le 0,
}
\tag{21}
```

where:

- `\mathcal K_r^{\mathrm{Eul}}` is a diagonal-plus-off-diagonal functional of
  the spatial derivative family `\{U_\alpha\}`;
- `\mathcal D_r^{\mathrm{Eul}}` is the visible viscous drain;
- `\mathcal F_r^{\mathrm{Eul}}` is the nonnegative transport-assisted
  dissipation term seen in Eulerian coordinates.

So the hierarchy is:

```text
primary closure law:
deformation-geometry dissipation on (v,G)

visible shadow law:
transport-assisted dissipation inequality on {U_alpha}
```

This is the precise sense in which the first branch is the visible shadow of
the second.

## 6. Honest boundary

This note does **not** claim that the deformation-geometry theorem is already
proved.

What is established now is the route constraint:

1. a bare quadratic Eulerian weighted-Gram functional cannot by itself produce
   the YM square;
2. the honest Lagrangian rewrite turns viscosity into geometry-modified heat;
3. therefore the strongest theorem target is written first on the
   deformation geometry `G`, with the Eulerian tower treated as a shadowed
   consequence.

So the new search target is not merely:

```text
find weights that make the mixed tower negative.
```

It is:

```math
\boxed{
\text{find the deformation-geometry functional whose dissipation law shadows down to transport-assisted dissipation in the Eulerian tower.}
}
\tag{22}
```
