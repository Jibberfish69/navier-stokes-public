Status: proved noncanonical exact same-history localization inside Thomas

method.

The physical object is one smooth fixed-viscosity Navier--Stokes history
generated by \(u_0\).  This note combines the already proved FIM exterior

source-square Cauchy estimate.  The surviving current therefore retains the
complete dynamic-core triad mask, all three possible output legs, both input

The result is exact.  A failed record forces a source square formed only from
dynamic-core triads.  After a record-dependent high-output cut, the static FIM
floor applies to the minimum of all three legs, so both physical input parents
are above

\[
 r_n\simeq
 \left({\nu\over\|u_0\|_2}\right)^{2/5}K_n^{4/5}.

Every term containing datum heat ancestry is then datum-paid.  Splitting both
remaining nonlinear Duhamel parents at one quantified heat lag

total \(L_t^1\) mass over all records is finite.

This is a stronger support and ancestry localization of the same critical

## 2. Freeze the complete core mask and only then take Cauchy

\(\chi_{\rm core}(k,p,q;t)\) denote the resulting bounded symmetric triad
mask.  It has the same value under every permutation of the three geometric

Let

\[
 \Theta_u(k,p;t)
 :=-i\,\mathbb P_k
 \big[(\widehat u(p,t)\cdot(k-p))\widehat u(k-p,t)\big].
 \tag{CDR.12}

Define the selected source by

\[
 \widehat Q_{\rm core}(k,t)
 :=\int\chi_{\rm core}(k,p,k-p;t)\Theta_u(k,p;t)\,dp,
 \tag{CDR.13}

with the fixed real-field, helical, and Littlewood--Paley multiplicities of

`(CDR.13)` over output \(k\) retains all six assignments: each of the three

\[

\[

\begin{aligned}
 {A_n\over4}

## 3. High output puts both physical parents above the static core floor

The incompressibility identity

\[
 \widehat u(p)\cdot(k-p)=\widehat u(p)\cdot k
 \tag{CDR.18}

and the bounded sector mask give the uniform low-output estimate

 \boxed{

\[
 |\widehat Q_{\rm core}(k,t)|

and integration of \(|k|^{-1}|\widehat Q_{\rm core}(k)|^2\) over
\(|k|<K\) gives `(CDR.19)`.  The estimate is uniform in the moving core
boundary because the mask only removes terms before the Fourier modulus is
taken.

Set

\[
 c_{\rm core}:={1\over32},

 \boxed{
 K_n^4:=
 {c_{\rm core}\nu A_n
 \over4C_LU_0^4\Delta_n}.}

Since \(\Delta_n\le T_*\), one has \(K_n\to\infty\).  Output orthogonality,

\[
 \boxed{
 \int_{I_n}
 \|\Lambda^{-1/2}P_{\ge K_n}Q_{\rm core}(t)\|_2^2dt

 \tag{CDR.21}

## 4. Datum heat ancestry vanishes after the core and output are joined

Use the exact one-history mild decomposition

\[
 h_0(t):=e^{-\nu tA}u_0,
 \qquad
 w(t):=u(t)-h_0(t)
 =\int_0^t e^{-\nu(t-s)A}Q(u(s))ds.
 \tag{CDR.25}
\]

The notation \(h_0\) avoids confusion with the maximum triad radius \(h\).
For any ordered fields \(a,b\), let
\(\mathcal Q_n^{\rm ch}[a,b]\) denote `(CDR.13)` with the core mask frozen
from the full field \(u(t)\), the output restricted to \(|k|\ge K_n\), and
the two velocity slots replaced by \(a,b\).  The superscript ch means
core/high.

Because the selector is frozen, bilinearity gives the exact decomposition

\[
\begin{aligned}
 P_{\ge K_n}Q_{\rm core}(u,u)
 ={}&
 \mathcal Q_n^{\rm ch}[h_0,h_0]
 +\mathcal Q_n^{\rm ch}[h_0,w]
 +\mathcal Q_n^{\rm ch}[w,h_0]\\
 &+\mathcal Q_n^{\rm ch}[w,w].
\end{aligned}
\tag{CDR.26}
\]

No selector for \(h_0\) or \(w\) is recomputed.  Doing so would change the
one fluid object.

The sector-uniform pressure-complete estimate is

\[
 \boxed{
 \|\Lambda^{-1/2}\mathcal Q_n^{\rm ch}[a,b](t)\|_2
 \le C_{\rm sec}\|\Lambda a(t)\|_2\|\Lambda b(t)\|_2.}
 \tag{CDR.27}
\]

It is independent of \(n\), \(K_n\), and the dynamic-core boundary: after
the restricted convolution is formed, taking its Fourier modulus reduces it
to the same unrestricted Sobolev product estimate as `(RHL.10a)--(RHL.10b)`.

Put

\[
 Z_0:=\|\Lambda u_0\|_2^2,\qquad
 Z_w(t):=\|\Lambda w(t)\|_2^2.
 \tag{CDR.28}
\]

The heat contraction gives
\(\|\Lambda h_0(t)\|_2^2\le Z_0\).  Thus the complete

 \|\Lambda^{-1/2}\mathcal Q_n^{\rm ic}(t)\|_2^2
 \le C_{\rm ic}\bigl(Z_0^2+Z_0Z_w(t)\bigr).
 \tag{CDR.29}

The records are disjoint and

\[
 \int_0^{T_*}Z_w(t)dt
 \le2\int_0^{T_*}Z(t)dt+2Z_0T_*<\infty.

Consequently

\[
 \int_{I_n}

 \tag{CDR.31}

The reverse triangle inequality in

\[
 \boxed{

\]

Both parents in `(CDR.32)` are nonlinear Duhamel descendants of the one
history, and `(CDR.24)` applies to both.

## 5. Both high Duhamel parents must be recent

Put

\[
 v_n(t):=P_{\ge r_n}w(t).
 \tag{CDR.33}

\[

 =\mathcal Q_n^{\rm ch}[v_n,v_n].
 \tag{CDR.34}

For a lag \(\tau>0\), split this same Duhamel history as

\[
\begin{aligned}
 v_{n,\tau}^{\rm old}(t)
 &:={\bf1}_{\{t>\tau\}}
 e^{-\nu\tau A}P_{\ge r_n}w(t-\tau),\\

 &:=\int_{(t-\tau)_+}^t

 v_n(t)&=v_{n,\tau}^{\rm old}(t)+v_{n,\tau}^{\rm rec}(t).

\tag{CDR.35}

Since \(\|w(t)\|_2\le2U_0\), whenever \(2\nu\tau r_n^2\ge1\),

\[
 \boxed{
 \sup_t\|\Lambda v_{n,\tau}^{\rm old}(t)\|_2^2
 \le D_ne^{-2\nu\tau r_n^2},
 \qquad D_n:=4U_0^2r_n^2.}
 \tag{CDR.36}

\[
 e_n:=\int_{I_n}\|\Lambda v_n(t)\|_2^2dt
 \le\int_{I_n}Z_w(t)dt,

and take

\[
 C_{\rm old}:=8C_{\rm sec}^2.

From

\tag{CDR.40}

 \tag{CDR.41}

Choose

 \tag{CDR.44}

\begin{aligned}

## 7. Exact edge/interior source-support fork

\[
\begin{aligned}
 I_n^{\rm edge}

\quad\text{when }s_n+\tau_n<t_n.
\end{aligned}
\tag{CDR.60}
\]

The integrand in `(CDR.49)` is nonnegative.  Hence at least one
\(\sigma_n\in\{\mathrm{edge},\mathrm{int}\}\) carries

\[
 \boxed{

 t\in I_n^{\rm int},\quad

 \tag{CDR.62}

Thus both pressure-complete source ancestries belong to the same disjoint

The same selected branch has

Combining FIM with the canonical record before source-square Cauchy does
force the desired same-triad geometry:

\[
 \boxed{
\begin{aligned}
 \text{failed canonical record}
 &\Longrightarrow
 \text{dynamic-core high-output source square}\\
 &\Longrightarrow

 \tag{CDR.64}
\]

The static floor acts on the minimum of the three geometric legs, which is
why it applies to both physical inputs in every one of the six output/input
assignments.  The dynamic selector remains frozen at receiver time and is
never differentiated.

The survivor is still a scale-critical fourth-moment concentration.  The
datum pays `(CDR.59)`, not `(CDR.53)`.  This note therefore proves a genuine
double-recent-parent localization, but not a strict reduction, a datum-paid
turn-down, `(TIR.37a)`, or MPP closure.
