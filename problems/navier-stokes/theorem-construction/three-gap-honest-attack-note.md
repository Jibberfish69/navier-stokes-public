## Gap 1. Exactness quotient

### Candidate object

Let the full visible packet module be

```math
\mathcal T_{\mathrm{full}}
:=
\mathcal T_{\mathrm{jet}}
\oplus
\mathcal T_{\mathrm{sig}}
\oplus
\mathcal T_{\mathrm{desc}},
```

where:

```math
\mathcal T_{\mathrm{jet}}
:=
\bigoplus_{A,B}
\mathcal A\cdot
\{\mathcal P_{A,B},\mathcal L_{A,B},\mathcal R_{A,B}\},
```

with

```math
\mathcal P_{A,B}
:=
\langle \nabla \Pi_A,J_B\rangle
+
\langle J_A,\nabla \Pi_B\rangle,
```

```math
\mathcal L_{A,B}
:=
\langle (u\cdot\nabla)J_A,J_B\rangle
+
\langle J_A,(u\cdot\nabla)J_B\rangle,
```

```math
\mathcal R_{A,B}
:=
\langle \widetilde T_A,J_B\rangle
+
\langle J_A,\widetilde T_B\rangle,
```

and

```math
\mathcal T_{\mathrm{sig}}
:=
\int^{\oplus}\mathcal A_\ell\cdot \mathfrak c_\ell\,\frac{d\ell}{\ell},
\qquad
\mathfrak c_\ell
:=
\ell^{-2}u_\ell[Q_\ell,b_\ell^{meso}\!\cdot\nabla]u.
```

The exactness candidate is

```math
0
\to
\mathcal E_{\mathrm{exact}}
\to
\mathcal T_{\mathrm{full}}
\overset{\pi}{\to}
\mathcal S
\to
0,
\tag{1}
```

with `\mathcal E_{\mathrm{exact}}` generated by:

1. pressure-trivial generators:
   ```math
   \mathcal P_{A,B};
   ```
2. transport-skew generators:
   ```math
   \mathcal L_{A,B};
   ```
3. signed descent generators:
   ```math
   \nabla_x\cdot J_\ell,\qquad
   \partial_tR_\ell,\qquad
   (\ell\partial_\ell)\Psi_\ell;
   ```
4. gluing/contact generators suggested by the jet/bicomplex route.

## Gap 2. Primitive-survivor identification

### Exact Hopf-side residual

For derivative label `A=(m,\alpha)` and Hopf symbol `\Theta^A`, the strict
reduced coproduct is

```math
\Delta'\Theta^A
:=
\Delta\Theta^A-1\otimes\Theta^A-\Theta^A\otimes 1
=
\sum_{0<B<A}\binom{A}{B}\Theta^B\otimes\Theta^{A-B}.
\tag{9}
```

Under `B(f,g):=(f\cdot\nabla)g`, this gives the interior mixed transport
packet

```math
T_A^{int}
:=
B\!\left((J\otimes J)\Delta'\Theta^A\right)
=
\sum_{0<B<A}\binom{A}{B}(J_B\cdot\nabla)J_{A-B}.
\tag{10}
```

### Candidate primitive-survivor theorem

After quotienting by exact and edge/spill layers, the hoped-for theorem is:

```math

=
\mathcal T_{\mathrm{exact}}

\mathcal T_{\mathrm{shuffle\text{-}composite}}
+
\mathcal S_{\mathrm{prim}},
}
\tag{11}
```

with the residual class `\mathcal S_{\mathrm{prim}}` primitive or coideal.

## Gap 3. No-loss deformation-side domination

### Exact differentiated Lagrangian equation

With

```math
U_\alpha:=\partial_a^\alpha v,
\qquad
Q_\alpha:=\partial_a^\alpha q,
\qquad
G:=AA^\top,
```

the differentiated Lagrangian system is

```math
\partial_t U_\alpha + A^\top\nabla_a Q_\alpha
=
\nu\,\operatorname{div}_a(G\nabla_a U_\alpha)
+
\mathcal C_\alpha^v,
\tag{20}
```

where

```math
\mathcal C_\alpha^v
=
-\sum_{0<\beta\le \alpha}\binom{\alpha}{\beta}
(\partial_a^\beta A^\top)\nabla_a Q_{\alpha-\beta}
+
\nu\sum_{0<\beta\le \alpha}\binom{\alpha}{\beta}
\operatorname{div}_a\!\Big((\partial_a^\beta G)\nabla_a U_{\alpha-\beta}\Big).
\tag{21}
```

The differentiated constraint is

```math
\operatorname{div}_a(AU_\alpha)=\mathcal P_\alpha.
\tag{22}
```

### Candidate drain theorem

The strongest honest target is:

```math
\frac{d}{dt}\mathcal E_r^{Lag}[v,G]
+
c\nu\sum_{1\le |\alpha|\le r}\int G\nabla_a U_\alpha:\nabla_a U_\alpha\,da
+
c\sum_{1\le |\alpha|\le r}\|\mathcal C_\alpha^v\|_{L_a^2}^2
\le 0,
\tag{23}
```

with absorption target

```math
\big|\mathcal N_{N,\mathrm{grad}}^{lift}(t)\big|
\le
\varepsilon\Big(\mathcal D_r^{Lag}(t)+\mathcal C_r^{Lag}(t)\Big)
+
C_*\,2^{-2\delta N}.
\tag{24}
```

### Bounded self-attempt

The top coefficient term can be partially tamed by adding `G`-derivatives to
the energy:

```math
\left|
\nu\int (\partial_a^\alpha G)\,\nabla_a v:\nabla_a U_\alpha\,da
\right|
\le
\varepsilon \nu \|\nabla_a U_\alpha\|_{L_a^2}^2
+
C_{\varepsilon,\nu}\|\nabla_a v\|_{L^\infty}^2
\|\partial_a^\alpha G\|_{L_a^2}^2.
\tag{25}
```

So the pure coefficient-loss problem is not hopeless.

### Exact failure point

After the Route A verification in
[lemma-4b-no-loss-pressure-recovery-attack.md](/Users/thomasbirnie/Documents/Research-Consolidation/problems/navier-stokes/theorem-construction/lemma-4b-no-loss-pressure-recovery-attack.md#L885),
the naked principal viscous-pressure contribution is no longer the live wall.
It reduces exactly to

```math
\mathcal B_G(\operatorname{div}_a(AG\nabla_aU_\alpha),\mathcal Z_\alpha)
=
-\|\mathcal P_\alpha\|_{L_a^2}^2
-
\mathcal B_G(R_\alpha,\mathcal Z_\alpha),
\tag{26}
```

with

```math
R_\alpha=\operatorname{div}_a\!\big(G(\nabla_aA)U_\alpha\big).
\tag{27}
```

So the remaining no-loss issue is narrower:

```math
\boxed{
\text{can one justify a same-depth bound for }
\mathcal B_G(R_\alpha,\mathcal Z_\alpha)
\text{ on the current theorem surface?}
}
\tag{28}
```

The strongest bound currently available is conditional on the coefficient
window

```math
G\nabla_aA,\ \nabla_a(G\nabla_aA)\in L^\infty,
\tag{29}
```

which is stronger than what the current six-lemma mainline explicitly owns.

So Gap 3 is now:

```math
\boxed{
\text{the pressure wall has reduced to a coefficient-window problem for the Route A remainder,}
}
```

```math
\boxed{
\text{not the original naked top-order viscous-pressure term.}
}
\tag{30}
```

## Honest verdict

The three-gap attack is therefore:

1. close the lifted exactness module so the survivor quotient is a theorem,
   not a slogan;
2. prove that the first truly non-composite packet `\mathcal A_{\ell,r}` is
   exactly the Hopf primitive residual in the lifted quotient;
3. prove a no-loss variable-coefficient pressure/elliptic estimate that lets
   the Lagrangian deformation coercion absorb that survivor.

At present:

- Gap 1 is explicit on the jet side and formal on the lifted side;
- Gap 2 has the right abstract residual and the right packet-side candidate,
  but no theorem equating them;
- Gap 3 has a plausible coefficient-control start, but still fails at
  top-order pressure recovery.
