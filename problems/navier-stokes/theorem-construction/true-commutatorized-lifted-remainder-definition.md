# True Commutatorized Lifted Remainder Definition

## Purpose

The bare separated shell exchange vanishes in the geometry `j+M<k<ell-4`. The live lifted object comes from the gradient high-side remainder generated by

```math
(S_{j-4}-S_{N+M})u.
```

Thus the transport shell is intermediate:

```math
N+M<k<j-4,
```

and the active shell lies in the output collar:

```math
|\ell-j|\le C_{LP}.
```

## Definition

Set `a_k:=Delta_k u`. Define the true commutatorized lifted remainder by

```math
\mathcal R_{j,k,\ell}^{lift}(t)
:=
2^{2j}\left\langle
[\Delta_j,a_k(t)\cdot\nabla]\Delta_\ell u(t),
\Delta_j u(t)
\right\rangle,
```

with support conditions

```math
j\ge N,
\qquad
N+M<k<j-4,
\qquad
|\ell-j|\le C_{LP}.
```

Equivalently,

```math
\mathcal R_{j,k,\ell}^{lift}
=
2^{2j}\left\langle
\Delta_j(a_k\cdot\nabla\Delta_\ell u),
\Delta_j u
\right\rangle
-
2^{2j}\left\langle
a_k\cdot\nabla\Delta_j\Delta_\ell u,
\Delta_j u
\right\rangle.
```

The second term is the transport cancellation term. Since `a_k` is divergence-free,

```math
\left\langle a_k\cdot\nabla\Delta_j\Delta_\ell u,
\Delta_j\Delta_\ell u\right\rangle=0,
```

and the output-collar replacement converts the lifted transport contribution into the commutator remainder above.

## Lifted packet decomposition

The gradient lifted packet used by this route is the fixed-collar sum

```math
\mathfrak H_N^{grad,lift}(t)
:=
\sum_{j\ge N}
\sum_{N+M<k<j-4}
\sum_{|\ell-j|\le C_{LP}}
\mathcal R_{j,k,\ell}^{lift}(t).
```

This is the live terminal record for the signed weighted route.

## Signed weighted object

Define

```math
\mathfrak G_N^{lift,\sigma}(t)
:=
\sum_{j\ge N}
\sum_{N+M<k<j-4}
\sum_{|\ell-j|\le C_{LP}}
W_{j,k,\ell}^{\sigma}
\mathcal R_{j,k,\ell}^{lift}(t),
```

where `W_{j,k,ell}^sigma` is the outer one-sided weighted-tail coefficient inherited from the lifted packet route.

The next theorem target is

```math
\int_0^T\mathfrak G_N^{lift,\sigma}(t)dt
\le C2^{-2\delta N},
```

or an equivalent signed estimate before absolute values are introduced.
