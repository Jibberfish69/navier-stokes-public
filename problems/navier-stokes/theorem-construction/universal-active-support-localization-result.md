# Universal Active-Support Localization Result

## Target

A global selector independent of the test readout requires a carrier core `\mathcal K_j(t)` satisfying

```math
\operatorname{supp}(\widetilde Q_iP_{\le j}v_{coh})^{+M}
\subseteq
\mathcal K_j(t)
\qquad
\text{for every active }v_{coh}.
\tag{UASL.1}
```

## Minimal global core

Let `\mathcal A_{j,i}(t)` denote the active coherent readout class entering the collar at `(i,j,t)`. Define

```math
\mathcal K_{j,i}^{0}(t)
:=
\overline{\bigcup_{v\in\mathcal A_{j,i}(t)}
\operatorname{supp}(\widetilde Q_iP_{\le j}v)}.
\tag{UASL.2}
```

and then enlarge by the fixed collar:

```math
\mathcal K_{j,i}(t)
:=
(\mathcal K_{j,i}^{0}(t))^{+M}.
\tag{UASL.3}
```

Then every active collar support satisfies

```math
\operatorname{supp}(\widetilde Q_iP_{\le j}v_{coh})^{+M}
\subseteq
\mathcal K_{j,i}(t).
\tag{UASL.4}
```

### Proof

For every `v\in\mathcal A_{j,i}(t)`, its localized support appears in the union defining `\mathcal K_{j,i}^{0}(t)`. Taking closure and then the fixed collar enlargement gives `UASL.4`. ∎

## Minimality

If another closed carrier core `\mathcal K_j(t)` satisfies `UASL.1`, then

```math
\mathcal K_{j,i}(t)
\subseteq
\mathcal K_j(t).
\tag{UASL.5}
```

Thus `\mathcal K_{j,i}(t)` is the smallest closed global collar core generated by the active readout class.

## Carrier-localized active class

A stronger geometric supplier is the carrier-localization statement

```math
\operatorname{supp}(\widetilde Q_iP_{\le j}v)
\subseteq
\Gamma_j(t)
\qquad
\text{for all }v\in\mathcal A_{j,i}(t).
\tag{UASL.6}
```

Under `UASL.6`, the carrier core

```math
\mathcal K_j(t):=\Gamma_j(t)^{+M}
\tag{UASL.7}
```

satisfies `UASL.1`.

## Proper-core condition

A formal global selector always exists through `UASL.2`--`UASL.3`. Its geometric content depends on the proper-core condition

```math
\mathcal K_{j,i}(t)\subsetneq\mathbb R^3
\quad\text{with controlled fixed }2^{-j}\text{ collar size.}
\tag{UASL.8}
```

If the union core fills the ambient space, the associated global selector is the full-space plateau `w_j\equiv1`; this closes the weighted algebra while providing no localization gain.

## Result

Universal active-support localization is complete at the formal level by the minimal-core construction. The remaining geometric theorem is the controlled proper-core statement `UASL.8`, preferably supplied by carrier localization `UASL.6`.
