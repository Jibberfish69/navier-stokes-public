For the unforced three-dimensional incompressible Navier--Stokes equations on
\(\R^3\), we prove that one cutoff-uniform estimate on the maximal classical
solution rules out a finite maximal time.

Fix \(\nu>0\), let \(u_0\in\mathscr S(\R^3;\R^3)\) be divergence-free, and
suppose the corresponding solution \(u\) has maximal lifespan \([0,T_*)\) with
\(T_*<\infty\).  Classical smoothness controls any chosen finite derivative
block on each strict subinterval \([0,T]\), but the resulting bound may
deteriorate as \(T\uparrow T_*\).  What is not automatic is the stronger
statement that, for every pair of integers \(N,M\geq0\),
\[
  \sup_{0<T<T_*}
  \sum_{n=0}^{N}
  \left(
    \|\partial_t^n u\|_{L^2(0,T;H^{M+1})}^{2}
    +
    \|\partial_t^{n+1}u\|_{L^2(0,T;H^{M-1})}^{2}
  \right)
  <\infty.
\]
With this bound, the Hilbert-space trace theorem carries \(u\) to a limit in
every finite Sobolev space, and compatibility among the blocks makes those
limits agree as one terminal velocity
\(u_*\in\bigcap_{m<\infty}H^m(\R^3)\).  Local well-posedness then continues the
original solution from \(u_*\) beyond \(T_*\), contradicting maximality; the
continued solution is smooth for all time.

The argument presented here proves this closure but does not derive the
displayed bound from \((u_0,\nu)\), so its global-regularity conclusion remains
conditional on that missing derivation.
