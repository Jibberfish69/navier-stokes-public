\subsection{The same spatial ladder inside every response}\label{sub:SobolevRegularityInsideEveryCompletedRow}

Fix one temporal response (V_r).  It is itself a velocity-like field driven by all
the lower responses that produced it.  For (r=1), the differentiated equation reads
\[
  V_2
  +(V_1\cdot\nabla)V_0
  +(V_0\cdot\nabla)V_1
  +\nabla Q_1
  =\nu\Delta V_1.
\]
The transport has split into two terms, the pressure has differentiated with it, and
the same Laplacian still acts linearly on (V_1).  Pairing this equation at spatial
height (s) gives the same balance we found for (u).

At arbitrary temporal order, set
\begin{align*}
  E_{r,s}
  &:=\frac12\norm{\Lambda^sV_r}_2^2,
  \\
  \mathcal P_{r,s}
  &:=-\operatorname{Re}
  \pair{\Lambda^sV_r}
  {\Lambda^s\!\left(
    \sum_{a=0}^{r}\binom{r}{a}(V_a\cdot\nabla)V_{r-a}
    +\nabla Q_r
  \right)}_{L^2}.
\end{align*}
The recurrence \eqref{eq:BodyTemporalVelocityRecurrence} gives
\begin{equation}\label{eq:BodyEveryTemporalRowSpatialEnergy}
  E_{r,s}'=\mathcal P_{r,s}-2\nu E_{r,s+1}.
\end{equation}
Starting from (s=\tfrac12) and repeating the critical-height calculation yields
\begin{equation}\label{eq:BodyEveryTemporalRowCompletedHeight}
  \partial_t^nE_{r,1/2}
  =(-2\nu)^nE_{r,n+1/2}
  +\sum_{j=0}^{n-1}
  (-2\nu)^j
  \partial_t^{\,n-1-j}\mathcal P_{r,j+1/2}.
\end{equation}
So there is not one spatial ladder attached only to (u).  There is a separate ladder
inside (u_t), another inside (u_{tt}), and another inside every fixed (V_r).
Temporal order selects the response; spatial order asks how finely that response is
resolved.  The equation keeps those directions distinct while viscosity connects each
row to its own next spatial height.

Now fix one row (V_r) and return to the singularity.  Repeated integration in time
showed that a finite terminal time would force
\[
  \sup_{0<t<T_*}\norm{V_r(t)}_3=\infty.
\]
To stop that escape, it is enough to place the same row in
(C([0,T_*];H^1)), because (H^1(\R^3)\hookrightarrow L^3(\R^3)).  But a terminal
trace cannot be read from one space-time norm alone.  For (V_r) to arrive
continuously in (H^1), the natural pair is
\[
  V_r\in L^2(I_*;H^2),
  \qquad
  V_{r+1}=\partial_tV_r\in L^2(I_*;L^2).
\]
More generally, an (H^m) trace asks for
\[
  V_r\in L^2(I_*;H^{m+1}),
  \qquad
  V_{r+1}\in L^2(I_*;H^{m-1}).
\]
The two rows meet at the missing middle height.  That adjacent pair is the first finite
piece of the grid with enough information to survive the terminal time.
